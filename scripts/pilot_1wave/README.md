# Pilot one-wave drivers

This directory is the reusable-code entry point for pilot one-wave preparation, calibration, training orchestration, verification, post-processing, scoring, retention, and the pinned Grounded-SAM runtime build.

Tests live in `tests/pilot_1wave/`. Frozen configs and run receipts remain in `phases/p2-gsjso/`; shared historical metric and read-out implementations stay phase-local where their exact SHA or path is part of the protocol.
