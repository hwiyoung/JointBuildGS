# v7 작업 이슈

- 준비 1차: 호스트 표준라이브러리 파일 작성 중 변수 재사용(TypeError)으로 설정 파일 생성이 중단됐다. 뒤따른 launcher는 설정 복사(FileNotFoundError) 단계에서 종료했고 Docker 과학 계산은 시작되지 않았다. 부분 run/source와 실패 영수증을 보존했다. 변수명을 분리해 설정을 만들고 별도 v7-r2로 실행한다. 기존 v5/v6 결과 및 원자료 변경 없음.

- 해결 확인: 별도 `PHD-WU-VALLET-SYNTHESIS-v7-r2` Docker 실행 exit 0. 세 지역 입력 해시·마스크·출처 집계·F1 분자/분모·평균 합계 검산 및 PNG/PDF/CSV 생성 완료. 이전 준비 실패는 수치 계산 단계에 들어가기 전 발생했다.
- 문헌 접근: GeoGS 출판사 전문 접근 실패. 관련 주장은 출판사 초록·공식 README·공식 코드 확인 수준으로 한정한다. ARSGaussian HTML v2 접근은 404였지만 PDF v2 전문은 별도 검토에서 확인했다. 코드 미공개/미확인은 연구 실패로 해석하지 않는다.
