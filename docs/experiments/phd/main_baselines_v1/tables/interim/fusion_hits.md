# 판정의 놓침과 잘못 잡음 — MVS 기반 결합(재현)과 본 방법의 판정으로 갈아 끼운 변형 (발주문 6.5, 6.6)

- 이 발주에서 냄. 영역 파일 v3의 평가 범위 0.25 m 패치로 센다. 몫은 그 코드의 패치 넓이 대비 넓이 몫이다.
- 결합: 패치 가운데가 최종 변화 칸(색 문턱 25)에 들면 '변화'. 놓친 변화는 둘로 나눠 적는다. '판정함'은 그 칸을 짝 있는 시점 둘 이상이 보고 변화가 아니라고 한 것, '판정 못 함'은 짝 있는 시점 둘 미만이라 판정이 없는 것이다.
- 변형: 본 방법의 학습 전 판정(r14 기본값, 전파 포함)이 충돌이면 '잡음', 일치면 '놓침', 혼재·근거 부족·없음(비가시)은 '미판정'으로 따로 적는다.
- 코드 13은 영상에 보이나 MVS가 없어 색으로 찾아도 채울 깊이가 없는 곳, 코드 14는 어느 학습 영상에도 보이지 않는 곳이다. 넓이와 변화 칸에 든 몫만 적는다.
- 모든 몫은 패치 배열(결합 `detect/patches.npz`, 변형은 판정 파일과 영역 파일)에서 다시 셌다. 각 결과의 기록과 모두 같았다(표의 '다시 셈'과 끝의 '점검').
