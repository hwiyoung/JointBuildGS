# Wu–Vallet 동등조건 재실행 v5

2026-09-07 · `PHD-WU-VALLET-MATCHED-v5` · `scientific_verdict: null`

## 실행 이유

사용자는 구현 결함을 교정하고 방법 간 조건을 동일하게 맞추는 일을 선행해야 한다고 지적했다. 기존 v4 주표는 추가 관측지원 시점 P1/P2와 기존 hash-first 시점 P3를 함께 놓았다. 각 지역 내부의 원점 전후 비교는 가능했지만, 서로 다른 시점 선택 절차의 결과를 묶어 구역별 알고리즘 효과로 설명하기에는 통제가 부족했다. 알려진 작은 변화영역 재유입 버그는 v3에서 교정됐으며, 이를 미수정 상태인 것처럼 모호하게 설명한 것도 정정한다.

이번 실행은 세 구역 모두 같은 정책·같은 구현을 적용하고, 독립적인 핵심 코드 감사와 회귀 검증을 선행한다. 기존 v1–v4 파일·결과·서비스를 보존하며 새 v5 경로에 기록한다. 기존 396개 dirty/untracked 파일은 시작 시 해시·tar로 보존했다. 연구 우위나 원논문 실패를 미리 결론내리지 않는다.

## 공통 입력과 비교 규칙

1. 기존 P1/P2/P3 prism, ALS 원점·원행·좌표 변환을 유지한다. 지역 정의는 기존 개발 범위이며 평가 점수로 crop을 변경하지 않는다.
2. 각 지역에 이미 동결된 전체 영상 집합 113/66/157개를 모두 검사한다. 원점 메시의 0.5m XY 점유 셀 수가 최대인 시점을 선택하고, 동률은 `PHD-WU-VALLET-P3-v1` seed의 hash 순서로 결정한다. 최소 64면, image edge 2m/depth jump 1m 규칙은 전 구역 동일하다. UAS나 갱신 결과로 시점을 선택하지 않는다.
3. ALS 주변 문맥은 각 prism에서 XY 25m buffer, Z[-90,80]m로 통일한다. scan mesh 설정·추정 궤적 정책·거리 0.3m·양방향 광선·교정된 최종 점 조립 규칙을 공유한다. P3의 legacy `p3_*` 배열은 내용 변화 없는 `region_*` alias로 연결하고 dtype·shape·원배열 일치를 검증한다.
4. 세 구역 모두 같은 v5 updater로 새 갱신을 실행한다. 과거 P3 출력만 재사용하지 않는다. 작은 영역 면적 0/0.25/1/4m²와 1m²의 CHANGED-only를 모두 산출하고, 주표는 전 구역 1m²다. 결과별 최적 문턱을 사후 선택하지 않는다.
5. 각 지역 내 ALS 단독은 `common.old_xyz`, 영상 단독은 `common.new_xyz`, 합집합은 둘의 결합, Wu는 같은 배열의 선택 부분집합이다. 점 이동·평활화·GS를 넣지 않는다. OpenMVS 융합점은 별도 생산 계보의 문맥 자료로 두며 동일입력 주비교와 분리한다.

## 구현 검증과 평가 경계

v2의 잘못된 조립 결과를 사용하지 않고 raw face evidence와 v3 교정 조립만 사용하는 것을 검사한다. 작은 new 변화영역만 지지받는 점은 다시 추가될 수 없어야 한다. 일치·신축·철거·단독 관측·혼합 면 정점의 기대 동작을 점검한다. 알고리즘이 부정확한 새 기하를 변화로 받는 합성 대조는 실행 오류와 방법의 동작을 구분하는 기제 검사이며 실측 실패의 증명으로 대신하지 않는다.

후보 생성·갱신 컨테이너에는 필요한 영상·과거 ALS·센서 입력만 읽기 전용으로 마운트한다. raw UAS뿐 아니라 기존 UAS crop도 접근하지 못한다. 세 지역 후보와 입력 해시, 공통 코드/설정 gate를 모두 확인한 뒤 별도 평가에서 기존 v4 UAS crop을 정확히 재사용한다.

평가의 고정 문턱은 0.1/0.25/0.5/1/2m다. 모든 원점으로 양방향 최근접 거리, precision/recall/F1, 0.5m XY 결손을 계산하고 같은 단면·높이색·출처 표시로 비교한다. UAS는 실제 평가 기준이며, 과거 개발에서 이미 결과를 보았기 때문에 독립 blind/confirmatory 평가라고 하지 않는다. 작업 EPSG:25832와 UAS header EPSG:32632의 기존 좌표 처리·datum/epoch·정합 한계는 전 구역에 동일하게 기록한다.

## 원문 재현과 동등조건의 구분

같은 대체 입력/구현을 모든 구역·비교군에 적용하는 것은 비교 조건의 통제다. 이것만으로 저자 원방법과 동일함이 입증되지는 않는다. PSMNet 재학습과 다중시점 전방교차, 실측 ALS 궤적, 미공개 정제/광선 세부에 대한 원문 차이는 별도 감사에 남긴다. 오류가 확인된 코드는 먼저 교정하고, 미확인 세부를 원논문 결과인 것처럼 명명하지 않는다. A 판단과 B 재구성은 독립적으로 유지하며 이번 갱신 점군 평가는 B 렌더/텍스처 품질 비교를 대신하지 않는다.
