# 검증 기록

수치 검증과 그림 검토를 구분한다. 사용자 그림 승인과 과학적 결론은 포함하지 않는다.

- r2: 별도 합산 코드로 면 기록 2,970개와 패치 3,363,896개의 넓이·영역·참값 연결을 확인했다. 지역 중복이 있으므로 서로 다른 면 또는 패치의 모집단 수를 뜻하지 않는다.
- r2: 입력 239개 파일의 해시, 작은 면 합계, 순도 분포 합계, 학습 사진 소속, 공개 파일의 확인용 건물 정보 누출 여부를 검사했다. 그림 48장의 PNG와 같은 이름 JSON을 확인했다.
- 최종 공통 코드로 r2를 다시 계산했다. 실험·개발용 70개와 확인용 36개 파생 파일, 합계 106개가 이전 파일과 SHA-256 기준 바이트 동일했다. 면별 표와 패치 연결 파일이 포함된다. 검사 목록은 외부 결과 폴더의 `r2_replay_before.sha256` 및 `holdout/r2_replay_before.sha256`에 보존한다.
- 대표 그림 직접 검토: B173 주변의 B173 항공 LiDAR 지도, R1 LoD2 전체 지도, B0 LoD2 벽 펼친 그림, r2 순도 분포. 글자·범례·번호표·좌표·색과 빨간 점선을 확인했다. 전체 그림의 사용자 수용을 대신하지 않는다.
- r7: 면 기록 2,970개·패치 3,363,896개를 같은 별도 합산 코드로 검증했다. r2와 면 연결·기하·넓이·참값이 정확히 같고, 영역 변화는 기존 관측 없음에서 저장된 사라짐 표지로 바뀐 것뿐이다. 개발용·확인용도 저장된 사라짐 배열과 전체 원소를 대조했다. 입력 401개 파일의 해시가 유지됐고, 공개 확인용 상세값 누출은 발견되지 않았다.
- r7 그림 48장의 PNG·JSON과 학습 사진 소속을 확인했다. B173 주변의 B173 LoD2 지도, B0 벽 펼친 그림, r7 순도 분포도 직접 열어 검토했다. 두 판 합계는 그림 96장이다. 실험 지역 면 기록 88개의 영역 비율 변화는 별도 표에 있다. 중복 지역은 합쳐 모집단으로 해석하지 않는다.
- 지도의 빈 칸은 평가 패치가 없는 곳이다. 기울어진 면을 평면 칸으로 모으면서 생긴 빈 칸도 보간하지 않았다. 사진은 선택한 학습 영상의 화면 범위까지만 보인다. 지역 전체 지도 옆에는 가장 넓게 평가된 건물 한 채의 사진을 두고, 건물별 그림도 제공한다.
- 벽면은 남·동·북·서 순서로 놓되 실제 모서리가 이어지지 않는 연결은 그림과 JSON에 남겼다. 끊김 없는 실제 둘레라고 해석하지 않는다.

정확한 검사 결과는 `tables/verification_r2.json`, `tables/verification_r7.json`과 각 그림의 JSON에 있다. ZIP 검사는 내부 파일 SHA-256와 CRC를 확인하며 원본 입력을 포함한 전체 재계산을 뜻하지 않는다.
