# P2 A→B v6 실제 개발 결과

실제 P2 영상에서 계산한 관측 구간을 Gaussian의 허용 위치와 렌더 표면 검사에 연결해
실행했다. **연결은 동작했지만, 현재 구현은 구조 보호와 유의미한 세부 개선을 함께
달성하지 못했다.** 이 결과를 박사 기여 입증이나 전체 A 완성으로 보고하지 않는다.
`scientific_verdict: null`.

## 무엇을 바꾸고 무엇을 확인했는가

| 수정 | 기대 | 실제 결과 |
|---|---|---|
| 합성 오차 범위 대신 실제 P2 decision 22뷰의 두 그룹 위치 비용 계산 | 관측 근거가 있는 구간을 B에 전달 | 16,476 anchor 중 48개, 266,361 Gaussian 중 381개(0.143%) |
| 관측 구간에서 최악 사용오차를 만족하는 출력 위치 구간 계산 | 유지 가능과 보정 필요 구분 | 초기 사용 범위 안 139개, 보정 필요 242개 |
| 매 기하 제안에서 두 그룹 비용을 재검사하는 동적 gate | RGB만 개선하는 불리한 기하 갱신 억제 | 고정 마스크의 그룹 비용 악화 132개→동적 0개; 보호 표면 위반 62→14 ray |
| 실제 렌더 깊이·지지 검사와 최종 A 구간 검사 결합 | 허용 위치와 출력 표면 조건 동시 집행 | 움직인 점의 구간 위반 0, 그룹 비용 악화 0, 보호 ray 위반 0 |
| 동일 G0·색 학습·일정의 5조건과 UAS 평가 | 구조를 보호하면서 세부가 개선되는지 | 최종 27개만 1mm 초과 이동; 보정 필요 242개 모두 미해결; 추가 외관·세부 개선은 사실상 없음 |

계산식과 실제 P2 수치 예는 [B 방법](B_METHOD_ko_v6.md), A 원영상 비용과 관측 실패 분해는
[A 실행 결과](A_RETURN_ko_v6.md)에 있다. A는 두 소스 후보의 영상 비용을 실제 계산했지만
공동 시스템 오차·현재성 보정과 영역별 최종 소스 선택은 완료하지 않았다. 모든 B 조건은
사용자가 지정한 현재 MVS G0에서 출발하며 A가 전체 P2에서 MVS를 선택했다는 뜻이 아니다.

## 같은 초기값의 최종 비교

동일한 MVS Gaussian 266,361개, 33 train/11 eval 뷰, 512개 tile 순서, SH3 색 손실을
사용했다. 원본 방향·크기·opacity·개수는 고정했다. 바뀌는 기하 변수는 중심의 법선
방향 변위다. 외관 분모는 모든 조건에서 같은 5,150,892pixel이다. 아래 최종 값은
`PHD-P2-AB-V6-B-SURFACE-v3`와 별도 C 평가의 값이다.

| 조건 | MAE ↓ | PSNR dB ↑ | 최종 1mm 초과 이동 수 | 보호 630 ray 위반 | UAS 거리 p90 m ↓ | 0.5m 높이 잔차 RMSE m ↓ |
|---|---:|---:|---:|---:|---:|---:|
| MVS 초기 | 0.161113 | 12.82560 | 0 | 0 | 1.123701 | 1.552289 |
| 기하 고정·색 학습 | 0.149427 | 13.25560 | 0 | 0 | 1.123701 | 1.552289 |
| RGB 잔차 기하 갱신 | 0.149107 | 13.26851 | 256,467 | 164 | 1.121946 | 1.539382 |
| 고정 관측 마스크 | 0.149413 | 13.25576 | 323 | 62 | 1.123726 | 1.552111 |
| 동적 관측 마스크 | 0.149418 | 13.25558 | 161 | 14 | 1.123720 | 1.552061 |
| 동적 마스크+최종 A·표면 검사 | 0.149430 | 13.25530 | 27 | 0 | 1.123712 | 1.552279 |

**외관:** 초기보다 좋아진 대부분은 모든 조건이 공유하는 색 학습 효과다. 최종 제약
조건은 기하 고정 기준보다 MAE가 약 0.000003 높아 사실상 같다. RGB 잔차 조건의
0.000320 감소도 크지 않으며, 절대 PSNR 약 13.26dB를 고품질 복원이라고 부르지 않는다.
이 RGB 잔차 조건은 법선 변위만 허용하는 ablation이다. 공식 vanilla GS, 2DGS,
SuGaR의 완전한 구현·충분한 학습 비교가 아니다.

**구조:** 최종 조건의 27개 이동은 최대 0.02051m였고 보호 ray의 평균 깊이 변화는
0.002804m였다. 검사한 630 ray의 허용 깊이와 표면 지지는 통과했다. 전체 경계·위상·
벽과 모든 출력 표면의 구조 유지가 만족됐다고 확대하지 않는다. 특히 242개 보정 필요
지점은 원래 위치에 남았다. 이들은 보정 성공이나 A 채택으로 세지 않는다.

**세부:** 0.5m 공통 stencil RMSE는 1.55228882→1.55227852m로 차이가 극히 작다.
0.25m에서는 1.55586865→1.55587036m, 1m에서는 1.94547561→1.94548009m로 역시
사실상 같았다. 이번 국소 기하 갱신은 실행했으며 전체 세부 개선은 확인하지 못했다.
Gaussian 추가·분할과 없는 형상의 생성은 실행하지 않았다. 따라서 창틀·용마루·배관
복원은 아직 시험하지 않았고, 그 방법들이 실패했다고 판정한 것은 아니다.

UAS 참조는 최적화가 완료된 뒤에만 읽었으며 2,325,976개 고정 참조점이다. 모든 조건이
함께 존재하는 0.25/0.5/1m stencil은 각각 33,141/8,297/2,015개이며 전체 적격 참조
stencil 33,707/8,353/2,024개를 함께 기록했다. 높이 잔차는 2.5D 진단으로 벽·겹층·
밀도와 참조 잡음의 영향을 받으며 특정 세부 형상의 정답 평가는 아니다.

## 전역 수치와 국소 열화를 함께 본 결과

A 위치와 마스크로 미리 정한 국소 영역에 UAS 참조점 2,509개가 있었다. 참조 오차로
좋은 영역을 고른 것이 아니다. 이 영역의 0.5m 이내 참조 회복률은 다음과 같다.

| 조건 | 국소 회복률 | 전역 회복률 |
|---|---:|---:|
| 초기 / 기하 고정 | 84.097% | 87.112% |
| RGB 잔차 기하 갱신 | 80.231% | 87.182% |
| 고정 관측 마스크 | 84.735% | 87.111% |
| 동적 관측 마스크 | 84.416% | 87.113% |
| 최종 A·표면 검사 | 84.097% | 87.113% |

RGB 잔차 조건의 전역 수치가 조금 좋아져도 국소 열화가 생겼다. 동적 관측 조건에는
작은 국소 회복 이득이 있지만 14개의 보호 ray 위반이 남았다. 최종 제약은 이 위반을
없앴으나 보정 이득도 제거했다. 점 표본 기반 지표이므로 표면적 비율로 해석하지 않는다.

## 확인된 실패 원인과 수정 내역

1. A의 기존 patch 검사는 틀린 깊이에서 한 번 저텍스처가 나와도 전체 비용 곡선을
   버렸다. 분모 처리를 수정한 별도 A v3에서 유효 곡선 12,345개가 회복됐다. 그래도
   작은 patch의 기준 텍스처 부족, 가림·지지 부족, 검색 경계·비용 평탄 때문에 관측
   범위가 0.143%에 그쳤다. P2 전체에 세부 정보가 없다는 결론은 아니다.
2. B v2의 표면 검사만 통과시키는 backtracking은 보정 중인 점을 허용 구간 밖 중간
   위치로 돌렸다. 보호 ray 위반 0이어도 조건부 구간 위반 217개가 남았다. 별도 B v3은
   최종 제안을 A 구간·그룹 비용으로 다시 검사하며, 미완료 보정은 초기 미해결로 남긴다.
3. v3은 전체 381개 후보 변위를 한 비율로 줄인다. 실제 수용 비율은 32/64/96/128step에
   1/4, 1/16, 1/64, 1/256이고 160step부터 끝까지 0이었다. 한 곳의 표면 충돌이 다른
   곳의 보정도 막는 구현 병목이 확인됐다. 작은 primitive 이동 제한만 추가하면
   원하는 구조 유지·세부 개선이 저절로 양립한다는 가정은 성립하지 않았다.

따라서 다음 설계 변경의 대상은 명확하다. 관측을 얻을 위치와 규모를 정하는 A 관측
구성과, 표면에 함께 기여하는 국소 묶음별로 제약을 푸는 B 변경 제어가 필요하다.
새 세부 생성은 그 다음 독립 축이다. 이 세 항목의 효과를 이번 결과로 미리 주장하거나,
임계값을 계속 바꾸어 P2에 맞춘 성공 수치를 만들지 않았다.

## 정성 검토와 재현

[새 비교 뷰어](http://127.0.0.1:8896/PHD-P2-AB-V6-VIEWER-v1/viewer/?view=333)는 실제
11개 eval 영상, 초기/5조건의 Gaussian RGB 렌더, 출력 법선, 깊이 변화, 최종 갱신
위치와 48개의 실제 A 비용 곡선을 포함한다. 선택한 A 위치를 사진에서 찾아 동기
확대할 수 있다. 초기 마스크는 A 관측 가능 위치, 최종 마스크는 실제 1mm 초과 이동한
중심의 3pixel 투영 진단이다. 이 마스크 자체가 Gaussian 렌더는 아니다.

실제 Chrome 검사는 23종×11뷰, PNG 275개, A 사례 48개, 동기 확대·이동·wipe와
모바일을 포함해 1,105개 검사를 통과했다. 14개 screenshot을 보존했다. 직접 확인한
지붕 전체 영상에서도 색 학습 후의 흐림과 미복원 지지가 남고, 기하 고정과 최종 제약
조건의 차이는 눈에 띄지 않는다. 가장 큰 표시 변위 사례에서도 깊이 변화는 작은 국소
부분이며 창·배관의 새 형상 복원으로 볼 수 없다.

첫 Chrome QA의 한 이미지 로딩은 `ERR_ABORTED`로 실패했고 그 결과를 보존했다.
같은 파일의 HTTP 200 확인 뒤 코드를 바꾸지 않은 별도 QA v2가 통과했다. 일시적 중단의
원인은 확정하지 않았다. 사용자 브라우저 대신 새 임시 profile과 별도 port를 사용했다.

기존 v1–v5 문서·소스·산출물은 보존했다. A v1/v2/v3와 B v1/v2/v3의 실행 snapshot도
따로 남겼다. 최종 사용 경로는 A `OBSERVATIONAL-v3`, B `SURFACE-v3`, C `REFERENCE-v1`,
뷰어 `VIEWER-v1`이며 모두 외부 artifact root의 `phase-payloads/phd/p2_ab_v6/` 아래다.
실행 드라이버와 hash 검증은 [패키징 스크립트](../../../../scripts/phd/p2_ab_v6/package_return.py)에 있다.
