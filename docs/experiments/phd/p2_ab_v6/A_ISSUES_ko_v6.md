# A v6 문제 기록

| ID | 확인 내용 | 조치·상태 |
|---|---|---|
| A6-001 | 집단당 한 영상쌍으로 16,476 anchor 중 24개만 구간을 얻음. 나머지 영상을 검사하지 않아 전체 관측 불가로 해석할 수 없음 | v1 보존. 모든 가능한 쌍의 중앙값을 쓰는 별도 v2 실행 완료 |
| A6-002 | 틀린 후보 변위 한 곳의 flat target이 전체 정상 비용 곡선을 버리는 유효성 오류 | 원본 v1/v2 보존. 후보별 contrast 분모 처리로 수정한 v3 실행. 회귀검산 통과, 실제 MVS 곡선 12,345개 회복 |
| A6-003 | 수정 후에도 48 anchor/381 Gaussian만 조건부 구간을 얻음. 0.143% 적용 범위 | 열림. 참조/모든 후보의 저텍스처·검색 경계·큰 비용·집단 불일치를 구분해 기록. P2 전체 성공으로 해석하지 않음 |
| A6-004 | 1m voxel 첫 native 원점과 같은 patch 근거리 전달이 같은 cell의 더 좋은 texture·세부를 놓칠 수 있음 | 열림. 범위 제한으로 명시. 이번 결과에 맞추어 anchor·ε·slack을 반복 조정하지 않음 |
| A6-005 | 공유 카메라/좌표·정합·MVS/ALS 시스템 오차의 실제 보정은 미구현 | 열림. 절대 소스 승인 ABSTAIN_UNCALIBRATED 유지. 실제 관측 구간의 B 전달과 구분 |

계산 결과와 재현 경로는 [A 실행 결과](A_RETURN_ko_v6.md), 수정 정의는
[texture 유효성 수정](A_TEXTURE_VALIDITY_FIX_ko_v6.md)에 기록했다.
