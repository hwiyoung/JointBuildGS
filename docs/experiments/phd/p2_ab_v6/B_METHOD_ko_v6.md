# B v6 — 관측 구간을 실제 재구성 변경 범위에 연결한 구현

현재 P2의 같은 MVS Gaussian 266,361개에서 색을 학습하면서, A의 실제 영상 검사로
구간을 얻은 곳에만 법선 방향 기하 갱신을 허용한다. 갱신 뒤에는 Gaussian 중심뿐
아니라 실제 미분 가능 렌더링의 깊이와 표면 지지를 검사한다. 미해결인 점은 초기
MVS 비교 배경으로 남으며 A에서 사용 가능한 기하로 채택된 것이 아니다.

이번 구현은 **조건부 구간을 전달하고 재구성에서 집행하는 개발 실험**이다. MVS와
ALS의 공동 시스템 오차 보정, 영역별 최종 소스 선정, 새 세부의 생성은 완료하지
않았다. `scientific_verdict: null`.

## 1. 허용 범위는 신뢰도 가중치가 아니라 결과 위치의 제약이다

기준 위치에서 법선 방향으로 가능한 현재 위치가 `X=[l,h]`라고 하자. 출력 위치 `d`를
사용할 때 최악의 위치 오차는 `r(d)=max(|d-l|, |d-h|)`다. 요구오차를 ε라고 정하면
허용할 출력 위치는 `Cε=[h-ε, l+ε]`다. `h-l>2ε`면 이 범위가 비므로 유보한다.
`d`가 관측 구간 X 안에 있다는 사실만으로 최악 오차가 ε 이내인 것은 아니다.

실제 P2 seed 9747의 관측 구간은 `[-0.075,+0.175]m`다. ε=0.15m인 개발 설정에서는
허용 위치가 `[+0.025,+0.075]m`다. 초기 위치 0m는 통과하지 못하며, 예를 들어
+0.05m는 양 끝까지의 거리가 0.125m여서 통과한다. 따라서 이 점을 0.01m만 움직이고
"보정했다"고 채택하면 안 된다. 보정이 끝나지 않으면 미해결이다.

이 계산의 이론적 전제는 실제 현재 위치가 X에 포함된다는 것이다. 그 전제가 성립하면
모든 `d∈Cε`의 위치 오차가 ε 이내라는 결론은 구간 양 끝 검사로 바로 성립한다.
전제 자체는 이번 사진 비용 곡선으로 확률적으로 보장되지 않는다. 공동 편향이
미보정된 현재 구간을 절대오차 인증 구간으로 부르지 않는다.

전체 A에서는 MVS 오류, ALS 오류, 공유 pose/좌표 오차, 상대 정합 오차와 시기 차이를
함께 허용한 현재 위치 집합을 먼저 구해야 한다. 같은 표면·변화·무대응 가설 중 관측으로
배제하지 못한 가설이 여러 개면 가능한 위치 집합을 합쳐야 하며, 임의로 두 소스 구간을
교차해 좁혀서는 안 된다. 그 집합의 방향별 범위가 위 X를 대체한다. **집합에서 출력
허용 범위로 가는 계산은 같지만, 실제 P2의 공동 오류 집합 추정은 남아 있다.**

## 2. 실제 최적화 변수와 손실

기하 변수는 각 Gaussian 중심의 법선 방향 스칼라 변위 `d_i`다:
`mu_i=mu_i_initial+n_i*d_i`. 방향·크기·opacity·개수는 모든 조건에서 고정한다.
색은 SH3 계수를 학습한다. 새 Gaussian 생성·분할·삭제나 접선 방향 이동은 없다.
따라서 이미 존재하는 표면의 국소 보정은 실행하지만, 없는 창틀·배관을 새로 만드는
실험은 아니다. 정상적인 법선 추정과 같은 local patch 내 평면 근사도 전제다.

사진 손실은 모든 조건에서 같은 `0.8 L1 + 0.2 SSIM`이다. A 관측 조건에는 두 decision
영상 그룹의 위치 비용 평균을 계수 0.05로 추가한다. 색과 기하의 학습률은 각각
0.015, 0.002이며 동일한 512개 tile 순서와 감소율을 사용한다. 가중치와 한계는
UAS 평가 전에 고정한 개발 설정이다. 색 학습 방법 차이가 새 기하 방법 효과로
섞이지 않도록 동일하게 유지한다.

A의 22 decision 뷰에서 계산한 원영상 비용 곡선은 고정한다. B는 별도 33 train 뷰의
RGB를 학습하고, 11 eval 뷰에서 평가한다. 원래 MVS와 영상/pose 계보를 공유하므로
분할을 독립 센서 증거라고 부르지 않는다.

## 3. 동적 마스크의 실제 동작

각 최적화 step에서 후보 변위를 만들고 Cε에 제한한 뒤, **두 decision 영상 그룹의
비용이 모두 비증가하고 하나 이상 감소하는 점**만 갱신한다. 거부한 점은 원래 위치로
복원하고 기하 Adam momentum도 지운다. 색 계수의 학습은 계속한다. 변경 제안마다
통과 여부가 바뀌는 동적 gate이며, 매 step 영상쌍을 다시 고르거나 마스크 추정 신경망을
학습하는 방식은 아니다. 원본 사진에서 미리 계산한 비용 곡선을 변경 위치에서 다시 읽는다.

큰 RGB 잔차만으로 기하를 허용하는 조건을 별도 비교한다. 반사·그림자·색 표현 부족이
큰 RGB 잔차를 만들 수 있으므로 그 조건과 다중 영상의 위치 지지 조건을 구분한다.
이번 비교의 RGB 손실 자체는 모든 조건에서 동일하다.

## 4. Gaussian 위치 제한을 실제 표면 검사로 연결한다

초기 위치가 Cε 안에 있는 지점의 남은 법선 이동 예산은
`b=ε-max(|l|,|h|)`다. 초기 렌더의 ray를 인근 MVS 평면에 연결하고 ray 방향을 r이라
하면, 법선 이동 예산을 ray 깊이 예산 `b/|n·r|`로 변환한다. r은 camera-Z가 1인
비정규화 ray이므로 검사 깊이도 camera-Z 단위다. 사선 입사에서 무한히 넓어지지 않도록
`|n·r|>=0.2`인 경우만 사용한다.

33 train 뷰의 초기 표면 내부에서 4pixel 간격으로 고정한 ray를 보호한다. 초기
geometry mass≥0.7, 2pixel erosion, 인근 seed 거리≤0.75m를 적용한다. 최종 깊이는
독립 C8 geometry mass로 나눈 plane-depth read-out이고 RGB alpha와 분리되어 있다.
검사는 초기 깊이 대비 이동 한계와 geometry mass≥0.5를 모두 요구한다.

32step마다 실제 렌더로 검사하고, 실패하면 마지막 통과 상태와 제안 상태 사이의
변위를 줄여 다시 검사한다. v3에서는 **줄어든 최종 제안에 대해 Cε와 두 영상 그룹
비용을 다시 검사한 다음 렌더 표면을 검사**한다. 미완료 보정이나 비용이 나빠지는
중간 위치는 마지막 상태로 되돌린다. 어떤 제안도 통과하지 않으면 갱신을 유보한다.
최종 결과는 허용 구간 밖으로 움직인 점과 초기보다 영상 그룹 비용이 악화한 점이
없어야 성공 종료한다. 그대로 남은 미해결 초기점은 따로 센다.

이는 실제 출력 표면을 검사하지만, 630개의 제한된 학습 ray에 대한 계약이다. 모든
경계·벽·위상·mesh manifold의 보존을 입증하지 않는다. 최근접 평면의 공간 전달도
근사이며, 서로 다른 표면의 혼합 깊이나 가림 변화까지 전부 보장하는 것은 아니다.

## 5. 비교와 기대 결과

| 동일 입력의 조건 | 실제 변경 | 기대하는 검증 |
|---|---|---|
| 기하 고정·색 학습 | SH3만 | 순수 외관 개선 기준 |
| RGB 잔차 기하 갱신 | 큰 잔차 위치의 법선 변위 | 사진 오차 감소가 기하 정확도로 이어지는지 |
| 고정 관측 마스크 | A 구간·비용, 고정 observable 집합 | 관측 범위만 제한했을 때의 효과 |
| 동적 관측 마스크 | 변경마다 두 그룹 비용 검사 | 불리한 기하 제안을 줄이는지 |
| 동적 마스크+표면 검사 | 최종 A 조건과 렌더 깊이·지지 동시 검사 | 실제 표면 열화 억제와 기하 개선의 양립 여부 |

표면 위반 감소만으로 세부 복원 성공을 선언하지 않는다. 같은 고정 분모의 RGB,
UAS 거리와 회복률, 모든 조건 공통 stencil의 2.5D 높이 잔차, 정성 영상을 함께 본다.
전역 rollback이 너무 많은 갱신을 막는지도 기록한다.

## 6. 박사 기여 후보와 선행연구 범위

동적 마스크나 다중 뷰 일관성 자체가 새롭다는 주장은 하지 않는다.
[SAD-GS](https://vcai.mpi-inf.mpg.de/projects/SAD-GS/)는 구조/주파수 정보와 다중 뷰
일관성을 사용하는 densification을 제안하며,
[VAD-GS](https://arxiv.org/abs/2510.09364)는 visibility를 이용해 뷰를 고르고 MVS로
누락 기하를 복원해 Gaussian을 추가한다. 이들은 이번 normal-only 구현과 비교할
관련 방법이며 기존 과거 ALS의 사용오차를 이번 방식으로 보장한다는 뜻은 아니다.

기여 후보는 **오차·시기 차이가 있는 두 소스에서 확인한 구조의 사용 범위를, 새 세부를
갱신할 위치·방향과 실제 출력 표면의 비열화 조건으로 함께 전달하는 계산**이다.
이를 입증하려면 같은 A 판단·G0·학습량의 강한 재구성법보다 세부가 개선되고 양호
구조의 열화가 감소해야 한다. 본 개발 실험은 그 연결과 실패 지점을 검증하며, 새
세부 생성이나 학위 기여의 성립을 미리 선언하지 않는다.
