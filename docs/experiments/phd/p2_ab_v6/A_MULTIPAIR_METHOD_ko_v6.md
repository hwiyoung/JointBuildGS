# A v6 추가 실행 — 가능한 영상쌍 전체의 비용 중앙값

단일 영상쌍 실행은 16,476 anchor 중 24개만 두 집단의 관측 구간을 얻었다. 가장 큰
시차의 한 쌍이 저텍스처·가림·국소 평면 불일치일 때 나머지 decision 영상의 증거를
검사하지 못하는 계산상의 제한이 있다. 이를 P2 전체의 관측 불가로 해석하지 않는다.

별도 `PHD-P2-AB-V6-A-OBSERVATIONAL-v2`에서 두 11뷰 집단 각각의 모든 비중복 영상쌍,
최대 55쌍을 검사한다. 기존 가시성·1~60° 시차·법선 관측각 기준을 그대로 적용하고
같은 쌍의 기준 영상은 법선 관측각이 좋은 쪽으로 정한다. 색 비용은 쌍 선택에 쓰지 않는다.

기존 7×7 고정 pixel, ±0.30m/0.05m 평면 스캔, NCC·지지·텍스처·구간 기준을 바꾸지
않는다. 각 집단에서 전체 변위에 유효한 비용 곡선이 2쌍 이상 있어야 하며, 모든 유효
영상쌍 비용의 중앙값을 그 집단의 비용 곡선으로 쓴다. 가장 잘 맞는 쌍의 최소값을
고르지 않는다. 두 집단의 관측 구간 합집합·조건부 ε=0.15m 사용오차 계산·같은 patch
근거리 전달은 [첫 방법](A_METHOD_ko_v6.md)과 같다.

각 쌍의 원본 비용·유효성·영상 ID·pixel 수를 `all_pair_profiles.npz`로 보존한다.
MVS/ALS 비교는 두 후보 모두 유효한 동일 영상쌍·동일 pixel만 사용하여 각각 중앙값을
계산한다. 그룹 집계의 유효한 쌍 수 역시 보존한다. 중복 영상으로 만든 쌍은 독립
표본이 아니며 표준오차·확률 계산에 독립성을 가정하지 않는다.

이 추가 측정은 첫 결과를 보존하고 새 실행으로 수행한다. UAS/LoD2 또는 B 최종 평가를
보며 설정을 고른 것이 아니며, 낮은 비용을 주는 사례만 선택하지 않는다. 시스템 편향,
정합, 절대 정확성의 보정되지 않은 상태와 국소 평면·고정 pose 가정은 계속 남는다.
`systematic_error_calibrated=false`, `scientific_verdict=null`이다.
