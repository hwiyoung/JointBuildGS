# A v6 실제 P2 관측 실행 결과

최신 `PHD-P2-AB-V6-A-OBSERVATIONAL-v3`은 실제 P2 decision 사진 22개에서 모든 가능한
영상쌍의 법선 변위 비용을 측정하고, 두 영상 집단이 지지한 **381 Gaussian의 조건부
변위 구간을 B에 실제 전달**했다. 앞선 합성 LP 예제가 아니다. 전체 266,361개 중
0.143%라는 작은 적용 범위를 숨기지 않는다. 공동 시스템 오차 보정과 영역별 최종
MVS/ALS 소스 선택까지 완성한 A 방법은 아니다.

좌표 계약은 기존 공통 P2와 동일한 `SCENE_LOCAL_XYZ`, 수평 CRS `EPSG:25832`다.
world 좌표는 local XYZ에 `[690953, 5336071, 604]`m를 더한다. 새 좌표계나 gravity를
추정하거나 입력 좌표를 변환하지 않았고 `seed_id`로 기존 native 행을 그대로 연결했다.

| 실제 처리 결과 | 수 |
|---|---:|
| 현재 MVS G0 Gaussian | 266,361 |
| 1m 같은 native patch 원점 anchor | 16,476 |
| 두 영상 집단에서 구간을 얻은 anchor | 48 |
| 관측 구간을 전달받은 Gaussian | 381 (0.143%) |
| 초기 0 변위가 조건부 허용 구간에 포함 | 139 |
| 0은 포함되지 않아 조건부 보정 필요 | 242 |

통과 anchor는 38개 unit에 걸쳐 있다. 두 집단 중 충분한 유효 영상쌍이 없는 anchor
15,110개, 높은 최소 비용 682개, 검색 경계·평평한 profile 488개, 다봉 50개, 집단
불일치 93개, 조건부 사용오차 예산 부족 5개를 제외했다. 이는 이 국소 평면/현재
카메라/7×7 patch 측정법의 적용 범위이며, P2 전체에 실제 기하 정보가 없다는 뜻이 아니다.

## 실제 계산 예

아래는 각 유형에서 원점 순서상 첫 사례이며 좋은 비용 크기로 고른 사례가 아니다.
변위는 anchor의 native 법선 방향이고 m 단위다. 좌표는 동일 P2 scene-local frame이다.

| native seed ID / unit | 두 집단의 유효 영상쌍 수 | 관측 위치 구간 | ε=0.15 조건부 후보 허용 구간 | B 목표 변위 | 연결 Gaussian |
|---|---|---|---|---:|---:|
| 9389 / 70 | 4 / 3 | [−0.025, +0.025] | [−0.125, +0.125] | 0.000 | 24 |
| 9747 / 24 | 4 / 3 | [−0.075, +0.175] | [+0.025, +0.075] | +0.075 | 7 |
| 3577 / 204 | 4 / 3 | [−0.275, −0.175] | [−0.325, −0.125] | −0.250 | 3 |

첫 사례는 현재 0 변위를 유지해도 구간 양 끝에 대한 최대 거리가 0.025m여서 조건부
예산이 남는다. 둘째는 0을 그대로 두면 가능한 +0.175m 위치에 대해 예산을 넘으므로
보정이 필요하다. +0.075m로 움직이면 양 끝에 대한 거리는 0.15m/0.10m가 된다. 이는
센서 정확도를 인증한 수치가 아니라 **측정 구간을 진실 포함 구간이라고 가정한**
후보 사용오차 계산이다. 실제 13개 비용과 각 쌍 ID는 원본 NPZ에 남아 있다.

동일 기준 pixel·동일 영상쌍에서 MVS/ALS 양쪽을 평가할 수 있었던 551 anchor에서는
MVS의 최소 집계 비용이 낮은 경우 256개, ALS가 낮은 경우 295개였다. 이는 관측 가능한
제한된 공통 부분의 사진 비용 비교이며, ALS가 현재 전체 기하에 더 정확하다는 뜻이
아니다. 같은 unit 내 XY 최근접 ALS는 후보 제안이며 대응·현재성이 보장되지 않았다.

`handoff_mvs.npz`의 모든 원점 ID, 266,361개 행, finite 구간값과
`mvs_profiles.npz`의 `(2,16476,13)` 형태를 읽어 확인했다. 조건부 최악 사용오차
구간 변환, 경계/집단 불일치 유보, 같은 patch만 공간 전달, 여러 쌍의 중앙값, texture
유효성의 단위검산 8개도
Docker에서 통과했다. 기준 영상은 기존 decision 22개, B train 33개와 eval 11개는
이번 계산에서 사진 입력으로 읽지 않았다. 원본 MVS의 영상 계보 공유는 남는다.

`systematic_error_calibrated=false`, `absolute_source_authority_status=ABSTAIN_UNCALIBRATED`,
`scientific_verdict=null`이다. B가 받은 구간은 [방법 문서](A_METHOD_ko_v6.md)의 국소
평면·고정 pose·가림·공간 전달 가정 아래의 관측 구간이며, 절대 정확성 인증이 아니다.

## 작은 적용 범위의 확인된 원인과 수정

| 보존한 실행 | 계산 | 관측 anchor / 전달 Gaussian | 시간 |
|---|---|---:|---:|
| v1 | 집단마다 기하 기준으로 고른 한 영상쌍 | 24 / 460 | 11.34s |
| v2 | 집단마다 가능한 모든 영상쌍, 최소 2쌍의 중앙값 | 24 / 217 | 37.79s |
| v3 | v2에서 잘못된 변위의 flat target이 전체 곡선을 버리던 처리 수정 | 48 / 381 | 30.90s |

v2는 두 집단에서 2쌍 이상 기하적으로 가능한 anchor가 6,317개, 모든 변위에 36pixel
이상 공통 지지가 있는 anchor가 5,317개였다. 원래 코드는 틀린 변위 하나가 flat
target을 가리켜도 곡선 전체를 버렸다. [수정 정의와 검산](A_TEXTURE_VALIDITY_FIX_ko_v6.md)
후 실제 MVS anchor–쌍에서 12,345개 곡선이 회복되어 유효 곡선이 22,118→34,463개가 됐다.

104,424 기하적 anchor–쌍 방문 중 21,477개는 고정 pixel 지지가 부족했다. 지원이
있는 82,947개 중 33,785개는 **기준 patch 자체가 저텍스처**, 14,699개는 모든 변위의
target이 저텍스처였다. 수정 후에도 가장 큰 병목은 이 작은 patch의 대응 증거 부족이며,
유효한 두 집단 곡선이 있는 1,366 anchor에서도 682개는 최소 비용이 크고 488개는
검색 경계/평평한 구간이다. 하나의 임계값으로 충분한 기하가 있다고 선언하지 않았다.

22 decision 뷰는 기존 66개 뷰를 고정 hash로 나눈 22/33/11 분할에서 온 것이다.
이 22개를 ALS에 유리한 사진만 골라 새로 선정한 것은 아니다. 다만 66개 pool 자체는
역사 P2 evidence bank에서 재사용한 것으로 전체 937뷰에 대한 최적 관측 집합은 아니다.
1m voxel의 첫 native 원점을 대표로 쓰는 방식도 같은 cell 안의 다른 textured/구조
부분을 놓칠 수 있다. 향후 관측 기반 anchor 선택과 더 큰/적응 patch를 별도 실험할
수 있지만 이번 결과를 보고 현재 설정을 계속 바꾸어 coverage를 늘리지는 않았다.

첫 v1 실행 뒤 기본 방법 문서 맨 아래 3개 상대 링크만 수정했다. 실행 payload의 원본
snapshot과 hash는 보존했으며 v1 계산 코드는 바꾸지 않았다. 다중 쌍과 texture 수정은
별도 script/config/source snapshot/run으로 남았다. 이 문서도 실행 후의 결과 설명이다.
