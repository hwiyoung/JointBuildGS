# 두 줄·세 칸 복원 기록

- 사용자 승인: 원래 목적에 맞춰 영역·사진 검사·두 신뢰도 계산의 공간 분포와 영역별 비율을 함께 보는 여섯 패널로 복원한다.
- A·S와 단일 패치의 별도 판정 패널을 없앤다. 6번의 평지붕과 흰 돌출물은 실사 부위 이름으로만 구분한다.
- 기존 단면은 원래 패치 중심 XY에 다섯 높이를 함께 배치했다. 법선 이동에 수평 성분이 있으면 사진의 참조 위치와 같은 공간의 단면이 아니었다. 새 코드는 각 자료의 실제 XYZ를 먼저 구한 뒤 같은 XY 띠에 들어오는 값만 집계한다. 원래 시작·끝 XY와 폭, 제공된 이동량은 바꾸지 않는다.
- 영역·검사 사진에도 두 계산 사진과 동일한 참조값이 있는 지붕 패치를 사용한다. 기존 영역별 비율과의 일치를 검증한다. 이전 그림과 ZIP은 보존한다.
- 제공된 최소점을 학습 결과로 표시하지 않는다. 보존 실패는 제공 깊이 손실 계산의 실패이며, 실사에서 보이는 물체를 원인으로 단정하지 않는다.
- 첫 prepare 실행은 기존 자원 보호 실행기에서 후처리/대형 채점 잠금으로 입장하지 못했다. 컨테이너·계산·그림 생성은 시작되지 않았다. 정책 변경안은 PROPOSED_NOT_ACTIVE이며 기존 승인 정책은 변경하지 않았다.
- 준비된 스크립트와 설정은 아직 실행 및 시각 검증 전이다. 실행하지 않은 코드를 통과 또는 완료로 보고하지 않는다. `scientific_verdict: null`.

## 실행과 검증

- 사용자가 CPU 1개·RAM 2 GiB·여유 32 GiB 시작/24 GiB 중단 조건에서 이번 정적 그림 작업의 병행을 승인했다. 원래 보호 실행기는 변경하지 않고 전용 실행기와 승인 기록을 추가했다.
- 첫 2·6 시안의 흰 패치 윤곽이 사진을 가려, 해당 영역만 진하게 표시하는 방식으로 수정했다. 시안·원래 설정·수정 이유를 보존하고 설정을 다시 잠갔다.
- 여덟 장 생성 완료. 원본 195개 파일과 입력 보존, 영역별 수치, 강조 영역 분모, 실제 XY 공간 단면 및 사진 위치선의 잘라내기/회전 대응을 포함한 634개 검사를 통과했다.
- 여덟 최종 미리보기를 저자가 확인했다. 독립적인 제목 숨김 검토는 이번 개정에서 수행하지 않았다. 6번 시작 위치 설명과 평지붕 설명이 붙어 보여 위치를 분리했다.
- 가림 및 독립적인 동일 표면 진실을 확인했다는 주장은 하지 않는다. 모든 실패 표시는 학습 전 깊이 손실 계산에 한정한다.
