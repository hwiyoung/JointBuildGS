# 대표 그림 보완 기록

- 원본 영역 정의, 입력값, 사진, 고정 단면과 기존 여덟 그림은 유지한다. 새 A 패치는 사례의 조건을 충족하는 후보 중 단면 중간에 가장 가까운 것으로 골랐다. 모든 A는 결과 확인 후 고른 설명용 표본이다. 모집단의 전형성 또는 성능을 주장하지 않는다.
- 4번을 순수 보존 성공으로 제시하지 않는다. 사진 범위 보존 영역의 검사 기반 맞은 넓이는 78.7%다. A는 허용 범위 안이지만 사전 정보보다 오차가 크다.
- 7번의 옛 명칭 ‘비가시’를 ‘사진 정보 부족’으로 변경했다. 기존 공개 검사 레코드의 A는 eligible_images=2, selected_count=2이며 최소 3장 기준에 못 미친다. 물리적으로 가려진 원인은 확인 불가다. 원본은 수정하지 않는다.
- 첫 시안의 ③ 판정 패널 하단 설명이 축 제목에 가까워 보였다. 중복 설명을 제거했다.
- 제목을 숨긴 2·5·7번을 독립 검토자 두 명이 확인했다. 세 핵심 관계를 모두 읽었으나 5번의 A 원값과 주변 중앙값 선을 혼동할 수 있다고 지적했다. 원래 검토 이미지는 reviews/pilot/에 해시와 함께 보존했다.
- 보완: 단면 안에서 ‘A 사전 정보 원값’, ‘A 검사 기반 원값’을 화살표로 직접 가리킨다. 패널 위에 큰 기호와 주변 중앙값의 차이를 설명하고 주변 선을 연하게 했다. A를 선에 맞춰 이동시키거나 수치를 바꾸지 않았다.
- 보완: 사진 확대 제목을 ‘사진 검사의 판단’, 정오 눈금을 ‘제공 참조값 기준’으로 분리했다. 분홍/청록/회색 패치의 뜻을 사진 밑에 직접 적었다. 0 m 시작점, 단면 폭 안의 A와 중심선의 차이, 법선 오차와 연직 높이의 차이, 사례 사이 축 범위 차이도 명시했다.
- 검토자 B가 5번의 영역 비율 두 값을 하나로 읽었다. 실제 시안에는 범주별 97.0%와 검사 기반 93.4%가 모두 있었다. 읽기 실패를 반영하여 화살표 대신 명시적 두 항목을 나란히 표기했다.
- scientific_verdict: null
- 후속 검토 후 원값/중앙값 설명을 11.5 pt로 키우고 제목과 간격을 늘렸다. 단면 범례에 실제 A 기호(사각형·삼각형·빈 원·마름모·×)를 넣었다. 수치·자리·축·사례 내용은 유지했다.
- 남은 범위: 사진은 검사 판단의 상태를 보여주며 그 판단을 낳은 전체 다중 사진 점수 근거를 재현하지 않는다. 단면 폭 전체의 사진 투영 윤곽은 별도로 그리지 않았다. A의 포함 여부는 패치 ID와 고정 단면 데이터로 검증한다. 축소 화면에서 작은 각주는 원본 확대가 필요하다.
- 전달 묶음 첫 실행 실패: `rfcore`가 v1 공통 코드 경로를 앞에 두어 `from package import digest_stream`이 v1의 동명 모듈을 찾았다. ZIP 생성 전에 ImportError로 종료했다. 스트림 해시 함수를 묶음 스크립트 내부에 두어 모듈 이름 충돌을 제거했다. 이미 공개된 그림 커밋은 유지하고 별도 전달 정리 커밋으로 수정·실패 기록을 남긴다.
