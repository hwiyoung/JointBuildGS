# 관련 연구에서 상보성의 의미 — 갱신·RGB-D·동일 영상 파생 기하

검토일: 2026-09-09 · `scientific_verdict: null` · 문헌·공식 구현 열람만 수행. 기존 문서와 실험 산출물은 수정하지 않았다.

## 1. 판단 기준

여기서 **두 입력의 상보성**은 주어진 복원 대상·관측 조건·품질 기준에서 각 입력의 부족을 상대 입력의 유효 정보가 보완할 가능성을 뜻한다. **실현된 상보성**은 양쪽 단독의 부족을 보완하는 두 입력의 유효한 기여가 최종 결과에 함께 나타난 경우다. 한 방향의 이득만 확인한 근거는 그 범위로 기록한다. 최적화가 양방향이라는 뜻도, 두 입력의 원본을 모두 수정한다는 뜻도 아니다. 아래 분류는 우리 분석이며, 저자가 논문에서 쓴 단어와 구분한다.

단독 입력이 모두 모든 영역에서 실패해야 상보적인 것은 아니다. 어떤 위치·속성은 prior가, 다른 위치·속성은 영상이 지지할 수 있다. 두 입력이 같은 부분을 관측하며 서로 다른 방향의 불확실성을 줄이는 경우도 가능하다. 반면 두 점수의 평균이 오르거나 두 입력을 사용했다는 사실만으로 이 관계가 검증되는 것은 아니다.

## 2. 네 문헌의 목표와 검증

### CL-Splats: 과거 장면 지식과 현재의 국소 관측

- **원문 사실:** 기존 색 있는 3DGS와 희소한 현재 RGB를 입력하여 국소 변화를 반영하고, 재관측이 적은 배경과 과거 상태를 보존한다. 이는 무색 ALS/LoD와 영상의 결합을 직접 다루는 설정은 아니다. 기존 GS에는 과거 영상의 기하·외관 추정이 함께 들어 있다.
- **우리 해석:** 기존 GS만으로 현재 변화가 갱신되지 않고, 적은 새 영상으로 장면 전체를 다시 추정하면 관측 부족이 생긴다는 의미에서 사용자의 상보성과 가깝다. 결과에서는 변하지 않은 배경을 보존하고 변경부에 신규 정보를 사용한다. 모든 기존 기하의 정확도가 높다는 입증과는 다르다.
- **실제 증거:** §4.2 Table 5(Level 2)에서 배경 고정 제거 20.773 dB, 전체 방법 40.833 dB다. 이는 선택적 보존 효과의 근거이며, `기존 GS 단독 / 현재 RGB 단독 / 결합`의 독립 표면 정확도·완전성 세 팔 비교는 아니다. 렌더 평가를 metric geometry의 상보성으로 바꾸지 않는다.
- **정보 흐름:** 기존 렌더와 현재 영상의 변화 검출→3D 영역→국소 최적화. 비변경부 고정도 상보성 실현 방식이 될 수 있다.

근거: [arXiv 2506.21117v2, Abstract·§1·§3·§4.2 Table 5·§6](https://arxiv.org/html/2506.21117v2). [공식 공개판 README, commit 587fffc207f9c7cbb348f35e6d1d223d007eab69, Disclaimer](https://github.com/jan-ackermann/cl-splats/blob/587fffc207f9c7cbb348f35e6d1d223d007eab69/README.md#disclaimer)는 원논문 구현과 차이가 있을 수 있는 재구현임을 명시한다.

### GaussianUpdate: 과거 지식 유지와 현재 외관·배치 갱신

- **원문 사실:** 학습된 GS에 시간별 RGB·자세를 추가하여 조명과 배치를 갱신하고, 과거 시점 렌더도 회복한다. 신규 SfM점은 현재 영상의 파생 기하이고, replay는 이전 GS가 생성한 감독이다. ALS/LoD를 독립 측정 입력으로 더하는 방법은 아니다.
- **우리 해석:** 과거의 공간·외관 정보와 현재 변경 정보를 보완적으로 이용한다. 따라서 장면 유지·갱신이라는 목적은 유사하지만, 서로 다른 센서와 표현 수준의 기하 정확도 상보성을 직접 입증한 연구로 분류하면 과장이다. 과거 replay는 새로운 현재 관측이 아니다.
- **실제 증거:** §4 Tables 1–4는 렌더·망각·구성요소 효과를 평가한다. 모든 과거 사진을 쓰는 UB와의 비교는 정보 접근 조건도 다르다. 독립 표면 참조로 두 입력의 단독부족과 결합 이득을 분리한 검증은 확인되지 않았다.
- **정보 흐름:** 외관 갱신→배치 갱신→공동 refinement와 과거 replay를 사용한다. 단계 수나 마지막 공동 최적화가 상보성을 정의하지 않는다.

근거: [arXiv 2508.08867v1, §3.1 Task Formulation·§3.2–3.3·§4 Tables 1–4](https://arxiv.org/html/2508.08867v1). [공식 프로젝트](https://zju3dv.github.io/GaussianUpdate/)에서 이번 열람으로 학습 구현 링크는 확인하지 못했다.

### AGS-Mesh: RGB·저해상도 센서 깊이·사전학습 법선의 보완

- **원문 사실·저자 동기:** 저해상도 센서 깊이는 평면에 유용하지만 세부·경계가 부정확하고, 사진 감독만 쓰면 무텍스처 실내에서 모호성이 크다. RGB-D와 사전학습 단안 법선을 선택적으로 결합하여 mesh와 렌더를 개선한다. 기구축 시점의 자산 재사용은 native 문제가 아니다.
- **우리 해석:** 측정 깊이와 영상의 서로 다른 장점을 결합한다는 의미는 매우 가깝다. 그러나 normal에는 사전학습 지식도 들어가므로 결과를 순수한 두 센서 정보의 효과로만 귀속할 수 없다.
- **실제 증거:** Table 3의 3장면 평균 F1은 2DGS .6345, +Depth .8861, +Normal .6342, +Both .8880, +Both+DNC+ANR .9092다. 영상 기반 baseline에 깊이를 추가한 이득과 감독 선택 이득이 분리된다. normal 단독 추가는 모든 지표를 개선하지 않는다. Table 1에는 전통적 volumetric fusion 비교도 있지만, 모든 처리·정보를 일치시킨 센서 단독/영상 단독/융합의 완전한 인과 분리는 아니다.
- **정보 흐름:** 원 센서 깊이·단안 법선은 재사용하고 현재 GS와의 일치에 따라 감독을 제한한다. 상보성은 원자료 양방향 갱신을 요구하지 않는다.

근거: [arXiv 2411.19271v2, §1·§3.1·§4.1–4.3·§5.1–5.3 Tables 1–4](https://arxiv.org/html/2411.19271v2). [공식 train.py, commit 93fda851a20cf0bd5fce642c46da0c83c637165e, L127–181](https://github.com/XuqianRen/AGS_Mesh/blob/93fda851a20cf0bd5fce642c46da0c83c637165e/train.py#L127)은 camera의 depth confidence를 읽고 현재 surf normal에서 normal confidence를 계산한다.

### HelixSurf: 같은 영상에 적용한 서로 다른 추정 전략의 상보성

- **원문 사실·저자 동기:** 저자는 Abstract·§1에서 상보성을 명시한다. MVS는 텍스처가 있는 곳의 세부를, SDF의 연속 표현·평활성 편향은 표면의 연속성을 제공한다. 서로의 중간 예측으로 정규화한다. 기본 입력 관측은 보정된 동일 RGB이며, 두 독립 센서나 기존 ALS/LoD가 아니다.
- **우리 해석:** “각각의 한계를 다른 장점으로 보완”이라는 논리는 같다. 구분해야 할 것은 **자료의 추가 정보**와 **추정기·표현의 다른 성질**이다. 같은 영상을 재처리해도 더 좋은 추정이 가능하지만 독립 관측이 추가된 것은 아니다.
- **실제 증거:** Table 2는 MVS 감독·textureless 처리 효과를, Table 3은 표면 결과로 재정규화한 MVS의 depth RMSE .147→.106과 normal 개선을 분리한다. 양방향 효과의 실제 근거가 있다. 외부 prior+현재 영상의 상보성이나 모든 지역·지표의 비악화를 입증한 표는 아니다.
- **정보 흐름:** MVS→SDF→depth/normal→MVS 재실행→SDF. 양방향 갱신은 이 논문이 선택하고 평가한 실현 방법이다.

근거: [arXiv 2302.14340v2, Abstract·§1·§4.1–4.2·§5.2 Tables 2–3](https://arxiv.org/html/2302.14340v2). [공식 next_mvs.sh, commit 3b46727bf76b4f089afbc79a37a6fb37dc9c66c2, L20](https://github.com/Gorilla-Lab-SCUT/HelixSurf/blob/3b46727bf76b4f089afbc79a37a6fb37dc9c66c2/run_scripts/next_mvs.sh#L20)은 표면 depth/normal을 받아 MVS를 재실행하는 경로를 확인해 준다.

## 3. 직접 융합 연구와 구분해야 할 구성요소 문헌

| 문헌 | 원문 목표·입력 관계 | 상보성 논의에서의 역할 |
|---|---|---|
| 3DGS | RGB와 SfM 파생 sparse로 효율적인 장면 표현·새 시점 합성. [v1 §1·§3–5](https://arxiv.org/html/2308.04079v1) | 기존 독립 기하+현재 영상의 융합법 자체가 아니다. 영상 단독 대조 또는 결합을 구현할 표현·최적화 기반 |
| 2DGS | 보정 RGB에서 표면에 맞는 Gaussian 표현과 기하 정규화. [v1 Abstract·§4](https://arxiv.org/html/2403.17888v1) | 영상 단독 표면 복원의 강한 비교군. 외부 prior를 도입하기 전 표현 오류를 얼마나 줄이는지 구분 |
| SpotLessSplats | 여러 RGB와 사전학습 특징으로 방해물을 억제하여 정적 배경을 복원. [v2 §4–6](https://arxiv.org/html/2406.20055v2) | 사용할 영상 증거를 강건하게 고르는 구성요소. 최신 영구 변화를 복원하는 목표와 transient 제거 목표를 구분 |
| NeuRIS | RGB와 사전학습 normal의 결합에서 불량 normal 감독을 완화. [저자 페이지 Abstract·Framework](https://jiepengwang.github.io/NeuRIS/) | 관측·학습 prior의 보완 사례. 기존 장면의 외부 측정기하와 같은 계보가 아니며, 감독 선택의 가까운 선행 해결책 |
| VCR-GauS | RGB·SfM·예측 normal로 표면을 복원하고 view consistency로 감독 가중. [v2 §3.2–3.4](https://arxiv.org/html/2406.05774v2) | 예측 prior의 오차 전달과 normal→위치 수정 경로에 대한 구성요소 비교 |
| BayesRays | 학습된 NeRF를 고정하고 공간 불확실성을 사후 추정·필터링. [v1 §4–5](https://arxiv.org/html/2309.03185v1) | 관측 부족 진단 후보. 새로운 기하·영상 정보를 추가하는 융합법이나 결손 복원 자체는 아님 |

이 분류는 서로 배타적인 기여 분류가 아니다. 같은 논문이 표현·감독·추출을 동시에 바꿀 수 있다. 또한 사전학습 정보가 있다고 해서 장면 고유 정보가 모두 외부에서 온 것도 아니다. 예측 normal은 현재 RGB와 사전학습 지식에 함께 의존한다.

## 4. 이번 정의 정리에서 유지할 결론

**여러 관련 연구도 서로 다른 강점으로 부족을 보완하려는 의미에서 융합한다.** 그러므로 “상보적으로 결합한다”는 목적 자체가 신규성은 아니다. 다만 무엇과 무엇이 상보적인지 구분해야 한다: 독립 센서·외부 자산, 과거 장면 추정과 현재 관측, 센서와 사전학습 추정, 동일 영상의 서로 다른 추정 전략은 같지 않다.

후속 비교에는 `무엇이 각 단독 입력에서 부족한가 → 다른 입력의 어떤 정보가 이를 줄이는가 → 실제 결과에서 어느 축이 개선·악화되는가`를 동일 조건에 기록한다. 현재성·세부·외관을 하나의 렌더 점수로 대체하지 않는다. 고정 prior+영상 처리, 선택·합성, 순차, 반복 모두 후보이며 양방향 갱신을 정의의 필수 조건으로 삼지 않는다.

이번 문서는 이 관계를 분류한 해석이다. 특정 새 방법의 필요성, 모든 조건의 상보성, 독립 기하 개선의 과학적 결론을 확정하지 않는다.
