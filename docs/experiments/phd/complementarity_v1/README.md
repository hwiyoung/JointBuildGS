# 상보성 정의와 관련 연구 대조 v1

2026-09-09 · `PHD-COMPLEMENTARITY-v1` · 문헌/개념 정의 초안 · `scientific_verdict: null`

**각 입력의 부족을 상대 입력의 유효한 정보로 보완하고, 두 기여가 최종 결과에 함께 남는 것**을 실현된 상보성의 기준으로 정리했다. 단독 불충분은 목표·영역·속성·관측 조건에 따른다. 입력 파일의 상호 수정이나 반복 최적화는 정의의 필요조건이 아니다.

Schenk–Csathó, SRDM, Zhou, Wu–Vallet, GS4Buildings, GeoGS, ARSGaussian 등도 같은 큰 의미에서 정보 보완을 추구한다. 센서·외부 자산의 보완, 기존 GS의 보존·갱신, 같은 영상의 다른 추정 전략은 입력 계보와 평가 범위를 나누었다. 문헌의 의도·정보 경로·실험 근거를 구분하며 신규성을 선언하지 않는다.
