# 기존 3D 기하와 현재 영상의 상보성 — 정의와 문헌 해석

2026-09-09 · `PHD-COMPLEMENTARITY-v1` · 개념 정의/문헌 분석 초안 · `scientific_verdict: null`

이 문서는 사용자의 원래 연구 목적을 유지한다. 지붕면·구조 손상으로 범위를 제한하지 않으며 GS, 명시적 판단, 소스 교체, 공동·반복 최적화의 필요성을 전제하지 않는다. 기존 정본과 [문헌 분석 v1](../literature_research_question_v1/README.md)은 보존한다. 여기의 분류와 검증 제안은 **우리 분석**이며 표준 분류나 확정 신규성 주장이 아니다.

## 1. 상보성의 작업 정의

> **기존 3D 기하와 현재 영상의 상보성이란, 특정 복원 대상·형상 규모·관측 조건에서 각 입력이 제공하는 유효한 정보가 다른 입력만으로는 부족한 기하·피복·세부·현재성·외관 정보를 보완하여, 두 입력을 함께 사용하는 결과가 각각의 단독 사용으로 충족하기 어려운 복원 요구를 더 잘 충족할 수 있는 관계다.**

상보성은 입력이 가진 **가능성**과 이를 방법이 **실제로 실현한 결과**를 구별해 사용한다. “기존 기하는 정확하고 영상은 상세하다”를 모든 위치에서 참인 전제로 삼지 않는다. 어느 입력이 무엇에 강한지는 원자료 계보, 오차, 형상 규모, 피복, 촬영 기하와 대상 표면에 따라 달라진다.

사용자의 “각각 따로는 불충분하고 함께 쓰면 서로 보완한다”는 뜻을 다음처럼 구체화한다.

- **단독 불충분의 기준은 목표 산출물이다.** 한 입력이 모든 영역·모든 품질축에서 실패해야 하는 것은 아니다. 기존 기하가 형상은 충분하지만 외관이 없고, 영상은 외관을 관측하지만 일부 형상을 안정적으로 복원하지 못하는 경우도 포함한다.
- **상호 보완의 위치는 달라도 된다.** A영역에서 기존 기하가 영상 결손을 메우고 B영역에서 영상이 기존 기하의 결손을 메워도 전체 결과의 상보성이 성립할 수 있다. 같은 위치에서도 면의 위치와 작은 경계, 기하와 외관처럼 서로 다른 성분을 보완할 수 있다.
- **두 원본을 모두 수정할 필요는 없다.** 원prior bytes를 고정한 채 복원 결과에 기하·세부·외관을 함께 담을 수 있다. 순차 처리, 선택·접합, 감독, 공동 추정은 상보성을 실현하는 서로 다른 방법이다. 실제 upstream feedback 유무와 상보성 유무는 별개다.
- **모든 지표에서 두 단독법을 동시에 이겨야 한다는 정의는 두지 않는다.** 어떤 요구를 개선했고 어떤 요구를 유지하거나 악화시켰는지 함께 제시한다. 특정 축의 이득을 전체 복원의 무조건적 성공으로 바꾸지 않는다.
- **두 입력의 유효한 기여가 결과에 함께 남아야 한다.** 한쪽 입력이 아무 기여를 하지 않은 채 다른 입력의 결과만 재현했다면, 사용자가 의도한 상호 보완을 실현했다고 부르지 않는다. 한 방향의 이득만 확인했다면 그 범위의 보조 효과로 기록한다. 일부 지역에서는 한쪽 정보만 사용하는 것이 전체 결과의 상호 보완과 양립할 수 있다.
- **초가산적 시너지와 구별한다.** 단순한 역할 분담·지역별 선택도 상보성을 실현할 수 있다. “부분의 합보다 더 큰 효과”를 별도로 주장하려면 효과 척도와 상호작용 비교를 정의해야 한다. 그것은 상보성의 필수 조건이 아니다.

## 2. 두 입력이 구체적으로 제공하는 것

아래는 **조건부 가능성에 관한 우리 분석**이다. 입력 이름만으로 성능을 보장하지 않는다.

| 입력 | 제공할 수 있는 유효 정보 | 단독 사용의 부족 | 다른 입력이 보완할 수 있는 내용 |
|---|---|---|---|
| 기존 측량 점군/면 | 실제 측정에 근거한 위치·거리·표면 방향, 영상 대응과 다른 측정 근거, 현재 영상이 덮지 않는 기하 | 불균일 피복·희소성·잡음·잘못된 점/면, 외관 부족, 취득 이후 변화 가능성 | 현재 영상이 지지하는 경계·형상·결손 부분·외관, 관측 가능한 불일치의 검정·수정 |
| 기존 LoD 등 단순화된 모델 | 면·연결 구조·넓은 피복과 압축된 형상 가설 | 작은 형상 생략, 단순화·구축 오류, 원측정 정확도의 손실, 외관/현재성 부족 가능성 | 실제 관측이 구별하는 표면 위치·작은 형상·외관, 부적합한 구조 제약을 제한할 근거 |
| 현재 RGB와 허용된 카메라 정보 | 영상 강도·색·경계·가시성, 다중뷰 대응에서 얻는 현재 형상 제약 | 깊이 모호성·저텍스처·낮은 시차·가림·반사·조명 교란·카메라 오차, 미관측 영역 | 기존 기하의 위치·면 가설이 탐색/대응/형상 추정을 제약하고, 유효한 기존 표면이 결과의 구조와 피복을 지지 |

현재 영상의 고해상도는 관측 가능한 3D 세부의 해상도와 같지 않다. 작은 색 무늬를 관측하는 것과 작은 돌출 형상을 복원하는 것은 구별한다. 기존 모델이 조밀하거나 평면적이라는 사실도 그 위치와 현재 유효성을 보장하지 않는다.

RGB에서 만든 MVS·깊이·법선은 원영상의 **파생 추정**으로 계보를 기록한다. 사전학습 depth/normal을 쓰면 학습된 정보가 추가된다. RGB·MVS·단안 깊이를 서로 독립한 세 번의 측량 관측처럼 취급하지 않는다. 반대로 같은 관측의 다른 추정기가 서로 다른 장점을 갖는 **방법·표현의 상보성**도 연구할 수 있지만 외부 3D 자산의 정보 기여와 구분한다.

## 3. 상보성이 나타나는 여섯 가지 형태

서로 배타적인 범주가 아니며 한 논문·한 영역이 여러 형태를 가질 수 있다.

| 형태 | 각 단독 사용의 부족과 결합의 의미 | 확인할 결과 | 성립을 제한하는 조건 |
|---|---|---|---|
| **속성 보완** | 기존 기하는 위치·형상을 제공하고 영상은 색·외관을 제공하여 사용 가능한 textured 3D를 구성 | 형상 품질과 외관 품질을 각각 측정 | 채색으로 외관이 생겼다는 사실만으로 기하 개선이나 새 융합 원리를 입증하지 않음 |
| **공간·피복 보완** | 한 자료에 없는 표면을 다른 자료의 유효한 관측/기하로 보충 | 같은 공간에서 복원된 면·남은 결손·잘못 채워진 면 | 두 입력 모두 없는 영역; 미관측 과거 표면의 현재성; 접합·중복면 |
| **형상 규모·자유도 보완** | 넓은 면의 위치/방향과 작은 경계·굴곡 등 서로 다른 성분의 정보를 함께 사용 | 면·경계·국소 형상별 정확도와 완전성 | 영상 texture를 형상으로 오해, 잘못된 coarse 제약, 추출 시 세부 소실 |
| **같은 기하량의 오차 보완** | 같은 표면을 측정한 두 추정의 유효한 제약을 함께 사용해 오차를 감소 | 독립 참조의 위치/방향 오차, 편향·분산, 유효 영역의 악화 | 공통 편향, 정합 잔차, 다른 표면을 같은 표면으로 융합. 단순 일치가 정확성을 뜻하지 않음 |
| **추정·검정의 조건 보완** | 기존 기하가 영상 대응의 후보를 제한하고, 영상 관측이 기존 기하의 사용 가능 부분과 수정 방향을 제한 | 대응/깊이/표면의 실제 개선, 잘못 사용하거나 버린 정보 | 둘이 같은 오답을 지지하거나 관측으로 후보를 구별하지 못함. 명시적 판단 모듈은 필수 형식이 아님 |
| **시기·갱신 보완** | 기존 자료가 과거의 넓은 장면 정보를, 현재 영상이 관측된 현재 형상·외관을 제공 | 확인 가능한 현재 형상의 갱신과 안정 영역 보존 | 영상에서 보이지 않는다고 철거로 판단하지 않음. 과거 자료 존치를 현재성 확인과 구별 |

예를 들어 “기하+외관”과 “현재 영상의 결손을 기존 기하로 채움”은 그 자체로 유용한 상보성이다. 단순 texture mapping이나 기존 선택·접합으로 그 목표를 충족하면 해당 이득을 인정한다. 상보성의 존재와 추가 알고리즘의 신규성은 다른 주장이다.

## 4. 가능성, 실현, 추가 기여를 구별한다

| 주장 수준 | 의미 | 필요한 근거 |
|---|---|---|
| **상보적 정보의 가능성** | 서로 다른 입력에 서로 보완할 정보가 있음 | 계보·오차·피복·형상 규모와 실제 관측 조건. 참조를 쓰는 oracle은 잠재적 여지의 진단이며 실제 방법이 그 정보를 식별할 수 있다는 증거는 아님 |
| **특정 방법에서 실현된 상보성** | 양쪽 단독 결과가 목표에서 갖는 부족을 상대 입력의 정보로 줄이고, 두 유효한 기여가 결합 결과에 함께 남음 | 충분히 강한 영상 단독, 기존 기하 단독, 결합 결과의 공통 목표별 비교. 성공·악화와 결과를 낸 정보 경로를 제시 |
| **새 방법의 추가 기여** | 기존의 상보성 실현 방법보다 결과 또는 적용 가능성을 개선 | 가장 가까운 기존 융합/정합/추출과 합리적 조합을 같은 정보·출력에서 비교. 동일 예산 또는 비용 차이를 보고하고 이득의 원인을 새 요소와 연결 |

“둘을 썼다”, “평균 PSNR이 높다”, “점 수가 늘었다”만으로 두 번째 수준을 모두 채우지 않는다. 양쪽 단독의 모든 요구를 무리하게 동일 수치로 비교할 필요도 없다. 무색 prior-only에 RGB를 제공하면 이미 결합 입력이므로 명칭을 바꿔야 한다. 외관 비교에서 prior-only의 부재를 보고하고, **기존 기하+표준 texture mapping**을 별도의 간단한 결합 비교로 두면 신규 기하 복원 효과와 혼동을 줄일 수 있다.

같은 표현·알고리즘을 단독법들에 강제하지 않는다. 공통 표면·속성·지원영역에서 평가하고 원천적으로 없는 속성은 미제공으로 기록한다. 원점군과 추출면의 거리만으로 결론을 내리기보다 표본화·완성 처리와 비용의 차이를 드러낸다. 두 단독 비교가 불완전한 논문도 구현 경로와 구성요소 제거로 부분 기여를 뒷받침할 수 있다. 그러한 근거를 0으로 취급하거나, 평가 미비만으로 방법론적 공백을 선언하지 않는다.

결합 방법에서 특정 depth loss 하나를 지워도 같은 prior의 초기화·표본·mask가 남으면 그 조건은 prior-free가 아니다. RGB loss를 유지한 채 visual depth만 지운 조건도 geometry-only/prior-only가 아니다. 동일 입력에서 GS를 거치지 않은 점군/면·기존 후단이 충분한지 열어 둔다.

## 5. 문헌의 의도와 우리 연구의 관계

원문 재확인 결과를 종합할 문헌 비교는 [고전 기하 융합](CLASSICAL_SOURCE_NOTES_ko_v1.md), [외부 기하를 사용하는 GS](GS_SOURCE_NOTES_ko_v1.md), [관련 보완·갱신 연구](RELATED_SOURCE_NOTES_ko_v1.md)에 둔다. 각 노트는 **저자가 명시한 목표 / 실제 정보 경로 / 검증한 결과 / 우리 해석**을 구분한다.

**질문에 대한 답은 “여러 직접 관련 연구가 같은 의미로 융합을 시도했다”이다.** 특히 Schenk–Csathó 2002, SRDM, GeoGS는 한 자료의 부족을 다른 자료의 강점으로 보완한다는 뜻을 원문에서 명시한다. 나머지는 같은 단어의 사용 여부보다 입력의 역할·목표·정보 경로로 판단한다. 다음 표는 우리의 재분류이고, 모든 논문이 동일 입력·최종 출력·오류 조건을 검증했다는 뜻은 아니다.

| 문헌 | 원문이 대응시킨 부족과 강점 | 같은 의미인가 / 무엇이 다른가 | 실제 검증의 해석 |
|---|---|---|---|
| **Schenk–Csathó 2002** | LiDAR의 면 패치와 영상의 경계·불연속 정보 | 직접 같은 의미. 현대 GS 이전의 기하 융합 | 실제 건물 구현 예시 있음; 넓은 양단독 정량 대조는 아님. §1–2, Tables1–2, §4–5 |

Schenk–Csathó 2007은 단일 센서의 부분적 해결을 동기로 삼고 **중복·상보·충돌 정보가 공존**한다고 구별한다([Abstract/§1](https://rsl.geology.buffalo.edu/documents/urban2007_schenkandcsatho.pdf)). 다만 실자료 예시 없는 개념 논문이다. 이는 현재 데이터의 성능 증거가 아니라 개념의 선행 근거다. 따라서 두 입력 전체를 언제나 상보적이라고 부르기보다, 어떤 속성·영역·조건에서 보완되는지를 밝혀야 한다.

3DGS·2DGS는 외부 자산의 보완을 구현하거나 영상 단독의 품질을 확인할 기반이다. SpotLessSplats·NeuRIS·VCR-GauS는 영상/학습 prior의 증거 사용과 감독 제어에, BayesRays는 사후 불확실성 진단에 관련된다. 이들이 같은 외부 3D+현재 영상 문제를 모두 풀었다고 묶지 않는다. 상세 구분은 [관련 문헌 노트 §3](RELATED_SOURCE_NOTES_ko_v1.md#3-직접-융합-연구와-구분해야-할-구성요소-문헌)을 따른다.

**이번 해석:** 상보성은 우리의 연구를 설명하는 중심 개념이면서 오래된 연구 동기이기도 하다. 우리 연구가 확인할 내용은 상보성이라는 목표의 최초성이 아니라, 어떤 상보 정보가 주어진 조건에서 실제 복원에 전달되며 기존 방법으로 어디까지 실현되는가이다. 두 단독보다 나은 결과와 기존 융합보다 나은 결과는 서로 다른 비교다.

## 6. 연구 질문에 주는 의미

상보성에 집중한다는 것은 새 용어를 신규성으로 삼거나 먼저 특정 부위·방법으로 범위를 줄이는 일이 아니다. 원래 연구 목적 안에서 다음 항목을 대응시키는 것이다.

1. **영상 단독의 어떤 부족을 기존 기하의 어떤 정보가 줄이는가?**
2. **기존 기하 단독의 어떤 부족을 현재 영상의 어떤 정보가 줄이는가?**
3. **두 기여가 결합된 최종 결과에서 각각 유지되는가? 다른 부위/성분의 손상은 무엇인가?**
4. **가까운 기존 방법은 어떤 상보성을 이미 실현했고, 같은 조건에서 무엇이 남는가?**

이 네 항목에서 어려움이 특정되면 연구 질문을 좁힐 근거가 생긴다. 대응 추정의 보완, 서로 다른 형상 규모의 결합, 외관과 기하의 역할 분담, 피복·시기의 보완 중 어느 것도 현재 자동 우선순위로 두지 않는다. 시간차는 여섯 형태 중 하나와 관계되는 조건이며 전체 연구의 필요조건이 아니다.
