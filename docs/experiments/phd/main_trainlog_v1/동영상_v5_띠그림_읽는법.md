## 동영상 v5 (건물 전체)

| 칸 | 무엇 |
|---|---|
| A·B | 색 감독 신호(사진)와 GS 렌더 |
| C·D·E | 깊이 감독 신호, 렌더 깊이, 둘이 21 cm 넘게 다른 곳(보라). 선 = 판정 영역 |
| 입력 1 | 사전 정보: 옛 항공 LiDAR 지붕면(분홍). 옛 박공지붕 |
| 입력 2 | 영상 MVS: 패치마다 한 점(회색). 지금 평지붕 |
| F | 가우시안 + 판정 영역. ①②③ 점선 = 띠 그림 자리 |
| G | 메시. 판정색 = 참값 21 cm 안, 보라 = 넘음 |
| H | 가로 단면: 분홍 점선(사전 정보)과 회색 사각(MVS)이 입력, 남색 선(메시)과 점(가우시안)이 결과 |
| I | 사전 정보가 틀린 곳(지붕이 바뀐 곳)에서 메시가 지금 지붕을 덮는 비율(주요 메시 13개), 옛 지붕에 놓인 가우시안 수 |

고정 시점: 남쪽에서 북쪽을 봄(방위 270°, 높이각 35°). 세 자리 중 가장 덜 보이는 자리의 보임 비율이 가장 큰 방향(`analysis/spots_v5/spots_v5.json`).

## 자리별 띠 그림 (`figures_spot/`)

자리 = 논문 B173 그림 자리(1단계 장면 1·3·5). 열 = [입력·감독] + 0, 1,000, 2,000, 3,000 직전, 7,000, 10,000, 15,000, 30,000회. 행 = 가우시안, 메시, 단면.

- 가우시안 칸: 같은 확대 시점의 실제 렌더(r27 렌더러, 화소마다 가장 많이 기여한 원반 찾기)에서 보인 원반만 그림(2σ, 진하기 = 불투명도). 자리 상자 +2 m, 시선 ±40 m 안 원반만 렌더(멀리 배경 원반이 화면을 덮는 것을 막음). 벽은 벽 면 ±3 m 원반만.
- 남색 선 = 단면 자리(메시를 자른 선). 단면은 그 자리 ±25 cm만 자른 것이고, 위 두 줄은 자리 전체를 보임.
- 분홍 점선(사전 정보 단면)은 첫 열에만. 결과 칸의 분홍 점은 옛 지붕에 놓인 가우시안.
- 참값 = 밀집 참값 점(연회색).

| 자리 | 묻는 것 | 띠 그림에 보이는 것 (`tables/spot_strip_measures.csv`) |
|---|---|---|
| ① 날개 | 옛 박공이 남는가 | 메시가 지금 지붕 참값 점을 21 cm 안에서 덮는 비율 0 % → 80.7 %(1,000) → 96.7 %(2,000) → 99.3 %(30,000). 옛 높이에 메시 면 없음. 창 안 옛 지붕에 놓인 가우시안 261 → 62(30,000)개는 옛 높이(지면 위 22~23 m)에 남음: 그 자리 판정이 보존이라 목표가 옛 높이 |
| ② 긴 벽 | 영상이 보지 못한 벽이 서는가 | 벽 면 53 패치 중 메시가 0.25 m 안인 비율이 끝까지 8 % 아래(30,000회 3.2 %). 벽 면 목표 0개(항공 LiDAR에 벽 없음). 벽 앞 원반은 있어도 메시에 없음: 메시는 실제 영상 203장 시점의 렌더 깊이로 만드는데 이 벽은 그 시점들에서 보이지 않음. 지붕 끝 바로 바깥(0.1~0.8 m)에 지붕보다 0~6 m 솟은 어긋난 면 264 m²(30,000회) |
| ③ 유리 채광창 | 영상이 틀린 곳에서 틀린 영상을 따르는가 | 입력 MVS가 유리(지면 위 16 m) 아래 12~14 m. 메시 단면도 13~14 m(유리와 바닥 사이). 참값이 여러 층이라 덮는 비율(86.3 %)은 판단에 쓰지 않음 |
