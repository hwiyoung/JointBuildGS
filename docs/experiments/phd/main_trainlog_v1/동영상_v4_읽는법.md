# B173 학습 과정 동영상 v4 읽는 법

scientific_verdict: null. 설정 덧붙임 `configs/phd/main_trainlog_v1/trainlog_v1.video_v4.json`. 다시 돌린 판(attempt2)의 저장 상태 65개, 고정 시점.

읽는 순서: 감독 신호(위 줄) → 가우시안(F) → 메시(G) → 단면(H) → 판단이 틀린 자리 곡선(I).

| 칸 | 무엇 | 볼 곳 |
|---|---|---|
| A | 색 감독 신호: 학습 영상 0146 실제 사진 | 기준 |
| B | GS 렌더(색) | A에 가까워짐 |
| C | 깊이 감독 신호: 학습 목표 깊이(회색). 선 = 판정 영역(선 색 = 깊이 출처) | 분홍 윤곽 안 밝은 점 = 옛 지붕 높이를 목표로 한 패치 |
| D | GS 렌더 깊이(C와 같은 눈금, 같은 선) | C와 밝기 비교 |
| E | 렌더 깊이가 감독과 21 cm 넘게 다른 곳(보라). 건물(판정 영역) 밖은 옅게(나무·도로는 늘 달라 눈을 가림) | 분홍 윤곽 안 옛 지붕 목표 화소가 보라로 남음 = 틀린 감독을 따르지 않음. 30,000회: 옛 지붕 목표 화소 67 %, 영상 목표 화소 10.5 % |
| F | 가우시안(점) + 판정 영역(연한 바탕) | 분홍 점(옛 지붕 출신)이 사라지고, 판정색 점이 바탕과 맞음 |
| G | 메시 표면: 판정색 = 참값에 맞는 면, 보라 = 21 cm 넘게 벗어난 면 | 보라가 판정색으로 바뀜. 10,000~15,000회 뒤로는 거의 같음 |
| H | 가로 단면(긴 방향 28 m) | 옛 박공지붕(분홍 점선) 대신 참값 평지붕(16 m)에 면(남색) |
| I | 판단이 틀린 자리: 메시 면 맞음 비율(남색), 옛 지붕 출신 수(분홍) | 오르고 줄어듦 |

깊이 감독 출처(판정이 정함): 일치 = 사전 정보·영상 둘 다(불확실도 가중 평균), 보정 = 영상(MVS), 보존·결측 = 사전 정보(옛 항공 LiDAR), 판정 영역 밖 = 영상(MVS).

색 사전: 중간 톤 판정색 = 그 판정의 메시 면·묶인 가우시안, 연한 판정색 = 판정 영역(F 바탕), 빈 점 = 풀림, 회색 점 = 자유, 분홍 = 옛 지붕·거기서 온 가우시안·판단이 틀린 자리, 보라 = 어긋남(G는 참값에서, E는 감독에서), 남색 = 면·단면 위치, 검정 = 참값.

10,000회 뒤: 면 형상은 거의 정해진다(사전 정보 오류 자리 완전성 96.6 → 98.8 %). 15,000회에 원반 나누기·지우기가 끝나 가우시안 수가 고정된다. 사진 맞춤(PSNR)은 21.6 → 25.8 dB로 30,000회까지 오른다.
