## 제안과 근거

제안: 기존 초기화·보호·밀도 제어는 유지한다. 실제 초기화 뒤 1~99회는 불투명도 중단 판정만 유예하고 100회부터 0.05 기준을 다시 적용한다. NaN과 다른 오류는 계속 즉시 중단한다. 승인 후 실패 기록을 보존한 채 두 판을 씨앗 0부터 다시 실행한다.
