# 짧은 학습 기울기 기록의 한계

전체 가우시안(0 포함) 기준 사진·깊이 기울기 중앙값이 모두 0이다. 따라서 두 중앙값의 비율은 확인 불가이고 이 통계로 세기를 구분하지 못했다. 학습 전 잠금에 적은 엄격 부등식 `깊이 < 0.1 × 사진`은 0 < 0이므로 거짓이다. 선택 규칙과 λ는 사후 변경하지 않았다. 아래 보이는 가우시안 통계는 기록용이며 선택에 쓰지 않았다.
