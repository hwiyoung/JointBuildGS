# PHD-MAIN-LOSSTRAIN-v1 — 11판 중간 결과 분석 의뢰

**B173 주변·항공 LiDAR와 B0·항공 LiDAR는 네 판의 핵심 결과를 모두 비교할 수 있다. R1·항공 LiDAR는 다이내믹 세 판만 비교할 수 있다.** 이 자료로 먼저 손실의 학습 후 효과와 남은 한계를 분석한다. 전체 24개 시험의 최종 결론을 요청하는 자료는 아니다.

실험은 지역 3개 × 사전 정보 2개 × 판 4개 = 24개이며 모두 씨앗 0이다. 현재 분석 범위는 항공 LiDAR 12조건 가운데 핵심 채점 11판과 중단 1판이다. 한 행이 네 판을 담으므로 아래 여섯 행이 24개 실험이다. 실행 단계의 최신 고정 사본은 ZIP 루트의 `STATUS.json`과 `run_inventory.csv`를 따른다.

|---|---|---|---|---|---|
| B173 주변·항공 LiDAR | 있음 | 있음 | 있음 | 있음 | 네 판 비교 |

핵심 채점에는 보존 면적·면 없음 넓이·칸별 정확도·학습 없는 도착점과의 비교가 포함된다. 전체 채점은 여기에 8.3 등 추가 지표까지 갖춘 상태다. 핵심 결과가 있으면 아래 기하 비교를 할 수 있고, 추가 지표는 실제 파일이 있는 판에 한해 분석한다.

## 네 판의 뜻과 사전 기대

아래 확률은 참값이 있는 패치에서 사전 정보에 주는 유효 확률이다. MVS 유효 확률과 불확실도는 네 판이 같고, 사전 정보의 참값으로 MVS 확률까지 바꾸지 않는다. 참값이 없는 패치와 기타 대체 규칙은 기존 설정을 그대로 따른다.

| 판·코드 | 쉬운 설명 | 사전 정보가 맞음 / 틀림 | 확인하려는 것 |
|---|---|---|---|
| 1 `lt_fixgt` | 맞고 틀림을 알려준 고정 손실 | 0.999 / 0.001 | 같은 정보 아래 고정 손실의 결과. 충돌한 자료가 결과를 중간으로 당기는 문제가 남는지 본다. |
| 2 `lt_dyngt` | 맞고 틀림을 알려준 다이내믹 손실 | 0.999 / 0.001 | 판 1과 정보는 같고 손실만 다르다. 틀린 자료의 영향을 놓아주어 맞는 면에 더 잘 도착하는지 본다. |
| 3 `lt_dynsoft` | 맞고 틀림을 약하게 구분해 알려준 손실 | 0.98 / 0.85 | 틀린 곳에도 높은 신뢰를 남겨 둔 조건에서 판 2의 효과가 얼마나 유지되는지 본다. |
| 4 `lt_dynnow` | 개별 정답 대신 상황별 신뢰도를 준 손실 | 지붕 가장자리·형태·사전 정보 불확실도 등으로 정한 표 | 개별 패치의 참값에 따른 맞음/틀림을 직접 넣지 않은 현재 설정의 성능을 본다. |

‘약한 참값’은 참값 좌표를 바꾼 것이 아니다. 참값에 따른 구분은 유지하고 학습에 주는 확률의 차이를 줄였다. 실제 사진 판정기의 오분류를 재현한 실험은 아니므로 판 3을 사진 확인 완료 방법의 실측 성능이라고 해석하지 않는다.

‘평균값’은 사전 정보와 MVS의 높이를 평균한 값이 아니다. 비슷한 상황의 패치들에 부여하는 사전 정보 유효 확률이다. 따라서 점이 깨끗해도 오래된 지붕이면 높은 확률을 잘못 받을 수 있다.

발주문 2.2절의 다음 항목은 **결과를 보기 전에 적은 기대**다. 성공 판정이나 중단 기준으로 새로 정한 것이 아니다.

| 기대 | 비교할 관측값 |
|---|---|
| 두 자료의 차가 불확실도로 설명되지 않는 곳에서 판 2 > 판 1, 판 2 ≥ 판 3 > 판 4 | 같은 단위·같은 평가 패치의 τ 안 넓이 비율. 판 1과 판 3의 순서는 별도로 가정하지 않는다. |
| 판 2는 학습 없는 시험과의 차이가 10 %p 이내 | `unexplained` 범위의 학습 없는 값 − 학습 후 값. 발주문에서 근거가 약한 기대라고 명시했다. |
| 판 2는 해당 범위 넓이의 80% 넘게 학습 없는 도착점과 같은 쪽 | 기존 `side_rows`의 같은 쪽 넓이 비율. 역시 근거가 약한 기대다. |
| 다듬기 칸의 오차가 감소하고 정확도는 변동 문턱을 넘게 나빠지지 않음 | 칸 0의 참값 거리 중앙값 및 τ 안 비율을 nojudge와 비교한다. |
| B173 날개에서 판 2는 새 지붕으로, 판 4의 깨끗한 사전 정보 구간은 옛 지붕에 남을 수 있음 | 고정된 날개 단면과 동일 구간의 수치. 판 2의 새 지붕 도착 기대는 넓이 80% 초과다. |
| MVS가 없는 사전 정보 정답 칸의 성능 유지 | 칸 4를 nojudge와 비교한다. 표본 부족 여부를 함께 적는다. |
| 평가 영상 PSNR이 nojudge와 1 dB 이내 | 같은 평가 영상·같은 계산의 PSNR 차이. 학습 중 3 dB 중단 기준과 구분한다. |

## 요청하는 분석

1. **손실 효과:** B173과 B0에서 판 2 − 판 1을 비교한다. 전체 정확도뿐 아니라 보정 칸 1, 보존 칸 2, 다듬기 칸 0, 설명되지 않는 충돌 구간을 나눠 개선과 악화를 함께 제시한다.
2. **신뢰도 정보의 효과:** 판 2·3·4를 세 지역에서 비교한다. 참값으로 맞고 틀림을 알려준 효과와 손실 형태의 효과를 구분한다. R1에서는 판 1 대비 효과를 추정하지 않는다.
3. **기존 방법 대비 효과:** nojudge, 1단계 본 방법 씨앗 0·1, MVS, 학습 전 사전 정보와 비교한다. 고정 손실보다 좋아져도 기존 방법보다 나빠진 지표가 있으면 함께 보고한다.
4. **보존과 보정의 균형:** 맞는 사전 정보는 남고 틀린 사전 정보는 현재 면으로 옮겨가는지 본다. 보존 면적의 증가만으로 전체 개선을 판단하지 않는다. 면 없음 넓이도 같은 분모로 병기한다.
5. **학습 없는 시험과 실제 학습의 차이:** 1단계 패치로 다시 계산한 도착점을 사용한다. 넓히기 v2 전체 영역의 과거 수치를 분모가 다른 학습 결과와 직접 비교하지 않는다. B173 날개 단면과 칸 0·2를 분리한 심긴 점 운명으로 관측을 보충한다.
6. **판단 가능한 범위:** 단위별로 기대와 관측이 맞는 부분, 어긋나는 부분, 자료 부족으로 확인할 수 없는 부분을 나눈다. 원인 설명은 관측과 가설을 구분하고, 필요한 후속 검증을 좁혀 적는다. LoD2나 다른 지역까지 일반화하지 않는다.

분석 결과는 비교별로 `지역·사전 정보 / 비교 판 / 범위 / N / 분모 m² / 두 값 / 차이 / 8.4 문턱 / 관측 해석 / 제한 / 원본 파일`을 남기면 된다. 비율 차이는 %p로 적고, 면적은 m²로 적는다. 최종 과학적 판정은 사람 검토자가 한다. 이 전달의 `scientific_verdict`는 null로 유지한다.

## 계산과 해석에서 유지할 것

- 1단계 패치와 고정된 평가 범위·기존 첫 교차 채점을 사용한다. 면 없음은 τ 안 비율에서는 실패로 센다. ‘맞음’은 고정 참조와 τ 이내라는 뜻이다.
- 칸 0은 둘 다 맞음(다듬기), 칸 1은 사전 정보 틀림·MVS 맞음(보정), 칸 2는 사전 정보 맞음·MVS 틀림(보존), 칸 3은 둘 다 틀림이다. 칸 4·5는 MVS 없음, 칸 6은 참값 없음이다.
- 중단·미채점·참값 없는 결과는 0이나 면 없음 100%로 채우지 않는다. N < 100인 세부 칸은 표본 부족을 표시한다.
- 8.4의 세 문턱과 최댓값을 함께 읽는다. 같은 단위의 씨앗 변동 폭은 `2.8 × |prop_ALS_s0 − prop_ALS_s1| / √2`다. 기존 모은 변동 폭이 없는 지표는 자료 없음 상태를 유지하고 모든 문턱이 완비됐다고 해석하지 않는다.
- 비율은 분자·분모 넓이로 계산한다. 지역별 비율을 단순 평균하지 않는다. 지역마다 결과를 먼저 제시한다.
- 판 1의 중단 네 건을 제외한 생존 판만으로 고정 손실과 다이내믹의 전체 평균 우열을 추정하지 않는다.
- 조각 TSDF는 같은 영상·순서·5 cm 복셀·25 cm 절단 거리와 기존 채점을 쓴다. 두 실제 16 m 영역에서 기존 방식과 동일성 검증을 했고 전체 ALS 11판 실행이 완료됐다. 전체 장면을 기존 일괄 방식과 직접 비교한 검증은 없다.
- 분석용 패치 배열에는 채점용 참값이 포함돼 있다. 이를 새 학습이나 파라미터 선택에 사용하도록 승인하는 전달은 아니다.

4. [B173 날개 단면](figures/section_B173nb_b10_ALS_0.png), [단면 출처](figures/section_B173nb_b10_ALS_0.json). 칸별 지도와 심긴 점 운명 그림은 중간 보고에서 연결된다.
5. [11판 원자료 재계산·그림·메시 출처 검증](tables/twelve_arm_verification.json). 추가 지표는 `tables/axes/`의 해당 판 JSON과 `run_inventory.csv`를 대조한다.

전체 ZIP에는 `patch_z/`의 판별·기준별 결과와 `direct_stage1_v2/<지역>__ALS/evaluation.npz`, `values.npz`를 함께 넣었다. 패치의 넓이·참값·MVS 값·칸·평가 여부·불확실도를 이용해 표를 다시 계산할 수 있다. 각 결과의 `patch_id`는 `stage1:<지역>:ALS:<행 번호>`이며 순서를 검증한다. `z`, `p_gt`, `p_mvs`는 해당 사전 정보 패치의 법선 방향 거리(m)다. `z`의 NaN은 면 없음이고, `side`의 0/1/2/3은 사전 정보 쪽/MVS 쪽/둘 다 아님/면 없음이다. 이는 정답·오답 칸 번호와 다르다.

`fates/`와 `fate_cell_split/`에는 심긴 점 운명과 칸 0·2 분리가 있다. 대형 학습 모델·원시 영상·전체 메시 자체는 포함하지 않았으므로 새 시점 렌더링이나 메시 재채점은 이 ZIP만으로 하지 않는다. 가벼운 ZIP에는 요약 표와 그림만 있으므로 원자료 분석에는 전체 ZIP을 사용한다.

## 이번 전달에서 바꾼 것

24개 구성과 비교 가능 범위를 설명하고, 판 이름·사전 기대·분석 질문을 추가했다. 전체 ZIP에 ALS 세 단위의 평가 분모와 규칙 배열을 추가해 외부 환경에서 핵심 표를 재계산할 수 있게 했다. 기존 11판 측정값·검증된 그림·학습·손실·채점·판·실행 순서는 바꾸지 않았다. 이전 ZIP은 보존한다.
