## 종료 시간: 잠정 계획

정상 완료 11회의 학습 시간은 40.4~74.8분, 중앙값 48.1분이다. 남은 학습은 GPU 두 개를 사용할 때 오늘 10월 27일 15~18시를 잠정 범위로 둔다. 후처리의 GPU 점유와 시작 메모리 대기가 길면 늦어진다.

이전 nojudge의 같은 후처리 단계 기록은 장면당 약 5~7.5분, 추가 run 단계는 약 0.4~2.8분이었다. 새 모델의 조각 처리·CPU 채점·메모리 대기까지 합친 실측은 아직 없다. 계획에는 한 판 20~40분을 가정한다. 중단된 두 판을 제외한 최대 22회의 직렬 후처리·채점은 7시간 20분~14시간 40분이며 학습과 일부 겹친다. 따라서 전체 정리는 오늘 밤~내일 오전을 잠정 범위로 둔다. 이는 종료 보장이 아니며 첫 전체 장면의 실측 뒤 갱신해야 한다. 추가 오류나 장기 메모리 대기는 포함하지 않았다.
