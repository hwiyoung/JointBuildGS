## 1. 같은 지역과 실제 평가 범위

P2는 tile `x004_y004`의 기존 동쪽 톱니형 지붕 개발 prism이다. 전체 552개의 2 m XY 셀을 유지하고 원자료 점 수로 미리 정한 64개를 개발 비교한다. 후보·관측이 부족한 셀을 다른 셀로 바꾸지 않았다. 셀은 건물 stable ID나 검증된 표면 면적이 아니다.

- 원자료: MVS **330,679점**, ALS **45,986점**. 원 PLY/LAZ에서 partition 전체 XYZ를 순서대로 재생하고 선택 원행까지 결속했다.
- A 후보: IMAGE 63개, PRIOR 50개, 실제 결합 FUSION 39개, 총 **152후보·9,005점**. 소스별 지배 planar patch의 제한된 원점 지지이며 다른 층·비선정 점은 공통 자료에 보존했다.
- 영상: frozen66을 SHA 기반으로 판단 **22** / 학습 **33** / 외관 평가 **11**로 고정했다. 모두 역사적으로 사용한 개발 사진이고 exact937 카메라/MVS 계보도 공유한다.
- 현재 UAS: prism 전체 **2,325,976점**, 개발64셀의 고정 평가 분모 **268,544점**. 552셀 모두 점 지지가 있지만 모든 표면의 피복·정확도가 확인된 것은 아니다. raw classification은 모두 0이므로 지붕·지면 정답으로 읽지 않았다.
- GroundSurface XY와 교차하는 stable ID는 `DEBY_LOD2_4959326`, `DEBY_LOD2_4959460`이다. RoofSurface·Z·roof type은 판단·학습에 사용하지 않았다.

ALS의 기존 `+45.7 m → world shift 차감`을 중복 적용하지 않았다. 카메라/MVS/UAS의 원 수치 좌표와 ALS의 기준계 이력은 [frame 감사](SAMPLE_CONTRACT_ko_v1.md)에 연결했다. UAS header의 EPSG:32632와 프로젝트 EPSG:25832 계약, 당시 투영 연산과 실제 datum/epoch 불확실성을 구분한다. P2에서 확인한 투영 연산의 수치 차이는 최대 약 **0.000167 m**이나 이것이 측량·datum 오차의 상한은 아니다. 아래 UAS 수치는 기존 수치 좌표 연결을 조건으로 한 점군 근접성 진단이다.

## 2. A — 추가 계산이 더 유용한 판단을 만들었는가

비교는 원후보 사진 점수, 한쪽 소스 고정, Gaussian+uniform 관측모형의 확률적 높이 추정, 유한 높이 가능집합, 공유 이동 오차 확대를 사용했다. 확률적 비교는 원논문의 관측모형을 유한 높이 격자에 적용한 공개된 변형이다. 미검증 대응·카메라 오차를 해결한 원논문 전체 재현으로 부르지 않는다.

아래는 사전에 정한 표시/인계 설정 `τ=0.3, ε=0.5 m`의 실제 입력 조건이다. ‘부적합’은 원점 후보의 UAS 최근접 3D 거리 p90이 이 감도값을 넘는다는 조건부 진단이다. 공식 사용 허용오차가 아니다.

| 판단 | 채택 / 64 | 조건부 부적합 / 채택 | 기하상 적합 후보가 있는 60셀 중 유보 |
|---|---:|---:|---:|
| IMAGE 고정 | 63 | 9 / 63 | 1 / 60 |
| PRIOR 고정 | 50 | 25 / 50 | 11 / 60 |
| 사진 점수 | 2 | 0 / 2 | 58 / 60 |
| 확률적 비교, 카메라 분리쌍 | 4 | 0 / 4 | 56 / 60 |
| 확률적 비교, 공유 카메라 포함 모든 쌍 | 5 | 3 / 5 | 57 / 60 |
| 유한 높이 범위 | 2 | 1 / 2 | 59 / 60 |
| 유한 높이 범위 + 공유 이동 불확실성 | 0 | **산출 불가** | 60 / 60 |

이 설정에서 범위법은 점수법과 같은 채택 수에서 부적합이 더 많았고, 분리쌍 확률적 비교보다 채택 수가 작았다. 전수 유보를 위험 0의 성공으로 세지 않았다. 전체 감도 설정을 [A 검증 그림](../../../../../JointBuildGS-artifacts/phase-payloads/phd/p2_ab_v1/PHD-P2-AB-A-FIGURES-v2/A_decision_validation.pdf)과 [672개 조건/설정 집계](../../../../../JointBuildGS-artifacts/phase-payloads/phd/p2_ab_v1/PHD-P2-AB-C-v2/decision_risk_coverage.csv)에 보존했다. 반복 설정은 새로운 독립 표본이 아니다.

실패는 같은 ID로 추적된다. `P2_X066_Y043`은 높이 범위 상한 0.375 m와 조건부 이동 여유 0.125 m를 얻었지만 후보의 UAS 최근접 3D p90은 약 0.782 m였다. 높이 상한과 최근접 3D 오차는 다른 성분이므로 이를 곧바로 상한 보정 실패율로 계산하지 않는다. 대응을 조건으로 한 XY 최근접 높이 오차도 함께 기록했다. 자연 MVS 결손 `P2_X078_Y056`에서는 prior의 근접성은 양호했지만 관측 기반 방법 모두 유보했다. prior가 필요한 곳에서 판단 근거도 부족할 수 있다는 미해결 문제다.

카메라·정합·현재 가림·연속 영역의 오차 계약이 확보되지 않아 모든 `strict_current_use_action`은 `ABSTAIN`이다. B에 전달한 것은 실제 영상으로 계산한 **조건부 개발 판단**이며, 실제 사용 승인을 가정한 성공 결과가 아니다.

## 3. B — 같은 판단에서 재구성이 무엇을 바꿨는가

선택 후보의 정확한 원점 지지를 planar Gaussian으로 표현하고, 구조의 offset/slope와 그 affine 성분에 직교하는 세부 변위를 분리했다. 사진 잔차를 줄이는 갱신 후 고정 train ray의 깊이 이동·표면 소실·범위 침범을 검사하고 실패 시 파라미터와 optimizer 상태를 복원한다. 유보 경계의 연결·분할·제거는 새 사용 범위를 승인할 수 없다.

실제 A 인계는 높이 성분만 제한하므로 제안 arm에서 허용된 기하는 해당 성분의 이동으로 제한했다. 면 지지·방향·세부 예산을 만들지 않았고, 예산이 없는 인계에서는 기하를 고정했다. 표현의 구조/세부 분해 구현과 그것을 실제 관측으로 허용하는 일은 구분한다.

유한 범위 판단의 두 셀에서는 72번의 기하 갱신이 모두 존재·경계 검사에서 복원됐다. 따라서 **제안 재구성은 기하 고정 GS와 같았으며 추가 기하 이득이 없었다.** 검사 완화나 유리한 설정 선택으로 결과를 바꾸지 않았다. 다른 고정-source 인계에서도 미확정 예산을 임의로 만들어 제약 갱신을 허용하지 않았다.

기존 prior-loss 형태의 local 비교에서는 외관과 기하가 함께 개선되지 않았다. IMAGE 고정 인계의 평균 단위 p90은 약 0.067 m 감소했지만, 63개 비교 단위 중 26개는 1 mm 이상 증가했고 고정 UAS 회복률은 74.46%에서 74.30%로 조금 감소했다. 이 1 mm 구간은 수치 변화 표시용이며 사용 성공 기준이 아니다. 평균 오차만으로 양호 영역의 비열화를 주장하지 않는다.

DN-Splatter는 pinned 원코드로 수행한 별도 96단계 개발 비교다. 동일 선택 prior와 33/11 사진·crop를 사용하지만 원법의 3DGS, SH3, 초기 scale/opacity와 optimizer는 2DGS 비교와 다르다. 원법 자체 초기화도 별도로 렌더하여 최종과 비교했다. 수렴한 성능이나 원논문의 전체 벤치마크 재현으로 해석하지 않는다.

## 4. C — 전체 범위를 고정하면 결과가 어떻게 보이는가

기하 평가 분모는 항상 개발64셀의 UAS **268,544점**이다. 외관 비교는 학습하지 않은 IMAGE/PRIOR 고정 표현의 alpha 합집합으로 **69,722개 공통 평가 픽셀**을 정하고, 모든 A×B에서 target crop의 byte 일치를 확인했다. 이 픽셀 집합은 검증된 표면 면적이 아니다. 방법별 초기 alpha 영역의 PSNR은 B 내부 비교용이고 A간 순위에는 사용하지 않았다.

| 전체 조합 | 표면이 나온 셀 / 64 | 0.5 m 안의 고정 UAS 회복률 | 공통 영상 픽셀 피복 | 공통 픽셀 PSNR |
|---|---:|---:|---:|---:|
| 범위 판단 → 제약 GS | 2 | 2.17% | 1.10% | 6.01 dB |
| 점수 판단 → 고정 GS | 2 | 2.66% | 1.68% | 6.02 dB |
| 분리쌍 확률 판단 → 고정 GS | 4 | 7.36% | 4.31% | 6.11 dB |
| IMAGE 고정 → 고정 GS | 63 | 74.46% | 73.02% | 9.74 dB |
| PRIOR 고정 → 고정 GS | 50 | 32.36% | 46.91% | 8.01 dB |
| PRIOR 고정 → 원 DN-Splatter, 96단계 | 49 | 30.19% | 34.22% | 9.90 dB |
| 공유 오차 포함 범위 판단 → 재구성 유보 | 0 | 0% | 0% | 미산출 |

유보가 많은 판단은 채택 부분의 오차만 낮게 보일 수 있지만 전체 복원 범위는 작았다. DN의 높은 공통 PSNR도 더 나은 기하·완전성으로 이어지지 않았다. 서로 다른 오채택 비용과 유보 비용을 하나의 순위로 합치지 않는다. 원점·영상 적합도나 이 개발 표를 건물 사용 성공 또는 현재시점 표면 보장으로 바꾸지 않는다.

## 5. 검증·보존과 남은 설계

Docker에서 새 워크스트림의 의미 검사 30개와 저장소 agent 계약/동기 검사를 통과했다. 독립 재계산으로 43,008행 판단 연결, 672개 위험/유보 집계, 단위별 UAS 분모 및 공통 픽셀 MAE/PSNR/피복을 검증했다. 기존 문서·코드 169개 해시는 시작 상태와 일치한다. 원자료·이전 실험·실패 실행을 보존했고 stage/commit하지 않았다. 새 입력·결과·소스 snapshot·컨테이너·설정은 [통합 manifest](../../../../artifacts/manifests/phd/p2_ab_v1/technical_result_manifest_v1.json)에 연결한다.

기술적 실패와 조치는 [샘플 이슈](SAMPLE_ISSUES_ko_v1.md), [A 이슈](A_ISSUES_ko_v1.md), [B 이슈](B_ISSUES_ko_v1.md), [C 이슈](C_ISSUES_ko_v1.md)에 보존한다. 3D 뷰어는 실제 Chrome에서 단위 선택·시점 이동·모바일·이미지 로드를 확인했다.

다음 설계의 대상은 결과가 드러낸 세 부분이다.

1. **A:** 사진 대응/가림과 공유 카메라·정합 오차를 입력에서 추정하여 사용 범위로 옮기는 계산. 유한 높이 점수집합 자체를 사용 보장으로 승격하지 않는다. 좋은 prior가 있는 자연 결손에서 왜 유보하는지 해결해야 한다.
2. **B:** 직접 지지된 점에서 면·경계·세부의 허용 조건을 얻는 계산과, 관측 가능한 갱신까지 모두 복원하지 않는 표면 검사. 이번 실행은 비선정 영역의 생성, 실제 접합/증감, 방향·세부 허용을 입증하지 않았다.
3. **전체:** 현재 참조의 오차·기준계·대응 조건 검증과 별도 장면/평가 설계. 이번 depth/alpha 유래 표면 표본은 완성된 연속 mesh 또는 LoD2/Roofer 성공 판정이 아니다.

필요한 개발 실행과 분리·통합 검증은 수행했다. 현재 방법의 우월성·절대 사용 안전성·확증 결과는 미확인 상태로 남긴다.
