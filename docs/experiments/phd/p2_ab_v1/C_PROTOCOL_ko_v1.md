# P2 판단·재구성의 분리 및 통합 검증

> `PHD-P2-AB-v1`. 2026-09-06 사용자 요청으로 설계·필요 구현·개발 실험을 수행한다. 비확증 개발이며 `scientific_verdict: null`. E1–E6와 역사적 C 계보는 변경하지 않는다.

현재 영상과 과거 ALS 중 사용할 기하를 정하는 A와, 정해진 기하를 현재 외관과 함께 표현·갱신하는 B를 독립 구현한다. 같은 P2 지역·단위 ID를 사용하여 A의 결정 변화가 선택 기하의 실제 오차에 주는 영향, 같은 A 결과에서 B의 표현·갱신이 주는 영향, 실행한 A×B 조합의 최종 결과를 구별한다.

기존 자료는 읽기 전용으로 마운트하고 실행별 새 외부 디렉토리에 저장한다. 기존 연구 문서와 코드의 시작 해시는 `PHD-P2-AB-AUDIT-v1/preserved_workspace.sha256`에 보존했다. 새 본문은 이 디렉토리에 추가하여 이전 r3.7과 미커밋 작업의 바이트를 유지한다. 기존 인계 문서의 ‘실행하지 않았다’는 당시 상태이고 이번 개발 실행은 현재 사용자 요청에 근거한다.

## 공통 비교와 증거의 수준

| 비교 | 고정 | 변경 | 결과 |
|---|---|---|---|
| A 판단만 | 후보·판단 사진·기하 오차 기준·고정 표면 표현 | 점수 게이트, 소스 고정, 불확실성 추정, 가능집합 판단 | 실제 후보 점군 오차, 조건부 채택/오채택/유보, 평가 불가 |
| B 재구성만 | 실제 측정된 동일 A 결과·초기 표면·학습/평가 사진 | 텍스처링, 기하 고정 GS, prior 손실 GS, 제한 갱신 GS | 산출 표면 변화·소실·외관·UAS 오차 |
| C 전체 | 같은 원입력·영역·평가 분모 | 실제 실행한 A×B 조합 | 최종 개선/열화 및 원인이 된 단계 |

현재 관측에서 계산한 **조건부 판단 인계**와, 실제 관측으로 지지하지 않은 값을 가정한 **solver 검산**을 나눈다. 카메라·정합·가림·연속영역 오차를 검증하지 못한 경우 엄격한 현재 사용 행동은 `ABSTAIN`이다. 이 조건을 명시한 개발 인계로 전체 계산은 실행할 수 있지만 현재 사용의 확정이나 과학적 기여 입증으로 제시하지 않는다.

## 평가 계산과 고정할 분모

현재 UAS는 평가에서만 읽는다. 후보별 실제 좌표와 원점 소속을 유지하고 UAS에 대한 최근접 3D 거리의 중앙값·p90·RMSE를 계산한다. 다른 점밀도의 영향을 드러내기 위해 예측→참조 정밀도와 참조→예측 회복률을 함께 남긴다. 후자의 분모는 같은 단위의 고정 UAS 원점이다. 점군 기반 수치를 면적이나 건물 사용 성공으로 바꾸지 않는다.

0.25/0.5/1 m는 이전 높이 진단에서 이어온 감도축이며 공식 허용오차가 아니다. 후보 점군의 p90 거리로 조건부 `candidate_ok`를 계산하되, 모든 표본점에서 0.5 m XY 안의 UAS 지지가 없으면 상태는 미확정으로 남긴다. XY 대응의 거리·부호 높이차도 보존하지만 다층 대응을 해결한 증거로 사용하지 않는다. 참조 자체 정확도·잔여 수직 기준의 불확실성을 임의의 수치로 채우지 않는다.

각 방법에 대해 채택 전체 수, 평가 가능한 채택 수, 평가 불가 채택 수를 구분한다. 오채택률은 **평가 가능한 채택 중 부적합 비율**이고 채택이 없으면 `null`이다. 하나라도 사용 가능한 후보가 있는 단위에서 유보한 비율도 함께 계산한다. 여러 후보가 동시에 적합할 수 있으며 단일 정답 소스 라벨을 만들지 않는다. 두 원후보 모두 부적합인 경우와 그때의 유보를 별도로 센다. 실제 결합 후보의 오차를 직접 평가한다.

재구성 예측이 사라진 단위도 공통 UAS 분모에 남겨 회복률 0으로 계산한다. 참조가 없는 단위는 평가 불가다. 표면 이동·소실은 초기 표현과의 비교이고 현재 기하 정확도는 UAS와의 비교이므로 별개로 기록한다. 별도 역할로 고정한 평가 영상의 외관을 비교하되, 역사적으로 66뷰 모두 개발에 사용됐고 MVS와 exact937 계보도 공유하므로 독립 확증으로 부르지 않는다.

## 실행 전에 고정한 보고 원칙

실제 조건과 소스 이동·공통 이동·관측 제한 통제를 구별한다. 주입값을 원후보의 참오차로 해석하지 않는다. 관측이 부족해 성공 사례가 없더라도 지역이나 기준값을 유리하게 바꾸지 않는다. 모든 감도 설정을 보존하며 동일 단위·반복 설정·공유 카메라쌍을 독립 표본으로 세지 않는다. 같은 채택 범위/위험이 실제로 겹치는 지점에서만 우열을 비교한다. 강한 출판 방법의 일부 계산을 변형해 구현하면 원논문의 전체 재현과 구분한다.

실행 상태와 수치는 후속 `TECHNICAL_RETURN_ko_v1.md`에서 실제 산출물에 연결한다. 이 프로토콜은 결과를 미리 주장하지 않는다.
