# A — 판단 비교와 개발 실험 설계

> `PHD-P2-AB-A-v1`; 2026-09-06. 사용자 요청에 따른 새 구현·비확증 개발 실험. `scientific_verdict: null`.
> 기존 입력·높이 진단·E1–E6·C 계보와 수정 중인 논문 초안은 보존한다. 계산 전 이 문서·설정·코드의 해시를 새 실행 폴더에 저장한다.

## 판단할 것과 실제 구현 범위

공통 P2의 **고정 64개 XY 단위에서 IMAGE·PRIOR·FUSION 후보를 각각 현재 사진으로 검사**한다. 점수 하나, 확률분포, 남은 높이 집합이 어떤 다른 채택·유보를 만드는지 비교한다. 같은 기준 후보·관측·허용오차를 쓰고, 선택된 실제 후보 배열을 B와 C에 넘긴다. 사진 적합도 계산은 이전 native-point 높이 검사를 재사용하되 새 22개 판단뷰와 새 후보·단위에서 다시 측정한다.

실행되는 범위는 후보 형상을 통째로 scene-Z 방향으로 이동한 33개 이산 높이 `−2…2 m, 0.125 m 간격`이다. 수직 성분은 좌표 성분이며 gravity 추정이라고 하지 않는다. 카메라/정합의 절대오차, 현재 가림·참 대응, 연속 검색 범위, 점→면 사용 승인은 미검증이다. 따라서 실제 관측에 의한 `conditional_action`과 검증 계약을 요구하는 `strict_current_use_action`을 구분한다. 후자는 현재 모든 단위에서 `ABSTAIN`이다. 전자의 실제 측정 결과를 B의 개발 재구성과 UAS 진단 평가까지 연결한다. 이를 합성 가정만으로 만든 인계와 혼동하지 않는다.

## 공통 후보와 관측

`PHD-P2-AB-COMMON-v2/common/units.json`의 `pilot_unit_indices` 64개를 그대로 사용한다. 전체 552개 단위, 후보를 만들지 못한 선택 단위, 다른 층, 미표집 단위를 분모에 보존한다. 각 소스에서 단위 내 점수가 아닌 **native 점 수가 가장 많은 planar patch**를 고르고 30점 이상일 때 원행 순서의 균등 최대 64점을 사용한다. 다른 층을 선택층에 섞지 않으며 이 결과는 단위 전체 층의 사용 판정이 아니다.

- `IMAGE`: exact common-base MVS의 원좌표·원행. 현재 영상 유래라는 이유로 정확성을 가정하지 않는다.
- `PRIOR`: supplied scene frame의 ALS 원좌표·원행. ALS의 기존 `+45.7 m` 변환 계보를 그대로 사용하며 새 정합을 하지 않는다.
- `FUSION`: sampled ALS점에서 같은 단위의 선택 MVS patch 원점까지 XY 거리 `≤0.3 m`인 대응을 찾고 명시한 두 원점의 산술평균으로 생성한다. 원 MVS/ALS와 구별되는 파생 후보다. 대응 30점 미만이면 후보 없음. 이 XY 반경은 개발 대응 범위이며 같은 현재 표면임을 입증하지 않는다. 두 부모가 해당 판단법에서 사용 지지를 얻고, 전체 대응의 거리 상한이 해당 ε 이하이며 법선 차이 상한이 20° 이하일 때만 FUSION 행동이 가능하다. 두 후보를 단순 중복 GS로 쌓지 않는다.

서로 다른 후보의 원점 지지는 다를 수 있다. **판단법들 사이에는 각 후보별 동일한 관측·원점·높이 곡선을 제공**한다. 모든 높이에서 같은 원점이 FOV 안에 있는 뷰쌍만 사용하고, 모든 높이에서 유효한 동일 쌍 3개 이상일 때 중앙 ZNCC 곡선을 산출한다. 결측을 0으로 채우지 않는다. 후보 간 서로 다른 표면 표본은 결과의 제한이며 표본 수·쌍 수를 기록한다.

22개 decision뷰만 판단에서 읽는다. train 33개와 appearance_eval 11개는 새 계산에서 역할이 분리되지만, 66개는 모두 과거 개발뷰이고 원 MVS 생성에도 이미지 계보가 공유된다. 손대지 않은 확증 분할이 아니다. UAS·LoD2 평가 자료는 A가 읽지 않는다.

## 비교법·원출력·4행동 변환

| 구현 arm | 계산과 원출력 | 현재 문제로의 명시적 변환과 한계 |
|---|---|---|
| `FIXED_IMAGE`, `FIXED_PRIOR` | 기준 소스 기하를 고정 | 해당 소스가 있으면 무조건 선택. 한쪽 기하를 참으로 고정하는 영향의 대조군이며 사용 승인을 보장하는 알고리즘이 아님 |
| `SCORE_GATE` | 고정 후보에서 ZNCC 중앙값 | τ 이상 후보 중 점수가 큰 후보 선택. 사용 허용오차 정보가 없음. 구성요소 비교이지 강한 완전 방법이 아님 |
| `BAYES_GAUSS_UNIFORM` | Vogiatzis–Hernández Gaussian+uniform likelihood의 full `height×inlier-rate` 사후분포를 수치적분 | 각 후보의 `P(|h−h_candidate|≤ε)`가 0.9 이상인 후보 중 예상 절대오차 최소 선택. 원법은 현재/과거 source action을 출력하지 않으므로 이 어댑터는 본 실험의 추가 구성 |
| `BAYES_GAUSS_UNIFORM_ALL_PAIRS` | 동일 Bayesian 계산에 중복 카메라를 포함한 전체 적격 쌍 | 공유 관측을 독립으로 처리할 때의 과신 대조. 기본 Bayesian은 원쌍 순서에서 카메라가 중복되지 않는 greedy matching을 먼저 적용. 완전한 통계 독립을 보장하지 않음 |
| `DISCRETE_RANGE` | ZNCC≥τ인 모든 이산 높이 유지; 후보와의 최소 B·최대 U 오차 | 비어 있지 않고 경계 설명이 없으며 U≤ε인 후보 중 U 최소 선택. 빈 집합은 `MODEL_MISMATCH`, 경계는 탐색 미완료, B>ε는 조건부 반대, 나머지는 모호함 |
| `DISCRETE_RANGE_SHARED_SHIFT` | 같은 가능집합에 공통 scene-Z 위치의 ±0.5m 미확정 범위 부가 | U를 0.5m 늘리고 B를 0까지 줄여 같은 검사를 수행. 새 정합 추정 또는 보정된 오차가 아닌 사전 공동 편향 민감도 arm |

Bayesian 원논문은 calibrated 영상의 광선 깊이에서 NCC 국소 극대를 Gaussian+uniform 센서로 보고, 깊이와 inlier 비율의 posterior를 추정한다. 식 (1)–(2)는 직접 확인했으며 원논문의 실시간 구현은 Gaussian×Beta 근사를 사용한다. 본 구현은 **한 후보의 scene-Z 이동, 각 쌍의 유일 최고점, 33×101 격자 full posterior**로 제한한 변형이다. 확률센서 계산을 실제 구현한 비교이며 원논문 시스템의 재현이나 최강 성능 입증이라고 하지 않는다. [저자 원문, §3](https://george-vogiatzis.org/publications/ivcj2010.pdf)

측정 표준편차는 후보 centroid에서 두 카메라의 4×3 투영 Jacobian을 만들고 픽셀 표준편차 1의 `(JᵀJ)⁻¹`에서 Z 분산을 구한다. 여기에 후보 native 점들의 선택 patch 법선방향 RMS 산포 제곱을 더한다. `sqrt(σ_triangulation,z² + scatter_source²)`는 소스별 roughness를 포함한 **조건부 모델**이며 센서오차 보정값이 아니다. 정합 공분산이 없다는 이유로 0이 확인됐다고 하지 않는다. 두 후보 모두 별도 현재 사진 검정을 받으므로 어느 소스도 참 기하로 고정하지 않는다. 동일 posterior를 이용한 shared-bias 통합·보정된 양소스 공분산·확률 coverage 검증은 남은 한계다.

현재 range 추가 계산은 전체 곡선에서 남은 대안을 명시하고 경계·공동 이동 가능성을 후보 오차로 전달한다. 기존 확률법도 같은 유보를 만들 수 있다. 추가 이득은 실제 같은 채택 범위의 오류와 유효 후보 유보를 통해 판별하며, 결정이 다르다는 사실이나 보수적 전수 유보만으로 기여를 확정하지 않는다.

τ=`0.3/0.5/0.7/0.9`, ε=`0.25/0.5/1m` 전부를 기록한다. 기본 인계 τ0.3·ε0.5m는 결과를 보기 전의 개발 출력 설정이며 운영 문턱 또는 응용 정확도 요구가 아니다. 1m 주입은 이전 metre-scale 통제와 같은 개발 규모다. 64×반복 설정을 독립 표본으로 세지 않는다. 임의의 좋은 설정을 평가 후 고르지 않는다.

## 인계와 평가 계약

`candidates.npz`는 모든 후보 xyz/normals/candidate_index와 MVS·ALS 원행을 보존한다. `handoff.jsonl` 각 행은 단위·방법·통제·실제 조건부 행동·strict 행동·선택 후보 인덱스·이동값·근거·미확정을 포함한다. range에서 산출된 `ε−U`만 `conditional_displacement_budget_m`으로 넘기고, 그 값은 이산 높이 범위 가정 아래의 성분 예산이다. 다른 법의 예산은 null이고 B에서 기하를 고정한다. 연속면 지지나 다른 방향의 변형 승인을 만들어 붙이지 않는다.

C는 판단 후 reference-only로 같은 후보·결합 후보 자체와 선택/재구성 결과를 검사한다. 후보 여러 개가 동시에 유효할 수 있으며 단일 정답 출처 라벨을 만들지 않는다. 미피복·참조 불확실성·수직 datum 차이는 따로 보고한다. 오채택 분모는 참조로 판별 가능한 채택 단위이고, 채택 0이면 오채택률 null이다. 유효 후보가 있는 단위 중 유보 비율, 모든 후보가 부적합한 단위, 실제 채택 오차, 전체 64개 대비 채택 범위를 함께 기록한다. 점수 순위가 기하 정확도의 대체값은 아니다.

현재 확인된 UAS 선언 CRS는 EPSG:32632, 프로젝트 좌표계는 EPSG:25832다. 수치 좌표의 legacy 일치만 이용한 C 결과는 current-UAS 근접성 진단이고 보정된 참오차 판정으로 승격할 수 없다. 이 제한을 이유로 A 문턱/영역을 참조에 맞춰 변경하지 않는다.
