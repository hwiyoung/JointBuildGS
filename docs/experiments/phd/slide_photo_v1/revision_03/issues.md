# R2/R3 제작 중 발견 사항

- R2 확대 시안은 사용자 검토와 독립 판독에서 목적 전달이 부족했다. 장소만 표시하는 사진을 최종본으로 채택하지 않고 R3에서 자료 비교와 짧은 설명을 추가했다.
- R2 첫 지붕에서 면 전체의 투영 다각형을 확대 기준으로 쓰면 실제로 검사한 작은 위치와 화면 중심이 어긋났다. 동결된 locmap의 실제 평가 화소를 원본 카메라로 투영해 표시 범위만 수정했다. 값과 패치 선택은 그대로다.
- R2 E 첫 실행에서 JSON의 회전/이동 목록을 배열로 변환하지 않아 `G.project`가 실패했다. 배열 변환을 추가한 후 다시 실행했다. 실패 로그: 외부 payload `logs/r2-e.log`; 성공 로그: `logs/r2-e-fixed.log`.
- R2 단면 시안은 결과 칸에 원시 참조점과 0.25 m 입력 요약점을 동시에 그려 층이 혼동되었다. 결과 칸은 원시 참조점 전체만 표시하고 입력 요약은 입력 칸에만 남겼다. 저장된 결과 면과 비율은 바꾸지 않았다.
- R3 초기 배치에서 3쪽 범례가 파일 아래 끝에 가깝고 4쪽 사진의 가로세로 비율이 맞지 않았다. 범례 위치와 표시 사각형을 수정했다. 최종 4쪽은 원본 공통 범위의 비율과 반올림 오차 0.3% 이내로 일치한다.
- 해석 제한은 보고서에 남겼다. 금속 면의 외관상 지붕/벽 혼동, 첫 지붕의 작은 평가 범위, 같은 건물 지붕에 의한 가림, B173 결합의 참값 근접을 숨기지 않는다.
- 첫 묶음 검증에서 Docker 안의 Git 조회가 외부 worktree 메타데이터 경로를 찾지 못했다. 파일·값 검사는 그 전에 통과했다. 호스트에서 읽은 정확한 커밋을 검증 프로그램 인자로 전달하도록 고친 뒤 전체 검증을 다시 실행했다. 저장소나 다른 컨테이너의 설정은 바꾸지 않았다.
