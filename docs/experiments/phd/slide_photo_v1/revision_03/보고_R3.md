# 설명 자료용 실사 그림 — 의도 전달 수정 R3

**중간 시안. 사용자가 사진과 글을 여전히 이해하기 어렵다고 지적해 R4로 대체했다. R3 전달 ZIP은 만들지 않았다. 최종 교체용 그림은 `../revision_04/`에 있다.**

작업: `PHD-SLIDE-PHOTO-v1-R3`. 학습·GPU 실행 없음. 기존 장소·시점·측정값 유지. `scientific_verdict: null`.

사용자가 확대와 영역 표시만으로는 의도가 읽히지 않는다고 지적했다. 6쪽 구성은 사용자가 선택한 **사진 + 비교 그림 + 짧은 설명**으로 변경했다. 원래 360×200 사진 칸에 억지로 내용을 넣지 않고, 네 목적을 함께 보여 주는 1600×600 배치를 추가했다. 원본 PPTX는 연결되어 있지 않아 교체용 PNG로 전달한다.

## 사진과 비교 자료의 연결

- 보존: 선택된 금속 면의 실제 사진과 동결된 `selected_clouds.npz`의 참값·사전 정보·MVS 점을 연결했다. 기존 측면 투영을 그대로 사용했다. 파란 점의 불일치와 참값에 가까운 사전 정보가 보존의 필요성을 설명한다.
- 보정: B173 사진과 원래 REGIONFIG의 0.25 m 간격 입력 단면을 연결했다. 옛 지붕과 현재 참값·영상의 차이를 보여 준다.
- 다듬기: 같은 B0 면 7의 사진과 기존 5 m 단면을 연결했다. 높이 방향을 확대해 표시한 단면이며, 선택 면 전체의 LoD2−참값 중앙값은 −14.61 cm다.
- 상속: 같은 벽 53과 가림 지붕 38의 실제 사전 정보 좌표를 측면으로 투영했다. 화살표는 해당 사진 카메라에서 벽으로 향하는 방향이고 길이만 줄여 표시했다. 현재 벽의 존재나 상속 성공을 새로 확인한 결과가 아니다.

## 원본 유지와 해석 제한

1. 원래 JSON 10개의 SHA-256을 R2 설정에 고정했고 수정 뒤에도 일치하는지 검사한다. 패치, 영상, 단면, 허용오차 안 비율을 바꾸지 않았다.
2. 3쪽 첫 지붕의 100%는 원래 깊이 격자 20화소의 결측률이다. 참조가 있는 4화소만 칠한다. 이를 지붕 전체의 결측률로 설명하지 않는다. 사진에서도 평가 범위가 작다는 한계가 남는다.
3. 금속 외관은 사진 판단이다. 반사가 깊이 불일치의 원인이라는 결론이나 같은 표면 대응의 완전한 검증은 아니다. 사진의 면은 독립 판독에서 여전히 좁은 지붕으로 읽혔다. 설명에는 중립적인 ‘금속 면’을 썼다.
4. 상속의 가림 면은 이웃 건물이 아니라 같은 건물의 지붕이다. 새 그림도 이 관계만 표시한다. ‘상속이 필요한 곳’은 연구 목적 설명이며 실제 현재 형상 또는 결과 성능 판정이 아니다.
5. 단면의 위치와 높이 범위는 그대로다. 참값은 고정된 단면 띠의 원시 참조점을 모두 표시했다. 결과 면을 높이로 삭제하거나 점을 얇게 추리지 않았다. 입력 칸의 0.25 m 높이 요약은 그대로 보존했다.
6. B173에서 결합도 참값에 가깝다. 두 사례 모두에서 결합이 실패했다고 말하지 않는다. 제안 방법의 τ 안 비율은 B173 85.283%, R1 100.000%로 원래 값이며, 추가 오류 면의 존재를 이 비율만으로 배제할 수 없다.
7. 6쪽 비교는 입력 자료이며 제안 방법의 결과를 합성한 그림이 아니다. 그림의 의도가 읽히는지는 독립 판독으로 확인했지만, 이는 과학적 결론의 검증이 아니다.

## 검증·재현

`verification.json`에 원본 해시, 선택/값 일치, PNG 크기, 슬라이드 글자 크기, 실제 크기 미리보기, 도구 버전, 수정 스크립트 해시를 기록한다. `package_receipt.json`은 전달 ZIP의 SHA-256, 구성 파일 해시와 CRC 검사 결과를 기록한다. `issues.md`는 제작 중 실패와 수정 사항을 기록한다.

기존 저장소와 외부 아티팩트가 있는 환경에서 Docker로 실행한다. 원래 과학 자료를 다시 선택하지 않는다.
