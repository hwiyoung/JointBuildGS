# 실사 그림 수정 R4 — 주변 모습과 설명을 함께

`PHD-SLIDE-PHOTO-v1-R4` · 학습/GPU 실행 없음 · 장소/시점/측정값 유지 · `scientific_verdict: null`.

사진을 과도하게 확대해 건물의 어느 부분인지 알아보기 어렵다는 사용자 지적을 반영했다. **3쪽과 6쪽은 사진을 넓혀 건물 주변을 보이고, 사진 위에 짧은 설명과 화살표를 추가했다.** 6쪽에서 이해하기 어렵다고 한 보존 점군은 같은 측정값의 막대 비교로 교체했다. 보정·다듬기·상속 비교 그림은 사용자가 이해하기 좋다고 한 R3 자료를 그대로 사용했다. 글은 ‘지킨다, 고친다, 다듬는다, 메운다’로 정리했다.

원본 PPTX는 제공/연결되어 있지 않아 교체용 PNG로 전달한다. ZIP의 `figures/`는 최신 그림이며 `previews/`는 실제 슬라이드 크기의 미리보기다.

## 이번 변경

- 3쪽: 위 사진을 원본에서 넓게 잘랐다. ‘지붕의 평가 구간’, ‘그늘에 있는 벽’, ‘금속으로 보이는 면’을 화살표로 설명한다. **노란 상자는 아래 확대 사진의 실제 범위**다. 아래는 같은 깊이 검사 마스크이며, 참조가 없는 화소는 여전히 칠하지 않는다.
- 6쪽 사진: 반투명 면 칠을 제거하고 위치 선과 설명만 사용했다. 건물과 주변 공간을 함께 보인다. 상속의 보이지 않는 벽 위치는 점선이다.
- 6쪽 보존: 참값과의 차이 중앙값을 사전 정보 11.641 cm, 영상 깊이 34.339 cm, 허용 20 cm로 표시한다. 그림 숫자는 각각 12, 34로 반올림하고 막대 길이는 원래 값을 사용한다. 원래 선택 덩어리 전체의 법선 방향 절댓값 중앙값이며, 실제 단면을 모사한 선이 아니다.
- 6쪽 나머지 비교: B173 입력 0.25 m 단면, B0 면 7의 5 m 단면, 벽 53/지붕 38의 측면 위치를 유지했다. 사진 설명과 비교 그림의 역할을 분리했다.
- 4쪽과 11쪽: R3 PNG와 같은 바이트를 유지한다. 4쪽은 실제 가우시안 175개의 같은 카메라 투영, 저장된 RGB·깊이 비교다. 11쪽은 참값을 짙은 점, 제안 방법을 굵은 빨강으로 강조했다. 전체 방법 비교본도 별도 제공한다.

## 유지한 해석 제한

1. 3쪽 첫 지붕은 깊이 격자 **20화소**만 평가했고 그중 참조가 있는 **4화소**만 칠했다. ‘없음 100%’를 건물 지붕 전체의 결측률로 설명하지 않는다. 이 사례의 평가 범위가 작은 한계는 남는다.
2. ‘금속으로 보이는 면’은 외관 설명이다. 재질이 불일치의 원인이라는 독립 검증은 아니다. 이 사진만으로 벽/지붕의 기하 분류를 확정하지 않는다. MVS와 정합된 참조의 일치도 독립적인 실제 표면 검증을 뜻하지 않는다.
3. 상속의 가림 면은 **같은 건물 지붕**이다. 이웃 건물이 가렸다고 쓰지 않는다. 현재 벽의 존재나 상속 성공은 확인한 결과가 아니며 연구 목적을 설명한다.
4. 6쪽 보정·다듬기 그래프는 입력 자료이고 제안 방법의 결과가 아니다. 다듬기 그래프는 높이를 확대했다. 선택 면 전체 LoD2−참값 중앙값은 −14.61 cm다.
5. 11쪽 단면의 시작/끝/띠 폭/높이 범위와 결과 면, τ 안 비율은 유지했다. 결과 칸에는 단면 띠의 원시 참조점을 모두 표시한다. 결과 면을 높이로 삭제하지 않았다.
6. B173에서 결합도 참값에 가깝다. 두 사례 모두 결합이 실패했다고 말하지 않는다. 제안 방법의 τ 안 비율은 B173 85.283%, R1 100.000%다. 이 한 방향 비율만으로 추가 오류 면을 배제할 수 없다.

## 처음 보는 사람 점검 — 답 전문

각 새 그림은 맥락 없는 별도 에이전트에게 파일 하나만 주고 ‘이 그림이 보여 주는 것을 한 문장으로’를 물었다. 그대로 유지한 4쪽·단면 두 장은 PNG 해시 일치를 확인하고 R3 답을 유지한다. **독립 판독의 성공을 사용자 수용이나 과학적 검증으로 간주하지 않는다.** R3도 독립 판독에서는 목적이 읽혔지만 사용자 지적으로 사진 구성을 다시 수정했다. R2·R3 답 전문은 `source_metadata/revision_03/blind_reviews.json`에 보존한다.

3쪽: “이 그림은 무늬 없는 지붕과 그늘진 벽에서는 깊이가 누락되고 금속으로 보이는 면에서는 참값과 다른 깊이가 많이 나타나는 세 사례를 보여 줍니다.”

보존: “금속으로 보이는 면에서 참값과의 차이 중앙값이 사전 정보는 12cm로 허용치 20cm 이내지만 영상 깊이는 34cm로 이를 넘어, 영상이 틀린 곳에서는 맞는 사전 정보를 보존해야 한다는 그림입니다.”

보정: “옛 지붕의 사전 정보가 현재 지붕과 다른 구간에서는 현재 영상에 맞춰 지붕 형상을 보정한다는 것을 보여 줍니다.”

다듬기: “이 그림은 사전 정보에서 단순하게 표현된 지붕을 영상의 세부 관측으로 다듬어 참값에 가까워지게 한다는 개념을 보여 줍니다.”

상속: “항공영상에서 지붕에 가려 보이지 않는 벽의 위치와 구조를 기존 사전 정보로 보완하는 ‘상속’ 개념을 보여 줍니다.”

6쪽 전체: “이 그림은 영상 깊이가 부정확한 곳의 사전 정보를 보존하고, 달라진 지붕은 현재 영상에 맞춰 보정하며, 지붕의 세부 형상을 다듬고, 영상에 가려진 벽은 사전 정보로 채우는 네 가지 역할을 보여 준다.”

4쪽(유지): “같은 지붕을 작은 타원들의 집합으로 표현하고 미분 가능 렌더링하여, 생성된 영상의 색과 깊이를 실제 영상·MVS 깊이·사전 정보 깊이와 비교하는 과정을 보여 줍니다.”

단면 강조본(유지): “이 그림은 B173과 R1의 단면에서 제안 방법이 사전 정보의 높이·형상 차이를 보정하여 참값에 가까워지고, 허용오차 τ 이내 비율이 각각 85%와 100%임을 보여 줍니다.”

전체 방법 비교본(유지): “두 지붕 사례의 높이 단면을 참값과 비교한 그림으로, 방법별 허용오차 τ 이내 비율은 사례에 따라 달라지며 제안 방법은 각각 85%와 100%를 보입니다.”

## 재현·검증

기존 저장소와 외부 아티팩트가 있는 환경에서 실행한다. R2/R3는 재현에 필요한 중간 배치이며 최종 전달은 R4다. 원본 데이터는 ZIP에 포함하지 않는다. 기존 `slide_photo_v1.json` 잠금은 유지했다. 새 표시 규칙은 `context_revision_04.json`, SHA-256 `a80ae4fd915ef8cc388535fe16db867a1841b70aba5f1eb4a5e5ec5e356af540`이다.

```bash
bash scripts/phd/slide_photo_v1/run_cpu.sh r2-replay-a layout_revision_02.py a
bash scripts/phd/slide_photo_v1/run_cpu.sh r2-replay-e layout_revision_02.py e
bash scripts/phd/slide_photo_v1/run_cpu.sh r2-replay-b layout_revision_02.py b
bash scripts/phd/slide_photo_v1/run_cpu.sh r3-replay-d semantic_revision_03.py d
bash scripts/phd/slide_photo_v1/run_cpu.sh r3-replay-b semantic_revision_03.py b
bash scripts/phd/slide_photo_v1/run_cpu.sh r4-replay-a context_revision_04.py a
bash scripts/phd/slide_photo_v1/run_cpu.sh r4-replay-e context_revision_04.py e
bash scripts/phd/slide_photo_v1/run_cpu.sh r4-replay-retain context_revision_04.py retain
bash scripts/phd/slide_photo_v1/run_cpu.sh r4-replay-verify verify_package_revision_04.py "$(git rev-parse HEAD)"
```

`verification.json`에 원본 해시, 값·단면 일치, PNG 크기, 슬라이드 글자 크기, 스크립트/설정/도구 버전을 기록한다. `package_receipt.json`은 ZIP SHA-256과 CRC·구성 파일 검증 결과다. 제작 중 실패는 `issues.md`에 남겼다.
