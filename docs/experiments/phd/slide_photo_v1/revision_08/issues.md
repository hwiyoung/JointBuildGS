# R8 시안 작업 이슈

1. **해결 — 메타데이터 확인 도구 부재:** 호스트에 `jq`가 없어 읽기 명령이 실패했다. 설치하지 않고 별도 Docker 컨테이너의 Python JSON 읽기로 필요한 항목을 확인했다. 최초 대형 객체 출력은 불필요하게 커서 이후 명시적인 키만 읽었다.
2. **해결 — 첫 렌더 스크립트 구문 오류:** 마지막 상태 출력문의 괄호 오타로 실행 전에 SyntaxError가 발생했다. 괄호를 고친 뒤 컨테이너에서 재실행해 두 PNG와 검증 기록을 생성했다. 실패 시에는 그림이나 원자료를 변경하지 않았다.
3. **미완료 — 별도 초견 판독:** 맥락을 주지 않은 새 에이전트를 생성하려 했으나 `collaboration.spawn_agent`가 `agent thread limit reached`를 반환했다. `list_agents`에는 root만 표시돼 새 판독자를 확보하지 못했다. 판독 답을 만들어 넣지 않았으며 자체 검토와 수치 검증만 완료했다. 시안 사용에는 영향이 없지만 별도 초견 판독 완료로 보고할 수 없다.
