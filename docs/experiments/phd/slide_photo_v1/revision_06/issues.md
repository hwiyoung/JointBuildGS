# R6 문제와 처리

- **지붕 사례 선정 결함 — 수정.** 이전 규칙은 결측률만 우선하고 평가 화소 수 하한이 없었다. 20화소에서 100% 결측인 사례가 뽑혔지만, 넓은 지붕 결측을 설명할 사례로는 부적절했다. 사용자의 지적 후 입력 면적·투영 패치 비율·연결 결측 면적 조건을 먼저 고정하고 다시 조사했다. 기존 사례의 대표 그림 사용을 철회했다. 원본과 R4 ZIP은 보존했다.
- **건물처럼 보이는 보정 다각형 — 수정.** 분석 패치 중심을 둘러싼 볼록 껍질을 건물 윤곽처럼 보이게 표시했다. 실제 건물 경계가 아니다. 이 표시를 제거하고 기존 단면의 240개 좌표를 원본 카메라로 투영한 A–A′ 선으로 바꿨다.
- **결측과 오차의 혼용 — 수정.** 사용자가 금속 면과 보존 사진이 같은데 깊이가 없다면서 어떻게 오차를 비교하는지 지적했다. 두 사진은 같은 JPEG다. 이 면은 결측 약 3%, 값이 있으나 불일치 약 80%로, 주된 문제는 부정확한 깊이값이다. 제목을 ‘금속 면의 깊이 오류’, 보존 문구를 ‘깊이값이 있어도 틀리면’으로 바꾸고 영향을 받은 세 장을 다시 독립 판독했다.
- **R5 A 생성 오류 — 중단 기록.** `dict(**rec, source=r)`의 중복 키로 실패했다. 구문은 수정했으나 위의 사례 문제로 R5 전체를 전달하지 않았다. R6은 별도 스크립트와 사례를 사용한다.
- **R6 첫 A 미리보기 하단 잘림 — 수정.** 900×400 미리보기에서 마지막 범례가 잘렸다. 범례 두 줄의 위치를 올렸다. 최종 실제 크기 미리보기에서 잘림이 없는 것을 확인했다.
- **남는 한계.** 새 지붕 사진에도 면 전체가 들어오지는 않는다. 통계는 그 시점의 투영 평가 영역이며 건물 전체 결측률이 아니다. 재질·무늬가 원인이라는 검증, 독립 참값 검증, 숨은 벽의 현재 상태, 보존·보정·다듬기·상속의 성공 판정은 하지 않는다. `scientific_verdict: null`을 유지한다.
