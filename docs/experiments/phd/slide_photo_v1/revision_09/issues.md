# R9 표시 점검 기록

- 첫 시안에서 벽의 R7 단면 축을 그대로 표시하면 화면의 위아래 방향이 익숙하지 않았다. 모든 벽 자료에 동일한 강체 회전을 적용해 원자료 수직 방향을 위로 표시했다. 점 위치의 상대 관계는 유지했다.
- 벽의 평면 내부 삼각형 선이 LoD2의 세부 형상처럼 보일 수 있어, 같은 볼록 외곽과 같은 평면을 하나의 반투명 다각형으로 표시했다. 실제 지붕 TIN의 삼각형은 유지했다.
- 벽을 지나치게 옆에서 보면 면이 좁아졌다. 최종 방위각 −42°·고도각 22°에서 면과 점의 앞뒤 차이를 함께 보여 준다. 선택 범위·원자료 값은 고정했다.
- GIF의 각 단계에는 그 단계에서 보이는 자료에 맞는 설명을 넣었다. 참조점·카메라·축척은 모든 단계에서 동일하다.
- 첫 초견 판독의 이미지 해시를 따로 보존하지 못했다. 초기 답은 경과 기록으로만 남기고, 최종 파일은 별도 새 에이전트 판독과 SHA-256으로 연결했다.
- 이 작업에서 실행 실패나 미해결 기술 차단은 없었다. 자료 해석의 한계는 README에 명시했다.
