# PHD-SLIDE-PHOTO-v1 R12 — 5쪽 비교 시안

사전 정보와 영상을 겹쳤던 R11에서 변화가 읽히지 않았다는 사용자 의견에 따라, 두 사례를 각각 크게 보여 주는 시안으로 바꿨다. 지붕은 건물 전체 맥락을 유지한 불투명 3D 표면 두 개, 벽은 같은 사진 위의 거리 색상 두 개다. 기존 R1–R11은 그대로 남겼다. 새 학습·새 방법 결과·GPU 실행은 없다. `scientific_verdict: null`.

## 사용할 파일

- `figures/slide5_roof_surfaces.png`: 3840 × 2160 지붕 시안. 현재 사진, 사전 항공 LiDAR, 영상 MVS를 배치했다.
- `figures/slide5_wall_distances.png`: 3840 × 2160 벽 시안. 같은 벽·같은 측정 칸·같은 거리 색상 범위를 썼다.
- `figures/roof_pair_for_slide.png`, `wall_pair_for_slide.png`: 큰 제목을 뺀 비교 그림. 기존 슬라이드에 넣을 때 사용한다.
- `previews/`: 1920 × 1080 미리보기. 기본 글자는 이 크기에서 26 px 이상이다.
- `qa/round1`, `qa/round2`: 처음 시안과 표시를 보완한 시안, 설명을 가린 점검 그림.

이 전달물은 5쪽 지붕·벽의 두 사례다. 기존 B0 표현 오차 사례와 3·4·6·12쪽 그림을 교체하는 전체 슬라이드 묶음은 아니다. 두 사례를 각각 한 장으로 보여 주는 구성을 권한다. 다시 한쪽 화면에 모두 줄이면 높이 표식과 벽의 거리 칸이 작아진다.

## 자료와 표현

### 지붕

- 위치: 기존 B173 단면 중점을 포함하는 `DEBY_LOD2_4959326`. 기존 건물 평면 범위에 0.5 m만 더했다.
- 사전 정보: 기존 ALS TIN에 기존 등록 이동량을 적용했다. 59,889개 원래 삼각형을 표시한다.
- 영상: 기존 `PHD-MAIN-AXES71-v2/mvs/B173nb_b10/mesh_mvs_a.ply`. 203개 학습 영상의 관측 신뢰도 검사를 통과한 MVS 깊이를 합친 보관된 TSDF 표면이다. 새 GS 결과가 아니다. 6,798,967개 원래 삼각형을 표시한다.
- 두 표면은 같은 좌표계·카메라·축척·중립색·조명을 쓴다. 면을 이동하거나 다시 맞추거나 빈 곳을 메우지 않았다. 기존 메시의 빈 곳, 늘어진 면, 이상점도 남는다.
- 황토색은 두 자료의 **같은 비교 구역**이다. 변화 검출 마스크나 지붕의 물리적 경계가 아니다. 기존 XY 구역에 들어오는 실제 지붕 삼각형만 색칠한다.
- 점선은 기존 단면 중점 한 위치의 드론 LiDAR 참조 높이를 화면에서 표시한 보조선이다. 건물 전체가 그 높이로 평평하다는 뜻이 아니다. 사전 표면 아래 가려진 참조 위치도 설명 표식으로 보인다.
- `+4.56 m`는 기존 REGIONFIG의 보정 구역 패치 중앙값(455.63414286315316 cm)을 옮긴 것이다. 국소 높이 화살표 길이와는 다른 범위의 값이다. 국소 원값은 `roof.json`에 별도로 기록했다.
- 현재 사진은 기존 학습 사진 원본을 90도 돌려 그대로 썼다. 전체 건물 사진을 새로 합성하지 않았다.

### 벽

- 기존 `candidate_0001`, `DEBY_LOD2_4906968`, 금속처럼 보이는 외벽과 기존 최적 사진을 유지했다. 재질이 오류의 원인이라고 단정하지 않는다.
- 원래 선택된 2,990개 패치 중 해당 사진에서 기존 전역 가시성·가림 검사와 유효 깊이 검사를 통과한 패치만 두 그림에 똑같이 표시했다. 정확한 표시 개수와 ID는 `wall.json`, 외부 `wall_support.npz`에 있다.
- 칠한 것은 25 cm 측정 칸이다. 실제 참조점과 기존 접선 방향을 카메라로 투영했다. 칸 사이와 참조가 없는 곳을 채우지 않았다.
- 거리는 기존 참조 층에 대한 벽 법선 방향의 절대 거리다. MVS 색은 **유효한 여러 학습 시점의 절대 거리 중앙값**이며, 배경 사진 한 장의 깊이 오차만 뜻하지 않는다. 두 자료 모두 같은 0–60 cm 범위이며 60 cm 이상은 최댓값 색이다.
- 표시한 동일 패치 집합의 중앙값: 사전 정보 **11.8 cm**, 영상 MVS **34.3 cm**. 전체 후보 집합의 기존 사전 중앙값 11.6 cm와 구분한다. 새 분석 결과를 만든 것이 아니라 표시 부분집합의 기존 값을 요약했다.
- 참조는 현재 드론 LiDAR의 기존 선택 층이다. 같은 실제 면 대응과 독립 참값 여부에 관한 기존 한계를 없애지 않는다.

외부 그림을 연구 자료로 바꾸거나 합성하지 않았다. 배치 원칙만 참고했다.

## 처음 보는 사람 점검

새 에이전트에 이전 대화를 주지 않고 그림 하나만 보였다. 큰 주장 제목과 요약 숫자를 가렸으며, 자료 이름·범례·높이 표식은 유지했다. 질문은 모두 “이 그림이 보여 주는 것을 한 문장으로”였다.

1차 지붕:
> 현재 사진에서 지정한 지붕의 같은 구역을 항공 LiDAR 사전 정보와 영상 기반 MVS 표면에서 표시하고, 같은 시점·축척·표면 표현으로 형상을 비교한 그림입니다.

형상 비교는 읽혔지만 높이 차이가 직접 읽히지 않아 PARTIAL로 기록했다. 자리와 수치를 유지하고, 기존 단면 중점의 현재 참조 높이 점선과 사전 지붕에서 내려오는 높이 화살표를 추가했다.

2차 지붕:
> 같은 지붕 구역에서 사전 항공 LiDAR의 지붕은 현재 드론 LiDAR 참조 높이보다 높게 나타나고, 영상으로 복원한 MVS 지붕은 참조 높이에 가깝게 나타납니다.

의도한 높이 대비가 읽혔다. 다만 이 답은 전체 지붕의 MVS 정확성이나 시간 변화 원인을 입증하지 않는다.

1차 벽:
> 같은 건물 벽면에서 LoD2 사전 정보는 현재 드론 LiDAR 참조에 대체로 가깝지만, MVS 영상 깊이는 더 큰 거리 차이를 보인다.

벽의 대비는 읽혔다. 이후 같은 자료를 유지한 채 사진의 남는 바닥과 측면 여백을 줄였다.

2차 벽:
> 표시된 벽면 구간에서 사전 LoD2는 현재 드론 LiDAR 참조와 대체로 가깝고, 영상 기반 MVS 깊이는 더 큰 거리 차이를 보인다.

답 전문·이미지 해시·에이전트 식별자는 `qa/blind_reviews.json`에 있다. 가독성 점검과 과학적 판정은 별개다.

## 재현과 검증

```bash
bash scripts/phd/slide_photo_v1/run_slide5_surfaces_12.sh
bash scripts/phd/slide_photo_v1/run_slide5_surfaces_12.sh --qa round2
bash scripts/phd/slide_photo_v1/run_slide5_surfaces_12.sh --verify-only
```

Docker, CPU 2개, RAM 4 GiB, 네트워크·GPU 없음. 설정과 원자료 해시를 첫 그림 전에 잠갔다. 표시 변경은 별도 설정과 잠금에 남겼다. 원래 삼각형 전체 재검사, 원본 사진 해시, 동일 카메라와 축척, 래스터 깊이, 벽 칸 위치와 값, 높이 표식, 점검 그림 일치, ZIP CRC와 구성 파일 해시를 확인한다. 결과는 `verification.json`, 전달 ZIP의 경로·해시는 `handover.json`에 있다.

ZIP에는 그림·설정·스크립트·설명·검증 기록·작은 벽 측정 자료가 들어간다. 대용량 원자료와 삼각형 캐시는 외부 아티팩트 저장소에 유지하며 경로와 해시로 연결한다. 제안 방법의 학습이나 재추론은 재현 과정에 포함되지 않는다.
