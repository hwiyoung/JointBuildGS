# 5쪽 건물 맥락과 짝 비교 시안 R10

- 작업: `PHD-SLIDE-PHOTO-v1-R10-SLIDE5-CONTEXT`
- 요청: 지붕과 벽으로 알아볼 수 있는 건물 맥락, 동일 시점 비교, 벽의 위치 차이 확대.
- 산출물: `figures/slide5_context_pairs.png` 3840×2160, `previews/slide5_context_pairs.png` 1920×1080.
- `scientific_verdict: null`

## 최종 표현

사진 → 사전 정보 → 영상 MVS를 두 행에서 같은 순서로 배치한다. 위는 B173의 기존 지붕 사례, 아래는 기존 `candidate_0001` 벽면 사례다. 사진의 노란 A–B는 기존 단면 중심선으로, 표면 마스크나 건물 외곽이 아니다. R9의 A′ 표기를 B로 바꾸었으며 좌표는 동일하다.

지붕 두 칸에는 **동일한 현재 드론 LiDAR 건물**을 회색 바탕으로 놓는다. 그 위에 기존 비교 범위의 사전 점 또는 영상 점을 표시한다. 두 자료 모두 같은 점 크기, 깊이 버퍼, 시점과 축척을 쓴다. 두 칸에서 회색 건물의 입력점은 동일하며, 서로 다른 색 점이 앞을 가릴 수 있다. 회색 바탕은 현재 참조 자료이지 사전 정보나 영상의 결과가 아니다.

사진과 3D의 A–B는 기존 카메라로 투영한 같은 참조 단면을 가리킨다. 주황·파랑 단면선은 기존 0.25 m 구간 대표값을 연결한 안내선이며 건물 모서리나 새로 복원한 면이 아니다. 진한 참조선은 앞 작업에서 만든 참조 단면의 사진 투영 경로를 그대로 사용한다. 사전 칸의 화살표는 단면의 기하학적 중점에 가장 가까운 기존 구간의 사전·참조 높이를 연결한다. 최대 차이를 찾아 고른 위치가 아니며, 이 값으로 전체 지붕을 대표하지 않는다.

벽은 원래 사진 범위를 넓혀 벽·지면·주변 건물을 함께 보인다. 아래 비교는 **위에서 본 점의 위치**다. 사전 면과 참조를 왼쪽에, MVS와 같은 참조를 오른쪽에 놓았다. 각 칸의 가로·세로는 같은 미터 축척이며, 사진을 찍은 쪽이 위다. 오른쪽 화살표도 고정 단면의 중점에 가장 가까운 기존 구간의 참조·MVS 대표 위치를 연결한다. 깊이 방향을 늘리거나 점을 옮기지 않았다.

## 고정된 자료와 범위

`slide5_context_revision_10.json`과 입력 11개를 `input_lock.json`에 고정했다. 비교할 지붕 범위는 R9와 같고, 맥락을 보이는 범위만 XY에 각각 12 m, Z에 10 m를 더해 세 자료에 공통 적용했다. 사진은 기존 R6·R7 원본과 카메라를 사용하며, 기존 자르기를 중심 기준 1.25배 넓혀 원본 영상 안으로 제한했다. 종횡비를 보존하고 빈 공간은 흰색으로 남겼다.

지붕 표시점은 모든 자료에 동일한 0.16 m 복셀을 적용하고 각 복셀의 첫 실제 입력점을 쓴다. 사전 정보는 기존 ALS TIN의 원래 정점에 이미 쓰던 정합 이동량만 적용한다. MVS와 드론 LiDAR도 원래 좌표다. 평균점, 새 메시, 표면 적합, 새 정합은 없다. 최종 표시의 원자료 목록과 행 번호는 외부 `revision_10/geometry.npz`에 보존했다.

| 자료 | 고정 맥락 범위 안 | 복셀 표시점 | 원래 강조 범위의 점 |
|---|---:|---:|---:|
| 사전 ALS 정점 | 17,998 | 16,642 | 4,334 |
| 영상 MVS | 2,023,215 | 196,645 | 42,463 |
| 현재 드론 LiDAR | 1,107,011 | 112,679 | 24,302 |

최종 지붕 그림에는 공통 참조 112,679점과 해당 자료의 강조 범위 점만 공급한다. 위 표의 복셀 표시점 전체는 맥락 범위·시점 계산과 재현용 캐시이며 모든 점이 각 최종 칸에 그려졌다는 뜻은 아니다. 실제 화면에서는 깊이 버퍼로 앞쪽 점이 뒤쪽 점을 가린다. 표시 간소화는 통계 표본이 아니다.

벽은 R7의 6 m × 1.2 m 띠 안 사전 42점, 참조 43점, MVS 670점을 모두 유지했다. 점이 많은 부분이나 큰 차이만 다시 고르지 않았다. 원자료 CRS는 EPSG:25832, 그림은 기존 국소 좌표의 강체 투영이다. 새 중력 추정이나 학습은 없다. 최종 지붕 시점은 방위각 145°·고도각 38°다.

## 표시 수정과 판독

첫 점군 전용 초안에서는 성긴 사전 점 때문에 지붕이 끊겨 보였다. 기존 TIN을 불투명하게 표시한 다음 판에서는 건물 면이 드러났지만, 설명문을 가린 첫 판독이 ‘정돈된 사전 형상 대 영상의 세부·산포’로 읽혔다. 이는 목표인 지붕 높이 차이를 충분히 전달하지 못한 것으로 기록했다. `display_01.json`은 이 중간 표현을, `display_02.json`은 최종 공통 참조 바탕과 동일한 점 표현을 기록한다. 좌표와 비교 범위는 바꾸지 않았다.

판독에는 제목·결론 설명을 지운 그림을 사용했다. 사진, 자료 이름, 참조 범례, 시점 이름과 A–B 표식은 남겼다. `qa/blind_reviews.json`에 별도 에이전트의 답 전문과 해당 이미지 해시를 보존했다. 첫 판독 그림은 `qa/round1_without_explanations.png`, 최종 판독 그림은 `qa/slide5_without_explanations.png`다. 판독의 도달 범위는 이 기록을 따르며 사용자 수용이나 과학적 판정으로 대신하지 않는다.

첫 답: “사진과 현재 드론 LiDAR 참조를 함께 놓고, 같은 위치에서 사전 정보의 단순하고 정돈된 형상과 영상 MVS의 세부 형상·누락·점 산포를 비교한 그림이다.”

둘째 답: “지붕에서는 영상 MVS가 사전 정보에 없는 세부 형태를 포착하고, 벽면에서는 사전 정보가 영상 MVS보다 현재 드론 LiDAR 참조에 가까운 정돈된 형태를 보인다.”

판독 결과는 **PARTIAL**이다. 벽의 참조 근접 관계는 읽혔지만 지붕 높이 변화는 두 번 모두 직접 읽히지 않았다. 사용자도 변화가 잘 보이지 않는다고 평가하고 두 자료를 겹치는 비교를 제안했다. R10은 이 한계를 가진 대안으로 보존하며, 별도 겹침 표현을 이어서 만든다.

## 검증과 한계

`verification.json`은 모든 표시 좌표의 원자료 행 재현, 고정 복셀 선택, 벽 원시점 유지, 단면선·중점 안내값 재현, 원본 사진 SHA-256과 재투영, 동일 시점·축척, 설명문을 가려도 그림 영역이 동일함을 검사한다. 최종 PNG를 직접 열어 배치와 글자를 확인했다. 원본이 보존된 이전 R9 등은 수정하지 않았다.

그림의 참조 일치는 독립적인 참값 검증이나 전체 건물 성능을 뜻하지 않는다. 금속처럼 보이는 벽 외관을 오류의 확정 원인으로 주장하지 않는다. 참조가 없는 부분을 새 면으로 채우지 않으며 성긴 점과 이상점도 규칙대로 남는다. 두 사례의 입력 자료를 설명하는 시안이며 새 방법 결과를 제시하지 않는다. 19동 holdout과 새 학습 결과는 열지 않았다.

## 재현과 전달

```bash
bash scripts/phd/slide_photo_v1/run_slide5_context_10.sh --roof-az 145 --roof-el 38
bash scripts/phd/slide_photo_v1/run_slide5_context_10.sh --verify-only
```

기존 외부 입력과 `jointbuildgs:dev` 이미지가 있는 저장소에서 실행한다. CPU 2개·메모리 4 GiB의 별도 Docker 컨테이너이며, 원자료와 기존 산출물은 읽기 전용이다. Docker 이미지 ID, 실행 기준 커밋, 스크립트 해시, 라이브러리 버전은 이 디렉터리에 기록한다.

외부 payload `slide_photo_v1/PHD-SLIDE-PHOTO-v1/revision_10/`의 `PHD-SLIDE-PHOTO-v1_part_R10_slide5_context.zip`에 최종 그림·보고·QA·설정·스크립트·표시 좌표를 묶었다. `handover.json`에 ZIP 경로·해시·CRC·구성원 해시 확인을 기록했다. 원자료 전체와 Docker 이미지를 포함한 독립 실행 패키지는 아니다.
