# R11 표현과 검증 기록

1. R10 분리 배치는 두 번의 맥락 없는 판독에서 지붕 높이 변화로 읽히지 않았다. 사용자도 같은 한계를 지적하고 겹침을 제안했다. 원본 자료를 그대로 두고 별도 R11 표현을 만들었다.
2. 첫 겹침의 사전 TIN 내부 깊이 경계는 복잡한 세로 선으로 보였다. 원래 TIN의 투영 외곽선만 표시하고 시점을 낮췄다. 데이터 점·삼각형·범위는 그대로다. 표시 변경은 `display_lock.json`에 고정했다.
3. 지붕 표시창을 키우면서 벽 제목과 사진 위쪽이 겹친 것을 직접 확인했다. 벽 사진을 아래로 배치하고 종횡비를 유지해 줄였다.
4. 새 별도 판독은 지붕 높이 차이와 벽 MVS 점의 흩어짐을 읽었다. 실제 변화의 독립 입증이나 사용자 최종 수용으로 확대 해석하지 않는다.
5. 과학적 결론은 `null`이며, 금속 외관을 깊이 오류의 확정 원인이라고 주장하지 않는다. 기술 감사와 판독 판단은 각각 저장한다.
