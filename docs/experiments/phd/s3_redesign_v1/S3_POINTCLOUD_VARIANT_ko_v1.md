## 0. 좌표 — "변수에 점유·평면이 왜 나오는가"에 대한 답

출발 질문(사용자, 2026-08-27): *"포인트클라우드를 최적화하는 거면 prior가
LiDAR면 그거 직접 쓰면 되고, LoD1/2면 그 외곽에서 포인트 샘플링해서 진행하면
되는 거 아니야? 변수에 점유와 평면이 왜 나오는 거지?"*

답: "S3의 판(version)"은 독립된 두 축으로 갈라진다 — **무엇을 상태로 두는가
(표현)** 와 **무엇으로 심판하는가(관측)**.

| | 심판 = 현재 영상 (렌더-대조) | 심판 = 현재 점군 (점-면 잔차·광선) |
|---|---|---|
| **표현 = 평면 배열(셀)** | 배열판 = **정본 r18** (변수 o·P·δ·A) | 배열×점군판 (2026-08-27 대화의 v0 초안 — 미문서화) |
| **표현 = prior 점군** | **점군판 = 본 문서** (변수 e·δ·A) | 점군×점군판 (§7 각주 — 강건 ICP + 점 카빙) |

점유 o와 평면 P는 변수이기 이전에 **배열 표현의 상태**다: 배열판의 모델은
"켜진 셀들의 경계" M(o, P)라서 상태가 (o, P)일 수밖에 없었다. 표현을 prior
점군으로 바꾸면 상태는 점들 자신이 되고,

- **o의 역할(존재의 재판)은 점별 존재 e가 승계**한다.
- **P의 역할(구조 어휘 — 수밀 경계·증축 표현·면 단위 인증)은 승계자가 없다.**
  이 비대칭이 §5(사다리)와 §6(정직한 대비)의 주제다.

## 1. 개요 — 방법론 3문장

1. prior를 점군으로 **실체화**하고 — Existing ALS는 점 그대로, LoD1/2는 외곽
   표면에서 균일 샘플링 — 각 점을 면형 가우시안 담체로 삼아, **현재 영상
   렌더-대조로 직접 최적화**한다(S1 평면 추출·S2 배열 절단이 없다).
2. 변수는 점(패치)에 붙는다: **존재 e**(이산 — prior 진술 "여기 표면이
   있었다"의 재판), **정합 δ**(자산 공유 1개), **색 A**(결측 → 관측이 생성) —
   평면·셀·배열은 존재하지 않는다.
3. 산출은 판정(채택/기각/유보)·보정(δ̂)·채색된 **생존 점군 = 현재화된
   prior**이고, 구조(수밀 LoD2)는 S4 Roofer가 그 점군에서 사후 추출한다 —
   판정은 최적화가, 구조화는 판독기가 맡는 분업.

- **Existing ALS → 점 그대로**: footprint 크롭(+고정 버퍼), 균일 서브샘플

- **LoD1/2 → 외곽 균일 샘플**: 지붕·벽 면 위 간격 s, 법선 = 면 법선,
  **원천 면 ID를 점에 보존**한다 — LoD판에서는 인증 3분류를 원천 면 단위로
  되돌려 보고할 수 있다(점판의 예외적 이점).
- **패치 Π = 판정·인증·w의 담체**: LoD판 = 원천 면, ALS판 = 법선-연결
  클러스터(간격 s 기준). ALS판 패치의 안정성은 미결 P3.

**담체 계약의 승계 (정본 §0.5·§2.1과 동일).** 가우시안 인자 = 위치 q⁰_i + δ
(+ h_i·n_i), 방향 = 법선 프레임, 크기 = (s, s, ε) 상수, 불투명도 = e_i ∈
{0,1}, 색 = A_i. **가우시안 소유 자유 변수는 색뿐 · 자유 알파 금지 ·

## 4. 목적함수와 제약

전체 형태(변수 3개):

```
L(e, δ, A) = 관측 잔차(§4.1) + 존재 앵커(§4.2) + 이웃 일관(§4.3) + 게이지(§4.4)
```

### 4.1 관측 잔차 — 정본 §2.1을 그대로 승계한다

**Î_j, D̂_j, Ŝ_j = R_j( G(e, δ), A )** — "현재 믿음(어느 점이 실재하고 e,
자산이 얼마나 밀려 있고 δ, 표면이 무슨 색인지 A)을 카메라 j에 넣으면 그
믿음이 참일 때 찍혔어야 할 사진 세 장이 나온다." 광도·깊이·실루엣 3채널,
채널 패턴표(변화/δ/외관/무증거 → 귀속), 지대별 가중 — 전부 배열판과 동일.

- **r18 경고의 상속**: 표현 교체는 심판을 바꾸지 않으므로, **광도 단독 δ
  비식별 [실측 r18]은 점군판에도 그대로 성립**한다. "점군판이면 δ가
  저절로 풀린다"는 기대는 성립하지 않는다 — 깊이 채널 도입(3c-2)은 판과
  무관하게 필요하다. 채널 구성은 정본 미결 8과 공유(미결 P7).
- **벽·지면 결손** [논리]: 항공 ALS는 벽 점이 희소해 실체화 모델이 "뜬
  지붕"이 된다 — 경사 뷰의 실루엣·깊이 잔차가 오염될 위험. 보완 후보 =
  footprint에서 벽·지면 합성점(안정 지위 — 재판·인증 비대상), 배열판의
  footprint 벽·지면 평면의 점판 대응물이다(미결 P5).

### 4.2 존재 앵커 — C_k의 점판

**Σ_i w_Π(i)·C_i(e_i)**, **C_i(e_i) = −[ e_i·log t_i + (1−e_i)·log(1−t_i) ]**

말로 읽기: "prior가 이 자리에 표면이 있다고 진술했다(확신도 t). 그 진술과
다른 상태를 두려면 w·|log(t/(1−t))| 만큼의 증거를 내라" — 정본 §2.2의
뒤집기 값 산식 그대로다.

- **t_i = 실체화 확신도의 차등**: ALS 실측점은 높게(예 0.9), LoD 샘플점은
  모델 유래(일반화·단순화·구버전 가능)라 낮게(예 0.7). "진술의 강도는 t가,
  증인의 신빙은 w가, 불확실은 유보가 맡는다"의 역할 분리 유지. 수치는 보정
  대상 [예정, 미결 P1].
- **w = 패치 단위 3값 갱신**(채택 = 유지 / 기각 = 0 / 유보 = 유지 + 표시),
  갱신 주체는 관측 채널 서명 — 정본 §2.2 반대신문 절차 승계.

### 4.3 이웃 일관 — 표면장력의 점판

**λ_n · Σ_{(i,j)∈N_s} ω_ij · |e_i − e_j|** (N_s = 간격 s 기준 kNN 그래프,
ω_ij = 거리 가중)

말로 읽기: "이웃과 존재 상태가 다르면 값을 치른다." 배열판 L_area는 표현이
면이라 겉넓이에 세금을 매길 수 있었다. 점판에는 면이 없으므로 이웃 불일치에
가격을 매긴다(Potts) — 고아점 하나 끄기는 싸고, 표면 한가운데 구멍은
둘레만큼 비싸다는 직관은 동일하다.

- 판정 부등식도 동형이다: **ΔE_obs(Π) > λ_n·ΔPotts(Π) + ΔW(Π)** —
  "진술을 뒤집으려면 증거가 매끄러움 가격에 더해 증언의 무게까지 이겨야
  한다."

### 4.4 게이지

**Γ(δ)** — 정본 §2.4 그대로: 비관측 성분(평지붕 평면-내·fine)은 추정에서
제외하고 0에 구속.

### 4.5 솔버 — 교대 구조 승계

연속(δ·A[, h]) 경사하강 ↔ 이산(e) 패치 두-세계 렌더 시행(현 세계는 공짜·
국소 평가·ICM 순차) 교대. 렌더 항 비분해가 국소 시행을 강제하는 사정,
A 웜업 필요성(회색 렌더는 평탄해 ∂r/∂δ 초기 ≈ 0)도 배열판과 동일.

- 구현 거리 [논리]: arrgs_v1의 시드·렌더 기계 + s3_verify_v1의 크롭·포즈
  번들이 그대로 출발 자산이고, S1(평면 추출)·S2(배열 절단)가 통째로
  불요라 세 판 중 구현 거리가 가장 짧다.

### 4.6 증축의 부재 — 이 판의 어휘 경계

점판의 어휘 = prior가 실체화한 점뿐이다. 철거·낡음·정합(= "찼음" 진술의
재판)은 표현 가능하지만, **증축(= "비어 있음" 진술의 기각)은 켤 담체가
없다.** 배열판은 이것을 빈 셀 켜기(채움 기하는 MVS·gapfill 가설이 공급)로
표현했다. 점판의 확장안 = 현재 MVS 점을 후보점(초기 e = 0)으로 추가 — 단
그 순간 "prior 점군 직접 최적화"의 단순성이 깨지고 표현이 혼합된다.
**기본안: 점군판의 범위를 철거·정합·낡음으로 한정하고 증축은 범위 밖으로
명시**(§5 사다리에서 배열판과의 차이 축, 미결 P4).

## 5. 세 판의 사다리 — 논쟁의 절제 설계

지도교수 제안 "(a) prior-as-loss 회귀"까지 한 축에 놓으면:

| | (a) prior-as-loss (회귀) | **점군판 (본 문서)** | 배열판 (정본 r18) |
|---|---|---|---|
| 표현 | 자유 GS (현행 E4/E5 문법) | prior 점 고정 담체 | 평면 배열 셀 |
| prior 사용 | 연속 가중 손실 | 이산 존재 재판 (e·w·유보) | 이산 점유 재판 + 구조 어휘 |
| 변화 표현 | 가중 감쇠 (판정 없음) | 철거만 (끄기) | 철거 + 증축 (끄기·켜기) |
| 산출 구조 | 비정형 GS → S4 재추출 | 판정·보정·채색 생존 점군 → Roofer | 수밀 경계 M(o,P) 무문턱 읽기 |
| 인증 3분류 | 없음 | 패치 단위 (LoD판 = 원천 면) | 면 단위 |

- **점군판 vs (a)**: 표현이 유사한 두 판의 차이 = 판정의 유무 → **판정의
  가치가 고립**된다. 색-위장 [실측 r17]·δ 비식별 [실측 r18]이 예측하는 것:
  (a)는 변화 지대의 잔차를 외관 재적합으로 흡수한다 — 점군판이 같은
  지대에서 기각을 내면 그 실측이 논쟁의 결정 증거가 된다 [예정].
- **배열판 vs 점군판**: 판정이 같은 두 판의 차이 = 어휘 → **배열의
  가치(수밀·증축·면 인증)가 고립**된다.
- 즉 이 사다리는 면담 논쟁("판정이 필요한가", "배열이 필요한가")을 통제
  절제 실험으로 바꾼다 [논리].

## 6. 정직한 대비 — 점군판이 얻는 것 / 잃는 것

**얻는 것.**

- S1·S2 불요 — 평면 추출 원천 사망 문제(B036 prior 평면 0 [실측])가
  원리적으로 없음. 구현 거리 최단(§4.5).
- prior 형식 무차별: ALS / LoD1 / LoD2 → 전부 점 — E4·E5·E6의 통일 담체.
- LoD판은 원천 면 ID 보존으로 면 단위 인증 보고 가능(§3).

**잃는 것.**

- 수밀성·평면성·의미론이 최적화 안에 없다 → S4 Roofer 재추출에 위임 —
  판정이 옳아도 Roofer가 실패하면 산출물이 없다(Roofer 민감성은 B036
  계보로 실측된 위험).
- 증축 어휘 없음(§4.6) — 변화의 절반이 범위 밖.
- 낡음의 기하 표현은 h 해동 없이는 불가 — 해동하면 자유도 폭발·prior 형태
  파괴 위험(미결 P2).
- ALS판 인증 담체(클러스터 패치)는 면만큼 안정적이지 않을 수 있다(미결 P3).

## 7. 각주와 미결

- **점군×점군판**(§0 표의 넷째 칸): 심판까지 현재 점군(공통기반 MVS 융합점
  또는 E1)으로 바꾸면 렌더가 사라지고 강건 ICP(δ) + 광선 카빙(e)이 된다 —
  가장 값싼 계기이나, 채움 지대(현재 점 부재 = 연구의 표적 지대)가
  무증거가 되고 MVS로 MVS를 심판하는 자기참조 논점이 생긴다. 필요 시 별도
  1쪽 설계로 분리.
- **첫 시험 재사용**: 3c 주입 2런(B022_DZ050·B173_DZ050 [실측 자산])을
  그대로 써서 점군판 δ 복원을 시험할 수 있다. 예측: 광도 단독이면
  배열판과 같은 비식별(§4.1 상속) — 채널 절제와 접합해 한 실험으로 처리.
- **미결(점판 국소 번호 P1~P7 — 정본 미결과 별도 원장)**:
  P1 t 차등 수치(ALS/LoD) · P2 h 해동 여부 · P3 ALS 패치 정의 안정성 ·
  P4 증축 확장(MVS 후보점) · P5 벽·지면 합성점 · P6 서브샘플 간격 s ·
  P7 채널 구성(정본 미결 8 공유).
