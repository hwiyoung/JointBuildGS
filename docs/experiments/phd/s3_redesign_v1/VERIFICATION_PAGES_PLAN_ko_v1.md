# 검증 페이지 계획 — 단계 실행 → 화면 판독 → 다음 단계 (v1)

> 지위: PLANNING RECORD — 실행 권한 없음. `scientific_verdict: null`.
> 리뷰어: 김휘영. 작성 2026-08-26. 방법론 정본 = 같은 폴더
> `S3_REDESIGN_METHODOLOGY_ko_v1.md` (r11) — 용어·수식·절차는 그 문서가
> 단일 진실이며, 이 문서는 그 실행을 눈으로 확인하는 화면의 계약이다.

## 0. 원칙

- **진행 규칙: 단계 실행 → 페이지 판독 → 통과 → 다음 단계 착수.** 화면에서
  납득되지 않으면 다음 단계 코드를 만들지 않는다.
- **페이지 단위 = 파이프라인 단계**(검증 항목 아님). 총 4페이지. 검증 항목은
  각 페이지의 판독 체크리스트로 흡수한다. 통짜 앱 금지 — 페이지는 각각
  독립 정적 HTML이고 공유 런 번들에서 자기 몫만 로드한다.
- 합격 기준은 페이지 상단에 **사전 명기**(화면을 본 뒤 정하지 않는다).
- 미결 ⑦(공정성 방식)·⑩(A 초기화)·⑫(앵커 참여) 등 비교 결정은 페이지를
  늘리지 않고 **같은 페이지의 런 비교 모드**(두 런 나란히)로 처리한다.
- 반복 용어: **스텝**(연속 블록 내부 경사하강) / **라운드**(이산 블록 내부
  후보 순회) / **사이클**(연속→이산 교대 한 바퀴).
- 판독 기록: 페이지마다 합격/불합격/보류 + 메모(리뷰어 김휘영). Technical
  Return·receipt은 `scientific_verdict: null` 유지.
- 판독 순서 규율(체리픽 방지): ① 전수 집계 → ② 무작위 표본 → ③ 지목 사례.
  보고 컷은 무작위 표본에서만 뽑는다.

## 1. 페이지 4종

  평면(들) / **고아 점**(어느 후보에도 안 붙는 점) 토글 / 카드: 출처·inlier
  수·RMS·중력각·GT 매칭.

  §1.1 "발명하지 않는다"의 전제) · 대형 오적합(B036형 49° 회전) 육안 0 ·
  고아 점 비율 사전 등록치 이하 · 출처 표기 정확.

### 페이지 2 — 배열·초기값 (S2)

- 화면: 셀 배열 3D + 초기 실재 면 F* 오버레이(잠든 면 반투명).
- 상호작용: **셀 클릭 → 다면체 + 인접 면 전부 + 그 면의 시드(샘플링 점) +
  초기값 카드**(표면고 기둥·기둥 안 ALS 점·p90 선·판정 0.75/0.15/0.2·앵커
  목표 t_k·뒤집기 값 w·|log(t/(1−t))|) / 면 클릭 → 양쪽 셀·소속 평면(페이지
  1로 점프) / 스위치 수동 젖히기 → 신규 면(비용)·소멸 면(환급) 하이라이트 +
  ΔA 수치(XOR 회계, §2.3).
- 판독 체크리스트: 참조 무결성 오류 0(자동 검사) · Σ셀 부피 = 프리즘 부피 ·
  분류-붕괴 건물에서 표면고 판정 정상(면역 확인) · 초기 경계가 prior 형상
  으로 읽힘 · 시드가 게이트 0 면에도 존재(수명 규칙 ②).

### 페이지 3 — 공동 최적화 (S3)

- 화면 축 = **사이클 타임라인 하나**: 연속 구간과 이산 라운드가 번갈아 표시.
  블록별 페이지 분리 금지 — 검증 대상이 블록 사이 인터페이스이기 때문
  (방법론 §4.3). 연속만 구현된 런은 연속 구간만 표시(페이지가 구현과 함께
  자란다).
- 연속 구간 클릭 → 항별 손실 곡선(광도·깊이·실루엣·앵커·면적·총 L) + 그
  스텝의 사진/렌더/잔차 3채널 타일 + 3D 상태 동기화 / δ̂ 궤적 + 주입 정답선
  + 게이지 성분 구분 / 잔차 브러시 → 광선 역투영 → 셀(후보 원천 ③의 직접
  검사) / 웜업 구간의 색 분화.
- 이산 라운드 클릭 → **판정 기록 표**(패치·원천 ①②③·ΔE 채널 벡터·λ_a·ΔA·
  ΔW·판정·귀속) → 행 클릭 → 패치로 카메라 비행 + **두 세계 국소 렌더
  나란히** + 부등식 막대(ΔE vs λ_a·ΔA+ΔW) + 유보 밴드(잡음 범위) + (주입
  런) GT 대조 배지. 유지 판정도 표에는 전수 기록된다(그림과 달리 생략 없음).
- 런 비교 모드: 같은 patch_id/스텝을 두 런 나란히 — 미결 ⑦·⑩·⑫의 결정
  증거 화면.
- 판독 체크리스트: L 단조 감소·고정점 도달 · 굵은 δ 복원(주입 대비) ·
  판정문-화면 증거 일치(무작위 20건) · 유보가 무증거 자리(가림·무텍스처)
  에서 발동 · 채널 서명이 §2.1 패턴표와 일치 · 보정 전후 재검정이 억울한
  기각을 정정(순환 의존 해소).

  재현**) + δ̂ 판독 + 건물 단위 인증 3분류 집계.

## 2. 데이터 규약 — 클릭 가능성은 UI 기능이 아니라 산출물 규약이다

- 모든 산출물에 안정 ID: plane / cell / face / seed / patch / step / round /
  cycle. 역참조 필수 — 평면→inlier 인덱스, 셀→인접 면·표면고 근거, 면→
  셀쌍·평면·시드 구간, 패치→구성 셀·판정 레코드.
- 런 번들(아티팩트 루트, Git 밖): manifest(설정·절제 축·주입 GT 포인터) +
  s1_planes(inlier 인덱스) + s1_points + s2_cells(표면고 근거·t_k) +
  s2_faces + s2_seeds + 연속 기록 jsonl(스텝별 항별 손실·δ̂) + 판정 기록
  jsonl(패치 검정 전수) + 스냅샷/타일 + gt_injection.
- 참조 무결성 자동 테스트(`tests/`) — 실패 = 런 불합격(면의 셀·평면 참조
  존재, 시드의 면 존재, 패치의 셀 포함, 스텝 인덱스 단조).
- 런타임 기록은 저비용 JSONL만. 무거운 3D/이미지 타일은 체크포인트에서
  결정론적으로 사후 재생성한다(GPU 루프 보호·재빌드 가능).
