# SRDM 구현 충실도와 P1 입력 적격성 재검토

2026-09-08 · `PHD-SRDM-IMPLEMENTATION-REVIEW-v3` · `scientific_verdict: null`

**현재 구현을 원문에 충실하게 검증된 SRDM이라고 확인할 수 없다. 특히 P1에는 대상 안뜰의 사용성을 판단할 근거가 확보되지 않은 영상쌍을 선택한 문제가 있다.** 앞선 답변에서 P1 결과를 SRDM 판단 능력의 실패로 확정한 해석을 철회한다. 기존 실행과 v2의 수치는 보존하되, 원방법의 적합성 판단 근거로 승격하지 않는다.

## 사용자 첨부 Figure 1과 실제 구현

[원문](https://cpb-us-w2.wpmucdn.com/u.osu.edu/dist/4/28638/files/2018/07/LiDAR_and_Image_paper-V3_close_to_final-28lqxo6.pdf) §3은 입력을 정밀하게 정합한 다음 전처리와 두 단계 최적화를 수행한다. 첫 최적화는 약한 ALS 제약의 영상 정합과 불일치 ALS 제거이며, 둘째 최적화는 남은 ALS를 강하게 사용한 조밀한 시차 추정이다. 앞선 보고서에서 '약한 정합 / 판단 / 후속 복원'으로 나눈 것은 설명 단위이며, 원문의 정합 횟수가 세 번이라는 뜻은 아니다.

| 원문 요구·절차 | 실제 코드에서 확인된 상태 |
|---|---|
| 사전 정밀 정합: 영상–LiDAR의 subpixel 수준 정합, 그 뒤 epipolar 정류 | 기존 카메라·ALS 좌표를 유지하고 정류했다. 별도 재정합과 실제 영상에 대한 subpixel 적격성 검증은 수행하지 않았다. 기존 정합이 충분하면 재조정 자체가 반드시 필요한 것은 아니지만, 충분하다는 확인이 없다. |
| 전처리: ALS를 epipolar 영상 격자에 투영, 가까운 점 우선, histogram 기반 gross outlier 제거 | 정류·투영·z-buffer는 구현했다. 원문의 histogram blunder filter는 빠졌다. 이 누락이 P1 실패의 원인으로 확인된 것은 아니다. |
| 첫 단계: 약한 ALS 제약의 영상 정합, 시차 불일치 제거 | 핵심 수식 형태는 반영했다. 실제 실행은 원해상도 판단이며 원문의 축소 피라미드 사용을 재현하지 않았다. 1배가 수학적으로 금지된다는 의미는 아니며 영향이 검증되지 않았다. |
| 둘째 단계: 유지 ALS의 강한 제약과 주변 탐색 범위로 고해상도 시차 계산 | 구현했다. 좌우 정합에서 판단 불가인 ALS까지 제외하는 정책은 재구현 선택이다. 원문 결과와의 충실도 검증이 없다. |

## 수식과 테스트 검토

`core.py` 및 `inm_backend.cpp`를 식6,11,13–19,21–22와 대조했다. Census/HOG 절단·정규화 결합, 시차 동일/±1 전파, 밝기 가중, 직교 양방향의 중복 제거·2P, 약한 제약, 불일치 판단, 강한 제약의 주요 형태에서 확정할 만한 부호나 항 누락 버그는 찾지 못했다. **이는 핵심 수식의 읽기 검토이며 논문 재현 인증이 아니다.**

재구현 선택으로 `weak_sigma=2`, 주변 반경15, 밝기 허용10, gamma2, 좌우 허용1, HOG count histogram 해석이 존재한다. 이 선택이 실제 실패 원인이라고 특정하지 않는다. HOG의 세부 충실도 등 미확인 사항은 기존 `IMPLEMENTATION_AUDIT_ko_v1.md`에 남아 있다.

전체 파이프라인을 통과하는 대표 테스트는 30×48 난수 RGB를 4px 이동시킨 영상에 올바른 시차4 prior 하나와 잘못된 시차8 prior 하나를 둔 경우다(`tests/phd/test_srdm_core.py:108`). 나머지는 소배열 수식·좌표·자원 방식 동치·평가 연결 등의 검사다. 실제 항공영상의 시간차 구조, 넓은 가림, 저텍스처·불연속에서 원문과 같은 성질을 보이는지, Toronto/Middlebury의 원문 결과에 대응하는지 확인하지 않았다. **33개 검사 통과를 원문 재현 검증 통과로 설명하면 안 된다.**

## P1: 확인된 입력 선택 문제

`src/phd/srdm_p1p2p3_v1/geometry.py:90–144`는 카메라·3D crop의 투영만으로 쌍을 고른다. 현재 영상 내용, MVS 표면, 가림을 읽지 않는다. 점수는 체적 격자의 프레임 포함 비율·교차각·투영 면적의 곱이다. 따라서 `common_lattice_fraction=0.992`는 안뜰이 99.2% 보인다는 뜻이 아니다.

P1에서 선택한 COLMAP ID는 **853/857**이다. 대상 중심을 보는 광선은 scene-local Z 기준 약66.53°/66.36°의 사선이다. 기존 입력 그림에는 전경 금속 지붕과 벽이 크게 나타나며, 안뜰의 과거 ALS 위치가 그 전경 건물 위에 투영된다.

기존 독립 관측 진단 은행에서 **동일 ID·동일 영상명·동일 SHA의 쌍**을 찾았다.

- 기존 은행: `phase-payloads/phd/warp_ncc_v1/PHD-WARP-NCC-v1/`.
- `warp_ncc_views.json`의 `pairs[1731]`: `a=853`, `b=857`, 기존 후보 중심 기준 교차각 약7.285°. SRDM crop 중심의 교차각7.551°와 기준점이 다르다.
- `ncc_pair_values_f16.npy`: float16, shape `(1807, 3600, 6)`, 후보 순서 `[M,P,M+z0.5,M+z1,M+z2,M+x1]`.
- `warp_ncc_cells.npy`의 관심 mask: `(state == 2) & (rough == 0)`, **1,229셀**.
- `isfinite(rho[1731, target_mask]).sum(axis=0)` = **`[0,0,0,0,0,0]`**. 전체3,600셀에서도 유효한 NCC 비교는 없다.
- 해당 두 영상의 기존 M 후보 단독 가시성·샘플 유효 셀은27/20개다. 기존 다른 준수직 뷰90/91은3,376/3,386개였다. 비교용 기존 기록이며 이 뷰로 SRDM을 새 실행한 것은 아니다.

영상 SHA는 SRDM metadata·기존 은행·실제 봉인 영상 바이트가 모두 일치했다.

| 영상 ID | SHA-256 |
|---|---|
| 853 | `d36d4e770e4952ca5a97b67f4b9886ffbeaf9cd49f2e9794a7cf7f1454612dc3` |
| 857 | `4e5aa6b29a3afd29e0fd7b624fd90961df6684b229f9ec40842cf14ecddce6e2` |

**0/1,229는 기존 가시성·NCC 유효성 기준에서 비교 근거가 없다는 뜻**이며, GT로 모든 픽셀의 물리적 가림이 증명됐다는 뜻은 아니다. 이를 SRDM의 새 판단 feature로 사용하지도 않았다. 그러나 안뜰 사용성을 시험할 입력쌍이라는 사전 확인이 누락됐다는 강한 근거이며, 실제 입력 영상과도 일치한다.

추가로 시차 범위160–300px를 P1 crop 모서리만으로 만들었다. ROI 영상 투영 범위에 들어오는 context ALS 58,725점 중7,055점은 더 가까운 범위(d>300, 최대425.11)에 있으며 모두 crop 밖이다. 전경 물체의 실제 대응이 탐색 범위에서 빠질 위험이 있다. 이것은 context 점 샘플 기준이며, 실제 보이는 영상 픽셀 수나 실패 원인의 기여율로 해석하지 않는다.

## 해석 정정과 남는 일

P1에서 현재 안뜰을 따라가는 기존 MVS가 존재한다는 사실과, 이번 사선 두 영상에서 SRDM이 그 면을 추정하지 못했다는 사실은 모순되지 않는다. 입력 영상과 관측 가능한 표면이 다르기 때문이다. **현재 P1 시험은 SRDM의 과거 ALS–현재 영상 판단 능력을 가르는 유효한 시험으로 확인되지 않았다.**

원문 §4.1은 시간차로 달라진 건물, 가림, ALS 이상점 제거를 직접 시험한다. 따라서 P1의 시간차 구조 문제가 원래 SRDM의 범위 밖이라서 실패했다는 설명도 맞지 않는다. 또한 SRDM은 어려운 영상 정합을 ALS로 보완하려는 방법이므로 P3도 '금속이니 실패가 당연하다'로 종결할 수 없다.

판단기에 대한 긍정·부정 결론보다 먼저 (1) 실제 대상이 관측되는 입력쌍과 정류·정합 적격성, (2) 원문 전처리·두 단계의 구현 충실도, (3) 정답 시차가 알려진 독립 영상에서 정상 prior 보존과 잘못된 prior 제거를 확인해야 한다. 정상 정합 확인과 시간차 판단 검증을 구분한다. 이는 다음 검증 범위의 정리이며, 이번 검토에서 새 학습·스테레오 정합·입력 변경·원 결과 덮어쓰기를 수행하지 않았다.

기존 수치·산출물은 그대로 보존한다. 본 검토는 읽기 중심의 코드·원문 대조와 기존 배열의 작은 집계만 수행했다. 배열 검사는 기존 Docker 이미지에서 CPU2·읽기 전용 mount로 실행했고, 다른 세션의 GeoGS 실행을 변경하지 않았다. `scientific_verdict: null`을 유지한다.
