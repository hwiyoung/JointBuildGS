## 점과 패치

`points/<타일>__<사전 정보>.npz`가 전체 단계의 정하는 곳 점 값이다. `patches/`의 같은 이름 파일에는 `patch_id`, `point_id`, `judgment`가 있다. 확인용 값은 별도 `holdout/points/`, `holdout/patches/`에만 있으며 전달 ZIP에 없다. 시범 벽 관찰은 `work/pilot/`에만 있고 전체 점·패치 파일에는 없다.

NPZ는 `numpy.load(path, allow_pickle=False)`로 연다. `patch_id`로 넓히기 v2의 같은 타일·사전 정보 파일과 연결하고, `point_id`로 이 작업의 점 값과 연결한다. 배열 행 순서가 같다고 가정하지 않는다.

| 항목 | 뜻 |
| --- | --- |
| `point_id`, `tile`, `prior`, `building`, `holdout` | 점 번호, 타일, 사전 정보, 대표 건물, 확인용 여부 |
| `building_ids` | 항공 LiDAR 점에 패치를 제공한 모든 건물. 대표 건물은 넓이가 가장 큰 건물이다. LoD2는 면별 건물이 하나다 |
| `centre`, `normal`, `tangent1`, `tangent2` | 중심 좌표와 단위 방향. EPSG:25832 좌표에서 [690953, 5336071, 604]m를 뺀 좌표 |
| `sigma`, `sigma_mvs`, `raw_u_mvs`, `mvs_p` | 새 사전 정보·MVS 불확실도, 원본 MVS 불확실도, MVS 높이. 단위 m |
| `heights`, `curve` | 같은 열끼리 대응하는 높이와 사진 점수. 148열이며 기본 141개 뒤에 조건에 따라 7개를 추가한다. 빈 값은 NaN |
| `s0`, `s_in`, `h_in`, `s_out`, `h_out`, `s_mvs`, `s_max`, `h_max`, `s_med`, `difference` | 발주문 5.1의 값. `difference=s_in-s_out` |
| `peak_mask` | 저장 높이 목록에서 봉우리로 센 열 |
| `eligible_images`, `selected_images`, `selected_count` | 조건을 채운 사진 수, 고른 사진 번호, 고른 수. 빈 사진 번호는 -1 |
| `max_direction_angle_deg`, `parallax`, `texture` | 가장 큰 촬영 방향 차(도), 시차(m/m), 밝기 표준편차의 중앙값(0~255 밝기) |

| `valid_images_per_height`, `zero_variance_images_per_height` | 높이마다 유효 사진 수와 밝기 분산이 0인 사진 수 |
| `judgment` | 15열 int8. 0 지지, 1 반박, 2 모름(애매), 3 모름(무늬 없음), 4 모름(사진 부족) |

사진 번호는 넓히기 v2 `image_split.json`의 `train` 이름을 오름차순으로 정렬한 819장 목록의 0부터 시작하는 번호다. 각 곡선 그림 JSON에는 해당 사진 이름도 있다.

15개 열은 δ=[0.05, 0.10, 0.15, 0.20, 0.30] 순서로, 각 δ 안에서 최소 점수=[0, 0.3, 0.5] 순서다. 보기 값은 0부터 시작하는 4번 열이다. 후보 선택이나 유효 확률 추정은 하지 않았다.

곡선은 float16, 곡선에서 뽑은 값은 float32다. 뽑은 값과 판단은 저장 전 float32 곡선으로 구했다. float16 곡선에서 다시 구하면 양자화 때문에 문턱 바로 옆의 값이 달라질 수 있다. 현재 판단을 재현할 때는 저장된 `s_in`, `s_out`, `texture`, `selected_count`를 쓴다. MVS에 가장 가까운 표본 높이의 점수가 없으면 `s_mvs`도 NaN이다.

## 표의 분모

`summary_15`의 `all_roof`와 `unexplained_all_roof`는 참값 누락을 포함한 판단 넓이다. `gt_known`과 `unexplained_gt_known`은 참값 점검 대상이다. 판단별 맞음 비율의 분모는 그 판단 안에서 참값과 새 σ가 있는 넓이다. 표마다 패치 수·넓이·누락 넓이·출처를 남겼다.

구간 끝이 겹치지 않도록 u_prior는 [0,1), [1,3], (3,∞)cm, 시차는 [0,0.2), [0.2,0.5], (0.5,1], (1,∞), 무늬는 [0,5), [5,10], (10,20], (20,∞)로 센다. MVS 불확실도 구간은 [0,3], (3,5], (5,10], (10,20], (20,40], (40,∞)cm다. 이 표의 u 값은 바닥값을 더하기 전 원본 값이다.

## 전달 파일

Light는 보고서·표·그림·설정·재현 코드와 SHA256SUMS를 담는다. 전체 묶음에는 정하는 곳의 점·패치 NPZ도 들어간다. 원본 사진과 큰 사전 정보 메시는 두 묶음 모두에 없다. 재실행에는 위 원본 입력 저장소가 필요하다.

파일이 여러 part ZIP으로 나뉘면 각 ZIP은 독립적으로 열린다. 모두 같은 폴더에 풀며, ZIP 파일을 이어 붙이지 않는다. 바깥 `SHA256SUMS`는 ZIP 바이트를, 각 ZIP 안의 `SHA256SUMS`는 담긴 파일 바이트를 확인한다. 확인용은 파일 수치·넓이와 파일 해시만 공개한다.
