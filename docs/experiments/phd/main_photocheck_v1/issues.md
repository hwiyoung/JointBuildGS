# 확인 불가와 예외

- CPU와 GPU 시간 측정이 같은 사진 캐시를 동시에 만들 때, GPU가 아직 완성되지 않은 파일을 읽어 첫 측정이 중단됐다. 캐시는 임시 파일을 완성한 뒤 한 번에 이름을 바꾸도록 고쳤다. 중단된 측정은 시간 어림과 판단에 쓰지 않는다. 설정과 입력 자료에는 변화가 없다.

- 원본 지붕 패치 가운데 1,698개는 법선이 정의되지 않았다. 원본을 보존하고 점의 기하 정보가 없다고 기록한다. 사진을 고르거나 참값으로 법선을 채우지 않는다. [이 발주에서 냄]
- 가려짐은 넓히기 v2의 타일별 등록 이동을 적용한 같은 메시로 구한다. 메시의 주변 범위는 앞 작업의 10m이며 그 밖에 표현되지 않은 사전 정보는 가려짐 계산에 없다.
- 높이별 가려짐은 다시 구하지 않는다. 사진 집합은 사전 정보 높이에서 한 번 고정한다.
- 사전 정보 불확실도가 없으면 범위 안·밖 비교는 확인 불가이며 모름(애매)으로 남긴다. 곡선과 원래 누락 상태를 보존한다.
- 한 사진 조각의 밝기 분산이 0이면 그 조각과의 상관은 정의되지 않는다. 해당 높이의 점수를 비우고 사진별 무늬의 세기와 0분산 사진 수를 남긴다.
