## 7. 점검

- 원통 점 수 = `none_cyl_points`: 무작위 1,000개 모두 같음(LoD2·항공 LiDAR), 범위 안 모든 패치도 같음(LoD2 876,555 / 항공 LiDAR 252,368; 법선 없는 12개 뺌).
- 정방향 넓이 합 = 사전 정보 패치 넓이 합(LoD2 54,784.63, 항공 LiDAR 16,516.66 m²).
- '두 자료' 비율과 옛 정답, 같은 세 지역 패치(`t6_both_check`):

| 사전 정보 | 새 '두 자료'(전체 / 정답 있는 넓이) | 옛 '두 자료 모두 유효'(패치 넓이 전체 / 경우 있는 넓이 / 참값 점) |
|---|---|---|
| LoD2 | 44.1 / 73.4 | 41.4 / 78.0 / 76.4 |
| 항공 LiDAR | 83.7 / 84.6 | 80.8 / 85.3 / 82.7 |

  LoD2의 전체 넓이 기준 차이는 주로 벽의 '정답 없음'(59 %)이다. 정답 있는 넓이로 견주면 4.6 %p 낮고, 6절 첫 두 줄과 '두 자료 모두 유효 → 사전 정보·영상 틀림'(837 m²)이 그 몫이다.
- 셈 도구 `gtcols.cpp`는 numpy 직접 셈과 맞대 불일치 0(`bin/gtcols_verify.json`).
- 학습·렌더·메시, 판단 규칙·값 바꾸기 없음. h_M은 바깥 첫 면 규칙 없이 원통 안 점 중앙값. 쓴 곳은 1절 5번의 네 폴더뿐.
