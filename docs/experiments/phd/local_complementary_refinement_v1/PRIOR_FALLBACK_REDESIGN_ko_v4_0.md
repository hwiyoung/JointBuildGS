## 1. 이번에 구체화한 운영 원칙

사용자는 비용으로 두 source를 구별하지 못하면 Prior를 사용한다는 방향에 명시적으로 동의했다. 따라서 Prior의 정확성을 먼저 증명해야만 fallback을 허용하는 구조로 만들지 않는다.

**관측만으로 수정할 근거가 부족하면 사용 가능한 Prior를 기존 강도로 사용하고, 현재 영상이 다른 표면을 구별하여 지지할수록 image 감독의 비중을 높인다.**

Prior fallback은 운영 기본값이다. Prior가 현재 정답이라는 평가 판정이 아니다. 현재 GS가 Prior와 다르면 Prior 감독은 GS를 Prior 쪽으로 당길 수 있으므로, 현재 GS 상태 동결과도 다르다. fallback에서 변화부를 수정하지 못한 실패도 평가에 포함한다.

| 상황 | 의도한 동작 | 함께 기록할 것 |
|---|---|---|
| 반복무늬·약한 텍스처·비슷한 대안 비용으로 후보 구별 곤란 | Prior 기본 사용 | 모호성 이유, Prior 현재성 미확인, 미수정 여부 |
| image 후보가 여러 관측에서 구별되어 지지됨 | image 비중을 연속적으로 높임 | 기존 정확한 부위 손상, 수정량과 잔차 |
| Prior 후보가 더 지지됨 | Prior 우선 | 이미지보다 시간적으로 과거라는 이유만으로 제외하지 않음 |
| image depth 결손, Prior 유효 | Prior 기본 사용 | 결손을 Prior 정확성 증거로 집계하지 않음 |
| 서로 다른 두 후보의 사진 비용 모두 나쁨 | 단순 상대 우열로 image로 전환하지 않음 | 가림/혼합 표면/정합 오류 등 비용 모델 부적합을 별도 기록 |
| Prior 결손 또는 prior 계수 0 | 없는 Prior를 되살리지 않음 | image 단독의 사용 근거가 별도로 필요 |

높은 사진 비용은 곧바로 해당 depth가 틀렸다는 뜻이 아니다. 양쪽 비용이 나쁜 경우도 관측 모형으로 구별할 근거가 부족하면 Prior fallback에 남지만, 이를 양쪽 후보가 잘 맞는 모호성과 같은 상태로 표시하지 않는다. 다른 허용 증거가 Prior 자체를 반박하는 경우의 처리까지 이번 사진 비용 검사로 검증했다고 주장하지 않는다.

## 2. 관측 검사를 두 점에서 깊이별 곡선으로 확장

기존에는 Prior 깊이와 image 깊이 두 곳에서의 비용만 확인했다. 새 진단은 같은 픽셀·카메라에서 가설 깊이를 바꿨을 때 비용이 어떻게 변하는지 추가로 확인한다.

\[
E_{j,r}(D)=\frac{1-\operatorname{ZNCC}(A_{p,r},W_{j,p,r}(D,n_s))}{2}.
\]

- `p`: 원사진의 중심 픽셀, `r`: 패치 크기, `j`: 이웃 사진.
- `A`: 원사진 패치, `W`: 해당 depth/normal 가설로 이웃 사진에서 가져온 패치.
- `n_s`: 해당 source에서 얻은 normal. 탐색 중 방향은 고정하고 중심 깊이만 바꾼다. 실제 두 source의 normal이 다르면 source별 곡선을 따로 계산해야 한다.
- 이 깊이 탐색은 관측의 모호성을 검사하기 위한 가설이다. 최저점 깊이로 DA3/MVS 감독 target을 교체하지 않는다.
- 가설 간 같은 픽셀 지원을 고정하고 시점·패치별 곡선을 보존한다. 중앙값 곡선만 보고 충돌을 숨기지 않는다.

우선 직접 측정할 값은 전체 비용 범위, 최소 비용, 대안 최소점들의 깊이·비용, 탐색 경계 도달 여부, source 깊이의 비용과 최저 비용의 차이, 시점·크기별 최소점과 우열이다. 최저점 근처의 허용 비용폭을 늘렸을 때 가능한 깊이 구간이 얼마나 넓어지고 여러 구간으로 나뉘는지도 저장한다.

**수치상 완전히 평평한 곡선**과 **관측 잡음을 고려하면 사실상 구별되지 않는 곡선**은 다르다. 이번 `1e-10`은 부동소수점 동일성 검사이며 실제 사진의 신뢰 문턱이 아니다. `.005/.01/.02/.05/.1` excess-cost 출력도 민감도를 그리기 위한 수준들이며 가중 정책에 적용하지 않았다.

## 4. 가중치 배분과 총강도 분리: 구현한 첫 비교 후보

두 source가 유효하고 활성인 픽셀에서 기존 유효 계수를

\[
c_P=\lambda_P/N_P,\qquad c_I=\lambda_I(t)/N_I
\]

로 둔다. `N`은 각 source의 유효 픽셀 분모다. 이 계수에는 전역 lambda와 원 reduction이 이미 포함되어 있다. 아래의 `q`는 **최종 image 감독 비중**이며 v3.8의 image 지지 `S_I`나 정답 확률이 아니다.

\[
w_P=s(1-q),\qquad w_I=sq,\qquad 0\le q\le1.
\]

첫 비교 후보는 source별 기존 강도를 상한으로 유지하면서 요청한 배분을 만족하는 가장 큰 총강도를 사용한다.

\[
s=\min\left(\frac{c_P}{1-q},\frac{c_I}{q}\right),\quad 0<q<1.
\]

끝점은 `q=0 → (wP,wI)=(cP,0)`, `q=1 → (0,cI)`다. 최종 loss는

\[
L_{depth}=\sum_p\{w_P(p)|\hat D(p)-D_P(p)|+w_I(p)|\hat D(p)-D_I(p)|\}.
\]

source별 분모를 반영했으므로 바깥에서 다시 평균 내지 않는다. 학습에 연결할 경우 지도와 target은 detach하고 mask/분모·실제 controller 계수·gradient를 기록해야 한다. 이번에는 학습에 연결하지 않았다.

이 식에서는 같은 q의 배분이 기존 계수비 때문에 역전되지 않고, fallback에서 image의 예산이 Prior로 옮겨져 Prior가 증폭되지 않는다. 모호성은 원칙상 q=0으로 보내되, 아직 실제 관측에서 q를 생성하는 검증된 함수는 없다.

Prior 비활성이면 two-source q를 image 단독 품질로 전용하지 않는다. 별도의 image admission 값이 없으면 해당 프로브는 depth 감독 0으로 명시한다. image 비활성이고 Prior 활성이면 cP를 사용한다. `missing`, `disabled`, `zero coefficient`는 별도 메타데이터로 남긴다. 이는 zero-prior 조건을 기존 GeoGS image-only와 동등하게 만든다는 뜻이 아니다.

### 통과한 성질과 남은 절충

Docker CPU 수식 감사에서 계수비 1/10/100의 q 보존, source별 상한, q=0/1 끝점, 비활성 source 재사용 방지 등을 확인했다. 631개 수치 검사 PASS이며 실제 지도 정확도나 가우시안 이동 검사가 아니다.

**이 후보도 최종 채택안으로 확정하지 않는다.** 상한을 지키면 중간 q에서 총강도가 작아질 수 있다.

- cP=.0005, cI=.05, q=.9이면 `(wP,wI)=(.0005,.0045)`. image 비중은 90%지만 image 절대계수는 원 .05의 9%만 남는다.
- 같은 두 target에서 q=.5를 쓰면 총강도는 .001로, 기존 .0505의 약 1.98%다. source가 같은 방향을 당기는 경우에도 최적화 강도 감소가 생길 수 있다.
- 서로 다른 target의 scalar L1에서는 q>.5여야 image 쪽이 우세하다. image 가중치가 단순히 양수라는 것만으로 충분한 수정이라고 평가하지 않는다.
- 고정 활성 source 집합 안에서는 연속이지만 source가 없거나 계수 0이 되는 운영 경계는 별도 분기다.

따라서 이 후보는 **배분 역전과 Prior 증폭을 통제하는 비교안**이다. 유효 영상의 수정력이 충분한지는 총강도·optimizer와 함께 검증해야 한다. 동일 target에서 기존 총강도 B=cP+cI를 보존하면서 source별 상한도 보존하려면 기존 `(cP,cI)`가 강제된다. 모든 경우에 q 계수비 독립·강도 보존·각 source 상한을 동시에 요구할 수는 없다.

## 5. 다음 검증의 순서와 산출물

1. **관측 판별부터:** 기존 8개 위치를 회귀 사례로 사용하여 Prior/DA3, Prior/MVS 각각의 비용곡선을 계산한다. P2의 9/17/33 순위 역전은 전부 보존한다. 좋은 패치만 사후 선택하지 않는다. 탐색 범위는 두 후보와 카메라 기하로 설정하고 최소점이 범위 끝에 있거나 범위 확장에 따라 바뀌면 함께 표시한다. 후보 결손은 깊이 탐색으로 채우지 않는다.
2. **비용 안정성 측정:** 개별 시점을 하나씩 제외한 곡선과 픽셀 재투영 오차에 대한 민감도를 기록한다. 격자 범위/간격, 패치 범위가 바뀌어도 어느 후보를 지지하는지 확인한다. 시점 제외의 변동은 독립 정답 오차나 생성 사진과 독립된 평가가 아니다. 이 자료 없이 새 `.1/.3/.5` 같은 비용 문턱을 확정하지 않는다.
3. **곡선→연속 q 비교 명세:** source별 실제 비용, 대안 깊이와의 구별 정도, 시점·크기 변동을 입력으로 한다. 모호한 양쪽 후보는 q=0, 강하고 안정적인 image 지지는 q가 .5를 넘어서 1에 접근할 수 있어야 한다. low-cost가 여러 깊이에 남는 반례는 q를 높여서는 안 된다. `관측 사용 가능률`과 `유효 image를 낮게 가중한 비율`을 동시에 평가한다. q 변환의 수치 문턱/기울기는 아직 미확정이며 이번 컴포넌트 PASS로 정당화하지 않는다.
4. **원사진에 지도 중첩:** 같은 위치에 원사진, 두 depth/normal, 비용곡선, q, wP/wI, 총강도 s, Prior fallback 이유를 연결한다. q만 표시하면 image 비중이 높지만 힘은 거의 없는 경우를 놓친다. 듬성한 grid 측정치를 검증 없이 사진 전체에 보간하여 학습 지도로 쓰지 않는다.
5. **GT는 이후 별도 평가:** 점수/가중 변환을 먼저 봉인하고 같은 참조점 ID의 source 오차와 대조한다. 평가 결과로 해당 사례를 손본 경우 개발 회귀로 기록하고 독립 검증으로 부르지 않는다. 실제 GT로 honest arm 문턱을 맞추지 않는다. 없는 참조는 정확도 NA로 남긴다.
6. **최적화 검증:** 관측→q가 고정되면 loss/gradient 검사와 동일 Anchor의 짧은 검증을 거친다. 본 비교에는 기존 G, 낮은 prior G, 새 정책, source별 평균 강도를 맞춘 전역 대조를 함께 둔다. controller 고정/replay와 반복이 없으면 공간 배분 효과와 작은 성능 차이의 재현성은 확정하지 않는다. DA3/MVS 교체는 별도 요인이다.

이번에 완료한 것은 1–6 전체가 아니라 **관측 실패를 볼 수 있는 비용곡선 컴포넌트와 q가 주어진 뒤의 배분/강도 컴포넌트**다. 실제 비용에서 q로 가는 부분이 남았음을 명시한다. 이 경계가 닫히기 전에 기존 LC 큐나 새 본 학습에 이 후보를 연결하지 않는다.
