## CW38-001 — 단위 검사의 부동소수점 경계 비교

최초 Docker CPU 실행에서 15개 테스트 중 2개가 실패했다. E=.1의 ramp 끝점에서 U=1.11e-16인 반올림 오차를 절대 허용오차 0으로 비교한 것이 원인이었다. 수식은 변경하지 않고 해당 경계 테스트의 atol만 1e-15로 바꿨다. 후속 15개 모두 통과했다. 대수 수식과 테스트의 수치 비교 문제이며, 실제 장면 가중치나 Gaussian 최적화의 실패·성공으로 해석하지 않는다.

## CW38-002 — 관측 gate 미결박 (OPEN)

v3.7의 가시성은 unknown이다. 높은 사진 비용을 source에 대한 반박으로 해석할 대응/가시성 자료의 계산기가 아직 결박되지 않았다. v3.8 수식 모듈에 gate를 외부 입력으로 명시하고, 현재 자료의 실제 정책 값은 0으로 정의했다. gate=1의 비용 대입 예시는 가정된 수치 예시다. 실제 지도 인증 및 새 학습 연결은 완료되지 않았다.

## CW38-003 — 보수적 가중치가 필요한 수정을 막을 위험 (OPEN)

P2_high의 기존 비용을 대입하면 이 후보는 DA3에 힘을 주지 않는다. 이것은 비용의 불안정성을 드러낼 뿐이며, 참조에 더 가까운 DA3를 찾아낸 결과가 아니다. 올바른 image를 제거한 비율, 변경부 미수정, fallback 면적을 정확성·손상 지표와 함께 평가해야 한다. 큰 패치의 경계 혼합과 낮은 prior 계수 대비 강화 배율도 후속 검증 대상이다.
