## 사용자가 명확히 한 의도와 현재 구현

현재 영상으로 신뢰할 만한 기하를 얻는 영역은 그 근거에 맞춰 수정하고, 현재 영상의 기하 근거가 부족한 영역은 재사용 가능한 prior를 기본값으로 유지한다. Prior 유지 정책과 그 표면의 현재 정확성 확인은 구분한다.

픽셀별 잔차에 배율을 곱하는 것은 실제 국소 가중이다. 전역 lambda와 곱한다는 이유로 전역 가중만의 방법이 되는 것은 아니다. 이는 영역별 Gaussian을 영상 증거에 맞추기 위한 수단이지만, 특정 Gaussian의 위치만을 직접 이동시키는 명령은 아니다. 여러 픽셀·시점의 gradient가 위치·회전·크기·불투명도 등에 함께 전달된다.

현재 LC는 `a=clip((abs(DP-DI)-.5)/1.5,0,1)`, 두 source가 유효한 곳에서 `bP=1-a`, `bI=a`를 적용한다. 유효성은 주로 유한 양수 target이며, 현재 영상의 실제 매칭 지지·가시성·국소 정확성을 이 값으로 판정하지 않는다. DA3가 양의 값을 출력한 넓은 MVS 결손 영역도 별도로 인식하지 못한다.

같은 전역 lambda와 source별 분모에서 LC/G의 image:prior 비율 변화는 `a/(1-a)`다. 따라서 현재 문턱에서는 delta>1.25m일 때만 G보다 영상의 상대 비중이 커진다. 반면 source가 정확히 같다면 하나의 depth 항을 꺼도 고립된 depth 목적의 최소점과 수정 방향은 유지된다. 이때 감독의 총강도를 줄이는 것이 적절한가는 다른 목적함수와의 균형 문제다. 하나를 끄는 행위 자체를 설계 오류로 판정하지 않는다. 현재의 delta<=.5m 분기는 정확한 일치보다 넓은 범위다.

## 카메라별 오차와 영상 근거의 충돌

서로 다른 카메라의 같은 표면에 대한 camera-Z 잔차가 같아야 한다는 요구는 없다. 같은 3D 위치 오차도 카메라 축에 투영하면 다른 깊이 오차가 된다. 각 시점의 오차가 다르다는 사실만으로 다중뷰 불일치를 입증할 수 없다.

필요한 일관성은 같은 가시 표면에 대한 예측을 공통 좌표로 옮기거나 재투영했을 때 양립하는가다. 예를 들어 A에서 복원한 바닥을 B로 재투영한 깊이와 B의 같은 가시 바닥 depth가 예상 불확실성보다 크게 어긋나면 충돌 후보다. A에서 난간이 바닥을 가리고 B에서는 바닥이 보이는 경우는 먼저 가시성으로 구분해야 한다. 일관된 공통 편향은 여러 시점에서 동시에 틀릴 수 있으므로 일관성이 정확성의 증명도 아니다.

현재 DA3 생성은 7/8장과 카메라를 함께 입력하는 다중뷰 추론이다. 영상 이름순 비중복 배치를 사용하며 배치 후 depth를 공동 재최적화하거나 재투영 일관성으로 필터링하는 단계는 없다. GS는 공유 Gaussian을 통해 여러 영상의 제약을 결합하지만 저장 DA3 target 자체를 공동 수정하지 않는다.

## 현재 증거로 나눌 수 있는 원인 질문

1. **G와 LC에 공통으로 남은 절대 오차:** P1의 노출 바닥에서 DA3가 참조보다 높은 표면을 제안하는 실제 관측이 있다. 입력 품질이 후보 원인이지만 표현·보호·최적화·추출의 기여와 크기를 분리하지 못했다.
2. **같은 DA3를 사용한 G 대비 LC의 추가 악화:** DA3 입력만으로 두 조건의 차이를 설명할 수 없다. 국소 규칙·감독 강도·controller 반응·최적화 경로를 포함한 변경 효과다. 부정확한 DA3와 그 target을 더 우선하는 규칙의 상호작용일 수 있다.
3. **현재 자료의 한계:** 입력 정확도와 loss 설계 중 어느 쪽이 몇 % 또는 더 크게 기여했는지 식별한 실험은 없다. 반복·평균 강도 전역 대조·controller replay도 없는 현재 비교에서 해당 귀속을 확정하지 않는다.

봉인된 P2 .005 native의 220개 대응 로그에서 raw DA3 L1 평균은 G6.758→LC4.487m, RGB 학습 목적은 .11520→.11397이지만, 전체 참조점→raw mesh 평균은 .737→1.070m다. 이는 서로 다른 카메라를 포함한 두 run의 표본 평균 비교이지 단일 상태의 전후 수렴 또는 국소 원인 분해가 아니다.

P1 A의 고정 사후 타일에서는 DA3 world-Z 편차 중앙값+2.440m, prior 배율0/image 배율1이며 기존 G의 근접점714개를 LC가 잃었다. P2 C에서는 같은 a=1로 기존 G의 회복663개를 LC가 유지했다. 유리한 target을 활용한 보존과 불리한 target을 따른 손상이 공존한다. 이를 DA3만의 원인 또는 국소 가중 일반의 실패로 바꾸지 않는다.

## 수정 방향: source 선택과 감독 총강도를 별도로 정의

두 source가 유효한 픽셀에서 다음은 후보 설계를 표현하는 방식이다.

`ell_p = s_p * ((1-q_p)*abs(pred-DP) + q_p*abs(pred-DI))`

- `q_p`: 최종 depth 감독에서 image가 차지할 비율. 전역 계수와 분모를 적용하기 전의 배율 a와 혼용하지 않는다.
- `s_p`: 두 depth 감독의 합계 강도. RGB·정규화와 비교할 강도이며 q가 바뀐다는 이유만으로 자동 감소시키지 않는다. 고정값이어야 한다는 뜻은 아니고, 변화 정책을 독립적으로 명시한다.
- 하나만 유효하면 해당 source만 계산하고, 둘 다 없으면 depth loss는0이다. 결손 target의 잔차를 계산한 뒤0을 곱하는 방식은 쓰지 않는다.
- 위 식은 임의의 비음수 두 계수를 합계와 비율로 다시 표현한 것이며 그 자체가 신규 방법 또는 개선 증거는 아니다. 평가 전에 q의 입력·규칙, s, 분모·유효 마스크·문턱을 실제 명세로 정해야 한다.

정책 후보는 다음과 같다.

| 영상 기하 근거 | 원하는 행동 | 필요한 설계 구분 |
|---|---|---|
| 결손 또는 신뢰 부족, 사용 가능한 prior 있음 | prior를 기본값으로 유지 | 양의 depth 존재와 실제 영상 지지를 구분; prior 유지 강도를 명시 |
| 충분하며 prior와 일치 | 공통 표면 유지 | 하나의 감독 선택도 허용; 합계 강도를 별도 결정 |
| 충분하며 prior와 충돌 | 영상 쪽 수정 허용 | 불일치만으로 영상 신뢰를 부여하지 않음; prior 완화와 영상 강도를 분리 |
| 같은 가시 표면의 영상 추정끼리 불일치 | 해당 불확실한 감독의 영향 감소 | 가림·경계 오대응을 먼저 구분; 신뢰되는 다른 시점까지 모두 끄지 않음 |

첫 후보에서 loss 종류 자체를 바꿀 필요는 없다. 기존 L1을 유지한 채 source 선택과 총강도 정의를 분리하면 불필요한 변경 요인을 줄일 수 있다. MVS의 매칭/재투영 지지는 q의 후보 입력이지만, MVS 유효 픽셀이나 다중뷰 일치만으로 정확성을 확정하지 않는다. GT 잔차를 q·s·문턱 또는 깊이 보정에 전달하지 않는다.

## gradient 분석이 설계에 주는 정보

동일한 저장 모델·optimizer 상태와 동일한 카메라에서 RGB/prior/image/정규화의 gradient를 분해하고 보호 전후·가중 전후를 비교한다. 개별 gradient 크기뿐 아니라 합성 방향과 Adam의 실제 업데이트, 업데이트 후 고정 시점의 렌더 깊이 변화도 구분한다. 다른 run의 다른 학습 상태 gradient를 직접 비교해 국소 가중의 단독 효과라고 쓰지 않는다.

| 관측되는 전달 경로 | 우선 검토할 수정 |
|---|---|
| 신뢰할 수 없는 image depth가 prior·다른 영상 근거를 압도 | 영상 감독의 신뢰 판단·배율 축소; DA3 계수를 일괄 증폭하지 않음 |
| 신뢰할 수 있는 image depth 쪽 수정이 prior/보호로 상쇄 | prior 완화 또는 보호 제어를 구분해 검토 |
| 렌더 depth는 target에 맞지만 표면이 잘못됨 | expected-depth 혼합·불투명도·표현·추출 경로를 확인 |
| source 선택과 함께 전체 depth 힘이 크게 줄어듦 | q와 s를 분리한 설계 및 총강도 대조 |

큰 gradient 또는 낮은 학습 잔차는 올바른 기하의 증거가 아니다. 참조를 사용하는 수정·손상 평가는 별도 평가 경로에서 수행한다.

## MVS 교체와 설계 변경을 분리할 비교안

MVS만 넣어도 개선된다고 말할 근거는 없다. 입력을 바꾸면 target, 결손, source별 분모가 바뀌며 현재 LC에서는 불일치 기반 gate까지 함께 바뀐다. 따라서 현재 LC에 대한 파일 교체는 순수 target 정확도 개입이 아니다.

동일 complete Anchor·카메라·prior 계수·보호를 사용하는 한 묶음의 비교 구조는 다음과 같다. 비교 구조일 뿐 새 run 수·자원·실행 승인 문서가 아니다.

| 감독 입력 | 기존 G 규칙 | 현재 LC 규칙 | 수정 규칙 |
|---|---|---|---|
| DA3 | 정확히 맞는 기존 결과 재사용 후보 | 정확히 맞는 기존 결과 재사용 후보 | 설계 효과 비교 |
| 유효 MVS depth | source 경로 효과 비교 | source에 따른 현재 gate 반응 비교 | source와 수정 규칙의 상호작용 비교 |

입력 오차 비교는 같은 가시 표면의 공통 지원 영역과 source별 결손 영역을 나눠 보고한다. MVS 구멍을 DA3로 즉시 채우지 않는 첫 비교가 source 효과를 읽기 쉽다. 부족한 영상 근거에서는 prior 유지 정책을 명시한다. 다중뷰 matching에 evaluation 카메라가 사용됐는지, K·해상도·픽셀 중심·척도·유효 마스크의 계보도 먼저 확인한다.

순수 target 개입을 더 좁게 보려면 공통 유효 마스크·배율·분모·controller 경로를 고정한 별도 진단이 필요하다. 이 진단은 결손을 포함한 실제 운용 성능 비교를 대신하지 않는다. 공간 배분 고유 효과에는 평균 강도 전역 대조, controller 효과에는 동일 계수 replay, 작은 차이의 재현성에는 반복이 필요하다. 기존18개에 없던 대조를 이미 수행한 것으로 해석하지 않는다.
