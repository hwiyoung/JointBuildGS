# 렌더 점검 범위 해석과 진행

사용자는 “이 실험의 목표가 뭔데 왜 그냥 서있는거야?”라고 진행을 요구했다. 에이전트는 발주문에 없던 ‘50cm 칸의 투영 경계와 렌더 영향 경계가 같아야 한다’는 추가 조건 때문에 중단한 것을 수정한다. 사용자가 특정 마스크 정의를 별도 승인했다고 기록하지 않는다.

50cm 칸은 자리 선택과 바탕 정리의 기하 단위다. 렌더의 시험 화소는 두 후보가 실제로 영향을 줄 수 있는 영역이며 가우시안의 정상적인 꼬리와 화소 필터를 포함한다. 이 범위 밖에서 바탕이 변하지 않아야 한다. 기존 전체 뷰 점검에서 실제 후보 영향영역 밖의 변화는 네 경우 모두 0이었고, 24개 초기 설정의 고정 값 기울기와 허용 변수 기울기 점검도 통과했다.

비교용 사진 오차의 화소 범위는 양쪽 후보 불투명도 1에서 계산한 영역을 학습 전에 고정한다. 모든 초기값과 SH 조건, 모든 반복에 같은 범위를 쓴다. 학습 중 불투명도가 낮아졌다고 측정 화소가 줄지 않는다. 100회마다 같은 5개 후보 관측 사진에서 오차를 계산하며, 시작·끝은 모든 학습 사진에서 계산한다. 학습 PSNR은 발주대로 앞 5장이다. 이 마스크는 사진 손실을 자르는 데 사용하지 않는다. 학습 손실은 전체 학습 사진의 원래 L1+D-SSIM이다.

자리 목록, 바탕 정리, 후보 크기·방향, 손실, 초기 불투명도, 학습률, 반복 수, 채점 기준은 바꾸지 않는다. 최초 50cm 칸 밖 변화와 STOP_PREFLIGHT 기록·첫 ZIP은 당시의 진단 기록으로 보존한다. 현재 실행의 설정·해시는 candpick_v1.json과 candpick_v1.lock.json이 소유한다.
