# PHD-MAIN-CANDPICK-v1 실행 이슈

- 발주문 ‘사진 확인 v2’ 명칭은 사용자 정정으로 PHOTOCHECK-v1 최종 점·패치로 해소했다. 보기 값은 0부터 4번 열, 보조 비교는 0번 열이다.
- 첫 바탕 모델 점검은 체크포인트 Tensor의 `requires_grad` 때문에 NumPy 변환에서 중단됐다. 읽기 전용 `detach()`로 고쳤다. 원본이나 시험 규칙을 바꾸지 않았고 최적화 0회다. 실패 로그를 외부 작업 폴더에 보존한다.
- gsplat API 확인용 첫 읽기 전용 컨테이너에 임시 경로가 없어 import가 중단됐다. `/tmp` tmpfs로 해결한다. 본 CPU 실행기는 이미 tmpfs를 사용한다.
- GPU 대기기가 원격 데스크톱 데몬의 260MiB 사용을 학습으로 분류해 대기했다. 확인된 `/usr/libexec/gnome-remote-desktop-daemon`만 대기 대상에서 제외하고, 첫 점검은 빈 GPU 1에서 실행한다. 해당 서비스는 중단하거나 변경하지 않았다.
- LoD2용 근거 공간 메타데이터에 상속한 ALS 파일의 해시 이름이 남아 있음을 발견했다. 원래 메타데이터를 보존하고 실제 LoD2 파생 파일 해시로 정정했다. 기하·삭제 대상·불확실도 수치는 바뀌지 않았다.
- 대표 낙엽 지붕은 지정 지역에서 적격 1–3m² 덩어리를 찾지 못하여 같은 조건의 대체 자리를 잠갔다. B173 사진이 속는 예시는 같은 조건의 1–3m² 덩어리도 없어 확인 불가다. 사진이 속음만으로 유리 재질을 판정하지 않는다.
- **미해결: 3.3_OUTSIDE_TRIAL_CELL_IDENTITY.** 50cm 칸 밖에 후보 가우시안의 꼬리가 그려져 네 경우 모두 동일성 검사가 실패했다. 최초 B173-ALS 뷰는 3,523화소가 변했다. 전체 뷰에서도 같은 유형이 확인됐다. 실제 후보 렌더 영향영역 밖 변화는 0이나 이를 기준 변경 없이 통과로 쓰지 않는다. 사용자에게 판정 범위 확정을 요청했으며, 학습 0/24판·최적화 0회로 보류한다. 이는 메모리나 실행 환경 문제가 아니므로 사용자에게 받은 환경 문제 자체 해결 지시로 기준을 바꾸지 않았다.
