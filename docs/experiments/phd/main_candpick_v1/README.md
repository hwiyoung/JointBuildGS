# 후보 고르기 시험 v1 — 자리 잠금 기록

네 경우의 적격 자리 13,849점을 학습 전에 잠갔다. 장면 정리·가림 기록·기울기 점검을 마쳤으나, **발주문 3.3의 50cm 시험 칸 밖 동일 검사에서 중단했다. 학습은 0/24판**이다. [사전 점검 보고서](stage1_report.md)와 [집계 원표](stage1_summary.json)에 실패와 완료 범위를 구분했다. `scientific_verdict: null`.

13,849점은 경우별 점 수의 합이며, 사전 정보 간 중복을 제거한 물리적 자리 수가 아니다.

## 입력 명칭과 판정 열

사용자가 발주문 2.1의 “사진 확인 v2”를 **PHD-MAIN-PHOTOCHECK-v1 최종 점·패치 파일**로 정정했다. 원본의 `데이터_읽기.md`와 `photocheck_v1.json`의 `judgments.candidates`를 직접 대조했다. 원본에는 README라는 이름 대신 데이터 설명 파일이 있다.

- 학습·채점: δ=0.10, 최소 점수=0.3. **0부터 4번 열, 1부터 다섯 번째 열**.
- 보조 자리 표: δ=0.05, 최소 점수=0. **0부터 0번 열, 1부터 첫 번째 열**. 보조 판정은 학습·채점에 쓰지 않는다.
- 지지=0, 반박=1, 모름=2·3·4. 원본의 15열을 임의 재판정하지 않는다. 잠근 자리 NPZ의 `judgment`는 보기 값 1열이며, 1차 ZIP의 `payload/validation/*_photo_judgments.npz`에는 해당 점들의 원본 15열을 별도로 넣었다.

## 실행 상태

- 자리 목록·대표 자리: 잠금 완료. `configs/phd/main_candpick_v1/places_v1.json` 및 `.lock.json`.
- 네 판정 끔 30,000회 바탕 체크포인트: 존재·SHA-256·수치 유한성 검사 PASS.
- 네 바탕 장면: 근거 공간 밖 제거와 시험 칸 기둥 제거 완료. 원본은 읽기 전용 보존.
- 가림 기록: 네 경우의 전체 학습 뷰 계산 완료. 30% 초과 점을 표시하고 후보별 분자·분모를 보존했다.
- 3.3 기울기: 24개 초기 설정 모두 PASS. 최적화는 0회다.
- 3.3 렌더: 50cm 칸 밖 동일 FAIL. 실제 후보 렌더 영향영역 밖 변화는 0이지만, 이를 원래 기준의 통과로 대체하지 않는다.
- `candpick_v1.json` 잠금, 24판 학습·채점·최종 그림: 미실행. 시험 자리 밖의 판정 범위를 사용자가 확정한 뒤 남은 선행 검사를 마친다.

## 재현

`scripts/phd/main_candpick_v1/run_cpu.sh`로 Docker에서 `input_audit.py`, `check_baselines.py`, `prepare_places.py`, `verify_places.py`를 실행했다. 새 작업의 출력 외에는 읽기 전용으로 연결한다. 기존 잠금이나 결과가 있으면 덮어쓰지 않는다. 큰 파일은 `../JointBuildGS-artifacts/phase-payloads/phd/main_candpick_v1/PHD-MAIN-CANDPICK-v1`에 있다.

원본 사진과 바탕 모델을 전달 ZIP에 중복하지 않는다. 해시는 바이트 동일성을 확인하며 연구적 성공을 뜻하지 않는다.

ZIP에는 점·판정·가림 분자/분모·삭제 마스크·후보 기하·대표 사전 점검 PNG와 코드·설정·보고서를 넣는다. 전체 사진 묶음과 큰 바탕 모델은 넣지 않는다. 점 표 96행과 가림 집계는 ZIP만으로 재계산할 수 있다. 장면 재생성·렌더·가림 재실행에는 입력 기록에 지정된 외부 원본과 저장소의 상속 구현, Docker 이미지가 필요하다. 정확한 범위는 ZIP의 `BUNDLE_README.md`를 따른다.
