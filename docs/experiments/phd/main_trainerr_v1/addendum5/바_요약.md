# 일 바 요약: 케이스 그림 (한 그림 한 문장)

scientific_verdict: null. 그림 제목은 발주문 8절의 문장이다. 그 문장이 그림과 맞는지는 아래 '그림이 보이는 것' 열에 값으로 적었다.

## 공통

- **선:** 참값은 회색 점, 목표면은 파랑, 학습 뒤 표면은 빨강이다. 사진만 쓴 2DGS는 넣지 않았다.
- **축:** 가로·세로 눈금 비가 같다. 축에 단위(m)와 카메라 쪽(바깥)을 적었다.
- **크기:** 가로 1,600 화소 이상이다.
- **함께 낸 것:** 그림마다 출처 `figures/bb_<케이스>.json`과 점 자료 payload `addendum5/ba/bb_<케이스>.npz`를 냈다.
  - 점 자료에는 단면 위 참값 점, 목표면·표면 선분, 가우시안 중심과 종류가 들어 있다.
