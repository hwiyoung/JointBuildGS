# 덧붙임 6의 고침 1: 그림을 그리는 규칙 (2026-11-17)

- 받는 곳: 코딩 에이전트. `claude/본실험_학습오류원인_덧붙임6.md`와 함께 읽는다. 그 문서의 10절(그림)과 어긋나는 곳은 이 문서를 따른다.
- 고친 까닭: 사용자가 덧붙임 4·5의 그림을 보고, B0 남쪽 끝 벽 말고는 사진이 무엇을 보이려는지 알 수 없고, 사진 위의 단면 표시도 읽히지 않는다고 했다.
- 일의 차례는 바꾸지 않는다. 그림은 일 가~바의 값이 나온 뒤에 그린다. 새 학습은 하지 않는다.

## 1. 지금 그림이 읽히지 않는 까닭 (분석 세션이 본 것)

| 문제 | 보기 |
|---|---|
| 사진에 문제가 보이지 않는다 | 사진에는 자리만 칠해져 있다. "여기에 표면이 없다"는 결과는 사진 어디에도 없다 |
| 자리가 면으로 보이지 않는다 | 잘 보이는 벽은 분홍 점이 흩어져 있어 어느 벽인지 알 수 없다. 남쪽 끝 벽은 벽 전체가 칠해져 있어 읽힌다 |
| 단면선이 무엇을 자른 것인지 알 수 없다 | 노란 선이 짧고, 선의 어느 끝이 단면 그림의 어느 쪽인지 표시가 없다 |
| 사진과 단면이 따로 논다 | 단면 그림의 가로축이 사진의 어느 방향인지, 위아래가 무엇인지 사진에서 찾을 수 없다 |

## 2. 케이스 그림의 틀: 세 칸

케이스마다 그림 한 장을 세 칸으로 그린다. 세 칸은 **같은 자리, 같은 색**을 쓴다.

| 칸 | 그리는 것 | 지킬 것 |
|---|---|---|
| 1. 사진 | 그 자리가 가장 잘 보이는 학습 영상 한 장 | 자리는 흩어진 점이 아니라 **면의 윤곽**으로 칠한다(반투명). 단면선을 굵게 긋고 양 끝에 A, B를 적는다. 자리가 사진 폭의 4분의 1 이상이 되게 자른다 |
| 2. 결과 | 칸 1과 **같은 시점**에서 학습 뒤 표면(메시)을 그린 것 | 표면은 밝은 회색 음영으로 그린다. 문제가 되는 곳만 빨강으로 칠한다: 있어야 하는데 없는 면은 참값 면을 빨간 빗금으로, 없어야 하는데 있는 면은 그 면을 빨강으로. 같은 단면선과 A, B를 긋는다 |
| 3. 단면 | A에서 B로 자른 단면 | 가로축의 왼쪽 끝에 A, 오른쪽 끝에 B를 적는다. 참값은 회색, 목표면은 파랑, 학습 뒤 표면은 빨강이다. 선은 셋까지다. 문제가 되는 곳을 화살표 하나와 짧은 글자로 가리킨다 |

- 칸 2가 핵심이다. 사진 옆에 결과를 같은 시점으로 놓아, 설명 없이 "사진에는 벽이 있는데 결과에는 없다"가 보여야 한다.
- 비교가 요점인 케이스는 칸 2를 둘로 나눈다(예: 본 방법 / 가려진 화소의 감독을 끈 학습, 7,000회 / 30,000회).
- 그림 위에 보여야 할 한 문장을 제목으로 적는다. 그림 안의 글자는 그 밖에 A, B, 화살표의 짧은 말, 범례뿐이다.
- 내부 이름(판 이름, 영상 번호)은 그림에 적지 않는다. 출처 json에 적는다.
- 가로 2,400 화소 이상으로 낸다. 그림에 쓴 점 자료와 칸 2의 시점(카메라)을 묶음에 함께 넣는다.

## 3. 그릴 케이스와 보여야 할 한 문장

덧붙임 6의 10절 표 가운데 케이스 그림은 아래로 바꾼다. 값 그림(조각의 경과, 나간 길, 재설정을 넘는 조건, 원인 지도)은 10절 그대로 둔다.

| 케이스 | 보여야 할 한 문장 | 칸 2 |
|---|---|---|
| R1 바닥 띠 | 통로 바닥이 있어야 할 자리에 표면이 없고, 통로 위를 덮는 면이 있다 | 30,000회 |
| B0 벽 아랫단 | 벽이 바닥과 만나는 띠에 표면이 없다 | 30,000회 |
| B0 별채 지붕 아래 면 | 지붕 가장자리에서 아래 바닥까지 실제로 없는 비스듬한 면이 있다 | 30,000회 |
| B0 남쪽 끝 벽 | 벽 뒤 건물 안쪽에 실제로 없는 면이 있다 | 30,000회 |
| B0 잘 보이는 벽 | 본 방법에는 벽의 표면이 없고, 가려진 화소의 감독을 끈 학습에는 있다 | 본 방법 / 감독을 끈 학습 |
| R1 × LoD2 1번 벽 | 7,000회에 있던 벽의 표면이 30,000회에 없다 | 7,000회 / 30,000회 |
| 뜬 면 | 건물 벽 바깥 허공에 실제로 없는 세로 면이 있다 | 30,000회 |
| 학습 후 개선된 지점 | 목표면은 벽에서 떨어져 있는데 학습 뒤 표면은 벽에 있다 | 30,000회. 목표면을 파랑 반투명으로 함께 그린다 |

- 덧붙임 6의 일 라에서 표면을 다시 추출한 판이 원래 판과 눈에 띄게 다르면, 잘 보이는 벽과 1번 벽은 칸 2에 '가림 제외' 판을 하나 더 넣는다.
- 덧붙임 6의 일 바에서 '설명되지 않음'이 붙은 점이 모인 자리가 있으면, 큰 것 셋을 같은 틀로 그린다.

## 4. 보내기 전 점검 (그림)

- [ ] 그림마다 세 칸이 있고, 세 칸의 단면선과 A, B가 같다.
- [ ] 칸 1의 자리가 면의 윤곽으로 칠해져 있다.
- [ ] 칸 2에서 문제가 되는 곳이 빨강으로 칠해져 있고, 제목 문장이 칸 2만 보고도 읽힌다.
- [ ] 그림 안에 내부 이름이 없다.
- [ ] 점 자료와 칸 2의 시점을 묶음에 넣었다.
