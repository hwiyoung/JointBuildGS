- 50쪽: τ 초과 면의 61~73 %가 재할당 반경 밖이다. 다만 고정 반경(항공 LiDAR 0.56 m, LoD2 0.95 m)으로 셌고 대조가 없어 상관일 뿐이다.

## 2. 단계 0: 준비

1. **재현.** 저장된 메시로 0.1 표의 열두 값을 GTJUDGE 단계 1의 칸, 법선 측정선 거리, 덧붙임 2 3.4의 정확성 규칙으로 다시 센다. 0.1 %p 넘게 다르면 보고서 맨 앞에 적고, 다시 센 값으로 잇는다.
2. **점 집합.** 칸 × 판마다 잃은 점과 대조 점을 만든다. 점마다 id, 좌표, 법선, 칸, 기둥의 패치 id, 두 판의 판정, 목표면 거리, 학습 뒤 거리를 둔다. 파일 `sets/<칸>_<own|gt>.parquet`. 잃은 점이 1,000개 미만이면 '적음'을 붙이고 그대로 잇는다.
3. **기록 범위.** 장면마다 두 판의 잃은 점을 모두 담는 범위를 만든다. 잃은 점을 0.6 m로 이은 모임마다 XY 상자를 2 m 넓히고, 높이는 모임의 최저점 −1 m부터 최고점 +4 m까지로 한다(R1의 위 구조물이 들어가게). 파일 `region/<단위>__<사전 정보>.json`.
4. **새 판과 단위 점검.**

| 점검 | 통과 |
|---|---|
| 기본값 | 모든 스위치 기본값에서 r23과 같은 결정(작은 예제, 같은 씨앗, 300회, 밀도 제어 한 번 이상 포함) |

| 번호와 사건 | TRAINLOG 2.5의 번호 추적과 사건 맞춤 |

| `tl_B0_LoD2_gt` | B0 × LoD2 | 정답 판정 | GTJUDGE A-1과 같은 명령 + 기록 |
| `tl_R1_ALS_own` | R1 × 항공 LiDAR | 본 방법 판정 | FINALTRAIN과 같은 명령 + 기록 |
| `tl_B0_LoD2_own` | B0 × LoD2 | 본 방법 판정 | FINALTRAIN과 같은 명령 + 기록 |

- 기록 = `--jbgs_trainlog on --jbgs_trainlog_region <2절 3번 파일> --jbgs_trainlog_grads on`. 씨앗 0, 30,000회. 7,000회 건강 점검은 FINALTRAIN과 같다.
- 같은 설정을 기록만 더해 다시 돌리는 판이다. 같은 판을 여러 번 돌리는 것이 아니다.

### 3.2 저장

- 상태 저장 반복, 열, 사건은 TRAINLOG 2.2·2.3과 같다. 범위만 3번의 기록 범위로 바꾼다.
- 주요 반복 12개(0·100·300·1,000·2,000·3,000·5,000·7,000·10,000·15,000·20,000·30,000회)에서는 장면 전체 상태를 저장하고 메시를 만든다.
- 상태 파일이 한 판에 50 GB를 넘을 것 같으면 3,000~15,000회 저장 간격을 1,000회로 늘리고 적는다.

### 3.3 기울기 기록

- 저장 반복마다, 정상 역전파 전에 사진 손실, 깊이 손실, 2DGS 항 각각에 대해 `torch.autograd.grad`로 위치와 불투명도의 기울기를 구하고, 범위 안 가우시안의 크기만 적는다.
- `.grad`, 옵티마이저 상태, 밀도 제어 통계, 난수에 닿지 않아야 한다(단위 점검 '기록 불변').

### 3.4 원래 판과 대조

| 항목 | 7,000·15,000·30,000회마다 원래 판과 기록 판 |
|---|---|
| 기록 범위 가우시안 수, 꼬리표별 수 | 수와 차(%) |
| 그 장면 칸의 완전성·정확성(30,000회 메시) | 값과 차(%p) |
| 잃은 점의 겹침 | 기록 판 30,000회로 다시 정한 잃은 점과 원래 판 잃은 점의 겹침 비율 |

- 수 ±5 %, 값 ±2 %p 안이면 '원래 판과 같은 판'으로 적는다. 넘어도 멈추지 않고 보고서 맨 앞에 적는다.

## 4. 단계 2: 확인 1~4

- 저장된 30,000회 모델과 메시(두 판)만 쓴다.
- 칸 ①②는 잃은 점에, 칸 ③은 잃은 결과 점에 분류를 붙인다.
- 대조 점에도 같은 분류를 붙여 배율을 낸다.

### 4.1 확인 1: 하락이 진짜인가

판별 순서: 마 → 나 → 가 → 다 → 라

| 분류 | 판별 조건 |
|---|---|
| 1-마 면 없음 | 측정선이 찾는 길이(지붕 10 m, 벽 5 m) 안에서 결과 면을 만나지 못함 |
| 1-나 측정 방식 차이 | 최근접 거리 ≤ τ인데 법선 측정선 거리 > τ |
| 1-가 문턱 근처 | τ < \|s\| ≤ 2τ |
| 1-다 다른 물체에 닿음 | 처음 만난 결과 면의 자리가 다른 참값 면(그 점이 놓인 면이 아닌 위 구조물, 벽)까지 τ 안 |
| 1-라 떠 있는 면 | 위 넷이 아님 |

- 칸 ③은 결과 점에 가, 나, 라만 쓴다(나는 결과 점에서 참값까지의 최근접 거리).
- 더 낼 것: τ 0.5·1·1.5·2배에서 칸마다 목표면 → 학습 뒤 하락 폭. 잃은 점의 \|s\| 50·68.3·95 % 값.
- 다음 확인으로 넘기는 점: 1-다, 1-라, 1-마(칸 ③은 1-라).

### 4.2 확인 2: 목표가 학습에 들어갔나 (칸 ①②만)

판별 순서: 가 → 나 → 라 → 다 → 마 → 바

| 분류 | 판별 조건 |
|---|---|
| 2-가 목표 없음 | 그 점 기둥에 사전정보 패치가 없거나, 그 패치의 목표가 없음 |
| 2-나 목표 틀림 | 그 패치 목표면까지 그 점의 법선 측정선 거리 > τ |
| 2-라 관측 부족 | 보는 영상 < 3장 |
| 2-다 가려서 안 들어감 | 보는 영상 가운데, 그 점이 투영되는 화소의 목표 깊이 지도 값이 그 점의 패치에서 온 영상 < 3장. 목표 깊이 지도는 판이 실제로 쓴 코드(가장 앞 패치 원반)로 만들고 화소마다 출처 패치 id를 함께 낸다 |
| 2-마 무게 약함 | 2-다에서 센 영상의 절반 넘게에서 그 화소의 정밀도 무게가 하한 0.1 |
| 2-바 전달됨 | 위 다섯이 아님 |

- 더 낼 것: 잃은 점과 대조 점의 보는 영상 수, 목표가 들어간 영상 수, 정밀도 무게의 분포.

### 4.3 확인 3: 누가 그리나

- **그리는 가우시안:** 보는 영상마다 그 점이 투영되는 화소에서 α×T가 가장 큰 가우시안을 찾고, 영상들 가운데 가장 자주 나온 개체를 쓴다(PROCFIG 계보 방법). 칸 ③은 결과 점에서 같은 방법으로 찾는다. 이때 보는 영상은 결과 메시로 깊이 시험을 한다.
- 1-라 점(칸 ③은 모든 잃은 결과 점)은 아래 판별 순서 가 → 나 → 다 → 라 → 마로 나눈다.

| 분류 | 판별 조건 |
|---|---|
| 3-마 확인 불가 | 가장 자주 나온 개체가 보는 영상의 절반 미만(먼저 판별) |
| 3-가 같은 패치에 묶임 | 그 개체가 그 점 기둥의 패치에 묶여 있음 |
| 3-나 이웃 패치에 묶임 | 다른 패치에 묶여 있음 |
| 3-다 풀림 | 패치 출신이고 묶여 있지 않음 |
| 3-라 배경 | 배경 출신 |

- 1-다, 1-마 점은 아래 둘로 나눈다.

| 분류 | 판별 조건 |
|---|---|
| 3-바 묶인 것이 남음 | 30,000회에 그 점의 패치에 묶인 가우시안이 있고, 그 가운데 하나 이상이 그 점까지 법선 거리 τ 안 |
| 3-사 묶인 것이 없음 | 그렇지 않음 |

- 더 낼 것:
  - 3-가에서 그 개체 중심의 목표면까지 거리와 허용 구간 폭. 구간 안에서 τ 밖인지, 원반 기울기 때문인지(중심은 τ 안) 나눈다.
  - 50쪽의 61~73 %를 고정 반경과 패치별 반경(허용 구간 + 0.5 m) 두 가지로 다시 세고, 대조 점의 같은 비율과 배율을 나란히 둔다.

### 4.4 확인 4: 어느 단계에서 생기나

- 대상: 1-라 점, 3-바 점, 칸 ③의 잃은 결과 점.
- 보는 영상마다 렌더 깊이로 3차원 점을 만들고, 그 점의 법선 방향 거리 n·(X − p)로 셋을 가른다. τ 안이면 맞음, τ 밖이면 틀림, 렌더 불투명도가 0.5 미만이면 빔이다.
- 같은 광선에서 FLOATDIAG의 네 깊이(참값, 목표, 학습 렌더 깊이, 메시 첫 교차)를 함께 적는다.

판별 순서: 마 → 라 → 나 → 가 → 다

| 분류 | 판별 조건 |
|---|---|
| 4-마 확인 불가 | 보는 영상 < 3장 |
| 4-라 렌더 빔 | 보는 영상의 절반 넘게 빔 |
| 4-나 시점 의존 | 두 영상 묶음 모두 2장 이상이고, 묶음마다 다수결(맞음/틀림)이 다름 |
| 4-가 추출 단계 | 보는 영상의 절반 넘게 맞음인데 메시는 틀림 |
| 4-다 학습 단계 | 보는 영상의 절반 넘게 틀림 |

- 칸 ③에서 맞음·틀림은 결과 점 자리(조각 면)를 렌더 깊이가 재현하는지로 본다. 재현하면 학습 단계, 재현하지 않으면 추출 단계다.

### 4.5 교차표

- 칸 × 판마다 1 × 2, 2 × 3, 3 × 4 교차표(점 수와 비율)를 낸다. 3 × 4가 "어느 무리가 어느 단계에서"의 답이다.
- 범인 후보 표: 3-가~라 가운데 잃은 점의 50 % 이상이고 배율 2 이상인 분류. 없으면 '후보 없음'으로 적는다.

## 5. 단계 3: 확인 5 — 왜 그 자리인가

- 단계 1의 기록 판에서 한다.
- 잃은 점을 기록 판 30,000회로 다시 정하고, 4.3의 방법으로 그리는 개체를 찾는다.
- 3-나, 3-다, 3-라인 개체마다 아래로 나눈다.

판별 순서: 가 → 나 → 다 → 라 → 마

| 분류 | 판별 조건 |
|---|---|
| 5-가 이웃 목표에 끌림 | 30,000회에 이웃 패치에 묶여 있고, 중심이 그 패치 목표면의 τ 안 |
| 5-나 위 물체 면의 연장 | 결과 메시를 이웃 면 각 30° 이하, 간격 0.1 m 안으로 이은 조각으로 나눌 때, 그 개체 자리의 조각 넓이의 30 % 이상이 다른 참값 면까지 τ 안 |
| 5-다 태어난 자리에 머묾 | 태어난 자리와 30,000회 자리 사이 거리 ≤ τ. 처음 개체와 복제·분할 자식으로 나눠 적고, 자식은 부모가 태어날 때 자리도 적는다 |
| 5-라 광도 손실에 끌림 | 움직인 거리 > τ이고, 30,000회 중심이 MVS 면까지 τ 안이며, 태어남부터 최종 자리 τ 안에 처음 든 반복까지 저장 반복의 위치 기울기 크기 합이 사진 손실 > 깊이 손실 |
| 5-마 그 밖 | 위 넷이 아님 |

3-사 점은 그 패치에 묶였던 개체의 행방을 사건 기록으로 나눈다.

| 분류 | 판별 조건 |
|---|---|
| 5-바 지워짐 | 지우기 사건이 있음. 까닭(불투명도 문턱, 세계 크기, 화면 크기, 그 밖)별로 센다 |
| 5-사 풀려서 떠남 | 풀림 사건 뒤 범위 안 다른 자리에 있음. 30,000회 자리의 칸과 높이 차를 적는다 |
| 5-아 범위 밖 | 범위를 나감 |

- 더 낼 것: 주요 반복 12개 메시에서 잃은 점의 τ 안 비율 곡선(언제 잃는가). 범인 무리의 반복별 수.

## 6. 단계 4: 확인 6 — 빼면 회복되나

### 6.1 모의 (학습 없음)

- 4.5의 범인 후보마다 한다. 저장된 30,000회 모델(두 판)에서 그 칸의 기록 범위 안 그 분류의 가우시안을 불투명도 0으로 둔다. 그 뒤 모든 학습 영상을 다시 렌더하고, 같은 메시 규칙으로 메시를 다시 만들어 채점한다.
- 4-나가 그 칸 잃은 점의 50 % 이상이면, 마주 본 묶음 영상만으로, 또 비스듬한 묶음 영상만으로 메시를 다시 만들어 센다. 4-가가 50 % 이상이면 보는 영상 가운데 틀림인 영상을 빼고 메시를 다시 만들어 센다. 메시 규칙은 바꾸지 않으며 진단으로만 쓴다.
- 결과마다 잃은 점의 회복률, 대조 점 손실(%p), 장면 정확성 손실(%p)을 낸다.

### 6.2 확인 학습

- 장면 × 판마다, 6.1에서 회복률 20 % 이상인 범인 후보 가운데 회복률이 가장 큰 하나에 대해서만 한 판을 돈다. 최대 네 판이다. 해당이 없으면 돌리지 않고 적는다.
- 개입 스위치는 참값을 쓰지 않으며 장면 전체에 건다. 진단 판임을 이름과 보고서에 밝힌다.

| 범인 분류 | 스위치 | 하는 일 |
|---|---|---|
| 3-라 배경 | `--jbgs_bind_background on` | 100회 점검마다 묶이지 않은 배경 가우시안 가운데 재할당 규칙(목표 패치 기둥 안, 그 목표의 허용 구간 + 0.5 m 안)을 만족하는 것을 그 패치에 묶는다. 이후 패치 출신과 같은 규칙을 받는다 |
| 3-다 풀림 | `--jbgs_rebind_released on` | 100회 점검마다 풀린 가우시안 가운데 재할당 규칙을 만족하는 것을 다시 묶는다 |
| 3-나 이웃 | `--jbgs_reassign_same on` | 재할당할 패치를 원래 패치와 판정이 같고 목표 높이 차가 원래 패치의 허용 구간 안인 패치로 한정한다. 없으면 풀린다 |

- 판 이름 `cf_<단위>_<사전 정보>_<own|gt>_<bindbg|rebind|reassign>_s0`. 그 밖의 조건은 3.1의 판과 같고 기록은 끈다.
- 판이 끝나면 같은 메시 규칙으로 메시를 만들고, 세 칸과 장면 전체를 센다. 회복률, 대조 점 손실, 장면 정확성 손실, PSNR을 원래 판과 나란히 낸다.

### 6.3 분류

| 분류 | 판별 조건 |
|---|---|
| 6-가 원인 확인 | 회복률 ≥ 50 %이고 대조 점 손실 ≤ 2 %p, 장면 정확성 손실 ≤ 2 %p |
| 6-나 원인이나 부작용 | 회복률 ≥ 50 %이고 손실 가운데 하나가 2 %p 초과 |
| 6-다 일부 원인 | 20 % ≤ 회복률 < 50 % |
| 6-라 원인 아님 | 회복률 < 20 % |

모의와 확인 학습에 따로 붙인다.

| 단계 2가 끝나면 | `..._확인1-4_<월일>-<시분>.zip` |
| 기록 판마다 | `..._기록_<판 이름>.zip`(대조 표, 상태와 사건 목록, sha256) |
| 단계 3이 끝나면 | `..._확인5_<월일>-<시분>.zip` |
| 단계 4가 끝나면 | `..._확인6_<월일>-<시분>.zip` |
| 모두 끝나면 | `PHD-MAIN-TRAINERR-v1.zip`(보고서, 표, 그림, 설정, 바꾼 줄, SHA256SUMS) |

- 보고서 `docs/experiments/phd/main_trainerr_v1/보고.md`(8천 자 안). 맨 앞에 적을 것:
  1. 재현과 기록 판 대조에서 기준을 넘은 것.
  2. 칸 × 판마다 확인 1~4의 가장 큰 분류와 그 비율.
  3. 범인 후보 표와 3 × 4 교차표의 가장 큰 칸.
  4. 확인 5의 가장 큰 분류.
  5. 확인 6의 분류와 회복률.
  6. 기대와 다른 것.
- 묶음을 낼 때마다 작업 대화에 묶음 이름과 핵심 다섯 줄(숫자 위주)을 남긴다. 사실만 쓴다.

## 8. 보내기 전 점검

- [ ] 첫 계산 전에 설정을 잠갔다.
- [ ] 0.1 표의 열두 값을 재현했거나, 다른 값을 보고서 맨 앞에 적었다.
- [ ] 한 번호 안의 분류를 판별 순서대로 하나씩만 붙였고, 대조 점에도 붙여 배율을 냈다.
- [ ] 새 판이 기본값에서 r23, `--jbgs_targets`만 주면 r25와 같은 결정을 내리고, 기록과 기울기 기록이 결정을 바꾸지 않음을 보였다.
- [ ] 기록 판 네 판의 대조 표를 냈다.
- [ ] 개입 스위치와 학습에 참값을 쓰지 않았다.
- [ ] 모든 표에 그림과 json이 있다.

## 부록. 결과를 읽는 법 (분석 세션용, 결과 전에 정함. 코딩 에이전트는 쓰지 않는다)

| 결과 | 읽기 |
|---|---|
| 1-가 + 1-나 > 50 % | 그 칸의 하락은 주로 채점 문턱과 방식 탓이다. 개선 대상이 아니라 원고에서 τ 민감도와 함께 적는다 |
| 1-다 > 50 % | '떠 있는 면'이 아니라 '위 물체 아래를 비운 것'으로 고쳐 부른다 |
| 2-가 또는 2-나가 가장 큼 | 판정은 맞았지만 목표가 없거나 틀렸다. 목표 만들기를 고친다 |
| 2-다가 가장 큼 | 앞 패치 목표가 가려 그 점의 목표가 학습에 들어가지 않았다. 목표 깊이 지도 규칙을 고친다 |
| 2-라가 가장 큼 | 영상으로 관측되지 않는 자리다. 범위·한계로 적는다 |
| 2-마가 가장 큼 | 목표는 들어갔으나 무게가 약하다. 정밀도 무게를 본다 |
| 3번 범인 후보가 하나 | '판정이 맞은 곳의 틀린 면은 ○○ 가우시안이 그린다'(배율과 함께) |
| 범인 후보가 없음 | 원인이 한 무리로 모이지 않는다. 분류별 비율을 그대로 적는다 |
| 4-가가 가장 큼 | 표면 추출 단계의 문제다. 학습 쪽 고침보다 추출 쪽을 먼저 본다(메시 규칙을 바꿀지는 사용자 결정) |
| 4-나가 가장 큼 | 특정 시점에서만 앞을 덮는 가우시안이 생긴다. 그 시점 묶음의 학습을 본다 |
| 4-다 또는 4-라가 가장 큼 | 가우시안 장면 자체의 문제다 |
| 5번 가장 큰 분류 | 가: 재할당 조건, 나: 가장자리 처리, 다: 초기화와 밀도 제어, 라: 광도와 깊이 무게를 고칠 곳으로 본다 |
| 6-가 | 원인 확인. 그 개입을 개선 설계의 출발점으로 쓴다 |
| 6-나 | 원인이지만 무리 전체를 바꾸면 맞는 면도 해친다. 무리 안에서 고르는 규칙이 필요하다 |
| 6-다, 6-라 | 원인이 더 있거나 다른 곳이다. 교차표의 다음 칸을 본다 |

11/18까지 채울 문장: "판정이 맞은 곳에서 학습이 잃는 면은 ○○ 무리의 가우시안이 ○○ 단계에서 ○○ 때문에 만든 것이며, 그 무리를 ○○하면 잃은 점의 ○○ %가 회복된다."
