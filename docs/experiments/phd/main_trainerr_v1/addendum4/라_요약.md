# 일 라 요약: 고쳐진 자리의 면은 무엇이 그리는가

scientific_verdict: null. 표는 `tables/ra_*.csv`, 점별 값은 payload `addendum4/ra/draw_<장면>.npz`다.

## 셈 방법

- **무리:** 고친 점은 판단 메시는 τ 밖이고 FINALTRAIN 30,000회는 τ 안인 점이다. 지킨 점은 둘 다 τ 안, 둘 다 틀림은 둘 다 τ 밖인 점이다.
- **표본:** 장면마다 무리별로 2,000점을 뽑았다(씨앗 0).
- **영상:** 점마다 렌더링 깊이가 그 점 깊이에 가장 가까운 학습 영상 셋을 골랐다.
- **무게:** 그 화소의 렌더링 무게 가운데 참값 깊이 ± τ 안에 있는 가우시안의 무게(αT)를 종류별로 나눴다.
  - 같은 목표 = 그 점의 기둥 패치에 묶인 것
  - 다른 목표 = 다른 패치에 묶인 것(이웃 패치 포함)
  - 풀린 것
  - 묶이지 않은 것
- **모델:** FINALTRAIN 30,000회다.

## 무게가 가장 큰 가우시안의 이력 (기록 판; `tables/ra_history_<장면>.csv`)

**판:** B0 × LoD2는 TRAINLOG 기록 판(장면 저장 65개), R1 × 항공 LiDAR는 TRAINERR 기록 판(장면 저장 13개)이다. 고친 점 화소마다 τ 안 무게가 가장 큰 가우시안 하나를 셌다.

|---|---:|---:|
| 가우시안 수 | 1,719 | 1,186 |
| 처음 놓인 자리 – 참값 거리 중앙값 | 0.095 m | 0.090 m |
| 처음 놓인 자리가 참값 0.2 m 안 | 74.4 % | 74.8 % |

| 30,000회 묶임 / 풀림 / 묶이지 않음 | 86.2 / 6.7 / 7.0 % | 60.9 / 30.3 / 8.9 % |
| 참값 0.2 m 안에 처음 든 저장 상태 중앙값 | 10,500 | 10,000 |
| 한 번도 0.2 m 안에 들지 않음 | 9.7 % | 13.2 % |

- **같은 uid:** 기록 판은 FINALTRAIN과 다른 학습이다. 이력은 기록 판 30,000회 모델에서 같은 규칙으로 고른 가우시안이다.
- **'처음 0.2 m 안에 든 상태':** 저장 상태 간격이 거칠다. 그래서 '처음 놓인 자리가 0.2 m 안'과 함께 읽어야 한다.
