## 읽을 때 꼭 알아야 할 것

- **기록 판 채점 규칙:** TRAINLOG B0 기록 판의 옛 `score.json`은 정확성 규칙이 옛 판이다(완전성은 같다). 덧붙임 4에서 같은 메시를 지금 규칙으로 다시 채점했다(`tlre_*`). 사-2 비교는 모두 같은 규칙이다.
- **사-2 장면 정확성(30,000회):** 사-2 73.1 % 대 기록 판 79.0 %다. 벽은 76.7 % 대 83.7 %다.
- **사-3 입력:** 발주문 정의 그대로는 만들 수 없었다. 판정이 목표·씨앗·기준점에 박혀 있고, 학습 코드는 영상마다 목표 지도를 하나만 받는다. 그래서 가장 가까운 정의로 했다(issues.md). 깊이 손실 둘째 항(r32)을 더하고 모든 패치를 '보존'으로 두었다. 발주문의 124 m² 판과는 입력 만드는 법이 다르다.
- **GPU 비결정성:** 다시 학습한 판은 원래 판과 바이트까지 같지 않다(사-1 대 기록 판: 바닥 띠 묶인 것 152 대 153). 값마다 판 이름을 적었다.
- **사건 수 맞추기:** `ga_balance2_*`(가우시안별 차례 셈)를 쓴다. 모든 자리·창의 잔차가 0이다. 첫 셈 `ga_balance_*`는 버렸다.
- **무리가 작은 자리:** B0 가장자리 띠의 일 나 무리는 0~17개다.
- **사-2 가장자리 띠:** 사-2와 기록 판 모두 묶인 가우시안이 0~1개다. 그래서 두 판의 차이는 볼 수 없다.

## 추가 판 (11-16 04시까지 모두 들어옴)

v1 때 '진행 중'이던 값이 모두 들어왔다. 판은 설정 `addendum4_c.json`·`addendum4_c2.json`(잠금)이다.

| 채운 값 | 학습 판 | 어디 |
|---|---|---|
| 일 나: B0 가장자리 띠·별채의 불투명도 기울기 부호, 3,500회 값 | sb1·sb2 (6,000회) | `나_요약.md` '추가 판', `na_*_sb1`·`na_*_sb2` |
| 일 가 2.3: 7,000회 뒤 손실별 위치 기울기 | sb5 (30,000회 부호 기울기) | `가_요약.md` '7,000회 뒤 (sb5)', `ga_grad_normal_sb5` |
| 일 라: R1 × LoD2, B173 × LoD2 이력 (여섯 장면) | sb3·sb4b | `라_요약.md` 이력 표, `ra_history_*` |
| 일 마·바: 덩어리 여섯의 단계별 단면·곡선 (여섯 단계) | sb3·sb4b | `마_요약.md` '추가 판', `ba_ma_*` |

- **B173 × LoD2:** sb4는 14,000회 건강 점검(수 세기만 하는 점검)으로 멈췄다. 그래서 점검만 끈 sb4b로 다시 학습했다(issues.md).
- **무리 크기:** sb1·sb2에서도 B0 가장자리 띠 무리는 0~10개로 작다.
- **FINALTRAIN 값:** 추가 판 열을 더한 그리기 파일에서도 FINALTRAIN 열은 앞 파일과 바이트까지 같다. R1 × LoD2 앞 파일은 덮어쓴 뒤 묶음에서 되살렸다(issues.md 11-16 02시).
- **설정:** 추가 판 설정은 `configs/phd/main_trainerr_v1/addendum4_c.json`이다(잠금). 방법 설정과 규칙은 바꾸지 않았다(r31, 스위치 기본값 = r30).
