## 읽을 때 꼭 알아야 할 것

- **기록 판 채점 규칙:** TRAINLOG B0 기록 판의 옛 `score.json`은 정확성 규칙이 옛 판이다(완전성은 같다). 덧붙임 4에서 같은 메시를 지금 규칙으로 다시 채점했다(`tlre_*`). 사-2 비교는 모두 같은 규칙이다.
- **사-2 장면 정확성(30,000회):** 사-2 73.1 % 대 기록 판 79.0 %다. 벽은 76.7 % 대 83.7 %다.
- **사-3 입력:** 발주문 정의 그대로는 만들 수 없었다. 판정이 목표·씨앗·기준점에 박혀 있고, 학습 코드는 영상마다 목표 지도를 하나만 받는다. 그래서 가장 가까운 정의로 했다(issues.md). 깊이 손실 둘째 항(r32)을 더하고 모든 패치를 '보존'으로 두었다. 발주문의 124 m² 판과는 입력 만드는 법이 다르다.
- **GPU 비결정성:** 다시 학습한 판은 원래 판과 바이트까지 같지 않다(사-1 대 기록 판: 바닥 띠 묶인 것 152 대 153). 값마다 판 이름을 적었다.
- **사건 수 맞추기:** `ga_balance2_*`(가우시안별 차례 셈)를 쓴다. 모든 자리·창의 잔차가 0이다. 첫 셈 `ga_balance_*`는 버렸다.
- **무리가 작은 자리:** B0 가장자리 띠의 일 나 무리는 0~17개다.
- **사-2 가장자리 띠:** 사-2와 기록 판 모두 묶인 가우시안이 0~1개다. 그래서 두 판의 차이는 볼 수 없다.
