## 사건 수 맞추기 (`tables/ga_balance_<판>.csv`)

창마다 시작 + 생김 + 들어옴(재할당·범위) − 제거 − 풀림 − 나감(재할당·범위) = 끝을 셌다. 자식은 물려받은 목표가 자리 안일 때만 '생김'으로 센다.

- **잔차:** 창이 길수록(500·2,500회) 크다. 한 창 안에서 한 가우시안에 사건이 여럿 겹치는 경우를 세는 규칙이 없다.

## 2.3 손실별 위치 기울기의 목표 법선 성분 (사-1, `tables/ga_grad_normal.csv`)

- **값:** −∂L/∂x · n_바깥(경사 하강 방향, + = 바깥·카메라 쪽)이다. 그 반복의 영상에서 기울기를 받은 표본만 셌다.
- **바깥 쪽 비율(%) — R1 바닥 띠, 광도 / 깊이:**

| 창 | 6,000회 전에 풀린 것 | 끝까지 묶인 것 |
|---|---|---|
| 0–200 | 48.7 / 50.0 | 48.6 / 46.6 |
| 200–1,000 | 48.5 / 50.1 | 50.5 / 46.7 |
| 1,000–3,000 | 43.3 / 51.6 | 45.3 / 43.1 |
| 3,000–6,000 | 35.9 / 39.8 | 51.2 / 39.0 |

- **대조 바닥:** 같은 창에서 41~53 %다.
- **크기에서 법선 성분이 차지하는 몫:** 중앙값 0.63~0.93이다. 접선 성분 중앙값은 법선 성분 평균 절댓값보다 한 자릿수 이상 작다.
- **2DGS 정규화 항:** 0~6,000회에 기울기가 0이다. 거리 항 무게는 0이고, 법선 항은 7,000회 뒤에 켜진다.
