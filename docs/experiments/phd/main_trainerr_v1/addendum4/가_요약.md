## 사건 수 맞추기 (`tables/ga_balance2_<판>.csv`)

**셈 방법:** 저장 상태 사이 창마다, 그 창에 사건이 있거나 시작·끝에 자리 목표에 묶여 있던 가우시안을 하나씩 따라갔다.

- 시작 상태의 묶임에서 출발해 사건을 차례대로 적용했다.
- 묶임이 바뀐 사건만 종류별로 셌다.
  - 들어옴: 생김 · 재할당 · 범위 들어옴
  - 나감: 제거 · 풀림 · 재할당 · 범위 나감
- 생김과 범위 사건은 목표를 기록하지 않는다. 그 목표는 창 안 다음 사건의 이전 목표로, 없으면 끝 상태의 목표로 정했다.
- 끝 상태와 다시 따라간 끝이 다르면 '기록 없는 들어옴/나감'으로 따로 센다.

| 자리 · 판 | 창 | 들어옴 / 나감 | 잔차 (기록 없는 들어옴 / 나감) | 차례 어긋남 |
|---|---:|---|---|---:|
| R1 바닥 띠 · 사-1 | 102 | 3,325 / 4,750 | 0 (0 / 0) | 3 |
| 대조 · 사-1 | 102 | 27,990 / 29,545 | 0 (0 / 0) | 4 |
| R1 바닥 띠 · 기록 판 | 64 | 5,319 / 6,800 | 0 (0 / 0) | 4 |

- **모든 창:** 시작 + 들어옴 − 나감 = 끝이 맞는다.
- **차례 어긋남:** 사건에 적힌 이전 목표가 다시 따라간 묶임과 다른 경우다. 전체 사건 수에 비해 아주 적다(최대 31).
- **첫 셈(`ga_balance_<판>.csv`):** 사건 종류마다 따로 셌다. 그래서 한 창 안에서 한 가우시안에 사건이 여럿 겹치면 두 번 세거나 빠뜨렸다. 이 셈으로 바꾼다(파일은 남김).

## 2.3 손실별 위치 기울기의 목표 법선 성분 (사-1, `tables/ga_grad_normal.csv`)

- **값:** −∂L/∂x · n_바깥(경사 하강 방향, + = 바깥·카메라 쪽)이다. 그 반복의 영상에서 기울기를 받은 표본만 셌다.
- **바깥 쪽 비율(%) — R1 바닥 띠, 광도 / 깊이:**

| 창 | 6,000회 전에 풀린 것 | 끝까지 묶인 것 |

| 200–1,000 | 48.5 / 50.1 | 50.5 / 46.7 |
| 1,000–3,000 | 43.3 / 51.6 | 45.3 / 43.1 |
| 3,000–6,000 | 35.9 / 39.8 | 51.2 / 39.0 |

- **대조 바닥:** 같은 창에서 41~53 %다.
- **크기에서 법선 성분이 차지하는 몫:** 중앙값 0.63~0.93이다. 접선 성분 중앙값은 법선 성분 평균 절댓값보다 한 자릿수 이상 작다.
- **2DGS 정규화 항:** 0~6,000회에 기울기가 0이다. 거리 항 무게는 0이고, 법선 항은 7,000회 뒤에 켜진다.
