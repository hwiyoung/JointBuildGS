## 4.3 실제로 없는 면을 내는 화소 (`tables/da_wrong_*.csv`)

**계산 방법:**

- 30,000회 메시의 틀린 결과 점에서 2,000점을 뽑았다(씨앗 0).
- 렌더링 깊이가 그 점 깊이 0.1 m 안인 영상을 점마다 최대 셋 골랐다. 이것이 '그 점을 만든 영상'이다.
- 깊이 구간은 틀린 면 −0.5 m 앞 / ±0.5 m / 뒤다.
- '무엇을 그리던 것'은 그 가우시안 중심에서 가장 가까운 참값 점의 종류다. 1 m 넘으면 '참값 1 m 밖'이다.

| | 남쪽 끝 벽 뒤 0.64 m+ (기록 판) | 별채 지붕 아래 1 m+ (바-3) | 대조: 별채 지붕 맞게 나온 점 |
|---|---|---|---|
| 틀린 점 전체 / 뽑음 / 영상을 찾은 점 | 117,179 / 2,000 / 469 | 83,076 / 2,000 / 287 | 23,775 / 2,000 / 1,395 |
| 화소 평균 무게: 앞 / 그 깊이 / 뒤 | 0.47 / 0.36 / 0.15 | 0.16 / 0.42 / 0.11 | 0.07 / 0.72 / 0.08 |
| 그 깊이 무게 < 0.5인 화소 | 64.7 % | 60.3 % | 15.6 % |
| 그 깊이 무게의 종류: 묶임 / 풀림 / 묶이지 않음 | 27 / 5 / 68 % | 0 / 2 / 98 % | 0 / 0 / 100 % |

| 앞 무게가 그리던 것 (같은 순서) | 5 / 84 / 0 / 10 % | 20 / 7 / 0 / 74 % | 13 / 48 / 13 / 26 % |

- **남쪽 끝 벽, 중앙 깊이:** 그 점 0.1 m 안에 중앙 깊이가 오는 화소는 1.3 %다. 그 화소들의 그 깊이 무게는 0.88이다. 나머지 화소는 앞 0.47 / 그 깊이 0.35 / 뒤 0.15다.
- **영상을 찾은 점:** 2,000점 가운데 남쪽 끝 벽 469점, 별채 287점만 그 점 깊이 0.1 m 안의 렌더링 영상이 있었다.
- **첫 셈 버림:** 남쪽 끝 벽 첫 셈(거리 하한 없음)은 버렸다(issues.md).
