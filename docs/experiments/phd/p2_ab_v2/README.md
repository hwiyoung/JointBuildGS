## 연구 질문과 작업 분담

현재 영상 기하도 불완전하거나 부정확하고, 과거 3D 자산의 시간적 유효성과 상대
정합도 미확인된 조건에서, 두 소스의 오차와 관측 한계를 고려한 사용 판단과
재구성으로 현재 영상 기반 3D 복원의 품질을 어떻게 개선할 수 있는가?

준거는 [필요성 r7.1](../thesis_topic_v1/01_NECESSITY_ko_v1.md)의 R1~R4와
[연구 공백·차별성](../thesis_topic_v1/02_GAP_ko_v1.md)의 §2.5~2.7이다.
현재 영상 복원의 결손·오류 보완, 양립 영역의 정밀도 향상, 현재 텍스처와 관측
가능한 세부 복원, 기존 양호 영역의 열화 통제를 함께 다룬다.

| 작업 | 이번 역할 | 확인할 내용 |
|---|---|---|
| A | 근접 원문 문헌조사와 판단 방법 설계 | 오류·정합·시기차·관측불충분을 구분한 적격성 및 선택·보정·융합·유보; 기존법 대비 추가 계산과 검증 의무 |
| B | 재구성 방법 설계·동일 P2의 실제 gsplat 개발 비교 | 같은 prior 초기 표현에서 구조 유지·현재 외관·세부의 갱신 및 기존법 대비 효과를 각각 측정 |
| 공통 | 원자료·관측 규모·표현·평가 연결 | 역할·좌표·원점 계보, 충분한 해상도, 실제 Gaussian 화면, 같은 평가 분모와 누락 |

A의 새 설계를 실제 사용 판정으로 실행·보정한 것처럼 B에 넘기지 않는다. B의
독립 시험은 source와 구조 조건을 사전 지정한 조건부 개발 비교다. A의 실제
판단을 인계하는 통합 검증에서는 그 조건을 자료로 확보했는지를 별도로 검증한다.

## v1 보존과 수정 출발점

[v1 해석 정정](CORRECTIONS_ko_v2.md)을 먼저 따른다. 작은 후보·96-step 실행과
변수 고정을 연구 방법 전체의 실패로 해석하지 않는다. 기존 v1 수치·실행 폴더·
문서를 덮어쓰지 않고 v2를 별도 저장한다. 새 판단·재구성 방법의 독창성은 검증할
후보이며, 연구 목표나 데이터 계보 기록 자체를 방법적 기여로 주장하지 않는다.
