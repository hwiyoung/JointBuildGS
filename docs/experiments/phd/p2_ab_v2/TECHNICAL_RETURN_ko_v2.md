## 연구 질문에 맞춘 범위

목표는 두 소스에 오류·결손·시기차가 있을 때, 과거 자산을 적절히 사용하여 현재

[공백](../thesis_topic_v1/02_GAP_ko_v1.md) §2.5~2.7을 따른다.

| 작업 | 이번 산출물 | 해석 범위 |
|---|---|---|
| A | 근접 원문 6편, 판단 계산·이론 전제·강한 비교·오채택/유보 평가·B 인계 설계 | 새 보정 판단이나 P2 판단 성능 실측은 아직 없음 |
| B | 동일 ALS G0의 7조건, 별도 MVS G0의 영상 기준선, 표현 밀도 2조건, prior 이동 2조건 | source 사용을 사전 가정한 독립 solver 개발 비교 |
| C | 공통 영상 분모, 별도 UAS 참조, 구조/외관/세부 구분, 실제 Gaussian 및 사진 연결 | 개발 자료의 기술 검증; A의 신규 판단을 사용한 전체 방법 검증은 후속 단계 |

A는 조건부 포함관계에서 사용오차 상한이 따르는 관계를 설명하고, 그 관계의 실제
전제인 대응·공유오류·가림·연속 가능집합의 포함성은 별도로 입증해야 함을 정리했다.
가능집합이나 유보의 존재 자체를 신규성으로 주장하지 않는다. B도 강한 논문 전체를
재현한 비교가 아니라 동일 초기화·손실 계열에서 구성 요소를 분리한 비교다.
두 소스가 모두 유효한 양립 영역에서 결합 정밀도를 높이는 FUSION은 A의 설계에
포함했지만 이번 B 12조건으로 실험한 항목은 아니다. 계보·미확인 상태의 기록도
보정된 불확실성이나 상태 보고의 신뢰성이 검증되었다는 뜻은 아니다.

## 입력과 공정 비교

같은 P2 48×46m prism의 552개 셀과 native ALS 45,986점·MVS 330,679점을 보존했다.
원RGB 5280×3956에서 66개 영상을 다시 undistort/crop했으며, B는 고정 33 train/11 eval
뷰를 사용했다. B의 MVS 초기화는 0.12m voxel 처리 후 266,361개이므로 native 원점
전부를 초기화에 사용한 것은 아니다. ALS 초기화는 45,986개, 표현 4분할은 183,944개다.
이들은 과거 개발에 사용된 영상이며 독립 확증 세트가 아니다.

수정 비교는 `CORRECTED-NATIVE-v1` 8조건, `CORRECTED-REPRESENTATION-v1` 2조건,
`CORRECTED-PRIOR-SHIFT-v1` 2조건이다. 각각 2,048회 예산을 사용한다. ALS 기반 주
7조건은 같은 초기 상태를 사용하고, soft prior 가중치는 사전 선언한 0.005/0.05/0.5다.
prior 이동은 동일 ALS에 Z+1m를 적용한 상대 정합 통제이며 시기 변화 검증은 아니다.
정확한 초기화·변수·손실·학습률·조건부 관측 분모는
[수정 B 반환](B_CORRECTED_TECHNICAL_RETURN_ko_v2.md)에 기록한다.

원소스와 UAS의 참조거리 기준선은 renderer와 별개로 계산했다.

|---|---:|---:|
| ALS 45,986점 | 0.2471 / 4.8215 | 3.7115 |
| MVS 330,679점 | 0.0873 / 0.4541 | 0.5080 |

기존 numeric frame의 참조거리이며 datum/epoch·참조 피복과 정확도가 완전히 보정된
현재 사용 판정은 아니다. 큰 거리만으로 낡은 prior나 오류 원인을 확정하지 않는다.
원점과 여러 뷰에서 추출한 표본의 밀도·가중이 달라, 두 p90의 차이만으로 GS 변형의
기여량을 분해하지 않는다. [전체 거리·계산 기록](SAMPLE_NN_PERFORMANCE_ko_v2.md)을 보존했다.

## 먼저 바로잡은 구현과 결과의 유효 범위

v2 첫 실행의 geometry auxiliary는 RGB의 screen-only 저역 필터 기여도 실제 평면
교차의 지지로 사용했다. 거의 평행한 실제 광선에서 부당한 수천 m 깊이가 생겼고,
그 깊이가 관측 마스크와 기하 손실에도 들어갔다. 따라서 그 12조건은
`INVALID_FOR_METHOD_CONCLUSION`으로 보존하고 최종 비교에서 제외한다. 앞선 UI QA의
PASS는 저장한 값·사진을 제대로 표시했다는 뜻이며 기하 계산의 정확성 보장은 아니었다.

별도 gsplat adapter에서 RGB 합성과 plane-hit 기하 합성을 분리했다. 기하의 깊이·
법선·존재는 자체 투과율과 유효 mass를 사용한다. 조기 종료·포화·정규화 미분도 함께
검사했다. 최종 31개 기술 검산이 통과했고, 5변수 수치 미분의 최대 절대차는
0.000163615였다. 실제 361번 문제 광선은 4261.009m에서 183.898m로 바뀌었고,
해당 전체 화면의 RGB/alpha는 기존과 byte 동일했다. 원래 overlay는 수정하지 않았다.

이 복구 자체를 학술적 차별성이나 재구성 성능 향상으로 주장하지 않는다. 여러 유효
표면의 기대깊이는 실제 한 표면과 다를 수 있고, tile culling·중심깊이 순서·orientation
축의 부호 모호성도 남는다. Gaussian 중심의 제한과 추출 표면의 구조 보존도 구분한다.

## 최종 평가 결과

수정된 12조건을 고정 공통 영상 분모와 같은 UAS 참조에서 평가했다.
지표 정의와 해석 한계는 [C 평가 프로토콜](C_EVALUATION_PROTOCOL_ko_v2.md)을 따른다.
초기/최종/참조의 모든 조건이 함께 존재하는 동일 stencil과 전체 참조 결손 분모를
함께 사용하며, 표면 존재는 RGB alpha와 구분한 `geometry_mass≥0.5`로 계산한다.

**외관:** 같은 5,150,892개 평가 픽셀에서 native 구조 제한 조건은 초기 MAE
0.20035→0.19456, PSNR 11.556→11.672dB였다. 자유 최적화의 최종 MAE 0.19421보다
더 좋지는 않았고, 기하 고정·색만 최적화는 0.20909로 악화했다. 색 고정·기하 갱신은
0.18928로 더 낮았다. 따라서 사진 오차 감소가 곧 색 학습의 이득이나 올바른 세부
복원의 증거가 아니다. 실제 영상에도 지붕·벽의 흐림이 남았다.

**구조:** native 구조 제한 조건의 거친 최대 이동은 0.15000004m, 세부 이동 RMS는
0.07288m로 실제 변수 제한·세부 갱신이 확인됐다. 그러나 초기 지지에서 8,979픽셀이
사라지고 290,371픽셀이 추가됐고, 유지된 ray 깊이 변화의 뷰 평균은 1.05455m였다.
같은 변화의 픽셀 가중 평균은 0.75474m이며, CSV는 이 가중 평균을 기록한다.
기하 고정 조건만 깊이·기하 mass와 실제 변수가 정확히 유지됐다. 현재 구현은
거친 변수 제한을 출력 표면·경계·위상의 구조 보존으로 연결하지 못했다.

**현재 기하와 세부:** native 구조 제한 조건의 UAS 참조거리 p90은
4.9644→4.9807m로 악화했지만, 고정 참조점의 0.5m 이내 회복률은 63.98→64.64%로
조금 늘었다. 0.5m 공통 stencil의 국소 높이 잔차 RMSE는 1.8403→1.8975m로
악화했다. 0.25/1m에서도 각각 1.7813→1.8091m, 2.1368→2.3995m로 늘었다.
세부 자유도가 실제로 움직였어도 이번 진단에서 참조와 더 일치하지는 않았다.
이는 2.5D 높이 진단이며 벽·겹층·표본 밀도와 참조 잡음의 영향을 포함한다.
용마루·창·배관 등 특정 세부의 복원 성패를 직접 검증한 수치는 아니다.
