## A 해석 정정

- v1은 후보 전체를 33개 scene-Z 높이로 옮긴 사진 점수 구성요소다. 복수 대응·가림·
  공동 카메라 오차·연속 외측범위를 포함한 원래 판단 solver의 완성 실행이 아니다.
- 가능집합이 실제 형상을 포함하면 그 집합의 최대오차로 후보 오차를 제한할 수 있다는
  조건부 논리는 있지만, 사진으로 만든 실제 집합의 포함성은 증명·보정하지 않았다.
  구현의 단위 검사는 이 전제를 검증하지 않는다.
- 공유 이동 상한 0.5 m를 기존 상한에 더하면서 허용오차도 0.5 m로 둔 기본 조건은
  원래 상한이 0일 때만 채택 가능하다. 허용오차 0.25 m에서는 채택이 불가능하다.
  전수 유보를 실용성이나 안전성의 증명으로 해석하지 않는다.
- 관측 1쌍 통제에서 최소 3쌍 규칙을 유지한 결과 역시 결측 처리 검사다.
- 43,008행은 같은 64개 공간단위의 측정을 조건·문턱별로 반복한 행 수다.
- 작은 후보·64점 제한·관측 선택의 영향은 크기/해상도 대조 없이 원인으로 확정할 수 없다.
- 기존 [A 결과 사례](../p2_ab_v1/A_TECHNICAL_RETURN_ko_v1.md)의
  `P2_X066_Y043` 원점수 `약0.008`은 오기다. 동결 출력의 SCORE/RANGE 원점수는
  `-0.1021896116`이다. Bayesian 분리쌍은 별도 곡선의 사후질량 약 `0.548<0.9`로
  유보했다. 이 정정은 저장된 행동과 주요 집계를 바꾸지 않는다.

## B 해석 정정

| 축 | v1에서 확인한 것 | 해석의 범위 |
|---|---|---|
| 기하 유지 | fixed/constrained 최종 기하가 초기와 동일 | 고정·갱신 거부에 의한 보존. 세부 복원과의 동시 달성 입증이 아님 |
| 외관 | 모든 A 인계에서 별도 평가뷰 RGB MAE 개선 | Gaussian별 SH0 색 적합의 개선. 고해상도 텍스처 복원 전체가 아님 |
| 세부 | prior-loss 비교법에서 Z 변위 발생 | 제안 constrained의 detail·slope·방향·증감은 꺼져 있었고 세부 복원은 검증되지 않음 |

RANGE의 기하 후보 갱신 72회가 모두 거부된 사실은 확인했다. 하지만 로그는
누적 횟수만 남기므로 각 거부의 원인을 확정할 수 없다. 모든 학습뷰에서 표면 존재
mask의 한 픽셀 변화도 허용하지 않은 규칙이 강한 제약인 것은 코드로 확인되지만,
기존 본문의 “72회 모두 경계 때문에”는 원인별 로그로 입증된 표현이 아니다.
다른 A 인계는 예산 미산출로 처음부터 기하를 고정했다. 따라서 fixed와 같다는
결과로 재구성 방법의 추가 이득 부재를 판정할 수 없다.

## 뷰어와 후속 작업

v1 3D 화면은 expected-depth를 역투영한 점 표본을 `THREE.Points`로 표시한다.
실제 Gaussian은 학습·저장됐지만 화면은 크기·방향·불투명도·학습 색을 사용하지 않았다.
UI 작동 QA와 Gaussian/텍스처의 정성 평가 적합성을 구분한다.

v2는 A 문헌·판단 설계와 B 조건부 재구성 개발을 독립적으로 진행한다. B의 실험조건을
가정한 비교와 A가 실제 자료로 그 조건을 확보한 통합 결과를 구분한다. 같은 P2에서
관측 규모와 실제 변수를 확인하고, 구조·텍스처·세부의 개선과 열화를 각각 평가한다.
기존 결과를 삭제하거나 새 방법의 결과로 재명명하지 않는다.
