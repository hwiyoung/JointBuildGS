## 1. 상위 질문과 A의 역할

**목표는 기존 자산으로 현재 항공영상 복원의 결손·오류를 보완하고, 양립 영역의 정밀도를 높이며, 이미 양호한 영역의 열화를 통제하여 현재 기하·외관을 개선하는 것이다.**
일반적인 분류 정확도나 prior 보존량 자체가 목적이 아니다. A는 사용할 기하와 그 범위를 판단하고, B는 그 판단을 일관된 기하·현재 외관·관측 가능한 세부로 실현한다.
보존 대상은 prior 전체가 아니라 **사용 판단이 지지하는 기하**다. 근거 있는 정합 보정·융합·세부 수정도 허용해야 한다.

상위 질문은 공백 §2.5를 따른다: 현재 영상 기하와 과거 외부 자산의 오류·관측 한계를 고려한 사용 판단을 현재 기하·외관 개선으로 실현할 수 있는가? 기존 방법과 그 조합보다 추가 계산이 필요한 조건은 무엇인가?
A의 하위 질문은 **현재 영상 기하도 부정확하거나 없을 때, 과거 자산의 현재 적합성과 각 후보의 기하오차를 무엇으로 제한하고 선택·보정·융합·유보할 것인가**다.
R1은 이 판단, R2는 후속 재구성, R3는 출처·확인 범위의 보조 정보, R4는 판단과 최종 개선·열화의 검증에 대응한다.

## 2. 의미 흐름: 무엇을 보고 어떤 결정을 내리는가

1. **입력과 결손의 계보를 확인한다.** 현재 사진, 명목 카메라, 영상 유래 MVS, 과거 prior를 구분한다. MVS 없음·후처리 제거·기하 부적합·관측 불충분을 같은 결손으로 묶지 않는다.
2. **불일치의 설명을 분리한다.** 실제 시기 변화, 각 소스의 측정·처리 오류, 상대 정합, 관측 불가, 표현 규모 차이를 함께 검토한다. 차이가 크다는 사실만으로 원인을 하나로 확정하지 않는다.
3. **같은 현재 표면을 검정할 근거를 정한다.** 사진의 가림·대응·시차·질감과 정합의 미확정 성분을 확인한다. 현재 MVS와 같은 영상의 잔차를 독립 증거 두 개로 세지 않는다.
4. **후보 자체의 현재 사용 적정성을 평가한다.** 상대적으로 더 나은 후보여도 요구 기하오차를 충족하지 못하거나 확인할 수 없으면 채택하지 않는다. MVS가 없을 때도 prior 자체를 검사한다.
5. **선택·보정·융합·유보를 정한다.** 정합 보정은 근거와 불확실성을 갖춘 후보의 새 버전을 만드는 과정이다. 네 최종 행동과 혼동하여 다섯 번째 출처로 만들지 않는다.
6. **B에 기하와 판단 범위를 함께 넘긴다.** 직접 확인한 점·면 성분, 구조 가정에 따른 추론, 현재 미확인 영역을 구분한다. 외관 학습이나 잔차 감소만으로 기하 채택 권한을 확대하지 않는다.
7. **영상 복원의 순개선을 평가한다.** 결손 보완·오류 수정·정밀도 향상과 기존 양호 영역의 열화, 유효 prior의 불필요한 유보를 함께 본다.

원인을 항상 식별하는 알고리즘을 전제하지 않는다. 원인 이름을 확정하지 못해도 후보 사용오차가 제한되면 해당 성분을 사용할 수 있고, 반대로 원인 추정이 그럴듯해도 사용오차는 미확정일 수 있다.

## 4. 기존 계산에 무엇을 더하며, 왜 필요한가

아래는 **설계 가설**이다. 강한 확률법이나 순차법이 같은 기능을 충분히 제공하면 추가 방법의 필요성은 줄어든다.

| 검사 상황 | 점수·차이만으로 남는 질문 | 추가 계산 후보 | 반증·축소 조건 |
|---|---|---|---|
| prior가 잘 맞고 다른 높이도 잘 맞음 | prior가 정확한가, 단지 여러 설명 중 하나인가 | 복수 대응/기하 분기를 유지하고 후보의 요구오차 밖 대안이 남는지 계산 | 같은 대안을 보존한 Bayesian/기존 confidence가 같은 오류–유보 관계를 달성하면 range 추가이득 없음 |
| MVS가 없지만 prior는 존재 | 검정할 현재 관측이 남는가, prior만 남았다는 이유로 채택하는가 | MVS를 요구하지 않는 현재 사진 대응·경계·가시성 제약으로 prior 자체를 검사 | 자연 결손에서 유효 prior를 더 활용하지 못하거나 오채택이 늘면 목적 달성 못함 |
| 두 소스가 잘 일치함 | 공동 편향 때문에 함께 틀릴 수 있는가 | 정합·카메라의 공동 변수와 근거 있는 절대 좌표 오차를 전달 | 절대 좌표를 구별할 근거가 없으면 해당 성분은 미확정. 일치로 이를 0으로 만들지 않음 |
| 불일치와 가림이 함께 있음 | 현재 표면 차이인가, 다른 표면을 대조했는가 | 대상 표면 대응과 허용 결측/가림 분기를 함께 유지 | 가림 분기를 무제한 허용해 항상 모든 후보가 살아남으면 식별 불가로 축소 |
| 두 입력이 현재 유효하며 잡음이 있음 | 실제 결합이 단일 소스보다 정밀한가 | 공유오차를 포함한 결합 후보의 오차를 직접 평가 | 독립성 가정에서만 이득이 나거나 공동 편향이 남으면 정밀도 향상 주장 불가 |
| 국소 판정은 좋고 최종 표면은 나빠짐 | 판단한 지지·오차가 재구성에서 보존되는가 | 같은 성분의 오차 여유와 표면 추출 후 보존 검사를 B에 전달 | 같은 판단을 쓰는 단순 표면 선택·텍스처링이 같거나 좋으면 더 복잡한 재구성 축소 |

## 5. 판단 모형의 구체화

**후보와 상태.** 고정 후보 `g_I`, 정합 버전을 고정한 `g_P`, 실제 생성한 `g_F`를 분리한다. 후보 없음, 같은 현재 표면에 대한 유효성, 후보 자체의 기하오차, 관측 불충분을 별도 필드로 둔다.
MVS가 부재/사용불가면 `PRIOR/ABSTAIN`만 가능하다. prior를 지지하는 현재 관측이 없다는 이유로 prior가 틀렸다고 확정하지 않는다.

**대상과 지원 규모.** 출력·평가 단위와 사진 대조 영역을 구분한다. 2m 단위 안 64점이 충분한 사진 지지라는 전제를 두지 않는다.
동일 표면의 문맥을 더 넓게 검사할 수 있지만, 다른 층·경계 너머를 조용히 합치거나 넓은 검정의 지지를 전부 출력 면적으로 복사하지 않는다.
비교 후보와 방법에는 동일한 검정 지점·관측 목록·영상 해상도·검색 범위 원칙을 제공하고, 원소스 점/교점 계보와 제외 이유를 남긴다.

**사진·공동 오차에서 현재 위치로.** 관측 `D`에서 대응 영역 `E`, 허용 대응/가림 상태 `A`, 공동 카메라·정합 범위 `C`, 장면 범위 `W`를 만들고 `Z(D)`를 정의한다.
변수는 검정 지점의 현재 3D 위치 `X_j`, 공동 카메라/좌표 상태 `c`, 대응·가림 분기 `a`다. prior 전체를 같은 Z값으로 이동하는 형상만 허용하지 않는다.
각 대응 분기의 영상 영역은 한 peak만 남기기보다 복수 후보와 결측을 보존한다. 대응 영역의 크기는 점수만으로 정하지 않고 허용 보정 자료에서 실제 대응을 놓치는 비율과 함께 검증한다.
정합은 안정 근거의 선택, 자유도, 강건 추정, 잔여 공분산/범위를 분리한다. 작은 정합 잔차를 안정 영역의 현재성 증명으로 순환 사용하지 않는다.
공동 카메라 변수 하나가 관련 지점·뷰의 제약을 함께 만족해야 한다. 서로 다른 관측마다 편리한 독립 보정을 허용하지 않는다.

**연속 외측 계산안.** 고정 카메라와 대응 원판에서는 기존 재투영 원뿔 제약으로 시작하고, 카메라·위치 구간과 대응 분기를 나눠 보수적 투영 경계를 계산한다.
구간 전체가 필수 제약을 만족할 수 없음을 확인한 경우만 제거한다. 미탐색 구간·투영 특이점·경계 밖 가능성은 남긴다.
원래 제약을 만족하는 해의 존재와 외측 집합 `Z_hat ⊇ Z`를 구분한다. 외측 집합이 비어 있지 않아도 실제 가능한 해를 찾은 것은 아니다.
이는 [재설계 §3.3](../thesis_topic_v1/03_METHOD_REDESIGN_ko_v1.md#evidence-3-3)의 미완성 solver를 구체화할 경로이며, 이번 문헌조사에서 구현·검증했다고 하지 않는다.

**적격성과 선택.** 동일 고정 지지와 오차척도에서 각 후보의 하한·상한 또는 보정된 예상오차를 계산한다. 둘 중 상대적으로 좋은 후보를 고르는 단계보다 절대적 사용 적정성 검사가 먼저다.
`ABSTAIN`은 후보 전부 부적합, 미관측/미보정, 계산 미완료, 후보 부재를 구분해 기록한다. 재관측 필요와 기하 제거/빈 공간 확정은 다르다.
`FUSION`은 부모가 같은 현재 표면의 유효한 증거라는 근거와 실제 결합 후보의 오차·이득을 요구한다. 부모 각각의 단독 출력이 최종 ε를 통과해야 한다는 조건과는 구분한다.
이 구분은 필요성 §1.1의 정밀도 향상을 위한 v2 설계 수정안이다. 기존 r3.7/v1의 더 보수적인 양부모 단독 통과 규칙은 보존하며 비교 대상으로 둔다.
공유 편향은 평균으로 사라지지 않는다. 결합 가중·정합·대응을 바꿨다면 결합 후보의 동일 지지 오차를 다시 계산한다. prior에 현재 색을 입히는 것만으로 `FUSION`이라 부르지 않는다.

## 6. 이론적 관계와 실제로 검증해야 할 전제

**조건부 명제.** 같은 정의역·지지·오차척도 `L`에서 실제 상태 `z* ∈ Z(D) ⊆ Z_hat(D)`이고 `U_s ≥ sup L(g_s,z)`이면, `U_s≤ε`에서 `L(g_s,z*)≤ε`가 따른다.
이는 포함관계와 상한의 정의에서 바로 나오는 함의다. 최대값을 쓴다는 사실의 독창성, 사진으로 만든 집합의 신뢰성, 확률적 coverage를 증명하지 않는다.
확률적 포함성을 주장한다면 `P(z*∈Z_hat)≥1−α`의 데이터·모형·선정 조건부터 명시해야 한다. 주변 포함확률이 곧 채택된 부분의 조건부 오채택률 α라는 뜻도 아니다.

| 검증 의무 | 확인 방법 | 확인하지 못하면 |
|---|---|---|
| 입력 모형이 참 대응·가림·공동오류·장면을 포함 | 별도 허용 보정 자료와 이후 검증 자료에서 포함성/실패율·관측조건별 이탈 분석 | 보정된 사용오차 주장 불가; conditional 진단으로 남김 |
| 외측 solver가 참 가능해를 삭제하지 않음 | 해석 가능한 선형/고정카메라 예제에서 정확 집합과 대조; 구간 분할·퇴화·경계·복수해 수치검산 | 격자값을 연속 상한으로 부르지 않음 |
| 실제 가능한 해가 존재하고 허용 밖 대안도 정당하게 처리됨 | witness의 원제약 재검사, 외측 relaxation만 남은 경우와 미탐색 구간 분리 | 빈/가짜 가능집합으로 지지·반대 확정하지 않음 |
| 공유오류가 허위로 줄지 않음 | 같은 관측 복제 시 정보 증가 금지, 공동 이동/축척의 불변성, 오차를 넓히면 상한이 작아지지 않는지 검사 | 해당 방향 미확정; 독립쌍만으로 절대 calibration을 대체하지 않음 |
| 판단과 B 표면오차의 척도가 일치 | 동일 위치 대응·성분·표면 추출 규칙에서 보존 오차 검산 | `U_height`를 3D면 변형예산이나 NN3D p90 보장으로 전달하지 않음 |

**식별성 확인 예시.** 현재 관측이 `y=x+b+e`, `|e|≤η`, `|b|≤r`만 알려 주면 `x∈[y−η−r,y+η+r]`이고 어떤 고정 후보도 최악오차를 `η+r`보다 작게 만들 수 없다.
공유 `b`의 근거 있는 한계가 없으면 영상 잔차를 줄여도 절대 위치를 제한하지 못한다. 서로 다른 현재 위치와 공동 카메라 변환이 같은 투영을 만들 수 있기 때문이다.
이 예는 합성·이론 검산의 대상이며 P2가 이 오차 모형을 따른다는 실증이 아니다. **현재 v1 자료만으로 실제 포함성은 입증되지 않았다.**

## 8. 강한 비교와 후속 실험

**두 비교를 분리한다.** A의 추정·판단 효과는 같은 후보·현재 관측·오차척도·재구성을 고정하고 비교한다. 전체 방법은 원법에 필요한 입력과 본 조건용 변경을 명시한 강한 순차 재구성과 비교한다.

| 비교군 | 구체적 계산·원출력의 처리 |
|---|---|
| 고정 소스/정합 prior/단순 합집합 | 영상만·prior만·근거 있는 정합 prior·합집합. 자동 판단 이득과 prior 투입 자체의 효과를 분리 |
| 강한 score/confidence | 현재 patch 대응·가시성·일관성 검정을 포함한 순차법. 단순 NCC는 하위 ablation. Qin식 변화 판정의 원형과 기하오차/유보 어댑터를 분리 |
| 강한 Bayesian | 같은 복수 대응·공동 카메라 변수를 모델링하고 주변화한 posterior에서 후보의 허용오차 내 확률·예상오차를 계산. 단봉 근사·공유오류 생략·분리쌍만의 효과를 각각 분리 |
| 강한 순차 정합→검정→갱신 | 적용 가능한 GNC/기존 정합과 불확실성, Wu–Vallet식 광선·피복 처리, 동일 표면 추출. 입력 계보·센서 mesh/trajectory 가용성 차이를 공개 |
| 제안 외측범위 | 같은 입력 모형과 제한된 계산 예산에서 남은 대안·상한·미완료를 명시. Bayesian과 다른 목표량임을 밝히고 실제 위험–채택범위로 비교 |
| 평가 전용 local oracle | 고정 후보군에서 선택으로 개선할 여지가 있는지 확인. 단일 정답 출처를 강제하지 않고 둘 이상 유효한 경우를 허용 |

소스마다 별도 사진 집합을 유리하게 선택하거나 제안에만 정합/가림 처리를 더하지 않는다. 같은 비용함수에 추가 계산만 바꾸는 비교와, 실제 사용할 전체법의 비교를 모두 둔다.
Bayesian을 보정 없이 약한 비교로 두지 않으며, 원논문과 다른 posterior/행동 어댑터를 원법 재현으로 부르지 않는다. solver 시간·메모리·종료 오차와 지원 면적도 함께 보고한다.

**자료 역할.** 현재 P2와 기존 66뷰는 개발 자료다. 현재 UAS·LoD2 평가 기하를 A의 정합·대응 보정·문턱 선택에 사용하지 않는다.
포함성/오차 보정에는 별도로 허용된 보정 자료가 필요하며, 그것이 없으면 미확보로 표시한다. 보정용·개발용·최종 독립 장면을 구분하고, 같은 사진 계보의 의존성도 기록한다.
실제 사례와 통제 조건은 `영상 충분/불충분 × prior 현재유효/낡음 × 정합 양호/불량`에 양소스 자체 오류·자연 결손을 추가한다. 합성 주입으로 현실 빈도나 일반화를 주장하지 않는다.

**평가량.** 전체 고정 지지에서 결손 복구·오류 수정·양립 영역 정밀도 변화·양호 영역 열화, 채택 중 참조판별 가능한 오채택, 유효 후보가 있는데 유보한 비율을 함께 측정한다.
참조 미피복·대응 모호함은 unknown으로 남기고, 채택0의 오채택률은 null이다. 점수·점 개수·XY bbox 면적·실제 표면면적을 같은 분모로 쓰지 않는다.
판단 오류척도와 같은 성분으로 calibration/포함성을 검사한 뒤, 최종 표면의 양방향 거리·고정 참조 완전도·경계·현재 외관을 별도로 평가한다.

**반증 기준.** oracle에도 국소 선택 이득이 없으면 그 표본에서 복잡한 source arbitration의 필요성을 줄인다. 선택 여지는 있으나 허용 관측으로 구별하지 못하면 유보/추가 관측으로 범위를 좁힌다.
강한 기존 조합이 같은 개선·열화·유보 관계를 달성하면 새 계산의 기여를 주장하지 않는다. 판단 개선이 B 이후 사라지면 전체 재구성 개선으로 주장하지 않는다.
