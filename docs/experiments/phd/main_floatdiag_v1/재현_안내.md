# 단계 가 재현 안내

실행 지시는 지정한 발주문 v3.1과 이 대화의 사용자 추가·변경 지시다. 묶음의 다른 문서는 참고 자료로만 사용했다. 원래 데이터, 기존 학습, 관문 정의와 단계 나 미실행 결정을 유지했다. `scientific_verdict: null`.

프로젝트 계산은 Docker에서만 했다. `scripts/phd/main_floatdiag_v1/launch.py`는 실행 Bash와 코드·설정 스냅샷을 보존한다. 큰 CPU 작업과 GPU 작업은 기존 LOSSTRAIN 잠금·자원 조건을 쓴다. 환경은 `jointbuildgs:dev`, 학습·렌더는 `jointbuildgs:geogs-conf-guided-v1`, 오프라인 브라우저 확인은 `jointbuildgs:geogs-viewer-browser-v2`다. 각 실행의 입력 해시·출처·명령은 `provenance/` 및 외부 산출물의 `logs/`, `launches/`, `runs/`에 있다.

처리 순서는 `recount.py` → `geometry.py`·`render_gpu.py`·`select_photos.py` → `gaussians.py`·`diagnose_gpu.py`·`reduce_diagnostics.py`·`photo_metrics.py` → 사례 판·보기다. 원래 15,000/30,000회와 조건부 저장본은 `formation_gpu.py` → `formation_cpu.py` → `formation_residuals.py` → 생성 과정 그림으로 계산한다. 이미 완료한 경로를 다시 실행하면 덮어쓰기를 거부한다.

추가 네 깊이는 `four_depth_gpu.py`, `four_depth_cpu.py`, `depth_provenance.py`, `verify_tsdf_saved_depth.py`로 남겼다. 모든 학습 사진 확인은 `multiview_cpu.py`와 `multiview_figures.py`다. 대표 화소의 사진 수와 전체 패치 화소의 힘 비율은 서로 다른 분모이며 `multiview_measurement_v1.json`에 잠갔다. `check_multiview.py`는 저장 배열에서 분모와 집계를 별도로 확인한다.

`check_tsdf_update.py`는 실제 후처리와 같은 Open3D 0.19.0 런타임에서 수행했다. GPU가 필요 없는 작은 합성 평면 시험이다. Open3D 원문·해시·시험 배열을 묶음 ②에 포함했다.

`fd_dynnow_ALS_s0`와 `fd_current_ALS_s0`는 최초 승인한 두 조건부 실행이다. 기존 손실의 3,100회 STOP은 보존했다. 사용자가 이후 승인한 `fd_current_ALS_s0_record_only`는 별도 경로에서 한 번만 실행하며, 유한한 낮은 불투명도 중단만 기록 전용으로 둔다. NaN·실행 오류와 나머지 원래 검사는 유지한다. 변경은 실행 래퍼에만 있으며 원래 r17 파일을 고치지 않았다. 세 실행 모두 진단용이고 메시 성능을 채점하지 않았다.

핵심 측정과 사례 그림 스크립트는 `--prior ALS|LoD2`를 받는다. LoD2 선택 시 외부 출력과 문서는 각각 `.../PHD-MAIN-FLOATDIAG-v1/LoD2/`, `docs/.../main_floatdiag_v1/LoD2/` 아래에 분리한다. 결과 이름·입력 지도·사례 설정은 해당 사전 정보로 찾으며, 없는 저장본·입력·설정은 오류로 남긴다. 이번 발주에서는 LoD2를 실행하지 않았다. 조건부 학습과 이번 최종 보고서·전달 조립은 승인한 ALS 작업 전용이다. 미래 LoD2 실행에는 그 작업의 입력·설정 잠금과 별도 발주가 필요하다.

큰 그림·GLB·영상은 Git에 넣지 않고 외부 ZIP의 SHA-256과 구성 파일 목록으로 고정한다. 300 dpi 원본 그림은 묶음 ②, 다각도 캡처·영상은 먼저 전달한 묶음 ①, 줄이지 않은 PLY와 계산 배열은 별도 분할 자료에 있다. Git에는 설정·스크립트·표·보고서·그림 메타데이터·검증과 전달 명세를 남긴다. 전달 목록의 모든 파일은 CRC와 SHA-256을 다시 읽어 확인한다.
