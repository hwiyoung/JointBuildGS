사진마다 보는 추가 확인

사진 수는 각 결과 자신의 뜬 면 패치 첫 만남 점을 투영한 대표 화소에서 센다. 힘 비율은 기존 관문의 전체 패치 화소 중 실제 렌더가 참값+τ 위인 화소에서 센다. 두 분모는 다르다. 기존 관문 정의·값은 그대로다. 사진 수는 가림으로 사진을 제외하지 않으며 동일 물리적 표면의 사진 관찰을 증명하지 않는다.
