최종 판단에 쓰는 여러 patch/영상쌍의 집계값과 구분한다. UAS 거리는 선택 고정 후
native inlier로 평가한 수치다. 반복 무늬·평면 표현의 영향은 가능한 원인이며
개별 원인의 기여도를 분리 검증한 결과는 아니다.

그림 파일은 [전체 실행 보고서](RESULT_ko_v1.md)의 같은 cell_id 링크로 연결된다.
각 파일은 PNG/PDF 두 형식이고 원영상 ID·선정 규칙·마스크·비용 재현 provenance가
외부 payload의 `figures/figure_manifest.json`에 기록돼 있다.

요약 그림, P1 셀 16, P2 셀 5/120/195, P3 셀 43 및 P2/P3 전체 지도를 직접 검수했다.
공통 관측이 없는 셀에는 임의의 비교 영상을 넣지 않았다. 빈 변위 곡선의 legend 경고는
로그에 남겼으며 해당 셀의 관측 부재를 그대로 표현했다.

현재 증거가 지지하는 후속 구현은 복수 표면 후보와 광선 기준 후보 대응이다. P3의 큰
이격 띠 대부분이 보류인 지도와 P1의 관측 부족은 판단 가능한 영역 자체를 넓혀야 함을
보여준다. 별도 patch NCC를 곧바로 비교하는 대신 후보별 지지/반증/미관측을 먼저
평가하고, 실제 공통 관측이 있을 때만 소스 간 직접 비교를 더해야 한다.
