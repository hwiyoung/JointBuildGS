# 판별과 구조 정제를 어떻게 비교하고 연구 초점을 정할 것인가

2026-09-09 · `scientific_verdict: null`

## 1. 사용자 해석의 주장별 검토

| 주장 | 판정 | 이유 |
|---|---|---|
| 사용할 정보를 적절히 정하고 그것이 실제 복원에 도움이 되는지 확인해야 한다 | 연구 목적에 부합 | 다만 지역별로 한 소스를 고르는 명시적 분류기가 필수라는 뜻은 아니다. 위치·방향·세부·외관에 서로 다른 증거를 쓰거나 손실·제약에서 암묵적으로 조절할 수도 있다 |
| 기존 방법은 판별→재구성과 선구조→후정제로 양분된다 | 유용한 관찰이나 배타적 분류로는 부정확 | 전자는 증거 선택을, 후자는 구조 활용과 정제 순서를 강조한다. 한 방법 안에 함께 존재할 수 있고 판별이 재구성 결과로 갱신될 수도 있다 |
| 최근 연구는 선구조→후정제로 이동했다 | 관련 계열의 중요성은 확인; 분야 전체의 이동은 미입증 | GeoGS 같은 단계적 구조 정제가 있는 동시에 SurfFill의 선택적 보완과 Cross-Temporal 3DGS의 반복 신뢰도 갱신도 있다. 기간·모집단을 정의한 체계적 추세조사는 하지 않았다 |
| 가까운 구조 정제 방법이 덜 집중한 중요한 부분을 뾰족하게 잡아야 한다 | 타당한 연구 전략 | 전체 분야의 대세임을 증명할 필요 없이, 우리 입출력·목적과 가까운 강한 방법을 기준으로 연구할 관계를 정할 수 있다 |
| 그러려면 선구조→후정제의 실패부터 확정해야 한다 | 필요조건 아님 | 중요한 적용 가정과 해결·검증 범위의 경계도 연구 질문의 출발점이다. 실제 실패나 새 방법의 개선을 주장하는 단계에는 그 주장에 맞는 증거가 필요하다 |

여기서 ‘판별’은 변화 검출, 신뢰도 추정, 감독 선택, 수정 허용, 결과 채택을 구분해야 한다. 이들을 모두 ‘더 좋은 소스 판별’로 합치면 각 논문이 무엇을 결정했는지 흐려진다. ‘coarse-to-fine’ 역시 영상 해상도, 구조→세부 정제, 분할 일정, 추출 필터의 세밀화를 구분한다.

## 2. 가까운 방법의 실제 정보 흐름

다음은 **분류를 위한 문헌 종합**이다. 각 방법의 세부 기여·평가는 기존 카드 또는 [추가 카드](NEW_SOURCE_CARDS_ko_v1.md)를 따른다. 입력이 다른 행을 동일 조건 성능 순위로 읽지 않는다.

| 방법 | 정보 흐름 | 고정·수정·후단 피드백 | 우리 질문과 비교하는 역할 |
|---|---|---|---|
| SRDM | LiDAR의 약한 유도→영상 시차→불일치 LiDAR 제외→더 세밀한 시차 추정 | 추정된 시차가 이후 prior 사용을 바꾼다. 영상 피라미드와 증거 선택이 공존 | LiDAR+영상의 직접 경쟁 구성; ‘단계가 있으므로 단방향’ 반례 |
| Zhou 2020 | LiDAR 유도 시차→부분 변화 검출→영상 재매칭→시차 비교로 변화 영역 확장→재매칭 | 중간 재구성이 검출 범위를 수정한다 | 변화·재매칭 피드백의 직접 경쟁 구성 |
| Wu 2023/Vallet 계열 | 각 센서의 파생 기하·정합→가시성·시기·품질 판정→선택·접합 | 판정 이전에도 이미 재구성이 존재한다. 선택과 최종 접합의 피드백은 개별 구현으로 확인 | mesh 선택·보완 경쟁; 원시 영상→GS와 입출력 차이 유지 |
| GS4Buildings→GeoGS | 기존 모델에 근거한 초기 구조 및 감독→영상과 기하 감독으로 정제; GeoGS는 구조 anchoring/protection과 visual refinement 분리 | GeoGS는 두 단계 모두 RGB 사용. prior/카메라/파생 깊이는 고정 입력이지만 Gaussian은 계속 추정한다. 보호는 일부 gradient 감쇠와 clone/split/prune 제한 | 구조 안정·세부 복원에 가장 가까운 비교 계열 |
| LI-GS | LiDAR→평면 GMM→surfel 초기화→GMM+영상 감독 및 기하 기반 밀도 제어→표면 추출 | 초기 구조가 감독·생성·제거·추출에도 관여. 원문의 coarse-to-fine은 추출 필터를 가리킴 | 기하 prior를 계속 사용하는 mesh 복원 경쟁; 동시 수집 조건 차이 |
| SurfFill | 보완 후보 영역 선정→집중 surfel 성장→새 점 필터링→입력 점군과 합성 | 학습 Gaussian은 수정하지만 최종 합성은 수령한 입력 LiDAR의 전 점을 보존 | 보존+결손·세부 보완의 매우 가까운 경쟁; 구조 오류 교정과는 구분 |
| CL-Splats / GaussianUpdate | 기존 GS와 새 영상→변화 또는 불변 영역 추정→국소 갱신/정제 | 전자는 mask 기반 국소 갱신. 후자는 외관 적응→기하 갱신→정제이므로 ‘구조 먼저’에 그대로 배정 불가 | 기존 색상 GS를 입력으로 하는 갱신 경쟁; 무색 외부 기하와 동등 입력 아님 |

## 3. ‘구조를 먼저 잡는다’에서 구분해야 할 두 경우

**타당하지만 거친 구조에 세부를 보태는 일과, 구조 자체의 오류를 바꾸는 일은 요구하는 수정 범위가 다를 수 있다.** 이는 우리의 문제 분석이며 기존 정제가 후자를 반드시 못 한다는 결론은 아니다. 두 상태는 같은 건물·면에 함께 존재할 수 있다.

| 조건 | 필요한 복원 | 이미 있는 해결·검증 | 더 집중해 물을 관계 |
|---|---|---|---|
| 큰 형상은 유효하나 결손·관측 가능한 세부가 부족 | 유효 정보 유지와 보완 | GeoGS의 구조 정제, SurfFill의 선택적 completion 등이 직접 겨냥 | 새로 보완한 표면의 정확성과 유효부에 미치는 영향; 이 목표 자체는 신규성 아님 |
| 기존 면의 위치·방향·존재가 부분적으로 잘못됨 | 기존 형상 수정·제거와 올바른 형상 복원 | SRDM/Zhou/Wu의 오류·변화 처리, GS 갱신 연구가 이미 있음. GeoGS도 prior·pose 교란 평가 | 구조 보호·감독이 오류 수정을 어디까지 허용하는가; 기존 정합·적응 가중·갱신 조합으로 충분한가 |
| 영상은 불일치를 보이지만 대체 표면의 정확한 3D 위치를 충분히 지지하지 못함 | 확실한 정보 범위 안의 복원과 미확인 부분 구분 | 불확실성·강건 융합 문헌과 직접 대조해야 함 | ‘기존 형상이 틀렸음을 아는 것’과 ‘정확한 대체 형상을 아는 것’이 달라지는 조건은 무엇인가 |

현재성은 위 문제의 한 조건이다. 잘못된 구조는 시간 변화뿐 아니라 측정·모델링·정합 오차로도 생길 수 있다. 반대로 눈에 보이는 차이가 모두 구조 변화는 아니다. 이 구별은 관측이 허용할 때만 가능하며, 명시적 분류기를 도입해야 한다는 전제를 두지 않는다.

## 4. 기존 성과 때문에 더 좁혀야 하는 주장

### SurfFill: 보존+보완은 이미 직접 다룬다

원문 §6.1 Table1은 필터 제거 시 정확한 영역에 허위 보완점이 유입되는 영향을 평가하고, §6.3 Fig10은 같은 초기화만 준 2DGS와 full pipeline을 비교한다. 따라서 ‘정확부 손상을 보며 선택적 보완을 검증한다’는 목표와 절차 자체는 공백이 아니다.

[공식 최종 결합 코드](https://github.com/qy21gafy/SurfFill/blob/4849b5b6bd5fb5279913f7cec8e68de09f808e90/scene/combineLiDAR.py#L4)는 수령한 입력 점군을 그대로 읽어 새 점과 합친다. **기존 잘못된 면의 점까지 입력에 포함된다면, 이 결합만으로 그 점을 삭제·이동하지 않는다는 것은 코드에서 도출되는 추론**이다. 오류 구조에서 full method의 실패를 실험으로 관찰한 결론은 아니다. 학습 Gaussian은 움직일 수 있으므로 ‘구조 전체 고정’이라고도 쓰지 않는다.

### GeoGS: 잘못된 prior를 전혀 평가하지 않았다고 할 수 없다

출판판 Table7에는 높이·XY 이동·일부 면 결손과 pose 교란이 있다. 제한된 교란에서 기하 안정성을 보인 기존 성과를 인정해야 한다. Table6의 구조 보호 ablation도 이미 존재한다.

[고정 구현 train.py](https://github.com/zqlin0521/GeoGS/blob/db40c95c657ec03ff21c83cb99cf39f4e90247a6/train.py#L804)의 RGB는 anchor부터 사용된다. 후단에도 Gaussian 위치·회전·크기는 추정 변수이며, 보호부의 gradient 감쇠는 완전 고정이 아니다. 고정한 것은 prior·파생 감독과 특정 보호 규칙이다. ‘앞단 오류를 절대 수정 못 한다’는 주장은 기각한다.

따라서 추가로 물을 것은 **부분적으로 다른 유효성, 오류 종류, 관측 조건에서 기존 보호·정제 규칙의 적절한 적용 범위가 무엇인지**다. Table7 결과만으로 이 관계 전체를 해결했다고도, 미해결이라고도 판정하지 않는다.

## 5. 제안하는 하위 연구 질문

> 부분적으로 유효한 기존 기하와 불완전한 현재 영상에서, 결손·세부 부족과 기존 구조의 오류를 어느 조건에서 구별할 수 있는가? 그 구별 가능성은 기존 구조를 이용하는 범위와 수정할 수 있는 범위에 어떤 의미를 가지며, 기존 구조 기반 정제·선택적 갱신은 이를 어디까지 처리하는가?

이 질문은 **원래 연구 목적을 대체하지 않는 유력한 하위 질문**이다. 지붕면·시간차·GS에 한정하지 않으며 현재 기하·세부·외관이라는 산출물 범위도 유지한다. 외관 관측이 구조 오류 판정에 미치는 영향과, 기하를 고친 뒤 외관도 개선되는지는 별도로 남긴다.

중요성은 재사용 기하의 안정성이 큰 장점인 동시에 수정이 필요한 정보까지 제약할 수 있다는 관계에 있다. 이를 설명하려면 ‘어느 소스가 낫다’보다 **어떤 정보가 어떤 복원 성분을 어느 범위까지 지지하는가**를 물어야 한다. 그 관계에 기존 해법으로 충분한 경우도 포함한다.

## 6. 다음 세션에서 구체화할 비교와 기각 조건

새 방법을 설계·실행하기 전에 아래 비교 명세를 문헌과 기존 증거로 구체화한다. 이번 세션에서는 실험을 시작하지 않았다.

1. **정보 조건:** 유효한 거친 구조/결손/부분 구조 오류를 구별하되 혼합도 포함한다. 정합 오차와 영상 피복·각도·텍스처의 영향을 분리한다. 단순히 sparse-view 수만 바꾸지 않는다.
2. **가까운 기준 방법:** GeoGS 등 구조 정제, SurfFill 등 선택적 보완, SRDM/Zhou/Wu 또는 입력이 맞는 갱신 방법을 비교한다. prior/카메라/원본 과거 영상의 사용 차이를 명시한다.
3. **단순 대안:** 정합·입력 정제 후 정제, prior 가중 조정, 구조 보호 완화, 기존 변화 처리 후 정제의 조합을 포함한다. GeoGS의 prior 깊이 가중과 Gaussian 보호는 독립 요인이다.
4. **결과 연결:** 오류·결손부 개선과 기존 유효부의 국소 악화를 함께 측정하고, Gaussian·렌더·추출 표면을 구분한다. currentness, 세부, 외관, 계산량을 서로 대신 쓰지 않는다.
5. **기각 조건:** 기존 방법·단순 조합이 해당 조건에서 같은 정보·예산으로 충분히 해결하면 새 제어의 필요성 주장을 줄인다. 더 정확한 판단도 최종 복원을 개선하지 못하면 판단 개선만으로 복원 기여를 주장하지 않는다. 새 결과가 오직 입력 추가·예산 증가·유리한 추출 차이에서 나오면 그 요인을 분리한다. 관측으로 식별 불가능하면 올바른 최신 형상을 얻을 수 있다고 주장하지 않는다.

가능한 기여는 기존 제약의 성공·한계를 예측하는 설명, 그 원인에 대응하는 더 나은 제어, 또는 통제된 조건에서 관계를 밝히는 경험적 규명이다. 어느 형태가 학위 기여로 충분한지는 아직 판정하지 않는다. 명시적 판단 모듈·소스 교체·공동 최적화·새 GS 표현을 먼저 선택하지 않는다.
