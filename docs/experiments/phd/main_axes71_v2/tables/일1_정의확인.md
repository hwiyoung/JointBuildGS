### 2.1 패치의 사전 정보 어긋남 — (가)

- **정의.** `gt_med`(float32)는 패치에 소유된 참값 점의 '참값 − 사전 정보' 값의 중앙값이다. 평균이 아니다(`s04_gt_v7.py:307`, 짝수 개면 가운데 두 값의 평균).
  - 지붕꼴(\|n_z\| ≥ 0.5): 참값 점에서 내린 연직선이 처음 만난 정합된 사전 정보 면의 높이 zh로 z_참값 − zh(`s04_gt_v7.py:264`). 그 패치의 가장 높은 점에서 1 m 아래까지만 남긴다.
  - 벽꼴(LoD2만): 참값 점 X와 벽 삼각형 위 가장 가까운 점 cp로 (X − cp) · n(`:292`). n은 LoD2 면 표의 법선이다. 2 m 안이고 수선의 발이 면 안이어야 한다.
  - 점 5개 이상이면 라벨을 둔다: \|gt_med\| ≤ τ면 맞음(코드 2~5), 넘으면 틀림(코드 11~14)(`:309-313`). B0는 주 참값의 라벨이 없을 때 드론 LiDAR 라벨로 채운다(`regions_v1.py:45-54`).
- **부호.** + = 참값이 사전 정보보다 위(지붕) 또는 법선 쪽(벽).
- **새 거리 지표 일 5와 같은 값.** 그 작업의 '패치의 어긋남'은 `Unit.ratio` = \|gt_med\| ÷ τ(`dm_common.py:181`)이고, 행마다 `r_ratio`로 저장했다(`d2_dist.py:122`). 영역 파일에서 다시 낸 비와 배열이 같다(여섯 경우).

### 2.2 패치의 영상 깊이 어긋남 — (나)

- **코드 3을 정한 값.** 코드 2·3(과 11·12)의 지붕꼴 패치 가운데 MVS 값이 있는 소유 참값 점이 5개 이상이면 v2 갈래, 그 밖(벽꼴, 5개 미만 지붕꼴)은 v1 갈래다(`regions.py:30-41`, 키 `v1_kept`).
  - v2: `mvs_minus_gt_at_gt` = 패치의 지붕 소유 참값 점마다 (z_MVS − z_참값)의 중앙값(`regions_v3.py:169-179`). 개수는 `n_mvs_at_gt`다. z_MVS는 상자 MVS 기하 깊이(학습 영상 모두)를 3차원 점으로 되돌려 0.1 m XY 칸에 모은 높이 중앙값이다(3점 이상, `regions_v3.py:109-139`).
  - v1: `mvs_minus_prior` − `gt_med`(`regions_v1.py:79`). `mvs_minus_prior` = −`mvs_r_med`(`:73`)이고, `mvs_r_med`는 받치는 시점의 신뢰도 1 화소의 잔차 r = (MVS 깊이 − 사전 정보 깊이) × f의 중앙값이다(`s03_stage1_v6.py:152, 370-374, 474-477`).
  - 코드 3 = \|값\| > τ, 값이 없으면 3(`regions_v1.py:81`, `regions.py:37-40`). 값이 없어 3이 된 패치는 여섯 경우 모두 0개다.
- **'영상 깊이 − 참값'인가.** 부호는 '영상 − 참값'(+ = MVS가 참값보다 위)이 맞다. 다만 카메라 깊이 방향이 아니다. v2는 연직 높이 차이고, v1은 높이 환산 f(`conversion.py:47-56`)를 거친 값이라 지붕꼴은 연직, 벽꼴은 면 법선 방향이다.
- **패치마다 있는가.** 두 갈래를 합친 값 = where(v1_kept, mvs_minus_prior − gt_med, mvs_minus_gt_at_gt)를 영역 파일만으로 다시 낼 수 있다. 빈칸 채우기의 `SL/work/obs_masked/region_<지역>_<사전 정보>.npz` 키 `v_geo`가 같은 값이다(`om.py:224-229`; 코드 2·3에서 최대 차 1.5e-5 m). `v_geo`의 화소 갈래는 코드 2~5에서만 냈으므로 코드 11·12의 벽꼴은 위 식으로 내야 한다.

## 3. 사전 정보 깊이 항과 MVS 깊이 항의 꼴

**쓰인 코드.** 본 방법 결과(`prop_*`)는 r12로 학습했다. r12→r15의 손실 경로는 기본값에서 같다.
- `rho_truncated`, `weighted_l1`은 글자까지 같다. `truncated_prior_loss`는 r13에서 `rho=None` 인자만 더했다(기본 = `rho_truncated`).
- r14·r15는 지도를 호스트 메모리에 둔 것과 OOM 기록뿐이다(`d1_terms.py`의 AST 비교, json `terms.code.compare`; FACTS65 2.6-12도 같은 결정을 확인).
- r16은 두 스위치가 0이면 r15와 같다. 한 화소 값 2,000점 × 4선에서 r15와 r16의 손실·기울기가 비트까지 같았다.
- 학습 설정(영수증 22개): λ_mvs = λ_prior = 0.05, `--jbgs_trunc_hi 4.0`, `--jbgs_depth_norm pixels`. GeoGS 원래의 LoD2·DA 깊이 손실은 0(`--lambda_lod_init 0 --lambda_lod_anchor 0 --lambda_da_depth 0`)이고 판정 경로가 단계 전환을 건너뛴다(`train.py:874-882`).

**식** (영상 v 한 장, 화소 p; D = 렌더 `surf_depth`, P = 사전 정보 깊이, M = MVS 깊이, 모두 카메라 Z 깊이 m).

- 전체: L = L_rgb + L_dist + L_normal + λ_mvs · L_mvs + λ_prior · L_prior (`train.py:876`)
- 사전 정보 깊이 항(r15 `jbgs_judgment.py:410-426`, 호출 `:1339-1343`):
  L_prior = (1/n_px) Σ_p g_p · ρ(d_p; τ_p), d = D − P, n_px = 그 영상의 화소 수(1024 × 741 = 758,784, 유효 화소 수가 아님).
  - 합하는 화소: P 유한·> 0, τ 유한, g > 0, D 유한·> 0.
  - ρ(d; τ)(`:334-337`):

| 구간 (\|d\|) | 손실 ρ | 기울기 ∂(λ_prior L_prior)/∂D_p |
|---|---|---|
| 0~τ | 0 | 0 |
| τ~4τ | \|d\| − τ | λ_prior · g_p · sign(d) / n_px |
| 4τ 넘음 | 상수 (4 − 1)τ = 3τ (0이 아님) | 0 |

  - 구간 끝: \|d\| = τ에서는 torch.clamp가 기울기를 통과시켜 λ다. \|d\| = 4τ에서는 float32 반올림에 따라 0 또는 λ다(json `*_at_edges`).
- **쓰는 τ.** 화소마다 τ 지도 `maps/tau_<사전 정보>`(`--jbgs_tau_dir`)를 쓴다. τ_p = τ_종류 ÷ max(f_p, 10⁻³)(`s03_stage1_v6.py:353, 380`).
  - τ_종류는 LoD2 지붕꼴 면 τ_지붕, 벽꼴 면 τ_벽, 건물 아닌 면 τ_지붕이다. 항공 LiDAR는 모두 τ_지붕이다.
  - f = \|n · d_ray\| ÷ \|n_z\|(지붕꼴, 연직 환산) 또는 \|n · d_ray\|(벽꼴, 법선 환산)(`conversion.py:47-56`).
  - 그래서 '\|d\| ≤ τ_p'는 '높이(지붕꼴)·법선(벽꼴) 차 ≤ τ_종류'와 같다. 손실 값은 깊이 단위이고, 높이로 바꾸면 f를 곱한다. 높이 1 m당 기울기는 λg/(n_px f)다.
  - 판정의 화소 표시는 LoD2 τ, 항공 LiDAR 2τ에서 하지만 손실의 허용 구간은 둘 다 τ다(`jbgs_judgment.py` r11 문서, `rules.py:21-23`).
- **판정 가중 g_p**(학습 전에 한 번, r15 `_g_init` `:1233-1280`, `rule.prior_term_off` `rule.py:86-93`).
  - g = 0인 곳:
    - 화소가 닿은 패치의 판정 J_loc이 충돌인 곳(지지 패치의 투표 충돌, 결측 패치의 빌린 충돌)
    - 패치 없는 화소이면서 A = 1이고 그 화소의 학습 전 표시가 충돌인 곳
  - 그 밖은 g = 1이다. 일치, 섞임, 근거 부족, 패치 없는 A = 0 화소가 여기에 든다. 섞임도 g = 1이다.
  - r6의 1 − A 가중은 g 지도가 없을 때만 쓰는 옛 길이다(`:1340`).
- **판 A(r16 `--jbgs_sw_prior_share_band 1`, `:439-447, 1462-1470`).**
  - 손실: 0~w는 0, w~4τ는 \|d\| − w, 4τ 넘음은 상수 4τ − w다.
  - 기울기: w~4τ만 λg다.
  - w_p = w_종류 ÷ max(f, 10⁻³)(`w_maps.py`). w 값과 학습 여부는 표 12에 있다.
- **판 B(`--jbgs_sw_own_depth_release 1`).** 결측 패치의 화소는 절단하지 않는다. 4τ 넘어서도 손실 \|d\| − τ, 기울기 λ다.
- **MVS 깊이 항**(r15 `weighted_l1` `:362-374`, 호출 `:1328-1330`):
  L_mvs = (1/n_px) Σ_p A_p \|D_p − M_p\|. 합하는 화소: M 유한·> 0, A > 0, D 유한·> 0.

| 구간 (\|D − M\|) | 손실 | 기울기 |
|---|---|---|
| 0~τ, τ~4τ, 4τ 넘음 (모두 같음) | λ_mvs · A_p · \|D − M\| | λ_mvs · A_p · sign / n_px |

  - 허용 구간, 절단, 높이 환산이 없다. A는 관측 신뢰도 마스크(0/1)이고, A = 0인 화소는 M이 NaN이라 항이 없다.
  - 사전 정보 항은 A를 g에만(패치 없는 화소) 쓰므로, A = 1이고 g = 1인 화소에서는 두 항이 함께 당긴다.
- **두 항 가중의 비.** λ_mvs : λ_prior = 0.05 : 0.05 = 1 : 1이다. 분모도 같은 n_px다. 당김 구간 안에서 화소 하나의 깊이 1 m당 기울기 크기가 두 항에서 같다.

**그림** `figures/일1_두항의꼴.png`(PDF, json 함께) [새로 그림].
- B173 주변 · 항공 LiDAR, τ = 14.70 cm다.
