# Wu–Vallet 재구현과 P3 개발 프로토콜

## 1. 연구 필요성에서 결과로 연결하는 질문

목표는 오류·시간차·정합 불확실성이 있는 과거 ALS와 현재 영상 기반 기하를 활용하여 사용 가능한 구조를 유지하면서 현재 텍스처와 관측 가능한 세부를 복원하는 것이다. 현재 영상이 최신이라는 사실과 영상 기하가 정확하다는 사실, ALS가 매끈하다는 사실과 지금 사용할 수 있다는 사실을 구분한다.

Wu–Vallet 2026은 **전체 연구의 주 대조군**이다. 이미 과거 LiDAR 유지·변화 영역 교체·한쪽 관측 영역 보존과 점군 갱신을 다룬다. Zhou 2020도 LiDAR-guided matching으로 미변화 기하를 보존하고 변화 영역을 갱신한다. GeoGS·GS4Buildings·ARSGaussian은 구조 prior와 영상 기반 재구성을 연결하며 CL-Splats는 기존 GS의 보존과 신규 관측 갱신을 연결한다. 그러므로 ‘기하 보완’, ‘구조 보존’, ‘현재 영상 갱신’ 또는 ‘GS 사용’ 자체를 새 기여라고 확정할 수 없다. 원문 근거와 입력 차이는 [문헌 감사](RELATED_METHODS_ko_v1.md), [주 대조군 원문 감사](WU_VALLET_REPRODUCTION_ko_v1.md)에 있다.

## 2. 실행 권한과 보존

이번 사용자는 기존 방법 재현부터 개발 실험까지 요청했다. 이전 문서의 설계 전용 상태는 당시 승인 범위이며 이번 요청의 새 비확증 개발을 막는 근거로 사용하지 않는다. 기존 E1–E6·C 계보·공식 평가 기준을 변경하거나 새 확증 성능을 승인한 것으로 해석하지 않는다. 과학적 판단은 김휘영 리뷰어에게 남긴다.

기존 작업 스냅샷: 외부 `phase-payloads/phd/wu_vallet_p3_v1/preservation_20260907T0547/`의 `preservation.json`, `preexisting_work.tar.gz`, `preexisting.diff`. 281개 수정·미추적 파일의 사전 bytes/hash를 보존했다. 기존 인계문은 방향 수정 addendum만 추가하고 이전 본문을 유지한다. 기존 필요성·공백·방법 파일과 기존 P2 실험·뷰어를 덮어쓰지 않는다. 이번 연구 재검토는 본 문서와 별도 감사/결과 문서에 추가한다. commit·push는 하지 않는다.

프로젝트 실행은 Docker로 한다. 각 실행 전에 코드·설정·필요 manifest를 외부 source snapshot으로 고정하고, 기존 artifact 전체를 읽기 전용으로 마운트한다. 새 출력과 복사한 전용 CUDA cache만 쓸 수 있다. 기존 컨테이너·GPU 프로세스를 종료하거나 기존 cache를 수정하지 않는다. 실패 시 실패 snapshot/log를 보존하고 별도 시도 경로를 사용한다.

## 3. 공통 P3 입력과 역할

P3 prism은 tile `x003_y004`, `x[-60,-20), y[-42,12), z[-49.223,-16.993)`. 작업 CRS는 EPSG:25832, local shift는 `[690953,5336071,604]m`이다. 정확 원행으로 MVS 865,108점과 ALS 52,762점을 원본까지 역추적하고 XYZ equality/hash를 검증한다. MVS는 scene-local 그대로, ALS는 기존 raw Z+45.7m 후 local shift 차감이 이미 적용되어 있다. 추가 보정은 하지 않는다. 이 scalar 수직 연결과 datum/epoch 불확실성은 미보정이다.

157개 기존 개발 영상은 `SHA256('PHD-WU-VALLET-P3-v1'+decimal image ID)` 순서로 A40, B 학습24, 외관 평가8, reserve85로 나눈다. 지표를 보기 전에 역할을 고정한다. 이 분할은 새 계산에서만 배타적이다. 157뷰는 모두 역사적으로 사용되었고 MVS·카메라가 exact937에 의존하므로 손대지 않은 독립 검증/확증 영상이 아니다. 사진을 다시 읽어 기록된 hash와 맞춘다. 원 depth grid와 K·camera ID·pixel lineage를 기록한다.

현재 UAS는 **모든 후보 생성·기하 갱신 종료 뒤** 별도 평가 드라이버에서만 읽는다. LoD2 RoofSurface/Z·평가 라벨로 소스 선택·정합·문턱 조정을 하지 않는다. 기존 terrain-MVS gravity 출처를 재사용하며 Z축을 추정 gravity라고 부르지 않는다.

## 4. 원방법부터 구현하는 범위

원 목표는 GS 없이 원래 갱신 점군까지다. 저자 저장소가 현재 404라 원문 기반 재구현을 사용한다. 원문 명시 규칙과 미기재 매개변수·구현 선택을 [대응표](WU_VALLET_REPRODUCTION_ko_v1.md)에 분리한다. 단순 M3C2 또는 NCC threshold를 Wu–Vallet 구현으로 대체하지 않는다.

첫 구성요소는 optical center와 sensor mesh를 필수 입력으로 받는 양방향 교차 분류와 원점 선택/갱신이다. 통제 장면에서 일치·소실·신규 구조·단독 피복·가림을 검산한다. 광선 샘플링과 triangle→vertex 집계의 미기재 선택은 config에 남긴다. 이 실행은 원논문의 수치 재현이 아니다.

실제 P3의 ALS에 GPS time이 있어도 촬영 궤적·scan topology가 자동으로 복원되는 것은 아니다. 미확보일 때 임의 높이에 센서를 만들어 원방법이라고 부르지 않는다. 현재 depth grid를 이용한 pixel-adjacency mesh는 기존 MVS의 재사용이며 원논문 PSMNet checkpoint를 재현한 결과와 구분한다. native topology와 미기재 처리 동등성이 남으면 **원방법 전체 P3 재현은 미완료**로 보고한다.

## 5. A와 B의 독립 비교 및 이번 개발 범위

| 비교 | 공통 제어 | 필요한 산출물 | 이번 범위 |
|---|---|---|---|
| A 판단만 변경 | 같은 후보·허용 관측·정합 설정·기하 사용 기준, 같은 하류 재구성 | 원 분류/선택·유보, false keep/remove, coverage, 원점 출처 | 주 대조군 change/update module의 통제 검산. P3 실판단 대조는 ALS sensor 입력 결속 후 |
| B 재구성만 변경 | 같은 실제 A 판단·공급 기하·지원 범위·관측·자원 | 초기/최종 표면·외관·결손·경계·세부, 구조 열화 | 현재 실행은 **공급원을 가정한 개발 진단**. 실제 A 판단을 받은 B 결과가 아님. ALS 고정 외관 대 같은 ALS의 법선 방향 제한 갱신 |
| 전체 | 같은 원입력·원방법 처리·최종 목표 | Wu 원점군과 공통 확장, 수정한 A/B의 전체 품질 | 원방법 전체 재현과 실제 A→B 인계가 미완료이면 전체 비교도 미완료 |

검토에서 멈추지 않기 위해 native input 동결, 원문 구성요소 구현·통제 실행, P3에서 실제 gsplat 개발 실행과 별도 참조 평가를 수행한다. 전제의 일부를 가정한 B 진단은 실행 가능성과 구조/외관 결합의 반응을 측정하며, 검증된 prior 채택이나 제안법 성능으로 승격하지 않는다.

B는 `mvs_color`, `als_color`, `union_color`, `als_bounded_normal` 네 arm이다. 앞의 세 arm은 각각 native voxel-selected 기하에서 SH 외관만 적합한다. 마지막 arm은 `als_color`와 같은 초기 기하·외관·view schedule에서 법선 방향 이동만 최대0.15m 허용하고 약한 원위치 비용을 준다. 0.15m는 미보정 개발 제한값이며 정확도 인증값이 아니다. 이 최초 반응을 보고 참조에 맞추어 문턱을 고르지 않는다. 기하가 알려진 것으로 가정한 비교이므로 현재 적합성을 검증하는 추가 효과는 주장하지 않는다.

실행 전 원문 component 검산을 먼저 수행한다. 각 B arm은 동일384 step·24뷰 순서를 사용한다. 생성한 Gaussian의 scale/opacity/rotation은 고정한다. appearance-only arm의 파라미터뿐 아니라 plane geometry depth/mass도 전후 동일함을 검사한다. 렌더 RGB와 교차 기반 plane depth를 분리하는 기존 검증 adapter를 사용하고 snapshot/hash를 기록한다. 이 깊이는 평면 교차의 정규화 가중평균이며 물리적 첫 표면이 아니다. 실제 실행 후 확인한 source→기대 깊이 역투영의 차이와 해석 한계는 기술 반환에 기록한다.

외관 평가는 처음의 MVS/ALS/union 렌더 지지에서 **합집합과 교집합 두 분모를 고정**한다. 없는 출력은 분모에서 삭제하지 않는다. 조건부 자기 가림이며 외부 가림 검증은 미완료다. source마다 학습 지지가 다르므로 source 간 차이는 공급원 진단이고, ALS 고정 대 ALS 갱신만 동일 source의 B 비교다. 작은 변화가 실제 세부 복원인지는 참조·독립 관측으로 확인하기 전까지 미정이다.

## 6. 표시와 정량 평가

원 MVS·ALS와 원행 출처, 처리 후 점/추출면을 같은 P3 범위에서 제시한다. 고정 단면과 실제 카메라의 target/render, 초기/최종 plane depth·alpha·존재 범위를 함께 제공한다. point scatter·projection 그림은 실제 Gaussian RGB 렌더와 이름을 구분한다. source map의 색은 출처이며 현재성이나 정확성 label이 아니다.

UAS 수치 비교는 prediction→reference와 reference→prediction 거리, 고정0.5m XY grid 피복·결손 및 높이차를 포함한다. 큰 오차를 threshold로 버려 정확도가 좋아 보이게 하지 않는다. region 밖 제외 수는 따로 기록한다. XY height summary는 다층·overhang을 축약한 진단이다. UAS와 작업좌표의 datum/epoch bridge·정밀도가 새로 보정되지 않았으므로 **수치 공통 좌표에서의 차이**로 보고하며 확정 절대 기하 정확도라고 부르지 않는다.

결과는 [기술 반환](TECHNICAL_RETURN_ko_v1.md)과 [이슈 기록](ISSUES.md)에 성공·실패·미실행을 구분한다. 기존 방법의 실패·우리 방법의 우위·공식 PASS/usable·일반화·과학적 verdict는 사전 결론으로 두지 않는다.
