# 예측의 판정 [이 발주에서 냄]

판정 규칙: 방향을 말한 예측은 그 방향으로 기준을 넘으면 맞음, 같음이거나 반대 방향이면 틀림, 결과가 없거나(관문) 표본이 100점 미만이면 판단 불가. '기준 안'을 말한 예측은 모든 값이 같음이면 맞음. 등급은 판정을 정한 값 가운데 가장 약한 읽기다.
