## 1. SpotLessSplats

**근거 버전:** [arXiv:2406.20055v2, 2024-07-29](https://arxiv.org/html/2406.20055v2). [공식 프로젝트](https://spotlesssplats.github.io/)는 TOG 2025로 표기한다. 아래 절·그림은 확인한 v2 기준이다.

1. **문제·입출력·가정:** 포즈가 있는 RGB 관측으로 방해물이 제거된 정적 GS와 새 시점 영상을 복원한다. SfM은 영상 파생 초기화이고 Stable Diffusion 특징은 사전학습 정보다. 무색 외부 기하를 사용하지 않으므로 **관측 제어 구성요소 참고**다. 임시 가림 제거와 영구적인 현재 변화 반영은 목표가 다르다.
2. **기여 위치:** 입력·전처리=`기존` 특징 추출, `새` 활용 절차; 좌표·카메라=`기존`; 표현=`기존` 3DGS; 관측·렌더링=`기존`; 감독=`새` 특징 기반 마스킹; 초기화·최적화·모델 변경=`기존` SfM/GS, `새` warm-up·잔차 분포 추적·utilization pruning; 추출·후처리=`미확인` 표면 추출 기여. 독립적인 정합 기여는 확인되지 않았다.
3. **고정·수정·피드백:** 원영상·추출 특징은 고정한다. GS 상태→잔차→마스크/MLP→다음 GS 학습 경로가 있으며, MLP와 GS는 교대로 추정한다. 점진적 Bernoulli 마스킹은 초기에도 제외 후보의 학습 기회를 남긴다. §4.1–4.2.
4. **검증:** RobustNeRF·NeRF On-the-go의 clean test 렌더, PSNR/SSIM/LPIPS 및 primitive 수를 평가한다. Crab(1)은 학습·평가 시점이 같고 Crab(2)은 별도 시점이다. Fig.8–11은 pruning·마스크·warm-up 등을 분리한다. 측량 표면 보존은 미평가다.
5. **오류·원인:** §4.2.1의 미숙한 모델 동조는 **저자 설명이며 완화 대상**이다. §Limitations·Fig.8의 과도한 pruning으로 드문 관측 영역이 소실되는 사례, Fig.9의 얇은 특징 누락은 **제안법의 잔여 한계**다. 관측 원본 삭제와 Gaussian 지지 소실을 혼동하지 않는다.
6. **우리 후보·기각:** 드물지만 유효한 현재 관측을 활용도 부족과 분리할 수 있는지 검토한다. 최소 비교는 기존 warm-up/잔차 분포/특징 마스크를 갖춘 제어와 동일 정보의 제안 제어, pruning off/on이다. 기존 임계값 조정만으로 필요한 수정과 보존이 함께 회복되면 새 원리 필요성을 기각한다. 영구 변화 관측이 실제로 배제되는지는 이 논문에서 미확인이다.

**공식 코드 확인:** [gsplat 재현판 README](https://github.com/lilygoli/SpotLessSplats/blob/0caae3cc45bb1fddf86bd47e4a521888f5c49889/README.md), commit `0caae3cc45bb1fddf86bd47e4a521888f5c49889`. [trainer L559–644](https://github.com/lilygoli/SpotLessSplats/blob/0caae3cc45bb1fddf86bd47e4a521888f5c49889/examples/spotless_trainer.py#L559)에서 현 잔차 마스크, Bernoulli 샘플링, `detach`된 마스크로 RGB 손실, 별도 MLP 손실을 확인했다. 마스크의 영구 누적 제거가 아니다. README는 논문 원실행과 재현 수치를 분리하며, 재현 렌더에는 gsplat appearance modeling을 켜지 않았다고 밝힌다. 원논문과 코드 기본값을 동일시하지 않는다.

## 2. CL-Splats

**근거 버전:** [arXiv:2506.21117v2](https://arxiv.org/html/2506.21117v2), [ICCV 2025 공식 프로젝트](https://cl-splats.github.io/).

1. **문제·입출력·가정:** 기존의 색 있는 3DGS와 국소 변화부의 새 RGB·동일 좌표계 포즈로 장면을 갱신한다. 과거 원영상은 필요하지 않다. DINOv2는 사전학습 정보, 렌더는 기존 모델의 파생 증거다. **렌더 가능한 기존 GS 조건의 직접 갱신 경쟁법**, 무색 ALS/LoD/DSM 조건에서는 구성요소/입력 adaptation 비교다.
2. **기여 위치:** 입력·전처리=`새` 변화 특징 활용, `기존` DINOv2; 좌표·카메라=`기존` COLMAP; 표현=`기존` GS; 관측·렌더링=`새` 국소 커널, `기존` 합성 원리; 감독=`새` 2D→3D 투표; 초기화·최적화·모델 변경=`새` 샘플링·공간 제한·비변경 고정; 추출·후처리=`새` 이력 조립, 표면 추출=`미확인`.
3. **고정·수정·피드백:** 변경 GS를 최적화하고 바깥을 고정한다. 영역 밖 이동은 제거한다. 현재 GS의 재투영 영역은 반복 갱신되므로 단순 단방향으로 분류하지 않는다. 최초 누락 영역을 현재 잔차로 다시 열어 주는 경로는 확인되지 않았다. §3, Fig.2–3.
4. **검증:** 합성·실측 CL-Splats/CL-NeRF의 test 렌더, 마스크 precision/recall, 시간 평가. Table 5는 배경 고정 제거 시 악화를, Table 4는 마스크 효과를 분리한다. 측량 표면 정확도·정합 오류 교차 검증은 미평가다.
5. **오류·원인:** **제안법 관측 실패**인 §9.2 Fig.12에서 얇은 변경 영역을 작게 잡아 필요한 수정이 막힌다. §6은 전역 조명 변화를 범위 밖으로 둔다. 후단 최적화가 존재한다는 사실은 누락 복구 보장이 아니다.
6. **우리 후보·기각:** 허용 영역을 넓히면서 유효 배경 손상을 억제할 수 있는지 검토한다. 최소 비교는 기존 dilation/투표 임계값/공간 제약 조정, 제안 제어, 평가 전용 이상적 영역이다. 단순 확대가 같은 손상 수준에서 같은 복원에 도달하면 새 마스크 근거를 기각한다. 이상적 영역에서도 개선이 없으면 선택 범위가 핵심 병목이라는 가설을 기각한다.

**공식 코드 확인:** commit `587fffc207f9c7cbb348f35e6d1d223d007eab69`. [README Disclaimer](https://github.com/jan-ackermann/cl-splats/blob/587fffc207f9c7cbb348f35e6d1d223d007eab69/README.md#disclaimer)는 공개 재구현이 원논문과 다를 수 있다고 명시한다. [trainer L270–293](https://github.com/jan-ackermann/cl-splats/blob/587fffc207f9c7cbb348f35e6d1d223d007eab69/clsplats/trainer.py#L270)은 시점 시작에 change detection/lifting 및 비활성 optimizer 상태 초기화를 한다. [L413–488](https://github.com/jan-ackermann/cl-splats/blob/587fffc207f9c7cbb348f35e6d1d223d007eab69/clsplats/trainer.py#L413)은 비활성 gradient 고정, 생성/삭제 후 mask 계보 정렬과 primitive 재적합을 한다. 모델 수 변화에 따른 mask 정렬을 새 변화 판단으로 해석하지 않는다. 이 재구현의 Depth-Anything V2 lifting을 원논문의 입력으로 소급하지 않는다.

## 3. GaussianUpdate

**근거 버전:** [arXiv:2508.08867v1](https://arxiv.org/html/2508.08867v1), [ICCV 2025 공식 프로젝트](https://zju3dv.github.io/GaussianUpdate/).

1. **문제·입출력·가정:** 기존 색 있는 GS, 새 RGB·포즈로 시점별 장면과 이력을 갱신한다. MVS/SfM은 영상 파생 초기화, SAM은 사전학습 정보, replay는 과거 GS의 파생 감독이다. 기존 GS 조건의 **직접 경쟁법**, 무색 prior에서는 구성요소/adaptation 비교다.
2. **기여 위치:** 입력·전처리=`기존` SAM/SfM, `새` 불변 영역 활용; 좌표·카메라=`기존`; 표현=`새` GS+외관/visibility 관리, `기존` GS/hash 구성; 관측·렌더링=`기존`; 감독=`새` 불변 mask·replay; 초기화·최적화·모델 변경=`새` 단계별 외관/추가/제거/정제; 추출·후처리=`기존` DBSCAN, `새` 이력 회수 절차, 측량 표면=`미확인`.
3. **고정·수정·피드백:** 불변부에서 외관 적응→외관 고정 후 새 GS와 제거 계수→외관·새 GS 공동 정제. 원 GS는 재사용하며 제거는 비활성 이력으로 남긴다. 최종 정제는 앞선 외관 추정을 다시 수정한다. §3.2–3.3.
4. **검증:** WAT 10 실측 장면과 Synthetic NeRF 8 장면, 렌더·이력 유지·계산량 평가. 정적 Synthetic 실험은 appearance/visibility를 생략한다. Fig.3/Table 3은 mask·추가·제거 효과를 분리한다. 측량 표면의 국소 보존·오류는 미평가다.
5. **오류·원인:** 외관이 기하 변화 차이를 흡수해 제거가 실패한다는 §4.3 설명은 **mask 제거 ablation**이다. 제안법이 이미 다룬 문제를 그대로 미해결 공백으로 쓰지 않는다. §5의 강한 반사에서 기하·외관 오류는 **저자 보고 잔여 한계**다.
6. **우리 후보·기각:** 이미 현재 영상에 맞춘 무색 prior 기반 anchor에서도 구조 오류와 외관 보정을 분리할 수 있는지 검토한다. 최소 비교는 기존 단계 분리+SAM mask, 동일 입력의 제안 제어, 추가/제거를 모두 허용한 기본형이다. 기존 분리로 해결되면 기여 후보를 기각한다. 외관·기하 간섭이 P1/P2의 주원인인지는 미확인이다.

**공식 구현 가용성:** 2026-09-10 공식 프로젝트에서 논문·supplement 링크를 재확인했으나 학습 실행 코드 링크는 확인하지 못했다. 따라서 코드 commit과 실제 실행 경로는 **미확인**이다. 코드 미확보를 방법 실패 근거로 사용하지 않는다.

## 4. 본 연구에 연결할 때 지킬 경계

- **우리 해석:** 목적은 현재 복원의 개선이다. 보존·수정은 이 목적이 만족해야 할 국소 효과이며 별도의 목적을 덧붙여야만 생기는 신규성은 아니다.
- **우리 해석:** 두 소스의 참오류를 사전에 정답처럼 판별할 수 없다는 전제는 합리적이다. 그러나 적응 제어도 어떤 관측을 신뢰할지 암묵적으로 추정하므로, 학습 중 산정한 값의 의미와 오판 전달을 확인해야 한다.
- **우리 추론:** 무색 prior에서 현재 영상으로 만든 anchor의 렌더에는 실제 과거 외관이 없다. 이를 현재 영상과 비교하는 mask는 과거 GS와 현재 RGB를 비교한 시간 변화 mask와 의미가 다르다. 그 차이만으로 새 방법을 선언할 수 없고, 기존 규칙 adaptation의 성공과 실패를 함께 검증해야 한다.
- **우리 추론:** 공간 가중치가 올바른 감독을 남겨도, 기존 보호/생성/삭제 자유도가 필요한 변경을 막으면 복원이 좋아지지 않을 수 있다. 감독 제어와 수정 변수 제어의 최소 교차 비교가 필요하다. 세부 후보를 원인 분류기 네 종류로 강제할 이유는 없다.

## 5. 다음 검토의 최소 비교와 기각 기준

1. 동일 영상·prior·anchor·정합·계산 예산에서 전역 가중/기존 confidence/기존 강건 규칙/제안 제어를 비교하도록 설계한다. 현재는 설계 제안이며 실행 승인이 아니다.
2. 필요한 수정 영역과 유효 구조 영역의 결과를 분리한다. 표면 정확도·완전성·관측 가능한 세부·외관·국소 악화를 함께 기록하고, 동일 손상 수준에서 복원 이득을 비교한다.
3. GT 기반 이상적 영역·가중치는 평가 전용 상한 진단에만 둔다. 실제 제안법에 참조를 넣지 않는다.
4. 기존 warm-up/마스크 확대/변수 단계 분리의 단순 조합으로 해결되면 그 기능을 신규성 근거에서 제외한다. 새로운 데이터에 적용했다는 사실만 남으면 방법론 기여를 주장하지 않는다.
5. 관측되지 않은 영역의 현재성은 보존만으로 증명되지 않는다. 평가 불가를 실패 또는 성공으로 바꾸지 않는다.

## 6. 조회·해석 한계

- 세 원문과 두 공식 공개 코드의 고정 버전을 읽었다. 프로젝트 도구 실행, 이미지 생성, 모델 실행은 하지 않았다.
- CL-Splats의 `exp_avg` 문자열은 trainer 파일에서 찾지 못했다. 대신 실제 호출 `reset_inactive_optimizer_state`까지 확인했으며 그 내부 구현의 상세 알고리즘을 이번 카드에서 추가 단정하지 않았다.
- 논문 주장과 재구현 차이는 각 코드 항목에 기록했다. 예전 코드 가용성 또는 과거 로컬 결과 부재 주장을 현재 상태로 복사하지 않았다.
