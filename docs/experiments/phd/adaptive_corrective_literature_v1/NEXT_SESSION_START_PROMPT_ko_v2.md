[연구 목적]

현재 영상만으로 불완전하게 복원되는 도시 장면에서,
품질과 표현 수준이 다른 기존 기하(LiDAR, LoD, DSM 등)의
상보적 정보를 활용하여, 유효한 구조의 손상을 통제하면서
현재 기하·관측 가능한 세부·외관을 개선한다.

기대하는 결과는 다음과 같다.
- 정확한 구조는 유지된다.
- 틀린 구조는 수정된다.
- 부족한 관측 가능 세부는 복원된다.
- 외관은 현재 영상에 부합한다.

ALS는 지금까지 사용한 prior이며 입력을 ALS로 고정한 것은 아니다.
시간차는 여러 문제 조건 중 하나다.
기존 기하=큰 구조, 영상=세부라는 고정된 역할을 전제하지 않는다.

[접근 의도]

기존 기하로 초기 구조를 확보하고, 현재 영상에 근거해 학습 중
보정하는 접근에 관심이 있다. 두 입력과 영상 파생 감독의 타당성이
국소적으로 불균일할 때 감독 반영 정도와 수정 범위를 조절하려 한다.

오류 원인 분류기나 영역별 단일 소스 선택 모듈을 필수로 요구하지 않는다.
GS, coarse-to-fine, 마스크, 소스 교체, 공동·반복 최적화의
필요성이나 우위를 미리 확정하지 않는다.
가중치 조절뿐 아니라 감독 편향 보정·변수·제약 설계도 검토한다.

[진행 순서]

1. 기존 방법의 부족 찾기

우리 목표와 관련된 현실적인 입력·관측 조건을 정하고,
그 조건에서 기존 방법이 잘하는 것과 충분히 달성하지 못하는 것을 찾는다.
기존 방법에 실패가 있다고 미리 판정하지 않는다.

선행연구를 GeoGS·AGS-Mesh·NeuRIS로 한정하지 않는다.
이들은 이미 검토한 가까운 후보이며, 문헌 범위의 경계가 아니다.

기구축 기하 활용 복원, 적응적 기하 감독·정규화,
신뢰도·불확실성 추정, 감독 편향 보정, 이종 기하 융합,
구조 제약과 국소 갱신 등 관련 방법군을 탐색한다.
GS·도시·시간차라는 키워드를 모두 만족해야 한다고 제한하지 않는다.

다음 순서로 문헌을 선별하라.
연구 목표와 관련된 조건 → 관련 방법군 탐색 → 입출력·가정 대조 →
직접 경쟁 방법 / 구성요소 도입 후보 / 원인 설명 참고 문헌 구분.

기존 문헌의 인용·후속 연구를 활용하고, 추가 문헌은 관련성을 설명한다.
기존 제어의 적절한 조정·도입·단순 조합으로 해결 가능한지도 검토한다.
모든 선행에서 공통 실패가 있어야 한다고 요구하지 않는다.

2. 우리 목표에서 중요한 부족과 그 원인 찾기

남는 부족이 구조 보존·오류 수정·결손 및 세부 복원·외관에
얼마나 중요한지 평가하고 우선순위를 정한다.
정보 자체가 부족한 경우와, 정보가 있는데 활용하지 못하는 경우를 구분한다.

입력 품질, 감독 신뢰도, 수정 제약, 감독의 변수 전달,
표현·생성/삭제·추출, 정합·가시성·평가 범위 등 경쟁 원인을 검토한다.
관측된 현상·저자 설명·우리 추론·미확인을 구분하고,
원인 가설을 구별할 관찰과 최소 비교를 제시한다.

기존 해법의 부족은 기여 근거로 확인해야 하지만,
원인을 완전히 입증해야만 방법 구상을 시작할 수 있다는 조건은 두지 않는다.
분석·원인 가설·방법 설계를 함께 구체화한다.

3. 원인을 겨냥한 방법과 검증 계획 설계

도입할 기존 요소와 새롭게 제안할 추정·제약 원리를 구분한다.
왜 개선될 수 있는지와 그 가설을 기각할 조건을 함께 제시한다.
모듈 수·복잡성·새 입력 종류·단순 조합만으로 신규성을 주장하지 않는다.

동일 입력·초기 구조·감독 정보·정합·추출·계산 예산에서
기존 해법의 충분성과 제안 원리를 구별할 최소 비교를 설계한다.
prior 깊이 가중과 구조 보호는 별도 제어로 취급한다.

필요한 보정과 유효 구조 손상을 같은 영역에서 함께 평가한다.
정확도·완전성·현재성·관측 가능 세부·외관·계산량을 분리하고,
기존 방법의 성공과 제안법의 악화도 포함한다.

[기여 평가]

문제 설정의 차별성, 원인 설명, 방법 신규성, 검증 기여를 구분한다.
보존·수정을 함께 요구한다고 신규성을 확정하지 않는다.
방법이 아직 구체화되지 않았다는 이유로 연구 전체에 차별성이 없다고
판정하지도 않는다. 평가 항목을 나누는 것 자체는 방법 신규성이 아니다.
하나의 보정 규칙도 원인과 효과가 충분히 설명되면 기여 후보가 된다.

[기존 자료의 해석]

P1/P2/P3는 기존 개발 관찰이며 확정된 원인·일반화 근거가 아니다.
P2의 낮은 prior 가중 결과는 형상도 정성적으로 좋아졌다는 사용자 관찰이 있다.
평균 F1 하락만으로 이를 부정하지 말고 정확도·완전성·평가 피복을 구분한다.
P3에서 낮은 가중치가 악화될 것이라는 생각은 미검증 가설이다.

GeoGS refinement에 prior 손실·구조 보호가 남는다는 점은 알고 있다.
논문 valid mask, 공식 코드의 선택적 DA3 confidence, 실제 run 설정을 구분한다.
오래된 ‘GeoGS 전문 미확보·실제 결과 없음’을 현재 상태로 재사용하지 않는다.

새 문헌 주장은 원문과 공식 구현으로 확인한다.
관측된 실패·해결된 ablation·미평가·범위 밖을 구분한다.
단계의 존재만으로 단방향이라고 분류하지 말고 실제 피드백을 확인한다.

[산출물과 경계]

- 방법군 선별 근거와 기존 방법의 성공·부족·중요성 비교표
- 우선 부족과 경쟁 원인 가설
- 기존 요소 도입 및 새 방법 기여 후보
- 차별성·박사학위 기여 평가
- 질문별 최소 실험계획과 기각·축소 조건

이번에는 분석과 방법·실험계획까지만 작성한다.
새 학습·추론·렌더·재구성·방법 실험은 시작하지 않는다.
기존 코드·문서·산출물·진행 중 작업·서비스를 보존한다.

그다음 가까운 기존 방법의 성공과 부족을 비교하는 것부터 시작하자.
