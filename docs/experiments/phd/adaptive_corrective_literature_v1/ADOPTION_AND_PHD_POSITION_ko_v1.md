## 1. AGS-Mesh와 NeuRIS의 위치

지난 답변은 잔여 실패와 원인을 명시한 선행에 집중해 SenFuNet·DebSDF를 앞세웠다. AGS-Mesh와 NeuRIS의 관련성이 낮아진 것은 아니다. **원인을 공부할 문헌의 우선순위와 바로 도입해 비교할 방법의 우선순위가 달랐는데, 이를 명확히 설명하지 못했다.**

- **AGS-Mesh는 GS에 도입할 감독 제어의 첫 순위다.** 원문 §4.1–4.3에서 DNC는 센서 깊이 유래 법선과 예측 법선의 일치로 깊이를 거르고, ANR는 현재 GS 기하와 예측 법선을 대조한다. 부정확한 센서와 영상 파생 기하를 함께 사용하는 점이 가깝다. 동시 취득 실내 RGB-D 조건과 독립 기구축 ALS/LoD/DSM 조건의 차이는 남는다. [원문 v2](https://arxiv.org/html/2411.19271v2)
- **NeuRIS는 사용자 접근의 개념적 선행이자 단순 경쟁 규칙의 첫 순위다.** 초기 normal prior 감독 후 현재 표면에서 다중뷰 사진 일치를 검사한다. SDF 전체를 교체하는 것보다 NCC 기반 감독 제어를 동일 복원 기반에 이식해 비교하는 편이 질문을 분리하기 쉽다. [원문 v2 §3.2–3.3](https://arxiv.org/html/2206.13597v2)

고정 소스 재확인: AGS-Mesh `93fda851a20cf0bd5fce642c46da0c83c637165e`의 [train.py L125–185](https://github.com/XuqianRen/AGS_Mesh/blob/93fda851a20cf0bd5fce642c46da0c83c637165e/train.py#L125)는 현재 normal 차이를 다시 계산하고 DNC confidence를 불러온다. NeuRIS `fab2cc4ca45847fbee7490e978d3c60c582123b1`의 [exp_runner.py L329–392](https://github.com/jiepengwang/NeuRIS/blob/fab2cc4ca45847fbee7490e978d3c60c582123b1/exp_runner.py#L329)는 현재 NCC·이전 confidence·normal 차이를 결합한다. 원방법 코드의 제어를 확인했으며 GeoGS 이식이나 성능 재현은 수행하지 않았다.

AGS의 반복 ANR와 NeuRIS의 지속 기각을 비교할 수 있지만, 기각 정책 차이 자체를 새로운 기여라고 부르지 않는다. 각각이 성공하는 조건과 실패하는 조건을 확인해야 한다.

## 2. 찾는 분야의 명칭

상위 문헌군을 설명할 작업용 표현으로 다음이 적합하다.

> **불완전·부정확한 기하 prior를 이용한 강건한 다중뷰 3D 복원**  
> **Robust multi-view 3D reconstruction with imperfect geometric priors**

단 하나의 공인된 세부분야 명칭이 있다는 뜻은 아니다. `prior-guided surface reconstruction`, `geometric regularization`, `uncertainty-aware reconstruction`, `depth fusion` 등의 연구가 교차하는 범위다. 방법의 중심을 가리킬 때는 **신뢰도에 따른 적응적 기하 감독·정규화(adaptive geometric supervision and regularization)**가 더 구체적이다. AGS-Mesh의 §2·4, NeuRIS의 §3.2, VCR-GauS의 §3.3이 이 용어 범위를 뒷받침한다.

“학습 기반 3D 복원”은 큰 범주로 사용할 수 있지만, 현재 찾는 제어 원리를 특정하기에는 넓다. 장면별 GS 최적화와 여러 장면에서 학습한 신뢰도 추정기를 구별해야 한다. 미분 가능 렌더링은 관측 오차를 변수에 전달하는 방식이며, coarse-to-fine은 최적화 구성이다. 둘 중 어느 하나만으로 이 문헌군을 닫지 않는다. 시간차와 GS도 검색의 필수 조건으로 한정하지 않는다.

| 찾아야 할 문헌군·검색어 | 확인할 질문 | 우선 문헌 |
|---|---|---|
| `adaptive geometric regularization`, `geometric prior filtering` | 어떤 감독을 어느 위치·학습 시점에 약화/재사용하는가 | AGS-Mesh, NeuRIS |
| `confidence-aware surface reconstruction`, `geometric prior uncertainty` | confidence가 predictor 품질·현재 모델의 적합도·관측 충분성 중 무엇을 뜻하는가 | VCR-GauS, DebSDF, Confidence matters |
| `normal prior compensation`, `normal deflection field` | 감독을 버리기보다 형상과 감독 사이의 편향을 추정할 수 있는가 | ND-SDF, NC-SDF — 이번에는 아래 1차 선별 수준 |
| `uncertainty-aware depth fusion`, `learned volumetric fusion` | 서로 다른 기하의 상대 기여와 기존 상태 갱신을 어떻게 학습하는가 | SenFuNet, RoutedFusion |
| `partial geometric priors Gaussian splatting`, `local scene update` | 국소 제약·변수별 수정·생성/제거 범위가 필요한 수정을 허용하는가 | EnerGS, CL-Splats, GaussianUpdate |

### 추가 선별 문헌 — 완전 근거 카드와 구분

- **ND-SDF:** [공식 프로젝트](https://zju3dv.github.io/nd-sdf/)의 Method에서 장면 법선과 prior 법선 사이의 deflection을 학습하고 그 각도에 따라 감독·표본을 조절한다. **NC-SDF:** [arXiv 2405.00340v1 초록](https://arxiv.org/abs/2405.00340v1)은 시선별 normal bias의 보정을 제시한다. 둘은 “가중치를 낮추는 것 외에 무엇을 도입할 수 있는가”에 직접 관련된다. 이번에는 공식 설명/초록을 확인했으며 실제 잔여 실패·ablation·구현 충실도는 아직 감사하지 않았다.
- **GPU-SDF:** [arXiv 2602.23926v1](https://arxiv.org/html/2602.23926v1)의 Introduction·§III-B–C는 prior 기각 후 감독 부족을 문제로 제시하고, flip consistency 기반 uncertainty와 약한 감독 유지·추가 제약을 제안한다. 이 설명은 저자의 문제 해석이며 우리 조건에서의 원인 입증은 아니다. [공식 저장소](https://github.com/IRMVLab/GPU-SDF/tree/f0c6f7f7c83bd4c5c525ed3d8de784c23affe8ea)는 이번 조회 시 README와 결과 mesh 링크만 확인했으며 학습 코드는 확인하지 못했다. 코드 미확보는 방법 한계가 아니다. 후속 full-card 검토 후보로 둔다.

## 3. 무엇을 도입할 것인가 — 우리 설계 제안

논문 전체를 결합하기보다 **관측 증거→감독 제어→실제 기하 변수 수정** 중 한 연결을 동일 기반에서 비교한다. 아래는 향후 실험 설계이며 실행 지시가 아니다.

1. **기준을 먼저 고정:** GeoGS 기존 설정과 적절히 조정한 전역 설정, 공개된 영상 depth confidence 사용을 분리한다. prior 깊이 가중과 구조 보호를 동일 제어로 취급하지 않는다. 입력·anchor·정합·추출·예산을 맞춘다.
2. **첫 도입:** AGS DNC, ANR, 둘의 결합을 분리하고 NeuRIS식 NCC gate를 별도 비교한다. 센서 depth를 mesh에서 렌더한 depth로 바꾸면 가시성·결손·오류의 의미가 바뀌므로 adaptation을 명시한다. 가중치만 비교할 때 새로운 normal predictor를 한쪽에만 추가하지 않는다.
3. **신뢰도 산정이 병목이면:** VCR 연속 confidence와 DebSDF 학습형 uncertainty를 후보로 둔다. 비용·추가 학습정보·입력 추정기를 통제한다. 전체 SDF 방법을 GS로 복사하는 재현이라고 부르지 않는다.
4. **좋은 감독도 형상에 전달되지 않으면:** VCR의 normal→position 전달과 기존 GeoGS normal/depth 경로를 먼저 대조한다. 이미 같은 경로가 있다면 중복 도입을 새 기능으로 세지 않는다. 필요시 ND/NC의 감독 편향 보정이나 EnerGS의 변수별 제약을 검토한다.
5. **후순위는 조건부:** SenFuNet/RoutedFusion은 지도학습 정보·표현 차이가 크므로 즉시 구현보다 융합/갱신 원리의 경쟁 기준이다. CL/GaussianUpdate는 실제 추가·제거 또는 수정 범위가 병목일 때 우선순위를 높인다. 이들의 과거 색 있는 GS와 무색 prior 기반 anchor는 같은 입력이 아니다.

필수 선별 항목은 입력의 실제 확보 가능성, confidence의 의미, 감독 갱신 여부, GT 학습 요구, 감독이 수정하는 변수, 관측 범위와 표현 수준의 가정이다. 이를 만족하지 않는 원방법은 직접 비교 대신 구성요소 참고로 둔다. 성능이 좋다는 이유만으로 추가 감독·사전학습 정보의 차이를 숨기지 않는다.

## 4. 박사학위 관점의 현재 평가

| 평가 축 | 현재 판단 | 강한 기여로 발전하려면 필요한 내용 |
|---|---|---|
| 연구 필요성 | 목적과 실용적 중요성은 명확하다. 기존 국소 제어로도 충분하지 않은 조건의 근거는 보강 중이다. | 보완 가능한 정보가 실제로 있는데 기존 제어가 이를 잃는 조건을 보여야 한다. |
| 기존 연구와의 차별성 | GeoGS와 목적·초기 구조 활용을 공유하며 AGS/NeuRIS와 적응 감독 원리도 겹친다. | 두 입력의 타당성·표현·관측 조건이 기존 규칙의 어떤 가정을 깨는지 설명해야 한다. |
| 방법의 참신성 | 국소 adaptive 가중이라는 방향만으로는 약하다. 구체적 규칙이 없어 최종 방법의 참신성은 아직 평가 불가다. | 기존의 좋은 해법을 포함한 비교에서 새로운 추정·제약 원리의 효과를 분리해야 한다. |
| 박사학위의 중심 기여 | 현재는 발전 가능한 연구 프로그램이며, 이미 확보된 학위 기여로 판정할 단계는 아니다. | 조건/원인의 설명, 이를 겨냥한 방법, 적용 한계를 포함한 검증이 하나의 중심 명제로 연결되어야 한다. |

학위 기여를 모듈 수나 논문 수로 환산하지 않는다. 하나의 새로운 가중치 규칙도 기존 제어의 실패 원인을 해결하고 반복적으로 확인되면 의미 있는 방법 기여가 될 수 있다. 기존 구성요소를 채택했다는 사실이 신규성을 없애는 것도 아니다. 결합의 원리와 효과가 단순 조합으로 설명되는지 검토해야 한다.

### 가능한 중심 명제 — 미검증 가설

> 현재 복원 상태와 감독 사이의 일치도만으로 반영 정도를 정하면, 초기 구조가 틀린 곳에서 필요한 감독을 약화하거나 서로 일치하는 오류를 강화할 수 있다. 기존 기하와 현재 관측의 지지를 구분해 보정에 연결하면, 동일한 복원 수준에서 유효 구조의 손상을 줄일 수 있다.

이것은 방향을 구체화하는 예시다. AGS/NeuRIS 전체가 이런 실패를 공통으로 보였다는 주장도, 기존 연구가 이미 다루지 않았다는 주장도 아니다. GPU-SDF처럼 모델의 적합도와 prior 품질을 구별하려는 선행도 추가로 경쟁한다. 해당 현상이 나타나지 않으면 다른 병목을 검토해야 한다.

**설명 기여:** 실패한 결과를 모으는 수준을 넘어, 조건을 바꿀 때 기존 신뢰 규칙이나 수정 경로가 어떻게 달라지는지 설명한다. 통계적 상관만으로 원인이라고 부르지 않는다.

**방법 기여:** 그 설명에 따라 무엇을 새로 추정·제약하는지 제시한다. 명시적 원인 분류기, 별도 mask network, 특정 표현, 공동 최적화가 필수는 아니다. 단순한 보정 규칙도 후보가 된다.

**검증 기여:** 같은 관측·초기 구조·예산에서 필요한 수정·결손 복원과 유효 구조 손상을 함께 평가한다. 좋은 prior/약한 영상과 잘못된 prior/충분한 영상, 둘 다 유용한 조건과 판단 불가능한 조건을 구별한다. 형상 정확도·완전성·세부·외관·계산량을 분리한다. 모든 ALS/LoD/DSM을 첫 단계부터 포괄할 필요는 없지만, 주장한 범위 밖으로 일반화하지 않는다.

### 기각·축소 기준

- 기존 AGS/NeuRIS식 제어와 단순 confidence 보정이 같은 효과를 내면, 새로운 가중 원리의 필요성을 기각한다. 복원 목표의 실용적 해법은 얻은 것이다.
- 이득이 predictor 교체·추가 GT·더 많은 변수·예산·다른 추출에서만 나오면 그 효과에 맞게 기여를 다시 서술한다.
- 현재 영상에 필요한 구조 정보가 없으면 복원 불가능성을 제어 실패로 바꾸지 않는다.
- 개선 부위만 좋아지고 유효 구조 손상이 늘면, 두 효과와 적용 조건을 함께 보고한다. 필요한 평가 범위를 정하지 않은 평균 성능만으로 보존을 주장하지 않는다.
- 한 코드·세 개발 사례에만 맞는 규칙이면 일반 보정 원리의 근거는 약하다. 독립 조건에서 같은 설명이 유지되는지 확인해야 한다.

## 5. 다음 세션의 구체적 읽기 작업

AGS-Mesh와 NeuRIS의 **신뢰도 근거 / 제어 단위 / 재판단 가능성 / 수정 변수**를 GeoGS와 같은 표에 놓고, 기존 P1/P2/P3 자료로 어느 연결을 관찰할 수 있는지 확인한다. 이어 ND-SDF·NC-SDF·GPU-SDF의 완전 카드를 작성해 가중치 외의 보정과 직접 경쟁성을 검토한다. 단순한 기능 이식이 충분한지에 대한 실험은 별도 요청 시 정확한 조건을 정한 후 진행한다.

이번에는 위 문서 한 개만 추가했다. 기존 문서·코드·서비스와 실험 결과는 변경하지 않았다. `scientific_verdict: null`.
