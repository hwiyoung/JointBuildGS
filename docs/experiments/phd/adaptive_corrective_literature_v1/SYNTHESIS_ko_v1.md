## 1. 연구 목적과 접근의 관계

사용자가 “refinement에서 영상 감독을 일괄 사용한다”고 한 것은 refinement의 주된 의도와 보정 방식에 관한 설명이다. anchoring 손실의 존속을 모른다는 뜻으로 해석하지 않는다.

**목적은 복원으로 유지된다.** “유효 구조를 보호하고 필요한 수정을 허용한다”는 것은 목적의 교체보다 복원을 달성하는 제어 원리와 평가 기준의 구체화다. 확장되는 것이 있다면 정확한 구조 prior를 주로 가정한 상황에서 **기하·영상 감독의 타당성이 함께 불균일한 상황으로 적용 조건을 넓히는 것**이다. 이 조건 확장 자체가 방법론 신규성은 아니다.

| 층위 | 이번 연구에서 의미하는 것 |
|---|---|
| 목적 | 영상만으로 불완전한 현재 기하·관측 가능한 세부·외관을 기존 자산의 상보적 정보로 개선 |
| 접근 후보 | 기존 기하에서 출발해 학습 중 감독의 반영 정도와 수정 자유도를 조정 |
| 검증할 효과 | 유효 구조의 손상 억제, 오류 수정, 관측 가능한 결손·세부 복원, 현재 외관 |
| 기여의 근거 | 기존 제어가 충분한 조건과 부족한 조건을 구별하고, 부족한 원인을 설명·개선 |

네 기대를 네 종류의 정답 라벨이나 원인 검출기로 구현할 필요는 없다. 다만 적응 가중치도 관측의 유용성을 추정하는 규칙이므로, 무엇을 근거로 높이거나 낮추는지 설명해야 한다. 참오류를 사전에 모른다는 것과 증거로 타당성을 추정할 수 없다는 것은 다르다. 양쪽이 모두 틀리거나 모두 유용할 수 있으므로 항상 두 가중치의 합을 1로 만드는 것도 필수는 아니다.

## 2. 이미 구현된 부분과 원문에서 확인한 잔여 경로

아래는 카드의 핵심만 연결한다. 구체적인 입력·분할·기여 요소·코드 pin·실패 상태는 연결된 카드에 있다.

| 선행군 | 이미 해결하거나 다루는 부분 | 남는 근거의 종류 | 연구 질문에 주는 의미 |
|---|---|---|---|
| [NeuRIS·AGS-Mesh·VCR-GauS](GEOMETRIC_SUPERVISION_ko_v1.md) | 학습 중 현재 기하와 관측의 일치로 감독 제어 | VCR의 공통 법선 오류 한계; NeuRIS 영구기각의 오판 가능성은 우리 추론 | 모델과 잘 맞는 감독이 실제로 맞는 감독인지 구별 |
| [DebSDF](GEOMETRIC_SUPERVISION_ko_v1.md) | uncertainty 제어와 표현 변환의 원인 분리 | 오확신 가능성은 저자 설명; 전달 편향 개선은 해결한 ablation | 가중치의 오류와 감독→형상 전달의 오류를 분리 |
| [SenFuNet](HETEROGENEOUS_FUSION_ko_v1.md) | 소스별 국소 연속 가중·기각 | 완성 방법의 잘못된 선택·평균화·겹친 outlier | 국소 가중 뒤에도 구체적인 원인 연구가 가능 |
| [RoutedFusion](HETEROGENEOUS_FUSION_ko_v1.md) | 기존 유효 표면을 해치지 않는 상태 의존 갱신 | 미학습 오류 분포의 완전성 한계 | 보존·수정은 복원 내부의 이미 알려진 목표 |
| [SpotLessSplats·CL-Splats·GaussianUpdate](ROBUST_UPDATE_ko_v1.md) | 강건 감독, 변경 범위·배경 보호, 외관/기하 단계 분리 | 드문 유효 지지 소실·변경 누락; 외관 흡수는 GU가 해결한 ablation | 제외한 증거와 차단한 수정 기회를 구별 |
| [EnerGS](NEW_NEARBY_METHODS_ko_v1.md) | 부분 기하의 공간별 제약과 gradient 전달 분리 | trusted prior의 현재 타당성은 적용 전제 차이 | prior가 존재하는 곳과 현재 신뢰할 곳은 같지 않을 수 있음 |
| [Confidence matters](NEW_NEARBY_METHODS_ko_v1.md) | 영상 기하 confidence로 세부 손실 완화 | 성공한 ablation; 전체 장면의 일률 우위는 아님 | 단순 confidence가 충분한 조건을 먼저 인정 |

선행의 실패가 GeoGS P1/P2/P3에서도 같은 원인으로 발생했다는 결론은 내리지 않는다. 특히 감독 품질, prior 보호, 정합, 가림, densification, TSDF 추출, 평가 피복이 경쟁 설명으로 남는다. P2의 정성 개선을 평균 F1 하락으로 부정하지 않는다.

## 5. 우선 검증할 연구 질문과 기각 조건 — 우리 설계

**현재 우선순위는 새 모듈 이름보다 “타당성 추정 오류”와 “수정 전달 오류”를 나누는 것이다.** 두 개는 배타적인 이론이 아니며 같은 영역에서 함께 발생할 수 있다.

### 후보 A. 초기 복원과의 일치가 정확한 감독을 불리하게 만드는가

- 가까운 근거: SenFuNet의 잘못된 신뢰 순위, VCR의 공통 예측 오류, DebSDF의 uncertainty edge case.
- 우리 질문: 정확한 prior의 미세 구조와 매끈한 영상 depth가 충돌하거나, 틀린 prior와 영상 depth가 같은 단순화에 동의할 때 기존 confidence는 무엇을 지지하는가?
- 기여 후보: 국소 신뢰 순위가 잘못되는 조건과 전달 경로를 설명하고, 현재 관측의 추가 증거 또는 기존 uncertainty의 보정으로 이를 개선하는 원리. 명시적인 원인 분류기는 필수가 아니다.
- 최소 비교: 최선 전역 가중 → 공개 confidence 사용 → 기존 다중뷰/법선 일치 제어 → 제안 규칙. 동일 입력·anchor·수정 변수·추출·예산을 유지한다. confidence 자체의 단순 교정도 비교에 포함한다.
- 기각: 기존 confidence/강건 손실/단순 교정으로 같은 수준의 보존·수정이 되면 별도 원리 필요성을 기각한다. 현재 영상에 필요한 정보가 없으면 “정보를 활용하지 못한 실패”로 분류하지 않는다.

### 후보 B. 올바른 감독을 남겨도 보호·변수 결합 때문에 필요한 수정이 막히는가

- 가까운 근거: DebSDF의 전달 편향 개선, VCR의 법선→위치 전달, EnerGS의 gradient 분리, CL의 변경 허용 범위.
- 우리 질문: 감독 가중을 조정했는데도 정확한 표면으로 갈 수 없는지, 반대로 맞는 감독이 유효한 다른 구조를 함께 움직이는지 확인한다.
- 기여 후보: 학습 중 감독의 반영과 수정 범위 사이의 잘못된 연결을 설명·수정한다. 가중치와 제약이 한 규칙으로 구현되어도 무방하며 여러 모듈을 요구하지 않는다.
- 최소 비교: 기존/개선 감독 × 기존/개선 수정 제어의 작은 교차 비교. 이상적 감독·영역은 평가 전용 진단 상한이며 실제 방법 입력이 아니다. center/렌더 깊이/최종 표면을 구분한다.
- 기각: 기존 보호 강도·densification·추출 설정만으로 해결되거나, 제안한 제약이 단지 필요한 수정을 더 차단하면 기여 주장을 기각한다. 이상적 감독에서도 실패하면 소스 신뢰 추정만의 문제라는 설명을 기각한다.

두 후보 모두 **동일한 손상 수준에서 더 많은 오류·결손을 복원하는가**, 또는 **동일한 복원 수준에서 유효 구조를 덜 손상시키는가**로 검토한다. 단일 평균 PSNR/F1 우위, 새 입력 종류, 국소 가중 존재만으로 기여를 선언하지 않는다. 기존 방법의 성공·제안법의 악화 조건도 포함한다.
