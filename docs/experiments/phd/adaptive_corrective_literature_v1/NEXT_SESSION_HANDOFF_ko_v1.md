## 1. 이어갈 목적과 사용자의 접근 의도

현재 영상만으로 불완전하게 복원되는 도시 장면에서, 품질과 표현 수준이 다른 기존 기하(LiDAR, LoD, DSM 등)의 상보적 정보를 활용하여, 유효한 구조의 손상을 통제하면서 현재 기하·관측 가능한 세부·외관을 개선하는 것이 목적이다. ALS는 현재까지 사용한 정밀 prior이며 연구 입력을 ALS로 고정한 것은 아니다. 시간차는 여러 어려운 조건 중 하나다.

사용자는 기존 기하로 초기 구조를 확보하고, 현재 영상에 근거해 학습 중 보정하는 접근을 선호한다. 원인의 종류를 먼저 분류하거나 영역마다 한 소스를 고르는 모듈을 필수로 두려는 것이 아니다. 감독의 국소 반영 정도와 수정 범위를 적응적으로 조절하는 방향을 검토 중이다. GS, 명시적 판단 모듈, 소스 교체, 공동/반복 최적화의 필요성·우위를 전제하지 않는다.

네 기대는 결과에 대한 요구다: 정확한 구조는 유지, 틀린 구조는 수정, 부족한 관측 가능 세부는 복원, 외관은 현재 영상에 부합. 이를 네 종류의 classifier label이나 네 개의 모듈로 구현할 필요는 없다.

## 2. 마지막 사용자 질문 — 새 세션에서 먼저 다룰 것

### 질문 A: 보존·수정까지 다루면 차별성이 생긴 것 아닌가?

사용자는 “복원에서 보존·수정으로 확대됐는데 왜 차별성이 약하다고 하는가”를 질문했다.

정리할 점은 다음과 같다.

- **차별성이 없다고 판정한 것은 아니다.** 문제 조건과 평가 목표의 차별성, 실제 새로운 방법의 차별성을 구분해야 한다.
- 복원 목적 안에서 유효 구조 보존과 필요한 수정을 동시에 명시하고, 두 입력 모두 국소적으로 부정확할 수 있는 조건을 다루는 것은 연구의 초점을 구체화한다. 이 문제를 독립적으로 다룰 중요성은 검토할 가치가 있다.
- 그러나 보존·수정이라는 말이나 요구를 추가했다는 사실만으로 선행 대비 신규성이 확정되지는 않는다. 가까운 연구가 이미 다룬 제어와 검증 조건을 대조해야 한다.
- “복원에서 보호/수정으로 연구 목적이 교체됐다”거나 “GeoGS는 보존과 정제를 전혀 하지 않는다”고 말하지 않는다. 공유하는 목적 안에서 **어떤 조건을 더 다루고 무엇을 새롭게 설명·개선할지**가 논점이다.
- 기구축 기하의 현재 타당성, 표현 수준, 관측 충분성이 혼재한 조건에서의 동시 개선을 차별성 후보로 검토한다. 이것이 이미 확보된 방법 기여라는 뜻은 아니다.

### 질문 B: 기존 제어의 부족을 설명하는 것부터 시작해야 하나?

사용자는 연구 시작 순서를 묻고 있다. 기존 방법의 실패를 억지로 찾거나 완전한 원인 입증을 끝내야 설계를 시작할 수 있다는 순서를 강제하지 않는다.

1. 우리 연구가 달성할 복원 효과와 이를 어렵게 하는 현실적 입력·관측 조건을 구체화한다.
2. 그 조건에서 기존 해법이 이미 보장·검증한 것과 아직 미확인인 것을 나눈다.
3. 기존 방법의 충분성, 원인 가설, 새 보정 원리, 이를 구별할 최소 비교를 함께 설계한다.

새 방법의 필요성을 주장하려면 결국 기존 해법으로 충분하지 않은 근거가 필요하다. 하지만 모든 선행에서 공통 실패가 관측되어야 하는 것은 아니다. 중요한 미평가 조건도 정당한 검증 출발점이며, 그 상태를 ‘확인된 실패’와 구분한다. 설계 진행과 원인 확인은 병행할 수 있다.

## 3. 핵심 문헌의 역할과 현재 확인 수준

| 역할 | 문헌 | 다음 세션에서의 사용 |
|---|---|---|
| 복원 기반·가까운 목적 | GeoGS | 기존 구조 보호·현재 영상 정제와 새 제안의 관계를 설명 |
| 첫 도입·구성요소 경쟁 | AGS-Mesh, NeuRIS | DNC/ANR 및 사진 일치 제어가 현재 문제에 충분한지 비교 설계 |
| confidence 및 전달 원리 | VCR-GauS, DebSDF, Confidence matters | 신뢰도 산정 오류와 감독→형상 수정 오류를 분리 |
| 이종 기하 융합·갱신 | SenFuNet, RoutedFusion | 국소 가중·상태 의존 갱신의 선행 성공과 한계 검토 |
| 제약·변수·변경 범위 | EnerGS, SpotLessSplats, CL-Splats, GaussianUpdate | 감독 외에 수정 자유도·삭제/생성 범위가 병목인지 검토 |
| 추가 정밀 검토 후보 | ND-SDF, NC-SDF, GPU-SDF | 현재는 공식 설명/초록/일부 본문 선별 수준. 완전 근거 카드와 동일하게 취급하지 않음 |

AGS-Mesh와 NeuRIS는 중요도가 낮아서 빠졌던 것이 아니다. 앞선 답변이 잔여 실패가 명시된 문헌에 치우쳐 빠르게 도입할 해결책의 우선순위를 흐렸다. **AGS-Mesh·NeuRIS는 adopting 우선순위의 중심으로 유지한다.** 이들의 전체 SDF/RGB-D 파이프라인을 GeoGS에 적용한 것을 원방법의 충실 재현이라고 부르지 않는다.

문헌군의 작업용 명칭은 **불완전·부정확한 기하 prior를 이용한 강건한 다중뷰 3D 복원**이다. 방법론 검색은 **adaptive geometric supervision/regularization**, **geometric prior uncertainty**, **normal prior compensation**, **uncertainty-aware depth fusion**, **structure-preserving refinement/scene update**로 확장한다. 명칭 자체가 새 분야·새 기여라는 뜻은 아니다.

## 5. 반복하지 말아야 할 오해

- GeoGS refinement에 prior 깊이·구조 보호가 남는다는 점을 사용자는 알고 있다. “영상 감독을 일괄 사용”은 refinement의 의도에 대한 표현이었다.
- GeoGS 논문의 binary valid mask와 공식 코드의 선택적 DA3 confidence는 구분한다. 기존 감사는 해당 P1/P2/P3 실행에서 optional confidence가 꺼져 있다고 확인했다. 다음 실행계획에는 실제 대상 run 설정을 다시 확인한다.
- “GeoGS 전문 미확보·실제 결과 없음”이라는 오래된 상태를 현재 상태로 사용하지 않는다.
- P1/P2/P3 결과가 존재한다. 다만 특정 실패를 모두 DA3·refinement·전역 가중 탓으로 확정하지 않는다.
- 사용자는 P2의 prior 가중을 낮춘 결과가 형상도 정성적으로 좋아졌다고 지적했다. 평균 F1 하락을 국소 형상 악화의 증거로 반복하지 않는다. 평가 피복·같은 표면 대응·정확도/완전성·추출의 영향을 분리한다.
- P3에서 낮은 prior 가중이 악화될 것이라는 생각은 검증 가설이다.
- 단계가 있어도 정보 피드백이 존재할 수 있다. 순차적 처리와 미분 가능 렌더링은 배타적 분류가 아니다.
- 오류·미평가·범위 밖을 구분하고, ablation에서 이미 해결한 문제를 완성 방법의 미해결 실패로 쓰지 않는다.

## 6. 다음 세션에서 만들 구체적인 산출물

### A. 차별성 문장

동일한 복원 목적을 공유함을 인정하면서 다음을 각각 한 문장으로 작성한다.

- 기존 연구가 다루는 문제 조건과 이미 제공하는 해결 원리.
- 우리가 집중할 현실 조건 및 그것의 중요성.
- 기존 방법으로 충분한지 확인되지 않은 관계.
- 제안 원리의 가설과 그 가설이 틀렸음을 보여줄 조건.

문제·평가 기여, 설명 기여, 방법 기여를 구분한다. “GeoGS+국소 mask”만으로 평가를 끝내거나, 모듈 수를 늘려야 박사학위가 된다고 요구하지 않는다. 하나의 규칙도 충분한 설명과 검증을 갖추면 의미 있는 기여 후보가 된다.

### B. 최소 실험계획 — 실행하지 않음

| 결정할 것 | 계획에 들어갈 내용 |
|---|---|
| 질문 | 신뢰도 산정·수정 허용·표현/추출 중 무엇을 분리하는가 |
| 조건 | prior 유효성/표현과 영상 지지의 조합, 필요시 정합·현재성 차이 |
| 비교군 | 원 GeoGS·적절한 전역 조정·기존 confidence·AGS/NeuRIS식 제어·제안 규칙 중 질문에 필요한 최소 집합 |
| 공통 통제 | 동일 입력·anchor 계보·감독 정보·카메라·추출·예산. prior 깊이 가중과 보호를 분리 |
| 관찰 | 동일 영역의 입력→감독→변수 변화→최종 표면·외관. 기존 자료에서 확인 가능한 항목 우선 |
| 평가 | 정확도·완전성·현재성·관측 가능 세부·외관·유효 영역 손상·비용. 기존 방법의 성공과 새 방법의 악화 포함 |
| 판정 | 같은 복원에서 덜 손상 또는 같은 손상에서 더 복원하는지. 정보 부재/미평가는 성패와 구분 |
| 축소 | 단순 기존 제어로 충분한 경우 추가 규칙 생략. 상한 진단도 개선 불가이면 소스 가중 외의 병목 재검토 |

GT는 평가 전용이며 제어 입력에 누출하지 않는다. 원인 검증용 합성 교란과 독립 실제 장면 검증을 구분한다. P1/P2/P3는 개발 관찰이며 독립 일반화 결과로 부르지 않는다.

## 7. 보존·실행 경계

기존 코드·문서·산출물·진행 중 작업·서비스를 보존한다. 새로운 설계 정리는 별도 파일 또는 경로에 쓴다. 필요한 프로젝트 도구는 Docker에서 실행하며 이번 인계로 학습·렌더·방법 실험을 승인한 것이 아니다. 정본 결정문이나 E1–E6를 소급 수정하지 않는다. 이 인계는 대화 맥락 전달이며 두 호스트 간 artifact 쓰기 소유권 이전이 아니다.
