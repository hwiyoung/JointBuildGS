## 서사 (화살표 ①–⑨)

① 영상만으로 구조화된 의미론적 도시 모델을 자동 구축하면 실패 집합이 무시할
수 없다(모집단 93동 중 구조화 유효 79동, 관측공백 의존 45동) →
② 실패의 뿌리는 광도 대응의 구조적 한계(무텍스처·반복 무늬·유리/금속, 기하-색
모호성)라서 촬영을 늘려도 해결되지 않는다 — 해결에는 광도와 독립인 기하 증거가
필요하다 [개정 2026-08-24, 사용자 결정: 실패는 **영상 단독 경로의 구조적
실패**로 통합 서술 — 관측(광도 대응) 하위 유형과 해석(분류 취약: 영상-유래
점군의 무른 경계·벽 부재 위에서 증폭, 같은 장면에서 LiDAR 분류는 지붕 유지
실측) 하위 유형을 포함하며, 해석 실패도 관측이 이미 충분한 곳에서 나므로
**어느 쪽도 촬영 증설로 해결되지 않는다** — 차감 없이 45동 전체가 ①] →
③ 그 증거인 기구축 3D 자산(기존 ALS·LoD 모델)이 이미 대량 존재하고, 광도에
의존하지 않으므로 영상이 실패하는 바로 그 지점에서 상보적이다 →
④ 그러나 "과거에, 다른 기준계에서, 다른 센서로" 구축됐다는 정의 자체로부터
신뢰 결핍 3종 — 시간(변화)·공간(정합)·외관(질감 부재) — 이 필연으로 따라온다 →
⑤ 판단 없이 합치면(union) 상보성 덕에 완전도는 회복되지만, 모순의 해소가 하류
밀도 다수결이라는 조건부 우연에 맡겨진다; 오염은 연속-이산 경계에서 증폭되어
산출물 오류(평면 편향·모델화 실패·낡은 형상 잔존)가 되고, 하필 prior가 기여한
그 자리에 집중되며(이득-위험 동소성), 무보고라서 하나를 믿으려면 전부 검수해야
한다 →
⑥ 검증이 필요한 그 자리(영상-공백부)는 현재 3D가 없는 곳이라 3D-대-3D 검사가
정의되지 않는다 — 그곳에서 현재를 아는 유일한 증거는 영상이다 →
⑦ 그래서 prior 가설을 현재 영상에 렌더-대조하고, 불일치를 기울기로 되돌려
채택(점유)·정합(δ)·외관을 **하나의 목적함수에서 함께 추정하는 미분 가능 렌더링
기반 공동 최적화**를 제안한다 — 함께 푸는 이유는 미지수들이 얽혀 있어서다:
어긋난 prior는 보정해야 채택되고, 불일치는 기하/외관/가림의 몫이 섞여 있어,
따로 풀면 순차 추정의 오차 전파가 방법 안에서 재발한다
[개정 2026-08-26, S3 재설계 정합: "불일치를 기울기로 되돌려"는 연속 변수
(δ·평면·외관)에 한한다 — **채택(점유)은 이산 3값(채택/기각/유보)이며, 같은
목적함수의 두-세계 렌더 총점 검정으로 판정한다**(기울기 없음 — 정의역이
{0,1}이라 ∂L/∂o가 없고, 두 세계 비교가 그 정직한 대체물). "하나의 목적함수
에서 함께"는 그대로 유지된다 — 연속 블록(경사하강)과 이산 블록(검정)이 같은
L을 공유하며 공동 고정점까지 교대한다. 실행 정본 =
`../s3_redesign_v1/S3_REDESIGN_METHODOLOGY_ko_v1.md` §0.5·§3.] →
⑧ 제안 방법은 union의 이득(공백 보완)을 유지하면서 낡음·어긋남을 걸러 오염을
차단하고, 채택·기각의 근거를 건물별 현재성 인증으로 남기며, 판정에 필수인 외관
모델이 그대로 질감 산출물이 된다(판정의 재료가 곧 산출물) →
⑨ 검증은 2단이다: 변화·정합 오차를 통제 주입해 정답 있는 조건에서 판정·보정
능력을 측정하고(기제 증명 — 주입은 GT 있는 ROC가 되는 방법론적 강점), 실데이터
층화로 문제의 실재성과 실전 성능을 확인한다(모집단 주장).

## 공동 최적화의 계보 — 번들 조정과의 연관

**번들 조정(bundle adjustment)은 사진측량이 보유한 공동 최적화의 원형이다.**
목적함수는 재투영 오차 하나 — 영상에서 관측된 점과, 카메라·3D점으로 예측한
투영의 차 — 이고, 이 잔차는 **정의상 카메라 변수와 구조 변수 양쪽의 함수**다.
따라서 모든 영상 관측이 두 변수군을 동시에 구속하며(영상→카메라, 영상→구조
배선이 목적함수 정의에 내장), 이 구조는 항공삼각측량의 표준으로 수십 년 검증
됐다(Brown의 해석적 BA, Triggs et al. 2000 "Bundle Adjustment — A Modern
Synthesis").

**제안 방법은 이 문법의 일반화다**: 잔차를 "점의 재투영 오차"에서 "가설 표면의
렌더-대조 오차"로 확장하고(대응점 기반 → 대응 없는 조밀·가림-인지 비교), 공동
추정 변수 집합을 {카메라, 점}에서 **{prior 채택(점유), 정합 오프셋 δ, 평면,
외관}**으로 바꾼 것이다. BA에서 "관측이 카메라와 구조를 함께 심판"하듯, 제안
에서는 "현재 영상이 prior의 채택과 정합을 함께 심판"한다.

| | 번들 조정 | 제안 |
|---|---|---|
| 잔차 | 재투영 오차(점) | 렌더-대조 오차(표면·조밀·가림 인지) |
| 공동 변수 | 카메라 포즈·내부표정, 3D 점 | 점유(채택), δ(정합), 평면, 외관 |
| 대응 | 기지(매칭 완료 전제) | 미지(광도 모호성 포함 — 더 어려움) |
| 변수 성질 | 연속 | 연속+준이산(점유 이진화 압력) |
| 비관측 모드 | 게이지 자유도(전역 이동·회전·축척) → datum 구속으로 처리 | 평면-내 δ(측방 전맹, 실측) → 외관·실루엣 신호 또는 구속으로 처리(HV-3의 질문) |

마지막 행이 중요하다: **BA에도 잔차가 결정하지 못하는 방향(게이지)이 있고,
분야는 이를 구속으로 다스려 왔다.** 제안의 평면-내 δ 비관측성은 같은 종류의
문제이며, 처방 문법도 같다 — 추가 신호(외관)를 잔차에 넣거나, 구속을 걸거나.

- 개정 주석(2026-08-26): 표의 "준이산(점유 이진화 압력)"은 옛 설계(연속
  완화+어닐)의 서술이다 — S3 재설계에서 점유는 **이산 3값**이 되었고 이진화
  압력·어닐은 폐지됐다(재설계 §0.5 대비표). 마지막 행의 열린 처방("외관·
  실루엣 신호 **또는** 구속")도 판정전 실측으로 결정됐다: fine-δ 비관측 →
  **Γ(δ) 구속** 채택, GPU 결정판이 신호를 보이면 추정으로 승격(재설계 §2.4).

## 배선과 신호 — 무엇이 깨지고 무엇이 남는가

- **배선(기울기 경로)**: 렌더 이미지는 장면 파라미터 전부의 함수이므로, 미분
  가능 렌더링을 쓰는 순간 영상→{점유·평면·δ·외관} 배선은 원리적으로 존재한다.
  현행 구현은 점유만 배선된 상태(동시최적화 — 정정 E-6); 평면·δ 배선은 공학
  작업이지 원리적 장벽이 아니다.
- **신호(관측 가능성)**: 배선이 있어도 그 방향의 기울기에 정보가 실리는가는
  별개의 과학 질문이다. 평면-내 δ는 기하 신호로는 비관측(실측: 봉인 게이트
  측방 전맹, C2C AUC 0.57)이며, 외관·실루엣이 이를 보완하는지가 HV-3다.
- **강등 경로(실패해도 남는 것)**: ①–⑥의 진단·필요성은 배선과 무관하게 실측
  으로 성립. 판정(점유) 배선은 이미 구현되어 선택 결합+건물별 인증 기여가
  성립. 평면·δ 배선/신호가 실패하면 "공동(판정+보정+생성)" → "판정+생성(δ는
  탐지만)" → "검증-전용"으로 주장을 좁혀 정직 보고한다. E-6 규칙: 배선 전에는
  "공동최적화"라 부르지 않는다.
- **개정(2026-08-26)**: 위 "HV-3의 질문"은 판정전 3막으로 답이 나왔다 —
  판정(점유) 신호는 실증, fine-δ는 비관측이라 구속으로 처리(계보 표 아래
  주석). 이 절의 "배선은 공학 작업" 전망은 S3 재설계가 구체 설계로 이행했다:
  점유는 기울기 배선이 아니라 검정 배선이며(⑦ 주석), δ·평면·외관 배선과 그
  검증 절차는 재설계 정본 §2~§3과
  `../s3_redesign_v1/VERIFICATION_PAGES_PLAN_ko_v1.md`(단계별 화면 판독)가
  정의한다.

## 용어 (확정 스택)

- 방법 호칭: **미분 가능 렌더링 기반 공동 최적화**(joint optimization via
  differentiable rendering)
- 대비쌍: 기존 = **순차 추정**(sequential pipeline, 개방 루프) + 데이터-수준
  병합(union) ↔ 제안 = **공동 추정**(joint, 폐루프)
- 작동 원리 설명어(호칭 아님): 렌더-대조(render-and-compare), 분석-합성
- 금지·회피: "뉴럴 렌더링"(계약 금지), "학습 기반"(자기모순 유발)

## 기존 연구와의 차별성 (예비 문헌 조사 2026-08-22 — 본문 집필 전 레퍼런스 패스 필요)

이웃 연구는 세 군집이고, 각각 서사의 일부만 보유한다.

**군집 A — prior 유도 GS 재구성**: GS4Buildings(Zhang·Wysocki·Jutzi, ISPRS
2025 — LoD2 모델로 가우시안 초기화+prior 깊이/노멀 유도), GeoGS,
LiDAR-유도 GS 등. **prior를 신뢰하고 시작**하며 목적은 재구성 품질이다.
서사로는 ③(prior 유용)까지만 있고 ④(낡음 가능성)~⑧(인증)이 없다.

**군집 B — 기존 모델 vs 신규 관측의 변화탐지·충돌분류**: LoD2 모델-스테레오
영상 변화탐지(Qin 2014), 가시성 분석 기반 모델-관측 충돌 분류(Wysocki 2023),
3D 변화탐지 서베이(Qin·Tian·Reinartz 2016 — "변화탐지는 지도/모델 갱신의
필수 단계"). 문제의식(④⑤의 모순 인식)은 공유하나 **단계식**(탐지→표기→
재구축)이고 판정 기준이 새 3D 관측(DSM·MLS)이라 **새 관측이 충분한 곳에서만
작동** — ⑥(새 3D가 없는 자리의 판정)을 정면으로 다루지 않으며, 오염의
정량 진단(⑤의 동소성·무보고)도 없다.

**군집 C — 렌더-대조/분석-합성 방법론**: DenseRaC(ICCV 2019), render-and-
compare 포즈 정련, Diff-DOPE 등 — ⑦의 기계 자체는 물체 포즈 추정에서
확립돼 있다. 그러나 **기구축 지도 자산의 재사용 판정이라는 도메인 이전은
확인 범위에서 없다**.

| 서사 요소 | 군집 A | 군집 B | 군집 C | 제안 |
|---|---|---|---|---|
| ③ prior 활용 | ✓ | ✓ | — | ✓ |
| ④ 낡음(신뢰 결핍) 가정 | ✗ | ✓ | — | ✓ |
| ⑤ 무판단 결합 오염의 정량 진단 | ✗ | ✗ | — | ✓ (D1·E9 실측) |
| ⑥ 3D-부재 지대의 판정 | ✗ | ✗ | ✗ | ✓ (판정전 실측 2026-08-24: 합성 AUC 0.88~0.96 · 자연 B173 0.90) |
| ⑦ in-loop 공동 추정 | ✗ (신뢰 전제) | ✗ (단계식) | ✓ (타 도메인) | ✓ |
| ⑧ 건물별 현재성 인증 | ✗ | ✗ | ✗ | ✓ |

**갭 진술**: 낡았을 수 있는 기구축 prior를, 재구성 루프 안에서(in-loop),
현재 3D가 정의되지 않는 영역까지 포함해, 영상 일치 제약으로 채택·기각·보정
하고 그 근거를 건물별 인증으로 남기는 방법은 — 확인한 범위에서 — 없다.
부수 기여로, 무판단 결합의 침묵 오염을 조건(밀도 다수결 4조건)·채널(연속-
이산 증폭)·크기(동소성 54%)로 체계 정량화한 진단 연구도 선례를 찾지 못했다.
군집 A의 존재(ISPRS 2025 최신)는 오히려 prior 유도 GS의 가치를 커뮤니티가
인정하면서 신뢰·현재성 문제를 열어뒀다는 증거다 — 정확히 우리 자리.
