## 4. 읽을 때 알아 둘 것

* **세션 판:** A2와 A2-깊이 0.5 / 0.2 / 0.1 %, B-시점은 세션이 정한 판이다. COLMAP 기본값이나 논문 값이 아니다. 문턱은 고르지 않았다.
* **c ≥ 2:** 덧붙임의 예상(100 % 가까이)과 다르게 86.8 %가 나왔다. 회신 1대로 값을 바꾸지 않고 기록만 했다.
* **fig8의 JS 셈 1-4 경계:** 경계가 F(영상 깊이 오류가 아닌 유의 넓이 전체를 분모로 한 비율)로 정의되어, 잘못 되돌린 비율 축(왼쪽 판)에는 그을 수 없다. 그래서 오른쪽 판(가로 = F)에 그었다.
* **문턱을 줄인 A2 판의 범위:** 원통 값만 셌다. 고리 u_M·가시성·판정은 다시 내지 않았다. 회신 4절이 요구한 것은 표뿐이다(issues I-A2).
* **parquet 대신 csv.gz:** parquet 도구가 없다.
* 걸러내기에 참값을 쓰지 않았다. 설정 잠금(sha256 6430fc3b…)은 그대로다.
