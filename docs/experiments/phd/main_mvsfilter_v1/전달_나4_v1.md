## 3. 읽을 때 알아 둘 것

* **광도 결과의 출처:** JUDGECHECK-v2 `judge/base/{구역}__{사전정보}.npz` 의 photo_code. JP 패치 파일 값과 모든 패치에서 같음을 확인했다. 저장 안 된 패치는 0이고, 차이가 유의한 패치에 '셈 안 함'은 없다.
* **이름:** 발주의 '표본 부족' = JC 번호 5 '조각 부족'.
* **구조 상한을 넘는 줄:** LoD2 벽 점 단위에서 판 가·나·다·다″가 넘는다(가는 나2 의 t8_over_upper 에도 있던 줄). 패치 단위는 넘지 않는다. 처음 상태 × 판정 넓이는 t11_combo.md 끝에 있다.
* **fig11_points_ALS 의 경계 선:** 오른쪽 판에 JS 셈 1-4 경계 선이 없다. t14_boundary 에 항공 LiDAR 줄이 없어서이며, 원래 fig8 도 같다.
* 그림 여섯 장 모두 본보기 수를 채웠고 한 그림 안에서 건물이 겹치지 않는다. fig11_added_LoD2 첫 칸(4906991)만 사진 조각이 '영상 없음'이다(fig7 고르기 규칙에서 담는 학습 영상 없음; 단면은 있음).
* 본 방법·구조 하한·상한 줄의 세 비율은 '차이가 유의한 패치 가운데 그 줄의 판정이 사전정보 사용인 넓이'다. 본 방법 판정 = JUDGECHECK-v2 본값 판.

## 4. 검산 (모두 맞음)

1. 판 가 = 묶음 나2 t8_check_mode A2 본 판: 모든 값이 같다(가장 큰 차 1.8e-12).
2. 광도 결과별 넓이 합 = 차이가 유의한 넓이(네 면). JUDGECHECK-v2 확인 3 과 같은 정의로 다시 센 비율이 점 수와 모든 칸에서 같다.
3. 참고 판 다″ 대 세션 값: 가장 큰 차 0.035 %p(LoD2 47.97 / 9.28 / 19.33, 항공 LiDAR 63.43 / 3.30 / 35.47).
