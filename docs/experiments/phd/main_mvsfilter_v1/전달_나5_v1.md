## 3. 읽을 때 알아 둘 것

* **처리 W:** JUDGECHECK-v2 `target_height` 의 일치(region 0) 목표 그대로다. 차이가 유의한 패치에 u_M 이 없는 패치는 0 이어서 JUDGEABL-v1 4.1절 규칙이 쓰일 곳이 없다.
* **바뀐 비율:** 처리 P·W 는 같은 패치를 바꾸므로 바뀐 비율이 같다(목표만 다름). 본 방법·구조 상한 줄은 '사전정보 사용 또는 일치' 판정 넓이다.
* **혼합 경계 찾는 법:** 작은 무리 평균 위에서 큰 무리 사후 확률이 처음 커지는 값이다. 셈 전에 정했고, 자료 최솟값부터 찾아도 셋 모두 같다.
* **검산 2:** 이 덧붙임은 차이가 유의하지 않은 패치를 구조 하한 그대로 두므로, JUDGEABL '식별 2 없음'(모든 패치 1)과 그 패치들에서는 다르다. LoD2 162,121 m²(한계 없는 패치 37,523 m²), 항공 LiDAR 47,041 m²(1,423 m²). 차이가 유의한 패치에서는 같다.
* **그림:** fig12_small_change 는 여섯을 채웠고 건물이 겹치지 않으며 사진 조각이 빠진 칸이 없다. 단면 점선·json 걸러내기 값은 fig10 짜임 그대로 A2 값이다. fig12_curve 는 보조 눈금 글자 겹침을 고쳐 한 번 더 그렸다(값 같음).
