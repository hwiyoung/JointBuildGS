# 영상 깊이 걸러내기 확인 — 덧붙임 4 보고 (PHD-MAIN-MVSFILTER-v1, 11/22)

* scientific_verdict: null · 사실만, 해석 없음 · 학습·새 광도 점수·새 화소 셈 없음, CPU
* **판 스무 가지(T 열 가지 × 처리 둘)는 모두 세션이 정한 판이다. T 를 고르지 않는다.** 판에는 참값을 쓰지 않았다(참값은 처음 상태, 채점, 그림 표시에만).
* 규칙: 차이가 유의한 패치(지금 점군)를 |d| 와 T 로 나눈다. 큰 차이(|d| ≥ T)는 영상 깊이 사용이고, 덧붙임 3 판 다가 되돌리는 패치만 사전정보 사용이다. 작은 차이(|d| < T)는 처리 P 사전정보 사용, 처리 W 일치와 같은 목표(정밀도 가중 평균, 본값의 무게, JUDGECHECK-v2 `target_height` 의 region 0 그대로)다. 그 밖의 패치는 구조 하한 그대로다.
* |d| = |d_m|(JUDGEPROBE-v1 패치 값, 영상 깊이 평균 − 사전 정보 높이), L = L_m. 차이가 유의한 패치에서 |d|·L·u_M 이 없는 패치는 0 이다(처리 W 에서 JUDGEABL-v1 4.1절 규칙이 쓰일 패치 없음).

## 4. 검산 (4절, `tables/t12_checks.json`)

1. T = 0(모두 큰 차이) = 덧붙임 3 판 다(t11_combo): 모든 값이 같다(가장 큰 차 1.8e-12).
2. T = 무한대·처리 P: 차이가 유의한 패치가 모두 사전정보 사용이다. JUDGEABL-v1 '식별 2 없음·사전정보 사용'(a1_variants.py:152, 모든 패치 판정 1)과 차이가 유의한 패치에서 같다(LoD2 583,656, 항공 LiDAR 77,863 패치). 차이가 유의하지 않은 패치는 이 덧붙임에서 구조 하한 그대로라 판정이 다르다: LoD2 162,121 m²(그 가운데 한계가 없는 패치 37,523 m²), 항공 LiDAR 47,041 m²(1,423 m²). 판정별 넓이는 json.
3. 2.2절 분포 = 0절 표: 여섯 줄 모두 0.02 m 안(가장 큰 차 0.005 m).
4. 더한 열 둘(`d_abs_over_L`, `mix_large`)을 뗀 패치 값 = 묶음 나4: 바이트까지 같다(두 사전 정보).
