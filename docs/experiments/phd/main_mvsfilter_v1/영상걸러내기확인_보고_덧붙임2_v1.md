## 6. 검산 (4절)

1. 찾음 + 못 찾음 = t8_check_mode 영상 깊이 오류 분모, 되돌림 + 그대로 = 사전정보 오류 분모. 네 면 모두 같다(예: LoD2 모두 667.69 · 7,721.25 m²).
2. 0절 표와 차이는 칸마다 1 %p 안이다(가장 큼 0.9 %p, 항공 LiDAR 영상 깊이 오류 0~0.2).
   - 구간을 오른쪽 닫힘((0.2, 0.5] 등)으로 세면 0절 표와 모든 칸이 소수 첫째 자리까지 같다.
   - 이 보고의 2.1절 나눔은 덧붙임 문구('0.2 미만 / 0.2~0.5 / 0.5 이상')대로 왼쪽 닫힘이다.
3. 더한 열을 뺀 패치 값 = 묶음 나2 판. 두 사전 정보 모두 풀린 csv 바이트까지 같다.
   - 원본 줄 뒤에 새 열만 이어 붙였다.
   - 처음 시도는 csv 를 읽었다 다시 쓴 탓에 숫자 표기가 바뀌어 '다름'이었다. issues I-add2 에 적었다.
- 덧: 원통 값 다시 셈에서 원통 점 수·c 중앙값·c≥5 비율·f/(c+f) 평균이 덧붙임 1 값과 모든 패치에서 같다.
