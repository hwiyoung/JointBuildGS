## 3. 읽을 때 알아 둘 것

* **0절 표와의 차이(검산 2):** 칸마다 1 %p 안이고, 가장 큰 차이는 0.9 %p 다. 0절 표는 구간 오른쪽 닫힘((0.2, 0.5] 등)으로 센 값과 모든 칸이 소수 첫째 자리까지 같다. 2.1절 나눔은 덧붙임 문구('0.2 미만 / 0.2~0.5 / 0.5 이상')대로 왼쪽 닫힘으로 셌다.
* **참값 열의 부호:** JC `plane_distance` 그대로다. + 는 그 면이 참값보다 법선 쪽(지붕 위로 뜸, 벽 밖으로)이다. 덧붙임 문구 '영상 깊이 높이에서 참값까지'와 방향 이름이 반대로 읽힐 수 있어 표에 뜻을 적었다.
* **'고른 사진 수':** JUDGEPROBE-v1 `views_M`(그쪽 이름 '고른 사진 수(영상)')을 썼다.
* **2.3절 곡선의 문턱 규칙:** t8_check_curve 와 같은 '≤ 문턱'이다. 원통 점이 0이라 값이 없는 패치는 되돌리지 않는다. c ÷ m 은 0 보다 커서 문턱 0 에서는 아무 패치도 바뀌지 않는다.
* **셋째 값:** '2c ≥ m 또는 c ≥ 5' 는 c ≥ 5 비율과 AUC 가 소수 셋째 자리까지 같고, 곡선 차이는 0.1 %p 안이다.
* **m 구간:** m 1~4 인 차이가 유의한 패치는 없다.
* **그림의 단면 패치:** 모임에서 참값 점이 가장 많은 패치다(fig7 규칙). 그래서 그 패치 하나의 c≥5 비율은 무리 경계와 다를 수 있다. 모임 값은 json 에 있다.
* **검산 3 첫 시도 '다름':** csv 를 다시 쓰며 숫자 표기가 바뀐 탓이다. 원본 줄 뒤에 새 열만 이어 붙여 바이트까지 같게 했다(issues I-add2).
