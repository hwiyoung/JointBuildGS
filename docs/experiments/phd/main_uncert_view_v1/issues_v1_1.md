- 세 지역의 LoD2 면과 삼각형 파일을 확인했다. 면 파일 없음으로 인한 중단은 없었다.
- 앞 보고 6.1과 비교한 72개 수치에서 허용 범위를 넘는 차이는 없었다. 원래 보고와 수치는 변경하지 않았다.
- 첫 화면 점검에서 비스듬히 보기의 표본 부족 빗금이 면 밖에도 표시되었다. 빗금 뒤에 면 경로를 다시 지정하여 표시를 수정했다. 면 값과 정의는 변경하지 않았다.
- 세 지역 합의 점을 눌렀을 때 지도 선택이 상단 고리 크기를 따를 수 있었다. 구간 소속을 판정 그림과 같은 지역별 고리 크기로 확인하도록 수정했다. 지도에 칠하는 원래 층 값과 고리 선택은 유지한다.
- 100 cm를 넘는 보정 그림의 점과 막대는 축 끝의 세모와 함께, 그림 아래에 항목별 값을 모두 표시한다.
- 화면 사진 점검 중 대표 자리·비스듬히 보기·단위 비교 사진의 MVS 판 선택이 앞선 판 나 점검에 영향을 받을 수 있음을 확인했다. 해당 사진 전에 판 가와 지역별 고리 크기를 명시적으로 선택하도록 고쳤다.
- Windows Chrome·Edge는 이 Linux 환경에서 직접 실행할 수 없다. Linux Chromium에서 브라우저 계산·조작·사진을 점검한다.
- 기존 v1 ZIP·웹 폴더, 원본 패치 값·보고·방법 코드의 보존 여부는 전달 직전에 SHA-256으로 다시 확인한다.
- 2026-10-23 다운로드 중단 보고: Codex 앱 브라우저에서 299 MB 묶음이 거의 완료된 상태로 멈춤. 기존 SimpleHTTP 서버는 Range에 200 전체 응답을 반환하고 attachment 헤더가 없었으며 한 요청의 BrokenPipe를 기록했다. 클라이언트 저장 정지의 단독 원인으로 확정하지 않는다. Range/If-Range·파일명·정확한 전송 길이·명시적 연결 종료와 완료 로그를 추가했다. HTTP 시험 8개, 실제 주소의 Chromium 저장 완료·해시, 중단 후 전체 이어받기 해시가 통과했다. 5.4 MB 캡처·보고서 묶음도 제공한다. 후속 사용자 확인에서 작은 묶음도 Codex 앱의 완료 단계에 멈췄다. 해당 서버 요청은 12:52:12 UTC에 5,444,856 bytes 전송 완료. 앱 최종 저장은 미해결이며 별도 Chrome/Edge 직접 URL 다운로드로 우회하도록 안내했다. 이전 v1·v1.1 서버 컨테이너와 원래 ZIP을 보존했다.
