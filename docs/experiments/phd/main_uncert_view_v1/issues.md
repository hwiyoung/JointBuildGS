# PHD-MAIN-UNCERT-VIEW-v1 이슈 기록

scientific_verdict: null

- 해결: 최초 로그 리다이렉션에서 새 logs 디렉터리가 아직 없어 명령이 시작되지 않았다. 디렉터리 생성 후 감사를 다시 실행했다. 원본 처리 없음.
- 해결: HTTP 서버 시작 직후 첫 HEAD가 연결 재설정으로 끝났다. 서비스 준비 후 연구 서버 주소와 loopback 모두 HTTP 200을 확인했다.
- 해결: 첫 CDP 검증이 일반 페이지 대신 Chromium 내장 확장 배경 페이지를 선택해 화면 대기가 끝나지 않았다. `type == page`를 선택하도록 수정했다. 중복 QA 실행의 디버그 포트 경쟁은 소유한 QA 컨테이너만 종료하고 순차 실행하여 해결했다.
- 해결: 공통 label 스타일이 hidden 속성을 덮어썼다. `[hidden]` 우선 규칙 추가 후 화면 사진을 다시 생성했다.
- 해결: 최대 경우의 층 전환이 5,262 ms였다. 모든 패치를 유지하는 CPU 픽셀 렌더러와 접힌 통계표의 필요시 계산으로 바꿔 261 ms를 확인했다. 데이터 정밀도·표본·값·색 범위는 변경하지 않았다.
- 해결: 대응 패치가 0개인 원래 자리 목록을 누를 때 빈 영역을 확대할 가능성이 있었다. 없음으로 표시하고 버튼을 비활성화했다.
- 확인 불가: 이 Linux 환경에 Windows Chrome·Edge가 없어 해당 조합은 직접 실행하지 못했다. Linux Chromium 152와 file URL·네트워크 차단만 검증했다.
- 열림: 전체 웹 폴더가 300 MB를 초과했다. 발주문 2절에 따라 표시 점 수 또는 정밀도를 줄이기 전 사용자에게 질문했다. 현재는 모든 잠근 표본과 정밀도를 유지한 버전이며, 줄이는 조치는 실행하지 않았다.
- 범위: 연구 서버와 연결된 네트워크/VPN 주소를 제공한다. 외부 인터넷에서의 접속은 검증하지 않았다.

- 해결: QA 컨테이너가 만든 보고 JSON의 소유자가 root여서 호스트 편집이 거부되었다. 이 작업에서 새로 만든 문서 폴더만 사용자 소유로 복구했다. 다른 경로의 소유권은 변경하지 않았다. 큰 차트 원시 배열은 외부 페이로드 browser_details/에 보존하고 Git에는 비교 숫자와 compact QA 기록을 남겼다.
