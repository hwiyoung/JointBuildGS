## 1. 판단의 질문, 단위와 입력

판단의 질문은 **이 영역의 현재 기하를 만들 때 어떤 후보를 사용할 수 있고, 어느 범위까지 변경을 허용할 것인가**이다. 오류 원인을 구별할 근거가 있으면 함께 기록하되, 모든 영역에서 ‘영상 오류·자산 원래 오류·시간 변화’를 정확히 분류해야만 선택할 수 있는 구조로 고정하지 않는다. 원인을 모르더라도 한 후보를 사용하기에 충분한 근거가 있을 수 있고, 한 후보를 기각할 수 있어도 대체 기하를 채택할 수 없는 경우가 있다.

| 요소 | 이번 설계에서의 의미 |
|---|---|
| 현재 관측 | 동결된 현재 항공영상과 카메라, 허용된 공통 영상 기반 증거. 사진의 존재와 특정 기하량을 구별할 관측의 충분성은 다르다. |
| 영상 후보 `M` | 현재 영상에서 얻은 MVS 등 계보가 명확한 3D 표면 후보. 현재 촬영이라는 이유로 기하가 정확하다고 간주하지 않는다. |
| 자산 후보 `P` | 기존 ALS 등 기구축 3D 표면 후보. 원본을 보존하고 적용 정합과 표현 규모를 기록한다. |
| 판단 단위 | 국소 공간 영역에서 비교할 표면과 기하 성분·규모. 같은 XY 셀에 있다는 이유만으로 서로 다른 층을 하나의 표면으로 취급하지 않는다. |
| 최초 설계 범위 | 직접 관측되는 작은 지붕 영역의 거친 표면 위치·방향을 우선 대상으로 삼는다. 셀 크기·패치 추출법은 아직 고정하지 않는다. 경계·미세 형상·면 전파는 별도 확장 항목이다. |
| 평가 참조 | 현재 UAS LiDAR, LoD2 RoofSurface·Z·roof type 등은 평가 전용이다. 판단 입력·정합·문턱 조정에 사용하지 않는다. 공통 GroundSurface XY·stable ID는 기존 계약의 허용 범위를 따른다. |

한 영역에 여러 실제 표면이 공존할 수 있다. 지붕과 그 아래 지면처럼 서로 다른 층을 함께 표현하는 것은 동일 표면의 기하를 융합하는 것과 구별한다. 반면 과거 지붕과 현재 지붕이 다른 높이에 있는 경우에는 같은 영역의 현재 상태에 대한 경쟁 가설로 비교할 수 있으나, 그 사실만으로 평균낼 수는 없다.

## 2. 관측에서 후보의 사용 상태로 넘어가기

### 2.1 판단에 사용할 관측과 한계

| 관측·점검 | 어떤 질문에 답할 단서인가 | 이것만으로 내릴 수 없는 결론 |
|---|---|---|
| 후보별 다중시점 사진 대조 | 어느 후보가 현재 사진의 대응·윤곽을 더 일관되게 설명하는가? | 높은 사진 점수나 상대 우세만으로 기하오차가 허용 이내라고 할 수 없다. |
| 후보 위치·방향을 바꾼 대조, 시차·가시성 점검 | 관측이 지금 판단하려는 높이·방향·경계의 차이에 실제로 민감한가? | 사진 수가 많거나 외관이 선명하다고 모든 기하 성분이 식별되는 것은 아니다. |
| 광선·가림·착지 | 후보 표면이 현재 관측의 공간 관계와 충돌하는가? | 영상 기하를 착지면으로 썼다면 그 오류를 공유한다. 무착지는 빈 공간의 증거가 아니다. |
| 소스별 국소 구조·취득 정보 | 후보의 해상도, 산포, 편향 가능성, 지지 범위는 무엇인가? | 평평함·조밀함·작은 산포만으로 정확성이나 현재성을 알 수 없다. |
| 정합 근거·허용 변환 범위 | 관측 가능한 위치·방향 성분은 무엇이며, 정합을 달리하면 후보 선택이 바뀌는가? | 건물 전체의 일정한 차이만으로 실제 변화와 정합 오류를 가를 수 없다. |

여러 채널이 같은 영상·카메라·MVS에서 파생되면 오류를 공유할 수 있다. 증거 결합에서는 이 의존성을 기록한다. 후보 생성에 쓴 영상을 다시 대조한 결과를 독립 관측 검증으로 부르지 않는다. 후보에 대한 반대 근거도 단순히 낮은 점수가 아니라, 해당 차이를 구별할 관측 능력과 정합·가림의 대체 설명을 고려해 정의해야 한다.

### 2.2 후보별 상태의 의미

| 상태 | 의미 | 이후 처리 |
|---|---|---|
| 사용 지지 | 해당 기하 성분·규모에서 현재 관측의 지지, 관측의 구별 능력, 정합·소스 오류에 대한 점검을 종합했을 때 사용 조건을 충족한다고 추정 | 선택 후보에 포함한다. 실제 참기하를 확인했다는 뜻은 아니다. |
| 사용 반대 | 구별 능력이 있는 관측이 후보를 반박하며, 허용 정합·가림 등으로 그 반박을 설명하기 어려움 | 현재 기하의 채택 후보에서 기각한다. 원자료 삭제를 뜻하지 않는다. |
| 미확정 | 관측 부족, 서로 충돌하는 증거, 정합 불확실성 등으로 사용 여부를 정할 수 없음 | 사용 지지로 승격하지 않는다. 추가 계산 또는 유보 대상으로 둔다. |
| 후보 없음 | 현재 선택 단계에 넘겨진 해당 소스의 3D 후보가 없음 | 원사진 부재나 실제 표면 부재와 구별한다. |

이 네 상태는 알고리즘에 주어지는 정답 라벨이 아니다. **관측에서 ‘사용 지지·반대·미확정’을 어떻게 산출하고 그 오류를 검증할지가 다음 계산 설계의 핵심 미결 사항**이다. 필요한 수치 조건, 예상 기하오차 추정, 실용 허용 오차와 동률 처리는 후속 설계에서 정한다. 사용 지지는 정한 성분·규모·허용 위험에 관한 추정이며, 모든 오류 가능성을 완전히 배제할 것을 요구하지 않는다. 같은 관측 점수로 사용할 소스와 그 선택의 정답 여부를 동시에 선언하지 않는다.

## 3. 최종 행동과 재구성에 대한 의미

| 행동 | 기하에 대한 결정 | 재구성에 넘길 의미 |
|---|---|---|
| `IMAGE` | 사용이 지지된 영상 후보를 기준으로 채택 | 해당 영역·성분의 기하를 영상 후보에 근거해 구성한다. 자산이 없거나 기각됐다는 사실만으로 이 행동을 내리지 않는다. |
| `PRIOR` | 사용이 지지된 정합 자산 후보를 기준으로 채택 | 지지된 자산 구조를 기준으로 구성한다. 관측 가능한 현재 외관을 영상으로 입힐 수 있다. |
| `FUSION` | 같은 현재 표면에 대한 두 후보의 결합을 허용 | 각 후보의 사용 지지 외에 표면 대응·규모·정합·오류 의존성과 결합 이득을 따로 검토한다. 중간 높이의 단순 평균을 기본 해로 두지 않는다. |
| `ABSTAIN` | 해당 영역·성분의 현재 기하 채택을 확정하지 않음 | 기각 후보, 미확인 상태로 보존할 후보, 새 기하를 만들 수 없는 영역을 구분해 전달한다. |

`PRIOR` 기하에 현재 영상 텍스처를 입히는 것은 위 정의상 기하 `FUSION`이 아니다. 이 표의 행동은 기하 출처에 대한 판단이며, 외관과 세부 변형의 허용 범위는 별도로 기록한다. 구조의 특정 성분만 지지된다면 그 범위만 인계한다. 세부가 사진에 보인다는 이유로 그 세부의 3D 위치를 복원할 권한까지 자동 부여하지 않는다.

## 4. 판단상황표

아래 ‘상황’은 실제로 만날 수 있는 예시다. 방법이 숨은 정답을 이미 알고 있다는 뜻은 아니다. 표의 행동은 **관측·후보 상태 열의 조건이 충족되는 경우**에만 허용하며, 조건을 확인하지 못하면 해당 미확정 행으로 이동한다. 먼저 정합·대응 문제를 처리한 뒤 소스 사용 상황을 판단하고, 마지막으로 유보의 출력 형태를 정한다.

### 4.1 정합과 비교 대상에 관한 선행 점검

| ID | 관측되는 상황 | 먼저 해야 할 판단·계산 | 최종 처리의 범위 |
|---|---|---|---|
| R1 | 여러 영역에서 비슷한 방향의 차이가 보이며 안정 영역·변환 성분을 지지할 근거가 있음 | 제한된 정합을 추정하고 영향을 받은 대응·거리·광선·사진 증거를 갱신 | 갱신한 후보로 4.2·4.3을 적용한다. 결맞음만으로 정합 원인을 확정하지 않는다. |
| R2 | 허용 가능한 여러 정합에서 후보 선호가 달라지며 안정 영역이 부족함 | 정합 불확실성이 어느 후보·기하 성분의 사용을 막는지 구분 | 영향받은 `PRIOR / FUSION`을 유보한다. 자산과 독립적으로 사용 지지가 성립하는 `M`이 있으면 `IMAGE`는 가능하다. |
| R3 | 같은 XY 부근에 두 표면이 있으나 층·대응이 불명확함 | 공존하는 다른 표면인지 현재 상태의 경쟁 설명인지 검토하고 비교 단위를 분리 | 대응이 해결된 단위에서 각각 판단한다. 해결되지 않은 대응으로 자산 기각이나 융합을 강제하지 않는다. |

### 4.2 두 소스의 후보가 있는 경우

| ID | 발생 가능한 상황 | 실제로 확인해야 할 관측·후보 상태 | 허용 행동 | 재구성 처리·해석 한계 |
|---|---|---|---|---|
| S1 | 두 후보가 같은 표면을 비슷하게 설명함 | 양쪽 모두 사용 지지. 정합·대응·표현 규모가 맞고 필요한 오차 범위에서 양립 | `IMAGE` 또는 `PRIOR`; 추가 조건을 충족하면 `FUSION` | 융합의 이득과 오류 의존성을 평가한다. 이득이 불분명하면 한 후보를 사용한다. 동률 규칙은 별도로 정한다. |
| S2 | 같은 거친 표면에서 자산이 더 안정적인 후보로 보임 | `P`의 현재 사용 지지가 있으며, 산포 외의 근거를 포함한 예상 기하오차 비교가 `P`를 지지. 융합에는 `M`도 사용 지지이고 S1의 양립·융합 조건을 충족해야 함 | `PRIOR`, 또는 추가 조건과 이득이 지지된 `FUSION` | 거친 구조는 자산을 기준으로 삼고 가시 영역의 외관은 영상으로 구성할 수 있다. 자산의 공칭 정밀도만으로 선택하지 않는다. |
| S3 | 영상 후보와 자산 후보가 충돌함 | `M`의 사용 지지가 성립하고, 구별 가능한 관측이 `P`를 반박 | `IMAGE` | `P`를 현재 기하 후보에서 기각한다. 추가 근거 없이 원인을 철거·증축으로 단정하지 않는다. |
| S4 | 영상 기하가 흔들리거나 편향됐을 가능성이 있음 | `P`의 사용 지지가 성립하고, 관측이 `M`을 반박하거나 그 사용 위험이 더 높다고 지지 | `PRIOR` | 자산을 기준으로 기하를 구성하고 영상 외관을 사용할 수 있다. 사진의 상대 선호만으로 `P` 사용 지지가 성립하지는 않는다. |
| S5 | 양쪽 후보가 현재 관측과 충돌함 | 구별 능력과 정합을 점검한 후에도 두 후보 모두 사용 반대 | `ABSTAIN` | 양쪽을 현재 기하 후보에서 기각한다. 둘 중 덜 나쁜 후보의 강제 채택이나 평균으로 채우지 않는다. |
| S6 | 두 후보가 의미 있게 다른데 사진·광선은 구별하지 못함 | 양쪽 중 적어도 하나의 사용이 미확정이며, 남은 증거로 허용 가능한 선택을 지지하지 못함 | `ABSTAIN` | 경쟁 가설과 미확정 이유를 보존한다. 사진에 모두 그럴듯하다는 이유로 `FUSION`하지 않는다. |
| S7 | 두 후보의 차이는 작지만 관측이 약하거나, 사용 허용에 영향을 줄 공통 편향을 평가할 근거가 부족함 | 일치 외에 사용 조건을 지지할 근거가 부족하여 양쪽 모두 미확정 | `ABSTAIN` | 필요한 경우 기존 표현을 미확인 상태로 보존한다. 작은 차이·비유의 차이를 현재 기하 확인으로 세지 않는다. |

한 후보의 사용 지지가 독자적으로 성립하고 다른 후보가 단지 미확정인 경우에도 전자를 선택할 수 있다. 다만 중요한 차이가 있는 경쟁 설명을 관측으로 구별하지 못해 그 ‘사용 지지’ 자체가 성립하지 않는다면 S6이다. 상대 우세와 사용 가능성을 분리하는 이유가 여기에 있다.

### 4.3 후보가 없거나 관측이 부족한 경우

| ID | 발생 가능한 상황 | 실제로 확인해야 할 관측·후보 상태 | 허용 행동 | 재구성 처리·해석 한계 |
|---|---|---|---|---|
| S8 | `M`만 있음 | 현재 관측과 소스 오류 점검에서 `M` 사용 지지가 성립 | `IMAGE` | 자산 없이 지지 범위 안에서 구성한다. |
| S9 | `M`만 있으나 기하를 검정할 근거가 약하거나 반대 근거가 있음 | `M` 미확정 또는 사용 반대 | `ABSTAIN` | 미확정 기존 표현의 보존과 부적합 후보의 기각을 구분한다. 현재 촬영만으로 빈 판단을 대신하지 않는다. |
| S10 | `M`은 없지만 `P`와 현재 사진이 있음 | `P`의 위치·표현 규모·정합을 검정할 관측이 있고, 대안 위치와 구별하는 능력까지 포함해 사용 지지가 성립 | `PRIOR` | `P`를 3D 기준으로 조건부 재구성한다. MVS 결손이 사진 관측의 부재를 뜻하지는 않는다. |
| S11 | `P`만 있고 가림·약한 시차 등으로 현재 기하를 검정할 수 없음 | `P` 미확정. 사진이 있어도 해당 기하량의 구별 능력이 부족 | `ABSTAIN` | 기존 자산을 미확인 표현으로 보존할 수 있다. 이를 현재 기하 복원 성공으로 세지 않는다. |
| S12 | 한 후보를 쓸 수 없다는 근거는 있으나 대체 기하가 없음 또는 미확정 | 한 후보는 사용 반대, 다른 후보는 없음 또는 미확정. `P`와 `M`에 대칭 적용 | `ABSTAIN` | **반박된 후보의 기각과 새 기하 채택 유보를 함께 출력한다.** 한 후보가 틀렸다는 사실만으로 다른 후보, 빈 공간 또는 지면을 채택하지 않는다. |
| S13 | 선택할 두 3D 후보가 모두 없음 | 사진의 유무와 무관하게 현재 선택 단계에 넘겨진 3D 후보 없음 | `ABSTAIN` | 새 후보 생성은 별도 문제다. 기존 허용 영상 기반에서 계보가 있는 후보를 생성할 수 있다면 판단 확정 전에 후보 목록에 넣고 다시 검정해야 한다. |

### 4.4 유보를 재구성에 넘기는 방법

| 유보 이유 | 후보의 처리 | 산출물에서의 의미 |
|---|---|---|
| 관측 부족·정합 미정·구별 불가 | 미확정 후보를 기록하고, 필요한 기존 표현은 미확인 상태로 보존 가능 | 현재 기하를 채택한 영역과 구분하며 판단 면적·오차 평가에서 누락을 숨기지 않는다. |
| 후보 사용 반대, 대체 후보 미확정·없음 | 반박된 후보는 현재 재구성의 기하 근거에서 제외. 원본과 기각 이유는 보존 | 기각이 대체 표면 또는 빈 공간의 확인을 뜻하지 않는다. |
| 후보 자체가 없음 | 임의 3D 위치를 만들어 채우지 않음 | 현재 단계에서 기하 미제공. 사진 존재 여부와 별도로 기록한다. |

유보는 건물 전체에 하나의 상태를 강제하지 않는다. 예를 들어 거친 높이는 지지되지만 경계 위치는 미확정이면 지지된 성분과 유보한 성분을 구분할 수 있다. 이 자유도별 처리는 해당 성분의 정의와 GS 제약을 설계한 범위에서만 허용한다. 미확인 영역에 외관이 표현되더라도 기하의 미확인 상태는 유지한다.

## 5. 판단 흐름과 동결 시점

1. 판단 영역·표면·기하 성분·규모와 후보 목록을 만든다. 원자료, 후보 생성, 판단 관측의 사용 이력을 연결한다.
2. 비교 대상과 정합을 점검한다. 정합을 갱신하면 영향을 받은 후보·대응·증거를 함께 갱신한다. 해결되지 않은 정합은 영향을 받는 후보·성분에 미확정으로 남긴다.
3. 각 후보에 대해 관측의 구별 능력과 사용 지지·반대·미확정을 평가한다. 사용 반대와 관측 부족을 같은 낮은 점수로 합치지 않는다.
4. 사용이 지지된 후보 사이에서 선택하거나 조건부 융합을 검토한다. 지지된 후보가 없거나 의미 있는 경쟁 설명을 구별하지 못하면 유보한다.
5. 최종 후보·정합·근거 버전, 후보별 상태, 행동, 기하 기준과 허용 변형, 기각·미확인 보존 영역을 함께 확정한다.
6. GS는 이 인계 범위 안에서 기하·외관을 반복 최적화한다. 재구성 중 가시성 같은 수치 상태를 갱신해도 출처 사용 권한과 유보 영역을 자동 변경하지 않는다.
7. 결과의 기하·외관·세부와 판단 범위·열화를 평가한다. 허용 범위를 벗어나거나 검증에 실패한 결과는 실패로 기록한다. GS에서 판단으로 돌아오는 교대 구조는 후속 검증 가설로 둔다.

판단 내부의 반복 횟수·중단 기준은 아직 설계 대상이다. 합의한 ‘판단 확정 → 재구성 반복’은 5번 이후의 출처 판단을 고정한다는 의미다. 위 흐름을 표로 정리했다는 사실만으로 오판 확률이나 최종 기하 정확도가 보장되지는 않는다.

## 6. 먼저 확인할 판단의 성립 조건

| 설계 질문 | 필요한 검증 | 결과에 따른 설계 방향 |
|---|---|---|
| 영역별로 후보를 달리 고를 이득이 있는가? | 평가 전용 국소 oracle과 고정 소스를 비교. 양쪽 모두 부적합한 경우와 선택 가능한 범위도 함께 확인 | 선택 여지가 작으면 복잡한 국소 판단의 필요성을 축소한다. |
| 관측에서 사용 지지·반대를 추정할 수 있는가? | 고정 후보에서 사진·광선 등의 판단과 평가 전용 기하오차·부적합 여부를 대조. 학습·보정과 평가 자료의 역할 분리 | 상대 순위만 예측되는지, 실제 사용 범위까지 구분되는지에 따라 주장을 제한한다. |
| 어느 경우에 유보해야 하는가? | 판단한 범위의 오류와 유보 면적·미제공 기하를 함께 평가. 모두 유보하는 결과도 드러냄 | 유보를 늘려 얻은 오류 감소와 실용 범위의 손실을 함께 선택 기준에 반영한다. |
| 정합·관측 오류에도 판단이 유지되는가? | 정합 불확실성, 공유 영상 오류, 부분 변화, 두 후보 모두 오류를 포함한 조건별 비교 | 구별 불가능한 조건을 명시하고 특정 단서만으로 전체 변화를 정합으로 흡수하지 않게 한다. |

최초 판단 검증은 직접 관측되는 작은 고정 영역에서 GS·면 전파 없이 설계한다. 원인 통제 예시와 실제 사례는 구분하고, 기존 개발 사례를 미사용 확증 자료로 다시 부르지 않는다. 평가 참조로 판단 규칙이나 문턱을 맞추지 않는다. 검증 실험의 구체적 입력·표본·비교·수치 조건은 별도 설계 대상이다.

3.2부터 실제 처리 순서로 각 단계의 의도·입력·작동 과정·핵심 수식·출력과 미결 사항을 작성한다. 3.3–3.4에서는 **관측 → 사용 지지·반대·미확정의 판정 규칙**을 구체화한다. 상황표의 각 조건에 관측량·교란 요인·계산 후보·유보 조건을 대응시키고, 그 뒤 우도·점수·문턱을 설계한다. E1–E6와 역사적 C 계열, 원자료·기존 실험 산출물은 이 구성 개편으로 바꾸지 않는다.
