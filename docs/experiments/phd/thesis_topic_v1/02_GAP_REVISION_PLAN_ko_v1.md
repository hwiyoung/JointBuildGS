## 1. 수정의 중심

목표는 현재시점의 기하와 외관을 충실하게 표현하는 고품질 실사 3D 재구성이다. 현재성·기하 정밀도·텍스처·세부는 그 품질을 판단하는
평가축으로 유지한다. 네 속성을 목표로 삼았다는 사실만으로 각각 새로운 학술 기여가 되는 것은 아니다.

재구성 내부의 불확실성 판단은 소스의 선택·보정·융합·유보와 기하 갱신을 결정하므로 방법론의 핵심 후보가 된다. 출처·확인 상태·남은
불확실성을 산출물에 전달하는 것은 결과의 해석과 사용을 돕는 보조 요구다. 상태를 붙였다는 이유로 재구성 개선이나 검수 불필요를 주장하지 않는다.

공백은 논문별 성과와 적용 조건을 비교한 뒤 도출한다. 기존 기술을 조합한 강한 기준선으로 같은 문제를 해결할 수 있는지도 함께 묻는다.
세부 기능의 조합이 정확히 같은 논문을 찾지 못했다는 사실만으로 독창성을 확정하지 않는다.

### 1.1 동의한 분류와 검토 범위

두 계열은 연구 목적을 기준으로 나누며 한 논문이 양쪽에 속할 수 있다. 불확실성·정합·강건 융합은 양쪽에 걸친 공통 방법군으로
별도 절에서 검토한다. 이 분류는 문헌을 읽는 순서를 정하며, 어느 소스가 참인지 또는 연구 공백이 있는지를 미리 결정하지 않는다.

| 구분 | 중심 질문 | 포함 범위와 경계 |
|---|---|---|
| 계열 1: 기하 prior·이종자료를 활용한 영상 기반 3D 재구성 | 추가 기하와 다른 자료가 영상 재구성의 기하·완전성·세부·외관을 어떻게 개선하는가 | 외부 점군·LoD·DSM 등 기존 자산의 활용을 중심으로, 관련 사진측량·표면 융합과 GS를 함께 검토한다. 동일 영상에서 추정한 깊이·법선은 보조 방법 계보로 포함하되 외부 자산과 입력 독립성·시간차를 구분한다 |
| 계열 2: 시기 간 3D 장면·모델의 검정과 갱신 | 과거 모델을 현재 관측으로 어떻게 검정하고, 어디를 유지·제거·갱신하는가 | 3D 기하의 변화 검정, 장기 지도·장면 갱신, 비관측 영역 보존을 포함한다. 탐지 전용과 실제 재구성·갱신을 구분하며, 과거 정보를 쓴다는 이유만으로 모든 연구를 포함하지 않는다 |
| 공통 방법론: 불확실성·정합·강건 융합 | 자료의 오류와 충돌을 어떤 근거로 추정·보정·완화하고, 무엇까지 판단할 수 있는가 | 소스별 오차·정합 불확실성·관측 가능성·강건 추정·신뢰도 가중·선택과 융합을 검토한다. 두 계열에서 사용하는 방법과 연결하고, 기존 방법의 조합으로 본 연구 조건을 처리할 수 있는지도 비교한다 |

시간적 유효성, 입력 계보, 정합 수준, 관측 충분성, 오류 처리 방식은 논문별 **비교축**으로 옮긴다. 계열 1 전체를 "prior가 현재
유효하다고 가정하는 연구", 계열 2 전체를 "새 자료를 참으로 두는 연구"로 정의하지 않는다. 시간 변화 실험의 부재와 알고리즘의
오류 처리 능력 부재도 구분한다.

### 1.2 앞선 수정계획에서 추가로 달라지는 내용

| 항목 | 앞선 계획 | 분류 합의 후 r2 계획 |
|---|---|---|
| 문헌 검토 범위 | prior 재구성과 과거 모델 갱신의 성과를 각각 정리 | 두 계열의 포함 범위를 명시하고, GS 밖의 관련 사진측량·표면 융합도 검토한다. 중첩 논문을 최근접 비교의 중심에 둔다 |
| 정합·불확실성 처리 | 논문별 비교축과 혼합 오류 쟁점으로 포함 | 독립된 공통 방법론 절을 둔다. 이미 가능한 오류 처리와 본 연구에서 추가 설계·검증할 부분을 연결한다 |
| 비교표 | 논문 단위로 입력·기능·평가 조건을 공정하게 비교 | 입력·적용 조건 표와 판단·갱신·재구성 기능 표를 구분한다. 과거 영역 보존, 충돌 시 판단, 시간적 유효성 확인을 서로 다른 항목으로 비교한다 |
| 공백 도출 | 두 소스 사용 판단과 최종 재구성의 연결을 공백 후보로 제시 | 두 계열의 중첩 연구와 공통 방법론을 먼저 검토한 뒤, 해당 후보 중 기존 방법으로 해결되는 부분과 추가 연구가 필요한 부분을 좁힌다 |
| 차별성의 입증 | 강한 순차법·단순 재구성·GS와 비교 | 각 비교 방법이 어느 선행 성과를 대표하는지 명시한다. 기존 판정과 재구성을 조합한 방법의 설명력까지 확인한다 |

이에 따라 핵심 논증은 **두 계열의 성과 → 중첩과 공통 방법론 → 조건별로 남는 질문 → 방법적 차별성과 입증 계획** 순서가 된다.

## 3. 최근접 문헌에서 먼저 반영할 사실

VCR-GauS, CDGS, L2M-Reg, LT-Gaussian과 이론 문헌은 개정 본문의 개별 부정 주장에 사용하기 전에 정확한 논문·버전·알고리즘 위치를
확인한다. 광범위한 서베이의 검색 수는 연구 부재의 증거로 쓰지 않는다. 원문 확인이 끝나지 않은 항목은 핵심 공백을 떠받치는 근거에서 제외한다.

## 4. 개정 목차와 공백 문장 후보

| 개정 절 | 역할 |
|---|---|
| 2.0 연구 범위와 비교 기준 | 현재시점 실사 3D 목표, 두 중첩 계열과 공통 방법론, 입력·출력 범위와 문헌 확인 수준을 정의한다 |
| 2.1 기하 prior·이종자료를 활용한 영상 기반 3D 재구성 | 추가 자료가 기하·완전성·세부·외관에 기여하는 방식과 기존 오류 처리를 정리한다. 외부 자산과 영상 유래 prior를 구분한다 |
| 2.2 시기 간 3D 장면·모델의 검정과 갱신 | 변화 검정·기존 영역 보존·제거·국소 갱신의 성과를 정리한다. 탐지 전용과 재구성, 최신성과 자료 품질을 구분한다 |

| 2.4 두 계열의 중첩과 최근접 연구 비교 | 적용 조건 표와 기능·평가 표로 중첩 연구와 기존 방법의 조합을 비교한다. 직접 확인된 기능과 해당 설정의 미평가·미확인을 구분한다 |
| 2.5 연구 공백 | 비교에서 남은 질문만 소스 판단과 최종 재구성의 연결로 정리한다. 기존 기능의 부재와 추가 검증의 필요성을 구분한다 |
| 2.6 차별성 후보와 입증할 비교 | 방법적으로 더할 내용을 명시하고 강한 순차법·기존 방법 조합·단순 재구성·GS와 비교한다. 실패·유보·열화 조건과 주장 범위를 포함한다 |
| 2.7 기여 후보와 품질 평가축 | 무엇을 새롭게 제안하며 어떤 증거가 있어야 기여로 인정할지 연결한다. 현재성·기하 정밀도·텍스처·세부는 공통 평가축으로 유지한다 |

2.4의 첫 표는 **연구 / 계열과 목적 / 입력·계보 / 시간차 / 관측·정합 조건 / 출력 / 실제 평가 조건**으로 구성한다.
두 번째 표는 **연구 / 판정 근거와 오류 처리 / 일치·충돌·비관측 시 행동 / 최종 재구성 / 확인된 한계·미평가 조건 / 본 연구의 비교 대상**으로 구성한다.
기능의 존재와 해당 조건에서의 유효성 검증을 별도로 적고, 제안 방법은 설계 목표로 표시한다. 단순한 O/X 합계로 우열을 판단하지 않는다.

공통 방법론 문헌은 구성요소 수준에서 **추정 대상 / 오차·관측 가정 / 판정·보정 원리 / 검증 범위**를 비교한다. 완성된 재구성
방법과 구분하여 연결하고, 정합·강건 추정 방법에 최종 텍스처 산출물이 없다는 이유로 미해결 문제를 주장하지 않는다.

공백을 도출할 때에는 각 후보를 다음과 같이 구분한다.

| 문헌 비교 결과 | 본문에서 사용할 주장 |
|---|---|
| 기존 방법이 이미 수행하고 검증한 기능 | 기반 기술 또는 직접 비교 대상으로 인정한다 |
| 기능은 있지만 본 연구의 입력·오류 조건에서 검증되지 않음 | 적용·평가가 필요한 질문으로 둔다. 이것만으로 새로운 방법의 필요성을 확정하지 않는다 |
| 원문이나 구현을 아직 확인하지 못함 | 확인 대기로 남기고 공백의 근거로 사용하지 않는다 |
| 기존 가정·판정 규칙의 한계가 근거와 함께 확인됨 | 어떤 조건에서 문제가 남는지 좁혀 기술하고, 제안 방법과 기존 방법의 확장을 비교한다 |

공백으로 검토할 중심 문장:

> 기하 prior·이종자료를 활용한 영상 재구성과 시기 간 장면 검정·갱신 연구는 구조 보완, 변화 검정, 기존 기하 보존과 갱신을 각각 또는
> 함께 다뤄 왔다. 본 연구는 이러한 성과와 불확실성·정합·강건 융합 방법을 바탕으로, 현재 영상 기하와 과거 외부 자산 모두 부정확할 수
> 있는 조건에서 각 자료를 사용할 범위를 판단하고 그 판단을 최종 재구성의 기하·외관 개선으로 연결하는 문제를 다룬다. 연구 공백은 이
> 조건에서 기존 방법과 그 조합이 해결하는 범위를 비교한 뒤 구체화하며, 제안 방법의 차별성은 추가 개선과 열화 통제로 입증해야 한다.

이 문장은 문제설정과 검증 방향의 제안이다. 동일한 문제를 해결하는 기존 방법이 없다는 문헌 결론이나 제안 방법의 성능 결론은 아니다.
원문 비교가 진행되면 공백의 범위를 좁히거나 기존 방법의 확장으로 다시 서술할 수 있다.

## 5. 기여 후보와 입증 책임

| 기여 후보 | 기존 기술에 더해 입증할 내용 | 품질 목표와 연결할 증거 |
|---|---|---|
| 두 소스의 사용 범위를 판단하는 방법 | 시간적 유효성·정합·관측 가능성·기하 오류를 구분해 적합한 소스를 선택·보정·융합하거나 유보하는 데 어떤 방법적 새로움이 있는가 | 동일 관측을 사용하는 강한 기준선 대비 오선택과 예상오차의 감소. 판정률만 높이는 대신 유보 범위와 오류를 함께 평가 |
| 판단을 최종 품질로 실현하는 재구성 방법 | 선택한 기하를 보존하면서 현재 영상의 외관·세부를 회복하는 데 제안 설계가 더하는 것이 무엇인가 | 동일 판정 결과를 사용하는 단순 표면 결합·텍스처링 및 기존 prior 재구성 대비 기하·외관·세부 개선과 기존 양호 영역의 열화 통제 |
| 성립 범위와 실패 조건에 관한 실증적 지식 | 어느 관측·자산 조건에서 이득이 생기며, 언제 선택·갱신이 식별되지 않거나 더 단순한 방법으로 충분한가 | 통제 조건과 독립 실제 장면에서의 일관된 비교. 정보 부족에 따른 한계와 특정 구현의 한계를 구분 |

현재성·기하 정밀도·텍스처·세부는 위 기여 후보들을 평가하는 공통 축으로 남긴다. 각 축에 대해 개선 목표, 실제로 제안한 장치,
비교 결과를 연결하되 목표를 달성했다는 문장을 미리 쓰지 않는다. 출처·확인 상태는 보조 정보로, 공개 벤치마크·규약은 실제 완성·공개와
재사용 가치를 입증할 때의 추가 산출물로 둔다. 정량적 불확실성 추정의 새로움과 단순 상태 기록도 구분한다.
문헌을 두 계열과 공통 방법론으로 나눴다는 사실과 기여의 개수는 대응시키지 않는다.

## 6. 비교 계획에 남길 최소 조건

1. 같은 입력과 사용 가능한 관측을 기준으로 원래 영상 기하, 기존 자산, 정합한 자산, 단순 병합, 고정·신뢰도 가중, 변화 검정 후 갱신을 비교한다.
   계열 1의 prior 재구성, 계열 2의 검정·갱신, 공통 방법론의 오류 처리를 결합한 강한 비교 방법도 검토한다. 각 비교가 대표하는 선행 성과를
   명시하고, 정확한 원방법 재현과 연구 조건에 맞춰 확장한 비교 방법을 구분한다. 이 후보들을 새 E 번호로 만들지 않는다.
2. 판정의 이득과 재구성의 이득을 나누어 본다. 같은 판정 결과를 주는 단순 재구성 대 GS 비교와, 같은 재구성에 다른 판정을 주는 비교를 둔다.
   출력 목표·관측·표면 추출 조건과 계산 자원을 명시하고, 입력이나 재구성 능력의 차이를 제안 원리의 이득으로 읽지 않는다.
3. 순차·반복·공동 추정의 형식 자체를 기여로 삼지 않는다. 같은 관측과 추정 능력, 비교 가능한 계산 예산을 가진 강한 순차법이 같거나 더 낫다면
   더 단순한 방법을 채택한다. 국소 선택으로 얻을 수 있는 이득 자체가 작거나 관측으로 식별되지 않으면 주장 범위도 축소한다.
4. 영상 충분/불충분 × 자산 유효/낡음 × 정합 양호/불량을 구분하고, 두 소스가 함께 부적합한 경우도 평가한다. 실제 변화와 정합 오차의
   혼동, 같은 영상 유래 증거의 의존성, 미관측 영역으로의 구조 추론은 방법 설계에서 따로 검토한다.
5. 새로운 독립 시험을 설계한다. 기존 개발 집합을 손대지 않은 확증 집합으로 취급하지 않는다. 기존 계약에서 허용한 공통 GroundSurface XY·stable ID는
   정해진 공통 통제 범위로 유지하고, 그 밖의 참조 기하·평가 라벨은 학습·정합·소스 선택에 사용하지 않는다. 텍스처 표면과 LoD2의 품질을 각각 평가한다.

이 절은 비교 설계의 요구를 정한다. 실행 대상·임계값·학습·실험·과학적 판정의 승인이 아니다.

## 7. 실제 본문 수정 순서와 완료 기준

수정 순서는 두 계열의 문헌 사실 정리 → 공통 방법론 확인 → 중첩 연구·기존 방법 조합의 비교 → 조건별 공백 도출 → 차별성 후보 → 기여와
평가축 연결이다. 먼저 원하는 공백을 정하고 선행연구를 그에 맞춰 배제하지 않는다. 검토된 계획을 02 본문에 반영할 때에는 다음을 확인한다.

- 계열은 목적에 따라 분류하고 중첩을 허용한다. 시간적 유효성·정합·관측 조건은 논문별 비교축으로 적으며, 분류만으로 기능 부재를 추론하지 않는다.
- 관련 사진측량·표면 융합과 공통 방법론을 검토했는지 확인한다. 과거 영역 보존, 충돌 시 소스 판단, 현재성 확인을 같은 기능으로 취급하지 않는다.
- 선행연구의 기능 부재는 직접 근거가 있을 때만 쓴다. "원문 확인 완료", "공식 구현 확인", "해당 설정 미평가", "원문 확인 필요"를 구분한다.
- 제안 방법은 설계 목표·가설·예정된 검증으로 표시한다. 완료되지 않은 기능을 기존 연구의 검증된 결과와 같은 지위로 비교하지 않는다.
- 원래 양호한 영역의 보존과 실패·유보 사례를 함께 다룬다. 상태 표시는 재구성 개선의 대체 성과가 되지 않는다.
- 구체적 계산식, primitive 조작, 공간 전파, 규모 분리, 최적화 순서는 03의 설계 후보로 남긴다. 그중 하나만 가능하다고 미리 선언하지 않는다.
- E1–E6와 역사적 C 계보, 참조 분리, `scientific_verdict: null`을 유지한다. 01과 R1~R4 및 용어가 일치하는지 확인한다.
- 문헌·내부 링크와 Markdown 형식을 확인하고, 수정 범위만 검토한다. 이 계획 단계에서는 02 본문과 03을 수정하지 않는다.
