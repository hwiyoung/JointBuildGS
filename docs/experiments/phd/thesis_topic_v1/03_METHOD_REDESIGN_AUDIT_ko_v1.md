## 1. 점검 결론과 유지할 전체 흐름

전체 흐름은 **판단을 확정한 뒤 그 판단 아래에서 GS 재구성을 반복하고, 최종 결과를 검증하는 순차 구조**로 유지한다. 먼저 다시 설계할 것은 판단의 의미, 판단 가능한 조건, 재구성에 넘기는 허용 범위다. 현재 r4는 필요한 문제를 제기하고 있지만, 일부 제한된 예시를 일반 명제로 확대했고 구현 후보를 논리적으로 보장된 해법처럼 서술했다. 문장만 완화하거나 우도·문턱을 채우는 수정으로는 충분하지 않다.

```text
입력·후보·사용 가능한 관측 정의
  → 판단 단계 내부의 정합·증거 평가 및 필요한 제한적 재추정
  → 판단과 최종 정합·근거 버전·재구성 허용 범위 확정
  → 허용 범위 안에서 GS 재구성 반복
  → 독립된 평가 기준으로 결과 검증
```

여기서 ‘판단 한 번’은 내부 계산을 한 번만 한다는 뜻이 아니다. 정합을 바꾸면 영향을 받은 대응·가시성·광선·사진 대조를 일관되게 다시 계산할 수 있다. 다만 재구성에 넘긴 뒤에는 GS의 적합도 향상만을 이유로 출처 선택이나 허용 범위를 바꾸지 않는다. 같은 관측을 반복 계산에 사용하는 것 자체가 오류는 아니며, 적합도 개선을 독립적인 정확성 증거로 해석하는 것이 문제다. GS에서 판단으로 돌아오는 교대 구조는 추후 필요성과 효과를 검증할 별도 가설로 둔다.

A2의 `H_V / H_S`도 재정의가 필요하다. 현재는 자산의 원래 측정·모델 오류와 시간 변화가 충분히 구분되지 않는다. 모든 오류 원인을 반드시 식별할 필요는 없지만, 방법이 추정하는 것이 ‘과거 이후 변화 여부’인지 ‘현재 표면 후보로 사용할 수 있는지’인지부터 정해야 한다. 후자를 추정하면서 원인까지 확인한 것처럼 이름 붙이지 않는다. 두 후보가 각각 허용되더라도 같은 물리적 표면을 지지하고 융합의 오차 가정이 성립하는지 별도로 판단한다.

### 가중식에 대한 제한된 반례

r4의 정의에서 `ρ = σ_M² / σ_P²`라 하면, **기각되지 않고 남은** 자산의 정규화 비중은 `vρ / (1 + vρ)`이다. 따라서 통과한 `v > 0`가 고정되어 있으면 `ρ`가 커질수록 자산 비중은 1에 가까워진다. 예를 들어 `v = 0.01`, `ρ = 10000`을 대입하면 약 99.0%다. 이는 실측값이 아니라 식의 성질을 확인하는 가상 예시다.

부록 245행의 `v < v_lo` 제거를 먼저 적용해 해당 후보를 기각한다면 이 예시는 실제 인계에 들어가지 않는다. 따라서 ‘전체 방법이 반드시 실패한다’는 반례가 아니라, **유효성 곱셈만으로 정밀도비에 무관한 안전성이 생기지 않으며 기각 규칙을 포함한 전체 위험 정의가 필요하다**는 지적이다.

### 이론 근거를 다시 쓸 때의 범위

M3C2의 원래 역할은 표면 거리와 불확실성을 추정하는 것이다. 현재성·출처 선택은 추가 가정을 필요로 하는 별도 문제다([M3C2 원문](https://arxiv.org/abs/1302.1183)). GNC 역시 선택한 강건 비용에 따라 가중의 성질이 달라지므로 연속 가중과 이산 기각을 모두 하나의 필연적 행동으로 쓰지 않는다([GNC 원문, §III–IV](https://arxiv.org/abs/1909.08605)). 제한된 모형의 유도, 방법 설계 가설, 실험으로 확인할 성질을 각각 표시한다.

실제 재설계 검증에서는 **기하오차, 외관 품질, 유보를 제외하고 판단한 범위의 오류율과 면적, 기존 양호 영역의 비열화**를 구분해야 한다. 사진 점수 개선만으로 기하 개선을 대신하지 않는다. 기존 prism·주입·199동은 개발 증거의 역할을 유지하며, 보정에 사용한 건물·장면을 같은 주장에 대한 미사용 시험 자료로 부르지 않는다. 부록 212행의 ‘B173 held-out’도 이번 용도에서의 역할을 명시하되 과거 산출물 ID는 바꾸지 않는다.

## 5. 재설계 순서와 다음 문서의 완료 조건

우선 수식 없는 판단 흐름을 작성한다. 순서는 다음과 같으며, 이는 설계할 항목이지 이미 성립한 알고리즘이 아니다.

| 순서 | 설계할 내용 | 다음 단계로 넘어갈 때 있어야 할 것 |
|---|---|---|
| 1 | 판단의 단위·후보·출력 의미 | 어떤 위치·표면·기하 자유도에 대해 무엇을 선택하는지, `IMAGE / PRIOR / FUSION / ABSTAIN`의 의미, 유보 이유와 시간 상태를 정의한 상황표. |
| 2 | 관측과 오류 모형 | 현재 영상 기하 오류, 자산 원래 오류, 시간 변화, 정합 오류, 가림·관측 부족을 구별해 설명할 수 있는 증거와 구별할 수 없는 조합. 같은 영상·자세에서 파생된 증거의 의존성 포함. |
| 3 | 사용 허용·선택·융합·유보 흐름 | 상대적으로 나은 후보와 사용 가능한 후보의 구별, 둘 다 부적합할 때의 처리, 같은 표면으로 융합해도 되는 조건. 이 흐름 뒤에 확률·점수·문턱 후보를 놓는다. |
| 4 | 정합과 판단의 내부 계산 | 안정 영역, 관측 가능한 변환 성분, 정합을 바꿨을 때 갱신할 증거, 종료·실패 조건과 최종 동결 시점. |
| 5 | 판단만의 최소 검증 설계 | 작은 고정 영역에서 후보 선택의 가능 이득과 관측 기반 선택 가능성을 분리해서 평가하는 계획. 첫 비교는 전파·GS 없이 수행하도록 설계한다. |
| 6 | GS 재구성 인계 | 선택 영역·허용 변형·유보와 Gaussian 연산의 대응표. 우선 구조 보존과 관측된 외관의 재현을 다루고, 세부 기하 변화는 별도의 허용 범위와 검증 기준을 둔다. |
| 7 | 통합 평가와 문서 개정 | 판단이 맞아도 재구성이 훼손할 수 있는 경우를 검사한다. 본문·부록·도식의 용어와 주장 수준을 함께 개정한다. |

순서 5의 첫 질문은 ‘지역별로 더 나은 후보를 고를 수만 있다면 고정된 한 소스를 쓰는 것보다 이득이 있는가’이다. 두 번째는 ‘허용된 관측만으로 그 선택을 예측할 수 있는가’이다. 전자는 평가 전용 oracle 비교이며 실제 방법의 입력이 아니다. 구분할 수 없는 구간은 유보하도록 설계하고, 사용 범위를 줄인 정도와 남은 오차를 함께 평가한다. 현재 영상으로 후보를 만들고 그 영상을 다시 대조한 경우에는 이를 독립 관측 검증으로 부르지 않는다. 별도 판단 뷰를 설계할 때도 후보 생성 단계부터 사용 이력을 확인해야 한다.

현재 UAS LiDAR와 LoD2 RoofSurface·Z·roof type 등은 평가 전용이다. 이 참조를 이용해 정합·출처 선택·방법의 문턱을 맞추지 않는다. 공통 GroundSurface XY·stable ID의 허용 범위와 출처는 기존 계약을 따른다. 통제 주입의 알려진 조작과 평가용 실측 참조도 서로 다른 증거로 기록한다.

재구성에서는 ‘기하 유지’를 먼저 측정 가능한 말로 바꾼다. 거친 지붕면·법선·높이·윤곽 중 무엇을 어느 허용 오차로 보존할지 정해야 한다. 동일한 자유도를 완전히 고정하면서 새 세부 기하를 복원할 수는 없다. 세부를 허용한다면 이동 가능한 규모·방향·영역을 정하고, 가시성이 갱신되더라도 출처 사용 권한이 조용히 바뀌지 않게 해야 한다. 최종 검사 실패는 실패로 기록하며, 통과할 때까지 판단을 다시 바꾸는 반복으로 대체하지 않는다.

## 6. 문서 정리 및 범위

- 본문 9행의 ‘GS 표현층에 별도 결정 로그 필요’는 DEC-P1-025가 이미 gsplat 기반 planar 2D Gaussian 설계를 허용한다는 점과 대조해 정리한다. 출력 계약·실행 승인은 별개다.
- 본문 171행의 ‘합집합(E8)’은 새 조건을 암시하지 않는 비교법 이름으로 고친다. ‘잔차 게이트(E5)’도 특정 구현·버전의 관측과 E5 전체 정의를 구별한다. E1–E6와 과거 C 계열 산출물의 계보는 보존한다.
- 부록 98행의 ‘1–4 실행’은 3단계 정합이 설계 상태라는 표와 불일치한다. 증거 계산 실행과 새 판단·정합 방법 실행을 분리해서 적는다.
- 본문 46행의 GS4Buildings 세부 손실 원인 해석은 현재 공백·차별성 문서에서 확인한 범위를 따라 완화한다. 원문이 입증하지 않은 원인을 확정하지 않는다.
- 본문 Mermaid와 그림 1·4의 텍스트에도 위 논리가 반복되어 있다. 향후 본문 개정 시 함께 수정한다. 이번 점검에서는 SVG의 텍스트를 확인했으며 시각 렌더링 검수는 수행하지 않았다.

이번 변경은 이 점검 문서의 추가뿐이다. 기존 필요성·공백·수정계획·방법론 본문·부록은 보존한다. 실험·학습·재구성, 조건 변경, 임계값 확정, 과학적 판정은 수행하지 않았다.
