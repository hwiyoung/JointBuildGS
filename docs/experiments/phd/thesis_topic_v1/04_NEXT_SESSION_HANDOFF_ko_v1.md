## 2. 유지할 판단과 기여의 상태

- 최종 행동은 `IMAGE / PRIOR / FUSION / ABSTAIN`이다. MVS가 없거나 사용 불가로 확정되면 `PRIOR / ABSTAIN`이다.
- 현재 영상과 영상 유래 기하를 구별한다. 현재 촬영은 MVS 정확성의 보장이 아니며, 과거 자산의 정밀도는 현재 적합성의 보장이 아니다.
- 어느 소스도 정답으로 고정하지 않는다. 두 소스가 일치해도 함께 틀릴 수 있고, 충돌해도 그 차이만으로 원인을 분리할 수 없다. 허용 관측으로 구별할 수 없는 범위는 유보한다.
- 판단은 후보의 상대 우세와 절대적인 현재 사용 가능성을 구분한다. `FUSION`은 두 후보의 사용 지지·같은 현재 표면·대응과 결합 이득이 필요하다.
- 실행 흐름은 **판단 확정 → GS 재구성 반복 → 결과 검증**이다. 확정 전의 정합·증거 재추정은 가능하다. 연구 설계와 비교 실험을 병행한다는 것은 GS 중 출처 판단을 자동 변경한다는 뜻이 아니다.
- 관측점의 지지는 전체 면의 사용 승인이 아니다. 미관측 영역의 평면 전파나 Gaussian 확장을 현재성 확인으로 세지 않는다.
- **양쪽 오류 고려, 가능집합·오차 상한, 네 행동, GS·제약 최적화 자체는 독창성이 확보된 기여가 아니다.** 판단과 재구성 모두 기여 후보로 두고, 강한 기존 방법과 실제 계산·결정·결과가 무엇이 다른지 확인한다. 판단 기여를 포기하거나 재구성 기여가 자동으로 성립한다고 결론 내리지 않는다.

현재 §3.3–3.4는 주어진 대응·오차 범위 아래의 조건부 계산안이다. 실제 대응·가림·공유 카메라 오차 범위의 산출과 점→면 연결은 미완성이다. §3.5–3.6도 표면 대응·추출, Gaussian 갱신 제약과 세부·경계 처리를 구체화해야 한다. ‘실험만 남았다’는 상태가 아니다.

## 4. A — 판단 비교·실험 설계

판단 작업은 **① 공통 판단 문제와 입력 고정 → ② 비교법·추가 계산 명시 → ③ 실제·통제 조건 구성 → ④ 오차·유보 평가 → ⑤ 결정과 재구성 인계 기록**으로 진행한다. [방법론 §3.2–3.4와 §3.7.1](03_METHOD_REDESIGN_ko_v1.md)의 계산·평가안을 실제 비교 프로토콜로 연결하는 독립 작업이다.

### 4.1 공통 판단 문제와 입력 고정

**의도:** 입력이나 판단 범위의 차이를 판단 알고리즘의 개선으로 오인하지 않는다.

**정할 계산·조건:** 같은 P2 영역에서 원후보 MVS·prior, 허용 영상·카메라·좌표 근거, 평가 단위와 기하 성분·규모, 사용 허용오차를 맞춘다. 점군 비교·정합이 필요한 경우에도 M3C2를 정합 solver나 현재 사용 판단 자체로 취급하지 않는다. 정합을 공통으로 고정해 판단 계산만 비교하는 조건과, 정합·오차 추정까지 포함해 방법 전체를 비교하는 조건을 구분한다. 후보·관측 보정·판단·평가 자료의 역할과 공유 관계를 기록한다.

**산출물:** 고정 입력·단위·후보 상태·허용 관측·자료 역할·제외 사유의 비교 계약. MVS 없음·사용 불가 확정·미확정은 다른 입력 상태로 유지한다. `PRIOR / ABSTAIN` 분기는 먼저 구체화하되, 같은 후보별 사용 검정을 `IMAGE / FUSION` 판단에 어떻게 연결할지도 비교 범위에 포함한다.

### 4.2 비교법과 추가 계산 명시

**의도:** 양쪽 오차를 고려한다는 원칙이 기존 방법보다 실제로 어떤 계산·결정을 더하는지 확인한다.

| 비교축 | 실제로 명시할 계산 | 비교의 역할 |
|---|---|---|
| 원후보 사진 점수 게이트 | 같은 원점·사진에서 후보 점수를 계산하고 문턱을 적용하는 기존 높이 진단의 규칙 | 구성요소 진단. 완전한 현재 사용 판단법이나 강한 기준선으로 취급하지 않음 |
| 한쪽 기하를 기준으로 고정하는 처리 | 어느 소스를 기준으로 고정하고 다른 소스의 차이·적합도를 어떻게 판정하는지, 반대 기준 조건도 가능한지 | 기준 소스의 오류 때문에 생기는 판단 변화를 분리 |
| 양쪽 오차·현재 관측을 고려하는 강한 기존 방법 | 각 소스·정합의 불확실성과 영상 기반 현재 기하 또는 검정 증거에서 후보 사용을 판단하는 실제 알고리즘 | ‘양쪽 오차 고려’만으로는 설명되지 않는 추가 계산이 필요한지 확인하는 핵심 비교 |
| 현재 §3.3–3.4의 설계와 구성요소 제외 비교 | 복수 대응·공유 오차의 가능집합, 고정 후보 오차 범위, 채택·유보의 실제 계산 절차 | 어떤 추가 계산 때문에 결정·실제 오차·채택 범위가 달라지는지 확인 |

강한 비교법의 구체적 이름·구현·추정량은 원논문과 코드에서 확인하여 정한다. 정합 알고리즘 하나를 완전한 사용 판단 기준선으로 대체하지 않는다. 기존 방법에 본 연구의 입력·판정 규칙을 붙였다면 그 확장을 명시하고 원방법의 출력과 구분한다. 같은 관측과 비교 가능한 계산 자원을 주되, 원방법이 하지 않는 계산을 이미 수행한 것으로 해석하지 않는다.

**산출물:** `기존 계산 → 남는 판단 문제 → 추가 계산 → 달라질 것으로 예상하는 결정 → 성립 조건` 대조표와 실행 가능한 알고리즘 정의. 두 방법이 같은 결정을 만드는 경우도 명시한다. 정확도 실험에 앞서 비교 계산과 가설을 정하고, 실패 사례가 나올 때까지 새 기여 설계를 미루지 않는다. 미완성 대응·가림·공유 오차 범위를 임의의 좁은 값으로 채우지 않는다.

### 4.3 실제 상태와 통제 조건 구성

**의도:** 어느 소스가 맞는지, 무엇 때문에 판단이 어려운지, 관측으로 구별할 수 있는지를 분리해 확인한다.

| 같은 지역에서 확인할 조건 | 검증할 판단 문제 | 실제 사례와 통제의 구분 |
|---|---|---|
| 두 후보가 가깝거나 함께 부적합 | 상호 일치를 현재 정확성으로 오인하는가? 둘 다 사용할 수 없을 때 유보하는가? | 실제 오류는 평가 전용 참조로 확인. 공통 이동 주입은 기제 검증이며 원후보의 참오차 라벨이 아님 |
| 두 후보가 충돌 | MVS 오류·prior의 현재 부적합·정합 오차를 허용 관측으로 어디까지 구별하는가? | 실제 충돌과 소스별/정합 이동 통제를 별도 조건으로 기록 |
| MVS 없음 또는 사용 불가 | 상대 비교 대상 없이 prior 자체의 사용 가능성을 검사하는가? | 자연 결손·실제 부적합과 MVS 입력을 제외한 통제를 구분 |
| 관측 부족·가림·대응 모호함 | 반박이 없다는 이유로 채택하거나 모형 실패를 prior 오류로 단정하는가? | 실제 관측 상태와 사전에 정한 관측 제한을 구분. 좋은 사진 점수만 남기는 시점 선택은 하지 않음 |
| 일부 지점만 관측된 표면 | 점의 지지를 면 전체의 사용 승인으로 확대하는가? | 판단한 지점·성분과 실제 재구성에 전달한 면 범위를 따로 기록 |

지역과 공통 단위를 먼저 고정하고, 참조를 이용한 오류 분류는 평가에서만 사용한다. P2에 없는 자연 조건은 없다고 보고한다. 통제 조작의 크기·방향·관측 제한은 모형과 시험할 가설에서 정하며 결과를 보고 유리하게 고르지 않는다. 정합·공통 편향·국소 형상 변화가 같은 관측 반응을 낼 수 있는 조건을 보존한다.

**산출물:** 실제/통제 여부, 변경한 입력, 고정한 입력, 기대 반응, 식별 불가 조건이 연결된 실험 조건표. 주입값만으로 원래 prior가 현재 맞았다고 가정하지 않는다.

### 4.4 오차와 유보를 함께 평가

**의도:** 결정이 달라졌다는 결과를 넘어 그 결정이 실제로 더 유용한지 확인한다.

**정할 평가:** 같은 참조 피복과 평가 단위에서 오채택–채택 범위 관계, 사용할 수 있는 후보를 유보한 비율, 두 후보 모두 부적합한 경우의 처리, 채택 기하의 실제 오차를 기록한다. 참조 자체의 불확실성·미피복은 별도로 남긴다. 유효 후보가 여러 개일 수 있으므로 단일 소스 라벨과 일치하는지만으로 판단 정확도를 정의하지 않는다. 융합 후보도 실제 결합 기하의 오차를 평가한다.

추정 오차 범위와 실제 오차의 관계, 관측 부족·모형 불일치·탐색 미완료를 함께 보고한다. 관측점의 분모를 표면 면적으로 바꾸거나, 중복 뷰쌍·반복 설정을 독립 표본으로 세지 않는다. 채택이 없을 때 오채택 비율을 0으로 보고하지 않는다. 같은 채택 범위에서 오채택이 줄거나 같은 위험에서 채택 범위가 넓어지는지 비교하고, 평가 참조로 정합·문턱·유리한 설정을 맞추지 않는다.

**산출물:** 전체 단위의 후보 상태·결정·추정 범위·실제 오차·유보 이유, 오채택–채택 범위 표/곡선, 유지·개선·실패·식별 불가 사례. 단순 점수 게이트 대비 결정 변화와 강한 기존 방법 대비 추가 이득을 구분한다.

### 4.5 결정과 재구성 인계 기록

**의도:** 판단 비교의 결과가 어떤 기하 사용 조건을 만들고 최종 재구성에 어떤 영향을 주었는지 연결한다.

**정할 기록:** 각 방법의 네 행동과 함께 기준 기하·점/면 지지·성분·규모·허용 변형과 근거·미확정 범위·정합/카메라 버전을 고정한다. 기존 방법의 원출력을 네 행동으로 변환했다면 대응 규칙을 공개하며, ‘변화 없음’이나 높은 점수를 자동적인 사용 승인으로 바꾸지 않는다. 오차 상한이나 면 지지를 산출하지 못한 결과에 확정 값을 만들어 붙이지 않는다.

**산출물:** 공통 ID의 판단 결과와 인계표. 같은 재구성에 서로 다른 판단을 주는 비교와, 같은 실제 판단 결과를 §5의 서로 다른 재구성에 주는 비교로 연결한다. 인계 조건을 가정한 계산 검산은 실제 판단으로 확보한 결과와 따로 보고한다.

## 5. B — 재구성 방법 설계

재구성은 **① 선택 기하의 Gaussian 표현 → ② 구조·세부 변형의 변수화 → ③ 현재 기하·외관의 갱신 → ④ 경계·분할·제거 처리 → ⑤ 표면 산출과 검사**로 구체화한다. 이 다섯 항은 최적화 안에서 연결되는 계산이며, 출처를 다시 판단하는 단계가 아니다. §3.5–3.6을 개정할 때 아래 내용을 실제 변수·계산 절차·필요한 수식으로 옮기고, 도입 순서와 하위 항의 구성을 맞춘다.

검토할 중심 설계는 **선택한 표면을 기준으로 구조의 이동과 국소 세부의 변형을 구분하고, 현재 영상으로 기하·외관을 갱신하면서 산출 표면의 변화를 제한하는 방법**이다. ‘prior로 초기화한다’, ‘강한 기하 손실을 넣는다’, `G∈Γ(ℬ)`라고 쓰는 것만으로 이 설계가 완결되지 않는다. 기준 표면의 표현, 실제로 움직일 변수, 허용 여부를 계산할 절차가 필요하다.

### 5.1 선택 기하의 Gaussian 표현

**의도:** 서로 다른 밀도와 오차를 가진 MVS·prior를 한 장면에서 사용하고, MVS가 없는 곳에도 사용이 지지된 prior로 초기 기하를 제공한다.

**계산의 출발안:** 행동별로 검정한 MVS·prior·결합 표면을 공급원으로 고정한다. 각 Gaussian에 원후보의 기준 위치, 표면 소속, 지지 범위와 허용 성분을 연결하고, 중심·방향·평면 내 두 크기·불투명도·외관의 초기값을 정한다. 원점 밀도가 다르다는 이유만으로 한 소스가 중복 표면이나 과도한 렌더 가중을 갖지 않도록 표본 배치와 중첩을 계산한다. `FUSION`은 검정한 결합 기하를 표현하며, 두 원후보를 겹쳐 놓고 학습 중 하나가 사라지길 기대하는 초기화로 대체하지 않는다.

**작성할 결과:** `고정 후보·지지 범위 → 초기 Gaussian G⁰ → 초기 표면 S(G⁰)`의 변환과 대응 규칙. 원후보에서의 위치·방향 차이, 누락과 범위 초과를 계산한다. MVS 없는 곳의 prior 초기화는 명시적으로 포함하되, prior 자체도 지지하지 않는 틈을 큰 Gaussian으로 메우지 않는다. 점 지지만 확보한 곳과 실제 면 사용이 가능한 곳을 구분한다.

### 5.2 구조·세부 변형의 변수화

**의도:** 기준 구조를 보호하면서 관측이 지지하는 세부 형상을 복원할 자유도를 남긴다. 구조 전체의 이동과 작은 Gaussian들의 변형을 구분하지 않으면, 모두 고정하여 세부를 잃거나 국소 이동이 누적되어 구조가 달라질 수 있다.

**계산의 출발안:** 지지된 기준 표면의 국소 좌표에서 **Gaussian 위치 = 기준점 + 면 안의 이동 + 법선 방향 이동**으로 표현하는 안을 검토한다. 해당 영역의 거친 위치·방향을 나타내는 성분과 Gaussian별 국소 변위를 분리한다. 어떤 변위를 거친 구조 변화로 읽을지, 같은 변형이 두 변수에 중복 표현되지 않게 할 조건, 국소 변위의 집합이 기준 구조를 얼마나 바꾸는지 계산할 집계량을 정한다. 이를 단순히 ‘큰 구조는 prior, 작은 구조는 영상’이라는 소스 고정 규칙으로 바꾸지 않는다.

**작성할 결과:** 위치·방향·경계 및 세부 성분별 고정/허용 변수와 변형 한계의 대응표, 구조와 세부를 분리할 연산과 필요한 수식. 판단의 오차 여유가 있어도 그것만으로 새로운 돌출이나 경계를 지지하지는 않는다. 현행 `b=1−Ū`는 같은 성분·대응에서의 조건부 한계이며, 실제 표현·갱신에 어떻게 적용할지는 여기서 설계한다. 국소 좌표 표현과 규모 분리 자체를 독창성으로 주장하지 않는다.

### 5.3 현재 기하·외관의 갱신

**의도:** 현재 색과 관측 가능한 세부를 복원하면서 영상 잔차를 줄이기 위해 기준 기하가 불필요하게 이동하는 일을 통제한다.

**계산의 출발안:** 현재 영상의 유효 관측에서 색·밝기·시점 의존 외관을 설명할 변수와 비용을 정한다. 비교 가능한 출발 절차로, 초기 기하·크기·불투명도를 고정한 외관 적합을 두고 이후 허용된 기하·외관 갱신을 검토한다. 색·밝기로 설명되지 않은 잔차도 곧바로 기하 변경의 증거로 삼지 않는다. 기각된 MVS의 깊이·법선 감독은 제외하고, 허용된 관측과 인계된 기하 범위 안에서만 갱신한다.

갱신 후보마다 산출 표면의 변형·존재·지지 범위를 계산하여 허용 여부를 정한다. 범위를 벗어나면 해당 이동을 축소하거나 직전 허용 상태로 복원하는 절차를 정하고, 초기 상태부터 허용 조건을 만족하지 못하는 경우도 기록한다. 크기·불투명도는 영상 색뿐 아니라 표면 읽기에도 영향을 주므로 외관 전용 변수로 취급하지 않는다.

**작성할 결과:** 최적화할 변수와 고정할 변수, 영상 비용과 기하 조건, 갱신 생성·검사·채택/축소/복원 순서가 연결된 알고리즘. 표면 조건을 직접 계산할지, 대리 조건을 사용하고 최종 검사로 연결할지와 그 관계를 정한다. 새로운 손실 항의 이름만 늘리지 않으며, 처음의 외관 적합을 둘 필요성도 비교한다.

### 5.4 경계·분할·제거 처리

**의도:** 다른 소스를 선택한 영역들을 일관된 표면으로 연결하고, 결손 보완·세부 표현에 필요한 Gaussian 수 변화를 허용하면서 단차·유보 경계를 유지한다.

**계산의 출발안:** 고정 판단이 같은 현재 표면으로 지지한 이웃만 접합 대상으로 삼아 연결 관계와 경계 차이를 계산한다. 실제 단차·다른 층·미확정 경계는 구분한다. 지지된 접합 구간에서 어떤 위치·방향·외관 연속성을 최적화할지 정하되, 경계 처리로 사용 범위를 새로 승인하지 않는다.

분할·복제에서는 자식 중심·방향·크기·불투명도가 원표면의 범위와 렌더 표면을 어떻게 바꾸는지 계산한다. 제거에서는 낮은 불투명도만이 아니라 지지된 표면의 소실 여부를 확인한다. 부모 출처 태그의 복사만으로 자식의 범위가 허용되었다고 보지 않는다. MVS 결손을 prior에서 초기화하는 것, 이미 지지된 표면의 표현을 세분하는 것, 미관측 영역으로 새 표면을 생성하는 것을 구분한다.

**작성할 결과:** 경계의 연결 관계·연속성 조건과 Gaussian 분할·복제·제거의 적용 조건, 연산 후 표면 변화의 검사 절차. 비교에는 이음새 감소뿐 아니라 잘못된 연결, 표면 소실과 유보 범위 침범을 포함한다.

### 5.5 표면 산출과 검사

**의도:** 렌더 영상의 개선이 실제 기하·외관의 개선으로 이어졌는지 확인한다.

**계산의 출발안:** 렌더링할 GS 장면과 평가할 파생 표면의 관계를 먼저 정한다. 깊이·법선·불투명도에서 어떤 고정 규칙으로 표면 `S(G)`를 얻는지, 여러 뷰의 표면을 합칠 때 지지 범위와 불연속을 어떻게 보존하는지 결정한다. 초기화·중간 갱신·최종 평가에서 사용하는 표면 정의를 일치시키거나 서로 다를 경우 오차 관계를 계산한다. 단순히 Gaussian 중심만 가까운 상태를 표면 보존으로 판정하지 않는다.

**작성할 결과:** 표면 추출·대응과 위치·방향·존재·경계의 검사식, 현재 참조에 대한 실제 오차 및 별도 평가 영상의 외관 비교. 출력이 사라진 위치를 평가에서 제외하여 정확도가 좋아 보이게 하지 않는다. 기준 기하 보존과 실제 현재 기하 정확성은 따로 기록한다.

**재구성의 추가 효과를 확인할 비교.** 같은 실제 판단·기준 기하·유효 관측·평가 범위를 주고 다음 비교를 구성한다. 각 방법의 고유한 표현과 최적화 방식은 명시하며, 수정한 변형을 원논문의 재현으로 부르지 않는다.

| 비교할 재구성 | 구체적으로 확인할 질문 |
|---|---|
| 선택한 표면의 접합·현재 영상 텍스처링 | 이미 사용할 기하가 있을 때 GS로 다시 재구성할 추가 이득이 있는가? |
| 같은 초기 GS에서 기하를 고정한 외관 적합 | 외관만 바꾸어 얻는 효과를 넘어 기하·세부 갱신이 필요한가? 표면에 영향을 주는 변수의 고정 범위를 명시 |
| 같은 초기 GS의 기존 prior 손실 기반 최적화와 강한 기존 prior 재구성 | 현재 설계의 변수·갱신 제약이 기존의 기하 감독보다 구조·세부·외관의 관계를 개선하는가? |
| 위 계산을 구체화한 제안 재구성 및 구성요소 제외 비교 | 구조·세부 분리, 표면 검사, 경계·분할 처리 중 실제로 개선·열화를 바꾼 계산은 무엇인가? |

P2 안에서 먼저 작은 지지 영역의 표현·갱신을 확인하고 같은 고정 지역의 결손·경계로 연결한다. prior 단독 사례는 첫 계산 사례이며, 전체 재구성 범위를 prior 표면 하나에 한정하지 않는다. 해당 지역에 실제로 없는 상태는 없다고 기록한다.

**재사용을 검토할 구현 경로.** 다음 코드는 기반 기능의 위치이며 새 판단·재구성 방법이 이미 구현되었다는 뜻은 아니다. 과거 실행 드라이버를 그대로 재실행하는 대신 기능과 적용 범위를 읽고 새 설계에 필요한 부분을 정한다.

| 경로 | 확인할 기반과 남은 설계 |
|---|---|
| [학습·초기화](../../../../src/stage2/train.py) | 표면 시드 공급과 GS 학습. 네 행동별 기하·감독 인계, 갱신 허용·복원 절차와 구분 |

## 6. C — 동일 지역의 분리·통합 검증

**① 공통 지역·자료·평가 단위를 먼저 고정한다.** P2 입력과 평가 참조의 실제 겹침을 확인하고, 공통 단위 ID·원점 소속·영역·자료 역할·변환·제외 사유를 하나의 manifest로 연결한다. 동일 지역이라는 이유로 판단·학습·평가 사진을 구별 없이 재사용하지 않는다. 이미 사용한 개발 66뷰를 손대지 않은 확증 자료로 재명명하지 않는다. 참조가 없는 곳은 평가 불가로 보고하며, 자료가 부족하면 검증 가능한 범위와 부족한 입력을 먼저 명시한다. 성능을 본 뒤 유리한 지역으로 옮기지 않는다.

**② A와 B를 병행 설계한다.** §4에서는 판단 비교법·추가 계산·조건표·오차/유보 평가를, §5에서는 Gaussian 표현·구조와 세부의 변수·기하/외관 갱신·경계와 증감·표면 추출을 정한다. 각 작업의 계산·미결·산출물을 따로 작성하고 공통 인계 항목을 맞춘다. 어느 한쪽을 마친 뒤 다른 쪽을 시작해야 하는 연구 일정으로 묶지 않는다.

**③ 판단과 재구성을 각각 비교한다.** 아래 표의 ‘판단만 변경’과 ‘재구성만 변경’ 조건을 구성한다. 판단 비교는 후보·관측·오차 기준과 하류 재구성을, 재구성 비교는 실제 판단·기준 기하·지지 범위·허용 변형을 맞춘다. 미확정 값을 임의로 채우지 않으며, 조건을 가정한 계산 검산과 실제 판단으로 그 조건을 확보한 검증을 구별한다.

**④ 구체화한 방법을 같은 지역에서 구현·개발 검증한다.** Docker에서 새 설정·코드·입력·출력 계보를 기록하며 필요한 계산을 실행한다. 기존 실행 폴더는 보존하고 새 출력에 저장한다. 선택한 판단을 고정한 뒤 GS를 반복하고 결과를 검증한다. 판정 근거 또는 표면 제약을 계산할 수 없으면 해당 범위의 유보·실패를 기록하며, 이를 현재 재구성 성공으로 채우지 않는다.

비교는 다음 세 가지를 연결한다.

| 비교 | 공통으로 둘 것 | 확인할 결과 |
|---|---|---|
| **판단만 변경** | 지역·후보·허용 관측·사용 허용오차·평가 단위, 하류 재구성 | 같은 채택 범위의 오채택, 같은 위험의 채택 범위, 사용할 수 있는 후보의 유보, 오차 범위의 타당성과 미산출 사유 |
| **재구성만 변경** | 같은 실제 판단 결과·기준 기하·지지 범위·허용 변형·관측 | 선택·접합·텍스처링 및 기존 prior 재구성 대비 초기 표현 차이, 표면 이동·소실·경계·완전성, 현재 외관·세부, 양호 영역의 열화 |
| **전체 방법 비교** | 같은 지역·원입력·평가 기준과 비교 가능한 자원 | 강한 기존 순차 조합 대비 최종 기하·외관 개선, 실패·유보 면적과 원인, 개선이 발생한 단계 |

현재 UAS와 LoD2 RoofSurface·Z 등 평가 전용 정보는 후보 생성·정합·소스 선택·문턱 조정에 사용하지 않는다. 공통 GroundSurface XY·stable ID의 허용 통제는 기존 계약을 따른다. 참조의 피복과 정확도가 뒷받침하는 범위에서 실제 오차를 평가하며, 표현 차이나 학습 영상 적합도를 실제 정확도의 대용으로 삼지 않는다. 같은 개발 지역의 반복 검증은 일반화·확증 결과가 아니다.
