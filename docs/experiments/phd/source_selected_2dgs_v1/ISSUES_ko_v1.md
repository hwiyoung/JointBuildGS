- 원인: 최종 미리보기 검증 컨테이너가 `report/preparation_overview.png`와 `data.json`을
  root 소유로 생성했다. 실행 대기열의 고정 UID 1000은 PNG를 직접 갱신할 수 없었다.
- 조치: 이번 attempt의 두 파생 표시 파일만 UID/GID 1000으로 수정했다. 입력과
  동결 소스는 그대로 유지하고, 최초 PID/시작/로그/실패 상태를 별도 event에 보존한다.

  `status.txt`로 확인한다. 초기 실패를 기술 완료로 덮어 기록하지 않는다.
- 복구 확인: 새 PID 3387832 / PPID 1 / SID 3387832를 확인했다. 동결 소스 검사와

  시작 시점의 기록은 `background_status_receipt.json`이며 새 GPU 학습은 아직 시작 전이다.
