# 2단계 설계 v3 — 의미, 1단계와의 연결, 사례의 수식 적용

> 상태: 발주서 작성 직전 정리(2026-09-24). `scientific_verdict: null`. 용어: 조건 = 학습 실행 조건.

## 0. 2단계는 무엇인가

1단계가 자리마다 기록한 두 가지, **A(사진이 이 자리를 재는가)** 와 **τ(정상적인 차이의 폭)** 를 GS 학습의 손실과 갱신 규칙에 넣어,
옛 자료가 맞는 자리는 남기고, 사진이 재는 자리의 틀림은 사진으로 고치고, 사진이 못 재는 자리는 옛 자료를 붙잡아 두는 학습이다.
판정은 라벨이 아니라 A·τ(·E)가 만드는 가중과 손실 모양 그 자체이고, 끝에 면별 표로 읽어 낸다.

## 2. 손실과 갱신 규칙

시점 v를 하나 골라 렌더한 카메라 깊이를 D_p, 1단계 MVS 깊이를 M_p, 옛 자료 깊이를 P_p, 관측 여부를 A_p ∈ {0,1}라 하자.

```
L(v) = L_rgb(v)
     + λ_mvs   · Σ_p A_p · |D_p − M_p|                    / Σ_p A_p            (영상 깊이 항, A=1인 픽셀만)
     + λ_prior · Σ_p (1 − A_p) · ρ_{τ_p}(D_p − P_p)       / Σ_p (1 − A_p)      (옛 자료 깊이 항, A=0인 픽셀만)
     + (2DGS 정규화: 법선·왜곡, GeoGS 그대로)

ρ_τ(r) = 0            (|r| ≤ τ)        정상 차이: 당기지 않음
       = |r| − τ      (τ < |r| ≤ 4τ)   τ를 넘은 만큼만 당김
       = 3τ           (|r| > 4τ)       상수: 더는 당기지 않음(옛 자료를 고집하지 않음)
τ_p = τ_v / f_p ,  f_p = |n_p·d_p| / |n_p,z|   (연직 폭을 그 픽셀 광선의 카메라 깊이 폭으로)
```

원반 k(옛 자료 출신)의 관측 여부 E_k: 0회와 500회마다, 중심 x_k를 학습 시점 13장에 투영해 보이는 시점(옛 자료 깊이와 0.5 m 안)에서 A를 읽어 평균.

```
E_k ≥ 0.5 → 자유 (보통 학습률, 불투명도 재설정·가지치기·분할 모두 허용)
E_k < 0.5 → 잠금 (위치·회전·크기 학습률 ×0.01, 불투명도 ≥ 0.5로 클램프, 재설정·가지치기·분할 면제)
관측 출신·밀집화 출신 원반은 늘 자유(자식은 부모 출처 상속)
```

초기 원반 = 옛 자료 점(출처 prior) ∪ SfM 점(출처 관측). 8000회 규약·거리 기반 보호 등록 없음. λ_mvs, λ_prior는 GeoGS 기본 0.05에서 짧은 예비 실행으로 고정.

판독(30,000회 뒤, 시점별 렌더 깊이 D를 저장): LoD2 면 F마다
```
d_F   = median_{p∈F, A_p=1} ( (D_p − P_p) · f_p )        옛 자료로부터의 연직 이동
e_F   = median_{p∈F, A_p=1} ( (D_p − M_p) · f_p )        사진으로부터의 연직 차
cov_F = Σ_{p∈F} A_p / |F|
보존   : cov_F ≥ 0.5 이고 |d_F| < τ_v
보정   : cov_F ≥ 0.5 이고 |d_F| ≥ τ_v 이고 |e_F| < τ_v
미판정 : cov_F < 0.5
```
GT 평가(평가 전용): GT 점군을 같은 카메라로 투영한 깊이 G_p로 g_F = median((D_p − G_p)·f_p). 조건 간 차이로 읽는다.

## 3. 사례가 수식에서 어떻게 되는가

## 4. 조건과 무엇을 가르는가

| 조건 | 옛 자료 항 | 원반 잠금 | 초기화 | 영상 깊이 항 |
|---|---|---|---|---|
| P 판정 켬 | (1−A)·ρ_τ | E<0.5 잠금 | prior ∪ SfM | A·L1 (MVS) |
| P0 판정 끔 | 1·L1 (모든 픽셀, 팽팽) | 없음 | prior ∪ SfM | 같음 |
| O 공식 GeoGS | 8000회 이후 L1(λ 0.005) | 거리 기반 보호 | prior 표본만 | DA3 단안 깊이 |
| I 영상 단독 | 없음 | 없음 | SfM만 | A·L1 (MVS) |

P−P0 = 판정의 효과, P0−O = 골격(MVS 깊이·SfM 씨앗·단일 단계)의 효과, P−I = 옛 자료의 효과.
장면: 정상 N, 본지붕 1 m 주입 B. 옛 자료: L, M. 회수: P 4 + P0 4(또는 정상만 2) + O(M) 2 + I 1 = 11(또는 9).
영역: 단일 건물 장면(15시점, 학습 13·시험 2), 옛 자료는 대상 건물 ±15 m 크롭 안에서만, 평가는 대상 건물 지붕 6면·벽면.

## 5. 결과가 뜻하는 것 (읽는 법)

- ①에서 d_F(P)와 g_F(P)가 O·I와 같거나 작다 → 판정이 맞는 곳을 해치지 않는다.
- ②에서 d_F ≈ −1.0, g_F(B) ≈ g_F(N) → 틀린 옛 자료를 사진으로 고쳤고 스스로 "보정"으로 표시했다.
- ③에서 g_F(P) < g_F(O) (3387·3389) → 공식 방법이 못 하던 빠뜨림 보정을 판정 골격이 한다. P0와의 차이가 그중 판정의 몫.
- ④·⑤의 면 수가 4.5% 안이고 P의 형상이 I보다 옛 자료에 가깝다 → 못 재는 자리를 옛 자료로 채웠다.
- P0에서 ①이 흔들리거나 ③이 덜 고쳐진다 → 팽팽한 옛 자료 줄과 자물쇠 없음의 대가가 곧 판정의 값어치다.
