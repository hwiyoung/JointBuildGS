# 2단계 설계 초안 v1 — 관측 신뢰도·허용 오차로 조종되는 prior 기반 GS 학습

> 상태: 설계 토론용 초안(2026-09-23). 실행 권한 없음. `scientific_verdict: null`.
> 1단계 인계값은 실측 폭 기준(사용자 결정 2026-09-23): τ_L = 2.5·s2 = 4.1 cm, τ_M = 5.7 cm(연직, 지붕 풀; `PHD-STAGE1-VERIFY-v2/out_v2_data/`).
> 실측 폭에서의 검증: 민감도 L 0.99/0.99, M 1.00/1.00; 두 장면 τ 상대차 L 4.8%·M 0.2%; 중심 통과; 정상 장면 폭 밖 L 16.6%(본지붕 13.5%), M 20.2%(본지붕 14.6%). 1 m ÷ τ = L 25, M 18.
> 사양값(ALS 12 cm, LoD2 1 m)은 폭이 아니라 "오류 크기 규모"로만 기록한다.

## 0. 한 줄 목적

1단계가 만든 두 산출물, A(사진이 잴 수 있는 자리)와 τ(정상 차이의 폭)를 GeoGS 학습에 넣어,
옛 자료가 맞는 곳은 **보존**하고, 사진이 잘 보는 곳의 틀림은 **보정**하고, 사진이 못 보는 곳은 **보류**하는지를
판독 가능한 형태(면 단위 표)로 보인다. 정답을 아는 틀림(주입 면)과 실제 빠뜨림(도머·처마)이 시험 대상이다.

## 1. 진단 실험이 미리 알려 준 것 (설계 전제)

공식 GeoGS(GEOGS-ROOF-BIAS-20260921, 5조건 완료)는 LoD2를 +1 m 올려도 최종 지붕 오차가 거의 안 변한다
(GT 대비 부호 오차 중앙값 N 0.225 → B+1.0 0.246 m). prior 출신 원반은 보호되지만 불투명도 중앙값 0.004로 사실상
투명해지고, 지붕은 보호되지 않은 원반이 그린다. 즉 공식 방법은 "틀린 prior를 고집"하지 않고 사진이 이기게 둔다.
따라서 2단계의 차별점은 "해치지 않음"이 아니라 다음 셋이다.

- 사진이 못 보는 자리(A=0, 지붕의 4.5%)에서 prior 구조를 실제로 유지하는가(공식 방법은 거기서도 prior가 투명해진다).
- 무엇이 보존·보정·보류됐는지를 방법이 스스로 **판독**해 내놓는가(공식 방법은 판독이 없다).
- 사진이 보는 자리의 실제 빠뜨림(처마·도머; 실측 폭 기준 지붕의 17~20%, 그중 본지붕 내부 13~15%)을 국소 보정하면서 본지붕을 흔들지 않는가.

## 2. 질문 세 개 (측정 가능한 형태)

| 질문 | 시험 자리 | 측정 | 기대(1단계 인계) |
|---|---|---|---|
| Q1 보존 | 옛 자료가 맞는 본지붕(3396) | 결과 표면 − prior의 면 중앙값 \|d\| < τ; GT 오차가 공식·영상단독보다 나쁘지 않음 | 보존 |
| Q2 보정 | 주입 면(3387·3389·3404)과 빠뜨림 면(3394 등) | 면 중앙값 \|d\| ≥ τ이고 결과 − MVS < τ; GT 오차가 정상 수준으로 복귀 | 보정, 주입 면 97~99% |
| Q3 보류 | A=0 자리 | prior 유지·판독 "미판정"; 영상 단독은 구멍/잡음 | 미판정 ≈ 4.5% |

## 3. arm

방법 × prior × 장면. 장면은 1단계 v2의 정합된 정상판(N)과 소면 주입 편향판(B).

| 방법 | 내용 | L-N | L-B | M-N | M-B |
|---|---|---|---|---|---|
| P 제안 | 5수정 GeoGS | ○ | ○ | ○ | ○ |
| O 공식 | GeoGS 그대로(prior 깊이 배열만 교체) | △ | △ | ○ | ○ |
| I 영상 단독 | prior 항·초기화·보호 없음, MVS 깊이 항만 | ○ (장면 무관 1회) | | | |

최소 7회(P 4 + O-M 2 + I 1), 전체 9회(O-L 2 추가). 회당 약 1시간(30,000회, 진단과 동일 설정), GPU 2장 병렬로 4~5시간.

주입량: 실측 폭 기준에서는 1 m가 이미 τ의 25배(L)·17배(M)이므로 **두 prior 모두 Δ = 1.0 m**로 통일(M 소면 1 m 편향판 렌더 필요, 2분).
v2의 M 3 m는 검증용이었고 2단계에는 쓰지 않는다.

## 4. 방법 P의 다섯 수정과 GeoGS 코드 자리

기반 소스: `GeoGS-mvs-pgsr-v1`(공식 db40c95 + MVS 깊이 적재 `jbgs_mvs_pgsr` + 상태 계측 `jbgs_state`). 새 분기 `GeoGS-conf-guided-v1`로 패치하고 해시를 남긴다.

| 수정 | 공식 코드 자리 | 바꾸는 것 |
|---|---|---|
| ① prior 깊이 항 절단·가중 | `train.py` `compute_depth_loss(surf_depth, lod_depth)` (L1, 8000회 이후 λ 0.005) | 새 손실: \|r\| ≤ τ_px → 0, τ_px < \|r\| ≤ 4τ_px → \|r\| − τ_px, 그 밖 → 3τ_px. 픽셀 가중 (1 − A)·prior 마스크. τ_px = τ_v / (\|n·d\|/\|n_z\|)를 prior 법선 지도(`raw_normal`)로 시점별 미리 계산해 깊이 지도처럼 적재. 8000회 이전(`lambda_lod_init` 0.08, L1)은 유지(초기 형상 구축). |
| ② 영상 깊이 항 | DA3 슬롯 → MVS 깊이(`jbgs_mvs_pgsr.load_mvs_depth_set` 기존) | `conf_map` 인자에 A(0/1)를 넣어 A 가중 L1. 동적 가중(`dynamic_depth_weight`) 대신 고정 λ_mvs(기본 0.05)로 통제. |
| ③ 원반 신뢰도 E | 8000회 전환 시 `find_building_mask_from_pcd`(prior 점 0.2 m 이내 → `frozen_mask`) 후 `attenuate_*_lr`(×0.01) | prior 출신 원반 중심을 13개 학습 시점에 투영해 A 평균 = E. E < 0.5 → 기존 감쇠(×0.01) + 불투명도 하한 0.5(`completed_mask` 하한 장치 재사용); E ≥ 0.5 → 감쇠 없음. 500회마다 재계산. |
| ④ 밀집화·가지치기 | `densify_and_prune` + 재감쇠 | prior 출신·E < 0.5는 분할·가지치기 제외(동결), 그 외 허용. 제거·분할 기록에 출처·E 남김. |
| ⑤ 초기화 관측 점 | `--lod_init` → `sparse_lod/0` (prior 메시 표본 `generate_pcd.py`) | MVS 융합 점 중 prior 표면 연직 거리 > τ_v인 점을 관측 출처로 추가(합성 트랙 동일 방식). 원반마다 출처 태그(prior/관측/밀집화 자식은 부모 상속). |
| 판독 | (없음) | 30,000회 뒤 시점별 렌더 깊이 − prior 깊이 − MVS 깊이 → LoD2 면별 중앙값 d(연직) → 보존/보정/미판정. 원반별 출처·E·불투명도·이동량은 기제 설명용 2차 기록. |

L prior도 같은 자리에 들어간다: 깊이 배열은 v2 ALS TIN 렌더, 보호·초기화 점군은 ALS 점(정합 후) 그대로.

## 5. 입력 (모두 1단계 v2 산출)

- A: `PHD-STAGE1-CONF-TOL-CONFLICT-v1/out/conf/{view}_conf.npy` 15시점(학습 13, 판독 15).
- τ_v: `PHD-STAGE1-VERIFY-v2/out_v2_data/stage2_config_v2_{L,M}.json` (실측 폭). 4τ, 3τ 상수는 규칙대로.
- prior 깊이·법선: `PHD-STAGE1-VERIFY-v2/inputs_v2/prior_render/{L,M}_{nominal,biased_small}/lod2_prior/{raw_depth,raw_normal}` (정합 반영; M 소면 1 m 판은 추가 렌더).
- prior 점군: M = 정합 메시에서 `generate_pcd.py`; L = `inputs/als_points.npz` 정합 후 점.
- MVS 깊이: `inputs/mvs_full` (시점 격자) 또는 원 배열; 관측 초기점은 COLMAP 융합 점군(있으면) 또는 깊이 역투영.
- 기대치(실측 폭): 정상에서 폭 밖 비율 L 16.6%(본지붕 13.5%, 소면 43~66%), M 20.2%(본지붕 14.6%, 소면 53~96%) = 2단계가 정상 조건에서 '다듬기'로 건드릴 상한; 편향에서 주입 면 민감도 L 0.99·M 1.00 = '보정' 기대; 구멍 4.5% = '미판정' 상한.

## 6. 평가 (측정만, 판정 없음)

1. 판독표: arm별 면 라벨과 d(연직). 주입 면의 "보정" 정밀·재현, 본지붕 "보존" 비율, "미판정" 비율 vs 기대 4.5%. P·O·I 모두 같은 렌더 깊이 판독으로 비교.
2. GT(평가 전용, 진단과 같은 파이프라인: 크롭 → mesh2pcd → 최근접 부호 오차, 지붕/벽면·면별): N/B × P/O/I. 주입 면의 B 오차가 N 수준으로 돌아오는가, 본지붕 오차가 O·I보다 나쁘지 않은가, A=0 자리의 오차가 I보다 좋은가.
3. 부수: 시험 시점 2장 PSNR·SSIM, E 분포, 출처별 가지치기 기록, prior 원반 불투명도(진단 표 C 방식).
4. 진단이 보인 GT 대비 +0.22 m 상수 편차는 프레임 차이 가능성이 있어, 절대값보다 arm 사이 차이와 NMAD로 읽는다. 별도로 GT−MVS 편차를 한 번 재서 기록한다(평가 전용).

## 7. 실행·예산

- Docker: GeoGS 호환 이미지(진단과 동일), 수정 소스 마운트. 회당 30,000회 ≈ 1시간, GPU 0·1.
- 사전 점검: 절단 손실·E 계산·판독의 단위 시험(합성 배열), arm별 100회 스모크, 상태 계측으로 재개 가능.
- 산출: arm별 모델·렌더·판독표·GT 표, 보고서(사실 서술), 그림(면 라벨 지도 전·후, 단면). 뷰어는 최소(그림)로.

## 8. 위험

- GS 표면 잡음이 τ(4~6 cm)보다 클 수 있다 → 판독은 면 중앙값을 1차로, 픽셀 충돌은 2차로. 정상 arm의 본지붕에서 잡음 바닥을 먼저 잰다.
- 실측 폭에서는 옛 자료가 맞는 본지붕에서도 픽셀의 13~15%가 폭 밖이라, 절단 prior 항이 그 픽셀에서 켜져 MVS 항과 줄다리기한다. 면 중앙값 판독은 흔들리지 않겠지만 픽셀 단위 잔차는 λ 비율에 민감하다 → λ_mvs·λ_prior를 고정하고 기록한다.
- 8000회 이전 단계가 틀린 prior 형상을 먼저 만들고 8000회 이후 MVS 항이 고쳐야 한다 → 고정 λ_mvs로 통제, 동적 감쇠 배제.
- ALS 점군으로 보호하면 지면 원반도 보호된다(클래스 2 포함) → 의도된 동작으로 기록.
- 시험 시점 2장은 A·τ 계산에는 쓰였고 학습에는 안 쓰인다 → 외관 지표만 그 2장으로.

## 9. 결정 사항

1. arm 범위: 최소 7회 / 전체 9회.
2. 주입량: 양 prior Δ = 1.0 m(권고) / v2 그대로(L 1 m, M 3 m).
3. 영상 항 가중: 고정 λ_mvs(권고) / GeoGS 동적.
4. 판독 1차 단위: LoD2 면 중앙값(권고) / 원반.
5. GT 평가 포함(권고, 평가 전용) / 판독만.
6. 기반 소스: `GeoGS-mvs-pgsr-v1` 분기(권고) / 공식 소스에서 새로.
