# 2단계 설계 초안 v2 — 판정이 최적화를 조종하는 prior 기반 GS 학습

> 상태: 설계 토론용 초안(2026-09-23 밤, v1의 문답 반영). 실행 권한 없음. `scientific_verdict: null`.
> 용어: "조건" = 한 번의 학습 실행 조건(방법 × 옛 자료 × 장면). 이전 초안의 "arm"은 이 뜻이다.

## 0. v1에서 고친 것

1. **8000회 보호 등록을 없앤다.** 처음부터 prior 출신 원반과 관측(사진) 출신 원반을 함께 넣고, 원반 신뢰도 E와 판정 기반 가중을 0회부터 적용한다. 8000회는 공식 GeoGS의 2단계 규약과 1단계 연결표에서 온 것이지 설계 의도가 아니었다.
2. **판독은 목적이 아니라 수단이다.** 판정(픽셀·원반·면 단위의 일치/충돌/미관측)은 학습 중에 가중·동결·씨앗을 조종하는 제어 신호이고, 성과는 기하 품질(GT 대비 오차, 비악화)로 잰다. 사후 라벨(보존/보정/미판정)은 진단용 부산물이다. 판정의 효과는 **같은 파이프라인에서 판정만 끈 절제 조건**과의 차이로 분리한다.
3. **"사진이 못 보는 자리"를 세 상태로 나눈다.** (i) MVS 일관 = A=1, (ii) 카메라는 보지만 MVS 비일관 = A=0(무텍스처·그늘·얇은 구조), (iii) 어느 카메라도 못 봄. 진단 실험을 다시 잰 결과 공식 GeoGS에서 prior 원반의 운명을 정하는 것은 보호 장치가 아니라 RGB 손실이다(4절).

## 1. 진단 실험을 다시 잰 사실 (설계 전제)

공식 GeoGS N·B+1.0 실행의 최종 원반(건물 크롭 62만 개)에 1단계 A를 투영해 관측 상태별로 불투명도를 나눴다.

| prior 출신 원반 | N: 불투명도 중앙값 / >0.5 비율 | B+1.0 (prior 1 m 위): 중앙값 / >0.5 |
|---|---|---|
| 어느 학습 시점도 못 봄 (374 / 993개) | 0.21 / 45% | 0.006 / 33% |
| 카메라는 보지만 MVS 비일관, E=0 (218 / 467개) | 0.25 / 39% | 0.004 / 9% |
| 0 < E < 0.5 (545 / 2,245개) | 0.004 / 23% | 0.004 / 2% |
| E ≥ 0.5 (47,442 / 24,555개) | 0.37 / 44% | 0.012 / 8% |

- 옛 자료가 맞을 때(N) prior 원반은 관측 상태와 무관하게 절반쯤 살아남고, 틀릴 때(B+1.0)는 관측 상태와 무관하게 거의 다 투명해진다. 죽이는 것은 MVS가 아니라 RGB다. 1 m 위에 떠 있는 원반은 진짜 지붕의 텍스처를 가리므로 카메라가 보기만 하면 사라진다.
- 따라서 "A=0 자리 보존"은 공식 방법과의 차별점이 되기 어렵다. 그 자리의 prior 원반은 공식 방법에서도 대체로 남는다(다만 불투명도 재설정으로 절반은 흐려진다). 차별점은 다른 데 있다(2절).
- 공식 GeoGS의 면별 GT 오차(N): 본지붕 3396 +0.23 m(NMAD 0.04), 뒷지붕 3393 +0.14, 3394 +0.17, 3404 +0.14, **3387 +0.31(NMAD 0.23), 3389 +0.86(NMAD 1.0)**. prior를 1 m 올려도 면별 값은 2 cm 안에서 같다. 즉 (a) 전 면에 +0.14~0.25 m의 상수 편차가 있고(GT 프레임 또는 표면 추출 편향, 5절에서 확인), (b) 소면 3387·3389에서 공식 방법이 실패하며(1단계에서 MVS−prior 충돌 62~75%인 면), (c) 그 실패는 prior 높이와 무관하므로 원인은 영상 항(DA3 단안 깊이)이나 GS 자체다. 여기가 2단계가 개선을 보일 수 있는 구체적 자리다.

## 2. 2단계가 답할 것

1. **판정이 최적화를 좋게 하는가.** 판정을 켠 조건(P)이 판정을 끈 절제 조건(P0: 같은 초기화·같은 항, A≡1·τ→∞·E≡1)보다 GT 오차가 낮거나 같은가. 어디서 좋아지는가(면별).
2. **틀린 옛 자료를 사진이 좋은 자리에서 고치는가.** 소면 주입(Δ 1 m) 조건에서 주입 면의 GT 오차가 정상 조건 수준으로 돌아오는가. 공식 GeoGS도 이건 한다(1절). 그러니 기준은 "고치는가"가 아니라 "고치면서 본지붕과 나머지 면을 흔들지 않고, 고친 자리를 스스로 표시하는가"다.
3. **실제 빠뜨림 면(3387·3389)에서 나아지는가.** MVS 깊이 항 + 관측 씨앗 + 충돌 픽셀에서의 prior 해제가 공식 방법의 0.31/0.86 m 실패를 줄이는가. 이것이 가장 직접적인 개선 지표다.
4. **A=0·미관측 자리에서 무엇이 남는가.** 절대량은 작다(prior 원반의 1% 남짓). 기록만 하고 주장하지 않는다.

## 3. 방법 P: 판정이 조종하는 것

초기화(0회): prior 원반 = prior 점(M: 정합 메시 표본, L: 정합 ALS 점) 전부, 출처 태그 prior. 관측 원반 = MVS 깊이를 역투영한 점 중 prior 표면에서 연직 거리 > τ인 점(1단계 규칙), 출처 태그 관측. 둘 다 같은 초기 불투명도.

| 판정 신호 | 어디서 오나 | 무엇을 조종하나 |
|---|---|---|
| 픽셀 A (0/1) | 1단계 conf.npy | 영상 깊이 항 가중 = A, prior 깊이 항 가중 = 1 − A |
| 픽셀 잔차 대 τ | 렌더 깊이 − prior 깊이, τ_px = τ_v / (\|n·d\|/\|n_z\|) | prior 항 절단: \|r\| ≤ τ → 0, 4τ까지 초과분, 그 밖 3τ 상수 |
| 원반 E | 원반 중심을 학습 시점에 투영해 A 평균, 0회와 500회마다 | prior 출신·E < 0.5: 위치·회전·크기 학습률 ×0.01, 불투명도 하한 0.5, 불투명도 재설정 면제, 밀집화·가지치기 동결. E ≥ 0.5: 자유 |
| 면 충돌 비율(선택) | 1단계 면표 또는 학습 중 렌더 깊이의 면 중앙값 | 충돌 비율 높은 면의 prior 원반은 E와 무관하게 자유(선택 사항, 절제로 효과 확인) |

영상 깊이 항은 DA3 대신 MVS 깊이(분기 `jbgs_mvs_pgsr`가 적재), 고정 λ. RGB·정규화·밀집화·표면 추출은 GeoGS/2DGS 그대로.
절제 P0 = 같은 초기화(prior + 관측 원반)에서 A≡1, τ→∞(절단 없음, L1), E≡1(동결 없음). P0 − O(공식)의 차이가 "MVS 깊이 + 관측 씨앗 + 단일 단계"의 효과, P − P0의 차이가 "판정"의 효과다.

## 4. 조건 (학습 실행)

| 방법 | L-정상 | L-소면 주입 | M-정상 | M-소면 주입 |
|---|---|---|---|---|
| P 판정 켬 | ○ | ○ | ○ | ○ |
| P0 판정 끔(절제) | ○ | ○ | ○ | ○ |
| O 공식 GeoGS(prior 배열만 교체) | | | ○ | ○ |
| I 영상 단독(prior 없음, MVS 항) | ○ (장면 무관 1회) | | | |

11회, 회당 약 1시간, GPU 2장으로 6시간. 주입은 소면 3개에 Δ = 1.0 m(양 prior 동일; M 1 m 편향판 렌더 필요). 공식 O의 L 조건은 선택.

## 5. 평가 (측정만)

- GT(평가 전용) 면별 부호 오차: 지붕 6면·벽면, 조건마다. 판정 효과 = P − P0, 방법 효과 = P0 − O, prior 효과 = P − I. 비악화 = 본지붕에서 P가 O·I보다 나쁘지 않음.
- **GT 프레임 편차(측정 완료)**: 정합된 prior 대비 GT의 연직 차는 본지붕 3396 +0.07 m(NMAD 0.06), 뒷지붕 +0.03, 3394 +0.02, 3387 +0.20, 3389 +0.18(3404는 급경사 소면이라 수직선 표본이 섞여 무효). MVS는 prior와 1 cm 안에서 맞으므로 GT는 장면 프레임과 7 cm 안에서 맞는다. 따라서 공식 출력의 +0.23 m는 프레임 편차가 아니라 **표면 추출 편향**이다. 진단은 `render.py --mesh_res 1024`의 bounded TSDF를 썼고 복셀 크기 = (카메라 반경×2)/1024 ≈ 0.3~0.5 m, 절단 5복셀이라 표면이 0.2 m 수준으로 양자화·편향된다(모든 면·모든 조건에서 같은 +0.23, NMAD 0.04가 그 증거).
- **평가 대상은 렌더 깊이다.** 30,000회 뒤 학습·시험 시점마다 `surf_depth`를 수치로 저장하고, (a) GT 점군을 같은 카메라로 투영한 GT 깊이, (b) MVS 깊이, (c) prior 깊이와 픽셀별로 비교해 1단계와 같은 축·같은 면 라벨로 면별 중앙값·NMAD를 낸다. TSDF 메시는 필요하면 복셀 0.05 m bounded로 따로 뽑아 참고로만 쓴다. 이 정의로 판정 효과(P−P0)·방법 효과(P0−O)·prior 효과(P−I)를 면별로 읽는다.
- 사후 판독(면별 보존/보정/미판정 라벨과 이동량)은 진단으로만 기록하고, 1단계 기대치(주입 면 보정 0.99, 정상 다듬기 상한 L 17%·M 20%, 미판정 4.5%)와 맞는지 적는다.
- 부수: 시험 시점 2장 PSNR·SSIM, E 분포, 출처별 가지치기 기록.

## 6. 실행

Docker GeoGS 호환 이미지, 분기 `GeoGS-conf-guided-v1`(`GeoGS-mvs-pgsr-v1`에서 파생, 패치·해시 기록). 절단 손실·E 계산·씨앗 선택·판독의 단위 시험, 조건별 200회 스모크, λ 두 값(λ_prior, λ_mvs) 감도 예비 실행 2회(짧게)로 고정값 결정 후 본 실행.

## 7. 더 필요한 내용 (결정 또는 측정)

1. 관측 원반의 재료: COLMAP 융합 점군이 없으므로 시점별 geometric 깊이를 역투영해 만든다. 밀도(격자 간격)와 중복 제거 규칙, 그리고 "τ보다 먼 점만"인지 "MVS 점 전부"인지 결정.
2. λ_prior·λ_mvs 고정값: GeoGS 기본(0.05, 0.05)에서 출발하되 예비 실행으로 확인.
3. 불투명도 재설정(3000회마다 0.01로)과 E<0.5 동결 원반의 하한 0.5가 충돌한다 → 동결 원반은 재설정 면제로 정함(위 표). 확인 필요.
4. GT 프레임 편차: 측정 완료(본지붕 +0.07 m). 남은 것은 렌더 깊이 저장 코드와 GT 깊이 투영 스크립트.
5. 면 충돌 비율로 prior 원반을 해제하는 선택 규칙을 넣을지(P에 넣으면 절제 조건이 하나 더 필요).
6. 공식 GeoGS의 L 조건(ALS 배열을 LoD2 자리에)을 돌릴지.
