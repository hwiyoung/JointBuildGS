# 2단계 실험 발주: 판정(관측 여부·허용 오차)이 조종하는 prior 기반 GS 학습

> 상태: **v1 확정**(2026-09-24). 범위 B0, 12절 항목은 추천안으로 확정(사용자). 실행 준비(소스 분기·단위 시험)에 착수. 실행 착수 전 정정 6건은 13절. `scientific_verdict: null`.
> 용어: **조건** = 학습 실행 조건(방법 × 옛 자료 × 장면). **판정** = 자리마다 옛 자료를 믿을지, 사진을 믿을지, 둘 다 못 믿는지를 정하는 것으로, 1단계의 A(관측 여부)와 τ(허용 오차)에서 나오며 학습 안에서는 라벨이 아니라 가중·손실 모양·잠금으로 작동한다. **원반** = 2D 가우시안(surfel). **출처** = 원반이 어디서 왔는가(prior / 관측 / 밀집화 자식).

## 1. 목적

1단계가 만든 관측 신뢰도 지도 A와 허용 오차 τ를 GS 학습에 넣어, 옛 자료(과거 ALS L, 과거 LoD2 M)가 맞는 자리는 남기고, 사진이 재는 자리의 틀림은 사진으로 고치고, 사진이 못 재는 자리는 옛 자료를 붙잡아 두는 학습이 실제로 그렇게 움직이는지를 **면 단위 기하 오차**로 보인다. 판정의 값어치는 같은 골격에서 판정만 끈 절제 조건과의 차이로 분리한다.

답할 질문:
- Q1 보존: 옛 자료가 맞는 본지붕에서 결과 표면이 옛 자료·사진에서 τ 안에 머물고, 공식 GeoGS·영상 단독보다 나쁘지 않은가.
- Q2 보정: 일부러 1 m 올린 본지붕이 사진 쪽으로 돌아오고, 방법이 그 면을 스스로 "보정"으로 표시하는가.
- Q3 빠뜨림: 공식 GeoGS가 실패한 소면(3387 +0.31 m, 3389 +0.86 m)에서 오차가 줄어드는가. 어느 몫이 골격(MVS 깊이·관측 씨앗)이고 어느 몫이 판정인가.
- Q4 보류: 사진이 못 재는 자리(지붕 4.5%)에서 옛 자료 형상이 남고 "미판정"으로 표시되는가.

## 2. 범위와 지역

- **1차 범위(이 발주)**: 1단계와 같은 단일 건물 장면 B0 = GeoGS 저자 예제(15시점 5644×4082, 학습 13·시험 2, 대상 건물 DEBY_LOD2_4959323). 옛 자료는 대상 건물 ±15 m 크롭 안에서만(L의 ALS 크롭 사각형; M도 같은 사각형으로 자름). 평가는 대상 건물 지붕 6면·벽면.
- B0는 2026-09-15에 채택한 지역 R1~R5(`configs/phd/region_view_support_v1/regions_v1.json`) 밖에 있다. R1~R5로 넓히려면 지역마다 1단계(A·τ·정합·검증)를 먼저 돌려야 하며, 시점 수가 100~350장이라 1단계 렌더·집계가 지역당 수 시간, 2단계는 조건당 1.5~3시간 × 조건 수가 된다. **R1~R5 확장은 B0에서 4절의 의도 점검이 통과한 뒤 별도 발주로 한다.** 확장 규약: 지역마다 (i) 대상 건물 목록과 크롭, (ii) 1단계 실행(같은 스크립트, 지역 시점), (iii) 실측 폭 τ와 기대치 재산출, (iv) 2단계 조건 축소판(P·P0·I, 정상 장면 우선).

## 3. 1단계 → 2단계 연결 (의미별)

### 3.1 관측 여부 — "사진이 이 자리를 재는가"
- 픽셀 A(시점별 `out/conf/{view}_conf.npy`, 0/1) → 영상 깊이 항의 픽셀 가중 A, 옛 자료 깊이 항의 픽셀 가중 1−A. 사진이 재는 자리는 사진이, 못 재는 자리는 옛 자료가 표면을 잡는다.
- 원반 E(학습 중 계산) → 옛 자료 출신 원반의 잠금/해제. E는 A를 원반 자리로 옮긴 것이다.
- 기대치: 지붕 커버리지 95.5% → 미판정 상한 4.5%.

### 3.2 허용 오차 — "얼마나 다르면 틀린 것인가"
- τ_v(연직, 지붕 풀, 실측 폭 2.5·s2): L 0.041 m, M 0.057 m (`PHD-STAGE1-VERIFY-v2/out_v2_data/stage2_config_v2_{L,M}.json`).
- 옛 자료 깊이 항의 느슨한 구간 τ, 기울기 구간 4τ, 상수 3τ. 판독의 보존/보정 문턱.
- 픽셀 환산: τ_p = τ_v / f_p, f_p = |n_p·d_p|/|n_{p,z}| (옛 자료 법선 지도 `raw_normal`과 광선 방향으로 시점별 배열을 미리 만든다).
- 사양값(ALS 0.12 m, LoD2 1 m)은 폭이 아니라 오류 크기 규모로만 기록한다.

### 3.3 프레임과 정합 — "두 자료가 같은 자리에 있는가"
- 정합 이동 L +0.0186 m, M +0.1216 m는 v2 렌더와 점군에 이미 반영되어 있다. 2단계 입력은 모두 v2 정합본을 쓴다. 저자 제공 LoD2 배열은 쓰지 않는다.
- GT는 정합된 옛 자료와 본지붕에서 +0.07 m 안에서 맞는다. 평가는 렌더 깊이로 하고 TSDF 메시는 쓰지 않는다(진단의 +0.23 m는 메시 추출 편향).

### 3.4 옛 자료 자체 — "무엇을 prior로 넣는가"
- 깊이 지도 P(시점별, 정상·본지붕 1 m 주입): `PHD-STAGE1-VERIFY-v2/inputs_v2/prior_render/{L,M}_{nominal,biased_main}` (M 1 m 판은 추가 렌더).
- 법선 지도: 같은 폴더 `raw_normal`.
- 점군(초기 원반·E 계산의 옛 자료 표면): M = 정합 메시 표본(`generate_pcd.py`), L = 정합 ALS 점(`inputs/als_points.npz` + 이동). 둘 다 크롭 안만.

### 3.5 기대치 — "결과가 어떻게 나와야 의도대로인가"
| 자리 | 1단계 근거 | 2단계 기대 |
|---|---|---|
| 본지붕 3396(정상) | MVS−prior 1 cm, 폭 밖 픽셀 13.5%(L)·14.6%(M)는 꼬리 | 면 이동 d_F ≈ 0, 보존 |
| 본지붕 1 m 주입 | 민감도 L 0.99·M 1.00 | d_F ≈ +1.0 m(렌더가 올린 옛 자료보다 1 m 아래 = 사진 쪽), 보정, GT 오차가 정상 수준 |
| 소면 3387·3389·3394·3404(정상) | 폭 밖 43~66%(L)·53~96%(M), MVS−prior −0.1~−0.3 m; 공식 GeoGS 오차 0.31·0.86 m | d_F ≈ −0.1~−0.3 m, 다듬기; GT 오차 감소 |

## 4. GS 구현 다섯 가지 (수식)

기호: 시점 v의 렌더 깊이 D_p(카메라 깊이), MVS 깊이 M_p, 옛 자료 깊이 P_p, A_p ∈ {0,1}, 원반 k의 위치 x_k·불투명도 α_k·출처 o_k ∈ {prior, obs, child}.

### ① 원반 초기화 (0회)
```
X_0 = { 옛 자료 점 (크롭 안), o=prior }  ∪  { SfM 점 sparse/0 (크롭 안·밖 모두), o=obs }
```
출처 o_k는 원반마다 저장되는 속성이다(위치·불투명도처럼 원반 수만큼의 정수 텐서; 밀집화·제거 때 함께 갱신되고 PLY에 `origin` 필드로 저장). 쓰임: ③의 잠금은 o_k = prior에만 적용, ④의 자식은 부모의 o를 물려받음, ⑤·7절의 집계는 출처별로 낸다. 8000회 규약·거리 기반 보호 등록 없음. 초기 불투명도·크기는 GeoGS 기본. 옛 자료 점의 수(M 표본 수, L ALS 점 수)와 SfM 점 수를 기록하고, 소면 3387·3389 위 SfM 점 수를 미리 센다(부족하면 그 면에만 MVS 역투영 점을 보태고 기록).

### ② 손실과 가중 (매 반복, 시점 v)
```
L(v) = L_rgb(v)
     + λ_mvs   · Σ_p A_p · |D_p − M_p|              / Σ_p A_p             영상 깊이 항 (픽셀 가중 A)
     + λ_prior · Σ_p (1−A_p) · ρ_{τ_p}(D_p − P_p)   / Σ_p (1−A_p)         옛 자료 깊이 항 (픽셀 가중 1−A, 절단)
     + L_normal + L_dist                                                  2DGS 정규화 (GeoGS 그대로)

ρ_τ(r) = 0          (|r| ≤ τ)         정상 차이: 힘 없음
       = |r| − τ    (τ < |r| ≤ 4τ)    넘은 만큼만
       = 3τ         (|r| > 4τ)        상수: 옛 자료를 고집하지 않음
```
유효 픽셀: M_p는 A_p=1인 곳에만 존재, P_p는 옛 자료가 덮는 곳(크롭 안)에만. 시험 시점 2장은 손실에 쓰지 않는다. λ_mvs·λ_prior는 GeoGS 기본 0.05에서 시작해 6절의 예비 실행으로 고정하고, 본 실행 중에는 바꾸지 않는다. GeoGS의 동적 깊이 가중·DA3 항은 쓰지 않는다.

### ③ 기울기 감쇠와 동결 (원반 판정 E)
```
E_k = (1/|V_k|) · Σ_{v∈V_k} A_v( π_v(x_k) )
V_k = { v ∈ 학습 13시점 : π_v(x_k)가 영상 안이고  |z_v(x_k) − P_v(π_v(x_k))| < 0.5 m }     (원반 자리를 실제로 보는 시점)
E_k = 0  (V_k = ∅: 어느 학습 시점도 그 자리를 못 봄)
      0회에 계산, 500회마다 갱신(자유 원반은 움직이고 자식이 생기므로).
뜻: 원반 k가 앉은 자리를 사진이 재는 시점의 비율. π_v는 시점 v로의 투영, z_v는 그 시점의 카메라 깊이, A_v는 1단계 관측 신뢰도 지도.
o_k = prior 이고 E_k < 0.5  →  잠금: lr(x,회전,크기) × 0.01, α_k ← max(α_k, 0.5) 매 반복, 불투명도 재설정 면제
o_k = prior 이고 E_k ≥ 0.5  →  자유
o_k ∈ {obs, child}          →  자유
```

### ④ 밀집화와 제거
```
분할·복제: GeoGS 규칙 그대로(기울기 문턱, 500~15,000회, 100회마다). 단 잠긴 원반은 분할·복제 대상에서 제외.
자식 출처: o_child = o_parent (prior 자식은 prior로 남고 E를 새로 받는다).
제거: 불투명도 < 0.05 또는 크기 문턱 → 제거. 단 잠긴 원반은 제외.
불투명도 재설정(3000회마다 0.01): 잠긴 원반 제외.
기록: 100회마다 출처×잠금별 원반 수, 제거·분할 수, 불투명도 분포.
```

### ⑤ 학습 뒤 원반에서 읽어 내는 것
원반 수준(기제 설명용): 출처, 최종 E, 최종 불투명도, 초기 위치로부터의 이동량(prior 출신), 제거 여부와 시점.
면 수준(1차 판독, 15시점 렌더 깊이 D를 저장해 계산):
```
d_F   = median_{p∈F, A_p=1} ( (D_p − P_p) · f_p )     옛 자료로부터의 연직 이동
e_F   = median_{p∈F, A_p=1} ( (D_p − M_p) · f_p )     사진과의 연직 차
cov_F = Σ_{p∈F} A_p / |F|
부호   : 1단계 규약(REPORT §2)과 같다. 카메라 깊이는 아래로 갈수록 크므로 d_F > 0 = 옛 자료가 렌더 표면보다 위,
         e_F > 0 = MVS가 렌더보다 위, g_F > 0 = GT가 렌더보다 위. 예: 1 m 올린 지붕에서 렌더가 사진 표면에 있으면 d_F = +1.0, 올린 옛 자료를 따라가면 d_F ≈ 0.
보존   : cov_F ≥ 0.5, |d_F| < τ_v
보정   : cov_F ≥ 0.5, |d_F| ≥ τ_v, |e_F| < τ_v
미판정 : cov_F < 0.5
```
GT(평가 전용): GT 점군을 같은 카메라로 투영한 깊이 G_p로 g_F = median((D_p − G_p)·f_p), NMAD 병기. 조건 사이 차이로 읽는다.

## 6. 절차

1. **소스 준비**: `GeoGS-mvs-pgsr-v1`에서 분기 `GeoGS-conf-guided-v1`. 수정 자리와 해시를 `provenance/`에 남긴다. 수정 대상: `compute_depth_loss`(픽셀 가중·절단), 초기화(`sparse_lod` 대신 prior∪SfM 병합), E 계산과 잠금(기존 `attenuate_*_lr`·`completed_mask` 재사용), `densify_and_prune`·`reset_opacity`의 잠금 면제, 출처 태그 유지, 렌더 깊이 저장. 공식 8000회 전환·거리 기반 보호·DA3 적재는 P·P0·I에서 끈다(O는 그대로).
2. **단위 시험**(dev 이미지): ρ_τ, τ_p 환산, E 계산(합성 원반·A), 자식 출처 상속, 잠금 원반의 재설정 면제, 면 판독. 모두 통과해야 다음으로.
3. **사전 실행**: 조건 P(M-N)로 300회 스모크(손실 항 유한, 잠금 수 기록, 렌더 저장 확인). 이어 λ 예비 실행 2회(λ_prior 0.02·0.05, 2,000회, P M-N)로 본지붕 d_F가 τ 안에 머무는 쪽을 고정값으로 택한다. 선택 근거를 기록하고 이후 고정.
4. **본 실행**: 11(또는 9) 조건. 조건마다 receipts(명령·이미지·소요·종료 코드).
5. **의도 점검**(7절)을 지정 반복마다 자동 기록하고 대시보드에 띄운다. 빨간 신호가 나면 실행을 멈추고 원인을 적은 뒤 8절 허용 범위 안에서만 조정해 재개한다.
6. **평가**: 렌더 깊이 대 P·M·G, 면별 표, 조건 간 차이표(P−P0, P0−O, P−I), 시험 시점 PSNR·SSIM, 원반 기록 요약.
7. **보고서**: 사실 서술 + "의미" 절(1절 질문 Q1~Q4에 대응하는 표와 문장) + 실패·조정 기록.

## 8. 규칙

- 상수 고정: τ_v(L 0.041, M 0.057), A, 정합 이동, 주입 Δ 1.0 m, E 문턱 0.5, 잠금 배율 0.01, 불투명도 하한 0.5, E 갱신 500회, 절단 3τ·4τ. 본 실행 중 변경 금지.

## 10. 함정

- τ는 연직이고 손실은 카메라 깊이다. f_p 환산을 시점별 배열로 미리 만들고 단위 시험으로 확인.
- 잠긴 원반의 불투명도 클램프와 재설정 면제를 빠뜨리면 A=0 자리의 옛 자료가 3000회마다 사라진다.
- 자식 원반의 출처 상속을 빠뜨리면 prior 출신 수가 밀집화로 왜곡된다.
- M 크롭: 옛 자료 깊이·점군을 대상 건물 ±15 m로 잘라야 L과 조건이 같다. 크롭 밖은 영상 단독.
- 렌더 깊이 저장은 `surf_depth`(2DGS 표면 깊이)로, 카메라 깊이 단위.
- O 조건은 공식 그대로 돌리되 옛 자료 배열만 v2 정합본으로 바꾼다(저자 배열 아님). 그래서 진단의 N과 수치가 다를 수 있다.
- 시험 시점 2장의 A는 판독에는 쓰지만 손실에는 쓰지 않는다.

## 13. 정정 기록 (2026-09-23, 실행 착수 전)

학습 실행 전에 고쳤다. 상수·조건·절차는 바뀌지 않았다.

1. **부호(발주서 내부 불일치).** ⑤의 식 d_F = median((D−P)·f)는 1단계 규약(+ = 옛 자료가 위)을 따르는데 3.5절·7절의 주입 지붕 기대치만 −1.0으로 적혀 있었다. 식과 소면 기대치(−0.1~−0.3, 사진이 옛 자료보다 위)는 그대로 두고 주입 지붕 쪽을 +1.0, "이동 시작 d_F > +τ", "|d_F − 1| > 0.3"으로 고쳤다. 반대 방향 이동(d_F < −τ)은 빨강에 넣었다. 7절의 지붕 규칙은 2,000회부터 적용하고(그 전은 대기), 2,000~15,000회는 "이동 시작", 15,000회부터는 "복귀" 규칙을 쓴다. 지붕 규칙이 실행을 멈추게 하는 것은 조건 P뿐이고 P0·O·I에서는 기록만 한다(절제 조건은 의도가 다르다). 손실 항 NaN은 모든 조건에서 즉시 멈춘다.
2. **잠금 구현(③).** "lr × 0.01"을 기울기 ×0.01로 구현하면 Adam이 기울기 크기를 나눠 없애므로 이동 폭이 거의 그대로다(합성 시험: 잠긴 원반 이동 = 자유 원반의 98.7%). 그래서 잠긴 원반은 Adam 한 걸음의 이동량을 0.01배로 줄이는 방식으로 구현했다(같은 시험 1.08%, GPU 시험에서 원소별 확인). GeoGS 공식 `attenuate_*_lr`도 기울기 방식이므로 조건 O의 보호 원반 감쇠는 학습률 감쇠로서는 거의 작동하지 않는다는 점을 보고서에 적는다(O는 공식 그대로 둔다).
3. **덤프 정밀도.** 렌더 깊이 덤프를 float16에서 float32로 바꿨다(깊이 44 m에서 float16 간격 3.1 cm = τ 크기).
4. **원반 초기 id.** ⑤의 "초기 위치로부터의 이동량·제거 여부와 시점"을 위해 원반마다 초기 원반 번호(`init_id`, 자식 상속)를 두고, 100회마다 살아 있는 번호를 기록한다.
5. **PLY 필드.** 출처를 int8로 PLY에 쓰면 레코드 크기가 4의 배수가 아니어서 GeoGS `load_ply`가 실패한다. int32로 저장한다.
6. **스모크 길이.** 6절 3의 300회 대신 700회로 한다(밀집화 600·700회와 불투명도 기록을 지나가도록).
7. **벽면 환산(3.2절 보완, 사용자 승인 2026-09-23).** f_p = |n·d|/|n_z|는 벽(n_z = 0)에서 발산해(중앙값 약 87만) 벽의 τ_p가 6.5×10⁻⁸ m가 되었다. B0는 경사 촬영이라 시점마다 벽이 영상의 30~60%, 옛 자료 픽셀의 약 2/3이고 A=0 옛 자료 픽셀의 85%다. 그대로 두면 조건 P에서 벽의 옛 자료 항이 0이 되고 분모만 키워 지붕의 옛 자료 힘을 약 7배 희석하며, P0는 벽에 L1 전체 힘을 걸어 P−P0 차이에 환산 결함이 섞인다. 벽형 면(|n_z| < 0.5; 자료는 벽 0, 지붕 ≥ 0.742)은 연직 대신 **면 법선 방향**으로 환산한다: f_p = |n·d|, 같은 τ 값(L 0.041, M 0.057)을 법선 방향 폭으로 쓴다(상수는 바꾸지 않음). 벽 τ_p는 카메라 깊이로 L 4.6~6.1 cm, M 6.3~8.7 cm가 된다. 벽 판독(d·e·g)도 법선 방향(+ = 기준이 렌더보다 바깥)이다. 지붕은 발주서 식 그대로다.
8. **잠금 예외(③ 보완, 사용자 승인 2026-09-23).** V_k는 원반이 *옛 자료 표면 위*에 있는 시점만 세므로(|z − P| < 0.5 m), 사진을 따라 옛 자료에서 0.5 m 넘게 움직인 자유 원반도 V_k = ∅, E = 0이 되어 다음 갱신에서 잠긴다. 700회 스모크에서 자유 prior 원반 이동량 중앙값이 0.30 m였고, 0.5 m 넘게 움직인 뒤 잠긴 원반이 1,138개(그중 985개는 보는 시점 0)였다. B 조건에서는 1 m 올린 지붕의 원반이 내려오다 중간에 잠겨(불투명도 ≥ 0.5, 제거 면제) Q2를 기계적으로 망칠 수 있다. 그래서 **보는 시점이 0개이고 초기 위치에서 0.5 m(같은 문턱) 넘게 움직인 원반은 옛 자료 표면을 떠난 원반으로 보고 잠그지 않는다.** 제자리에서 못 보는 원반은 발주서대로 잠긴다. E 값 자체와 문턱은 그대로이고, 갱신마다 해당 원반 수(`n_prior_off_prior`)를 기록한다.
9. **빨간 신호 정지.** 조건 P에서 구속 항목(7절 지붕 규칙)이 빨강이면 그 반복의 판독 덤프·PLY·`stop.json`을 남기고 실행을 멈춘다. 대기열은 다음 조건으로 넘어가고, 원인과 조정은 `logs/issues.jsonl`에 적는다. 경로는 τ를 인위로 0.001로 둔 시험에서 확인했다.
10. **평가 렌더.** 모든 조건(O 포함)의 최종 PLY를 같은 보정 카메라(주점 복원)로 다시 렌더해 면 표를 만든다(`render_depths.py` → `evaluate.py`). 스모크 모델에서 재렌더는 학습 중 덤프와 최대 차 0.0 m, 면 판독은 학습 중 값과 소수 넷째 자리까지 같았다. O는 주점 중심 가정으로 학습되었으므로 P0−O 차이에는 주점 효과가 섞인다(보고서에 명시).
11. **λ 선택(6절 3).** 규칙을 먼저 기록한 뒤(`logs/lambda_selection_rule.json`) P M-N 2,000회를 λ_prior 0.02·0.05로 돌렸다. 본지붕 d_F = +0.014 / +0.013 m로 둘 다 τ 안 → 규칙대로 **λ_prior = λ_mvs = 0.05** 유지(`logs/lambda_selection.json`).
12. **평가 참값 정리(사용자 승인 2026-09-25, 학습 후 평가에만 적용).** 참값 깊이 지도(평가용 점군을 픽셀마다 z-버퍼로 투영)에서 두 결함을 실측했다: ① 가려진 점 — 점군이 원본 해상도에서 성겨서, 지붕 점이 떨어지지 않은 픽셀에 지붕 뒤(안뜰·반대편 벽, 중앙값 12 m 뒤)의 점이 참값으로 들어갔다(지붕 픽셀의 21 %); ② 기준면 높이 차 — 사진 표면 − 참값이 지면 −6.4 cm, 지붕 일치 칸 −8.0 cm였다. 정리(`make_gt_clean.py` → `inputs/maps/gt_clean/`): 9×9 픽셀 안의 가장 가까운 참값보다 0.3 m 넘게 뒤인 점을 빼고, 판정과 무관한 **지면**의 사진 − 참값 중앙값만큼 점군을 연직으로 옮겼다(두 번 반복해 −7.46 cm). 정리 후 사진 − 참값: 지면 −0.2 cm, 지붕 일치 칸 −2.1 cm, 정면 벽(수평) −3.9 cm, 가려진 점 0.3 %. 판정·학습에는 참값을 쓰지 않으므로 학습 결과는 그대로이고, 참값을 쓰는 모든 평가(`eval_intent`, `evaluate`, `make_intent_viewer`, `conflict_anatomy`, 3D 내보내기, `make_depth_qa`, `make_figures`)를 `JBGS_GT_SET=gt_clean`으로 다시 계산했다. 원래 참값 기준 표는 `eval/rawgt_20260925/`에 둔다. 지붕 절대 오차가 크게 줄었다(예: LoD2 정상 지붕 일치 칸 소스 오차 11 → 3 cm, 충돌 칸 LoD2 40 → 20 cm, P 결과 12 → 5 cm, P0 39 → 19 cm).
