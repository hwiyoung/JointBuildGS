# 판정 유도 GS 결과 — 영역마다 prior를 쓰게 했을 때 일어난 일

2단계 판정 유도 GS(`PHD-STAGE2-CONF-GUIDED-GS-v1`, 이번 실행 판 r5)의 30,000회 결과다. 건물 하나(B0)에서 prior 둘(LoD2, ALS)과 장면 둘(정상, 본지붕 1 m 주입)을 비교했다. 2026-09-29. 참값은 정리한 참값이다. `scientific_verdict: null`.
구성은 논문의 결과 절을 따른다: 요약 → 대표 사례 → 전체 결과 → 절제 비교 → 분석 → 한계 → 산출물 → 다음 설계. 실험 설정의 세부는 부록 A에 있다.
이전 판: [v6](reading_v6.html), [v5](reading_v5.html), [v4](reading_v4.html).

## 요약

> 영상이 깊이를 잰 곳(측정 영역)에서는 판정 덕에 틀린 prior가 고쳐졌다. 판정 GS는 영상 GS처럼 움직였고, prior 강제 GS는 틀린 prior에 끌려갔다(끝 경사면, 정면 벽, 1 m 올린 본지붕).
>
> 어느 영상에도 없는 면(비가시 영역)은 판정 GS만 prior를 남겼다. 지키는 힘은 규칙이 아니라 prior 원반을 고정하는 장치에서 나왔고, 그래서 벽 점이 거의 없는 ALS는 안 찍힌 벽을 남기지 못했다.
>
> 영상에 찍혔지만 깊이를 못 잰 곳(미측정 영역)에서도 규칙은 prior를 고정했다. prior가 맞은 그늘진 지붕면에서는 이득, 틀린 무늬 없는 벽면에서는 손해였다. 미측정 영역은 관측이 없는 곳이 아니다. 영상 GS는 사진만으로 벽면을 맞췄고, 같은 벽의 잰 부분도 'prior가 틀렸다'는 것을 이미 알고 있었다.

**이 결과가 뜻하는 것 [사후]**
- 이번 판정 GS의 학습을 바꾼 것은 1단계 판정 가운데 '영상이 쟀나(A)'와 허용 폭(τ)뿐이다. 두 소스의 오차를 비교한 충돌 판정은 학습에 들어가지 않았다. 그래서 판정 GS는 '더 나은 쪽'이 아니라 '있는 쪽'을 썼다(4절).
- 차별점이 보인 곳은 prior를 모든 픽셀에 거는 방식(prior 강제 GS) 대비 측정 영역뿐이다. 영상 GS 대비 차별점은 보이지 않았다(3절).
- 다음 설계는 prior 조각별 판정을 초기화·손실·기울기·밀도 제어에 넘기는 것이다(7절).

**읽기 전에**
- **세 GS:**
  - 판정 GS(P, 제안): 영상이 잰 픽셀은 영상 깊이, 못 잰 픽셀은 prior 깊이로 학습하고, 대부분의 영상이 못 잰 자리의 prior 원반을 고정한다
  - prior 강제 GS(P0): prior 깊이를 모든 픽셀에 걸고, 고정하지 않는다
  - 영상 GS(I): prior 없이 SfM 점으로 시작한다
- **세 영역:** 측정(영상이 깊이를 잰 곳) · 미측정(영상에 찍혔지만 대부분의 영상이 깊이를 못 잰 곳) · 비가시(어느 영상에도 없는 곳).
- **수치와 판독:** 수치는 참값에서 떨어진 거리(cm)다. 두 결과의 차이가 참값 잔차(지붕 2 cm, 벽 4 cm) 이하면 '같음', 허용 폭(LoD2 5.7 cm)을 넘으면 '뚜렷함'으로 읽는다.
- **절 표시:** [계획]은 결과 전에 정한 질문(9-24 발주서 Q1~Q4)에 답하는 부분, [사후]는 결과를 보고 더한 분석이다.
- **v6 정정 둘:** v6까지 '창'이라 부른 미측정 벽 자리는 창 사이의 무늬 없는 벽면이다(창과 창틀은 영상이 쟀다). 영상 GS의 초기 원반은 SfM 점뿐이다.

## 3. 절제 비교 — 무엇 덕인가

세 GS는 prior를 쓰는 방식만 다르다. prior 강제 GS는 판정을 뺀 것, 영상 GS는 prior를 뺀 것이다.

**표 2. 두 비교가 가르는 것** (표 1에서 영역별로 모은 것)

**볼 것:** 영역마다 차이가 판정에서 오는지(prior 강제 GS 대비), prior에서 오는지(영상 GS 대비) 본다.

| 비교 | 빠진 것 | 측정 영역 | 미측정 영역 | 비가시 영역 |
|---|---|---|---|---|
| 판정 GS 대 prior 강제 GS | 판정 | 뚜렷이 나음 (14–93 cm) | 같음 | 판정 GS만 면을 남김 (97 % 대 5 %) |
| 판정 GS 대 영상 GS | prior | 같음 | prior가 맞으면 뚜렷이 나음(15), 틀리면 뚜렷이 나쁨(14) | 판정 GS만 면을 남김 (97 % 대 12 %) |

**읽은 결과**
- **측정 영역의 개선은 판정 덕이다.** prior 강제 GS보다 14–93 cm 낫다. prior는 여기서 보탠 것이 없다(영상 GS와 같음).
- **미측정 영역에서 판정은 차이를 만들지 않았다.** 판정 GS는 prior 강제 GS와 같다. 결과는 prior가 맞았는지로만 갈렸다.
- **비가시 영역의 차이는 판정 GS의 고정에서 나왔다.**
  - prior 강제 GS도 prior 깊이를 모든 픽셀에 걸었지만 5 %만 남겼다. 영상에 안 찍히는 면에는 깊이 항이 닿지 않는다.
  - prior 깊이 항은 허용 폭의 4배(LoD2 23 cm)를 넘으면 힘이 없다. 다른 영상이 멀리 당기는 LoD2 지붕 자리에서 고정이 없으면 prior가 54 %만 남았다. 당기는 이웃이 없는 자리는 98 %가 남았다(`eval/intent_mechanism_30000.csv`).

## 4. 분석 — 왜 그렇게 됐나 [사후]

### 4.1 판정은 '있는 쪽'을 골랐다

- 1단계는 세 가지를 만들었다(실험 이름 CONF-TOL-CONFLICT): 관측 여부 A, 허용 폭 τ, 그리고 두 소스의 오차를 비교한 충돌 판정.
- 2단계 학습(이름 그대로 CONF-GUIDED)에는 A와 τ만 들어갔다. 발주서 4절의 학습 규칙에 충돌 판정이 없고, 충돌은 결과를 읽을 때만 쓰였다.
- 그래서 판정 GS는 영상이 재면 영상, 못 재면 prior를 썼다. '어느 쪽이 더 나은가'는 어디서도 따지지 않았다.
- 표 1의 모든 줄에서 판정 GS가 영상 GS나 prior 강제 GS와 같은 까닭이 이것이다. 결과는 '영상 GS를 만들고 못 잰 곳을 LoD2로 채운 것'과 거의 같다(표에서 읽은 것이고 따로 계산하지는 않았다).

**표 3. 네 조작점에 판정이 들어간 방식** (이번 실행 r5)

| 조작점 | 판정이 들어간 방식 | 결과로 보인 것 |
|---|---|---|
| 초기화 | 들어가지 않음. prior 점 전부 + SfM 점 | 틀린 조각(정면 벽)에도 LoD2를 심었다. 무늬 없는 벽면 손해가 여기서 시작한다 |
| 손실 | 잰 픽셀은 영상 깊이, 못 잰 픽셀은 prior 깊이(허용 폭 띠) | 측정 영역에서 prior 강제 GS보다 14–93 cm 나음, 영상 GS와 같음 |
| 기울기 | 대부분의 영상이 못 잰 자리(관측 비율 < 0.5)의 prior 원반을 고정 | 미측정 영역에서 prior 강제 GS와 같음. 그늘진 지붕면 이득, 무늬 없는 벽면 손해, 둘레 번짐 |
| 밀도 제어 | 고정된 원반만 재설정·제거 면제 | 따로 확인된 효과 없음(절제 실험 없음) |

### 4.2 미측정 영역의 정체: 사진에는 찍혀 있다

- **관측 비율로 나누면(부록 표 A5)** 픽셀 단위 '미측정' 판정의 대부분은 다른 영상이 잰 자리다.
  - 지붕 미측정 픽셀의 91–94 %가 이런 자리이고, 83 %는 비스듬한 두 장(0031, 0032)의 본지붕에서 나왔다.
  - 그래서 본문의 미측정 영역은 대부분의 영상이 못 잰 자리(관측 비율 < 0.5)로 정의했다.
- **무늬 없는 벽면.** 사진 밝기가 거의 균일하다. 7×7 픽셀 밝기 흩어짐은 0.6으로, 영상이 잰 지붕(8.7)보다 훨씬 작고 밝기는 208이다.
  - 영상 GS는 prior 씨앗 없이 이 벽면을 5 cm까지 맞췄다. 벽면 자체는 무늬가 없으니 둘레의 잰 벽에서 온 정보로 보인다(추정).
  - 같은 벽에서 잰 픽셀의 95 %가 이미 'LoD2 틀림'(충돌)이었다. 판정이 픽셀마다 따로라서 그 증거가 벽면으로 건너가지 못했다.
- **그늘진 지붕면.** 사진이 어둡고(밝기 42, 영상이 잰 지붕은 78) 무늬가 약하다(흩어짐 6.7).
  - 영상 GS의 오차는 가장자리에 몰렸다. 면 경계 3픽셀 안에서는 83 cm, 10픽셀 밖에서는 7 cm다. 사진만으로는 이 가장자리를 잡지 못했다.
  - 이 면의 잰 부분은 일치 47 %, 충돌 53 %로 갈렸다. 같은 면의 증거로도 prior가 맞는지 분명하지 않았다.
- 출처: 사진 무늬·밝기, 가장자리 거리별 오차, 면별 일치·충돌 비율은 `eval/intent_cases_30000.csv`.

### 4.3 prior 표현에 따라 갈린다 — ALS

**표 4. LoD2와 ALS의 벽**

| | LoD2 | ALS |
|---|---|---|
| 벽 근처 초기 prior 원반 (1 m²당) | 9–28 | 0.5–1.9 |
| 미측정 벽 픽셀에서 prior가 남은 몫 (판정 GS) | 89 % | 62 % |
| 비가시 벽에서 prior가 남은 몫 (판정 GS, 시작 → 끝) | 96 → 87 % | 18 → 14–15 % |

- ALS(2.5D TIN)에는 수직 벽이 없다. 벽 자리는 처마 점과 땅 점을 잇는 가파른 삼각형이라 원반이 거의 없고, 고정할 것도 없다.
- 1 m 올린 지붕의 미측정 픽셀에서 LoD2는 틀린 prior를 79 % 붙잡았고, ALS는 10 %만 붙잡았다. prior 강제 GS에서도 같은 방향(99 % 대 74 %)이다. 판정이 아니라 prior 표현의 차이다(D4).
- ALS 벽을 대표 사례로 세우지 않은 이유는 둘이다.
  - 차이가 뚜렷한 곳은 비가시 벽인데, 비가시 유지는 방법론 4.2와 어긋난 r5의 동작이다.
  - 미측정 벽에서는 ALS prior 자체가 약 20 cm 틀려서, 못 지킨 것이 결과에는 오히려 이득이다. 사례의 뜻이 섞인다.

## 6. 산출물: prior 조각별 판정 보고 [계획]

학습 뒤 prior 조각마다 상태 라벨을 붙여 사용자에게 알려 준다.
- 유지: 결과가 prior에서 허용 폭 안에 머묾
- 수정: 허용 폭 넘게 움직였고, 영상과는 허용 폭 안에서 같음
- 유보: 영상이 조각의 절반 미만을 잼

산출물 단위는 prior 고유 조각이다(LoD2는 면, ALS는 TIN 삼각형 또는 1 m 격자). 아래 표만 두 prior를 나란히 보려고 LoD2 면을 평가용 공통 단위로 썼다. ALS 고유 단위의 보고는 아직 계산하지 않았다(D8). 이번 실행에서 라벨은 결과를 읽을 때만 쓰였고, 학습에는 되먹여지지 않았다(4.1절).

**표 6. 면별 라벨 (판정 GS)**

**볼 것:** 라벨이 prior의 실제 상태와 맞는가(수정은 prior가 허용 폭 넘게 틀린 면에 붙어야 한다), 그리고 결과가 참값에서 허용 폭 2배 안인가. 둘 다면 ✓다.

| 면 | LoD2·정상 | LoD2·+1 m | ALS·정상 | ALS·+1 m |
|---|---|---|---|---|
| 3396 본지붕 | 유지 ✓ (−2 → −2) | 수정 ✓ (+98 → −2) | 유지 ✓ (−2 → −2) | 수정 ✓ (+98 → −2) |
| 3404 끝 경사면 | 수정 ✓ (+83 → +1) | 수정 ✓ (+83 → +1) | 유지 ✓ (−3 → +1) | 유지 ✓ (−3 → +1) |
| 3387 날개 | 수정 ✓ (−25 → −4) | 유지 ✗ 가림 (−25 → −2) | 수정 ✓ (−7 → −3) | 유지 ✗ 가림·경계 (−7 → −3) |
| 3389 날개 | 수정 ✓ (−13 → −2) | 수정 ✓ (−13 → 0) | 유지 ✓ (−3 → −1) | 수정 ✗ 가림 (−3 → 0) |
| 3394 날개 옆 | 유지 ✓ (0 → −1) | 유지 ✗ 번짐 (0 → +41) | 유지 ✗ 경계 (−7 → −5) | 수정 ✓ (−7 → +6) |
| 벽 전체 | 수정 ✓ (+18 → −1) | 수정 ✓ (+18 → −1) | 수정 ✓ (+14 → −2) | 수정 ✓ (+14 → −2) |
| 3393 뒷지붕 | 유보 (영상 관측 33 %) | 유보 | 유보 | 유보 |

- 괄호는 면 중앙값 'prior − 참값 → 결과 − 참값'이다(cm, + = 위·바깥).
- 주입하지 않은 면의 prior − 참값은 정상 장면 값을 썼다. +1 m 장면에서는 올린 본지붕의 가림이 그 값에 섞이기 때문이다.
- 이 값은 판독에 쓰는 면 중앙값의 차(prior − 렌더와 참값 − 렌더의 차)라서, 단면 그림 상자의 직접 중앙값과 몇 cm 다를 수 있다(예: 3404 LoD2 +83 대 +93).

**읽은 결과**
- 정상 장면은 12면 중 11면이 맞았다.
  - 같은 3404 면이 LoD2에서는 '수정'(LoD2가 틀림), ALS에서는 '유지'(ALS가 맞음)로, prior에 따라 옳게 갈렸다.
  - 틀린 1면(ALS 3394)은 경계선이었다.
- +1 m 장면은 12면 중 4면이 틀렸다.
  - 3면은 가림 탓이다. 영상 공간에서 잰 탓이며, prior 조각 단위(3D)로 재면 없어질 문제다.
  - 1면(LoD2 3394)은 결과가 41 cm 틀렸는데 '유지'로 표시해 피해를 가렸다.

## 7. 다음 설계로 넘기는 것 [사후 제안]

**핵심은 하나다.** 2단계에 넘기는 것을 'A와 τ'에서 'prior 조각별 판정 결과(유지·수정·유보)'로 바꾼다. 판정은 조각의 잰 부분에서 충돌 비율로 내리고(방법 장 3.2.3의 면 전파), 네 조작점이 그 결과를 쓴다. 조각 번호는 그 장면의 prior 자체를 렌더해 매긴다(영상 공간 면 번호는 가림에 약하다).

**표 7. 조각 판정별 규칙 (제안)**

| 조작점 | 유지 조각 (잰 부분이 대부분 일치) | 수정 조각 (잰 부분이 대부분 충돌) | 유보 조각 (잰 부분이 없거나 갈림) |
|---|---|---|---|
| 초기화 | prior 점을 심는다 | 심지 않는다(또는 잰 차이만큼 옮겨 심는다) | 보이는 점만 심는다(방법론 4.2) |
| 손실 | 못 잰 픽셀에 prior 항 | prior 항을 끈다 | 못 잰 픽셀에 prior 항 |
| 기울기 | 보호 | 보호하지 않는다 | 보호 |
| 밀도 제어 | 재설정·제거 면제 | prior 원반 제거 허용 | 재설정·제거 면제 |

잰 픽셀은 모든 조각에서 지금처럼 영상 깊이로 학습한다.

**이 건물에서의 예측 (시험 전).** 잰 부분의 판정 비율은 `eval/intent_cases_30000.csv`에서 왔다.
- **정면 벽**(잰 부분의 95 %가 충돌 → 수정): 무늬 없는 벽면이 영상 GS 수준(19 → 약 5 cm)으로 가고, 둘레 번짐도 사라질 것이다.
- **본지붕**(85 %가 일치 → 유지): 가장자리 이득이 유지된다.
- **1 m 올린 본지붕**(100 %가 충돌 → 수정): 올린 prior 원반을 심지도 보호하지도 않으므로, 이웃 면 번짐(+41 cm)과 못 잰 부분의 오차가 사라질 것이다.
  - 정상 장면 면 번호로 세면 3394의 잰 부분도 91 %가 충돌로 나온다. 이는 올린 3396이 가린 픽셀이 3394로 세어진 것이다.
  - 조각 번호를 그 장면의 prior로 매기면 그 픽셀은 3396에 속한다.
- **그늘진 지붕면 3394**(정상 장면, 47 : 53)는 갈리는 조각을 어떻게 처리하느냐에 달렸다.
- 이렇게 되면 표 1의 모든 줄에서 판정 GS가 세 대조군 중 가장 좋은 쪽과 같거나 나아진다.

**정할 것**
1. 9-24 원칙 '미측정은 맞든 틀리든 유지'를 조각 단위로 바꿀지(D1). 표 7은 수정 조각의 미측정 부분을 유지하지 않는다는 뜻이다.
2. 갈리는 조각의 처리. 방법 장 3.2.3의 '반대 결론이 뭉치면 나누고, 흩어져 있으면 잡음'을 따를지.
3. 충돌에서 누가 틀렸나. 지금은 늘 영상이 맞다고 본다. 이 건물에서는 맞았지만(충돌 자리의 영상 오차 3–6 cm), 일반화하려면 사진·광선으로 대조하는 독립 증인(명제 1)이 필요하다. S3에서 식별 문제로 보류 중이다.
4. 비가시 면. 방법론 4.2(제거)와 유보(남기고 미확인 표시)를 어떻게 맞출지.
5. 수정 조각을 '안 심기'로 할지 '옮겨 심기'(조건부 재정렬)로 할지.

**대조군과 범위 (제안)**
- 대조군에 **구멍 메우기**(영상 GS + 미측정·비가시 영역은 LoD2)를 추가한다. 이번에 없던 가장 필요한 대조군이다.
- r6(방법론 4.2·4.4를 반영한 판) 위에 조각 판정판을 얹어, LoD2 정상·+1 m 두 장면부터 돌린다.
- 그다음 실제 변화가 있는 지역(R2 등)에서 '일부만 잰 변경 조각'이 얼마나 흔한지 본다.

**결정 대기 목록**
- D1 유보 단위: 픽셀 → prior 조각 (위 1번)
- D2 '관측 없는 곳은 유지' 원칙과 '허용 폭 4배 밖은 포기' 설계 중 무엇을 고칠지
- D3 무늬 없는 벽면 둘레 번짐을 막는 장치
- D4 LoD2·ALS의 끈질김 차이를 원반 단위로 확인할지
- D5 비가시 면에 남은 prior의 정확도(가상 시점 렌더)
- D6 공식 GeoGS를 보정 카메라로 다시 돌릴지
- D7 영상이 잰 곳에서도 prior 구조를 쓸지
- D8 ALS 고유 단위 보고

## 부록

### A. 실험 설정

**비교한 세 GS.** 같은 영상 15장(학습 13, 시험 2)과 같은 반복 수(30,000회)로 학습했다.

| 이름 (파일 표기) | prior를 어떻게 쓰나 | 초기 원반 | 비교하면 알 수 있는 것 |
|---|---|---|---|
| **판정 GS** (P, 제안) | 영상이 잰 픽셀은 영상 깊이, 못 잰 픽셀은 prior 깊이로 학습한다. 대부분의 영상이 못 잰 자리의 prior 원반은 고정한다 | prior 점 + SfM 점 | — |
| **prior 강제 GS** (P0) | 판정 없이 prior 깊이를 모든 픽셀에 건다. 고정하지 않는다 | prior 점 + SfM 점 | 판정 GS와의 차이 = 판정 효과 |
| **영상 GS** (I) | prior를 쓰지 않는다. 영상 색과 MVS 깊이로만 학습한다 | SfM 점만 | 판정 GS와의 차이 = prior 효과 |

- v6에는 '세 GS의 초기 원반이 같다'고 적었으나, 영상 GS는 SfM 점만으로 시작한다(발주서 5절).
- prior 강제 GS는 GeoGS가 처음 8,000회 동안 LoD2 깊이를 모든 픽셀에 거는 방식과 같은 계열이다.
- 공식 GeoGS(O)는 결과 전체가 0.3–0.4 m 떠 있어(주점 가정 차이로 추정) 비교에서 뺐다(D6).

**세 영역과 학습 규칙.**

| 영역 | 뜻 | 판정 GS가 학습에 쓴 깊이 | 이 건물의 예 |
|---|---|---|---|
| 측정 | 영상이 깊이를 잰 곳 | 영상 깊이 (prior와 같든 다르든) | 대부분의 지붕, 창·창틀·장식 |
| 미측정 | 영상에는 찍혔지만 대부분의 영상이 깊이를 못 잰 곳 | prior 깊이, prior 원반 고정 | 창 사이의 무늬 없는 벽면, 그늘진 지붕면 |
| 비가시 | 어느 영상에도 안 찍힌 곳 | 깊이 항 없음, prior 원반 고정 | 뒷지붕, 뒷벽·옆벽 |

- 1단계 판정의 일치(두 소스가 허용 폭 안에서 같음)·충돌(허용 폭 넘게 다름)은 학습 규칙에 없다. 측정 영역에서는 둘 다 영상 깊이로 학습했다.
- 허용 폭은 LoD2 5.7 cm, ALS 4.1 cm다. 1단계에서 두 소스가 맞는 지붕의 흩어짐(LoD2 2.3 cm, ALS 1.6 cm)을 재어 그 2.5배로 정했다.

**차이를 읽는 기준.** 결과는 참값에서 떨어진 거리(중앙값, cm)로 잰다.

| 판독 | 기준 | 뜻 |
|---|---|---|
| 같음 | 참값에 남은 차이 이하 (지붕 2 cm, 벽 4 cm) | 참값이 이만큼 흔들려서 어느 쪽이 나은지 가를 수 없다 |
| 작은 차이 | 그보다 크고 허용 폭(LoD2 5.7 cm) 이하 | 가를 수는 있지만, 두 소스가 맞는 곳에서도 보통 나는 차이 안이다 |
| 뚜렷한 차이 | 허용 폭 초과 | 판정 자신이 '다르다'고 보는 크기다 |

- 반복 실행이 없어서 흩어짐 대신 참값 잔차를 기준으로 썼다.
- 판정은 참값 없이 입력만으로 정했다. 참값은 평가에만 쓴다.

**계획한 질문 (9-24 발주서, 결과 전).**
- Q1 보존: prior가 맞는 본지붕에서 결과가 prior·영상에서 허용 폭 안에 머물고, 공식 GeoGS·영상 GS보다 나쁘지 않은가.
- Q2 보정: 1 m 올린 본지붕이 영상 쪽으로 돌아오고, 그 면을 '보정'으로 표시하는가.
- Q3 빠뜨림: 공식 GeoGS가 실패한 날개 지붕(3387·3389)에서 오차가 줄어드는가.
- Q4 보류: 영상이 못 재는 자리에서 prior 형상이 남고 '미판정'으로 표시되는가.
- 판정의 값어치는 판정만 끈 조건(prior 강제 GS)과의 차이로 가른다.

### C. 용어와 출처

**용어.**
- prior: 기존 LoD2·ALS
- 영상 깊이: MVS가 잰 깊이
- 측정 / 미측정 / 비가시 영역: 영상이 깊이를 잰 곳 / 영상에는 찍혔지만 대부분의 영상이 깊이를 못 잰 곳 / 어느 영상에도 안 찍힌 곳
- 관측 비율: 그 자리를 보는 학습 영상 중 깊이를 잰 영상의 비율. 미측정 자리는 관측 비율 < 0.5다
- 판정: 픽셀마다 일치 / 충돌 / 미측정
- 무늬 없는 벽면: 정면 벽의 창 사이 노란 회벽
- 그늘진 지붕면: 옆 건물 쪽으로 기운 어두운 지붕면(3394)
- 판정 효과 / prior 효과: prior 강제 GS / 영상 GS와 판정 GS의 결과 오차 차이
- 같음 / 작은 차이 / 뚜렷한 차이: 부록 A의 기준
- 고정: 원반을 거의 못 움직이게 묶는 장치(갱신량 × 0.01, 불투명도 0.5 이상, 재설정·제거 면제)
- 허용 폭: τ(1단계, prior와 영상 차이의 흩어짐 × 2.5)
- 판정 GS / prior 강제 GS / 영상 GS: 파일 표기 P / P0 / I
