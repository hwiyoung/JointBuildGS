# 판단 평가 뷰어 사용법 (PHD-MAIN-JUDGEEVAL-v1 덧붙임 1, 묶음 라)

## 여는 법

`<지역>_<건물>_<사전 정보>.html` 파일 하나가 건물 하나 × 사전 정보 하나다(10동 × LoD2·항공 LiDAR = 20개). 브라우저(Chrome·Edge)로 파일을 바로 연다. 인터넷이 없어도 열린다(three.js를 파일 안에 넣음).

## 화면

- 왼쪽 판
  - **층**: 사전 정보 면(회색), 영상 깊이 점(초록, 처음엔 꺼 둠), 드론 LiDAR 참값(검정), 패치. 점은 층마다 30만 점까지만 보이고(씨앗 고정 솎음), 왼쪽 아래에 보이는 점 / 모든 점을 적었다. 패치는 솎지 않는다.
  - **패치 색**(고르기 상자):

    | 색 | 무엇 |
    |---|---|
    | 정답 | 가3 정답 넷 + 채점 밖 셋 |
    | ① 결과 | 같다 / 다르다 / 값 없음 |
    | ② 결과 | 사전 정보 / ③으로. ①이 값 없음인 패치만 칠한다 |
    | ③ 결과 | 사전 정보 / 영상. ③을 거친 패치만 칠한다 |
    | 최종 판정 | 판정 넷 |
    | 판단 맞음·틀림 | 맞음은 연회색이다. 틀림은 판정을 정한 단계로 나눈다: ① 빨강, ② 주황, ③ 보라 |
    | 목표 맞음·틀림 | 맞음은 연회색, 틀림은 빨강이다 |

  - **갈래 목록**: 누르면 그 갈래를 끄고 켠다. 옆 수는 넓이(m²)다.
  - **틀림으로 바로 가기**: 칸(정답 → 판정)마다 패치 다섯 개로 가는 단추다. 넓은 칸이 위에 온다. 패치 넓이가 거의 같아서, 같은 넓이에서는 씨앗 고정 무작위로 골랐다.
- **조작**: 왼쪽 끌기로 돌리고, 오른쪽 끌기(또는 Shift + 끌기)로 옮긴다. 휠은 크기를 바꾼다. 패치를 누르면 고른다.
- **오른쪽 판**(패치를 누르면 나옴)
  - 값: 건물, 자리, 지붕·벽, 넓이, 정답, ①②③ 결과, 판정 넷, 판정을 정한 단계, 판단·목표 맞음, d, L, h_I, h_T ± τ_T, τ_P, τ_I, two_layer, 기둥 안 영상·참값 점 수, ②의 화소 넷, ③의 일관된 점 / 시작 점.
  - 기둥 단면(가로 = 옆 ±1.5 m, 세로 = 법선 거리):
    - 띠와 선: 보라 띠 0 ± τ_P, 연두 띠 h_I ± τ_I(정답), 파란 선 h_T(목표), 주황 사각형 ① 원통, 주황 점선 ① d, 왼쪽 주황 띠 d ± L.
    - 점: 검정 참값, 연두 영상 점. 큰 점은 ③ 시작 점이다(진한 초록 = 일관됨).
    - ②를 거친 패치는 영상마다 중심 시선 끝을 색으로 그린다(회색 못 봄, 빨강 지나감, 주황 막힘, 초록 일치). 칸 밖으로 나간 끝은 ▲▼로 표시한다.

## 기둥 점을 솎지 않은 패치는 일부만 담았다

건물마다 점이 수백만~수천만 개라, 모든 패치의 기둥 점을 솎지 않고 한 파일에 담을 수는 없다(파일이 수백 MB가 됨). 그래서 다음 패치만 기둥 점을 모두 담았다.

- 틀림 목록의 패치
- 정답 × 판정 칸마다 20개
- 채점 밖 정답마다 10개

이 패치들에서는 ② 시선 끝과 ③ 시작 점도 함께 보인다. 그 밖의 패치는 화면에 보이는 솎은 점으로 단면을 그리고, 단면 아래에 그렇다고 굵게 적는다(그때도 기둥 안 점 수는 표의 저장값이다). 패치마다 담은 수는 같은 이름의 `.json`과 `index.json`의 `embedded`에 있다.
