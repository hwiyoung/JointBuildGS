## 5. 코드 옮겨 적기 (`판단코드_옮겨적기.md`, `figures/fig0_flow_current.png`)

기준 코드는 worktree `JointBuildGS-wt-mvsfilter1` HEAD 566eecae다. 옮겨 적기는 하위 에이전트가 코드를 읽어 적었고, 줄 번호 넷은 직접 맞대 확인했다(`a2_count.cpp:62`, `mf12_A2.py:24`, `jc2_judge.py:54`, `s2_calibrate.py:65`).

| 물음 | 답 |
|---|---|
| 1 대푯값 | **평균.** 바깥 첫 면 ±1 m 점의 평균(`cylinders.cpp:69,72`)이 `mvs_mean_m`이고, d와 h_M에 쓰인다. 중앙값은 저장만 한다 |
| 2 원통·바깥 첫 면 | 반지름 LoD2 벽 0.125 m, 그 밖 0.075 m; 반길이 지붕 10 m, 벽 5 m. +H부터 0.05 m씩 내리며 두께 0.3 m 층의 점이 원통 점의 20 % 이상인 첫 층 → o = 층 위 − 0.15, 쓰는 점 = [o−1, o+1]. 값은 코드 상수 |
| 3 한계 L | 1.96 · (√(u_M² + σ_P² + σ_W²) + \|r\|). u_M = 고리 LMedS 평면 거리의 √(중앙값² + NMAD²), σ_P = LoD2 지붕 형태 표·벽 0.144 / 항공 LiDAR WIDEN0 u_prior, σ_W = 항공 LiDAR 지붕 일치 패치 100개 이상 건물의 (d 중앙값 − r) NMAD, r = 지역×자료×면 일치 d 중앙값 |
| 4 예외 | 법선 없음·사전 정보 높이 없음 → 미판정 9. 0 ≤ n < 4 → 시선 검사에서 너머가 보이면 제거 3, 아니면 결측 4. n ≥ 4·u_M 없음 → 광도 결과(지지 → 1, 반박 → 2, 그 밖 기본: 항공 LiDAR 1, LoD2 2). L만 없음 → 9 |
| 5 다시점 셈 | 화소 단위, 셈은 영상 수. c = 1(자기) + 깊이 1 %·되비춤 2 화소·법선 10°를 만족한 다른 영상 수, c ≥ 5면 남김. '살아남은 점 4개' = 남은 점으로 다시 잰 바깥 첫 면 ±1 m 점 수 n(원통 안 모든 점이 아님) |

문서와 코드가 다른 곳은 6곳이다(내용 4, 값 출처 2; 표는 옮겨 적기 3절).
