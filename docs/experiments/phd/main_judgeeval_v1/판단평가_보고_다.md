## 5. 목표 높이의 출처와 확인 불가

- **목표 높이 식은 학습 코드와 같다.** 두 자료 = h_M·σ_P² / (σ_P² + u_M²)로, `scripts/phd/main_finaltrain_v1/targets.py:18`과 같고 σ_W는 넣지 않는다. 영상 = h_M, 사전 정보 = 0이다.
- **학습 코드와 다른 곳은 h_M 하나다.** 학습 코드의 h_M은 저장된 `mvs_mean_m`(바깥 첫 면 ±1 m 평균)이다. 이 판단의 h_M은 ①의 대푯값(원통 안 모든 점의 평균)이다. JUDGECHECK-v2와 11/22 구조 열은 학습과 같은 저장값으로 셌다.
- **② → ③ 길의 h_M:** ③이 일관되다고 본 시작 점의 법선 거리 평균이다. 판 2에서는 ③을 거치지 않으므로 시작 점 모두의 평균을 썼다(S). 다시 돌린 fuse의 일관된 점 수는 step3 저장값과 패치마다 같다.
- **`target_check.py`:** 학습 뒤 높이를 넣는 길과 다섯 줄 사용법이 파일 머리에 있다. 입력은 patch_index, h csv다.
- **확인 불가:** 없다. **시간:** ② 확인 1분, 목표 높이 참값 셈 15분, 채점 2분, 그림 2분.
