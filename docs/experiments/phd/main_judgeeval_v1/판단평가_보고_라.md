## 3. 발주와 다른 곳

1. **솎지 않은 기둥 점은 일부 패치에만 담았다.** 건물마다 영상 점이 370만~8,800만 개라, 모든 패치의 기둥 점을 한 파일에 담으면 수백 MB가 된다. 그래서 다음 패치만 담았다. 건물·자료마다 48~437개다.
   - 틀림 목록의 패치
   - 정답 × 판정 칸마다 20개
   - 채점 밖 정답마다 10개
   - 담는 범위는 옆 ±1.5 m, 두께 ±0.125 m, 기둥 반길이 안의 점이다.

   그 밖의 패치는 솎은 점으로 단면을 그리고, 단면 아래에 굵게 그렇다고 적는다. 기둥 안 점 수는 늘 표의 저장값이다.
2. **틀림 목록의 '넓은 차례'**는 칸 넓이 차례다. 칸 안에서는 패치 넓이가 거의 같아서, 씨앗 고정 무작위로 다섯을 골랐다.
3. **화면 문제 다섯을 덧씌워 고쳤다**(`g18_viewer_patch.py`):
   - 창 크기가 0으로 잡힐 때 시점 맞춤이 NaN이 되던 것. 헤드리스 화면 갈무리에서 빈 화면으로 나타났다.
   - 점 비율 판이 틀림 목록을 가리던 것
   - 주소 `#w=<n>` 더함(틀림 목록 n번째 고르기)
   - 창 크기가 아직 0이면 시점 맞춤을 미룸(헤드리스에서 건물이 점 하나로 작게 보이던 것)
   - 단면 세로 범위에 ③ 시작 점을 넣음. 처음 판에서는 벽 위쪽 시작 점이 화면 밖으로 나갔다. 점 위치를 다시 옮겨 맞대 보니 저장 좌표와 같아서, 자료 잘못은 아니었다.
