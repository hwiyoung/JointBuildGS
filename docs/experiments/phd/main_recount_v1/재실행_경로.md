`scientific_verdict: null`. 계산 단위는 RELEASE/RESCORE에 저장된 `thin` 참값 행이다. 기존 중복도, 기둥 소유자, τ, 거리를 유지했다. 새 학습·렌더·메시 생성은 없다.

기존 캐시가 있으면 그 값을 재사용한다. 완료 장면은 재계산하지 않는다.

```bash
bash scripts/phd/main_recount_v1/run_queue.sh
bash scripts/phd/main_recount_v1/run_cpu.sh publish publish.py
bash scripts/phd/main_recount_v1/run_cpu.sh figures figures.py
bash scripts/phd/main_recount_v1/run_cpu.sh report report.py
```

`freeze.py`는 최초 잠금 전용이며 이미 잠근 설정이 있으면 실행을 거부한다. `validate.py`는 발주문 7절의 여섯 항목만 확인한다. `boundary.py`는 저장소 상태 전후 기록과 기존 Git 소유 입력의 잠금 해시를 대조한다. 전체 저장소의 기존 dirty 파일 바이트를 재감사한 것은 아니다.

`tables/judgment_summary_wide.csv`는 본 방법·늘 보존·늘 보정의 장면별 판단 맞음 %, 장면 하위 `judgment_matrix.md`는 경우 × 판단의 점 수와 행 비율이다. `result_accuracy.csv`는 정확성의 결과 점 분모 `n_result`도 유지한다. `method_summary.csv`는 완전성·정확성 각각의 최솟값, 최대 차이·자리·동률 자리, 3/5/10 %p 이내 칸 수를 제공한다. 참고 방법이 비교 후보의 최고보다 높으면 차이는 음수다.

벽 비율의 분모는 기존 τ 안 벽 점이다. 주 조건의 1,000개 기준은 해당 경우 전체 참값 수 `n_gt`이며, 벽 자체 수 `n_wall`과 `wall_n_at_least_1000`도 별도 제공한다. 두 해석 모두에서 2% 초과가 발생했다. 벽 참값이 없는 ALS의 비율은 0으로 채우지 않는다.

그림은 지정된 세 장면의 지도 묶음과 단면, 총 6개 PNG다. 각 JSON은 출처·색·단면 위치를 기록한다. 지도는 저장된 모든 참값 행을 표시하고 XY가 겹치면 높은 Z가 위에 놓인다. 단면의 선들은 기존 메시와 평면의 교차, 목표는 기존 목표점이다. 모델 렌더링을 실행하지 않았다.

τ 0.5~2배는 `docs/experiments/phd/main_release_v1/tables/stage0/table4_all.csv`를 참조하며 재집계하지 않는다. ZIP에는 보고·표·그림·설정·재집계 스크립트와 SHA256SUMS를 넣고, 큰 원본 입력·캐시는 출처 잠금으로 연결한다.
