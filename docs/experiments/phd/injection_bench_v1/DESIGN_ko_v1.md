# 주입 벤치 v1 설계 (2026-09-04, 코드 전)

> 지위: 설계(코드 전). 작업 ID `PHD-INJECTION-BENCH-v1`. 상위 근거 = 방법 설계 v2 §9 검증 계약(통제 폐루프), §10.8(prior 우세 자리의
> 합성 표본), §10.9(반복의 결정 실험), D-5.7(통제 후보), 기여 진술 v1 §6. `scientific_verdict: null`.

## 1. 목적 — 무엇에 답하는가

진실을 아는 통제 표본에서 증거 채널의 반응을 재는 벤치다. 지금 단계(T1·T2 완료, T3~T6 미구축)에서 답할 수 있는 질문은 셋이다.

1. **H_M 서명의 실물.** 자연 표본이 아직 없는 "MVS 결손·잡음·편향" 자리에서 세 심판이 무엇을 말하는가. 특히 MVS 편향은 3D 광선에서 **차단**(MVS 가
   prior 앞), 사진에서 **P 우세**(Δ < 0) 가 나와야 하며, 이것이 변화(관통 + M 우세)와 갈라지는가.
2. **정합 오차의 교락.** prior 전체를 δ 만큼 옮기면 양립 자리가 "옛 것이 위/아래"로 읽히고 광선·사진이 변화 서명을 낸다. 그 교락의 문턱(δ 가 얼마부터
   양립이 무너지는가)과, 은행이 그 오차를 **결맞은 오프셋**(같은 벡터가 건물 전체에)으로 식별할 정보를 담고 있는가(3D-c 의 근거). 이것이 반복(δ̂ 루프)의
   필요 조건을 재는 첫 절반이다. 둘째 절반(루프가 실제로 회복하는가)은 T6 이 생긴 뒤 같은 벤치에서 잰다.
3. **T3 의 보정 표본.** 원인이 알려진 셀에서 채널값의 분포(관통·차단 비율, ρ_M·ρ_P·Δ, dz)를 얻는다.

벤치가 지금 답하지 못하는 것: 책임 pi 의 오류율(T4 미구축), 반복의 회복(T6 미구축), 재구성 비열화(T5 미구축). 이들은 같은 주입 데이터 위에서
나중에 잰다 — 그래서 주입 데이터는 해시로 동결한다.

## 2. 대상과 입력

- 대상 prism = **prism 2**(x[110,158) y[86,132), 타일 x004_y004): 준수직 66장, 셀당 쌍 ~20 으로 채널 검정력이 가장 좋은 사진 배치.
- 주입 대상 구역 = prism 2 기준 실행(`PHD-*-P2-v1`)의 pairing 에서 **COMPATIBLE ∧ 평면**인 셀(548 m² 중 평면 1,986셀; 지면·도로). 주입 전에 두 소스가
  같은 표면을 지지하는 자리이므로 주입 뒤의 차이는 전부 주입이 만든 것이다.
- 입력 = 동결 타일 파티션(MVS·ALS `x004_y004.xyz_f32le.bin`)의 사본에 주입을 가한 새 파티션 + 동결 관계 지도(변경 없음). 관계 지도의 3D-a core 는
  주입 전 데이터의 산출물이므로 벤치에서 3D-a 는 **pairing 의 dz(재계산)** 로 대신 읽는다(D-1 의 M3C2 재실행은 범위 밖, 명시).

## 3. 주입 변형 (각각 별도 실행, 별도 산출물)

| ID | 주입 | 대상 | 시뮬레이션하는 원인 | 진실 라벨 |
|---|---|---|---|---|
| V1 | ALS 전체 z + 0.5 m | 타일 ALS 전부 | H_δ (수직 정합 오차, 작음) | 전 셀 δ = (0,0,+0.5) |
| V2 | ALS 전체 z + 1.0 m | 〃 | H_δ | (0,0,+1.0) |
| V3 | ALS 전체 z + 2.0 m | 〃 | H_δ (큼) | (0,0,+2.0) |
| V4 | ALS 전체 x + 1.0 m | 〃 | H_δ 수평 (수평면에서 관측 불가, 벽·경사면에서 관측) | (+1.0,0,0) |
| V5 | MVS 점 삭제 | 양립 평면 셀 위 3 × 3 m 조각, 면적의 ~30 % | H_M 결손 | 조각 셀 = MISSING |
| V6 | MVS z 에 N(0, 0.3 m) 잡음 | 〃 (다른 조각) | H_M 잡음(품질) | 조각 셀 = NOISY |
| V7 | MVS z + 1.0 m | 〃 | H_M 편향(MVS 가 틀림) | 조각 셀 = BIASED |
| V8 | ALS z + 2.0 m | 〃 (조각) | H_chg 소실(옛 표면이 위에 있었음) — 자연 표본 2건과 대조 | 조각 셀 = STALE |

조각 배치: 양립 평면 셀 집합 위에 3 m 격자를 놓고, 격자 칸 중 양립 셀이 80 % 이상인 칸을 후보로 하여 결정론적 난수(seed 20260904)로 고른다. 비율은 처음 30 % 로 적었으나 prism 2 의 양립 평면 구역이 조각나 있어 후보 칸이 25개뿐이므로(8칸 = 72 m² 는 주입 셀이 너무 적음) 체인 실행 전에 **60 %(15칸, 135 m²)** 로 올렸다.
V5~V8 은 **같은** 조각 집합을 쓴다 — 변형은 각각 별도 실행이므로 겹쳐도 진실이 섞이지 않고, 같은 셀에 다른 원인을 넣어 짝지어 비교할 수 있다. 조각 밖의 셀은 대조군(주입 없음)이다.

## 4. 파이프라인과 재현

주입 파티션 생성(`scripts/phd/injection_bench_v1/inject.py`, config `configs/phd/injection_bench_v1/inject_<ID>.json`) → 표면 패치 → XY pairing →
T1 → T2 를 기존 드라이버와 config(`run_v1_bench_<ID>.json`)로 그대로 실행(체인 스크립트가 config 를 생성). 주입 파티션은 `partition_receipt.json`
과 점별 진실 플래그(`truth_mvs_u8.npy`, `truth_als_u8.npy`: 0 = 원본, k = 주입 ID)와 조각 마스크(`injection_manifest.json`)를 함께 저장하고 SHA-256 으로
동결한다. 평가(`evaluate.py`)는 변형별 T1·T2 셀을 기준 실행(주입 없음)의 같은 셀과 진실 라벨에 결합한다.

## 5. 측정 (변형별, 셀 단위; 기준 실행과 짝지어 비교)

| 채널 | 측정 | V1~V4 (δ) | V5 결손 | V6 잡음 | V7 편향 | V8 낡음 |
|---|---|---|---|---|---|---|
| pairing | 상태 분포, dz 중앙값 | 전 셀 dz ≈ δ_z; 상태 PRIOR_ABOVE 로 이동(δ_z ≥ 0.3) | PRIOR_ONLY | COMPATIBLE 유지(dz 산포 ↑) | CURRENT_ABOVE(dz ≈ −1) | PRIOR_ABOVE(dz ≈ +2) |
| 3D-b | 관통/일치/차단 비율 | δ_z ≥ 0.5: 관통 ↑(τ = 0.5), 0.25~0.5: 일치 유지 | 무착지 우세(비관측) | 일치 유지 | **차단** 우세 | 관통 우세 |
| 2D-a | S_M, S_P, Δ, f | δ_z ≥ 0.5: S_P ↓, Δ > 0(M 우세) — 변화와 같은 부호; δ_x: 수평면 Δ ≈ 0 | M 쌍 0, S_P 유지(사진이 P 설명) | S_M ↓, Δ < 0 약함 | S_M ↓, **Δ < 0**(P 우세) | Δ > 0 |
| 결맞음(3D-c 근거) | 양립 셀 dz 의 건물 내 분산, 부호 일치율 | δ: 분산 작고 부호 100 % 일치(결맞음) | — | — | 조각 안만 편향(국소) | 조각 안만(국소) |
| 2D-c·r | 검정력 셀 비율 | 유지 | M 검정력 0, P 유지 | 유지 | 유지 | 유지 |

**사전 등록 기대(핵심 4개).**
(a) V7 편향은 3D-b **차단** + 2D-a **Δ < 0** 로, V8 낡음(관통 + Δ > 0)과 두 채널 모두에서 부호가 갈린다.
(b) V5 결손은 M 쌍 0·무착지 우세이면서 S_P 가 기준 실행의 S_M 수준(≥ 0.6)을 유지한다 — "사진이 P 를 부정하지 않음".
(c) V1(δ_z 0.5)부터 양립 셀이 PRIOR_ABOVE 로 넘어가고 관통·Δ > 0 이 나타난다 — 순차법이 정합 오차를 변화로 오독하는 문턱은 pairing 허용 0.3 m 과
    광선 허용 0.5 m 사이다. 그러나 dz 의 결맞음(분산 ≤ 0.1 m², 부호 일치 ≥ 0.95)은 V8 국소 낡음과 갈린다 — 즉 은행은 δ 를 식별할 정보를 담는다.
(d) V4(δ_x 1 m)는 수평면에서 Δ ≈ 0, dz ≈ 0 으로 관측 불가(§7 예측), 경사·벽에서만 신호.

**판정 규칙(잠정, D-7 손 규칙 + Δ 부호)의 혼동행렬.** 원인 라벨 {H_C, H_chg, H_M-결손, H_M-편향, H_δ} 대 규칙 판독. 규칙은 판정이 아니라 T4 이전의
점검이며, 혼동행렬은 T3 가 우도를 만들 때의 목표다.

## 6. 합격·불합격의 뜻

이 벤치에는 합격선이 없다. 기대 (a)~(d) 의 충족 여부는 채널의 **식별성**을 말해 줄 뿐이며, 어긋나면 그것이 T3 가 다뤄야 할 사례다.
단 (a) 가 어긋나면(편향과 낡음이 두 채널 모두에서 같은 부호) H_M 을 H_chg 와 가르지 못한다는 뜻이므로 기여 1 의 핵심 주장을 재검토한다.
