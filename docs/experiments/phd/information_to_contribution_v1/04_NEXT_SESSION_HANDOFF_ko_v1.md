# 다음 세션: 연결의 미확인 부분을 좁히는 인계

2026-09-09 · `scientific_verdict: null`

## 1. 완료한 연결과 아직 결정하지 않은 것

[필요성과 기여 논증](03_NECESSITY_AND_CONTRIBUTION_ko_v1.md)의 여섯 문단을 현재 읽을 논증 초안으로 사용한다. 입력 정보 → 기존 이용 → 실제 성공/실패 → 원인 근거 수준 → 기존 해결의 충분성 → 추가 설명/방법의 기여 조건을 연결했다. 모든 단계가 동일 데이터에서 실증된 하나의 causal chain이라고 주장하지 않는다.

지붕·구조 손상, GS·명시적 판단·반복, 시간차를 핵심 문제로 자동 채택하지 않았다. 원래 목표의 현재 기하·결손/오류 보완·관측 가능한 세부·외관을 유지했다. 성과 측정의 편의성만으로 다음 연구 대상을 정하지 않는다.

문헌 원인 분석이 완료되었다는 말은 모든 잔여 원인이 확정되었다는 뜻이 아니다. 기존 해결을 적용한 뒤의 실제 실패가 확인되기 전에는 '공통 원인을 새 방법으로 해결한다'는 학위 기여를 쓰지 않는다. 반면 기존 관측·가정에서 기대 성능을 개선하는 연구도 허용하며 유일한 정답 식별을 모든 기여의 필요조건으로 강제하지 않는다.

## 2. 다음 검토는 기존 증거에서 시작할 수 있다

아래 수치는 기존 보고를 읽은 것이며 이번 재계산 결과가 아니다. 두 사례는 편의상 예시이고 학위 전체를 해당 지역·부위로 좁히는 선택이 아니다. 시간차가 없는 조건과 원래 성공 조건도 같은 설명에 포함할 수 있어야 한다.

| 기존 사례 | 이미 확보된 현상과 기존 변경의 결과 | 지금 채울 수 있는 연결 | 추가로 필요한 근거 |
|---|---|---|---|
| **Wu 로컬 v7, P3** | 기본 F1@.5m 86.17%, 작은 영역 4m² 정제 90.07%, ALS 90.14%. 그러나 정제 결과의 출력→참조 평균 .196m와 빈 XY셀125는 ALS .136m/11보다 큼 | 단순 정제가 상당 부분을 회복한다는 성공을 먼저 인정. 하나의 F1 근접으로 모든 요구 충족이라고 보지 않음 | 같은 고정 영역에서 원관측/중간 mesh/선택·제거·추가의 경로를 추적해 생성기 오류와 사용 규칙 영향을 구분. 원점·밀도·참조 가림과 CRS 제약 유지 |
| **GeoGS ALS 적용, P2** | prior-depth .005→.0005, native 보호에서 ROI PSNR 증가와 final1024 raw F1@.5 감소가 함께 기록. 동일 model의 raw→post도 정방향/역방향 지표가 다르게 움직임 | 외관·추출 표면의 결과가 다름은 실제 현상. 보호·감독·density·추출을 나눠 볼 이유가 있음 | 학습된 표현의 native depth/normal/opacity/support와 추출 결과의 연결. 실제 DA3 controller 경로와 gradient/density 효과는 현 문서만으로 원인 확정 불가 |

Wu는 원문 기반 재구현이고 GeoGS는 ALS 파생 입력/공통 anchor 조건이다. 두 결과를 저자 native 성능 또는 독립 확증 결과로 바꾸지 않는다. UAS 헤더/작업 CRS·datum 한계도 기존 보고 그대로 유지한다.

## 3. 한 현상에 붙일 완성된 기록의 형태

다음 세션에서는 선택한 사례마다 아래를 하나의 기록으로 채운다. 새 방법의 이름부터 만들지 않는다.

1. **목표와 단위:** 위치·방향·경계·형상·피복·현재성·외관 중 무엇의 실패인지, 전체 복원 목적에서 왜 중요한지, 같은 현상이 얼마나 반복되는지.
2. **허용 입력:** 원관측, camera/정합, 자산 계보, 파생 추정, 사전학습 정보를 구분하고 각자의 불확실성을 적는다.
3. **정상 경로:** 기존 방법이 성공한 경우의 정보 사용과 최종 기여를 먼저 기록한다.
4. **실패 경로:** 처음 달라지는 중간 결과와 이후 전파를 추적한다. 관측 없음/오류/표현 생략/미판정/추출 부재를 구분한다.
5. **경쟁 설명:** 관측의 한계, 정합·생성기, 감독/수정 규칙, 표현/추출 중 실제 근거가 있는 설명을 제한해서 적는다.
6. **가까운 기존 해결:** 문헌 원방법과 단순 조정의 성공 범위를 포함한다. native 입력 비교와 adaptation을 섞지 않는다.
7. **구별하는 대비:** 동일 중간 결과에서 후단만 변경하는 비교와 동일 원입력에서 앞단을 변경하는 비교를 나눈다. 참조를 쓰는 교체는 진단으로만 표시한다.
8. **해석의 종착점:** 기존 해결로 충분/관측·가정의 한계/원인 미분리/새 설명 또는 변경의 추가 효과 중 근거에 맞는 결론을 쓴다. 기존 조합이 같은 결과를 내면 추가 요소의 필요성을 축소한다.

새 학습 없이 기존 기록으로 채울 수 있는 칸부터 채운다. 추가 원문은 그 사례의 경쟁 원인에 직접 해당하는 문헌으로 좁힌다. 기존 기록이 없는 비교를 이미 수행한 것으로 적거나, 이번 문서 작성 범위를 새 방법 실행으로 확대하지 않는다.

## 4. 비교가 필요해질 때 고정할 항목

정확한 대상 입력/버전·촬영/피복·정합·추정 변수·고정 중간 결과·후단 출력·계산 예산을 적는다. 표면과 렌더 성과를 각각 평가하며 개선 영역뿐 아니라 원래 양호한 영역·새 결손·비관측도 포함한다. 다른 표현의 방법을 비교할 때 같은 코드까지 강제하지 않고 공통 목표·지원영역과 정보·비용 차이를 드러낸다.

이미 조사한 199동/P1/P2/P3를 새 독립 confirmatory test로 재명명하지 않는다. 평가 참조는 source 선택·정합·학습·파라미터 조절의 honest 입력으로 쓰지 않는다. 이 문서는 새 수치 임계값·공식 PASS·scientific verdict를 정하지 않는다.
