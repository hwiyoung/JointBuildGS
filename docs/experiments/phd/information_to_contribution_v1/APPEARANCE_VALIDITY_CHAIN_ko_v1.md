# 현재 기하·관측 세부·외관: 정보에서 잔여 원인까지의 연결

검토일: 2026-09-09 · `scientific_verdict: null` · 범위: 문헌 원문과 공식 소스 열람, 연구 논증. 새 학습·렌더·방법 실험 없음.

## 1. 이 연결에서 먼저 구별할 정보

다음은 연구 목적을 분석하기 위한 우리의 구분이다. 세부를 지붕의 기하 세부로만 제한하지 않으며, 외관도 원래 목표에 유지한다. 현재 영상이라는 이유만으로 영상에서 유도한 모든 3D 변수가 현재 기하를 식별하는 것은 아니다.

| 입력에 있는 정보 | 사용할 수 있는 경로 | 그 정보만으로 정당화되지 않는 주장 |
|---|---|---|
| 기존 mesh·점군의 위치·면 방향·연결·지지 범위 | 영상의 대응/표면 추정을 제한하거나 기존 표면에 외관을 부여 | 기존 표면의 정확성·현재성·없는 세부가 자동으로 보장됨 |
| 현재 RGB의 색·무늬·경계와 촬영 시각 | 해당 시각에 보인 외관과, 대응 가능한 특징의 투영 위치를 제공 | 선명한 무늬가 깊이 요철임, 색 차이가 형상 변화임 |
| 보정된 여러 영상의 대응·시차·가시성 | 정합과 관측모형이 타당한 범위에서 깊이·경계·존재를 제약 | 가림 영역이 현재도 과거와 같음; 동일 색 잔차가 유일한 오류 원인을 지시함 |
| 기존 GS의 색·밀도와 과거 렌더 | 국소 갱신의 비교·보존·replay 감독 | 과거 렌더가 독립 측정임, 재현이 현재성의 새 관측임 |
| 사전학습 특징·예측 법선 | 관측의 해석 및 약한 영역의 규칙성 제공 | 해당 건물에 대한 독립 측량 증거임 |
| 불확실성·활용도·사진 일치 점수 | 각 정의에 맞는 약관측 진단·선택·가중 | 낮은 값/높은 점수가 곧 현재 정답 기하 또는 수정의 이득임 |

예를 들어 벽돌 무늬를 더 선명하게 표현하는 것은 유효한 외관 보완이다. 벽돌 돌출 깊이까지 복원했다고 하려면 그 깊이를 구별하는 관측과 별도 표면 검증이 필요하다. 이 구분은 외관의 연구 가치를 낮추는 규칙이 아니라, 실제 이용한 정보에 맞추어 성과를 설명하는 규칙이다.

## 2. 이미 연결되는 경로: 무엇을 새 문제라고 부를 수 없는가

### 2.1 기하를 유지하고 영상으로 외관을 보완하는 경로

**[원문 사실]** Waechter–Moehrle–Goesele의 *Let There Be Color!*는 정합된 영상과 양호하지만 완벽하지 않은 삼각 mesh를 입력받는다. 면별 가시성과 영상 품질·사진 일치로 texture view를 선택하고 색·경계를 보정한다. 기하와 카메라의 불완전성도 §3의 가정에 명시한다. 공식 구현의 호출 흐름은 mesh 준비→data cost→view selection→global/local seam leveling→OBJ이다. 외관을 얻기 위해 반드시 GS나 기하 재최적화가 필요한 것은 아니다. [저자 원문, ECCV 2014, §3–4, PDF pp.4–9](https://download.hrz.tu-darmstadt.de/pub/FB20/GCC/paper/Waechter-2014-LTB.pdf), [공식 코드, commit f3374298ac959cb5afe47a14e4d35d2ac7fbdbb1, texrecon.cpp L64–187](https://github.com/nmoehrle/mvs-texturing/blob/f3374298ac959cb5afe47a14e4d35d2ac7fbdbb1/apps/texrecon/texrecon.cpp#L64).

**[원문 사실·관측된 잔여 오류와 저자 해석]** 저자는 소수 view에서 photo-consistency 분류가 불안정해지고, 인접 면의 평활화도 경계에서 이를 고치지 못하는 사례를 Fig.9 우하단에 보인다. 다수 view가 올바른 색을 본다는 가정은 §4.2에 명시되어 있다. 이는 저관측 외관 선택의 제한이며, 새로운 기하 복원법의 필요성을 바로 입증하지 않는다. [같은 원문 §4.2·§5, PDF pp.7, 11–12, Fig.9](https://download.hrz.tu-darmstadt.de/pub/FB20/GCC/paper/Waechter-2014-LTB.pdf).

**[우리 판단]** 무색 자산+현재 RGB에서 색이 생겼다는 사실은 상보성의 실현일 수 있지만 신규성은 아니다. 먼저 기존 기하+표준 texturing이 외관 목표를 충족하는지 보아야 한다. 점군에서 mesh를 만드는 단계가 필요하면 그 단계의 형상 변화와 실패도 별도 기록한다. 해당 방법이 시간차 자산의 정합·현재성을 해결했다는 주장은 하지 않는다.

### 2.2 국소 변화와 외관 변화에 이미 존재하는 해결책

| 문헌·원문 위치 | 실제 이용한 정보와 경로 | 이미 해결한 범위 | 넘어가면 안 되는 해석 |
|---|---|---|---|
| [CL-Splats, 2506.21117v2, §3·§4.2 Table5·§9.2 Fig12](https://arxiv.org/html/2506.21117v2) | 기존 GS 렌더+현재 RGB→DINO 변화 근거→3D 영역→배경 고정·국소 갱신 | 재관측이 적은 배경의 보존과 변경부 갱신. Table5의 배경 고정 이득은 실제 ablation | 영상 점수의 보존이 metric 표면 정확성·현재성의 전부라는 해석 |
| [GaussianUpdate, 2508.08867v1, §3.2·§4.3 Fig3/Table3](https://arxiv.org/html/2508.08867v1) | 불변 영역으로 외관 fit→SfM 신규 지지와 removal→외관·신규 GS refinement | 조명/배치 간섭 완화, 추가·삭제와 과거 replay. 단순 densification보다 신규 SfM 지지가 유효한 사례 | 1단계가 색만 수정한다는 해석; 외관모델 출력에는 Gaussian scale도 포함 |
| [SpotLessSplats, 2406.20055v2, §4–6](https://arxiv.org/html/2406.20055v2) | 현재 RGB 잔차+고정 사전학습 feature→mask/MLP↔GS, 초기 scheduled sampling, 활용도 pruning | transient 억제와 초기 오기각 완화. 모델과 감독의 반복 갱신 | 정적 배경 복원과 최신 영구 변화 반영이 같은 과제라는 해석 |
| [NeuRIS, 2206.13597v2, §3.2 Eq6·§4.3 Fig6](https://arxiv.org/html/2206.13597v2) | SDF depth/normal→다중뷰 NCC→부정확한 normal prior 기각→표면 갱신 | 법선 prior 과평활로 손실되는 얇은 구조의 회복. 후단 기하가 감독을 검정하는 feedback | 얇은 구조 손실을 이미 고친 full 방법의 잔여 실패로 쓰거나, 단안법선을 외부 독립 기하로 세는 해석 |
| [BayesRays, 2309.03185v1, §4–6 Fig7](https://arxiv.org/html/2309.03185v1) | 고정 NeRF의 공간 섭동 민감도→조건부 uncertainty→출력 density filter | 미관측·가림에 따른 epistemic 진단과 floater 정리 | 새 기하를 복원함, 낮은 uncertainty가 모든 오류의 부재임 |

CL-Splats와 GaussianUpdate는 기존 색 있는 GS 갱신의 직접 경쟁 후보이고, 무색 외부 측량자산의 동등 입력법은 아니다. 이 입력 차이 자체를 신규성으로 쓰지 않는다. SpotLessSplats·NeuRIS·BayesRays는 서로 다른 과제/표현의 구성요소 참고이며, 최종 복원법끼리의 직접 우열표에 섞지 않는다.

## 3. 남은 실패와 원인의 연결: 증거 강도별 판정

| 근거 | 실제 관측·서술 | 확인된 연결 / 아직 다른 원인과 분리되지 않은 것 | 다음 논증의 한계 |
|---|---|---|---|
| CL-Splats §9.2, PDF p.14; Fig12 p.17 | **[원문 사실·full 실패]** 매우 얇은 구조의 변화영역이 과소추정되어 갱신 실패 | **[저자 해석]** 영역 recall 부족이 허용 수정 범위를 제한. 관측량·초기 GS와의 개별 인과 분리는 없음 | 더 나은 기존 검출·팽창·sampling으로 해결되는지 남음. 반복 재판정이 필요하다는 증거는 아님 |
| GaussianUpdate §4.3 Fig3/Table3 | **[원문 사실·ablation]** 불변 mask를 빼면 사라진 물체가 남음 | **[저자 해석]** 외관 단계가 배치 변화의 영상 차이를 먼저 설명하여 removal 방해 | full은 이를 해결하도록 설계됨. 이 사례는 잔차의 해석을 제한할 이유이며 full 방법의 공백 증명이 아님 |
| GaussianUpdate §5 Limitation | **[저자 보고·잔여 실패]** 거울 등 강반사의 기하·외관 갱신 오류 | **[저자 해석]** 표현 한계. 반사·pose·가림을 분리한 독립 실험은 미확인 | 반사 표현 연구를 직접 대안으로 검토해야 하며 학위의 새 중심 문제로 자동 채택하지 않음 |
| SpotLessSplats §6 Limitations, HTML Fig8–9 | **[원문 사실·잔여 실패/설정 위험]** 같은 class의 근접 객체, 얇은 구조 feature 누락, 공격적 pruning에서 드물게 보인 유효 부분 제거 | semantic 해상도/유사성 및 threshold가 정보 사용·모델 지지에 영향을 줌. 각 오류의 표면 정량은 미평가 | threshold 완화·강건 손실·기존 갱신법을 먼저 비교. 영구 건물을 실제로 지웠다는 사실로 확장 금지 |
| NeuRIS §4.3 Fig6 | **[원문 사실·ablation]** 무조건 normal prior에서 chair leg 소실, adaptive full에서 회복 | 잘못된 감독을 선택적으로 기각하면 실제 세부가 회복된 사례 | 잘못된 초기 표면이 옳은 prior를 영구 기각할 가능성은 **우리 추론**, 해당 원문의 관측된 실패가 아님 |
| BayesRays §6 Fig7, PDF p.8 | **[원문 사실·full 한계]** view 불일치가 만든 floater를 epistemic 점수가 놓침 | **[저자 해석]** aleatoric 효과를 대상으로 삼지 않음 | 점수 대상 밖 오류이지 모든 uncertainty의 무효성 아님. 저자가 제안한 aleatoric 결합도 가까운 대안 |

**[우리 추론]** 서로 다른 문헌에서 발견한 실패를 한 방법의 공통 결함으로 합칠 수 없다. 다만 이 사례들은 관측의 존재, 선택된 감독, 허용된 수정, 최종 결과 사이를 각각 확인해야 한다는 근거가 된다. `영상 잔차 감소→기하 개선`, `관측 희소→삭제`, `과거 상태 유지→현재성 확인`의 세 연결은 별도 증거 없이는 닫히지 않는다.

## 4. 추가 설명·해결 여지가 남는 경우와 기각 조건

아래는 **우리 연구 가설**이다. 입력·현재성·세부·외관을 유지한 채 기존 해결책의 충분성을 먼저 묻는다. 특정 수치 임계값이나 공식 평가를 새로 채택하지 않았다.

| 조사할 현상 | 가장 가까운 단순 해결 | 원인이 특정되었다고 볼 최소 비교 | 기각 또는 축소 조건 |
|---|---|---|---|
| 현재 영상에 보인 외관만 부족 | 고정 mesh+표준 texturing, 노출/색 보정 | 같은 geometry/pose/RGB에서 텍스처 품질·coverage와 새 시점 일관성 | 목표 충족 시 외관 부여를 새 방법 기여에서 제외 |
| 외관 개선 뒤 기하 오류·결손은 그대로 | 기하 고정 외관 fit, 기존 기하 갱신법, 정합+외관보정+갱신 | 외관만/기하만/두 자유도를 허용한 기존 처리에서 독립 표면과 영상 성과를 따로 비교 | 이득이 외관에만 있으면 기하 기여를 축소; 기존 조합으로 충분하면 새 분리/공동법 필요성 기각 |
| 보이는 얇은 요소가 수정 영역에서 탈락 | 기존 검출 민감도·팽창·sampling·가시성 조정 | 동일 관측에서 실제 mask 탈락→학습 감독/표현 지지 소실→최종 누락이 이어지는지 추적; 더 넓은 영역의 악화도 함께 확인 | 기존 조정이 회복과 비악화를 충족하면 새 판단·재판정 필요성 기각 |
| 약관측 부분을 제거하면 좋아 보이나 유효 support 감소 | 보수적 pruning·노출빈도·photo-consistency, 기존 불확실성의 분리된 사용 | threshold에 따른 오류뿐 아니라 coverage와 원래 유효한 부분의 손실을 공통 표면에서 측정 | 단순 지지량이 충분히 예측하면 새 uncertainty model 불필요; 정보가 없어 정답을 구별 못 하면 적용 조건/추가 관측 문제 |
| 과거 복원이 잘 유지되지만 현재 타당성은 미확인 | 관측 가능한 부분의 기존 변화검정·현재 대응·보수적 유지 | 현시점 관측이 있는 영역과 없는 영역, 가림과 삭제를 분리 | 미관측부의 최신 형상 복원 주장은 제한. 과거 보존 성과는 그대로 인정 |

표면 참조는 평가에만 사용한다. 참조 기반 oracle이 수정 여지를 보이는 것과 실제 입력에서 이를 식별할 수 있다는 것은 다르다. 비용·정보 접근을 맞추기 어려운 대안은 그 차이를 명시하며 억지로 같은 알고리즘이나 표현을 강제하지 않는다.

## 5. 현재 근거로 끝까지 연결할 수 있는 7문장

1. 기존 기하에는 영상만으로 불안정한 표면의 지지가, 현재 영상에는 기존 자산에 없는 외관과 조건부 기하 단서가 있을 수 있다.
2. 외관의 추가와 기하의 수정은 필요한 정보가 다르므로, 목표 성분별로 그 지지가 실제로 존재하는지 구분해야 한다.
3. 표준 texturing, 국소 GS 갱신, 외관/배치 분리, 선택적 prior 기각은 이미 그 정보를 사용하는 구체적인 기존 해결책이다.
4. 그럼에도 원문에는 특정 조건의 변화영역 누락, 드문 유효 support 제거, uncertainty 대상 밖 오류가 남아 있으며, 일부 외관/기하 간섭은 기존 방법이 이미 해결한 ablation 사례로 확인된다.
5. 이 근거는 모든 융합법에 공통적인 미해결 원인을 확정하지는 않지만, 정보가 존재해도 선택·수정 범위·관측모형을 거치며 원하는 성분으로 전달되지 않을 수 있다는 조사 경로를 준다.
6. 따라서 추가 연구의 필요성은 동일 입력에서 가까운 기존 처리로 충분한 경우를 인정한 뒤, 여전히 남는 현상에 대해 정보 부족과 처리상 손실을 구분하고 후자의 구체적 원인을 확인할 때 성립한다.
7. 기존 조합 이후에도 그 원인을 설명하거나 줄이는 이득이 확인되면 기여를 주장할 수 있으며, 현재 문헌 분석만으로는 특정 새 방법의 필요성까지 확정하지 않는다.

이는 조건과 추론을 숨기지 않고 논증의 구조를 연결한 것이다. 실증되지 않은 원인 칸까지 사실로 채웠다는 뜻은 아니다. 다음 단계의 문헌/기존 증거 감사는 하나의 임의 부위보다, 위 표에서 실제로 원인 추적이 가능한 사례를 선정하는 데 사용한다.
