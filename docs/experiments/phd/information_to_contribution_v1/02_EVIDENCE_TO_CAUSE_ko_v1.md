# 기존 정보 이용에서 잔여 실패의 원인까지

2026-09-09 · `scientific_verdict: null`

## 1. 원인이라고 부를 수 있는 범위

아래 표는 [입력 정보](01_INPUT_INFORMATION_ko_v1.md)를 기존 방법의 동작과 연결한다. **원문 관찰**, **저자 원인 해석**, **조건부 개입/ablation 근거**, **우리의 후속 가설**을 구분한다. ablation도 해당 방법·자료·설정에서의 증거이며 모든 방법의 보편적 원인 증명은 아니다.

잔여 실패가 있다는 사실은 해당 논문이 모든 조건을 해결하지 않았다는 근거다. 기존 후속책의 실패, 새로운 방법의 필요성, 우리 데이터에서의 동일 원인을 자동으로 입증하지 않는다. 논문의 full method에서 남은 실패와, 제거한 구성요소를 복원하면 해결되는 ablation 실패를 구별한다.

## 3. 연결에서 실제로 달라진 판단

### 3.1 '관측 부족'과 '처리 실패'를 원문 이상으로 구분했다고 주장하지 않는다

Zhou에서 prior를 해제한 뒤 second matching 실패가 있다는 것은 직접 근거다. 그러나 원영상에 복원 가능한 제약이 충분했다는 것은 별도 문제다. 단순히 다른 matcher가 더 좋을 것이라고 쓰면 원인이 채워진 것이 아니다. 같은 허용 관측을 쓰는 강한 재매칭이 실제로 무엇을 회복하는지 비교해야 정보 이용 실패라는 주장이 강화된다. 둘 다 실패해도 모든 가능한 방법의 불가능성이 증명되는 것은 아니다.

### 3.2 이미 원인에 개입한 선행연구는 공백을 줄이는 근거다

VCR-GauS·DebSDF·HelixSurf의 구성요소 비교는 감독/렌더링/재추정이 결과에 영향을 줄 수 있음을 보여준다. 이들은 서로 다른 모델·입력에서 수행한 비교이므로 수치를 합쳐 하나의 우열표로 만들지 않는다. 하지만 '후단으로 앞단을 바꿀 수 없다', 'prior를 기각하기만 하면 된다', '표현은 결과에 관계없다'와 같은 포괄 전제는 사용할 수 없다.

### 3.3 잔여 손상의 공통 단일 원인은 아직 확인되지 않았다

GS4B의 얇은 형상 손실, GeoGS의 특정 지역 악화, Wu의 오탐, CL의 갱신 누락을 모두 소스 선택·고정 prior·단방향 처리의 문제로 합치지 않는다. 각 오류가 시작되는 경로가 다르고, 어떤 경우에는 그 원인 자체가 미확인이다. 특히 GeoGS의 보호는 성공 조건에서 도움이 되며 이를 제거하는 것이 일반 해법이라는 근거가 없다.

### 3.4 정합·강건 추정은 이미 존재하는 원인 제거 수단이다

GNC는 정해진 관측 잔차에 대해 상태와 가중치를 교대로 갱신하는 강건 추정을 제공하며 point/mesh registration 등에 검증되어 있다. global optimum을 일반 보장하는 방법으로 소개하지 않는다. [GNC arXiv v2, §III–V](https://arxiv.org/html/1909.08605v2)

따라서 모든 불일치를 '변화/오류의 의미를 몰라서 생긴다'고 선언할 수 없다. 공통 좌표·scale·camera 및 단순 정제의 문제로 충분히 설명되면 기존 처리를 사용한다. 잔차의 크기가 특정 의미의 확률이라는 해석은 별도로 검증한다. 정합 분야 전체의 최신 방법을 전수 감사한 문서는 아니다.

## 4. 실제 원인 분리를 위한 최소 대비 — 설계, 실행 없음

아래는 전 실험 조합을 승인하는 목록이 아니다. 특정 현상을 고른 후 설명을 경쟁시키는 최소 대비 후보다. 평가 참조는 점수·진단용이며 honest method의 입력/선택으로 누출하지 않는다.

| 설명하려는 현상 | 먼저 비교할 기존 해결 | 원인에 더 가까워지는 대비 | 그 결과가 뜻하지 않는 것 |
|---|---|---|---|
| prior를 제외한 곳의 결손 | 기존 강한 guided matching/재매칭 | 원영상·pose를 고정하고 matcher와 prior 사용만 분리; 실제 관측 제약도 함께 확인 | 재매칭 실패만으로 입력정보 부재 확정 불가 |
| 혼합 입력에서의 위치/경계 오류 | 기존 정합·정제+원 복원 | 정합만 바꾼 결과, 같은 기하에서 supervision만 바꾼 결과를 나눔 | 정합 개선 이득을 새 소스 판단 효과로 귀속 불가 |
| 작은 형상이 학습/추출 후 사라짐 | 원방법 적정 설정, 기존 감독/표현 보정 | depth/normal 원증거 → 학습 표현의 native depth/normal·opacity/support → 동일 추출 및 대안 추출을 같은 영역에서 대조 | 최종 구멍만으로 prior 제약이 원인이라고 확정 불가 |
| 갱신 대상이 수정되지 않음 | 원 mask·기존 확장/재투영·강한 검출 | 수정 가능 영역만 바꾼 효과와 해당 영역 안의 복원 능력을 분리 | 참조 기반 oracle mask가 좋다고 자동 검출 가능성이 입증되지 않음 |
| 외관 개선과 기하 악화가 동시 관찰 | 고정 기하 texturing/appearance 처리 | 기하 고정+외관 수정, 기하 수정+동일 외관 처리, 최종 표면 평가 분리 | RGB 개선을 3D 세부 회복으로 해석 불가 |
| confidence가 잘못된 기하를 통과시킴 | score 원형·단순 보정·visibility 기준 | 같은 평가 대상·출력 종류에서 coverage를 맞춘 오류 순위·수정 손상 대조; 공유 입력 오류 확인 | threshold를 바꾼 차이를 새로운 uncertainty 추정의 효과로 귀속 불가 |

## 5. 기존 로컬 결과가 제공하는 것

기존 GeoGS P1/P2/P3와 Wu v7에는 실제 결과가 있다. 이들은 실패 현상을 고르고 입력–처리–출력 경로를 추적할 개발 자료로 쓸 수 있다. GeoGS는 ALS 파생 입력·공통 anchor 분기 등 native LoD2 조건과 다르고, Wu도 원문 기반 로컬 재구현이다. 따라서 논문 고유 실패의 직접 재현이나 독립 확증 자료로 취급하지 않는다. 현재 결과·제약은 [출처 감사](../literature_research_question_v1/05_SOURCE_AUDIT_AND_CONTEXT_ko_v1.md)와 거기 연결된 원기록을 읽었다. 이번 작업에서 payload를 재계산하지 않았다.

현상 선택에는 성공 사례와 이미 양호했던 부분도 포함해야 한다. 수정 부위만 골라 평가하거나, 결과를 보고 평가 단위·임계값을 바꾸어서는 같은 질문에 대한 비교가 되지 않는다. 참조가 없는 곳과 예측이 없는 곳도 구분한다.
