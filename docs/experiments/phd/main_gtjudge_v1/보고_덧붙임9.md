6. 대체 규칙과 제한

- 요청한 광축 30~60°에서 엄격 조건을 만족하는 사진이 없으면 70°까지의 경사사진으로 후보를 확장했다(실제 각도는 위 표·JSON에 기록). 건물 전체 화면 포함, MVS에 연직 투영한 같은 XY의 대상 선·지붕 가시 비율 98% 이상 여부, 대상 가시 비율, 지붕 가시 비율, 점유율 순으로 골랐다. 이 투영은 사진 선택에만 썼다. 전달하는 선 XYZ와 경우 점의 0.15m 가림 판정은 원래 참값 높이 그대로다. c3 현재 참값 높이의 선은 원래 30~60° 후보 전부에서 MVS상 가려졌다.
- 진단 정사영상은 덧붙임 6과 같은 원본 래스터를 쓰되, 기존 잘라낸 범위에서 1,450점 중 736점만 들어와 건물과 경우 2 전체를 포함하도록 범위를 넓혔다.
- 사진 범위에 원본 LoD2 Z가 섞인 초기 구도를 발견해 수정했다. LoD2는 GroundSurface XY 건물 식별에만 쓰고 등록된 단계1 참값 XYZ로 구도를 정했다. 사진의 건물 포함 비율은 그 참값의 3D 볼록껍질이 화면 안에 들어오는 비율이며, 실제 보이는 외벽 면적 비율은 아니다. 실제 점 가림 수는 별도 JSON에 있다.
- 점 상태 그림은 모든 요청 점을 보이는 대로가 아니라 XY 범위로 표시한다. 정사영상의 원 깊이가 없어 선 가림은 null로 명시했다.
- 확대 사진 저장 중 numpy.bool_ JSON 직렬화 오류 1회 발생 후 Python bool 변환으로 같은 설정 재실행했다.
