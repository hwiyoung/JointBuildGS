## 0. 한눈에

덧붙임 4의 1절 색 표에서 **경우 색 한 줄만** 바꾼다. 참값 점 색, 단면 선 색, 목표 색, 크기, json, 글자 없음은 모두 그대로다.

## 1. 바꾸는 색

| 경우 | 덧붙임 4 | 이 덧붙임 |
| --- | --- | --- |
| 둘 다 맞음 | `#7FA7D9` | `#7FA7D9` (그대로) |
| 사전 정보가 틀린 곳 | `#D85A30` | **`#1D9E75`** (초록) |
| 영상이 틀린 곳 | `#1D9E75` | **`#D85A30`** (주황) |
| 영상 없음 | `#E8B931` | **`#F0A07F`** (옅은 주황) |
| 둘 다 틀림 | `#8C95A3` | `#8C95A3` (그대로) |

- 까닭: 발표는 5~18쪽 모두 경우를 '그 자리에서 따를 자료의 색'으로 칠한다.
  - 사전 정보가 틀린 곳은 영상 깊이를 따르므로 영상 깊이(MVS) 색인 초록이다.
  - 영상이 틀린 곳은 사전 정보를 따르므로 사전 정보 색인 주황이다.
  - 영상 없음은 사전 정보를 물려받으므로 옅은 주황이다.
  - 그래서 1절의 단면 선 색(사전 정보 `#D85A30`, MVS `#1D9E75`)과 일부러 같게 둔다.
- 불투명도는 덧붙임 4의 3.1 그대로다(0.55, 둘 다 맞음만 0.35).
- **칠하는 차례**(점이 겹칠 때 나중 것이 위): 둘 다 맞음 → 둘 다 틀림 → 사전 정보가 틀린 곳 → 영상이 틀린 곳 → 영상 없음. 위에서 보면 벽의 점이 지붕 가장자리에 겹치므로, 수가 적은 경우를 나중에 칠해 가려지지 않게 한다.
