# PHD-MAIN-GTJUDGE-v1 덧붙임 4 산출물

scientific_verdict: null

사용자 시각 수정 요청에 따라 c1~c3은 사진 대신 실제 색 MVS를 30° 가상 시점에서 렌더했다. c1은 건물 전체의 지붕과 외벽, c2는 처마와 외벽이 함께 보인다. 전달 파일은 `_context_MVS.png`로 명명하며 사진으로 표시하지 않는다. c3은 나무·주변 벽의 가림 때문에 명시적인 국소 절개 렌더 `_context_MVS_cutaway.png`를 제공한다. 원래 자리 상자에 1m를 더한 UV 범위와 원래 표시선 높이 ±1.5m 안의 원본 삼각형만 남겼다. 절개 경계는 원자료의 결손을 의미하지 않는다. c4는 학습 사진을 사용한다. 같은 사례의 색 MVS/사진과 틀린 입력·참값 렌더는 같은 카메라와 화면 범위이고, c3의 절개 범위도 동일하다.

- c1: `MVS_virtual_c1_2_profile30`, 단면 띠 안 본 방법 완전성 75.7192%, 869점.
- c2: `MVS_virtual_c2_2_profile30`, 단면 띠 안 본 방법 완전성 81.9562%, 3,425점.
- c3: `MVS_virtual_c3_1_profile30_cutaway`, 단면 띠 안 본 방법 완전성 70.0422%, 237점. 기존 사례는 높은 본채 지붕이 아닌 약 44.05㎡의 낮은 평지붕(RoofSurface, DEBY_LOD2_4959324)을 지난다. 같은 단면 띠의 사전 정보 완전성 97.4684%, MVS 25.7384%, MVS 법선 거리 중앙값 +0.3839m이다. 원래 LoD2의 지붕 의미와 저장 거리값을 확인했으며 검사는 `verification/addendum4_c3_audit.json`에 기록했다.
- c4: `DJI_20241217103051_0002_D`, 단면 띠 안 본 방법 완전성 34.2382%, 2,947점.

원래 단면 XY·폭 1m·채점값을 유지했다. c1~c3의 색 MVS 위 표시선은 원래 참값의 지붕 점 높이를 따르며 지붕 높이가 불연속인 부분을 연결하지 않는다. 거리 색은 보이는 각 면 화소 위치에서 법선 원기둥의 가장 가까운 축 좌표로 계산한다. 회색은 원기둥 내 참값 없음이며 맞음 표시가 아니다. 참값 면은 확인 불가이므로 원래 점군의 PCA 음영 렌더를 제공했고 새 삼각화는 하지 않았다.

c3에는 같은 카메라의 사전 정보 음영과 `_input_section_detail.png`를 추가했다. 확대 단면은 사전 정보 주황·MVS 초록·참값 검정이며 수평과 수직의 미터당 화소 수가 같다. 표시 범위를 벗어난 선분 수를 JSON에 적었다. 기존 모든 방법의 전체 높이 범위 단면은 그대로 포함한다.

덧붙임 5는 위 사진 8장에만 적용했다. 경우 색은 둘 다 맞음 파랑, 사전 정보가 틀린 곳 초록, 영상이 틀린 곳 주황, 영상 없음 옅은 주황, 둘 다 틀림 회색이다. 겹침 순서는 둘 다 맞음 → 둘 다 틀림 → 사전 정보가 틀린 곳 → 영상이 틀린 곳 → 영상 없음이다. 좌표·점 수·크기·불투명도와 다른 그림의 바이트 보존은 `verification/addendum5_recolor.json`에서 검사한다. 발표 명칭은 LGDM이며 기존 fusion/결합 파일·표 이름은 유지한다. 별도 `PHD-MAIN-GTJUDGE-v1_사례사진색고침.zip`에는 위 사진 8장과 JSON만 담았다.

늘 보존 진단은 여섯 장면, 절단 0.25m/0.10m의 12개 메시와 1,260행 표다. 원래 사전 정보 높이의 정확 일치, 저장된 보존 칸 분류 일치, 메시 SHA-256, 표의 수 보존을 검사했다. 학습 실행 없음.

묶음은 `PHD-MAIN-GTJUDGE-v1_발표사례그림.zip`, `PHD-MAIN-GTJUDGE-v1_발표실험대상.zip`, `PHD-MAIN-GTJUDGE-v1_늘보존.zip`이다. 실제 경로·크기·SHA-256·CRC 검사는 `verification/addendum4_*_archive.json`에 기록했다. 최초 사례 ZIP은 시각 검토 부족으로 철회하여 외부 산출물의 `addendum4/delivery_revisions/visual_rejected_20261106T1742/`에 보존했다.
