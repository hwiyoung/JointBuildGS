# 실행 기록과 미완료 사항

- PH는 manifest의 외부 phase-payloads/phd로 해석했다. 재실행 문서의 실제 경로는 docs/experiments/phd/main_rescore_v1/addendum3_stage1/재실행_경로.md다.
- 여섯 장면의 상속 참값 입력은 점군이고 PCA 법선의 부호도 미설정이다. 발주문 2.1의 참값 삼각형 면/바깥방향을 확인하지 못했다.
- 90% 신호를 측정하지 못했으므로 없음/있음 어느 쪽으로도 채우지 않았다. 단계 1용 최근접 칸 fallback은 미적용이다.
- A-2는 500회부터 항을 적용하지만 λ는 1000회에 처음 정한다. 상속 FINALTRAIN에는 이 항이 없어 500~999회의 값을 가져올 수 없다. r25 준비본에 명시적 미정 오류를 두었으며 실행하지 않았다.
- GPU 사용은 상속된 작은 단위 예제 r23/r25 각각 100회와 합성 손실 점검에 한정했다. 실제 장면 학습·렌더·메시 생성은 0회다.
- r25의 실제 목표/맵 초기화 검증, A-2 전 구간 손실·삭제 수 추적, 전체 대기열, 실험 채점·정성 산출물은 미완료다.
- 묶음 첫 시도에서 상속 score 디렉터리의 절대 /out 심볼릭 링크가 호스트에서 해석되지 않아 source hash 재검사가 FileNotFoundError로 끝났다. 링크는 바꾸지 않고 원래 Docker 마운트 안에서 재검사하도록 수정했다. 설정·실험 정의 변경은 없다.
