# 재실행 경로와 현재 한계

`scientific_verdict: null`. 상태는 PARTIAL_PREFLIGHT_ONLY이며 실제 장면 계산 명령은 아직 없다.

| 명령 | 범위 |
|---|---|
| `bash scripts/phd/main_gtjudge_v1/run_cpu.sh reference inspect_reference.py` | 상속 입력 구조와 단계 0 계산 가능 여부 점검 |
| `bash scripts/phd/main_gtjudge_v1/run_cpu.sh unit-cpu unit_cpu.py` | 합성 거리·다수결 점검 |
| `python3 -B scripts/phd/main_gtjudge_v1/gpu_checks.py` | Docker GPU 단위점검만; 기존 fixture가 있으면 덮어쓰기 거부 |
| `bash scripts/phd/main_gtjudge_v1/run_cpu.sh report report_preflight.py` | 실제 실행하지 않은 단계들을 명시한 부분 보고 |

최초 freeze.py는 설정이 이미 있으면 거부한다. GPU 명령을 그대로 재실행하면 기본값 fixture 경로가 이미 있어 실패하므로 재실행을 자동 요청하지 않는다. 소스 변경 시 별도 검증 폴더/receipt를 추가해야 한다.

r25에는 목표 파일 스위치, 동일 해시의 목표·맵·씨앗 검사, 빈 공간 선택/기울기 원형이 있다. --jbgs_preserve_freespace on은 미정인 500~999회 λ 때문에 현재 실행 가능한 A-2가 아니다. 실제 목표가 없으므로 6.3 전체 통과로 간주하지 않는다.

부족한 참값 면을 찾은 뒤에는 기존 잠금을 덮어쓰지 말고 근거·정책을 별도 추가 잠금으로 남겨야 한다. 삼각화나 법선 교체를 이 문서에서 승인하지 않는다.
