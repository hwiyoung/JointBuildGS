- 칸은 '잘못 버림 / 잘못 지킴'(패치 수)이다.

### 1.3 확인하는 곳 (상자 넷, 보고서 3절)

- 규칙을 고르는 데 쓰지 않고 보고만 했다. 방향은 고르는 곳과 같았다.
  - 항공 LiDAR에 여유(모두) 2를 쓰면 상자마다 잘못 버림이 줄었다. B0는 802 → 431개, B173과 이웃은 1,873 → 695개, B173만은 1,510 → 831개, R1 부채꼴은 8,148 → 5,644개다. 잘못 지킴은 상자마다 30~87개 늘었다.
  - LoD2에 여유(모두) 2를 쓰면 잘못 지킴이 크게 늘었다. 예를 들어 R1 부채꼴은 1,203 → 5,005개다.
- 상자 안에는 재지 못한 곳이 적다. 그래서 전파만 바꾸는 규칙은 상자에서 지금 규칙과 거의 같았다. 여유(전파만)의 k도 상자로는 가를 수 없다.

## 2. 정할 것

항목마다 무엇을 정하는지, 왜, 선택지, 분석자 의견, 고르면 생기는 일의 순서로 적었다.

### 가. 버리는 규칙과 k (사전 정보별) — 핵심 (보고서 1.4절, 7.2-1)

- **정할 것:** 본 실험에서 LoD2와 항공 LiDAR에 쓸 버리는 규칙과 k.
- **왜:**
  - 두 사전 정보에서 잘못의 성격이 다르다.
  - LoD2는 일반화된 옛 자료다. 참 충돌이 많고(지붕 잰 곳의 25 %), 지금 규칙의 버림은 대부분 맞다.
  - 항공 LiDAR는 정확한 옛 자료다. 참 충돌이 적고(3 %), 지금 규칙의 버림은 대부분 MVS의 큰 오차(반투명 지붕, 넓은 평지붕의 어긋남, 벽 앞 나무)에서 온다.
- **선택지:**
  - LoD2:
    1. 지금 규칙.
    2. 여유(전파만) 1.5. 재지 못한 지붕의 잘못 버림이 945 → 509개로 줄고, 잘못 지킴은 565 → 774개로 는다.
    3. 여유(모두) 1.5~3. 잰 곳에서 잘못 버림 하나를 줄일 때 잘못 지킴이 1.6~2.8개 는다.
  - 항공 LiDAR:
    1. 여유(전파만) 2. 재지 못한 곳의 잘못 버림이 1,541 → 515개(−67 %)로 줄고, 잘못 지킴은 316 → 330개(+14개)로 는다. 잰 곳은 지금 규칙과 같다.
    2. 여유(모두) 2. 잰 곳의 잘못 버림이 37,244 → 15,291개(−59 %)로 줄고, 잘못 지킴은 3,992 → 6,250개(+57 %)로 는다. 늘어난 2,258개 가운데 1,395개는 참 차이가 1~2τ(항공 LiDAR τ = 8~16 cm)이고, 634개는 4τ를 넘는다. 재지 못한 곳은 720개, 329개로 1과 비슷하다.
    3. 여유(모두) 1.5. 2보다 약하다. 잰 곳은 −41 % / +37 %, 재지 못한 곳은 1,085개 / 324개다.
    4. 지금 규칙.
- **분석자 의견:** LoD2 = 1(지금 규칙), 항공 LiDAR = 1(여유(전파만) 2).
  - 설정에 미리 적은 기준('잘못 버림이 크게 줄면서 잘못 지킴은 거의 늘지 않는')을 채우는 것은 항공 LiDAR 재지 못한 곳의 여유(전파만)뿐이었다. k = 3(409개, 339개)도 거의 같아, 더 작은 2를 고른다.
  - 항공 LiDAR 잰 곳은 기준을 채우는 규칙이 없다. 여유(모두) 2는 잘못 버림을 크게 줄이지만 잘못 지킴이 57 % 늘어, 받아들일지는 사용자의 맞바꿈 판단이다.
  - 이 이득의 대부분은 R1 반투명 홀에서 나온다. 재지 못한 곳 잘못 버림 1,541개 가운데 1,128개가 R1이다.
- **고르면 생기는 일:**
  - 학습 코드 r11에서 사전 정보마다 `--jbgs_rule`로 고른다. 이름은 `current`, `margin_all_2`, `margin_prop_2` 등이다.
  - 손실의 허용 구간은 어느 규칙에서도 τ 그대로다(발주 4절).
  - 추가 계산은 없다.
  - 미리 적은 후보에 없는 조합을 원하면 새 규칙이다. 예를 들어 한 사전 정보 안에서 잰 곳과 재지 못한 곳에 다른 k를 쓰는 경우다. 이때는 설정을 새 판으로 적고 다시 세야 한다(학습 없음, 수십 분).

### 나. B0 연직 포함 조건의 영상 고르기 (보고서 5절, 7.2-2)

- **정할 것:** 관측의 양 비교에서 '연직을 넣은 같은 수' 조건(N13, N8, N2)의 영상을 어떻게 고를지.
- **왜:**
  - 지난 결정(사)대로 저자 조건(A15·A9·A3, 학습 13·8·2장) 옆에 연직을 넣은 같은 수의 조건을 더했다. 고르는 규칙은 결과 전에 적었다. 대상 건물을 가장 많이 새로 덮는 영상을 연직부터 더하는 규칙이다.
  - 그런데 그 규칙은 영상끼리 겹치는지를 보지 않았다.
  - N2의 두 장이 함께 보는 성긴 점은 17개뿐이라 깊이 지도가 하나도 나오지 않았다. A3의 두 장은 29개였다.

- **선택지:**
  1. 지금 규칙을 둔다. N2는 'MVS 불가'로 기록하고, 2장의 시점 방향 비교는 비워 둔다.
  2. N2만 바꾼다. 성긴 점을 29개 이상 함께 보는 (연직, 경사) 쌍 가운데 대상 건물을 가장 많이 덮는 쌍을 고른다(덮는 몫 39 %, A3는 37 %).

- **분석자 의견:** 3.
  - 같은 수에서 '연직을 넣으면 어떻게 되나'를 보려면, 고른 영상으로 MVS가 서야 한다.
  - 이 규칙으로 덮는 몫을 미리 재지는 않았다. 첫 연직 영상에서 시작한 같은 규칙은 N13·N8에서 60 %였다(A15 58 %).

### 마. 본 실험에서 돌릴 스위치 조합 (알림, 이번 발주에서 정하지 않음)

비교 방식을 정할 때 고를 수 있도록, 스위치를 끄면 무엇이 되는지를 적는다. 학습 코드 설정은 `--jbgs_sw_<이름> 0`이다.

| 스위치 | 끄면 | 비교로서의 뜻 |
|---|---|---|
| 관측 신뢰도 마스크 (`confidence_mask`) | 일관성 검사 없이, MVS 깊이가 있는 픽셀을 모두 신뢰도 1로 본다 | 관측 신뢰도의 몫 |
| 판정 (`judgment`) | 모든 판정이 일치가 되어 버리는 곳이 없다 | 옛 자료를 어디서나 믿는 비교 방법 |
| 판정 빌려 오기 (`propagation`) | 결측 패치는 모두 근거 부족으로 이어받는다 | 전파의 몫 |
| 사전 정보 당김의 구간 (`prior_band`) | 허용 구간과 절단 없이 늘 당긴다 | 손실 모양의 몫 |
| 보호 (`protection`) | 기울기 보호와 밀도 제어 예외가 없다 | 보호의 몫 |
| 초기화에서 빼기 (`init_exclusion`) | 충돌로 판정된 결측 패치의 점도 심는다 | 초기화 제외의 몫 |
| 사전 정보 (`prior`) | 사전 정보 출신 가우시안과 사전 정보 깊이 항이 없다 | 영상만 쓰는 비교 방법 |
