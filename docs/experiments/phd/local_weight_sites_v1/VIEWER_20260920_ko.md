## 수치와 표시의 역할

- **C 사례:** 같은 UAS 참조 표본에서 각 원본 삼각형 표면까지의 거리다.
- **W 사례:** 같은 MVS 입력 표본에서 표면까지의 잔차이며 독립 정확도가 아니다.
  주변 UAS를 이용한 별도 검사는 다른 표본 수·거리 정의로 구분한다.
- 원영상 표시는 기존에 검토한 실제 원영상의 투영 카드다. 3D는 원본 메시의 국소
  삼각형이며 새 표면 보간이나 높이 과장은 없다. MVS는 저장된 실제 입력 표본을 표시한다.
- 지도는 실제 MVS 위치를 표시용 1m XY 셀로 줄인 평면도다. 평가점·거리 계산에는 이 축약을 사용하지 않는다.
- 회색은 주변 UAS, 청록색은 MVS, 노란색은 선택한 평가점이다. 기본의 `평가점 가림 없이`
  설정은 가려진 표본도 보여 주는 진단 표시이며 실제 영상 가시성을 뜻하지 않는다.
- 거리선은 평가점→원본 메시의 최근접 삼각형 점이다. 화면 절단·가시 범위에 따라 선의 일부만 보일 수 있다.
- 분포의 0.5m 구간은 탐색용이며 합격 기준이 아니다. 기존 거리 상한 10m, CRS/정합·참조 한계를 상속한다.
- 기존 국소 prior0는 원래 보정 마스크를 쓴 결과다. Z07이나 W019를 대상으로 새 가중치를 적용한 결과가 아니다.
