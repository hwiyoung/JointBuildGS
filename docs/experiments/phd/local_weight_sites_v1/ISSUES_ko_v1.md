# 국소 가중치 후보 탐색 — 기술 이슈

## 2026-09-21 KST — 보류를 개선 불필요로 읽히게 한 요약과 접속 링크

- 문제: C10에 집중하자는 제안이 다른 MVS 사례의 개선이 불필요하다는 의미로
  읽혔다. 사용자는 수정 뷰어에서 연결 오류 또는 빈 화면도 보고했다.
- 원인: C05의 작은 보존 손실, W의 부분 개선·잔여 차이, 보류의 의미를 충분히
  구분하지 않았다. 링크는 실제 서비스 8913 대신 검증하지 않은 브라우저 표시
  포트 14782를 재사용했다. 사용자 클라이언트의 실제 중계 실패 원인은 미확정이다.
- 확인: 동일점 재집계 C05 146/345점에서 prior보다 MVS 거리가 0.1m 넘게 크다.
  W125/W150 잔차도 약 0.614/1.182m 남는다. 기존·새 페이지는 서비스 8913에서
  HTTP 200이며 호스트에 14782 listener는 없었다. 클라이언트 포트 상태와 동일시하지 않는다.
- 조치: 20개 전체 재검토 JSON/CSV·뷰어 패널을 추가하고 C05를 MVS 필터에도
  포함했다. 실제 서비스 주소를 제공하고 v2/v3 입구를 상대 경로로 최신 화면에
  연결했다. 정확한 기존 HTML은 보관본과 receipt로 보존했다.
- 해결 여부: 재집계 **PASS**, 브라우저 246개 + 입구/보관본 8개 **PASS**, HTTP
  571파일 검증. 사용자 측 연결의 성공 여부는 직접 확인하지 못했다.
- 남은 위험: 단방향 거리의 한계, 미확정 표면 대응·가중치 인과성, 사용자 측 포트 중계.
  GPU 학습·기하 변경 없음, `scientific_verdict: null`.

## 2026-09-21 KST — W019 우선순위와 원영상 위치 식별

- 문제: W019를 C10과 같은 우선 가중치 실험 대상으로 제안했지만, 사용자가
  원영상을 확인했을 때 옆면의 어느 구조를 가리키는지 분명하지 않았다. C 사례는
  투영 상자만 있었고 W 사례의 점은 축소된 사진에서 너무 작았다.
- 원인: MVS 입력과의 약 2m 잔차를 우선 보정 가설로 올렸지만, 출입구 주변 부속물의
  실제 표면 대응과 가림은 미확정이었다. 사진 표시도 개별 평가점 연결에 부족했다.
- 조치: C10을 MVS 우선 검토로, C03–C07을 DA3 개선 검토로 유지하고 W019는
  옆면 대응 보류로 변경했다. 전체 20개 기록·원수치는 보존했다. 원영상 전체/확대에
  실제 카메라 투영점·번호·시점 전환·3D 선택 강조를 추가했다.
- 해결 여부: 표시 **PASS**, 19사례 45시점·브라우저 205개 검사·HTTP 568개 파일 검증.
  남은 위험: 투영은 가시성 인증이 아니며, W019의 표면 대응·가중치 원인·회복 효과는
  미확정이다. GPU 학습 없음, `scientific_verdict: null`.

## 2026-09-20 KST — 뷰어 자동 검사의 완료 신호 직렬화

- 문제: 첫 브라우저 검사에서 Z07의 실제 네 화면·수치는 정상 표시됐지만 완료 대기가 시간 초과했다.
- 원인: `settled`는 비열거 getter여서 CDP `returnByValue`의 객체 직렬화에 포함되지 않았다.
  저장 상태는 `ready=true`, 네 화면 drawn, 오류 0인데 검사만 `settled` 부재로 계속 대기했다.
- 조치: 검사기가 브라우저 안에서 getter 값을 명시적으로 읽어 직렬화하도록 수정했다.
  게시 뷰어·기하·평가값은 변경하지 않고 새 `qa_v2`에서 다시 검증한다.
- 최초 `qa_v1/receipt.json`, `failure.png`, 검사 소스와 로그를 보존했다.
  `scientific_verdict: null`이며 브라우저 검사는 표시·상호작용의 기술 검사다.
- 해결 여부: `qa_v2` 141개 PASS. W 후보 초기 시점을 전체 사시로 바꾼 최종
  게시 v2의 `qa_v3`도 161개 PASS, 스크린샷 11개 확인. 기존 기하·수치는 유지했다.

## 2026-09-19 KST — Z07 보류를 후보 생략으로 요약한 오류

- 문제: “MVS는 전역 설정으로 충분한가”에 답하면서 W019만 잔여 후보로 설명하고,
  기존 R1 Z07 보존 후보와 다른 조건부 후보를 생략했다.
- 원인: 후보 유지와 표면·원인 판정의 보류를 구분하지 않았다. C03–C07의 좋은
  MVS 결과를 앞세운 요약도 MVS 전체의 잔여 문제를 축소해 전달했다.
- 확인: 동결 UAS 거리값에서 Z07 전체 155점 중 149점의 prior≤0.25m·MVS>1m를
  재현했다. 상단 대응 80점만 분리해도 **80/80**이 같은 구간이며, 중앙값은
  prior 0.121940m / MVS–GeoGS 1.606085m다. 아래층 혼입만으로 이 차이가 사라지지 않는다.
- 조치: 통합 문서 맨 앞에 Z07과 모든 기존 MVS 후보의 유지 이유를 명시했다.
  C10을 우선 보존 검토로 복원하고 현재 문서의 우선 기록을 7개로 갱신했다.
  원래 6개 우선 분류의 CSV·receipt는 역사 snapshot으로 보존하고 현재 판정과 구분한다.
- 해결 여부: 재집계 **PASS_FROZEN_REFERENCE_SUBSET_AUDIT**. 후보 누락 설명은 정정.
  상단 표본은 지붕·가시성 정답이 아니며 가중치 원인/국소 개입 효과는 여전히 미확정.
  새 학습·마스크·기하 변경 없음; `scientific_verdict: null`.

## 2026-09-19 KST — 이전 후보 생략과 대표 네 곳의 상태 혼합

- 문제: 직전 답변의 네 대표 위치가 전체 가중치 필요 지역 수로 읽혔고, 이전 C03–C07을 함께 제시하지 않았다.
- 원인: 이전 DA3 보정/보존 사례와 이번 MVS 불일치·잔여 오차 검색의 범위 차이를 명시하지 않았다.
- 조치: 이전 C 10개와 이번 W 10개를 metric·baseline·위치·상태·이유·가중치 가설별로 연결한 별도 통합 목록을 추가했다. 기존 완료 payload는 보존했다.
- 해결 여부: 기술 장부 `PASS_CASE_RECONCILIATION`. 우선 가설 검토 6사례는 가중치 필요성 확정 6지역을 뜻하지 않는다. 과학적 판단은 여전히 미확정이다.

## 2026-09-19 KST — 사진 검사 driver 이름의 표준 라이브러리 충돌

- 문제: 첫 사진 검사 실행이 NumPy import 단계에서 종료됐다.
- 원인: driver 이름 `inspect.py`가 Python 표준 라이브러리 `inspect`를 가려 순환 import가 발생했다.
- 조치: 저장소 driver를 `inspect_sites.py`로 변경하고, 충돌 파일이 없는 별도 `inspection_source_v2` snapshot에서 다시 실행한다.

- 해결 여부: `inspection/receipt.json`의 `PASS_SUPPORTED_VIEW_INSPECTION` 및 `review/receipt.json`의 `PASS_REVIEW_EXPORT_AND_RENDER_VIEW_IDENTITY` 확인. `scientific_verdict: null`.
