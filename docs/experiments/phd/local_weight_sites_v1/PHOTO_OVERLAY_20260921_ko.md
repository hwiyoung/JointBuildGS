## 사진에서 찾는 방법

원영상 절의 왼쪽은 원영상 전체, 오른쪽은 빨간 상자의 확대 영역이다. 두 화면 모두
동일 평가점의 정확한 카메라 투영 위치를 표시한다. `시점`을 바꾸어 비교하고,
점을 누르거나 `같은 점 찾기`에서 번호를 선택하면 해당 점을 분홍색으로 강조한다.
번호는 다른 시점과 3D에서도 같은 표본에 대응한다. 번호는 사례 내부 번호이며
원자료 행은 별도로 표시한다. `투영점 표시`를 끄면 영상 내용을 가리지 않고 볼 수 있다.
`크게 보기`에서도 투영점을 선택할 수 있다.

- 노랑: C 사례 UAS 투영점, W 사례에서 해당 시점의 동결 MVS 지지점.
- 주황: W 사례의 투영점 중 해당 시점의 MVS 지지가 확인되지 않은 점.
- 분홍: 선택한 점. 3D에서는 가림 없이 강조하므로 실제 가시성을 의미하지 않는다.
- C10의 전체 155 / 상단 대응 80 / 나머지 75 선택은 사진 투영점과도 연동한다.
- 원영상 파일은 원본 바이트를 그대로 복사하고 표시층은 SVG로 분리한다.
- 투영은 `K(RX+t)` 및 기존 카메라의 영상 크기를 사용한다. 임의 위치 표시나
  새 정합, 원영상 리사이즈·왜곡 보정은 추가하지 않는다.
- W145의 사진 부재는 그대로 유지한다. 전체 20개 기록을 삭제하지 않는다.

원영상 투영은 가림·표면 대응의 정답이 아니다. W의 MVS 지지는 동결된 진단
membership을 표시하며 정확도·보정 필요성 판정으로 바꾸지 않는다.
