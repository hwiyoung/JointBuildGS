# 잔여 실패 목록의 재검토

2026-09-09 · `scientific_verdict: null`

## 1. 판단

**네 표현을 잔여 실패의 확정 목록으로 사용할 수 없다.** 기존 정리는 오류의 존재·발생 위치·원인·새로운 해결 여지를 충분히 구분하지 못했다. 특히 변화 검출 결과의 누락을 최종 3D 형상의 누락처럼 설명한 부분을 정정한다.

| 이전 표현 | 정확한 지위 | 이번 처리 |
|---|---|---|
| 낡은 기하 | 입력의 시기·유효성 조건 | 실패명에서 제외. ‘잘못된 과거 형상이 현재 결과에 남음’이라는 별도 출력 증거가 있어야 한다. Wu2026의 낡은 학습 label 사례는 정제로 개선한 선행 문제다 |
| 기존 기하 제외 | 처리 동작 | 실패명에서 제외. Zhou에서 직접 확인한 잔여는 변화 누락·불완전 피복이며, ‘최종 현재 표면 전체가 복원되지 않았다’는 별도 검증과 같지 않다 |
| 세부 손실 | 출력 오류 현상 | GS4Buildings 등에서 유지. 해당 원형의 잔여라는 범위를 적고 GeoGS 등 후속 해결을 대조해야 한다 |
| 얇은 변화 영역 놓침 | 중간 검출 오류 | CL-Splats에서는 갱신 실패까지 연결한 사례가 있어 유지하되, ‘얇은 구조의 갱신 누락’으로 출력과 연결. 일반적인 metric 표면 정확도 실패로 확대하지 않는다 |

실패 이름은 입력 상태나 기능이 아니라 **어떤 출력에서 무엇이 잘못됐는지**로 쓴다. 서로 겹치는 현상을 억지로 상호 배타적 유형으로 나누거나 새 개수를 고정하지 않는다.

## 2. 무엇을 잔여 증거로 셌는가

- **결과 사례:** 원형의 최종 구성에서 특정 오류가 그림·표·사례 설명으로 제시됨. 정성 관찰과 정량 측정을 구분한다.
- **비교 열세:** 특정 지표·지역에서 비교군보다 낮음. 공식 실패 기준 통과 여부나 특정 형상 손상 원인은 증명하지 않는다.
- **교란/설정 결과:** 전체 구성은 유지하되 입력 잡음·결손 또는 parameter를 바꾼 조건에서 악화함. 기본 조건의 실패와 분리한다.
- **중간 오류:** 시차·변화 label·mask·불확실성 등의 오류. 최종 표면·외관에 미친 영향이 직접 확인됐는지 추가 표기한다.
- **저자 한계 진술:** 원문에서 인정하지만 해당 실패의 독립 그림·수치가 확인되지 않음.
- **제외:** full이 개선한 제거 실험, 적용 가정 자체, 평가하지 않은 조건, 우리만의 원인가설.

모든 방법의 절대 오류가 0이어야 성공이라는 기준을 만들지 않는다. 지표가 유한하게 남거나 1 미만이라는 이유만으로 새 연구가 필요한 실패 유형을 만들어내지 않는다.

SRDM의 깊이 급변 영역 시차 오정합, Wu2023의 오래 주차한 차량 잔류, GaussianUpdate의 강한 반사 실패는 원문에 한계로 기술된다. 해당 현상의 독립 실패 그림·수치 확인 수준을 원장에 명시했으며 위의 직접 사례와 같은 지위로 올리지 않았다.

## 5. 현재 잔여 목록에서 제외할 것

1. Wu2026 Fig.8의 낡은 감독 label→stereo 실패: SGM label 정제·재학습으로 개선한 기존 문제다.
2. Wu2023의 ray-only 평행 방향 오판: distance 검사를 결합해 완화한 기존 문제다.
3. NeuRIS의 chair leg/얇은 물체, VCR의 normal/confidence 제거 artifact, DebSDF의 불완전 구성에서 thin structure 손실: full 기여가 개선한 제거 실험이다.
4. GaussianUpdate의 mask/removal 요소 제거 뒤 사라진 물체 잔류: full이 이미 완화한 비교다.
5. SpotLessSplats의 공격적 UBP에서 드문 유효 영역 제거: clean MipNeRF360 압축 설정의 위험으로 기록하며 모든 기본 full 결과에 귀속하지 않는다.
6. ‘과거 자산을 평가하지 않았다’, ‘전역 조명 변화를 다루지 않는다’, ‘대규모 분산 구현이 없다’: 적용 범위·검증 부족·계산 조건이다. 관측된 복원 오류가 아니다.
7. ‘잘못된 두 평행면도 normal이 같으면 통과한다’, ‘피드백이 오판을 자기 강화한다’: 가능한 원인가설이며 해당 방법의 full 잔여로 관찰한 사실이 아니다.

## 6. 무엇이 아직 연구기여의 근거로 부족한가

이번 감사에서 확보한 것은 **방법·입력 조건·출력 종류가 붙은 잔여 증거 목록**이다. 다음 세 문장은 아직 구별해야 한다.

1. **해당 논문 원형에 오류가 남았다.** 위 사례로 말할 수 있다.
2. **가까운 후속 방법과 적절한 기존 처리를 적용해도 같은 조건의 같은 오류가 남는다.** 대부분은 직접 대비 근거가 아직 없다. 해결되지 않았다고도, 해결됐다고도 단정하지 않는다.
3. **그 잔여를 새롭게 설명하거나 해결할 수 있다.** 별도의 원인 분리와 기존 해결 대비 추가 설명력·효과가 필요하다.

따라서 세부 손실 하나를 GS4Buildings에서 찾았다는 이유로 GeoGS 뒤의 공백으로 옮기거나, 2DGS의 유리 구멍을 모든 prior 융합법의 미해결 문제로 옮기면 안 된다. 반대로 한 선행연구의 성공 사례가 다른 입력 조건의 동일 현상까지 모두 해결했다는 뜻도 아니다.

**기존 유효 구조의 손상과 잘못된 과거 형상의 잔류**는 원래 연구 목적에 중요하다. 그러나 이번 원문 감사만으로 모든 가까운 원형에서 이 두 문제가 직접 입증됐다고 할 수 없다. GeoGS의 지역 지표 열세는 원래 유효한 면의 손상 증거와 다르다. [Wu v7 로컬 결과](../wu_vallet_synthesis_v7/RESULTS_AND_CONTRIBUTION_ko_v7.md)에는 잔여 과거면·이중층·구멍·개선과 악화가 있고 [GeoGS P2](../geogs_p1p2p3_v1/P2_REVIEW_ko_v1.md)에도 실제 렌더/표면 결과가 있다. 이들은 입력 변환·재구현·개발 자료라는 별도 계보로 분석해야 하며, 원 논문의 full 실패로 소급하지 않는다. 이번 작업에서 재계산하지 않았다.

다음 원인 분석의 진입점은 다음과 같다. 이는 새 실험 실행 승인이 아니다.

| 후보 증거 | 다음에 밝혀야 할 연결 | 후보를 축소할 조건 |
|---|---|---|
| 외부 기하+영상의 세부/표면 결과 | 가장 가까운 GeoGS/기존 설정에서도 같은 관측·기하 정보가 결과에 반영되지 않는 위치가 있는가. 입력 depth→학습 표현→추출 중 어느 단계에서 달라지는가 | 기존 입력 정합·감독·밀도/추출 설정으로 해결되거나, 필요한 정보가 두 입력에서 확보되지 않음 |
| 기존 자산 갱신의 오탐·누락 | 변화 label 오류가 실제 최종 기하의 유지·삭제·추가 오류로 얼마나 전달되는가 | label은 틀려도 최종 복원 영향이 없거나, 기존 검출/필터/갱신으로 충분히 해결됨 |
| 외관 오류·갱신 잔류 | 목표 외관 계약과 관측 조건을 정했을 때 기존 외관/조명/반사 처리가 어디까지 해결하는가 | 계약 차이나 기존 외관 처리로 설명됨. 외관 점수 변화만 있고 목표 기하·외관의 실질적 손실이 없음 |

여기서 특정 건물 부분이나 표현을 학위 범위로 결정하지 않는다. 사례의 추적 가능성과 함께 원래 목적에서의 중요성, 반복성, 가까운 기존 해결 뒤의 잔여를 확인해야 한다.
