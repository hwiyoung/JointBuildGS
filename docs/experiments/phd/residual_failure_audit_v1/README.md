# 잔여 실패 목록 재감사 v1

2026-09-09 · 문헌 검토 · `scientific_verdict: null`

**앞선 ‘낡은 기하 / 기존 기하 제외 / 세부 손실 / 얇은 변화 영역 놓침’은 확정된 네 가지 잔여 실패가 아니다.** 입력 조건, 처리 동작, 최종 결과의 오류, 중간 검출 오류가 섞였고 다른 잔여 현상도 빠졌다. 이번 문서는 원문에 실제 제시된 결과와 그 해석 범위를 다시 연결한다.

- [재감사 결과와 연구기여에 사용할 수 있는 범위](RESIDUAL_FAILURE_AUDIT_ko_v1.md)
- [논문별 원문 근거·버전·위치·제외 항목](SOURCE_LEDGER_ko_v1.md)
- [이슈·확인 범위·보존 검증](ISSUES_ko_v1.md)

원문에 오류가 남았다는 사실과, 가까운 후속 방법·합리적인 조합으로도 해결되지 않았다는 사실은 다르다. 이 문서는 새로운 공백의 개수나 학위 기여를 확정하지 않는다. 연구의 상위 목적을 지붕면 보존, GS, 소스 판단 모듈, 반복 최적화 또는 시간차로 좁히지 않는다.

이전 [문헌 카드](../literature_research_question_v1/README.md)와 [정보–기여 연결](../information_to_contribution_v1/README.md)은 탐색 색인으로 사용했다. 원문과 재대조한 정정은 이 별도 경로에 기록하고 기존 문서를 덮어쓰지 않았다. GeoGS 출판 전문과 실제 로컬 결과는 존재한다. 로컬 입력 변환·재구현 결과와 논문 원형의 결과를 분리한다.

작업 범위는 문헌 읽기·비교·문서 작성이다. 새 장면 학습·장면 렌더·방법 실험·기존 결과 재계산을 수행하지 않았다. 기존 서비스·코드·산출물과 진행 중 작업을 변경하지 않았으며 stage/commit/push를 수행하지 않았다.
