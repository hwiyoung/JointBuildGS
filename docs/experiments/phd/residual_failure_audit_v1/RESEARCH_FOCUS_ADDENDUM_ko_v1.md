# 연구 초점과 중요성 — 잔여 실패 감사의 해석 정정

2026-09-09 · 사용자 지적 반영 · `scientific_verdict: null`

## 1. 정정하는 기준

**유효한 기존 구조의 보존과 잘못된 과거 형상의 최신화를 연구하기 위해, 여러 기존 방법에서 동일한 핵심 실패가 먼저 확인되어야 하는 것은 아니다.** 앞선 답변은 관측된 실패 주장에 필요한 근거와 연구 질문을 제안하는 데 필요한 근거를 혼동했다.

사용자의 의도는 보존·최신화라는 중요한 복원 목적을 기준으로 **기존 연구가 충분히 다루지 않았거나 주된 관심으로 삼지 않은 부분을 찾고, 그 부분이 결과에 왜 중요한지 논증하는 것**이다. 특정 공통 실패의 확인을 후보 제안의 필수 조건으로 두지 않는다.

[잔여 실패 감사](RESIDUAL_FAILURE_AUDIT_ko_v1.md)의 사실 구분은 유지한다. 관측되지 않은 오류를 관측됐다고 쓰거나, 제거 실험을 full method의 잔여로 쓰면 안 된다. 다만 ‘관측된 잔여’ 칸에서 제외한 적용 가정·조건 차이·검증 범위도 연구 필요성의 근거가 될 수 있다. 그 중요성과 기존 해결 범위의 차이를 논증하면 된다.

## 2. 기존 성과와 구별하여 검토할 연구 초점

아래는 **우리의 문헌 종합에 따른 질문 후보**다. 분야 전체의 부재·최초성이나 새 방법의 성능을 확정하지 않는다. 같은 기능이 있다는 이유로 연구 여지를 닫지도 않고, 기능이 비었다는 이유로 신규성을 확정하지도 않는다.

| 검토 초점 | 이미 존재하는 성과 | 더 집중해 물을 관계 | 복원 목적에서의 중요성 |
|---|---|---|---|
| **부분적으로 유효한 기존 기하의 사용 범위** | SRDM/Zhou의 prior 검정·재매칭, Wu의 시기·품질·가시성 선택, GeoGS/ARS의 입력 오류 강건성 | 정합 오차·관측 부족·실제 형상 차이가 섞일 때 어떤 정보까지 현재 복원에 사용할 근거가 있는가. 변화의 존재를 아는 것과 정확한 새 표면을 얻는 것은 어느 조건에서 구별되는가 | 현재 관측을 근거로 과거 일부가 틀렸다고 알더라도, 그 관측이 정확한 대체 형상 전체를 제공하는 것은 아니다. 잘못된 부분을 수정하면서 주변의 유효한 정보를 이용할 수 있어야 한다 |
| **기하 성분과 규모에 따른 보존·수정 범위** | depth/normal 감독, 구조 보호, 세부 정제, 적응적 가중이 이미 있음 | 같은 기하에서도 위치·방향·큰 형상·작은 세부의 유효성이 다를 때, 그 차이를 어떤 수정 범위와 제약으로 연결하는가 | 큰 형상에 유효한 prior가 작은 세부까지 정확하다는 뜻은 아니다. 세부를 추가할 필요가 큰 형상을 바꿀 근거가 되는 것도 아니다. 유효한 성분과 수정할 성분의 관계가 보존·복원 양쪽에 중요하다 |
| **판단·제어의 범위와 최종 복원 변화의 관계** | 변화 mask, 기하 선택, GS 제어, mesh 추출, 기하·렌더 평가가 이미 존재 | 어떤 판단·제어가 필요한 형상을 회복했고, 어떤 유효 형상에 영향을 주었는가. 판단 대상·수정 단위·추출 표면의 범위가 다를 때 결과를 어디까지 설명·통제할 수 있는가 | 중간 단계의 올바른 판단이나 primitive 보호만으로 최종 표면 보존을 대신 판단할 수 없다. 결과까지의 연결이 있어야 보존과 최신화의 실제 이득을 설명할 수 있다 |

여기서 세 번째는 평가 지표를 추가하는 것만을 기여로 삼는다는 뜻이 아니다. 이 관계를 분석해 기존 수정 규칙이 유효한 조건을 밝히거나, 더 적절한 제어를 도출하는 것이 연구 대상이다. 첫 번째도 명시적 소스 판단 모듈을, 두 번째도 GS나 특정 다중규모 표현을 필요조건으로 정하지 않는다.

## 3. ‘덜 집중했다’고 말할 수 있는 범위

- [Wu2023 §III–IV](https://arxiv.org/html/2303.07182v1)는 잘 정합된 sensor mesh의 일치·충돌·단독 관측, 시기·품질에 따른 선택과 접합을 직접 다룬다. 새로운 소스 선택이나 품질 고려라는 기능 자체를 공백으로 쓰지 않는다. 현재 영상의 파생 기하 오류와 잔여 정합 오차가 함께 있을 때 사용 범위를 어떻게 정할지는 그 입력·검증 조건과 비교해 구체화할 질문이다.
- [GeoGS §3.4·5.5–6, Tables6–7](https://doi.org/10.1016/j.isprsjprs.2026.07.011)는 구조 anchoring/protection, visual refinement와 prior/pose 오류 검증을 이미 제공한다. 구조 보존·세부 복원이라는 목적은 겹친다. 각 기하 성분의 유효한 정보 범위와 실제 제약·최종 표면 변화의 대응을 체계적으로 분리한 근거는 이번 검토에서 충분히 확인되지 않았다. 전문 근거는 [원문 원장](SOURCE_LEDGER_ko_v1.md)의 확보 PDF와 위치를 따른다.
- [CL-Splats §3–4·9.2](https://arxiv.org/html/2506.21117v2)는 국소 변경 검출과 배경 보존을 실제 갱신에 연결하며 mask recall 영향도 평가한다. 갱신 대상 검출과 배경 보호를 처음 연결한다는 주장은 불가하다. 기존 색상 GS와 무색 외부 기하의 입력 차이, metric 표면 수정의 영향은 별도로 비교할 부분이다.

따라서 현재 적절한 표현은 **‘검토한 가까운 연구는 각각의 목표와 조건에서 보존·갱신을 이미 다루지만, 부분적 정보 유효성을 실제 수정 범위와 최종 복원 영향에 연결하는 관계는 추가로 집중하여 연구할 대상이다’**이다. ‘기존 연구가 전혀 다루지 않았다’는 넓은 주장을 하지 않는다. 관측 조건에 따른 불확실성·강건 정합·다중규모 제약·표면 융합의 직접 경쟁 연구는 구체화한 각 초점에 맞춰 계속 대조한다.

## 4. 필요성과 기여를 연결하는 순서

1. **복원 요구:** 재사용할 수 있는 정보를 보존하면서 오류·변경 부분을 수정하고, 관측 가능한 세부·외관을 복원한다.
2. **기존 연구의 집중과 경계:** 무엇을 이미 해결했고 어떤 입력·관측·표현·검증 조건에 초점을 두었는지 확인한다.
3. **중요한 미집중 관계:** 위 목표를 달성하는 데 중요한데 충분히 분리해 설명·처리하지 않은 관계를 질문으로 제안한다.
4. **중요성의 근거:** 실제 사례, 기존 실험, 관측/표현 모형에 따른 분석, 조건별 비교로 그 관계가 복원 결과에 어떤 차이를 만드는지 보인다. 공통 실패 사례만이 유일한 증거는 아니다.
5. **기여의 판정:** 기존 설명을 넘어서는 분석·예측, 알려진 원인에 대한 더 나은 해결, 또는 엄밀한 경험적 규명 중 무엇을 추가했는지 평가한다.

지금 연구 질문을 제안하고 필요성을 서술할 수 있다. 가장 가까운 기존 방법의 같은 조건 실패를 모두 먼저 실험으로 입증한 뒤에만 후보를 논의해야 하는 것은 아니다. 반면 최종 방법 기여·효과를 주장할 때는 적합한 비교와 검증이 필요하다.

이번 문서는 연구 범위·실행 계약을 바꾸지 않는다. 시간차는 여러 조건 중 하나이며 지붕면·GS·명시적 판단·소스 교체·공동/반복 최적화를 미리 선택하지 않는다. 기존 문서·코드·결과를 수정하지 않았고 새 학습·장면 렌더·방법 실험은 수행하지 않았다.
