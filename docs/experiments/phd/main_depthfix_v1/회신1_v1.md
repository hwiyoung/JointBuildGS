## 1. 스위치 나: 무게

| 항목 | 내용 |
|---|---|
| 사실 | 본 방법 판의 무게는 clip(σ_ref ÷ σ, 0.1, 10)이다. 발주문 0절과 2.2절이 제곱으로 적은 것은 틀렸다(TARGETPATH-v1 `issues.md` 1) |
| 답 | 새 무게는 지금 무게의 제곱근, 곧 clip((σ_ref ÷ σ)^0.5, √0.1, √10)이다 |
| 판 2의 물음 | "무게의 제곱을 빼면"이 아니라 **"패치 사이의 무게 차이를 줄이면 덜 잃는가"**다 |
| 쓰는 말 | 표, 그림, 보고서에서 '제곱 빼기'라 쓰지 않고 '무게 차이 줄이기'라 쓴다 |

## 2. 새 판단 구조의 목표

| 항목 | 내용 |
|---|---|
| 답 | 목표 종류와 점수(`A2_c_ge5_frac`)는 묶음 나5의 패치에서, 높이는 학습 장면의 패치에서 가져온다 |
| 가중 평균 목표 | 장면의 두 높이와 장면의 정밀도로 구한다 |
| 이어지지 않은 패치 | 본 방법 판의 목표를 그대로 쓴다. 수와 넓이를 장면마다 적는다 |

종류는 캠퍼스 영상 깊이로 정하고 높이는 장면 영상 깊이를 쓰므로, 두 높이가 다른 패치에서는 종류와 높이가 서로 맞지 않는다. 그 크기를 학습 전 셈 묶음에 더한다.

- 두 영상 깊이 높이의 차이 분포를 장면마다, 목표 종류마다 낸다(중앙값, 90 % 값, 그 패치의 허용 거리를 넘는 넓이 비율).
- 장면의 높이로 '차이가 유의한가'와 '큰가(`mix_large`의 경계)'만 다시 따졌을 때 목표 종류가 바뀌는 패치의 수와 넓이를 낸다. 영상 점검은 다시 하지 않는다.
- 발주문 5.1절의 표는 종류가 바뀌는 패치에 놓인 참값 점을 뺀 값도 함께 낸다.

## 3. 그림 자리

정의되지 않은 세 자리(R1 톱니 모양 금속 지붕의 골, R1 × LoD2 둥근 건물 벽, B173 주변 옥상 구조물 둘레)는 에이전트가 정한다. 자리마다 건물, 상자의 좌표, 고른 까닭을 적고, 모든 판에 같은 자리와 같은 시점을 쓴다.

## 4. 학습 단위

- 이 발주의 학습은 본 방법 판(FINALTRAIN-v1)과 같은 **건물 단위 장면**으로 한다. 2 × 2 칸으로 하지 않는다.
- 화소 무게의 기준 정밀도(σ_ref)는 FINALTRAIN-v1과 같이 장면마다 하나다.
- 보고서 맨 앞에 학습 단위가 건물 단위 장면임을 적는다.
