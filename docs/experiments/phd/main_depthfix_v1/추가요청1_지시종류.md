- 학습 단위: 건물 단위 장면. 값만 싣는다. `scientific_verdict`: null.
- 대상 점 = 영상 깊이가 틀리고 판 0 목표가 맞는 점(잃음·지킴은 판 0 씨앗 0 기준 추출). 영상 = 점이 화면 안에 들고 점의 법선이 카메라 쪽인 학습 영상 가운데, 그 화소의 영상 깊이가 점보다 10 m 넘게 앞이 아닌 영상(가려지지 않은 영상).
- 종류(TARGETPATH-v1 2절 그대로): 맞는 목표(원반, 무게 > 0, 목표가 점에서 τ 안) · 앞의 다른 목표(원반, 목표 < 점 − τ) · 영상 깊이 지시(원반 없음, 무게 > 0) · 뒤의 목표(원반, 목표 > 점 + τ) · 지시 없음(무게 0). 화소 = floor(K·x + 0.5). 스크립트 `df19_kinds.py`, 표 `tables/kinds_visible_*.csv`.
