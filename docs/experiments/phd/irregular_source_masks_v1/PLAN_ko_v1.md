# P1/P2/P3 비정형 수정·소스판정 마스크 검토

`PHD-IRREGULAR-SOURCE-MASKS-v1` · 2026-09-15 · `scientific_verdict: null`

사용자가 요구한 것은 영상에서 수정이 필요한 비정형 영역의 위치·범위·경계를
잘 추출하는지 확인하는 것이다. 기존 13개 통과 관측의 7×7 소스 교체 실험은
국소 개입 시험이며 이 영역 추출 질문을 검증하지 못한다. 기존 결과와 실행은
그 계보로 보존하고, 영역 추출과 검토를 별도 추가 실험으로 바로잡는다.

## 계산할 범위

동결된 MVS 관측 실험의 P1/P2/P3 각 3개 기준 영상과 그 이웃 영상을 그대로
사용한다. 동일한 원 RGB 광선에서 보정 ALS Prior와 COLMAP MVS 깊이를 비교한다.
전체 프레임에 깊이차와 결측을 표시하고, 기존 지역 XY에 어느 소스 가설이든
들어오는 범위에서 모든 유효 불일치 픽셀을 직접 검사한다. 기존 통과 13개 위치나
마스크로 새 계산을 제한하지 않는다. 참조 Z, 결과 점수, 평가 주석은 입력하지 않는다.

7×7 주변 창은 중심 픽셀의 영상 대응 비용을 계산하는 데만 사용한다. 중심의
판정을 49개 픽셀에 복사하거나 희소 격자를 보간하지 않는다. 각 원픽셀의 결과가
모여 마스크 형태를 결정한다. 마스크 팽창·구멍 채우기·의미 영역 확장은 수행하지
않는다. 따라서 경계에서 근거가 부족하면 유보 또는 결측으로 남을 수 있다.

## 판정과 단계별 비교

1. **깊이 불일치 후보:** 두 깊이의 유효 영역, 부호 있는 camera-Z 차이,
   불일치 후보와 검사 XY 범위를 원사진에 겹친다.
2. **두 표면 가설의 관측 근거:** 같은 픽셀을 각각 Prior와 MVS 깊이에 놓고,
   같은 이웃에서 자체 깊이 호환성·교차 깊이 상태·시차·공통 영상 대응을 검사한다.
   깊이 모델과의 호환성을 독립적으로 확인된 실제 가시성이라고 부르지 않는다.
3. **대응 모호성:** 소스 선호가 있는 후보의 각 중심에서 두 소스 법선에 따른
   깊이 비용곡선을 검사한다. 실제 비교 가능한 모든 선택 이웃의 지지·반대·중립을
   포함한다. 탐색 범위·간격·폭·경계·다중 구간을 남긴다.
4. **비정형 판정:** MVS 지지 후보, Prior 지지 후보, 깊이 양립 가능, 유보,
   결측, 아직 계산하지 않은 픽셀을 구분한다. 깊이 양립 가능은 FUSION 우위나
   현재성 확정이 아니다. MVS 미채택을 Prior 정답으로 바꾸지 않는다.

소스 선호는 같은 적격 이웃 중 지지 2개 이상이면서 반대보다 많아야 한다.
2 대 2는 유보한다. 깊이 모호성 조건과 해당 소스 깊이 일치 조건도 통과해야
최종 지지 후보가 된다. 이 조건은 새 개발 규칙이며 보정된 관측 오차나 검증된
검출 정확도가 아니다. 비용곡선 검사 전후 이웃 수를 각각 저장한다.

## 데스크탑 검토

원영상과 결과를 동일 좌표·동일 확대율로 나란히 보여준다. 후보, 소스별 지지·반대,
모호성, 판정 레이어를 바꾸면서 경계·과선택·누락을 비교한다. 픽셀 클릭은 저장된
원 수치를 반환한다. 미산출은 0으로 표시하지 않는다. 계산 중에도 초기 후보와
완료된 관측 범위를 표시하며, 완료되지 않은 판정은 명시적으로 남긴다.

선택된 영역만 보지 않고 비선택·유보 영역까지 확인한다. 독립 평가 주석이 없는
현재 시각적 검토는 precision/recall/IoU를 제공하지 않는다. 실제 시간 변화와
Prior의 기존 오류도 별도 시기 증거 없이는 구분하지 않는다. 같은 영상에서 얻은
MVS와 RGB의 재투영 적합도는 독립 정확도 평가가 아니다.

## 실행과 후속 비교

기존 학습과 별도의 CPU Docker 계산이다. 고정 소스 snapshot, config, 입력 해시,
실행 로그, 픽셀별 배열, PNG와 receipt를 새 attempt에 저장한다. 이 작업은
영역 마스크를 산출하며 기존 Gaussian이나 이미 진행 중인 학습을 수정하지 않는다.
서비스는 읽기 전용으로 결과를 보여준다.

영역의 과선택·누락·경계를 먼저 검토한 뒤, 해당 마스크를 사용하는 GS 비교에서
원 소스 교체 효과와 최적화 효과를 분리한다. 마스크가 잘못됐는데 GS가 손실을
낮춘 경우를 영역 판정의 성공으로 세지 않는다. 학습 중 반복적인 영역 재판정은
별도 실험이며 이번 고정 마스크 추출에 포함하지 않는다.

원 논문과 입력 차이 및 영역 평가 절차는
[방법 비교](METHOD_COMPARISON_ko_v1.md)에 기록한다.
