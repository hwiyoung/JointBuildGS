## 다른 모든 조건을 통과했는데 단독으로 막는 조건

저장된 비용과 판정을 그대로 두고 한 조건만 제외하는 계산이다. 새 마스크를
채택하거나 새 관측을 계산한 것이 아니다. 여기서 추가 통과하는 픽셀이
정확한 소스 선택이라는 뜻도 아니다.

P1의 완전한 곡선과 다수 지지가 남은 5,893개는 모두 깊이 간격 조건을 실패했다.
그중 1,252개는 저장된 다른 조건은 모두 통과한다. 나머지는 여러 조건이 중복
실패하므로 단일 조건을 제외해도 선택되지 않는다.

실제 P2 `view_001`, 원픽셀 `(1032,45)`은 Prior 56.8277m, MVS 60.8648m이며
최적 깊이 60.9202m, 최소 비용 0.0450, MVS 지지 2개·Prior 지지 0개다.
다른 저장 조건은 통과하지만 최저점 주변 깊이 간격 0.2729m 때문에 유보됐다.
낮은 비용 구간 폭 0은 현재 이산 격자의 한 점만 남았다는 뜻이며 불확실성 0이 아니다.

## 해석과 후속 진단

현재 조건은 보정된 관측 오차나 검증된 검출 임계값이 아닌 개발 설정이다.
0.25m 이하 깊이 간격은 관측 신뢰도보다 계산 해상도의 조건이다. 예를 들어
Prior 100m, MVS 110m이면 현재 검색 범위는 95–115m이고 33개 inverse-depth
표본의 최소 간격조차 약 0.519m다. 대응 비용과 관계없이 간격 조건을 통과할 수 없다.

따라서 우선 깊이 탐색 샘플 수를 범위에 맞추거나 유망 구간을 정밀 탐색해
현재 간격 조건을 실제로 평가할 수 있어야 한다. 이후에도 폭·다중 구간·깊이
불일치가 남는지 다시 측정해야 한다. 간격 조건을 지웠을 때의 추가 통과 수는
그 정밀 탐색 결과를 예측하지 않는다.

완전 지지 조건은 관측 실패 이유를 나눠 보존한 뒤, 경계나 일부 잘못된 탐색
가설 때문에 유효한 중심까지 탈락하는지 진단해야 한다. 소스 판정의 폭을 넓힌
결과는 과선택·누락과 독립 기하 적합도로 별도 검증해야 한다.
