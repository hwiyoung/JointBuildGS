# 비정형 변화·소스판정 마스크: 방법 비교와 품질 검증 범위

- 작성일: 2026-09-15
- 상태: `DEVELOPMENT_METHOD_COMPARISON / MASK_QUALITY_NOT_ESTABLISHED`
- 범위: P1/P2/P3 현재 영상에서 수정 후보 및 소스판정 영역을 추출하고 검토하는 기술 진단
- `scientific_verdict: null`

## 1. 이번 작업의 중심 질문

사용자가 확인하려는 것은 영상 내에서 수정이 필요한 **비정형 영역의 위치·범위·경계**를 잘 선택하는지, 그리고 그 영역의 소스를 선택해 GS에 적용했을 때 형상·영상 적합도가 좋아지면서 주변 구조를 보존하는지다. 일부 통과 표본 주변에 고정 사각형을 놓는 국소 교체 시험만으로 첫 번째 질문에 답할 수 없다.

대응 비용을 계산하는 주변 패치와 수정 범위를 나타내는 마스크를 구분한다. 비용 계산에 패치를 사용하더라도 결과는 중심 픽셀의 근거다. 중심의 판정을 주변 모든 픽셀에 복사하지 않고, 실제 평가된 각 픽셀의 판정으로 비정형 마스크를 구성한다. 영상 해상도의 배열이 있다는 사실만으로 모든 픽셀에 관측 근거가 계산되었다고 보지 않는다.

## 2. 원 논문에서 실제로 하는 일

| 방법 | 영역을 만드는 과정 | 이 비교에서 구분할 점 |
|---|---|---|
| CL-Splats | 과거 GS를 현재 카메라로 RGB 렌더링한다. 현재 RGB와 DINOv2 특징의 코사인 유사도를 비교해 영상 전체의 변화 마스크를 만들고 확장한다. Gaussian을 여러 마스크에 투영해 투표하고, 변경 3D 영역에 국소 최적화를 적용한다. | 특징은 패치 단위지만 산출물은 영상 전체 마스크다. 최적화 중 변경 Gaussian의 재투영으로 계산 대상 타일을 갱신하는 것과 DINO 변화판정을 다시 수행하는 것은 다르다. |
| GaussianUpdate | 과거 렌더링과 현재 영상의 SAM 인스턴스를 IoU로 비교해 형상이 유지된 영역을 얻고, 먼저 전역 외관을 맞춘다. 이어 기존 Gaussian의 제거 계수를 학습하고 DBSCAN으로 제거 후보를 정리하며, 새 점을 추가한다. | SAM 마스크는 전역 외관 학습을 위한 정적 영역 근거다. 최종 기하 변화 판정 전체를 SAM이 직접 결정하는 방식으로 설명하지 않는다. |

근거: [CL-Splats 논문 §3](https://arxiv.org/html/2506.21117v1#S3), [GaussianUpdate 논문 §3.2](https://arxiv.org/html/2508.08867v1#S3.SS2).

CL-Splats는 합성 데이터의 세 복잡도 수준에서 수동 주석 마스크와 비교해 다음 결과를 보고했다. 이 수치는 해당 논문의 합성 장면에 한정되며 P1/P2/P3 성능으로 전용하지 않는다.

| CL-Splats Table 4의 비교 | Recall | Precision |
|---|---:|---:|
| Color L2 | 0.761 | 0.281 |
| SSIM | 0.745 | 0.332 |
| 초기 DINO 2D 마스크 | 0.961 | 0.370 |
| 팽창 생략 | 0.941 | 0.611 |
| 국소 최적화 후 변경 3D 영역을 재투영한 최종 마스크 | 0.942 | 0.609 |

초기 후보의 누락과 이후 3D 처리의 과선택 감소를 각각 검사한 사례다. 최종 계산 마스크에는 타일 단위 표현 때문에 경계 확장이 남는다. 정밀한 픽셀 경계를 보증하는 수치로 해석하지 않는다. [CL-Splats 논문 §4.2, Table 4](https://arxiv.org/html/2506.21117v1#S4.SS2).

2026-09-15 확인한 CL-Splats 공식 공개 저장소는 논문 구현과 차이가 있을 수 있는 재구현이라고 명시한다. 현재 공개 검출 코드는 `dinov2_vitb14`와 선택적인 마스크 확장·업샘플링을 사용한다. 논문 설명과 현재 코드를 같은 구현으로 간주하지 않고 버전과 설정을 각각 기록한다. [공식 저장소](https://github.com/jan-ackermann/cl-splats), [공개 DINO 검출 코드](https://github.com/jan-ackermann/cl-splats/blob/main/clsplats/change_detection/dinov2_detector.py).

## 3. ALS Prior·현재 MVS에 맞춘 적용 범위

두 논문의 시점 간 RGB 비교에는 과거 영상을 재현하는 GS가 필요하다. 이번 입력의 ALS Prior 깊이는 그 과거 RGB 렌더링에 해당하지 않는다. 현재 영상으로 ALS에 색을 입혀 만든 영상을 독립적인 과거 영상처럼 비교하면 시간 변화 증거가 되지 않는다.

따라서 이번 진단은 두 논문의 정확 재현이 아니라 다음 관측 기반 적용으로 정의한다.

1. 현재 영상 좌표에서 Prior–MVS 깊이 불일치와 각 소스의 유효 영역을 계산한다.
2. 동일 픽셀의 Prior 표면 가설과 MVS 표면 가설을 각각 3D에 놓는다. 유효한 이웃 관측을 이용해 깊이 호환성·가림 관련 상태·시차·영상 대응·대응 모호성을 조사한다.
3. 근거가 계산된 픽셀마다 두 가설의 지지·반대·정보 부족을 남긴다. 비용을 구할 수 없는 픽셀, 검색 범위 밖, 경계 또는 무효 깊이는 평가 실패 이유와 함께 보존한다.
4. 픽셀별 판정으로 비정형 영역을 만들고, 원본 영상 및 3D 표면 가설에 연결한다. 연결성이나 경계 정리는 원 관측 판정과 별도 레이어로 남긴다.

`native-pixel`은 유효한 원 영상 픽셀에서 실제 계산했다는 의미다. 축소 처리나 희소 평가를 사용한 경우 계산 해상도와 미평가 영역을 명시하고, 업샘플링된 색상만으로 원 픽셀 근거가 생긴 것으로 처리하지 않는다. 큰 영상을 타일로 나눠 계산하더라도 수정 마스크의 경계가 타일 경계로 결정되어서는 안 된다.

SAM·DINO는 영역 묶기나 별도 비교군으로 검토할 수 있다. 단일 현재 영상의 의미적 경계는 어느 소스가 현재 형상에 더 정확한지의 근거를 대신하지 않는다. 현재 영상 간 특징 대응을 이용하는 경우에도 과거 렌더링과 현재 영상의 특징 차이를 쓰는 원 논문 설정과 구분한다.

## 4. 표시할 판정과 유보의 의미

최소 표시 레이어는 원 영상, 유효 깊이 범위, 불일치 후보, 소스별 관측 지지·반대, 모호성·관측 부족, 최종 비정형 판정 마스크다. `IMAGE / PRIOR / FUSION / ABSTAIN`의 소스 결정과 `KEEP / CORRECT / SPAWN / PRUNE / NO-UPDATE`의 Gaussian 동작은 별도 필드로 둔다.

기술 진단에서 영상 가설 지지, Prior 가설 지지, 깊이 양립 가능, 판단 유보를 표시할 수 있지만 이를 보정된 예상 기하오차나 검증된 소스 정확도로 부르지 않는다. 양립 가능은 융합 우위의 증명이 아니며, MVS가 채택되지 않았다는 이유만으로 Prior가 옳거나 현재라고 판정하지 않는다. 유보를 변화 없음에 합치지 않는다.

Prior–MVS 불일치는 실제 시간 변화 외에 Prior의 기존 오류, MVS 오류, 정합·깊이 정의·가시성 차이에서도 발생할 수 있다. 시간 변화가 독립적으로 확인되지 않은 영역은 수정 후보 또는 소스판정 후보로 표현한다. 현재 영상에서 만든 MVS와 같은 영상의 재투영 일치는 독립된 두 측정의 합의가 아니라 공유 입력에 대한 일관성 검사다.

## 5. 마스크 품질 확인 절차

| 확인 대상 | 기록할 결과 | 결론의 경계 |
|---|---|---|
| 전체 영상의 선택·비선택·유보 | P1/P2/P3 동일 시점·동일 확대율의 전체 마스크, 계산 영역과 무효 영역, 각 범주의 픽셀 수·면적 | 선택 사례만 확대해서 보는 편향을 피한다. 유보율·계산 범위를 정확도와 구분한다. |
| 선택된 영역 | 근거가 없는 과선택, 지붕 경계·가림·그림자·정합 잔차와의 관계, 지지와 반대 관측 | 규칙 통과는 정답 판정이 아니다. |
| 비선택·유보 영역 | 수정이 필요해 보이지만 누락된 곳, 소스별 결측, 대응 불능 이유 | 무효·미평가 픽셀을 참음성으로 세지 않는다. |
| 영역 경계 | 잘린 부분·넘친 부분·구멍, 3D 연결 후 다른 면으로 번지는 부분 | 고정 패치나 보간의 경계를 실제 변화 경계로 해석하지 않는다. |
| 독립 평가 주석이 있는 범위 | TP/FP/FN/TN, precision·recall·IoU, 사전에 정한 허용 폭의 경계 오차, 평가 가능 면적과 유보율 | 주석의 시기·근거·불확실성을 기록한다. 마스크를 보고 같은 경계를 따라 그린 주석은 독립 평가가 아니다. |
| 소스 결정의 기하 적합성 | 같은 위치·참조 ID에서 Prior와 MVS 각각의 현재 형상 오차, 선택·비선택·유보별 결과 | 현재 UAS 등 참조는 평가 전용으로 사용한다. 이 결과를 판정 입력·임계값 선택에 다시 넣지 않는다. |

우선 전체 영상과 고정된 검토 사례를 눈으로 비교하면 오검출·누락의 원인을 찾을 수 있다. 이는 시각적 개발 검토다. 독립 주석 없이 precision·recall 또는 “잘 추출한다”는 정확도 주장을 만들지 않는다. 결과를 보며 수정한 설정은 개발 버전으로 구분하고, 별도 평가 범위가 확보되기 전까지 일반화 성능을 주장하지 않는다.

동일 입력·동일 평가 범위에서 깊이 불일치만 사용한 후보와, 가시성 관련 검사·다중 시점·모호성 검사를 추가한 마스크를 단계별로 비교한다. 검사를 추가할 때 줄어든 과선택뿐 아니라 증가한 누락과 유보도 함께 기록한다. 영역 정확도 평가는 학습 loss 감소 또는 GS 영상 품질 개선으로 대체하지 않는다.

## 6. 고정 마스크 검증과 반복 갱신의 구분

먼저 한 번 계산한 비정형 마스크를 고정하고 영역 품질을 검토한다. 그 다음 동일한 최적화 조건에서 해당 마스크를 사용했을 때의 수정 전후 형상·영상 적합도·주변 구조 손상을 비교한다. 이 순서는 마스크 판정과 Gaussian 반응을 나눠 확인하기 위한 개발 실험이며 새로운 최적화 기여나 검증된 우위를 뜻하지 않는다.

학습 중 영역 판정을 다시 계산하는 실험은 별도다. 같은 초기 마스크·관측·연산 예산에서 갱신 주기, 판정 안정성, 새로 선택되거나 해제된 면적, 오판정의 자기강화 여부를 비교해야 한다. Gaussian이 움직여 재투영 마스크가 달라지는 것만으로 소스판정이 재추정되었다고 보고하지 않는다.

이 문서는 방법 비교와 검증 범위를 기록한다. 구현 완료, GPU 학습 완료, 독립 주석 확보 또는 과학적 성능 입증의 영수증이 아니다.
