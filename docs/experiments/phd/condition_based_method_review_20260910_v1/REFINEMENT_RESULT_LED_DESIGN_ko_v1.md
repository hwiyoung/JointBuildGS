# GeoGS 결과에서 출발하는 수정·보존 refinement 설계

- 작성일: 2026-09-10

- 상태: `EXISTING_EVIDENCE_REVIEW / CONDITIONAL_DESIGN_HYPOTHESES`
- scientific_verdict: null
- 범위: 기존 문서·그림·공식 구현·원문 확인과 이 별도 문서 작성. 새 학습·추론·렌더·재구성·방법 실험 없음.

## 1. 설계 출발점의 정정

**Normal loss를 먼저 추가해야 한다는 근거는 확보되지 않았다.** [앞선 감독·loss 분석](SUPERVISION_AND_LOSS_DESIGN_BASIS_ko_v1.md)의 §5.4 normal 중심 비교안은 채택한 실행 순서에서 제외하고, 방향 감독의 추가 필요성이 드러났을 때의 조건부 예시로 해석한다. 기존 파일과 실험 계보는 보존한다. 감독 신호와 loss를 중심으로 설계 의도를 분석한다는 틀은 유지한다.

출발점은 **GeoGS refinement가 이미 달성한 수정·보존을 확인하고, 남는 중요한 부족에 대해 어떤 감독과 loss 관계를 변경해야 하는지 찾는 것**이다. 모든 원인을 완전히 입증한 뒤에만 설계를 시작하는 순서도 아니다. 관찰로 설계 가설을 세우고 관련 선행 해결책 및 최소 비교로 그 가설을 좁힌다.

GeoGS는 기존 구조를 확보하고 DA3 depth를 통해 현재 영상의 기하 정보를 추가한다. Refinement에도 prior depth loss와 구조 보호가 남는다. 따라서 이번 확장은 수정·보존 기능의 최초 도입이라는 주장이 아니라, **국소적으로 타당성이 다른 기존 기하와 영상 파생 감독의 요구를 현재 관측에 맞게 유지·완화·보정하는 원리가 필요한지**에 대한 질문이다. 오류 분류기나 단일 소스 선택은 필수로 두지 않는다.

## 2. 이미 있는 결과가 요구하는 설계 질문

아래는 기존 [원인 검토](../geogs_causal_followup_v1/CAUSAL_REVIEW_ko_v1.md)와 [저장 깊이 감사](../geogs_causal_followup_v1/DA3_INPUT_AUDIT_ko_v1.md)를 재검토한 내용이다. 이번에 수치를 새로 계산하지 않았다. 해당 연구의 ALS 적용판 개발 결과이며 공식 LoD2 조건의 일반 성능으로 확대하지 않는다.

| 기존 결과: 성공과 잔여 | 우리 목표에서의 중요성 | 감독 신호·loss로 연결할 질문 |
|---|---|---|
| **P1:** prior depth 가중 `.005→.0005`에서 높은 기존 형상이 현재 바닥 쪽으로 수정되지만 잔여가 남음. 보이는 바닥의 한 시선에서는 DA3 target도 현재 참조보다 얕음 | 틀린 구조의 수정이 시작되어도 정확한 현재 기하에 도달하지 못할 수 있음 | 기존 prior 요구를 더 완화하면 충분한가? DA3의 부정확한 목표값을 더 강하게 따르는 대신, 현재 영상의 다른 기하 근거로 감독을 보정하거나 보완할 필요가 있는가? |
| **P2 큰 변화부:** 낮은 prior 가중에서 높은 기존 면이 현재 낮은 면으로 크게 수정되고 잔존 상부 면이 줄어듦 | GeoGS의 수정 성공을 인정해야 함. 새 보존 제어가 이 수정을 되돌리면 목표에 어긋남 | 유효한 수정 근거는 유지하면서 다른 곳의 감독 오류를 제한할 수 있는가? Prior에 가까운 상태로 돌아가는 것과 유효 구조 보존을 어떻게 구별할 것인가? |
| **P2 골:** prior에 현재 골에 가까운 국소 표본이 있지만 anchor부터 표현이 불완전함. 낮은 prior 가중 결과는 불필요한 하부 조각을 줄이지만 골이 충분히 깊지 않음. 저장 expected depth에서도 anchor 대비 얕아짐이 있음 | 유효한 기존 세부 정보의 활용과 잘못된 표면 제거를 같은 영역에서 평가해야 함 | Refinement가 유지해야 할 것은 anchor 전체인가, 원 prior의 유효한 기하 정보인가? DA3와 prior가 요구하는 표면이 다를 때 어느 요구를 얼마나 적용하며, 원 prior의 유효 정보가 학습 표면에 도달하는가? |
| **P3:** 큰 곡면 지붕 유지와 prior mesh에 부족한 측벽 보완이 있음. 낮은 prior 가중이 전반적으로 악화한다는 가설은 지지되지 않음 | 구조 보존과 결손 보완이 이미 가능한 성공 조건을 새 설계가 유지해야 함 | P1/P2 잔여만 줄이는 규칙이 P3의 유효 구조·측벽·외관을 손상하지 않는가? |

핵심 근거는 두 가지다.

1. **같은 DA3에도 prior loss의 요구가 결과를 바꾼다.** P1/P2 native `.005/.0005` 쌍은 같은 입력 SHA, 기록된 DA3 가중 `.05`, 같은 보호 Gaussian 수를 가진다. 이 대비는 prior 깊이 가중의 영향을 뒷받침한다. DA3의 동적 가중 감쇠가 이 차이를 만들었다고 설명할 수 없다. 보호의 국소 영향이나 다른 손실의 기여까지 단독 분리한 것은 아니다.
2. **맞출 depth 자체도 점검해야 한다.** P1 train0100의 한 가시 바닥 픽셀에서 camera-Z는 현재 참조 74.671m, prior 69.974m, DA3 72.093m, final `.005` 70.453m, final `.0005` 72.927m다. DA3는 수정 방향을 제공하지만 정확한 깊이까지 제공하지 못하고, 최종 결과는 DA3보다도 깊어진다. 그러므로 DA3 단독 복사 실패나 prior 단독 문제로 단순화하지 않는다.

P2 골은 세 선정 시선에서 DA3와 최종 expected depth가 anchor보다 얕다. 이 변화는 TSDF 이전에도 존재한다. 그러나 골 바닥의 first-hit visibility, 반 픽셀 ray 차이, 다중 Gaussian의 expected-depth 혼합이 미분리다. **DA3가 정확한 anchor 골을 처음 파괴했다고 확정하지 않는다.** 원 prior의 정보가 anchor에서 불완전하게 전달된 문제와 refinement 중 추가 변화는 구별한다.

네 입력 조건인 기존 기하 O/X × 영상 O/X는 유지한다. 위 지역 전체를 단일 조건으로 지정하지 않으며, 영상에서 골의 명암이 보인다는 사실만으로 골 바닥의 metric geometry까지 관측 가능하다고 판정하지 않는다.

## 3. 이 질문에 관련된 선행 설계의 연결

각 방법은 복합 문제를 다루므로 하나의 원인에 대응하는 단일 모듈로 환원하지 않는다. 아래의 이식 가능성은 우리 추론이고, 독립 기존 기하를 쓰는 GeoGS에서 확인된 효과가 아니다.

| 선행 설계와 도입 이유 | 실제 감독·목적함수의 연결 및 이미 해결한 부분 | 우리 refinement에 가져올 질문과 남는 적용 범위 |
|---|---|---|
| **ACMP:** 영상 대응이 약한 곳의 깊이 결손을 평면 prior로 보완하되, 평면 가정이 경계·비평면 구조를 잘못 강제하는 문제도 처리 | 신뢰 가능한 영상 대응에서 평면 prior를 만들고, 다중뷰 photometric cost와 평면 호환성을 결합해 깊이 가설을 평가. 이후 다중뷰 재투영 일관성으로 추가 오류를 줄임. 따라서 prior 보완과 영상에 의한 수정이 이미 함께 설계됨 | P1에는 DA3 값 외의 현재 영상 대응 근거가 있는지, P2에는 유효 prior가 뒷받침하는 깊이 요구를 어떤 비용으로 남길지 검토. 원 prior는 영상에서 만든 평면이며 독립 ALS/LoD가 아님. 비평면 골에 평면 제약을 그대로 적용하는 계획은 아님 |
| **NeuRIS:** 유효한 예측 normal은 무텍스처 구조에 유용하지만 부정확한 normal은 얇은 구조·세부를 억제할 수 있음 | 현재 재구성에서 다중뷰 patch NCC를 계산하고, 이전 기각 상태·normal 불일치와 함께 normal 감독 사용을 조절. 실제 NCC 경로는 직접 최적화하는 loss가 아닌 감독 선택 근거. 적응적 검사로 개선한 ablation을 완성법의 실패로 세지 않음 | P1/P2의 prior·DA3 요구를 현재 영상 일관성으로 점검하는 원리의 후보. 현재 모델이 틀려도 NCC가 나쁠 수 있으므로 불일치만으로 입력 감독을 기각하면 안 됨. Depth에 적용할 판단 규칙은 별도 설계이며 normal 추가를 뜻하지 않음 |
| **ND-SDF:** 편향된 예측 normal을 그대로 강제하면 세부가 억제되지만 보정 자유도만 늘리면 유효한 평면 제약도 약해질 수 있음 | 기하 normal을 학습한 회전으로 변형해 고정 prior와 비교하며, 원 normal 손실도 적응적으로 남김. 편차를 depth 감독·표집·광도·부분 렌더링 보정에도 연결. 자유 보정의 평면 문제는 후속 adaptive prior로 개선한 ablation | P1처럼 target 자체가 부족하면 단순 약화 외에 제약된 편향 보정이 필요한지 검토. 이 논문은 DA3 metric depth 보정식을 제공하지 않으며, normal 편차로 독립 ALS depth의 타당성을 판단할 근거도 제공하지 않음 |

원문과 공식 구현 확인:

- ACMP: [원문 §Planar Prior Assistance·Geometric Consistency, 식7·13](https://cdn.aaai.org/ojs/6940/6940-13-10169-1-10-20200525.pdf), [공식 ACMP.cu 고정 버전](https://github.com/GhiXu/ACMP/blob/574c8e078b6f7bd93237bd180d46f5adf1169a19/ACMP.cu#L559). `PlaneHypothesisRefinement`에서 영상 비용과 prior 호환 확률을 결합하고, geometric-consistency 분기에서 재투영 비용을 포함하는 경로를 확인했다. PatchMatch의 가설 선택 목적함수이며 GS에 이미 존재하는 학습 loss라고 부르지 않는다.
- NeuRIS: [원문 §3.2·Table3](https://arxiv.org/html/2206.13597v2), [공식 exp_runner.py](https://github.com/jiepengwang/NeuRIS/blob/fab2cc4ca45847fbee7490e978d3c60c582123b1/exp_runner.py#L329). `no_grad` NCC, 현재·이전 confidence, normal 각도 조건을 확인했다.
- ND-SDF: [원문 §3·Table6](https://arxiv.org/html/2408.12598v3), [공식 loss.py](https://github.com/zju3dv/ND-SDF/blob/f58f29466a5f43e80dedb0cd155f57dae7569347/models/loss.py#L302). 원 normal 및 변형 normal 각각의 L1·cosine 손실과 편차 기반 반영을 확인했다.

ACMP는 현재 영상의 직접 대응과 구조 prior를 목적함수에 함께 넣는 방법군을 보충한다. NeuRIS와 ND-SDF는 각각 감독 사용과 편향 처리의 기존 설계 후보다. 이 세 편이 검토 범위의 경계는 아니다. 이미 검토한 AGS-Mesh·DebSDF·기존 장면 갱신법도 해당 잔여와의 연결이 명확한 경우 함께 비교한다.

## 4. 현재 근거에서 도출되는 방법 설계의 형태

**설계 가설:** 기존 기하와 DA3를 모두 오차가 있을 수 있는 기하 감독으로 다루고, 현재 영상의 관측 근거에 따라 각 감독을 유지·완화·보정하면, 일괄 prior 약화보다 필요한 수정과 유효 구조 보존을 함께 달성할 수 있다. 아직 검증된 신규 방법이나 채택한 모듈 구성은 아니다.

이 가설을 구체화할 때는 다음 연결을 명시한다.

- **감독 신호:** 기존 prior depth, DA3 depth, 현재 RGB와 카메라에서 얻는 다중시점 대응·가시성 근거. 추가 normal은 이 정보에 없는 유효한 방향 제약을 제공할 이유가 있을 때 후보가 된다. DA3 confidence는 예측 신뢰의 후보이며 prior의 현재 타당성을 대신하지 않는다.
- **Loss 요구:** prior와의 근접성을 유지하는 요구, 현재 관측을 만족하도록 수정하는 요구, 부정확한 DA3 target을 처리하는 요구를 구별한다. 같은 영역에 여러 요구가 함께 작동할 수 있고 하나의 소스를 반드시 배타적으로 선택하지 않는다.
- **보정의 제약:** target 보정을 허용한다면 보정량의 자유도·공간 범위와 영상의 독립 관측 관계를 함께 제한해야 한다. 보정 변수가 현재 모델의 모든 오류를 흡수하거나, 관측이 없는 곳에서 원하는 깊이를 만들어내는 방식이면 가설을 충족하지 못한다. 구체적인 보정식의 신규성은 아직 미정이다.
- **구조 보호와의 연결:** prior depth 가중을 줄이는 것과 Gaussian의 수정·생성·삭제 제한을 푸는 것은 별도 제어다. 감독 변경만으로 충분한지 먼저 구별하고, 보호가 필요한 수정을 막거나 유효 표면 보존을 보장하지 못하는 경우 관련 제약을 따로 비교한다. Anchor가 이미 불완전한 곳에서는 anchor 전부 고정이 원 prior의 유효 정보 보존을 뜻하지 않는다.

GeoGS 자체의 근거는 [공식 train.py](https://github.com/zqlin0521/GeoGS/blob/db40c95c657ec03ff21c83cb99cf39f4e90247a6/train.py), [보호·loss 감사](../geogs_causal_followup_v1/MASK_DESIGN_AUDIT_ko_v1.md), [실제 제어 기록](../geogs_p1p2p3_v1/CONTROL_TRAJECTORIES_ko_v1.md)에 있다. 논문 valid mask, 공식 선택적 DA3 confidence, 실제 실행 여부와 global adaptive weight를 구별한다.

## 5. 결과와 설계 질문에 대응하는 최소 비교안

기존 P1/P2/P3의 18개 주조건은 이미 수행한 prior 깊이 가중 × 구조 보호 비교로 사용한다. 이를 다시 수행해야 분석이 가능하다는 조건을 두지 않는다. 아래는 앞으로의 설계안이며 이번에 실행하지 않는다.

| 질문 | 최소 비교 | 기각·축소 조건 |
|---|---|---|
| **감독의 국소 반영이 필요한가?** | 같은 prior·DA3 target에서 기존 제어 / 사용 가능한 기존 confidence·영상 일관성 기반 반영을 비교. 같은 신호를 공급할 때는 반영식만 변경 | 기존 전역 제어로 충분하거나, 국소 제어가 유효한 수정 근거까지 제거하면 해당 추가 원리의 필요성 축소 |
| **Target의 보정·보완이 필요한가?** | 동일 영상·prior·카메라·추가 신호를 모든 비교에 제공하고 가중 조절 / 적합한 기존 보정 또는 직접 영상 관계 도입 / 구체화된 제안 규칙을 비교 | 단순 기존 도입과 차이가 없거나 보정이 기하 오류를 흡수하면 새 보정 원리 주장 축소. 추가 정보·연산만의 이득과 규칙의 이득을 구분 |
| **구조 보호 변경까지 필요한가?** | 선택한 감독 설계를 고정하고 기존 보호 / 기존 해제 / 필요성이 구체화된 제한 변경을 비교. Prior 깊이 가중은 고정 | 감독 변경만으로 충분하거나 보호 변경이 P2의 달성된 수정·P3의 유효 구조를 악화하면 확장 범위 축소 |

비교의 초기 구조·정합·표현·추출·계산 예산을 맞춘다. 동일 정보 비교와 새 정보 추가 비교를 혼합하지 않는다. 영상 일관성 계산 비용도 포함한다. 제안식이 미정인 항은 실행 가능한 확정 실험 계약으로 취급하지 않는다.

평가는 **P1의 잔여 수정, P2의 수정 성공과 유효 골 정보, P3의 구조·측벽 성공을 함께 포함**한다. 필요한 보정과 유효 구조 손상을 같은 영역에서 따로 집계하고 정확도·완전성·현재성·관측 가능한 세부·외관·계산량을 분리한다. P2의 낮은 prior 가중 결과가 정성적으로 좋아졌다는 관찰을 평균 F1만으로 부정하지 않는다. GT는 평가 전용이며 감독·보정·가중·보호 결정에 전달하지 않는다.

수정과 보존을 함께 평가하는 것, normal이나 confidence를 추가하는 것, 기존 항을 조합하는 것 자체로 방법 신규성을 주장하지 않는다. 학위 기여 후보는 **남은 중요한 부족에 대해 기존 해법보다 설명력과 효과가 있는 추정·제약 원리를 제시하는 경우**다. 이번 기록은 그 원리를 고르기 위한 결과 기반 설계 방향을 확정하며 과학적 판정은 남긴다.
