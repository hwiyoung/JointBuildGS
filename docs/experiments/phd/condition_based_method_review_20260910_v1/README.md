## 2. 먼저 분리할 입력·관측 축

| 축 | 구분할 상태 | 중요한 이유 |
|---|---|---|
| 기존 기하의 정확도 | 위치·법선·연결관계가 정확 / 일부 편향·이상치 / 잘못된 구조 | 점밀도·매끄러움·센서 이름은 정확도 자체가 아님 |
| 기존 기하의 표현과 피복 | 상세 point cloud, 삼각 mesh, 단순 LoD, 2.5D DSM; 결손·경계·중복 | 단순화된 표면, 실제로 없는 표면, 측정하지 않은 곳을 구분해야 함 |
| 현재 영상의 기하 식별력 | 여러 독립 방향에서 관측 / 작은 시차·무텍스처·가림 / 완전 미관측 | 사진에 보인다는 것과 metric geometry를 결정할 수 있다는 것은 다름 |
| 영상 파생 감독의 타당성 | 대체로 정확 / 경계 누락·과평활·scale/normal bias / confidence 오순위 | 원 영상의 정보와 predictor가 제공한 정보는 다를 수 있음 |
| 관측 간 독립성 | 서로 다른 기선·각도 / 거의 같은 시선 / 같은 predictor의 상관 오류 | 많은 시선의 동의가 독립적인 정확성 증거인지 따져야 함 |
| 정합·가시성 | 공통 frame·pose 안정 / 전역 오정합 / 국소 pose·가림 대응 오류 | 감독 제어 문제와 잘못된 좌표·대응 문제를 구별 |
| 시간·외관 | 동일 형상·다른 노출/반사 / 실제 형상 변화 / 시점 불명 | 시간차는 한 조건이며, 영상 차이가 모두 형상 변화는 아님 |

이 축들을 전수 조합한 대형 실험을 바로 만들지 않는다. 먼저 다음의 현실적인 조건 묶음이 문헌과 실제 자료에 존재하는지 확인한다. K 표기는 이 문서의 탐색용 label이며 기존 E/C 실험 조건을 대체하지 않는다.

| 조건 | 현실적인 예 | 원하는 결과·관측 경계 | 우선순위 |
|---|---|---|---|
| K0: 두 입력이 유효하고 대체로 일치 | 정합된 상세 기하와 충분한 사진 | 정확한 상태를 유지하며 외관 정제; 새 방법의 불필요한 변경 확인 | 필수 성공 대조 |
| K1: prior 유효·영상 기하 약함 | 정확한 지붕/벽과 작은 시차·무텍스처 | 관측 부족으로 기존 정확한 기하가 훼손되지 않아야 함. 미관측부의 현재성은 별도 미확인 | 높음 |
| K2: prior 부정확·현재 관측 충분 | 높이가 틀린 지붕, 철거/증축, 잘못 연결된 면 | 관측에 근거해 오류를 수정; 과거 형상을 유지했다고 성공 처리하지 않음 | 높음 |
| K3: 같은 국소 영역에 유효 구조와 필요한 보정이 섞임 | 맞는 능선 옆 틀린 지붕면; 정확한 얇은 구조와 편향된 영상 depth | 같은 영역에서 오류 감소와 정확한 부분 손상을 동시에 측정. 역할은 위치·자유도에 따라 달라짐 | 중심 후보 |
| K4: prior 결손·단순화, 원 영상에 세부가 있음 | DSM의 수직면 미표현, LoD의 돌출부 생략 | 지지되는 결손·세부를 복원. 감독 보정과 primitive 생성/추출 병목을 구별 | 높음 |
| K5: 감독이 함께 틀리거나 정보 자체가 부족 | prior와 단안 depth가 같은 돌출부를 생략; 양쪽 모두 미관측 | 원 RGB에 구별 증거가 있으면 활용 문제, 없으면 식별 한계. 보완 불가능한 정확 복원을 요구하지 않음 | 필수 한계 대조 |
| K6: 외관·정합이 기하 충돌처럼 보임 | 반사 지붕, 노출 차이, pose 편향, 가림 경계 | 외관/pose 원인을 보정할 기존 해법과 비교. 임의 기하 변형으로 RGB만 맞추지 않는지 평가 | 필수 교란 대조 |

**현재 가장 가치 있는 출발점은 K1·K2를 함께 포함하는 K3와 관측 가능한 K4다.** 이는 문헌과 목표에 근거한 설계 우선순위다. 실제 우리 자료에서 기존 방법이 실패했다는 판정은 아니다. K0·K5·K6가 없으면 제안의 이득·한계·오진을 구별하기 어렵다.

## 3. 조건에서 선별한 방법군

| 방법군 | 연결 조건 | 선별 문헌 | 비교에서 맡을 역할 |
|---|---|---|---|
| 기존 형상으로 시작하는 영상 기반 정제 | K0–K4 | GeoGS, photometric multiview mesh refinement | 목적·입출력이 가까운 직접 경쟁 후보. 카메라 모델·초기 topology·prior adapter 차이를 확인 |
| 평면·의미·구조 제약을 활용한 복원 | K1, K3, K4 | ACMP, Semantically Informed Multiview Surface Refinement, EnerGS | GS가 꼭 필요한지, 기존 구조 제약만으로 충분한지 비교 |
| 이종 기하 활용·국소 융합 | K1–K5 | SRDM, SenFuNet; RoutedFusion 확장 후보 | prior validity feedback 및 이종 오류 모델 비교. 추가 센서·학습 GT 요구가 다르면 직접 경쟁에서 제외 |
| 적응적 깊이·법선 감독 | K2–K4, K6 | AGS-Mesh, NeuRIS | 동일 기반에 도입할 간단하고 가까운 감독 제어 |
| uncertainty·감독 편향 보정 | K3–K6 | DebSDF, ND-SDF, NC-SDF, GPU-SDF, GURecon | 제거/가중만의 문제가 맞는지, 감독 자체 보정이 필요한지 비교 |
| 외관–형상 변수 전달·생성 제어 | K3, K4, K6 | CoMe, EnerGS; GaussianUpdate 확장 후보 | 새 제어 없이 외관 보정·변수 분리·생성 제어만으로 해결 가능한지 비교 |
| pose·정합과 기하의 상호 갱신 | K6 | SPARF; 위 mesh/SRDM의 실제 feedback | 정합을 감독 신뢰 문제로 오진하지 않기 위한 원인 대조 |

직접 경쟁 여부는 논문 제목이 아니라 **허용 입력으로 동일 과제를 수행할 수 있는가**로 판단한다. RGB-D 센서, semantic label, GT 지도학습, 추가 시선, 과거 색 있는 GS 등을 더 요구하면, 해당 원방법과의 비교는 별도 정보 조건을 갖는 참고 비교다. 필요한 핵심 원리만 같은 기반으로 옮긴 실험은 adaptation이며 충실 재현으로 부르지 않는다.

SenFuNet처럼 GT 지도학습을 요구하는 원방법의 신규 학습은 이번 GT 평가전용 설계에 포함하지 않는다. 공개 사전학습 가중치의 도입 가능성도 학습 데이터·추가 정보와 적용 분포를 밝힌 뒤 별도로 판단한다. 목표 장면의 평가 GT를 공급하는 비교로 바꾸지 않는다.

## 4. 가까운 기존 방법의 성공과 남는 질문

표의 '남는 질문'은 다음 상태를 구분한다: **보고 실패**=완성 방법에서 저자가 보인 한계, **해결된 ablation**=제안 요소가 개선한 제거/중간 실험, **미평가**=확인한 문헌에서 우리 질문이 평가되지 않음, **범위 밖**=원래 입출력·목표가 다름. 보고 실패가 우리 자료에서 재현됐다는 뜻은 아니다.

| 방법 | 이미 잘하는 것 | 남는 질문 또는 확인한 경계 | 목표에서의 중요성 |
|---|---|---|---|
| GeoGS | 기존 구조 활용·보호와 영상 정제, prior perturbation·부분 결손까지 검증 | 혼합된 세부 정확도와 감독 bias에서 보존·수정의 동시 성능은 추가 확인 필요. '틀린 prior를 다루지 않음'은 부적절 | 직접 목적 비교의 출발점 |
| AGS-Mesh | 부정확 RGB-D/normal 감독의 filtering과 학습 중 adaptive normal 제어 | 과거 외부 geometry의 정확한 세부와 틀린 구조가 혼재한 경우는 원 입력과 차이. 미평가를 실패로 바꾸지 않음 | 기존 제어의 충분성을 먼저 확인할 후보 |
| NeuRIS | 현재 표면의 다중뷰 사진 일치로 normal 감독을 제어 | 지속 기각이 필요한 감독을 놓칠 수 있다는 것은 조건부 가설. 사진 feedback 자체는 존재 | 현재 RGB로 감독을 검증하는 단순 비교 |
| Photometric mesh refinement | 초기 surface를 영상 일치로 반복 정제, 관측되는 facade도 개선 | 초기 topology·수렴 범위 전제. 저자 실험에 악화되는 초기 모델/자료 조합도 있음 | GS 밖에서 보정 목적이 이미 가능한지 확인 |
| Semantically Informed refinement | 형상과 semantic label 교대 갱신, class별 smoothing·구조 제약 | label 입력·의미 가정 차이. 형상/label 반복 자체가 새 방법은 아님 | 구조 보호·반복 결합의 선행 기준 |
| SRDM / SenFuNet | prior rejection feedback / sensor별 학습형 융합 | SenFuNet은 smooth-but-wrong 선택·평균화 및 겹친 outlier 한계 보고. 임의 prior+RGB로 바로 실행할 방법은 아님 | 국소 confidence가 실패할 구체 조건의 참고 |
| DebSDF / ND-SDF / NC-SDF | uncertainty, 전달 편향 보정, normal deflection/compensation | 무제약 보정의 문제는 일부 이미 해결된 ablation. ND-SDF는 낮은 관측 피복의 local optimum 한계 보고 | '버리기보다 보정'도 기존 경쟁 원리 |
| CoMe | self-supervised confidence·densification·외관 보정으로 surface 개선 | 강한 가림·미관측/원거리 세부 한계 보고. 외부 prior 손상 제어는 미평가 | 가중+수정 범위 연결을 신규성으로 단독 주장할 수 없게 함 |
| EnerGS | 부분 기하의 점유/자유/미지 공간을 이용한 위치 제약과 영상 변수 전달 분리 | fixed trusted field의 틀린 관측을 수정하는 목표와 차이; 기하 지표 간 tradeoff 있음 | 구조 제약 자체가 수정 병목인지 비교 |
| ACMP / GURecon / SPARF | 평면·사진 결합 / 기하 uncertainty / pose–형상 공동 개선 | 각각 외부 prior 갱신, 동일입력 정확도 이득, 외부 frame 정합까지 입증한 것은 아님 | MVS·신뢰도·정합 해법 도입으로 문제가 사라지는지 확인 |

근거와 공식 구현 확인 범위: [GeoGS·AGS·NeuRIS](NEARBY_METHODS_ko_v1.md), [융합·기존 mesh·구조 제약](HETEROGENEOUS_REFINEMENT_ko_v1.md), [감독 편향](SUPERVISION_BIAS_ko_v1.md), [CoMe·GURecon·ACMP·SPARF](OBSERVABILITY_APPEARANCE_AND_MVS_ko_v1.md). 원문 수치들은 데이터·추출·평가 범위가 달라 통합 순위를 만들지 않았다.

## 5. 우선 부족과 경쟁 원인

**우선 질문:** 같은 국소 영역에서 필요한 수정과 관측 가능한 세부 복원을 허용하면서, 이미 정확한 기하를 얼마나 덜 손상시킬 수 있는가. 이 성능의 잔여 부족이 확인되면 아래 원인들을 구별한다.

| 경쟁 가설 | 맞다면 보여야 할 관찰 | 가설을 약화하는 관찰 |
|---|---|---|
| H1: 감독 신뢰 순위/반영이 부적절 | 원 RGB에서 교정을 지지하지만 해당 감독이 낮게 가중되거나, 잘못된 감독이 높게 가중됨 | 기존 confidence·robust loss의 적정 조정만으로 해결 |
| H2: 감독 자체의 계통 편향 | 일관된 깊이 offset/scale 또는 normal 편향이 view를 바꿔도 남고 단순 보정으로 줄어듦 | 감독 보정 없이 pose·가시성만 바로잡아 해결 |
| H3: 수정 제약·변수 전달이 병목 | 감독은 유효하지만 위치/방향 수정이 보호에 막히거나, 결합 변수 때문에 이웃의 정확한 부분도 변형됨 | 같은 제약에서 기존 감독 제어만 바꿔 해결 |
| H4: 표현·생성/삭제·추출의 병목 | 관측 정보와 수정 신호가 있어도 필요한 surface를 만들지 못하거나 native→extracted에서 사라짐 | 생성/추출을 고정해도 새 감독만으로 해결 |
| H5: 정합·가시성·외관 교란 | residual이 pose/가림/노출과 함께 변하며 공통 전처리·외관 보정으로 개선 | 그 조건을 통제해도 같은 기하 부족 유지 |
| H6: 정보 또는 평가 피복 부족 | 서로 다른 기하가 허용 관측을 비슷하게 설명하거나, metric 변화가 참조 피복·결측으로 설명됨 | 독립 기선에 반복되는 기하 증거와 충분한 평가 reference가 있음 |

이 가설들은 배타적이지 않다. 원인을 전부 증명한 뒤에만 방법을 구상하는 순서를 두지 않는다. 질문별 작은 비교로 가설과 설계를 함께 좁힌다. **H6가 맞으면 무리한 정확 복원을 요구하는 범위를 줄이고, H5가 맞으면 먼저 기존 정합·외관 해법을 채택한다.** H1–H4의 상대 중요도는 현재 미정이다.

P1/P2/P3는 개발 관찰이다. P2 저가중 결과가 형상도 정성적으로 좋아졌다는 사용자 관찰을 유지한다. 평균 F1 변화만으로 이를 부정하지 않으며 precision/recall, 같은 표면 대응, reference coverage, 추출 영향을 따로 확인한다. P3 저가중 악화는 미검증이다. GeoGS 논문 valid mask, 공식 optional DA3 confidence, 실제 run 활성화는 별도 근거다.

## 6. 기존 요소 도입과 새 기여 후보의 경계

1. **먼저 충분성을 확인할 기존 요소:** prior 깊이 가중과 구조 보호의 독립 조정, robust loss·공개 confidence, 사진/법선 일치 제어, 단순 depth/normal bias 보정, 기존 외관 보정과 변수별 제약.
2. **조건부 후보 A:** 감독을 단순히 제거하지 않고, 독립 시선에서 반복 지지되는 만큼만 저차원 bias를 보정하는 규칙. ND/NC-SDF와의 차이가 없으면 기존 요소 도입으로 정리한다.
3. **조건부 후보 B:** 현재 모델과의 잔차 크기뿐 아니라, 독립 관측이 지지하는 기하 변화의 방향·범위에 따라 감독 반영과 수정 허용량을 조절하는 규칙. 기존 trust region, geometry uncertainty, CoMe식 생성 제어, EnerGS식 변수 제약과 충분성 비교가 필요하다.

둘을 모두 구현하거나 결합할 필요는 없다. 한 규칙이 원인과 효과를 설명하면 그 규칙이 중심 기여 후보가 될 수 있다. source classifier, 소스별 단일 선택, GS, 마스크, coarse-to-fine, 공동 최적화는 미확정이다. 상세 의미 흐름과 질문별 비교는 [방법·최소 실험계획](METHOD_AND_MINIMUM_TESTS_ko_v1.md)에 정리한다.

## 7. 차별성·박사학위 기여의 현재 평가

| 평가 축 | 현재 판단 | 주장 강화에 필요한 근거 |
|---|---|---|
| 문제 설정 차별성 | 이종 existing geometry와 현재 관측의 타당성이 섞인 조건에서 네 복원 효과를 동시에 다루는 초점은 구체적이다. 기존에도 보존·보정 목적이 있어 자동 신규성은 아님 | 중요한 실제 혼합 조건과 기존 해법의 충분/부족 범위 |
| 원인 설명 | 여러 경쟁 원인을 구별할 질문을 구성했다. P1/P2/P3의 확정 원인은 아님 | 조건 개입 시 예측한 변화와 반복되는 전달 경로 |
| 방법 신규성 | 적응 가중·감독 보정·변수 제약 각각에 가까운 선행이 있다. 새 규칙의 차이는 아직 미확정 | 가장 가까운 기존 규칙과 다른 추정 대상/제약 원리, 공정 비교에서의 효과 |
| 검증 기여 | 같은 영역의 교정·손상·결손·외관 분리 평가는 설계상 가치가 있다 | 재사용 가능한 평가 계약·자료와 한계를 설명하는 결과. 지표 분리 자체는 방법 신규성이 아님 |
| 학위 중심 명제 | 발전 가능한 연구 구상이며 '차별성 없음'이나 '학위 기여 확보'로 단정할 수 없다 | 중요한 잔여 부족→원인 가설→구체 규칙→성공·악화·식별 한계가 연결된 검증 |

현재 제안할 중심 질문은 **“국소적으로 유효성이 다른 기존 기하와 현재 관측을 이용할 때, 어떤 감독 보정 또는 수정 제약이 기존 제어보다 나은 교정–손상 관계를 만드는가?”**다. 복원 목표는 유지하고 방법의 중심 원리는 문헌과 작은 비교로 선택한다.

## 8. 산출물·한계

이 디렉터리에만 새 분석을 작성했다. 기존 수정/미추적 연구 자료를 stage·commit·덮어쓰기하지 않았다. 새 학습·추론·렌더·재구성, 프로젝트 test/tool 실행, 서비스 조작 없음. 문헌 확인은 원문 및 공식 소스 읽기다. 임의 외부 prior·대규모 도시 장면에서 새 후보를 실제 검증하지 않았다. 상세 코드가 공개되지 않거나 미확인인 후보는 각 카드에서 구분했다.

본 검토는 체계적 문헌조사의 완전성 선언이 아니다. 기존 색인에서 인용·후속·인접 방법으로 확장한 첫 조건 중심 비교이며, 특정 선행군 모두의 공통 실패를 요구하거나 주장하지 않는다.

문서 검토: 종합·최소계획의 별도 읽기 교차검토에서 실질 문제는 발견되지 않았다. 6개 신규 문서의 로컬 파일 링크 대상 존재와 null 상태를 확인했다. 이는 문서 정합 확인이며 방법 성능 검증이 아니다.
