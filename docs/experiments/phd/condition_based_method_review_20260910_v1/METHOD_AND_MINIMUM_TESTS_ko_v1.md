## 1. 이번에 구상할 방법의 의미

기존 기하에서 초기 구조를 얻고 현재 관측으로 정제한다. 문제는 모든 부분을 같은 정도로 움직이거나, 현재 형상과 잘 맞는 감독만 무조건 신뢰하는 규칙이 혼합 조건에서도 충분한가다. **가중치, 감독의 목표값, 실제 수정 가능한 기하 변수는 다른 제어**다. 어떤 것이 원인인지는 비교할 가설이며, 반드시 모두 새로 설계해야 하는 것은 아니다.

다음은 한 복원 과정 안에서 선택적으로 도입할 원리다. 별도의 오류 분류기나 소스 선택 모듈을 전제하지 않는다.

| 부분 | 도입할 수 있는 기존 원리 | 새 후보가 주장하려면 달라야 하는 것 |
|---|---|---|
| 초기 구조·사진 정제 | GeoGS 또는 기존 mesh refinement | 초기화 사용 자체는 기여 아님 |
| 감독 반영 | robust loss, 공개 confidence, AGS/NeuRIS식 일치 제어 | 어떤 조건에서 기존 신뢰 근거가 부족하며 새 근거가 무엇을 식별하는지 |
| 감독 bias 보정 | affine depth calibration, NC/ND-SDF형 normal compensation | 더 큰 보정망이 아니라 관측·표현 차이에 맞는 식별 및 제한 원리 |
| 기하 수정 제약 | 기존 보호 강도, trust region, EnerGS식 변수 전달 분리 | 유효 구조와 필요한 수정의 공존에서 제약을 어디에 얼마나 둘지의 근거 |
| 생성/삭제·외관 | 기존 densification, CoMe식 confidence 연결·외관 보정 | 단순 생성 수 증가나 외관 용량 증가로 설명되지 않는 효과 |

근거는 같은 디렉터리의 문헌 카드에 있다. 기존 원리의 충분성을 확인해 그대로 채택하는 결과도 연구 진행에 유효하다.

## 2. 후보 A: 독립 관측으로 제한하는 감독 보정

**겨냥하는 가설:** 원 영상에는 지지가 있으나 영상 파생 depth/normal의 계통 오차 때문에 감독을 줄이기만 하면 정보를 버리거나 prior를 잘못 이동시킨다.

**의미 흐름:**

1. 현재 기하, 기존 기하, 영상 파생 감독을 동일한 ray·frame·visibility에서 대조한다. depth는 metric/relative, normal은 방향 및 좌표 convention을 명시한다.
2. 사진의 기선·시차·가림·텍스처를 이용해 후보 보정을 검정할 수 있는 관측을 구분한다. 현재 기하와의 residual 하나를 '감독 참오류'로 해석하지 않는다.
3. 시선별 작은 depth scale/offset, 제한된 normal 회전 등 **원인에 맞는 가장 작은 보정 변수**를 둔다. 세 변수 모두를 자동 채택하지 않는다. metric prior의 depth/normal을 단안 감독과 같은 이유로 묶지 않는다.
4. 보정량을 추정한 시선과 다른 학습 시선 집합에서 그 보정이 일관된 사진 대응을 개선하는지 확인한다. 외관·pose 변수를 공통으로 통제하여 보정이 모든 residual을 흡수하지 못하게 한다.
5. 지지가 충분한 범위에서만 보정된 감독을 사용한다. 모호하면 무제약 bias 증가 대신 보정 자유도를 줄이거나 기존 제약을 유지한다. 원본 관측과 기하는 계속 보존한다.

이 시선 분할은 방법 내부의 train-evidence 분리이며 최종 평가용 held-out view를 보정 선택에 사용하는 것이 아니다. 같은 predictor의 반복 예측은 독립 관측으로 세지 않는다. 데이터가 매우 적으면 분할이 오히려 기하 지지를 줄일 수 있으므로, 단순 다중뷰 집약과 같은 총 관측·연산량에서 비교해야 한다.

**개선 이유는 가설:** 틀린 감독의 유용한 구조적 정보를 작은 bias 보정으로 살리면서, 형상이 감독 오류를 대신 따라가는 것을 줄일 수 있다. 하지만 bias와 실제 geometry는 서로 교환 가능할 수 있다. 보정의 크기·공간 변화·시선 의존성에 제한을 두어도 식별이 안 되면 이 후보의 자동 보정 주장을 축소한다.

**가장 가까운 경쟁:** ND/NC-SDF형 보정, 단순 affine/rotation 보정, 기존 normal/depth confidence. 이들보다 다른 원리와 효과가 없다면 기존 요소 도입으로 남긴다.

## 3. 후보 B: 관측이 지지하는 방향에 맞춘 수정 허용량

**겨냥하는 가설:** 감독이 유효해도 구조 보호가 필요한 이동을 막거나, 관측이 제한한 자유도보다 넓게 움직여 같은 영역의 유효 기하를 손상시킨다.

**의미 흐름:**

1. 독립 시선의 투영·대응 변화로 국소 기하 변수의 어떤 변화가 관측에서 구별되는지 계산한다. 시선 수만으로 모든 방향의 기하를 관측했다고 보지 않는다.
2. 현재 RGB·허용 감독의 여러 관측이 반복 지지하는 수정에는 더 큰 이동을 허용하고, 지지가 약한 방향에는 기존 구조와의 변화 제한을 둔다. 위치·방향·크기·연결관계의 허용량을 동일 숫자로 묶어야 한다고 전제하지 않는다.
3. 감독 가중은 '어떤 residual을 얼마나 반영할지', 수정 제약은 '그 residual이 어떤 변수를 얼마나 바꿀지'로 따로 기록한다. prior depth weight와 구조 보호는 독립 제어다.
4. 현재 허용 변수가 필요한 표면을 표현하지 못할 때에만 생성/삭제 또는 topology 수정 후보를 연다. 원래 위치를 움직이는 실험과 새 표면을 추가하는 실험을 섞지 않는다.

**선택 가능한 수식화의 의미:** 기하 증분에 구형 이동 제한 대신 관측 민감도에 따른 방향별 제한을 둘 수 있다. 큰 sensitivity가 정확한 감독을 보증하지 않으므로 residual 신뢰·pose/외관 교란과 함께 해석한다. 이 문서는 행렬식·가중·threshold를 구현 규칙으로 동결하지 않는다.

**새로운 부분의 후보:** 초기 모델 적합도와 실제 수정 지지를 구별하는 증거로, 감독 보정량과 기하 이동 제약을 제한하는 구체 규칙. 방향별 제한이나 trust region 자체는 기존 원리다. EnerGS의 gradient 분리, GeoGS 보호, CoMe의 confidence–densification 및 기존 기하 uncertainty 제어로 같은 효과를 낼 수 있으면 새 방법 주장을 하지 않는다.

**기각 가능성:** 보정을 충분히 지지하는 방향도 열지 못하거나, 모호한 prior를 과신해 틀린 구조를 영구 유지할 수 있다. 미관측부를 보존했으면 '기존 구조 유지·현재성 미확인'으로 기술한다. 보존을 현재 정확도의 증명으로 바꾸지 않는다.

A와 B를 묶는 공동 최적화는 선택 사항이다. A 단독, B 단독, 기존 강한 순차법이 충분하면 그 수준에서 멈춘다.

## 4. 공정 비교의 두 수준

### 4.1 제어 원리를 구별하는 비교

같은 raw inputs, 정확히 같은 초기 구조/checkpoint, camera/registration, 영상 파생 감독 bytes, 표현·renderer·surface extractor, 연산 예산을 유지한다. 바꾸는 것은 질문에 해당하는 규칙 한 개 또는 작은 2×2 요인이다. 학습된 predictor의 가중치·학습 데이터 및 전처리 비용도 기록한다.

GeoGS에서 이어간다면 같은 anchor를 사용한 branching과 처음부터 학습한 비교를 나눈다. PLY만으로 exact continuation이라 하지 않으며 optimizer·controller·RNG·mask·sampling 상태까지 포함한 checkpoint 계보를 요구한다. 이것은 미래 비교의 요건이며 이번에 checkpoint를 만들거나 변환하지 않는다.

### 4.2 기존 전체 해법의 충분성 비교

mesh/SDF/GS 전체 파이프라인은 초기 변수·native extractor를 문자 그대로 같게 만들기 어렵다. 같은 원 입력과 물리 초기 surface를 제공하고 각 원방법의 정당한 adapter/native 출력 및 비용을 명시한다. 공통 물리 영역·metric으로 비교하되 추출법 차이를 숨기지 않는다. 이 결과로 단일 모듈의 인과효과를 주장하지 않는다.

필요하면 동일 checkpoint의 rendered depth를 같은 공통 extractor로 읽는 별도 진단을 두되, 그 공통 extractor가 특정 표현에 불리할 수 있다는 범위를 남긴다. 서로 다른 표현의 full-pipeline 비교를 '동일 초기 구조·추출' 실험이라고 부르지 않는다.

## 5. 질문별 최소 실험계획 — 모두 미래 계획

모든 행을 일괄 실행하는 grid가 아니다. Q0–Q1에서 남은 질문에 따라 Q2–Q5 중 가장 잘 구별되는 하나를 선택한다. 각 단계 결과를 matched camera·단면·metric으로 검토한 뒤 다음 비교를 결정한다.

| 질문 | 최소 비교 | 고정·관찰 | 기각·축소 조건 |
|---|---|---|---|
| Q0. 정보 부족/정합/추출 문제인가 | 기존 산출물에서 동일 ROI의 RGB·prior·depth target·learned depth·native/extracted surface 대응을 읽기 검토 | view baseline, frame, ray convention, visibility, reference footprint와 결측. 재생성 필요한 항목은 이번에 실행하지 않음 | 대응이나 참조 부족이면 원인 미확인. 정합·외관·추출로 설명되면 그 기존 처리의 개선을 우선 |
| Q1. 전역 조정과 기존 confidence로 충분한가 | prior-depth weight 낮음/높음 × 구조 보호 약함/강함의 4설정으로 시작. 기존 설정이 포함되면 재사용. 유망 영역에 기존 robust/confidence 또는 AGS/NeuRIS 제어 한 가지 추가 | 같은 초기·예산·ROI에서 교정과 손상 함께. weight=0은 prior 영향 전부 제거가 아님 | 하나의 전역 값이나 기존 제어가 혼합 조건을 충분히 해결하면 새로운 국소 제어 필요성 축소. 2×2 하나만으로 전역 최선의 부재를 입증하지 않음 |
| Q2. 가중 부족인가 감독 편향인가 | Q1의 적정 기존 제어를 고정하고 '보정 없음 / 단순 bias 보정 / ND·NC형 기존 보정' 비교. 잔여에만 후보 A 추가 | 보정 변수·정합 및 같은 감독 자료. model-fit residual과 다른 학습 시선의 지지를 별도 기록 | 기존 보정으로 같은 효과면 채택. 후보 A가 자기 잔차만 낮추고 기하/손상을 악화시키면 축소 |
| Q3. 감독 문제인가 수정 제약 문제인가 | 기존/보정 감독 × 기존/대안 수정 제약의 2×2. 대안은 먼저 기존 보호 조정·변수 분리, 잔여에만 후보 B | 같은 위치의 감독 residual, 실제 parameter 이동, surface 변화. gradient 배율을 실제 이동 배율로 간주하지 않음 | 보정 감독만으로 해결하면 새 제약 필요성 축소. 제약만으로 해결하면 새 confidence 추정 주장 축소. 단순 기존 조합과 동등하면 새 원리 아님 |
| Q4. 관측 가능한 결손·세부의 병목은 어디인가 | 같은 제어·결과에서 native→surface 손실을 확인. 필요 시 '기존 생성/삭제 규칙 / 기존 개선 규칙' 중 한 변경 또는 추출 한 변경 | 생성 수·위치·표면 지지와 정확도/완전성. 표현 변경은 별도 비교로 분리 | 기존 densification/추출로 해결하면 그 효과로 명명. 원 RGB에도 정보가 없으면 관측 기반 세부 복원 주장 제외 |
| Q5. 반복/재검정의 필요성이 있는가 | 같은 photo check·예산에서 지속 기각 / 단순 재포함 / 제안 재검정(필요 시) | 유효 감독 회복과 잘못된 감독 재유입을 함께. 정합/감독 생성 정보를 추가하지 않음 | 단순 재포함으로 충분하면 복잡한 반복법 제거. 재유입 손상이 크면 지속/제한 기각 채택 |

Q1의 4설정은 방향을 식별하는 시작점이다. '기존 해법 충분성'을 비교할 때는 개발자료에서 같은 tuning 비용을 배정하고, 최선의 단일 값과 tradeoff 곡선을 모두 제시한다. 비교법에 불리한 기본값 하나만 두지 않는다. 평가 GT로 설정을 선택하지 않는다. 설정 선택에는 허용된 train evidence와 사전 정한 자원 제약을 쓰고, 모든 설정의 평가 결과를 공개한다. 사후 GT로 최선을 고른 곡선은 평가 전용 상한이며 deployable 설정의 성능과 분리한다.

현재 exact ROI/파일·독립 test scene·허용 tuning budget·수치 tolerance·seed 수는 미동결이다. 최소 arm 구조만 설계했다. 한 seed는 구현 관찰일 뿐 안정성 증거가 아니므로 방법 우위를 주장하는 비교에는 반복과 scene 단위 변동을 보고해야 한다.

## 6. 같은 영역에서 교정과 손상을 평가하는 방법

**영역 선정:** run 결과를 보기 전에 입력 기하·영상 피복·비-GT metadata로 고정한 ROI와 인접 buffer를 사용한다. 하나의 ROI에 정확한 요소, 틀린 요소, 결손 후보를 함께 포함한다. 모든 후보가 같은 물리 영역을 공유한다. '잘 고친 부분'과 '잘 보존한 부분'을 서로 다른 유리한 crop에서 고르지 않는다.

**평가용 분류:** 출력이 잠긴 뒤 독립 reference로 초기 기하의 정확한 부분·잘못된 부분·참조 존재/결측을 분류할 수 있다. 이 분류는 optimizer, supervision map, 정합, 모델 선택으로 되돌리지 않는다. 참조 오차와 등록 불확실성보다 작은 차이를 실제 손상/개선으로 확정하지 않는다. 서로 인접한 부분을 다른 실험 arm으로 나누지 않고 같은 ROI 내 지표로 함께 남긴다.

| 평가 대상 | 보고할 양 | 피할 오해 |
|---|---|---|

| 유효 구조 손상 | 초기 정확 요소의 오류 증가와 손상 비율·변위·경계/연결 손상 | 원래부터 틀린 prior를 그대로 둔 것을 보존 성공으로 세지 않음 |

추가 원칙:

- 같은 ROI에서 `(필요한 교정·결손 회복, 유효 구조 손상)`을 함께 제시한다. 동일 손상에서 더 회복하거나, 동일 회복에서 덜 손상하는지 비교한다. 상충하는 결과는 Pareto 관계로 남긴다.
- 참조가 충분한 전체 고정 ROI의 결과와, 모든 방법에 공통인 참조/가시 피복의 결과를 병기한다. 공통 피복만의 수치로 결손을 숨기지 않는다.
- 현재 RGB의 충분한 관측, prior의 coverage, 평가 reference의 coverage는 서로 다른 mask/metadata다. 양쪽 모두 없는 곳과 reference만 없는 곳을 구분한다.
- 원본 기하·native 출력·rendered depth·extracted surface를 분리한다. 표시용 voxel/mesh가 자동으로 scoring 대상이 되지 않는다.
- 실험 단위는 scene/ROI/건물 등 공간 집단이며 수백만 점을 독립 반복 표본으로 취급하지 않는다. 독립 장면 검증 전에는 개발 조건 밖 일반화를 주장하지 않는다.
- P1/P2/P3와 이미 열어본 기존 집합은 개발 증거다. 신규 확인 연구의 untouched test로 재명명하지 않는다. LoD2/Roofer는 선택적 downstream probe이며 현재 metric geometry·세부·외관의 성과를 대신하지 않는다.

## 7. GT·합성 조건·실행 경계

GT는 평가 전용이다. uncertainty calibration/보정 target/구조 보호 영역/정합/모델 선택에 참조 geometry를 넣지 않는다. GT로 고른 local best output은 출력 잠금 뒤의 평가 상한일 수 있지만, 그 mask나 geometry를 최적화에 주는 'oracle run'은 이 계획에 포함하지 않는다.

통제 오차 조건을 만들 경우 비-GT existing input의 복사본에 알려진 shift·결손·단순화를 적용하는 미래 설계를 검토할 수 있다. 알려진 주입량은 입력 변형량의 진실이며 원래 prior가 정확하다는 증거는 아니다. GT를 가공해 입력 prior를 만들지 않는다. 실제 혼합 장면이 없는 합성 결과만으로 현장 필요성·일반화를 주장하지 않는다.

새 실험 실행 전에는 정확한 input/초기 상태/환경·버전/ROI/평가/예산을 별도 실행 문서로 구체화해야 한다. 본 파일은 그 실행을 시작하는 지시가 아니다. 이번 작업은 새 문서 작성과 기존 증거·원문 읽기로 종료한다.

## 8. 최종 기각·축소 기준

1. 기존 제어의 적정 조정·도입·단순 조합으로 같은 결과가 나오면 새 방법의 필요성을 축소하고 실제 충분한 해법을 채택한다.
2. 이득이 새 predictor, 더 많은 허용 입력, 더 큰 표현·연산 예산, 다른 정합·추출에만 의존하면 그 원인으로 기여를 다시 기술한다. 평가 GT가 학습·정합·보정·선택에 누출되면 해당 비교를 무효로 처리한다.
3. 감독 보정이 기하 오류를 흡수하거나 수정 제약이 필요한 수정을 봉쇄하면 해당 변수·제약을 줄인다.
4. 독립 관측이 부족해 여러 기하를 구별할 수 없으면 그 영역의 현재 정확 복원 주장을 제한한다. 명시적 source classifier 도입이 자동 해법은 아니다.
5. 기존 방법의 성공과 제안법의 악화를 함께 보고한다. 한 지표/세 개발 사례의 개선을 학위 기여·범용 우위로 확정하지 않는다.
