# DA3→ACMP 감독 교체와 refinement 제어를 분리하는 설계

## 1. 현재 질문과 우선순위

사용자는 P1/P2/P3의 부족을 “refinement 감독이 얼마나 정확한가”와 “그 감독을 얼마나 신뢰해 기존 기하를 수정하는가”로 보고, DA3 대신 ACMP 같은 MVS depth를 쓰면 기존 제어만으로 보존·수정을 함께 개선할 수 있는지 질문했다.

**두 축은 현재의 우선 분석 질문으로 적합하다. ACMP depth로 target만 교체하는 비교를 앞선 허용 집합 제약의 신규 도입보다 먼저 검토한다.** 두 원인의 단순 가산 모델로 확정하는 것은 아니다. 정확한 감독이어도 기존 prior loss·primitive 보호가 수정을 막을 수 있고, 편향된 감독이어도 다른 관측·제약이 손상을 억제할 수 있다. 따라서 둘째 축은 영상 depth의 계수만이 아니라 prior의 반대 제약과 실제 수정 경로까지 포함한다.

## 2. 앞선 허용 집합 식은 무엇을 바꾼 것인가

앞선 `d*=argmin_{d in A_p}(d-D_P)^2`는 영상 비용이 허용한 깊이 가운데 prior 변경이 가장 작은 깊이를 고르는 **제약 설계 후보**다. 단순히 국소 가중치를 하나 추가한 식은 아니다.

그러나 두 원본 depth 중 하나를 복사하는 소스 선택도 아니다. A_p가 연속 범위나 여러 후보 구간이면 d*는 prior/영상 예측 depth 어느 쪽과도 다른 값일 수 있다. 이를 미리 계산해 감독으로 넣으면 target 생성·보정에 해당하고, 복원 중 제약으로 넣으면 수정 범위 제어에 해당한다. 따라서 남은 설계가 “소스 전체 또는 일부를 고르기” 하나로 축소되지 않는다. 이 후보는 확정하지 않았으며, 아래 단순 대안이 충분한지 먼저 확인할 수 있다.

## 3. ACMP 감독으로 교체하는 것이 왜 타당한 비교인가

- [ACMP 원문](https://ojs.aaai.org/index.php/AAAI/article/download/6940/6794)은 calibrated RGB에서 신뢰할 만한 대응을 얻고 삼각분할 평면 prior로 저텍스처 결손을 보완한다. Photometric cost와 완화 가능한 평면 적합성을 함께 고려하므로 평면 보간만 하는 방법이 아니다.
- 완성법은 후속 geometric consistency refinement를 포함한다. 공식 pin `574c8e078b6f7bd93237bd180d46f5adf1169a19`의 [main.cpp:334](https://github.com/GhiXu/ACMP/blob/574c8e078b6f7bd93237bd180d46f5adf1169a19/main.cpp#L334)은 planar prior를 끄고 두 차례 기하 정제 후 fusion한다. [ACMP.cu:483](https://github.com/GhiXu/ACMP/blob/574c8e078b6f7bd93237bd180d46f5adf1169a19/ACMP.cu#L483)은 시점 간 왕복 재투영 기하 비용을 계산한다.
- ACMP도 영상에서 **추정한 depth**다. 조밀함은 정확도와 다르고, DA3보다 더 조밀하거나 더 정확하다는 우리 조건의 직접 비교는 아직 없다. 최종 MVS 필터링의 피복 손실과 근사 평면의 세부 손실 가능성도 평가 질문이다. 이를 ACMP 전체의 관측된 실패로 미리 판정하지 않는다.
- [DA3 원문](https://arxiv.org/html/2511.10647v1#S3)과 [공식 모델 설명](https://github.com/ByteDance-Seed/Depth-Anything-3#-model-zoo)은 다중영상과 알려진 pose를 사용하는 추정을 포함한다. “DA3는 단안 추측, ACMP는 정확한 실제 깊이”라고 대조하지 않는다.

예를 들어 `L_V=lambda_V rho(D_G-D_ACMP)`는 완성 ACMP의 **depth 출력만 감독으로 도입**한 것이다. ACMP 내부 검사는 그 출력 생성에 반영되어 있지만, 후단 GS가 학습 중 새 기하의 타당성을 계속 재검사하는 기능이 추가된 것은 아니다. ACMP의 후보 비용·시점 선택·일관성 제어를 refinement 안에 이식하는 것은 별도 변경이다.

## 4. P1/P2/P3가 실제로 뒷받침하는 범위

최신 [동일점 공간 진단](../geogs_p1p2p3_v1/DA3_REFINEMENT_SPATIAL_RESULTS_ko_v1.md)의 값은 기존 Anchor8k와 6조건의 raw TSDF512 표면을 읽어 얻은 사후 연관 분석이다. UAS점의 초기 표면 근접 상태와 최종 근접 상태를 비교하며, 면적 보존율이나 prior 현재성 판정이 아니다.

| 기존 관찰 | 지지하는 질문 | 아직 입증하지 않은 것 |
|---|---|---|
| P2: DA3 목표가 참조 ±0.5m 이내이고 Anchor-far인 23,250점에서 회복률 84.46/84.93% | 유용한 영상 depth와 큰 구조 수정의 관계 | DA3만의 인과 효과, ACMP 교체 이득 |
| P2: DA3 목표 +1m 초과이고 Anchor-near인 37,821점에서 prior .005/.0005 보존률 50.30/12.88% | 감독 불일치와 prior 제약 완화의 상호작용 | 모든 손상의 원인이 DA3라는 주장 |
| P3: 목표 편차 중앙값 +1.675m인 지정 690점은 100/99.57% 유지 | 같은 target 편차라도 다른 제약·관측·상태에 따라 손상이 달라질 수 있음 | target 정확도만으로 보존·수정을 예측하는 규칙 |

P2 형상의 정성적 개선과 이 국소 손상은 함께 성립할 수 있다. 평균 F1로 정성적 개선을 부정하지 않는다. P3 전체에서 낮은 가중치가 항상 나쁘다는 결론도 아니다. 선택 관측·참조 피복·동일 UAS를 공유하는 분류의 한계는 원 문서에 남는다.

[인과 검토](../geogs_causal_followup_v1/CAUSAL_REVIEW_ko_v1.md)는 P2 골의 복수 표면이 Anchor에도 있음을 기록한다. DA3 감독이 없는 Anchor에서 이미 생긴 잔여까지 DA3만으로 설명할 수 없다. 현재 입력·합성 expected depth·추출 표면도 구분해야 한다.

[입력 감사 귀속 정정](../geogs_p1p2p3_v1/DA3_AUDIT_INTERPRETATION_CORRECTION_ko_v1.md)에 따라 배치 척도 파손·미터 깊이 아님이라는 이전 단정은 재사용하지 않는다. 큰 사경 잔차에는 다른 가시 표면·지역 참조 피복이 섞였다. 실제 국소 불일치와 배치 문맥 민감도는 남는 관찰이다.

## 5. 첫 비교: target 교체와 기존 prior 제어의 상호작용

새 실행은 시작하지 않는다. 우선 검토할 최소 요인은 다음과 같다.

| refinement target | 기존 prior 깊이 가중 | 완화한 prior 깊이 가중 |
|---|---|---|
| 봉인 DA3 depth | 기존 비교의 기준 | 기존 비교의 기준 |
| 동일 영상·pose로 얻은 완성 ACMP depth | target 교체의 효과 | target 개선과 prior 완화의 상호작용 |

기존 .005/.0005 쌍을 우선 후보로 검토하며, 이것은 **DA3 가중치 변경이 아니라 prior depth 가중치 변경**이다. Native primitive 보호는 첫 비교에서 동일하게 유지한다. 더 나은 target이 있어도 변경되지 않는 부분이 남으면 보호 변경을 별도 요인으로 검토한다.

필요한 통제:

1. 동일 complete Anchor, 현재 영상·카메라, RGB/normal 등 다른 감독, depth loss 형태, refinement 길이, 추출을 공유한다. ACMP에 외부 prior를 추가하지 않고 먼저 표준 입력으로 생성한 target을 비교한다. 외부 prior를 ACMP 내부에도 넣으면 감독의 독립성·정보량이 바뀌는 별도 adaptation이다.
2. Target만의 영향을 보려는 비교에서는 영상 depth의 공통 계수 일정을 동일하게 둔다. 같은 adaptive 코드도 target·유효 피복이 바뀌면 다른 계수 궤적을 만들 수 있다. 같은 규칙을 각각 실행하는 전체 방법 비교와 target-only 통제를 구분한다.
3. 동일 단위·camera-Z/ray-depth·해상도·픽셀 중심·가림 규약을 맞춘다. ACMP의 최종 depth map을 사용할지 fusion을 다시 raycast할지도 고정한다. 둘은 같은 감독이 아니다. GT로 scale·shift·정합을 맞추지 않는다.
4. 두 target의 공통 유효 영역에서는 정확도·뷰간 일관성을 대조하고, 각 방법의 native 유효 피복에서는 결손·완전성을 별도로 대조한다. 공통 영역 밖을 조용히 제외하거나 MVS 결손을 정답 깊이로 보충하지 않는다. 감독 픽셀 수와 loss 정규화가 달라져 유효 강도가 바뀌는 영향도 분리한다.
5. ACMP 생성 시간·메모리도 총 계산량에 포함한다. 동일 입력 비교와 동일 총 예산 비교를 구분한다. 더 많은 계산으로 얻은 이득을 제어 원리의 효과라고 쓰지 않는다.
6. 기존 DA3 실행은 위 통제와 일치하는 셀에 한해 재사용한다. 같은 controller 인자만으로 실제 계수가 같다고 가정하지 않는다. DA3 on/off를 추가한다면 CLI `lambda_da_depth=0`만으로 off가 성립하지 않을 수 있다는 기존 코드 감사를 따른다.

## 6. 결과에 따른 방법 방향

| 비교 결과 | 다음 설계 판단 |
|---|---|
| ACMP target만 교체해 수정·보존·세부가 함께 개선되고 기존 제어가 충분 | 우선 감독 생성기 개선을 채택. 새 source 선택·허용 집합 제약의 필요성 축소 |
| target은 일부 개선되지만 prior를 완화할수록 유효 영역 손상이 남음 | 같은 target에서 기존 국소 confidence/robust loss의 충분성을 비교. 어느 신호가 유효 감독과 오류를 구별하는지 설계 |
| target이 더 정확해도 학습된 depth가 움직이지 않음 | prior loss, primitive 보호, 변수 전달·생성/삭제 제약을 별도로 비교 |
| 학습된 depth는 좋아졌지만 최종 mesh가 그대로 나쁨 | 표면 표현·복수 층·추출에서 손실되는 원인을 비교 |
| ACMP가 관측 부족·세부에서 더 나쁘거나 결손이 큼 | 전면 대체의 적합성 축소. 기존 DA3의 유용 영역도 포함해 보완 도입 여부 검토 |

국소 confidence는 정답 소스 라벨을 반드시 요구하지 않으며, prior와 영상 가중을 `w_P=1-w_V`로 강제할 필요도 없다. 양쪽 근거가 유효하면 함께 쓰고, 둘 다 불확실하면 둘 다 약해질 수 있다. 그래도 정보가 없는 곳의 정확한 현재 기하가 자동 생성되는 것은 아니다.

우리 연구의 현재 의도는 **국소적으로 불완전한 refinement depth가 기존 기하를 수정하도록 하는 과정에서, 좋은 수정 신호의 효과는 살리고 유효 구조를 손상시키는 감독·제약의 작용을 통제하는 것**이다. 좋은 depth 생성기 도입만으로 충분한지와 추가 제어 원리가 필요한지를 함께 검증한다. ACMP 도입이나 국소 가중 자체만으로 신규성을 확정하지 않는다. 기존 결과와 계약·진행 중 작업·서비스는 보존했다.
