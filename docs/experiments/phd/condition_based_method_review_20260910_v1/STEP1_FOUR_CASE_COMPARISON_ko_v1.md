## 1. 진행 단계와 이번 문서의 역할

진행 순서는 **① 기존 방법의 부족 찾기 → ② 우리 목표에서 중요한 부족과 경쟁 원인 좁히기 → ③ 이를 겨냥한 방법 설계**다. 이번 파일은 ①의 조건 정리와 문헌 비교다. 이미 작성된 [방법 후보 문서](METHOD_AND_MINIMUM_TESTS_ko_v1.md)는 후속 검토용 구상으로 보존하며 채택된 설계로 간주하지 않는다.

AGENTS.md의 운영·보존 지침과 기존 연구계약의 계보를 유지한다. 새 탐색 연구에 ALS·GS·LoD2·고정 confidence·명시적 source decision을 필수로 적용하지 않는다. 여기서 O/X는 **입력의 국소 기하 정보 유효성**을 설명하는 기호다. 기존 Roofer/LoD2의 출력 O/X나 공식 acceptance label과 다르다.

## 2. 상위 네 분류의 기준

**판단 단위는 같은 위치·목표 해상도·기하 성분이다.** 높이, 면 방향, 경계 위치, 작은 돌출부 등 무엇에 관한 O/X인지 먼저 적는다. 한 건물이나 한 센서 전체에 하나의 O/X를 붙이지 않는다.

- **기존 기하 O:** 해당 성분에 타당하고 유효한 기하 제약을 제공한다. 허용되는 작은 측정오차가 있을 수 있으며, 전체 장면이 완전하다는 뜻은 아니다.
- **기존 기하 X:** 해당 성분이 잘못되어 있거나, 결손·표현 생략으로 유효한 제약을 제공하지 못한다.
- **영상 O:** 원 영상과 관측 배치가 해당 성분에 유효한 기하 단서를 제공한다. 한 소스만으로 완전복원할 수 있다는 뜻은 아니다.
- **영상 X:** 미관측·가림·작은 시차·반복무늬·광학 교란 등으로 해당 성분의 신뢰할 기하 구속이 부족하다.

영상의 depth/normal 추정기가 실패했다는 사실만으로 원 영상 X라고 하지 않는다. 반대로 영상에 윤곽이 보인다는 사실만으로 깊이·두께도 O라고 하지 않는다. **confidence나 낮은 residual은 O/X의 추정 근거이며 실제 유효성 자체가 아니다.**

O/X를 확인할 근거가 없으면 `판정 미확인`으로 기록한다. 이는 다섯 번째 입력 조건이 아니라 우리의 확인 상태다. 실제 평가에서의 O/X label은 평가 전용이며 방법에 제공할 classifier 정답이나 mask를 요구하지 않는다. 수치 허용오차는 이번에 동결하지 않는다.

| 상위 조건 | 기본 복원 요구 | 이 조건만으로 확정할 수 없는 것 |
|---|---|---|
| **OO: 기존 기하 O · 영상 O** | 유효 정보를 함께 활용해 유지·정제·보완 | 두 입력의 완전 일치, 단순 평균의 최적성, 이미 완전복원됐다는 결론 |
| **OX: 기존 기하 O · 영상 X** | 유효 기하 유지, 근거 부족한 변형 억제 | 현재 영상만으로 미관측 기하의 현재성까지 입증했다는 결론 |
| **XO: 기존 기하 X · 영상 O** | 잘못된 기하 수정 또는 결손·생략된 세부 복원 | 감독 약화 하나로 위치 이동·새 표면 생성까지 모두 해결된다는 결론 |
| **XX: 기존 기하 X · 영상 X** | 주어진 정보로 복원 가능한 범위와 불확실성 확인 | 특정 현재 형상이 관측으로 입증됐다는 결론 |

O는 유효한 **부분 제약**도 포함한다. 서로 다른 유효 제약이 함께 기하를 결정하는 상보성을, 각 소스가 단독으로 완전복원하지 못한다는 이유로 XX에 넣지 않는다. XX의 한계도 이웃 관측·경계 등 허용 정보가 해당 성분에 실제로 기여하는지 확인한 뒤 해석한다.

외관은 각 셀에서 별도로 기록한다. 영상 X는 기하 구속의 부족을 뜻하므로 색·외관 관측까지 모두 사용할 수 없다는 뜻은 아니다. OX의 prior가 현재도 유효한지 알 수 없다면 그 O 자체를 미확인으로 남긴다.

## 3. 세부 조건 — 모두 네 분류 아래에 둠

| 상위 | 하위 조건 | 구체 예 | 구분이 필요한 이유 |
|---|---|---|---|
| OO | **OO-1: 두 정보가 유효하고 잘 대응** | 정합된 지붕면과 여러 시선의 일관된 관측 | 기존 방법의 정상 성공과 불필요한 손상 확인 |
| OO | **OO-2: 두 정보가 유효하나 정밀도·표현 수준이 다름** | 같은 면의 방향/위치를 서로 다른 오차로 구속 | 매끄러움·점밀도·소스 이름으로 우열을 정할 수 없음 |
| OO | **OO-3: 원 영상은 유효하나 파생 감독이 왜곡** | 정확한 기존 세부와 사진 지지가 있는데 단안 법선이 과평활 | 정보 존재와 감독 생성/활용 실패를 구별 |
| OX | **OX-1: 현재 기하 단서가 거의 없음** | 정확한 기존 면이 현재 사진에서 가려짐 | 기존 형상 보존과 관측 기반 현재성 입증을 구별 |
| OX | **OX-2: 사진은 있으나 기하가 모호함** | 무텍스처·작은 기선·반사로 위치 제약 부족 | RGB 오차 감소가 기하 이동의 타당성을 뜻하지 않음 |
| XO | **XO-1: 기존 기하가 존재하지만 틀림** | 위치·높이·방향이 틀린 면, 현재와 다른 구조 | 기존 구조를 실제로 수정/제거할 수 있어야 함 |
| XO | **XO-2: 기존 기하가 없거나 표현에서 생략** | LoD의 돌출부 생략, DSM의 수직면 미표현 | 잘못된 면의 이동과 새로운 표면의 복원은 다른 과제 |
| XO | **XO-3: 원 영상은 유효하나 파생 감독도 틀림** | 사진에는 돌출부 지지가 있지만 기존 모델과 단안 depth 모두 생략 | 두 기하 산출물의 동의가 raw evidence의 활용을 막을 수 있는지 확인 |
| XX | **XX-1: 기존 기하가 틀리고 영상 구속 부족** | 변화한 구조가 현재 영상에서도 가려짐 | 수정 근거가 부족한 상황에서 틀린 prior를 유지할 위험 |
| XX | **XX-2: 기존 기하와 영상의 해당 정보가 모두 결손** | 어느 입력에도 지지가 없는 후면 세부 | 보완적 정보를 이용한 복원과 가정에 따른 추정을 구별 |

하위 조건은 중복 가능한 설명 항목이다. 예를 들어 잘못된 기존 면과 잘못된 파생 감독이 함께 있으면 XO-1과 XO-3을 함께 기록한다. 이 목록을 서로 배타적인 열 개의 실험군으로 만들지 않는다.

정합·가시성·시간차·외관은 별도의 다섯 번째 상위 분류로 만들지 않는다. 어느 셀인지 판단할 때 함께 기록하는 원인·관측 metadata다. 예를 들어, 잘못된 frame 때문에 위치가 어긋난 XO-1은 실제 형상이 변한 XO-1과 원인이 다르다. 허용된 정합을 수행한 전후의 상태를 구분해야 한다.

**한 영역의 혼합도 새 분류가 아니다.** 같은 지붕의 유효 면은 OX-2, 잘못된 돌출부는 XO-1, 누락된 난간은 XO-2일 수 있다. 같은 물리 영역에서 이 세 요소를 함께 평가하면 필요한 수정과 유효 구조 손상을 동시에 볼 수 있다.

이전 K0–K6는 다음처럼 읽는다: K0→OO, K1→OX, K2→XO-1, K3→네 셀의 국소 공존, K4→세부 성분의 XO-2, K5→원 RGB에 지지가 있으면 XO-3/OO-3이고 없으면 XX, K6→각 셀의 정합·가시성·외관 원인 metadata. 기존 파일은 그대로 보존한다.

## 4. 문헌을 네 셀에 대응시키는 원칙

문헌의 `prior`라는 단어만으로 기존 기하 축을 채우지 않는다. GeoGS의 외부 LoD, EnerGS의 LiDAR는 독립 기하 입력에 가깝다. AGS-Mesh의 동기화 sensor depth는 외부 기하 활용의 유사 조건이다. NeuRIS·ND/NC-SDF의 단안 감독, ACMP의 영상 유래 평면은 독립 기존 자산이 아니다. SenFuNet은 주로 여러 depth stream의 융합이며 원 영상의 기하 정보를 직접 모두 활용하는 문제가 아니다.

또한 희소 영상이라고 모든 위치가 X는 아니다. 실제 셀을 분리하지 않은 논문은 **해당 축을 다룬 근거**로 표시하고, 그 셀을 독립 검증했다고 쓰지 않는다.

이하 결과 상태는 `완성법 성공`, `완성법 잔여 실패/저자 한계`, `해결된 ablation`, `우리 추론`, `미평가/가정 밖`으로 구분한다. 모든 문헌이 네 셀을 전부 다뤄야 직접 경쟁 후보가 되는 것은 아니다.

## 5. OO — 두 입력이 유효할 때의 성공과 부족

| 세부 조건·방법 | 이미 제공하는 해결/성공 | 남는 부족 또는 확인 경계 |
|---|---|---|
| OO-1·2 / GeoGS, AGS-Mesh | 기존 구조 또는 sensor depth와 영상 감독을 결합해 표면·외관 개선을 보고. AGS는 depth 자체의 큰 이득과 DNC/ANR 추가 효과를 분리함 [S1,S2] | **미평가:** 정확한 기존 세부가 이미 있는 OO 부분의 손상률을 독립 분리한 결과인지는 별개. 논문 평균 향상을 모든 OO 요소의 비악화로 확대하지 않음 |
| OO-3 / AGS-Mesh, NeuRIS, ND-SDF | 부정확한 normal 감독의 반영을 조정하거나 보정해 세부를 회복하는 성공 [S2,S3,S4] | **성공·해결된 ablation:** 감독 편향 대응 자체는 기존 해결책. **미평가:** 같은 위치의 독립 정밀 prior 보존까지 함께 검증한 것은 아님 |
| OO-2 / SenFuNet의 이종 융합 | 센서가 불균형해도 융합으로 개선하는 사례 존재 [S6] | **원인 참고:** 매끄러움에 치우친 선택·경계에서 부적절한 평균화가 완성법의 잔여 사례. 두 depth의 참오류 사례를 raw 영상 O인 OO 셀의 직접 실패로 바꾸지 않음 |

**현재 확보한 결론:** 유효 정보 결합과 잘못된 파생 감독 제어는 이미 상당한 성공을 갖는다. OO에서는 '융합하면 좋아진다'를 다시 기여로 잡기보다, 어느 유효 요소가 손상되는지의 실제 잔여 증거가 필요하다. 현재 우리 OO 셀 전체의 실패를 확인한 상태는 아니다.

## 6. OX — 유효 기하가 있고 영상 구속이 약할 때

| 세부 조건·방법 | 이미 제공하는 해결/성공 | 남는 부족 또는 확인 경계 |
|---|---|---|
| OX-1·2 / GeoGS | sparse image에서 기존 구조의 초기화·depth·geometry protection으로 안정성을 확보. depth 제어와 보호 제거의 영향을 각각 ablation으로 확인 [S1] | **성공:** 영상만으로 불안정한 구조 보완은 기존 해법의 강점. 해당 장면의 모든 위치가 OX라는 뜻은 아님 |
| OX-2 / EnerGS | trusted occupied/free field와 위치 갱신 분리로 기하 위반을 줄이는 접근 [S5] | **성공·가정 경계:** trusted 기하가 유효하다는 전제에서 해석. 같은 제약이 XO의 틀린 구조도 보정한다는 근거는 아님 |
| OX-2 / NeuRIS·ACMP 계열 | 영상 유래 normal/planar prior로 무텍스처 모호성을 완화하는 유사 원리 [S3,S8] | **구성요소 근거:** 독립 existing geometry 보존의 직접 검증은 아님 |

**현재 확보한 결론:** OX의 구조 유지에는 강한 선행이 있다. 새 방법의 필요성을 주장하려면 그 방법들을 적절히 사용해도 남는 손상을 확인해야 한다. 현재 영상에서 기하 지지가 부족한 곳에 관측 가능한 세부 복원을 일률 요구하지 않는다. 외관 적합성은 별도로 확인한다.

## 7. XO — 영상 지지는 있는데 기존 기하가 부정확하거나 없음

| 세부 조건·방법 | 이미 제공하는 해결/성공 | 남는 부족 또는 확인 경계 |
|---|---|---|
| XO-1 / GeoGS | 높이·수평 shift·부분결손 prior perturbation을 실제 평가. building-scale geometry는 비교적 안정적 [S1] | **저자 결과:** prior perturbation에서 외관·국소 정합 영향이 남음. **미평가:** 각 잘못된 성분에서 영상 O가 독립 확인됐는지, 초기 오류가 얼마나 수정되고 이웃 O가 얼마나 손상됐는지는 그 표만으로 판단 불가 |
| XO-1 / SRDM·photometric mesh refinement | 불일치 range 제어와 사진에 따른 surface 보정은 이미 존재 [S7] | **잔여/가정:** SRDM의 균일 강도·depth jump mismatch, mesh refinement의 초기값/수렴 범위. 이 중 균일 강도 부분은 영상 X일 수 있어 XO 실패라고 바로 배정 불가 |
| XO-1 / AGS DNC | sensor depth의 normal inconsistency를 이용한 filtering이 전체 복원 개선에 기여 [S2] | **우리 추론:** 방향을 유지한 평면의 위치 이동은 normal 각도만으로 구별되지 않을 수 있음. 이는 DNC라는 개별 검사 정보의 범위이며, RGB 등 다른 항을 가진 완성 AGS의 실패 증거는 아님 |
| XO-2 / GeoGS·EnerGS | 부분결손 prior 또는 prior 미관측 공간에서의 유연성을 다룸 [S1,S5] | **미평가:** 기존 표면이 없을 때 보완하는 기능을, 존재하지만 틀린 trusted 표면을 수정하는 기능으로 전용할 수 없음. 두 조건을 각각 비교해야 함 |
| XO-3 / NeuRIS·ND/NC-SDF·DebSDF | 부정확한 영상 파생 감독의 약화·보정·전달 개선으로 세부를 회복한 선행 [S3,S4,S8] | **미평가:** 독립 existing geometry와 파생 감독이 같은 오류에 동의하는 조건까지 검증됐는지는 별개. 감독 보정으로 해결된 ablation을 미해결로 재사용하지 않음 |

**현재 확보한 결론:** '기존 방법은 틀린 prior를 고치지 못한다'는 일반 주장은 성립하지 않는다. 구별해야 할 잔여 질문은 **위치 오류와 normal 오류**, **잘못된 표면과 없는 표면**, **원 영상의 정보와 파생 감독의 오류**다. 어떤 잔여가 실제로 중요한지는 ②에서 판단한다.

## 8. XX — 양쪽의 유효 기하 정보가 부족할 때

| 세부 조건·방법 | 확인된 상태 | 우리 네 분류에서의 해석 |
|---|---|---|
| XX-1·2 / ND-SDF | **저자 한계:** 낮은 관측 피복에서는 모호성으로 잘못된 구조/local optimum이 가능 [S4] | 영상 부족에서의 한계 근거. 독립 existing geometry X까지 함께 확인한 실험은 아님 |
| XX-2 / CoMe | **저자 한계:** 심한 가림·미관측 부분의 구멍, 원거리 세부 부족 [S9] | image-only 조건의 관측·복원 한계. 유효 기존 기하가 추가되면 달라질 수 있음 |
| XX-1 / SenFuNet | **완성법 잔여:** 두 센서의 같은 voxel에 outlier가 겹칠 때 제거 한계 [S6] | 두 depth 표현의 결합 실패 근거. 원 RGB에 유효 단서가 남으면 우리 정의에서는 영상 O일 수 있으므로 자동 XX 배정 금지 |

**현재 확보한 결론:** 검토 문헌에는 XX와 관련된 부분 한계가 있지만, 우리의 외부 기하 X와 raw 영상 X를 함께 확정한 직접 검증은 충분히 확보하지 못했다. 필요한 정보가 없는 현상과, 정보가 있는데 처리 단계가 놓친 현상을 분리해야 한다. 새로운 가중치로 정보 자체가 생긴다는 주장을 하지 않는다.

## 9. 1단계에서 남긴 부족 후보 — 우선순위·방법 채택 전

| 부족 후보 | 현재 근거의 종류 | 아직 확인할 점 |
|---|---|---|
| 유효한 기하보다 잘못된 매끄러운 기하를 선호하거나 경계를 평균화함 | SenFuNet의 **완성법 잔여 사례** | 독립 prior+raw 영상에서도 같은 문제가 생기는지, 기존 제어 조정으로 충분한지 |
| normal 기반 신뢰 검사가 위치/높이 오류를 구별하지 못함 | AGS의 검사 정의 + **기하적 추론** | 다른 photometric/depth 제어가 전체 과정에서 이미 해결하는지 |
| 틀린 existing 표면의 보정과 결손 표면의 보완이 같은 제어로 충분하지 않을 수 있음 | EnerGS의 trusted/unknown 전제와 GeoGS의 perturbation 평가 + **미평가 질문** | 해당 조건의 충분한 영상 지지, 실제 수정·보존 동시 결과 |
| 원 영상의 세부가 파생 감독·표현·추출에서 사라짐 | NeuRIS/ND/Deb의 **이미 해결된 ablation**, AGS 추출의 **저자 한계** | 최종 기존 해법을 사용한 뒤에도 남는 부족인지 |
| 양쪽 정보 부족에서도 잘못된 현재 기하가 만들어질 수 있음 | ND/CoMe 관측 부족의 **저자 한계**, 외부 prior 축은 미확인 | 정보 식별 한계인지 제어 실패인지 |

이 표의 모든 행을 확인된 실패나 새 방법의 필요성으로 승격하지 않는다. 기존 성공을 포함해 잔여를 좁히는 것이 ①의 결과다. ②에서는 영향·빈도·복원 가능성을 비교해 중요한 부족을 고르고, ③에서 원리를 구체화한다.

P1/P2/P3는 셀별 실제 유효성이 확인되지 않은 개발 관찰이다. 장면 번호만으로 OO/OX/XO/XX를 붙이지 않는다. P2 저가중의 정성적 형상 개선을 유지하고 정확도·완전성·참조 피복을 분리한다. P3 저가중 악화는 가설이다. GeoGS prior depth weight와 구조 보호, 논문 valid mask와 optional confidence 및 실제 설정도 구분한다. 기존 [근접 감사](NEARBY_METHODS_ko_v1.md#4-geogs의-논문코드실제-개발-실행-구분)를 참조한다.
