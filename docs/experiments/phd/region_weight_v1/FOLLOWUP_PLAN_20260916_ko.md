> [전역 prior 0.0005에서 영역 가중치 반응 확인](GLOBAL_PRIOR_FOLLOWUP_20260916_ko.md)이다.
> 아래 지역 prior 감쇠는 그 결과의 보정–보존 절충을 확인한 다음 단계로 둔다.

- `scientific_verdict: null`
- 범위: 기존 최종 30k 결과를 읽은 CPU 진단과 다음 실험 설계. 신규 학습 미실행.
- 사용자 확인: DA3와 MVS 모두에서 prior 0.0005일 때 P1 지붕 평탄화와 끝 지붕 손상을 관찰했다.

## 1. prior 계수 해석

과거 P1 DA3의 D005_Pnative/D0005_Pnative와 MVS의 mvs_0.005/mvs_0.0005는
같은 Anchor8k SHA `c08a39aa2deb81b26dd4dd75d0be9e6bb5e150db503f9d422a05423388679274`
및 native 보호 유지 계열이다. 보호를 유지해도 prior 약화에 따라 결과가 바뀌었다는
관찰은 prior 손실의 경쟁과 보정–보존 절충을 주요 가설로 지지한다.
보호가 유일한 원인이거나 prior 계수만으로 모든 문제가 설명된다고 확정하지 않는다.

과거 MVS run은 동적 depth 계수가 켜져 있었고 .005 arm에서 실제 MVS 계수
0.05/0.0475, .0005 arm에서는 0.05가 관측됐다. 현재 수동 가중치 run은
계수를 0.05로 고정하고 감독 공간도 다르다. 따라서 과거 .0005 결과를 현재
수동 .005 결과의 완전히 동일한 조건 대조군으로 바로 쓰지 않는다.

읽은 과거 기록의 payload 상대 경로:

- `geogs_p1p2p3_v1/PHD-GEOGS-P1P2P3-v1/runs_allocator_v2/P1/{D005_Pnative,D0005_Pnative}/model/jbgs_restore.json`
- `geogs_mvs_pgsr_v1/PHD-GEOGS-MVS-PGSR-v1/train/P1/mvs_0.005/attempt.lQtLPxeE`
- `geogs_mvs_pgsr_v1/PHD-GEOGS-MVS-PGSR-v1/train/P1/mvs_0.0005/attempt.3iBmJucV`

## 2. 실제 R1 감독 노출

각 arm의 22,000회 refinement를 전체 camera trace로 집계했다. α=0/1/4에서
카메라 선택 횟수는 같다. α=0의 R1 손실은 0이므로 방문과 활성 감독을 구분한다.

| 대상 | R1 유효 표본을 가진 카메라 / 전체 | 해당 카메라 선택 | 전체 step 비율 |
|---|---:|---:|---:|
| P1 | 1 / 98 | 225 | 1.02% |
| P2 | 14 / 57 | 5,407 | 24.58% |
| P3 | 74 / 137 | 11,886 | 54.03% |

P2 0146/0108_D는 각각 385/387회, P3 0046/0142_D는 160/161회 선택됐다.
R1이 하나라도 있는 카메라의 총 방문 수이며 같은 표면점의 다시점 지지가 아니다.
P2/P3 전체를 ‘거의 사용하지 않아 반응하지 않았다’고 설명하기 어렵다.

## 3. 변화 위치와 평균 해석 정정

모든 값은 같은 R1 공통 픽셀의 expected camera-Z depth다. 입력 MVS 적합도이며
Gaussian 위치 변화량, 단일 표면 형성, 수직 지붕 높이 오차, 독립 정확도가 아니다.

### P2 0146_D

변화가 큰 부분은 원사진에서 반복된 지붕 구조 양옆의 넓은 지붕 면이다.
중앙 반복 구조 전체가 수 m 이동했다는 뜻은 아니다.

| 예시 픽셀 (x,y) | MVS | prior | GS α=0 | GS α=1 | GS α=4 |
|---|---:|---:|---:|---:|---:|
| A (733,545) | 60.368 | 55.304 | 55.389 | 60.349 | 60.405 |
| B (979,276) | 60.578 | 55.430 | 55.429 | 60.377 | 60.607 |

A의 절대차는 4.979m→0.019m→0.037m, B는 5.149m→0.201m→0.029m다.
모든 픽셀이 α=4에서 단조롭게 개선되는 것은 아니다.
전체 R1 평균은 3.326m→0.160m→0.070m지만, 최종 depth의 1↔4 차이 중앙값은
4.38cm다. TSDF 표면·텍스처 뷰어에서는 이러한 국소적 차이를 구분하기 어려울 수 있다.
두 예시 MVS 점 모두 기존 3D 표시 범위 안에 있다.

### P3 0142_D: 평균 3.2m의 의미

α=4의 평균은 3.179m, 중앙값 0.02323m, 95백분위 41.90m다.
10cm 이내는 84.75%, 10m 초과는 4,769 / 66,213픽셀(7.20%)이다.
후자가 절대잔차 합의 92.35%를 차지한다. 종전의 ‘지붕이 광범위하게 3m 미보정’
해석은 철회한다. 대부분의 **유효 집계 픽셀**이 가깝다는 뜻이며 결측 지붕도 정확하다는 뜻은 아니다.

| 예시 픽셀 (x,y) | MVS | prior | GS α=4 | 설명 |
|---|---:|---:|---:|---|
| A (713,616) | 52.127 | 52.132 | 52.110 | 작은 잔차, MVS 점은 표시 범위 안 |
| B (626,232) | 112.411 | 52.464 | 52.438 | 약 60m 큰 잔차, MVS 점은 표시 범위 밖 |

MVS 점이 기존 표시 범위 안에 있는 51,125픽셀의 평균은 0.736m, 중앙값은
0.02197m다. 이 부분에도 큰 잔차가 남는다. MVS 점의 범위 판정은 입력 카메라의
K/R/t로 복원한 좌표와 기존 뷰어 bounds만 사용했다. 평가 형상으로 골라내지 않았다.
범위 밖 또는 prior와 불일치라는 사실만으로 MVS를 틀렸다고 단정하지 않는다.
원본 depth, 투영·단위, 가림·표면 대응, 다른 뷰의 지지를 확인할 대상이다.

## 4. P1/P2/P3에 공통으로 적용할 다음 실험

### 단계 A — 입력과 보정 대상 고정, 학습 전

1. 큰 잔차 표본은 원본 MVS native depth와 K/R/t, 재투영, 다른 현재 뷰의 depth/영상 지지로 점검한다.
2. 현재 증거가 보정을 지지하는 부분, 유지 대상, 판단 불가·결측을 입력만으로 정한다.
   최종 GS 잔차나 UAS·LoD2 평가 형상으로 학습 마스크를 정하지 않는다.
3. MVS 감독 픽셀과 약화할 **과거 표면**을 따로 정의한다. P1 같은 XY의 과거 지붕과 현재 바닥을
   높이·표면별로 구분하고, 같은 과거 표면의 prior loss를 관련 모든 뷰에서 일관되게 감쇠한다.
4. 감독 mask가 바뀌면 기존 결과를 정확한 대조군으로 재사용하지 않고, 같은 변경 입력으로 대조군부터 만든다.

### 단계 B — prior 전역 약화와 지역 약화 비교, 우선순위 1

공통 Anchor8k, MVS α=4와 전역 계수 .05 고정, 동일 RGB/prior 카메라 순서,
학습 길이·손실 분모·native 보호·추출 설정을 고정한다. α=4의 효과를 분리하려는
비교이므로 기존 α=1 결과와도 함께 보되 조건별 최적 α를 임의로 섞지 않는다.

| 조건 | 보정할 과거 표면의 prior | 유지·판단 불가 표면의 prior | 검증 질문 |
|---|---:|---:|---|
| 기준 | .005 | .005 | 현재 결과 |
| 전역 약화 | .0005 | .0005 | prior 약화로 보정과 손상이 함께 증가하는가? |
| 지역 약화 | .0005 | .005 | 보정을 확보하면서 유지 영역 손상을 줄이는가? |

동일 설계를 세 지역에 적용한다. 원래 입력을 유지할 수 있으면 기존 α=4 3개와 신규 6개 비교다.
한 장의 MVS R1 마스크를 그대로 prior/보호 mask로 복사하거나 R1 전체를 무조건 감쇠하지 않는다.

| 지역 | 보정 측정 | 보존·부작용 측정 |
|---|---|---|
| P1 | 기존 지붕 잔존, 현재 지면 깊이·단면, 이중 표면 여부 | 끝부분과 인접 유지 지붕 |
| P2 | 입력으로 확인한 지붕 면·형상 불일치의 보정 | 반복 지붕 구조의 능선·골·경계 손상 |
| P3 | 신뢰 가능한 외벽·지붕 표면의 보정 | 현재 입력과 이미 맞는 지붕, 결측부의 무근거 변화 |

최종 렌더 depth 적합도와 독립적인 표면 정확도·완전성은 별도 측정한다.
평균/중앙값/95백분위/큰 잔차 비율/결측 비율, 동일 고정 단면, 동일 reference-point IDs,
prior 연결 Gaussian의 위치·opacity·활성 기여 변화를 함께 기록한다.
MVS에 더 잘 맞는 것을 실제 철거 성공이나 건물 정확도 향상과 동일시하지 않는다.

### 단계 C — 감독 노출과 보호 분리, 남은 문제에 따라

- 특정 표면의 현재 depth 지지가 적고 지역 prior 약화 후에도 반응이 약하면 depth-only 추가 감독을 비교한다.
  RGB와 prior 카메라 순서는 고정한다. 반복 횟수와 누적 MVS 가중량을 기록하고,
  빈도 자체의 효과를 주장하려면 누적 가중량을 맞춘 비교도 둔다. 같은 depth 반복은 새 관측이 아니다.
- 신뢰 가능한 관측을 충분히 주어도 prior 표면이 유지되면 해당 과거 표면의 보호만 완화하는 arm을 비교한다.
  prior 지역 계수·관측 조건은 고정한다. opacity 변화와 실제 Gaussian 기하 변화도 구분한다.
- P3의 큰 잔차를 해소하려고 검증 없이 prior 전체를 약화하지 않는다.

## 5. 방법론 기여로 연결할 가설

‘불완전한 과거 구조와 현재 관측 사이의 경쟁을 보정 필요 영역에서 조절하여,
전역적인 prior 약화보다 현재 형상 보정과 안정 구조 보존을 함께 달성할 수 있는가?’
수동 실험은 이 조절 기제의 가능성과 한계를 검증한다. 자동 confidence/보완 필요성 판단,
다시점 일관성, 과거 표면과의 연결 규칙 및 기존 방법 대비 성능은 이후 별도 검증 대상이다.
영역 가중치만 사용했다는 사실이 박사학위 방법론의 독창성을 자동으로 입증하지 않는다.
