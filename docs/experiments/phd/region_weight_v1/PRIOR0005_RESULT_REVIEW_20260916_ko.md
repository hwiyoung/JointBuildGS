## 1. 동일 마스크에서 prior 계수만 바꾼 비교

동일 Anchor8k, camera schedule, MVS .05, R1=4, native 보호를 유지하고
전역 prior 계수를 .005에서 .0005로 낮췄다. 각 지역 gate PASS를 확인했다.
아래 값은 뷰어에 연결된 대표 학습뷰에서 **두 조건 모두 유효한 동일 R1 픽셀**의
expected camera-Z depth다. 단위 m. 수직 높이 또는 독립 정확도가 아니다.

| 영역 / 영상 | 유효 픽셀 | MVS 평균 절대차 .005 → .0005 | 두 결과 차이 중앙값 |
|---|---:|---:|---:|
| P1 / 0100_D | 113,103 | 2.31664 → 0.03960 | 2.14980 |
| P2 / 0146_D | 330,875 | 0.07030 → 0.04925 | 0.01770 |
| P2 / 0108_D | 306,435 | 0.06924 → 0.04196 | 0.01665 |
| P3 / 0046_D | 477,074 | 0.06575 → 0.04095 | 0.01801 |
| P3 / 0142_D | 66,213 | 3.17915 → 3.17664 | 0.01710 |

P1은 MVS 10cm 이내 비율이 0.0115%에서 93.59%로 상승했다. 현재 지면 감독을
따르는 반응이 뚜렷하며, 현 설정에서 prior 손실의 경쟁이 보정을 제한했다는
가설을 지지한다. Gaussian 이동·opacity·표면 생성 중 무엇으로 실현됐는지는 미분리다.

P2 및 P3 사선뷰는 .005/R1=4에서 이미 대부분 MVS와 가까웠으며 추가 개선은
수 cm 수준이다. P3 0142_D의 중앙 절대잔차는 2.3228cm → 2.3220cm지만,
10m 초과 잔차 비율은 두 조건 모두 7.2025%다. 평균 약 3.18m는 지붕 전체가
3m 틀렸다는 뜻이 아니다. 해당 표본의 입력·가시성·표면 대응 점검이 우선이다.
결과는 다섯 대표 뷰의 관측이며 모든 카메라/건물의 정확도 평가로 일반화하지 않는다.

## 2. P1 지붕 끝 보존: 아직 확정하지 않음

과거 global-MVS/prior .0005 결과와 이번 regional-MVS/prior .0005를
같은 crop/카메라에서 비교한 그림은 `P1_mesh_matched.png`다.
끝부분의 국소 형상 차이는 보이나, 끝 지붕만 분리한 정확도·단면·결손 평가는
아직 수행하지 않았다. 그림상의 연속성이 정확도 향상을 뜻하지는 않는다.

참고로 0100_D의 **R2 건물 표면 전체**에서 과거 global → 이번 regional은:

- MVS 평균 절대차: 0.27955 → 0.32330m.
- MVS 중앙 절대차: 0.07761 → 0.07729m.
- 유효 prior 공통 픽셀의 prior 평균 절대차: 0.25504 → 0.24316m.

이 집계는 끝 지붕만의 수치가 아니며, 일관된 보존 개선의 근거가 되지 않는다.
과거 global은 감독 범위·공간 가중치와 동적 가중치 정책이 다른 맥락 비교군이다.
특정 마스크 요소 하나의 인과 효과를 분리한 ablation으로 해석하지 않는다.

또한 이번 .005 → .0005 변화는 R1에만 국한되지 않았다. P1 R2/R3의 depth 변화
중앙값은 각각 1.714m/2.109m다. prior 계수는 전역에서 낮췄고 다른 손실과
공유 Gaussian도 작동하므로, MVS 영역 가중치가 결과 변화 영역을 그대로 제한하지 않는다.

## 3. 해석 및 다음 검증

현재 가장 강한 근거는 P1의 지면 감독 반응이다. P2/P3의 작은 추가 반응은
이미 적합한 표면의 낮은 민감도와 양립한다. 원래 맞는 표면의 보존 확인에 활용하되,
가림·결측부 및 벽/지면의 mesh 변화는 별도로 점검한다.

우선 기존 결과의 같은 끝 지붕 범위와 단면을 고정해 과거 global 및 이번 regional의
높이 차이·결손을 함께 확인한다. 입력 적합도와 독립 UAS 표면 평가를 구분한다.
다음 학습 후보는 보정할 과거 표면에서만 prior .0005, 유지 표면에는 .005를
적용하는 비교다. 특히 P1 과거 지붕과 현재 바닥의 표면 대응을 분리하고 관련
모든 뷰에 일관되게 적용해야 한다. 이 문서는 추가 학습을 실행하지 않았다.
