# 전역 prior 0.0005에서 영역 가중치 반응 확인 — 제안

- `scientific_verdict: null`
- 상태: 사용자 질문에 대한 실험 설계 제안. 신규 학습 미실행.
- 현재 단계: 과거/현재 감독 조건 및 R1 카메라 포함 기준을 CPU로 재확인했다.
- 이전 [지역 prior 감쇠안](FOLLOWUP_PLAN_20260916_ko.md)에 앞서 아래 전역 계수 비교를 권고한다.
- 후속 질문 반영: 당장 필요한 비교를 **R1=4 고정, prior .005→.0005**로 축소했다.
  최초의 추가 9조건 제안은 필수 실행안이 아니며 α=0/1은 별도 질문이 생길 때의 선택 비교다.

## 1. 과거 결과는 어떤 비교에 쓸 수 있는가?

과거 P1 MVS prior .0005와 현재 수동 실험의 MVS binding SHA와 Anchor8k SHA는 같다.
과거 동적 옵션은 켜져 있었지만 `mvs_pgsr_trace.jsonl`에 기록된 MVS 계수는 모두 .05다.
따라서 동적 옵션 차이만으로 과거 결과를 비교에서 제외할 필요는 없다. 기록된 값과
모든 iteration에서의 실제 동일성은 구분한다.

그러나 현재는 픽셀 감독 범위도 다르다. P1 0100_D의 원래 유효 MVS 1,286,289픽셀 중
이번에는 수동 R1/R2/R3 571,461픽셀만 사용하고 714,828픽셀은 가중치 0이다.
나머지 97개 영상은 원래 감독을 유지한다. P2/P3는 모든 학습 영상에 영역 마스크를 적용한다.
R1은 α=0/1/4로 바꾸며, α=1도 전체 유효 MVS를 쓰던 과거 목적함수와 같지 않다.

과거 .005/.0005 결과는 기존 방식의 계수 민감도와 보정–보존 사례를 보여주는 비교 자료로
활용한다. 현재 마스크 조건에서 prior 계수만의 효과를 비교하려면, 현재 .005 결과와
동일 마스크/카메라/손실 정의를 유지한 .0005 결과가 필요하다.

## 2. R1 카메라 포함 기준

기존 14/57(P2), 74/137(P3)은 `r1_pixels > 0` 기준이다. 최소 관측 면적이나
3D 표면 커버율 조건을 적용하지 않았다. P3의 최소 사례는 1픽셀이다.

비율의 분모는 첫 카메라 방문 시 원래 유효 MVS 픽셀 수다. 건물 전체나 같은
3D 지붕점의 관측 커버율이 아니다. 아래 임계값은 설명용 집계이며 학습 기준 변경이 아니다.

| R1 / 원래 유효 MVS 픽셀 비율 | P2 영상 수 / 방문 수 | P3 영상 수 / 방문 수 |
|---|---:|---:|
| 0 초과 | 14 / 5,407 | 74 / 11,886 |
| 1% 이상 | 14 / 5,407 | 59 / 9,477 |
| 5% 이상 | 13 / 5,020 | 51 / 8,193 |
| 10% 이상 | 13 / 5,020 | 33 / 5,298 |
| 20% 이상 | 5 / 1,930 | 18 / 2,890 |

R1 포함 영상 중 비율의 최소/중앙값/최대는 P2 2.864/16.866/24.822%,
P3 0.000077/9.057/34.808%다. P1 0100_D는 8.793%이며 방문 225회다.
카메라 방문 수만으로 실제 gradient 크기나 같은 건물 부분의 충분한 지지를 주장하지 않는다.

## 3. 현재 권고: R1=4를 유지한 전역 prior 계수 비교

| 대상 | 대조: prior .005 / R1=4 | 추가: prior .0005 / R1=4 |
|---|---|---|
| P1 | 기존 결과 | 새 비교 1개 |
| P2 | 기존 결과 | 새 비교 1개 |
| P3 | 기존 결과 | 새 비교 1개 |

이 비교는 ‘현재 R1=4 감독을 유지한 채 prior를 약화하면 보정과 보존이 어떻게 달라지는가’를
직접 묻는다. 지역별 1개, 추가 총 3개 조건이다. P1을 먼저 확인하고 P2/P3로 이어간다.
이미 수행한 .005 조건은 재학습하지 않는다. 현재 질문에는 .0005에서 α=0/1까지
모두 실행할 필요가 없다. 최초 9개 제안은 prior와 α의 상호작용까지 보는 확장 설계였다.
이 문서는 실행 승인이나 큐 등록이 아니다.

고정할 요소:

- 각 지역의 동일한 complete Anchor8k부터 30k까지 refinement. 최종30k 결과에 추가 학습하지 않는다.
- MVS 원본·영역 mask·0인 영역·R2/R3=1 및 손실 분모 유지.
- MVS 전역 계수 .05 고정, 동적 조절 off, native 보호 유지.
- RGB/prior 관측과 카메라 순서, optimizer/RNG 복원, 추출·표시 조건 유지.
- prior의 지역 감쇠나 Gaussian 보호 완화는 동시에 도입하지 않는다.

핵심 해석과 선택적 추가 비교:

1. α=4를 고정한 .005→.0005: 전역 prior 약화의 효과와 주변 손상을 비교한다.
2. .0005에서 α=1은 ‘prior를 낮춘 뒤에도 R1 4배 강화가 필요한가’를 물을 때 추가한다.
   기존 수동 α=1은 prior .005이며, 과거 .0005의 전체 유효 MVS 감독은 현재 mask와 다르다.
   따라서 정확히 같은 .0005/현재 mask/α=1 조건이 이미 수행됐다는 뜻은 아니지만,
   현재 질문을 답하는 데 그 조건이 필수인 것도 아니다.
3. .0005에서 α=0은 ‘지정 R1 감독을 빼도 같은 보정이 되는가’를 물을 때 추가한다.
   α=0에서도 보정되면 RGB·다른 MVS 관측·기타 손실의 영향을 고려한다.
   α=0은 모든 MVS를 끈 조건이 아니다. 특히 P1은 다른 97뷰의 감독이 그대로 남는다.
4. 보정과 보존을 별도 측정하고, 둘 사이 절충이 확인되면 다음 단계로 지역 prior 감쇠를 비교한다.

P1은 과거 지붕/현재 지면과 끝 지붕 보존, P2는 넓은 지붕 면과 반복 구조,
P3는 신뢰 가능한 표본과 큰 불일치·결측을 분리한다. P3를 포함하여 MVS 적합도만으로
실제 정확도를 판정하지 않고 동일 단면·표면 및 독립 reference를 별도로 확인한다.
이번 원인 분리 중 입력 오류를 고쳐 mask를 바꾼다면 해당 .005 기준 조건도 재생성해야 한다.

## 4. 98개 학습 영상과 유효한 depth 감독의 구분

현재 train loop는 매 iteration에 한 카메라를 선택하고, 같은 시점에서 RGB/prior/MVS
손실을 계산한다. 매 iteration마다 98개 전체 영상을 처리하는 방식이 아니다.
0100_D는 P1 수동 R1 조작의 핵심 영상이지만, 나머지 영상의 RGB/prior 감독과 원래 MVS
손실은 유지돼 있다. 대상 지면의 MVS 관측이 약하다는 사실만으로 그 영상의 전체 학습
기여가 0이라고 할 수 없다. 0100_D가 유일한 인과적 기여원이라는 제거 비교도 아직 없다.

98개가 방법론적으로 필수인 것은 아니다. 그러나 이번 prior 계수 비교는 기존 대조군을
재사용하기 위해 카메라 집합과 순서를 유지한다. 학습 영상을 0100_D 한 장으로 바꾸면
22k iteration 기준으로 그 영상의 노출이 225회에서 22k회로 바뀌고 RGB/prior 제약도
함께 달라진다. 그 결과를 기존 98-view 결과와 비교해 prior 효과만으로 설명할 수 없다.
대표 뷰 집합으로 줄이는 별도 효율화 실험은 가능하지만, 축소된 집합에서 .005/.0005
대조를 모두 만들고 보정 면·유지 지붕·외벽의 관측 범위를 확인해야 한다.

학습용 RGB/prior 카메라 집합과 MVS 감독 카메라 선택은 분리할 수 있다. 다만 현재
구현에서 다른 depth를 끄거나 0100_D를 별도로 더 자주 감독하면 목적함수가 바뀌므로
이번 계수 비교와 동시에 바꾸지 않는다.

## 5. ‘실질적으로 작동한 감독’의 진단 기준

- `R1 > 0`: 감독 가능한 입력이 존재한다는 표시다. 실질적 보정 기여의 판정이 아니다.
- 첫 근사: 방문 수 × (유효 R1 픽셀 / 원래 유효 depth 분모) × R1 배율 × MVS 계수로
  카메라별 할당 가중량을 비교한다. 대상 영역별로 집계한다. 이는 현재 metric L1의
  표본 가중 구조를 반영한 값이며 실제 Gaussian gradient 크기나 이동량이 아니다.
- 함께 볼 것: 같은 목표 표면의 관측 범위·다시점 지지·가림·MVS 신뢰성. 영상 전체의
  1%여도 핵심 보정면 대부분일 수 있고, 20%여도 목표 면과 무관할 수 있다.
- 실제 작동 확인: 동일 상태에서 해당 depth 항이 대상 Gaussian의 위치/회전/크기/opacity에
  주는 gradient를 나누어 확인하고, 필요한 경우 같은 조건의 포함/제외 비교로 실제 결과를 확인한다.
  강한 gradient가 정확한 방향의 보정이나 최종 순효과를 보장하지 않는다.
- 5%/10%는 현황을 설명하는 집계 기준이며, 카메라 채택의 보편적 임계값으로 쓰지 않는다.
