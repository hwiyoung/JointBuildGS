# 기존 전역·영역별 감독 결과의 국소 검증

## 결과

주 비교는 **prior .0005에서 과거 전역 MVS 감독 → 이번 영역별 MVS 감독**이다.
P1의 사용자 지정 대상은 뷰어에서 바닥 옆에 길게 보이는 지붕 띠와 양끝이다.
세 지역 모두 완료된 30k 결과이며 신규 학습·입력 변경 없이 CPU로 평가했다.

아래 값은 동일한 원본 UAS 관측점에서 원본 TSDF512 mesh의 가장 가까운 삼각형까지
평균 거리다. 단위 cm. 같은 원본 row ID를 조건 간 공유했다. 수직 높이 오차는 아니다.

| 부위 | UAS 점 수 | 전역 .0005 | 영역별 .0005 | 영역별 .005 참고 |
|---|---:|---:|---:|---:|
| P1 보정 지면 | 45,576 | 12.1 | **9.9** | 68.7 |
| P1 지붕 띠 전체 | 16,387 | 64.2 | **54.5** | 22.8 |
| P1 빨간 끝 / local 서측 | 2,015 | 52.9 | **46.9** | 12.2 |
| P1 주황 중앙 | 7,666 | 74.8 | **72.2** | 24.4 |
| P1 파란 끝 / local 동측 | 6,706 | 55.6 | **36.6** | 24.2 |
| P2 대상 지붕 | 270,833 | 26.1 | **24.1** | 26.4 |
| P3 대상 지붕 | 229,168 | **16.7** | 19.6 | 12.2 |

### P1

- 지면 보정을 유지하면서 지붕 띠 손상이 부분적으로 줄었다는 관찰을 뒷받침한다.
  파란 끝의 개선이 가장 크고, 중앙은 변화가 작다. 파란 끝의 GT 50cm 이내 비율은
  62.3%→76.5%, 빨간 끝은 47.6%→59.3%다.
- prior .005 결과의 지붕 띠 평균은 22.8cm다. 이번 54.5cm는 이보다 크므로
  보정–보존 절충이 해소된 것은 아니다. 남아 있는 낮아진 표면과 결손은 단면에 표시했다.
- 전체 P1 관측점 평균은 74.9→84.9cm로 증가했고, 50cm 이내 비율도
  58.1%→55.1%로 낮아졌다. 국소 개선을 P1 전체 개선으로 확대하지 않는다.
- 위에서 쏜 수직 ray의 첫 표면 Z와 UAS Z 차이도 별도 저장했다. 지붕 띠 중앙
  절대 높이차는 50.5→44.5cm이나 일부 XY에서는 지붕 대신 낮은 표면이 남아 있다.

### P2

- 주 지붕의 소폭 개선이다. 중앙 GT 거리는 19.3→16.0cm, GT 50cm 이내 비율은
  85.8%→85.9%다. 큰 형상이 비슷한 관찰과 양립한다.
- 지붕 GT 점의 16.9%는 거리가 10cm 넘게 감소했고, 8.2%는 10cm 넘게 증가했다.
  능선·골 경계와 주변부의 오차가 남아 있으며 전체가 균일하게 개선된 것은 아니다.
- 전체 지역 평균은 40.5→35.3cm지만 중앙값은 17.5→19.5cm,
  50cm 이내 비율은 79.0%→76.7%다. 평균만으로 주변부 보존 성공을 주장하지 않는다.

### P3

- 주 지붕 평균 16.7→19.6cm, 중앙값 8.9→10.7cm로 악화했다.
  GT 50cm 이내 비율은 90.8%→89.8%다.
- 지붕 GT 점의 4.4%는 거리가 10cm 넘게 감소했지만, 15.6%는 10cm 넘게 증가했다.
  공간 지도에서 지붕 길이 방향의 일부 띠에 악화가 나타난다.
- 전체 지역 평균도 50.5→60.1cm로 증가했다. 현 결과를 영역별 감독의 보존 성공으로
  분류할 근거가 없다. 마스크/관측 신뢰도 정책의 한계를 분석할 사례다.

## MVS 입력과의 일치도

아래는 동일 학습뷰의 동일 R1 유효 픽셀에서 expected camera-Z depth 평균 절대차다.
GT 표와 표본 및 거리 정의가 다르다. 단위 cm.

| 영상 | 전역 .0005 | 영역별 .0005 |
|---|---:|---:|
| P1 0100_D | 8.9 | 4.0 |
| P2 0146_D | 6.5 | 4.9 |
| P2 0108_D | 5.4 | 4.2 |
| P3 0046_D | 9.2 | 4.1 |
| P3 0142_D | 319.3 | 317.7 |

P3 사선뷰의 MVS 적합도와 대상 지붕의 GT 오차는 서로 다른 표본이다.
이를 같은 표면점의 인과관계로 해석하지 않는다. 상공뷰의 큰 평균 역시 소수 큰 잔차의
영향을 받으며 지붕 전체의 수직 오차를 뜻하지 않는다.

P1 지붕 띠의 MVS 좌표가 고정 3D 평가 범위에 들어가는 픽셀에서는 MVS 차이가
31.0→36.8cm로 증가한 반면 GT 거리는 감소했다. 두 측정은 표현과 표본이 다르며,
MVS 일치도 하나로 보존을 판정하지 않아야 한다는 점을 보여준다.

## 비교·평가 계약

- 동일 Anchor SHA와 native 보호, prior .0005 및 지역별 TSDF 추출 설정을 확인했다.
  P1 과거 전역의 기록된 MVS 계수는 .05, P2/P3는 .0475/.05이며 이번은 고정 .05다.
  따라서 기존 두 정책 전체의 결과 비교로 사용하고 마스크 하나의 효과로 분해하지 않는다.
- 원본 `reference.npz`의 SHA를 기존 뷰어가 결박한 reference SHA와 대조했다.
  0.1m fixed-origin voxel 중심에 가장 가까운 원본 UAS 점을 선택했다.
  원본 좌표와 raw row ID가 정확히 동일한지 검증했다. display point cloud는 scoring에 쓰지 않았다.
- 원본 raw mesh의 SHA를 추출 receipt와 대조했다. 평가에는 전체 원본 mesh를 사용했다.
  crop·재정합·보간으로 표면을 바꾸지 않았다.
- XY/Z 평가 범위는 거리 측정 전에 고정했다. P1 지붕 띠의 양끝은 표시된 구간의
  양끝이며 실제 건물 전체의 끝선으로 확정한 범위가 아니다. 사진과 좌표 도면에 표시했다.
- UAS는 평가에만 사용했다. 학습 마스크·가중치·입력·결과는 변경하지 않았다.
- GT→mesh 단방향 거리는 관측 표면의 적합도를 측정한다. 관측이 없는 영역의 정확성,
  모든 과잉 표면, 독립적인 일반화 성능은 판정하지 않는다. 반복 실행 변동도 미측정이다.
- 기술 검증 PASS, `scientific_verdict: null`.
