## 2. 확인된 기제와 노출

- 모든 조건은 prior 계수 0.005, MVS 전역 계수 0.05, native 보호를 유지한다.
  prior loss에는 이번 R1/R2/R3 분할에 따른 지역 감쇠가 없다.
- R1 배율은 가중 합을 원래 뷰의 유효 MVS 표본 수로 나눈 metric L1에 적용된다.
  가중치 합으로 재정규화하지 않는다. 실제 첫 prediction에서 α=4 R1 depth-loss
  미분 4배 검사를 통과했다. Gaussian 변위가 4배라는 뜻은 아니다.
- P1 α=1의 22,000 refinement step 중 0100_D 방문은 225회(1.023%)이다.
  0100_D R1은 원래 유효 depth 표본의 8.793%다. 나머지 카메라 depth는 원래 조건 유지다.
  이 빈도만으로 나머지 97뷰가 모두 같은 지붕을 반대로 감독한다고 해석하지 않는다.
- P2는 R1 유효 표본을 가진 뷰가 14/57개이며 그 뷰 방문은 5,407회다.
  P3는 74/137개, 11,886회다. 이는 어떤 R1 표본이든 있는 뷰의 수이며,
  동일 지붕점의 다시점 지지 횟수와 다르다.
- native 보호는 prior 근접 Gaussian의 xyz/rotation/scale gradient에 0.01을 적용하고,
  해당 Gaussian을 clone/split/pruning 후보에서 제외한다. optimizer 이후 이동량이
  100분의 1이라고 해석해서는 안 된다. SH/opacity는 이 hook으로 동결되지 않는다.
- 렌더러의 `depth_ratio=0`은 누적 기여를 alpha로 나눈 expected depth를 사용한다.
  따라서 depth 적합도 개선만으로 특정 지붕 Gaussian의 제거, 단일 지면 표면 생성,
  평탄화가 입증되지 않는다. normal 정규화도 전역적인 평면 강제 조건은 아니다.

## 3. 결과별 해석

### P1

강화한 한 뷰의 MVS 신호, 유지된 prior 감독, native 보호가 함께 작동한다.
현재 수치는 부분적인 depth 반응과 주변 적합도 악화를 보인다.
prior 계수의 영향, 보호의 영향, RGB·다른 뷰·표현/최적화의 영향을 현재 비교로
분리하지 못한다. prior 적용 면적만으로 지붕 유지의 원인을 확정하지 않는다.

### P2

두 기준뷰에서 0→1의 변화는 크고, 1→4는 남은 오차를 줄인다.
따라서 ‘가중치가 안 먹는다’보다 ‘α=1에서 이미 상당 부분 MVS에 맞고,
α=4의 추가 변화는 국소적’이라는 설명이 현재 입력 진단에 부합한다.
1↔4 R1 depth 차이 중앙값은 두 뷰에서 각각 4.38/4.18cm다.
뷰어의 raw TSDF voxel 크기는 약 50.45cm라 작은 차이가 눈에 덜 띌 수 있다.
voxel 크기는 sub-voxel 변화가 불가능하다는 임계값이 아니며 추출 영향은 추론이다.

### P3

사선뷰의 R1은 P2처럼 입력 적합도가 크게 개선됐다. 상공뷰 0142_D는
α=4에서 평균 3.179m, 중앙값 0.02323m, 95백분위 41.90m이다.
66,213픽셀의 84.75%가 MVS와 10cm 이내이고, 7.20%의 10m 초과 잔차가
절대잔차 합의 92.35%를 차지한다. 따라서 평균만으로 지붕 전체의 미보정을
주장할 수 없다. 작은 잔차 부분과 큰 불일치 부분을 나누어 해석한다.
예시 픽셀 (626,232)은 MVS 112.41m, prior 52.46m, GS α=4 52.44m다.
여기서 MVS의 3D 점은 기존 뷰어 범위 밖(z=-79.14m)에 있다. 해당 범위 안의
MVS 점에 한정한 51,125픽셀도 평균 0.736m, 중앙값 0.02197m로 분포가 비대칭이다.
범위 밖 또는 큰 잔차라는 사실만으로 MVS 오류·prior 정확성을 판정하지 않는다.
0142_D native MVS·가중치 도면에는 지붕 결측이 많고, 유효 R1은 원래 유효
depth의 약 5.34%뿐이다. α는 결측 픽셀에 새 감독을 만들지 않는다.
큰 잔차가 생긴 위치의 입력 depth·표면 대응·다시점 지지를 먼저 점검하고,
그 이후 prior/보호 및 실제 기여 Gaussian의 영향을 판단한다.
