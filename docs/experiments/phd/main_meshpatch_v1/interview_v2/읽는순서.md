# 면담 빈칸 묶음 읽는 순서

맨 앞 `진행.md`의 완료 수와 보류 목록부터 확인한다. 완료되지 않은 값은 0이 아니다. 파일이 아직 없는 항목은 진행 중 또는 대기이며, 생성된 상태 파일의 `PASS`만 계산 완료다. `PARTIAL`은 일부만 확인됐다는 뜻이다.

1. 기존 메시 정리와 네 값: `tables/mesh_comparison.md`, `tables/axes_four_values.md`, `tables/axes_comparison.md`. 정리 전과 후를 같은 줄의 대상끼리 비교한다. `before`는 지금 채점 메시, `after`는 원래 GeoGS 함수로 정리한 메시다.
2. 새 그림: `interview_v2/figures/`의 보존·상속·비교 사례. 시점 1·2는 같은 자리의 두 고정 카메라다. 사진은 기존 학습 사진이고, 사람의 구조 판정은 확인 전 `모름`이다. 그림 아래 비율의 원본은 `interview_v2/tables/figure_*.csv`다.
3. 비교 방법: `interview_v2/tables/comparison_scores.md`와 `comparison_status.json`. 메모리 보류도 대상 이름을 유지한다. 기존 B0·B173 완료 값은 다시 계산하지 않는다.
4. 추가 집계: 같은 폴더의 `axis_curves.csv`, `missing_invisible.csv`, `boundary_spread.csv`, `lod2_four_way.csv`, `gaussians-*.csv`. 모든 비율은 해당 행의 넓이 분모를 확인한다. 면적 단위 m², 거리 단위 m, 각도 단위 도다.
5. 가상 메시: `virtual-*_walls.csv`, `virtual-*_missing_reclassified.csv`. 학습 종료·자원 입장·벽 92.3% 재현 점검을 통과한 경우만 계산한다.

정성 그림의 색은 결과 첫 면까지의 부호 있는 법선 거리다. 파랑은 참값 안쪽, 빨강은 바깥쪽이며 ±0.5 m에서 색만 포화된다. 수치 평균을 자르는 규칙이 아니다. 그림의 주변 맥락과 아래 숫자의 패치 분모는 구분하며, 분모는 캡션과 CSV에 적는다.

영역 코드는 이미 납품된 패치 표의 지역별 연결 열만 사용한다. 연결되지 않은 것은 `확인 불가`다. 가시 학습 사진 수는 기존 stage-0 사전 면의 양수 화소 관측 쌍이며, 학습된 가우시안으로 가시성을 다시 계산한 값은 아니다.

네 가지 진단 이름은 사용자가 지정한 구분이다. `정상 / 반영 실패 / 2단계가 뒤집음 / 1단계 탓`을 인과관계가 입증됐다는 뜻으로 해석하지 않는다. 해석·논문 결론은 검토자의 판단에 남긴다.

ZIP의 CRC·SHA-256·파일별 해시는 전송 무결성을 검증한다. 재계산에는 코드에 기록된 원본 외부 저장소와 Docker 실행 환경이 필요하다. 큰 원본 메시·사진·가우시안은 이 ZIP에 중복하지 않는다. 입력·출력·정의의 해시는 `provenance.json`, `checks/`, `configs/`에 기록한다.
