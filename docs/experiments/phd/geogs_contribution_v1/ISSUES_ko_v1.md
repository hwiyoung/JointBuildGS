# GeoGS 기여 탐색 v1 — 실패·확인 한계

1. **전문 미확보:** ScienceDirect HTML/PDF 403, Elsevier FULL 401, KIT pdf_url=null. 초록·코드 확인을 논문 전체 검토로 표현하지 않는다. 저자의 실험표·향후 과제는 미확인이다.
2. **외부 디렉터리 검색:** 최초 artifact 전체 `rg --files`에서 기존 다른 phase의 접근 권한 오류와 과도한 출력이 발생했다. 권한을 변경하지 않고 manifest와 새 패키지 경로로 탐색을 좁혔다.
3. **공식 예제 다운로드: 해결.** 첫 요청은 ZIP이 아니라 Google Drive의 대용량 파일 확인 HTML(918 MB 안내)이었다. 공개 confirmation form을 따라 963,110,591-byte ZIP을 확보했다. 55개 파일 중 작은 메타데이터만 읽었으며 전체 payload CRC 검사·배열 품질 검사·훈련은 하지 않았다. HTTP Content-Length와 받은 크기는 일치한다.
4. **합성 제어 진단의 한계:** 진단은 공식 제어 노드와 hook을 실행했으나 GS 렌더러·장면 학습·표면 추출을 실행하지 않았다. 실제 prior 오류·시간차 성능·알고리즘 우위를 입증하지 않는다.
5. **입력 계약:** GeoGS의 LoD2와 우리 ALS의 연결은 아직 원방법과 동일하지 않다. 동일한 변환·참조 배제·관측 분할을 고정하기 전에 ALS 비교를 원방법 재현으로 표시하지 않는다.
6. **기여 미확정:** SRDM/Zhou+현대 재구성의 강한 조합을 아직 실행하지 않았다. 제어 진단에서 확인한 차이는 기여 후보를 좁히는 근거이며 `scientific_verdict: null`이다.
7. **예제 계보의 미확인 부분:** 실제 저자 실행 인자·DA3 추론 membership 기록·원 LoD2 mesh가 없다. 기본값에서 13/2뷰 분할을 유도했지만 저자 실행 분할과 동일하다고 확정하지 않는다. 제공된 파생 입력을 사용한 재현과 전처리 전체 재현을 구별한다.
