## 결론

현재 수동 보정 영역 R1은 `DJI_20241217084553_0100_D.JPG`에서만 정의했고,
남은 R1 native 픽셀 표본의 **77.84%**가 이 시점에 있다. 보정 지면에 대한
감독 초안이 한 장 중심이라는 사용자의 우려는 근거가 있다.

다른 영상에도 P1 지면의 MVS depth는 있지만 가림과 결측 때문에 관측 범위가
작다. 대표 0 시점의 지면을 좌표 기준으로 삼는 전파 조건도 추가로 표본을 줄인다.
따라서 다른 MVS 전체를 부적합하다고 단정하거나, 회색 영역을 모두 MVS 결측으로
해석하면 안 된다. 기존 학습은 선택된 카메라 이름에 해당하는 자체 depth를 사용하고,
이번 수동 마스크는 아직 학습에 연결되지 않았다.

## 1. 현재 초안의 첫 시점 의존

| 표본 단위 | 첫 시점 R1 | 전체 R1 | 첫 시점 비중 |
|---|---:|---:|---:|
| native MVS 픽셀 | 60,438 | 77,646 | 77.84% |
| RGB로 nearest 조회한 픽셀 | 113,103 | 145,329 | 77.83% |

서로 다른 시점의 픽셀 수는 투영 크기와 표본 밀도의 영향을 받는다. 이 비중은
고유 3D 면적, 실제 loss 크기, gradient 기여율 또는 학습 기여율이 아니다.
R1 표본이 존재하는 시점 19개에는 몇 픽셀의 극소 조각도 포함된다.

## 2. 같은 지면 표본을 다른 모든 시점에서 조회

첫 시점 MVS에서 얻은 동일한 3D 표본을 나머지 97개 카메라에 투영했다.
각 투영 위치의 원본 native MVS 존재 여부, 기준면과 camera-Z 차이, 기준 영상으로
되돌린 재투영 차이, 현재 최종 R1 label을 각각 따로 계산했다.

기존 **30×30m P1 안의 R1**에 해당하는 기준 표본은 **23,118개**다.
이 표본 중 기준면과 **depth 차이 ≤0.5m 및 기준영상 재투영 차이 ≤2 native px**를
만족한 비율은 다음과 같다.

| 다른 시점에서의 일치 | 기준 표본 중 비율 |
|---|---:|
| 적어도 1개 다른 시점 | 34.20% |
| 적어도 2개 다른 시점 | 22.17% |
| 적어도 3개 다른 시점 | 15.88% |
| 다른 시점에서 확인되지 않음 | 65.80% |

가장 높은 개별 시점도 index 92 `DJI_20241217103051_0002_D.JPG`의 **11.87%**다.
index 93은 11.70%, index 97은 10.58%다. 다른 시점은 첫 시점의 지면 전체를
비슷한 수준으로 관측하고 있지 않다.

전체 80×80m 문맥 내 R1 기준 표본 60,438개로 범위를 넓히면 다른 시점 하나
이상과 일치하는 비율은 54.73%다. 이 수치는 기존 P1 내부의 34.20%와 구분한다.
원본 MVS XYZ가 기존 P1 prism 안에 하나라도 들어오는 시점은 46/98개이지만,
그 자체로 보정 지면이 충분하거나 정확하게 관측된다는 뜻은 아니다.

## 3. 가림과 전파 제한의 구분

index 92에서 기준 지면의 투영 위치 중 96.93%에 depth 값이 있지만, 82.95%는
기준 지면보다 가까운 관측이고 depth 차이 ≤0.5m는 13.92%다. 원 RGB와 depth를
함께 보면 전경 건물에 가려진 지면을 건물 depth가 대신 차지하는 현상과 부합한다.
깊이 부호만으로 가림과 MVS 오류를 완전히 구분한 결과는 아니다.

index 82·83에서는 RGB에 보이는 광장 일부가 원본 MVS부터 결측이다.
index 92·93·96·97에는 광장 depth가 남아 있고, 전파 후에는 그중 일부만 R1로
유지된다. 회색/유보에는 실제 결측 외에 미분류, 경계, source 간 충돌과 기하 검사
탈락도 포함된다.

이번 공통 표본의 전방 투영 진단과 기존 target-pixel 기준 역방향 label 전파는
서로 다른 검사다. 따라서 두 비율의 차이를 모두 잘못 버린 관측의 비율로 해석하지 않는다.
