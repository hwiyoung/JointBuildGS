# 기존 비교 방법 메시 출처 확인

scientific_verdict: null

기존 AXES71-v2의 전체 줄은 학습 영상 메시를 쓴다. 보통 칸도 같은 메시를 쓰고, 두 관측 불가 칸(c_inh_invis, c_invis_wrong)은 별도 가상 시점 메시를 쓴다. 화면 크기 정리 모의는 열두 칸·세 합계·전체에 학습 영상 메시 하나를 썼다.

| 방법 | 사전 정보 | 기존 전체 R(τ) % | 기존 전체 P(τ), 셈 마 % | 모의 값과 정확히 같음 | 학습 영상 수 | TSDF m |
|---|---|---:|---:|---|---:|---:|
| geogs_ALS_fix1 | ALS | 54.74095331 | 47.92004287 | True | 203 | 0.05 |
| trust_LoD2_fix1 | LoD2 | 55.34191051 | 59.44830832 | True | 203 | 0.05 |
| imgonly_2dgs_s0 | ALS | 39.97773431 | 41.99856431 | True | 203 | 0.05 |
| imgonly_2dgs_s0 | LoD2 | 47.93909682 | 51.58348744 | True | 203 | 0.05 |

따라서 발주문의 GeoGS 항공 LiDAR 54.7 / 47.9와 2DGS 40.0 / 42.0은 항공 LiDAR τ로 센 전체 줄이다. 해당 전체 줄은 소수 첫째 자리뿐 아니라 저장된 비반올림 값도 같다. 전체 줄의 같음으로 관측 불가 칸의 메시까지 같다고 볼 수는 없다.
