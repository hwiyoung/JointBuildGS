# r7 이어 학습 실행 오류 중단 기록

- 기록: 2026-11-01T21:43:50.383572+09:00. scientific_verdict: null.
- 항공 LiDAR의 역전파에서 CUDA 메모리 부족이 발생했다. 추가 64 MiB 할당 요청 시 여유 38.19 MiB, PyTorch 할당 22.51 GiB였다.
- 오류는 진행 표시 14,160회 직후다. 오류 반복 자체를 담은 OOM 전용 기록은 설정상 꺼져 있어 정확한 반복 번호는 확인 불가다.
- 공용 중단 제어가 LoD2도 종료했다. 자동 재학습은 하지 않았다.
- 두 판 모두 15,000·30,000회 상태와 메시가 없다. 재개 가능한 완전 저장 상태는 원래 7,000회다.

## 감시 구현 기록

- 동결된 r21의 가우시안 수 3배 검사는 `iteration == 7000`에만 실행된다. 항공 LiDAR의 14,100회 수는 6,000회의 3배를 넘었지만 이 조건은 그때 실행되지 않았다. 실제 중단 원인은 이후 CUDA 메모리 부족이다. 이어 학습에서 이 조건을 바꾸지 않았다.
- 이 한계를 건강 검사 통과로 해석하지 않는다. 추가 학습은 사용자 후속 결정 전까지 중단한다.

## 계속 수행하는 읽기 전용 작업

- r6·r7·기존 방법의 7,000회와 기존 기준선 30,000회: 8개 저장 모델 × 두 메시 = 16개 메시 채점.
- 도달하지 못한 r7 15,000·30,000회 두 판 × 두 메시 = 8개 줄은 결과 없음으로 기록.
- 기존 기준선 재채점과 항공 LiDAR 설정·계보·뜬 면 진단, 확인 가능한 자료의 전달 묶음을 마무리한다.
- 나머지 여섯 판은 시작하지 않았다. 결론과 해석은 쓰지 않는다.
