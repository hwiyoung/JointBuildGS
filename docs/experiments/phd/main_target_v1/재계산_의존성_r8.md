# r8 재계산 의존성 [이 발주에서 냄]

작은 전달 ZIP에는 코드·설정·표·그림·검증 기록이 들어간다. 원본 S0/S1/UNCERT, 잠긴 r7 목표/지도, 모델·메시·거리 배열, 실행 Docker 이미지는 외부 자료와 함께 사용해야 한다. 전체 자료 백업이 아니다.

출신별 최대 기여를 구하는 `r5/runtime/maxid_build/jbgs_target_r5_maxid.so`는 기존 진단 확장을 그대로 쓴다. 학습 모듈에는 넣지 않는다. `configs/phd/main_target_v1/diagnostic_runtime_r8.json`에 라이브러리, 빌드 명령, 모든 소스 파일의 바이트 수와 SHA-256을 남겼다. 원래 소스와 변경한 forward.cu의 해시를 검증했다. 진단 실행 때는 각 시점의 저장 깊이 203장을 바이트 단위로 재현해야 한다.

라이브러리 SHA-256: `f5f3b5a36e73bbcd56c4054c7fe3166370f0a482d88c4d918116e56402cbed00`.

이미지: `sha256:ff4eba02c450573e3258ec4946b9c536f32c213dde9abc83ee2969aaf18384be`. `prepare_maxid_r5.py`는 원 이미지의 렌더러에서 진단 출력을 만드는 절차이며 ZIP의 scripts 폴더에 포함된다. 위 r5/runtime 외부 자료의 경로와 해시를 확인한 뒤 같은 확장을 사용한다.

CRC와 SHA-256은 전달 무결성 검증이며 과학적 결론을 뜻하지 않는다. scientific_verdict: null.

기존 방법 7,000회의 출신 지도는 PLY의 origin·init_id를 사용한다. init_id로 원래 씨앗의 출신을 대조했고, 두 판 각각 203개 영상의 깊이·불투명도를 기존 저장 값과 바이트 단위로 재현했다. 같은 기여 정규화·0.25 m 가시성 규칙으로 첫 교차점에 연결했다. 기준선에는 풀림 제어가 없어 해당 채널은 해당 없음이다. 원본 모델·기하 채점은 변경하지 않았고, r8/baseline_origin에 덧붙인 결과와 독립 전수 투영 검증을 보존한다. 앞선 기준선 회색 지도는 미집계 초안으로 별도 보존한다.

7장 틀의 거리 배열은 기존 AXES71-v2 연결 코드(axes_adapter)를 그대로 호출한다. 이 코드가 거리 파일의 부속 JSON에 쓰는 `method: meshpatch`와 `GeoGS cleanup before/after` 문구도 그대로 남아 있다. 이 문구만으로 메시 종류나 추가 정리 여부를 판단하지 않는다. 실제 입력은 각 채점의 `binding.json`과 `values.json`에 기록한 메시 경로·SHA-256·`mesh_kind`(current/final)로 확인한다. current는 지금 채점 메시, final은 원래 최종 메시 정리 규칙으로 만든 메시다.

일부 재사용 실행기의 완료 로그는 `SCORE_7000` 또는 `POST7000_VERIFIED`라는 과거 표제를 쓴다. 15,000·30,000회에도 같은 문자열이 찍힐 수 있다. 실제 반복은 결과 폴더, `score.json`의 `iteration`, 독립 검증 영수증의 반복·파일 해시로 확인하며, 각 표와 그림은 그 실제 반복으로 생성했다.

r7 이어 학습은 원래 r21 포크를 변경하지 않았다. 그 포크가 포함된 앞 전달 묶음은 `PH/main_target_v1/PHD-MAIN-TARGET-v1/handover/PHD-MAIN-TARGET-v1_점검r7_1101-2038.zip`이며 SHA-256은 `23f9e16b45716328e63f9f00e50dcfd9ab8c1deac741c7735b2cb322c591d0e0`다. 이번에 원본 ZIP 해시도 다시 확인했다. 새 이어 학습 묶음은 이 포크·잠긴 입력을 전제로 한 추가 보고와 채점 코드를 담는다.

7장 틀 CPU 거리·축 채점은 `jointbuildgs:dev` (`sha256:251f83c17879a83b0c3dda5b9d71cbf45ca72cc0fdcbc89994194dc3edb86774`)를 쓴다. 그 밖의 r8 학습·렌더·현재/최종 메시 실행은 위 GeoGS 이미지다. 최종 전달 시 두 태그가 앞선 단계 0 이미지 잠금과 단계 1 버전 목록(`tables/stage1_environment.json`)의 이미지 ID와 같은지 대조했다(`r8/verification/image_tags_final.json`). 이 기록은 최종 대조이며 사전 잠금으로 소급 표기하지 않는다.
