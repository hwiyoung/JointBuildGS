# 화면 크기 정리 모의 자료

최종 보고서는 [화면크기_정리모의.md](../화면크기_정리모의.md)다. **`report_receipt.json`이 PASS가 되기 전에는 계산 중인 자료**이며, 개별 파일이 있다는 사실만으로 전체 완료를 뜻하지 않는다. 완료판은 저장 상태 8개, 렌더 8,120회, 현재 메시 40개, 채점 구분 45개, 열두 칸·세 합계·전체의 720줄이다. 영상만 2DGS의 같은 메시를 두 사전 정보의 기존 칸 구분으로 세므로 메시 수와 채점 구분 수가 다르다.

- `tables/`: 표와 계산·대조 기록. 일반 표는 md·json·csv, 무결성 및 검산 receipt는 json이다.
- `figures/`: 같은 그림의 png·pdf·json. JSON에 원수치와 시점·눈금 정의가 있다.
- `patches/`: 다섯 구현의 **미적용** 수정안. 문턱은 비워 두었다.
- [원자료 열 설명](원자료_열_설명.md): 행 번호, 단위, 외부 배열과 표의 연결.
- [참값 칸 이름과 합계 구성](tables/cell_definitions.md): 기존 AXES71-v2의 열두 칸·합계 세 줄 이름을 그대로 옮긴 대응표.

ZIP 밖에 별도로 제공하는 `handover_receipt.json`(ZIP 옆에서는 같은 이름의 `.receipt.json`)은 CRC와 내부 SHA-256 검사 결과다. 수치 검산과 파일 무결성은 서로 다른 확인이다. scientific_verdict: null.
