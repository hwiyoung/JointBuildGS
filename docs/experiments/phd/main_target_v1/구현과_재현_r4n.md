복제·분할·제거의 init_id·origin 상속은 r18에서 물려받은 구현을 그대로 사용한다. 실제 GPU 상속 검사와 기본 끔 경로 AST 동등성 검증을 통과했다. λ·학습률·밀도 제어·크기 상한 없음·불투명도 재설정·목표 폭·수치 허용치는 변경하지 않았다.

원래 r4 실행은 6,100회 float32 상쇄오차 검사로 두 판을 중단했다. 당시 실패 텐서는 없고 6,000회 실제 자료를 이용한 별도 재현만 있다. r4n은 묶기와 검사 중간 정밀도를 고친 새 잠금이며 앞 실행은 보존했다. 상세는 normal_projection_diagnosis_r4.json과 runtime_bounds_r4n.json이다.

잠금: target_v1.stage1.r4n.json 및 target_v1.runtime.r4n.lock.json(110개 파일), execution_r4n.code.lock.json(학습·메시 실행 코드). 입력 지도는 r2의 1,838장과 인덱스 SHA-256이다. 학습 전 r3 렌더는 별도 982장 재계산에서 같은 값을 확인했다.

도커 이미지: jointbuildgs:geogs-conf-guided-v1, ID sha256:ff4eba02c450573e3258ec4946b9c536f32c213dde9abc83ee2969aaf18384be. 실제 실행 명령·GPU·시작 시각·종료 코드·코드 해시는 각 r4n/runs/*에 기록한다. LoD2 종료 137은 공동 중단에 따른 docker stop이며 메모리 부족 판정이 아니다.

7,000회 저장은 그 반복 갱신·폭 묶기 뒤, 해당 반복의 밀도 제어 전에 이루어졌다. 목표 따름 실패가 건강 기록보다 먼저 발생해 health_7000.json은 없다. 마지막 곡선은 6,900회이며, 저장된 7,000회 모델의 수·불투명도·폭을 독립 재집계해 별도 표시한다.
