# P1·P2 실행과 P1·P2·P3 공통 비교 프로토콜

2026-09-07 · 사용자 요청: 융합 전후와 레퍼런스를 함께 보고, 변화된 P1/P2도 Wu–Vallet으로 실행하며 논문 개선 의도에 근거해 분석한다. `scientific_verdict: null`.

기존 연구·실험·서비스를 보존하고 `wu_vallet_regions_v4`를 추가한다. 새 연구 기여를 전제하지 않는다. 이 작업은 GS 없는 원문 기반 점군 갱신과 그 평가이며, 저자 코드·PSMNet·실측 ALS 궤적을 갖춘 완전 재현은 아니다. 이전 v3 작은영역 필터 교정을 주 구현으로 사용한다.

## 고정 입력과 실행

| 지역 | X 범위(m) | Y 범위(m) | Z 범위(m) | 기존 ALS | 별도 native OpenMVS |
|---|---|---|---|---:|---:|
| P1 | [-23,7) | [-21,9) | [-44.272,-25.962) | 20,189 | 139,033 |
| P2 | [110,158) | [86,132) | [-49.386,-17.679) | 45,986 | 330,679 |
| P3 | [-60,-20) | [-42,12) | [-49.223,-16.993) | 52,762 | 865,108 |

기존 개발 prism을 반개구간 그대로 재사용하며, 참조를 본 뒤 crop을 바꾸지 않는다. 좌표는 scene-local, world shift `[690953,5336071,604]m`, 작업 표기 EPSG:25832다. ALS의 기존 +45.7m 수직 변환을 유지한다. UAS reference는 원본 수치 좌표에서 같은 world shift만 빼며 재정합·datum/epoch 보정은 하지 않는다.

P1/P2는 각각 원래 동결된 113/66개 영상에서 기존 P3 해시 선택 규칙의 40개 후보를 확인한다. 참조·영상 유사도 점수를 사용하지 않고 최초로 영역 내 native mesh 64면 이상을 지지하는 master를 선택한다. 실제 P1은 image838, P2는 image295이며 모두 hash rank2다. 모든 40개 후보의 지원량도 기록한다. P3는 기존 image133의 점군 결과를 정확히 재사용한다. 단일 master 지원의 차이는 지역 간 순위의 교란요인이므로 각 지역 안의 같은 입력 전후를 비교한다.

ALS 원행→GPS time→pulse→scan 순서를 재생하고, 기존 다중반사 궤적 추정의 5설정×2strip을 그대로 적용한다. 추정은 실측 궤적의 대체이며 내부 holdout/재표본화 안정성을 절대 궤적 정확도로 부르지 않는다. 지원되지 않은 sensor origin을 임의로 채우지 않는다.

양방향 판정 문턱 0.3m, native image adjacency mesh의 길이·depth jump, ALS scan mesh의 연결 간격은 P3와 같은 설정이다. 참조를 보기 전에 area0/0.25/1/4m² 및 area1의 CHANGED-only를 산출·해시 고정한다. `raw_single`과 크기 탈락 `filtered`를 분리하며, 원점 좌표를 이동·평활화·평균하지 않는다. old/new 면의 혼합 지지 우선순위도 v3 그대로다.

## 공통 비교와 평가

초기 입력 지원 감사 후 추가 대조를 별도 동결했다. P1의 113뷰, P2의 66뷰 전체에서 `native mesh의 0.5m XY 점유 셀 최대 → 동률 hash rank`로 시점을 선택한다. 참조나 갱신 점수를 사용하지 않는다. P1 image90과 P2 image296을 선택했고 초기·추가 입력의 ALS/MVS NPZ는 완전히 같다. 기본 40뷰 조건은 보존한다. 이 대조는 관측 지원을 통제하는 재현 보완이며 연구 기여로 세지 않는다.

모든 지역에 **과거 ALS / 실제 Wu 입력인 단일 영상 depth 기하 / 단순 합집합 / Wu 갱신 결과 / 현재 UAS 참조**를 둔다. 별도 OpenMVS 융합점은 생산 계보가 다르므로 context baseline으로 표시한다. 그 점군을 실제 Wu 입력이라고 부르지 않는다.

평가는 후보 receipt와 출력 해시를 먼저 확인한 뒤 UAS를 읽는다. 고정 0.1/0.25/0.5/1/2m에서 prediction→reference와 reference→prediction의 비율 및 F1을 함께 낸다. 양방향 최근접 거리 mean/median/p90/p95/RMSE와 0.5m XY 격자의 지지·결손을 기록한다. 공통 XY 셀의 median Z 차이는 2.5D 진단이며 벽·roof semantic 정답이 아니다. 비유한 점은 임의 삭제하지 않고 검증 실패로 드러낸다.

old 유지/삭제와 new 추가/제외를 각각 집계하고, 각 집단의 참조 거리 분포를 별도 보고한다. 거리가 큰 점의 삭제율만으로 성공을 정하지 않는다. 필요한 표면·현재 갱신의 누락과 잘못된 유지·유입도 함께 본다. >2m는 사후 진단 기준이고 실제 변화·오류 정답을 생성하는 문턱이 아니다.

정성 비교는 같은 좌표·시점·높이 색 범위의 4패널과 단면에서 수행한다. 실제 사진과 native pixel/source ID를 연결하고, 표시용 sampling은 계산 점군·정량 평가에 사용하지 않는다. P1/P2가 변화 사례라는 사용자 설명과 기존 기록을 보존하되, 구역의 모든 점을 변화 정답으로 라벨링하지 않는다.

## 논문 의도와 기여 후보

[원문 기반 분석틀](PAPER_GUIDED_ANALYSIS_ko_v4.md)의 순서대로 정적 구조 보존, 실제 변화 최신화, visibility 기반 판단, 작은 오탐 억제, matching·가림의 잔존 한계를 확인한다. 이미 Wu가 다룬 시간차 학습 라벨 정제나 선택 갱신 자체를 새 기여로 주장하지 않는다. 구현 결함 수정도 연구 기여가 아니다.

실행 후 확인할 것은 (1) 기존 방법이 실제로 해결한 부분, (2) 대체 입력·구현 선택으로 설명되는 한계, (3) 입력을 통제해도 남을 가능성이 있는 판단 문제다. 세 번째에서 후보별 현재 사용성·관측 부족의 보류·연속 오류면 검증이 필요한지 검토한다. B의 텍스처·세부 재구성 기여는 별도의 같은 후단 비교로 검증하며 A의 결과로 대신하지 않는다.

보존 시작점: 외부 `wu_vallet_regions_v4/preservation_start_v4/`에 기존 dirty/untracked 358파일의 해시와 tar를 기록했다. 기존 인계문에 새 안내를 추가하는 경우에도 원문 전체를 유지한다. 새 실행은 Docker source snapshot, 고정 이미지, config, 입력/출력 해시와 실패 기록을 남긴다. 기존 8897/8898/8899 서비스는 유지하고 비교 화면은 별도 8900을 사용한다.
