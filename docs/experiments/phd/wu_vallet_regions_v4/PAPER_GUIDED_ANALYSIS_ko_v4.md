# Wu–Vallet의 의도에서 출발하는 P1·P2·P3 분석틀 v4

작성일: 2026-09-07. 목적: 동일 영역의 **갱신 전 ALS·현재 영상 기하 → Wu 갱신 점군 → 평가 전용 참조**를 비교하여, 기존 방법이 실제로 해결한 부분과 남는 문제를 구분한다. 이 문서는 새 P1/P2 결과를 예단하지 않는 분석틀이며 `scientific_verdict: null`이다.

주 출처: Wu, T. and Vallet, B. (2026), *Image LiDAR based change detection and updating for urban 3D reconstruction*, ISPRS Annals XI-2-2026, 385–392. [공식 원문](https://isprs-annals.copernicus.org/articles/XI-2-2026/385/2026/isprs-annals-XI-2-2026-385-2026.pdf), [DOI](https://doi.org/10.5194/isprs-annals-XI-2-2026-385-2026). 아래 쪽수는 인쇄 쪽수다. 원문 보존본은 [로컬 텍스트](/media/innopam/InnoPAM-8TB/hwiyoung/code/JointBuildGS-artifacts/phase-payloads/phd/wu_vallet_p3_v1/literature_20260907/jbgs_wu_vallet_2026_20260907.txt:18)이다.

**논문의 핵심 의도는 영상 기하로 전부 교체하는 것이 아니라, 정적인 영역에서는 좋은 기존 LiDAR를 보존하고 실제 변화한 부분만 현재 영상 기하로 갱신하는 것이다.** 이 전략 자체를 우리 기여로 다시 주장하지 않는다. 동시에 TUM2TWIN의 ALS가 모든 위치에서 더 정확하거나 현재에도 적합하다고 전제하지 않는다.

## 공통 비교판과 해석 순서

P1·P2·P3 모두 동일 순서로 **기존 ALS / 현재 영상 기하 / Wu 갱신 결과 / 평가 전용 UAS**를 보여준다. top view·회전 3D·고정 단면·실제 current RGB를 같은 위치와 축에서 연결하고, 업데이트 점의 원 ALS row 또는 image pixel 출처를 유지한다. input/output count, old 유지·삭제와 new 추가·제외의 수량을 함께 표시한다. 표시용 sampling이나 projection을 처리 점군 또는 평가 분모로 사용하지 않는다.

정량 비교는 현재 평가 설정의 동일 crop·참조·좌표 처리·XY 격자·가시화 범위를 모든 before/after에 고정한다. 정방향 `prediction→reference`는 출력의 부정확한 지지를, 역방향 `reference→prediction`과 고정 XY 결손은 빠진 구조를 살펴보는 진단이다. 하나로 다른 하나를 대신하지 않는다. UAS와 working CRS/datum/epoch 및 정합 불확실성이 남으면 수치는 보정된 절대 정확도 대신 동일 좌표 처리에서의 참조 편차로 해석한다.

정성적으로 실제 변화 여부를 읽을 수 있는 경우와 없는 경우를 구분한다. 현재 사진에서 보이지 않는 표면의 old 유지나 new 제외를 곧바로 정답으로 표시하지 않는다. source error, 정합, 시간차, 가림의 원인을 분리할 수 없는 사례는 원인 미확정으로 남긴다. 평가 참조는 후보 생성·문턱 선택·정합·사용성 판단에 넣지 않는다.

**P3는 ALS가 영상 기하의 잡음·결손을 보완하는지, P2는 오래된 ALS를 적절히 제외하는지 보는 개발 질문을 유지한다.** 이 설명은 결과 라벨이 아니다. P1도 같은 판에서 관찰한 뒤 어떤 조건을 대표하는지 기록하며, 결과에 맞춰 기준이나 비교 영역을 다시 고르지 않는다. 세 영역의 개발 결과를 모집단·건물 일반화나 확인적 우위로 확대하지 않는다.

어느 후보도 현재 확정된 우위나 승인된 최종 방법이 아니다. 새 결과를 받아 **논문 의도 → 기존 방법이 달성한 부분 → 남은 구체 사례 → 수정과 기대 효과 → 통제된 실행 결과** 순서로 채운다. 문턱 민감도나 입력 대체만으로 현상이 사라지면 그 범위에서 기존 방법을 인정하고, 불필요한 수정을 기여로 유지하지 않는다.
