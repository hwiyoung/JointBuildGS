## 4. 바꾼 것, 확인 불가, 정리 대상

- **정의를 새로 정한 것.** 섞인 패치는 발주 0.3을 따라 패치 다수 경우의 비율이 80 % 미만인 것으로 셌다. JC의 점 단위 '섞임'과는 다르다. 후보 관측 10~12는 두 면 가운데 작은 쪽 값을 쓰고, 두 면의 값도 따로 냈다(10a·b, 11a·b, 12a·b). 15(바깥면 높이 − 평균)와 16(n10 ÷ n)은 저장된 열이라 잠그기 전에 더했다.
- **다시 돌린 것.** 다시 셀 것 1~4는 첫 실행이 clusters.csv 읽기 오류로 멈춰, 한 번 다시 돌렸다(issues.md).
- **확인 불가.** COLMAP 판 번호.
- **정리 대상.** 작업 폴더 `../JointBuildGS-wt-judgeprobe1`, 결과 폴더 `PH/main_judgeprobe_v1`(패치 표 약 3 GB와 rc5 스테이지). 브랜치는 합치지 않았다.
