# A v3 — 두 소스 공동 오류를 푸는 구체 계산과 합성 검산

2026-09-07. `scientific_verdict: null`. 구현 범위는 한 고정 위치의 법선 방향 스칼라이다.
[상위 설계](00_CONTRIBUTION_AND_METHOD_DESIGN_ko_v3.md)의 A1을 작은 알려진 모형에서
실행한다. 실제 P2 보정·판단·3D 재구성을 완료했다는 결과가 아니다. v1/v2는 보존한다.

## 1. 입력부터 행동까지

1. 현재 MVS의 위치 `m`, prior의 위치 `p`, 현재 영상에서 얻는 기하 요약 `y`를 받는다.
   여기서 `y`는 **합성 스칼라 관측**이다. raw RGB·실제 삼각측량 구현은 없다.
2. 현재 참위치 `x`, 두 source의 자체 오류 `e_I/e_P`, 공유 오류 `c`, prior 정합 `δ`,
   영상 오차 `η`, MVS 추가 처리오차 `ν`, 시기 차이 `Δ`를 동시에 미지수로 둔다.
3. 각 변수의 주어진 범위와 관측식을 함께 만족하는 연속 집합을 LP로 구한다.
   같은 표면·변화·무대응을 별도 분기로 유지하고 모순인 분기만 제거한다.
4. 살아 있는 모든 분기에서 현재 위치의 최소·최대를 계산한다. 그 합집합에 대해
   원본 IMAGE/PRIOR와 새 보정/결합 후보의 절대 위치오차 하한·상한을 계산한다.
5. 상한이 허용오차 이내인 후보 중 상한이 가장 작은 후보를 선택한다. 없으면 유보한다.
   모형 미보정·계산 실패·현재 위치 무한범위도 유보하되 이유를 서로 구분한다.

이것은 사진 잔차가 작은 쪽을 고르는 점수법이 아니다. 어느 source도 참값으로 놓지 않고,
동시에 가능한 현재 위치 전체에 대해 **그 후보 자체가 얼마나 틀릴 수 있는지** 계산한다.

## 2. 실제 구현한 공동 관측식

```text
y = x + c + η
m = x + c + e_I,       e_I = η + ν
p = x + j_P c − δ − Δ + e_P
```

- `e_I/e_P`의 각 범위는 0이 아닌 오차·편향을 허용한다. 중심이 0이어야 할 필요도 없다.
- `e_I=η+ν`는 이 합성 실험의 **선언된 의존 모형**이다. 실제 P2의 검증된 식이 아니다.
  사진과 MVS에 독립 likelihood를 곱하지 않고 같은 `c,η`를 재사용한다.
  MVS가 없으면 이 연결식을 쓰지 않으며 없는 source의 오류 범위가 사진을 제한하지 않는다.
- `j_P=0`은 현재 카메라 교란이 prior에 직접 작용하지 않는 조건이다. 공유 좌표계 편향
  검산에서는 `j_P=1`을 명시한다. ALS가 현재 카메라에서 나왔다는 뜻이 아니다.
- `δ`는 이 단일 위치의 상대 정합 nuisance이다. 여러 위치의 전역 강체 정합 solver는 없다.
- `same`은 `Δ=0`, `changed`는 지정된 유한 변화 범위, `unmatched`는 prior 관측식 미사용이다.
  이 분기 목록과 범위는 입력이다. 작은 source 간 거리에서 현재성을 자동 확정하지 않는다.
- 실제 가림·오대응 검출기는 없다. 무관측/무대응 분기가 잘못 빠지면 포함 전제가 깨진다.
  변화 변수에 무한 자유도를 주고 모든 불일치를 변화로 판정하지 않는다.

실제 P2로 옮기려면 source별 bias/상관/이상치 범위, 공유 카메라 모형과 국소 선형화
나머지, 정합 자유도, 대응·가림 분기를 별도 자료에서 보정해야 한다. 이 코드는 그 자료를 만들지 않는다.

## 3. 연속 계산, 보정, 결합과 출력

각 분기의 선형 등식+box 제약은 연속 다면체이다. `scipy.optimize.linprog(method="highs")`로
`x`의 최소·최대와 별도 `δ` 최소·최대를 계산한다. 33개 높이를 전수한 v1 방식과 다르다.
`x`가 유계지만 `δ`가 무계이면 현재 위치 검사는 유지하고 등록 보정 후보만 생성하지 않는다.
모든 분기가 모순이면 `MODEL_INCONSISTENT`다. 이것은 어느 source가 참인지 알려주지 않는다.

후보 `g`의 상한은 모든 살아 있는 구간 끝점에서 `|g−x|`의 최대이고,
하한은 그 구간 합집합까지의 최소 거리다. `U≤ε`는 조건부 적격, `L>ε`는 조건부 부적격,
나머지는 unknown이다. 하한을 볼 때 서로 떨어진 분기를 하나의 연속구간으로 메우지 않는다.

보정 후보는 모든 생존 분기가 같은 현재 표면일 때 `δ` 투영 범위의 중점으로
`PRIOR_REGISTERED=p+mid(δ)`를 만든다. 후보를 만든 뒤 **원래 공동 집합 전체에서 다시 검사**한다.
정합과 source bias의 분리 추정이 완료됐다는 의미가 아니다. 이미지 보정 후보 최적화는 아직 없다.

결합은 같은 현재 표면이라는 조건이 모든 생존 분기에서 지지될 때만 잠정 생성한다.
현재 구현은 IMAGE와 등록 PRIOR(없으면 원본 PRIOR)의 사전 고정 0.5 결합이다.
결합 후 `U≤ε`이고 가장 좋은 부모보다 `U`가 엄격히 작아야 FUSION 채택 후보가 된다.
부모 각각의 최종 허용오차 통과는 요구하지 않는다. 공유 편향은 현재 위치 집합에 남으므로
평균이라는 이유로 줄어들지 않는다. 결합 가중치 최적화·비선형 면 대응은 아직 없다.

| 출력 | 의미 |
|---|---|
| `selected_candidate_id` | IMAGE_RAW / PRIOR_RAW / PRIOR_REGISTERED / FUSION_FIXED_WEIGHT / null |
| `conditional_action` | IMAGE / PRIOR / FUSION / ABSTAIN |
| `selected_value_m`, `selected_error_bounds_m` | 선택한 스칼라 위치와 같은 성분의 `{lower_m,upper_m}` |
| `status`, `model_status` | 수치 풀이, 미보정, 모순, 무계, 미해결 구분 |
| `branches`, `candidates` | 생존/탈락 이유, 보정량, 부모, 후보별 bounds·적격성 보존 |
| `strict_current_use_action` | 모두 ABSTAIN. 합성 가정은 실제 P2 현재사용 인증이 아니다 |

이 스칼라 값 자체는 B의 3D 초기화가 아니다. 실제 3D geometry/native membership/hash와
같은 지지·성분의 보정된 오차 계약을 갖춰야 B로 이전할 수 있다.

## 4. 조건부 수학 성질과 수치 구현의 차이

전제는 참 상태가 열거한 분기 중 하나에 포함되고, 모든 참 오류·정합·변화가 주어진 범위에
들며, 관측식이 정확하다는 것이다. 그때 참 `x`는 해당 다면체의 `x` 투영에 속한다.
따라서 모든 투영을 포함한 합집합에서 후보의 최대 절대오차를 구하면 참오차보다 작지 않다.
그 상한이 `ε` 이내이면 이 모형 안에서 후보 오차도 `ε` 이내이다. 후보를 데이터로부터
보정/결합해 만들었더라도, 만든 고정 후보를 동일한 전체 집합에서 재검사하면 같은 논리가 적용된다.

이 문장은 **정확 산술과 참집합 포함을 전제한 조건부 정리**다. 코드의 HiGHS는 부동소수점
수치 극값이며 rigorous interval certificate가 아니다. primal equality/bound residual과
solver tolerance를 기록하고 작은 numerical guard를 더하지만 이것만으로 엄밀 외측성을 증명하지 않는다.
별도 검증 산술·dual 오차·입력/선형화 오차 전파는 남아 있다. P2 포함성은 입증하지 않았다.

식별 불가의 예: `m,y,p`가 모두 `x+c`에만 반응하면 `x→x+t,c→c−t`로 같은 관측을
만들 수 있다. `c`의 절대 근거가 없으면 현재 절대위치도 무계이다. 정합 `δ`와 변화 `Δ`도
prior 식에 합으로 들어가므로 관측이 부족하면 둘의 원인은 분리되지 않는다.
수치 gauge 고정이나 `c=0` 가정은 이 불확실성의 실증적 해소가 아니다.

## 5. 고정 합성 조건과 공정한 해석

9개 사전 지정 조건은 반대 방향 양쪽 오류, 바뀐 prior, MVS 결손, 양쪽에 공통 편향,
정합 보정, 정합/변화 혼동, 무관측·무대응, 보정자료 없음, 의도적으로 틀린 prior 오류 범위다.
각 조건의 같은 관측에 joint / prior 오류=0 / MVS 오류=0 / noise 연결 제거 /
공유 오류=0 / 같은 시기 강제를 적용한다. 정답은 관측 생성과 **판단 이후 평가에만** 쓴다.
평가에서 전체 생성 latent의 포함성과 `x`만 고정하고 다른 nuisance를 허용한 현재위치
가능성을 따로 기록한다. 관측이 없는 source의 비활성 오류 변수가 full-latent 범위를
벗어나도 현재 `x`가 배제됐다는 뜻은 아니다.

의존 연결 제거는 제약을 느슨하게 하는 비교이므로 가능집합이 작아질 수 없다.
이 비교를 독립 Gaussian likelihood 곱셈의 과신 반증으로 부르지 않는다.
공유 오류를 0으로 고정하는 비교는 다른 가정 변경이며 두 결과를 합쳐 해석하지 않는다.
모순이 생기거나 truth가 제거된 제거실험도 그대로 남긴다. 잘못된 모형의 작은 bound는 안전한 판단이 아니다.

예시 입력은 참위치0, MVS +0.20m, prior −0.20m, 영상요약 +0.12m다.
양쪽 source 오류 범위 ±0.25m, 공유·정합 범위 ±0.02m를 동시에 둔다.
이 입력에서 부모와 0.5 결합의 오차 범위를 실제 LP로 구해 `ε=0.10m`와 비교한다.
정답을 알고 결합을 사후 선택하는 것이 아니라 사전 고정 후보들의 상한으로 선택한다.
정확 실행값과 모든 나머지 조건은 새 external receipt/JSONL에 보존한다.

이 예의 부모는 **오차가 있는 유효 관측**이지만 원본 후보를 그대로 채택할 최종 `ε`를
만족하지 못한다. MVS 자체가 결손·대응 실패·모형 이탈로 사용불가인 경우와 다르다.
후자는 `observations.mvs=null`로 관측식과 후보를 함께 제거하는 입력 계약이며
PRIOR/ABSTAIN만 가능하다. 현 코드는 사용불가 상태를 판별하는 실제 영상 검사기를 포함하지 않는다.

9조건×6가정=54행은 54개 독립 실험이 아니다. 설계된 수치 검산이며 P2 성능표가 아니다.
현재 가정에서 가능한 계산을 구현한 것이지, robust/Bayesian/집합추정에 대한 신규성이 증명된 것은 아니다.
같은 보정 정보·입력·후보·예산을 쓰는 강한 공동 Bayesian 및 robust 순차법과의 비교,
실제 source 오류 모형 포함성, 현재영상 대응·가림, 참조 분리 검증이 박사 기여 평가에 남아 있다.
