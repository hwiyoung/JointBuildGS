## 2. A: 두 소스 오류를 동시에 고려하는 계산

### 의미 흐름

1. 같은 고정 지지에서 MVS와 prior 후보를 보존하고, 두 소스 중 하나를 정답으로 놓지 않는다.
2. 현재 표면, source별 오류, 공동 카메라·좌표 오류, prior 정합, 대응·시기·가림 대안을 함께 둔다.
3. 현재 관측과 보정된 오류 범위에 모순되는 대안만 제거한다. 낮은 잔차만으로 시기나 원인을 확정하지 않는다.
4. 남은 대안 전체에서 각 후보의 사용오차를 계산해 채택·보정·결합·유보를 정한다.
5. 사용 가능한 기하와 성분별 오차·관측 범위를 B에 넘긴다. 상대적으로 좋은 후보라도 절대 적격성은 별도다.

### 공동 모형의 명시적 출발점

검정 지점의 현재 위치를 `X_j`, MVS 관측을 `m_j`, prior 관측을 `p_k`라 두면,
국소 선형화의 설명식은 다음과 같다.

```text
m_j             = X_j + J_Ij c + e_Ij
T_delta(p_k)     = X_j - Delta_j + e_Pk
u_vj            = project(camera_v + c_v, X_a(v,j)) + eta_vj
```

- `e_I`, `e_P`: 각 source의 측정·처리 잔차. bias·공간 상관·outlier를 포함하며 어느 쪽도 0으로 고정하지 않는다.
- `delta`: prior의 상대 정합. 사전 고정한 전역/국소 단위의 공유 변환이며 점마다 자유롭게 맞추지 않는다.
- `c`: MVS와 사진의 공통 카메라·좌표 오류. `J_I`는 그 교란에 대한 MVS 반응의 근사이며 검산 없이 정확한 식으로 취급하지 않는다.
- `Delta`: 현재 위치−과거 위치. 같은 현재 표면 분기에서는 0이고, 시기 차이 분기에서는 별도 변수다.
- `a`, `eta`: 복수 영상 대응·가림 상태와 영상 관측오류. 무대응을 임의의 0잔차로 넣지 않는다.

`(e_I,e_P,c,delta,eta)`의 결합 가능범위 또는 결합 통계모형을 사용한다. 공유좌표 편향,
source 간 상관, MVS와 영상의 의존성을 단순 대각 공분산으로 지우지 않는다.
이 식의 변수들을 넣었다는 사실 자체가 방법적 기여는 아니다.

**중복 증거 처리:** 현재 MVS가 같은 사진에서 계산됐다면 `p(MVS|X)×p(사진|X)`를
독립 증거로 곱하지 않는다. 첫 구현은 MVS를 평가할 고정 후보로 두고 현재 사진을 한 번
사용하는 보수적 경로로 시작한다. MVS 관측식을 추가 정보로 쓰는 확장은 영상과의
결합 오차/조건부 모형을 보정한 뒤에만 비교한다. 이 차이를 실행 이름과 제거실험에 명시한다.
앞의 후보-only 경로는 `A0` 기준선·계산 검산이다. 양소스 관측식과 결합 오류 모형을
확보하는 `A1`이 공동 오류 모형의 주 비교이며, 두 source 오류 제거실험은 A1에서 수행한다.
A0의 결과를 A1의 필요성·성능을 검증한 것으로 쓰지 않는다.
현재 P2의 과거 66뷰를 새 독립 decision set으로 재명명하지 않는다.

**오류와 시기 차이의 분리:** source 오류 범위는 허용된 별도 보정자료로 제한하고,
정합은 공유 자유도를 유지한다. 시기 변화·source 오류·가림이 관측상 구별되지 않으면
복수 분기를 보존한다. 자유 `Delta`가 모든 불일치를 흡수한 해를 변화의 증거로 쓰지 않는다.
두 source가 같이 이동한 경우 절대 좌표 근거가 없으면 해당 성분은 식별 불가다.
좌표 gauge를 수치적으로 고정하는 것과 절대오차를 0으로 확인하는 것은 다르다.

### 계산·판단 규칙과 검증 의무

연속 위치·카메라·정합 범위와 대응 분기를 나눠 보수적 재투영 경계를 계산한다.
구간 전체가 필수 관측과 모순일 때만 제거하며, 미탐색·특이점·경계 밖 가능성은 남긴다.
원제약을 만족하는 witness, 참 가능해를 포함하는 외측 범위, 빈 모형/계산 실패를 구분한다.

같은 지지·같은 성분에서 후보의 오차 상한이 요구오차 이내이면 적격이다. 하한까지
요구오차를 넘는 것이 확인되면 부적격, 그 사이·미보정·계산 미완료는 unknown이다.
복수 적격 후보는 사전 정의한 성분별 정규화 오차 상한의 최대값을 최소화해 선택하고,
동률 처리와 지지/결손 기준도 평가 전에 고정한다. 참 가능집합·보정이 없는 숫자를 보장으로 부르지 않는다.

보정은 고정한 정합 추정으로 새 prior 후보를 만든 뒤 남은 공동오류·시기 대안에서 다시 검사한다.
부모의 같은 현재 표면 대응·유효성이 지지되면 잠정 결합 후보를 만들고, 공동 오류 아래
그 후보의 오차·이득을 검사한 후 통과할 때 FUSION으로 채택한다.
부모 각각이 최종 요구오차를 이미 만족해야만 결합할 수 있다는
규칙과 구분한다. 단순 가중 결합도 교차공분산 항과 bias를 유지한다. 공유 편향은 평균으로 사라지지 않는다.

source별 보정자료, 오류모형의 포함성, 구간 계산·종료, 허용오차의 근거는 아직 구현·확보할 항목이다.
현재 UAS·LoD2 평가기하로 그 값을 맞추지 않는다. 통계 위험과 집합 상한을 같은 보증으로 혼용하지 않는다.

## 3. A의 판단을 B 초기화와 변경 권한으로 전달

| 판단/상태 | 실제 초기 기하 | 재구성에서의 처리 |
|---|---|---|
| IMAGE | 선택한 현재 영상 기하 | 그 기하를 기준으로 외관·허용 세부 갱신 |
| PRIOR | 선택·보정한 ALS 기하 | 지지된 구조는 보존하고 현재 사진으로 외관·관측 가능한 세부 갱신 |
| FUSION | 오류·대응을 검사한 결합 기하 | 부모 계보와 결합 오차를 보존한 갱신 |
| ABSTAIN/미확인 | 자동 채택된 현재 기하 없음 | 후보·미확인 표시 보존. 보이는 prior를 현재 확인 결과로 승격하지 않음 |

같은 geometry hash·native membership·정합 버전·지지·성분·단위·오차 범위를
초기화에 직접 전달한다. 영역 label만 넘기고 내부에서 전역 ALS로 바꾸면 실행 검산을 실패시킨다.
외관 출처는 모든 적격 가시 현재 영상이며 기하 source와 같을 필요가 없다.
선택 범위 밖으로 보간하거나 새 구조를 만들면 별도 후보 생성·재판단이 필요하다.

## 4. B: 출력 구조를 보호하면서 영상 기여와 표현을 늘리는 방법

### 표현과 보존 대상

A가 지지한 점·면으로 기준 표면과 확실한 경계/인접관계만 구성한다. 이를 기준으로
planar 2D Gaussian을 표면에 연결하고, 거친 지지와 관측된 국소 잔차를 분리한다.
표면 결속·mesh 결합 자체는 기존 기반이며 신규성으로 주장하지 않는다.
기준 표면을 표현할 수 없는 입력에서는 그 구성 실패/추론 영역을 표시한다.

보존 대상은 Gaussian 중심이 아니라 **최종 추출 규칙 `S(G)`의 같은 위치·법선·경계·인접관계**다.
학습용 미분 가능 제약과 최종 표면 검사를 함께 둔다. scale/rotation/opacity/증감도
검사에 포함하고, 정해진 성분 범위를 넘으면 해당 갱신을 되돌리거나 판단 단계로 돌려보낸다.
기하를 바꾼 렌더와 고정 기준 mesh를 따로 출력해 구조 보존을 통과시키지 않는다.
보존할 경계와 실제로 갱신할 경계를 A의 현재 근거에 따라 구분한다.

성분별 총 허용오차와 A의 사용오차 상한이 확보됐을 때만 같은 대응/척도에서 남은
변형 여유를 사용할 수 있다. 15cm 같은 solver 제한값을 A의 정확도 보장으로 쓰지 않는다.
유한 점/광선 검사에는 지지와 샘플링 한계를 명시하고 연속 표면 전체의 보장으로 확대하지 않는다.
구조 보존 검사와 독립 현재 참조에 대한 정확도 평가는 별도다. 잘못된 prior의 보존도 구분한다.

### 영상 기여 mask와 gradient의 역할

| mask/권한 | 구성할 근거 | 실제 연결 |
|---|---|---|
| 외관 관측 | 현재 사진의 유효성·가시성·해상도·선명도·노출 일관성 | 색/SH 및 표면 텍스처 학습. 기하 변경 허가가 없어도 외관 관측은 이용 가능 |
| 세부 기하 변경 | A의 변경 허가 + 다뷰 대응·시차·가림 검사의 국소 깊이/방향 관측성 | 세부 위치·방향·크기·opacity gradient 및 세부 표현에 쓸 계산 예산 |
| 새 seed 추가 | 현재 영상에서 얻은 3D 후보와 다뷰 검증·A 재판단 | prior에 없는 관측 구조의 Gaussian 추가. 미관측/사진 잔차만 큰 곳에서는 생성하지 않음 |

기하 선택 mask와 영상 기여 mask는 다르다. PRIOR 영역에서도 관측이 충분하면
현재 외관과 세부 영상 기여를 높인다. 반대로 A가 prior를 선택했다는 이유만으로
가려진 영역의 이미지 weight를 올리지는 않는다. mask는 동일 3D 지지에서 뷰별로 투영한다.

큰 사진 잔차는 후보 탐색 신호일 뿐 세부 허가가 아니다. 그림자·반사·색 경계와
기하 모서리를 다뷰 깊이 근거로 구분한다. texture만 지지되는 곳은 색을 갱신하고,
기하 gradient는 차단/분리한다. 타일·뷰별 유효 분모와 gradient 크기를 기록해 단순히
몇몇 작은 영역의 학습률만 커지는 효과와 구분한다. 평가 mask는 방법마다 바꾸지 않는다.

관측 가능한 세부에 mask를 곱하는 것과 표현 능력은 함께 검토한다. 같은 초기화에서
SH 표현과 관측에 따른 분할/증감이 작동하는 표준 GS를 먼저 확보하고, 제안에도 같은
표현·예산을 준다. seed가 없는 위치는 mask만으로 복원됐다고 주장하지 않는다.
새 영상 유래 기하 후보가 생기면 이전의 MVS 부재 상태를 조용히 IMAGE/FUSION으로 바꾸지 않고
후보 버전과 판단을 새로 만든다. 기존 후보 부재/사용불가 조건의 PRIOR/ABSTAIN 규칙은 보존한다.

## 5. 박사 기여를 분리하는 비교

| 검증 질문 | 고정할 것 | 비교 |
|---|---|---|
| 두 source 자체 오류를 모델링할 필요가 있는가 | 사진·후보·지지·보정자료·재구성 | 두 오류 모형 / prior 오류=0 / 현재 기하 오류=0 |
| 공유오류와 시기·정합 분리가 필요한가 | source별 오류 정보·관측·계산 예산 | 공동 의존 모형 / 독립 가정 / 차이를 시기 변화로 처리 / 자유 점별 정합 |
| 제안 A가 기존 판단보다 나은가 | 후보·입력 모형·처리 능력·동일 B | 강한 공동 Bayesian / 강건 정합→검정→갱신 순차법 / 외측범위 판단 |
| 제안 B가 재구성을 더 잘하는가 | **같은 A 판단·G0·영상·표현·계산 예산** | 표준 GS / 기존 표면 결속·prior regularization / 출력 구조 보존과 관측별 세부 갱신 |
| 세부 mask 자체의 효과인가 | 동일 A·G0·표현·총 최적화 예산 | 공통 관측 mask / 외관 기여 mask / 기하 허가 분리 / 추가 seed 포함 |
| 전체 방법이 필요한가 | 전체 원입력과 같은 출력 목표 | 영상만 / prior만·정합 prior / 단순 합집합 / 강한 순차 전체법 / A+B |

vanilla는 모호하게 부르지 않는다. gsplat 기반 표준 3DGS와 planar 2DGS를 이름으로
구분하고 실제 SH·밀도 제어·손실·추출·schedule을 기록한다. 공식 2DGS fork는 실행하지 않는다.
원방법 재현과 gsplat/이종 prior 어댑터의 차이를 명시하고, 표준법 기능을 뺀 약한 비교로
제안의 이득을 만들지 않는다. 동일 반복 수와 계산비용이 같은 것은 아니므로 시간·메모리·Gaussian 수를 함께 보고한다.

기존 기반 확인: [2DGS](https://arxiv.org/html/2403.17888v1)는 평면 표현과 depth distortion·normal consistency를,
[DN-Splatter](https://arxiv.org/html/2403.17822v3)는 depth/normal priors를,
[SuGaR](https://arxiv.org/abs/2311.12775)는 표면 정렬과 mesh-bound refinement를 다룬다.
단순한 기하 regularizer·mask·표면 결속을 학위의 새로움으로 주장하지 않는다.
DN-Splatter의 원래 입력과 여기의 ALS/현재 영상 조건은 같지 않으므로 전체 재현과 확장을 구분한다.

## 6. 실행 순서와 결과를 받아들일 기준

개발 입력은 보존된 `PHD-P2-AB-V2-COMMON-v1`의 같은 P2 48×46m 영역,
native ALS/MVS와 원영상 계보를 사용한다. 변경이 필요한 입력·관측 역할은 새 manifest로
버전 관리한다. 기존 오류·성능 결과가 나쁜 영역을 사후 제외하거나 새 표본으로 바꾸지 않는다.
고정 후보군의 평가 전용 local oracle로 선택·결합의 개선 여지가 있는지도 확인한다.
oracle의 참조 선택을 A 입력·정합·튜닝에 쓰지 않으며, 선택 여지가 없는 표본에서
복잡한 판단법의 이득을 전제하지 않는다.

1. **오류 모형 검산:** 알려진 정답의 합성 문제에서 양쪽 오류, 공유 bias, 정합·시기·가림의
   구별 가능/불가능 쌍을 검사한다. 같은 관측 복제가 신뢰를 올리지 않아야 한다.
   카메라 오류는 사진과 MVS 계보에 일관되게 주입하며 MVS만 Z 이동한 실험과 구분한다.
2. **표준 B와 외관 진단:** 동일 P2·입력/평가 분모로 표준 GS의 학습과 표현 능력을 확인한다.
   초기 색·SH·표현 밀도·뷰/타일 가중·가림을 분리해 변화 원인을 찾는다. 평가 결과로
   선택한 수정은 새 개발 버전으로 기록하고 독립 일반화 근거로 쓰지 않는다.
3. **A→B 소비 검사:** 고정한 판단 fixture로 실제 영역별 source·지지·변경 허가가 초기화와
   gradient에 반영되는지 먼저 검산한다. fixture는 성능 판단이나 실제 A 출력으로 부르지 않는다.
4. **같은 P2의 분리 비교:** 허용된 오류 보정·A 구현을 확보한 뒤 실제 판단과 같은 B,
   같은 판단과 B 변형을 비교한다. 양립 영역 FUSION 정밀도, 자연 결손, 둘 다 틀림을 포함한다.
5. **전체법·독립 장면:** 오채택/불필요 유보, 결손 보완, 기하·경계·외관·세부 개선과
   양호 영역 열화를 보고한다. 기존 P2와 과거 영상은 확증 세트가 아니다.

세부는 사전 정의한 용마루/단차/관측 가능한 작은 구조의 동일 위치·단면·경계로 검사한다.
독립 참조가 충분치 않은 세부는 unknown이며, 2.5D 높이 잔차를 그 세부의 정답으로 대체하지 않는다.
texture는 고정 평가뷰의 전체/공통/관측 조건별 지표와 실제 crop을 함께 보고한다.
구조는 최종 표면의 위치·법선·경계·연결·누락을 검사하고 source 보존과 현재 정확성을 별도 표시한다.

학위 기여 후보는 (A) 공동 오류와 식별 한계를 반영한 실제 사용 판단 계산,
(B) 그 판단의 지지를 출력 표면까지 유지하며 관측 가능한 외관·세부를 회복하는 방법,
(C) 강한 기존 조합보다 이득이 생기는 조건과 식별 불가 범위의 실증이다.
동일 입력의 강한 방법이 같은 개선·열화·유보 관계를 달성하면 추가 계산을 줄인다.
변수의 존재, 코드 실행 PASS, source 계보 기록만으로 기여를 확정하지 않는다.
