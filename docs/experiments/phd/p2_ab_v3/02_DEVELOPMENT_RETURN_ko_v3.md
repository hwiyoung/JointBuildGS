## A: 공동 오류 판단을 코드로 계산

국소 법선 위치의 공동 오차 제약을 LP로 풀고 후보별 사용오차 상·하한을 계산하는 코드를
실행했다. 두 source 오류, 공유 오차, 정합과 시기·무대응 분기를 함께 둔다.
알려진 정답의 9개 조건에 6개 가정을 적용한 54행이며, 독립 실험 54개가 아니다.

| 고안한 검산 사례 | 공동 계산에서 얻은 것 | 실제 선택 |
|---|---|---|
| MVS +0.20m, prior −0.20m, 영상 기하요약 +0.12m | 현재 위치 범위 [−0.07, +0.07]m; 부모 오차상한 각각 0.27000001m; 0.5 결합 상한 0.07000001m | 요구 0.10m에서 FUSION |
| prior +0.60m, IMAGE +0.02m, 같은 표면·정합 대안 | 새 보정 prior +0.01m의 상한 0.05000001m, IMAGE 상한 0.06000001m | PRIOR_REGISTERED |
| 두 source와 관측에 공통 편향 | 공유 오류를 유지하면 안전한 후보를 확인하지 못함 | ABSTAIN |
| 위 공통 편향을 잘못 0으로 가정 | 결합 +0.805m의 추정상한 0.05500001m, 실제 오류 0.805m | 잘못된 FUSION |

joint의 5채택·4유보에서 고안한 정답 기준 오채택은 0이었다. 이것은 모형 검산 집계이며
실지역 오채택률 0이라는 주장이 아니다. prior 오류=0 또는 IMAGE 오류=0에서는 이
조건들에서 모순·유보가 늘었지만 오채택 차이는 0이었다. noise 연결 제거도 행동 차이가
없었다. 강한 기존 판단법에 대한 성능 우위로 해석하지 않는다.

최대 primal residual은 약 `1.11e−16`이었다. 이는 수치 등식 검산이며 참집합 포함성이나
엄밀 외측 구간 인증이 아니다. 실제 P2의 오류 보정·영상 대응·3D 판단은 아직 실행하지 않았다.
첫 실행 v1은 보존하고, latent 전체 포함성과 현재 x의 가능성을 구분한 진단 보강 v2를
최종 기록으로 삼는다. 두 실행의 54개 판단 내용은 동일하다.

외부 기록: `phase-payloads/phd/p2_ab_v3/PHD-P2-AB-V3-A-JOINT-ERROR-PROBE-v2/receipt.json`.

## B: 같은 P2에서 잔차 가중치의 외관 효과를 분리

같은 native ALS 초기 Gaussian 45,986개를 사용했다. 실제 A 판단을 받은 초기화가 아니라
색 학습의 원인을 분리하는 고정 입력이다. 각 조건은 동일 33 train/11 eval 뷰,
같은 타일 순서, 512 step을 사용하며 기하·개수·opacity를 고정했다.

공통 평가 분모는 초기 ALS 지지와 보수적 전경 제외로 정한 **4,673,262픽셀**이다.
v2 C의 ALS/MVS 합집합 5,150,892픽셀과 다른 조건부 분모이므로 두 표의 MAE를 직접 비교하지 않는다.
평가 가중치를 잔차에 따라 바꾸지 않았다. MAE는 작을수록, SSIM은 클수록 좋다.

| 표현·갱신 | 고정 지지 픽셀 가중 MAE | 뷰 평균 MAE | 뷰 평균 SSIM |
|---|---:|---:|---:|
| 초기 SH0 | 0.182965 | 0.191453 | 0.303035 |
| SH0 균일 가중 색 학습 | 0.185543 | 0.184648 | 0.345269 |
| SH0 잔차 가중 색 학습 | 0.185017 | 0.185127 | 0.345038 |
| SH3 균일 가중 색 학습 | 0.171514 | 0.171496 | 0.367766 |
| SH3 잔차 가중 색 학습 | 0.171059 | 0.171879 | 0.366832 |

잔차 가중은 균일 가중보다 픽셀 가중 MAE를 약 0.000526 줄였지만 초기 MAE는 넘지 못했다.
두 조건 모두 SSIM과 뷰 평균 MAE는 초기보다 개선됐다. 따라서 외관 전체를 변화 없음이나
개선 완료 중 하나로 단정하지 않는다. 이 비교는 색만 갱신해도 평가 지표·뷰 사이에
교환관계가 생긴다는 점과 잔차 가중의 제한된 추가 효과를 보여 준다.

SH3는 같은 Gaussian에 시선 방향별 색 계수 15개×RGB를 추가했다. 고차 계수를 0으로
시작하여 SH0와 초기 렌더를 동일하게 두고, 같은 512 step으로 비교했다. 고차 학습률은
SH0의 1/20로 사전 고정했고 평가 결과로 조정하지 않았다. 이 확장에서 픽셀 가중 MAE와
SSIM이 초기보다 개선됐다. SH0에 잔차 가중치만 더한 것보다 표현 확장의 영향이 컸다.
SH3에서도 잔차 가중치는 픽셀 가중 MAE를 조금 줄였지만 SSIM과 뷰 평균 MAE는 균일
가중치보다 조금 나빴다. 잔차 가중의 보편적 우세나 모든 외관 개선의 원인으로 해석하지 않는다.

SH3는 색의 방향 의존성을 늘린 진단이다. 정확한 재질·조명 분리나 공간 세부 texture의
완전 복원, 새 형상 생성의 증거가 아니다. SH0/SH3는 표현 능력 비교이며 계산량까지 같은
조건은 아니다. 전체 실행은 각각 약 35.20/41.01초였다.

네 조건에서 실제 위치·방향·크기·opacity와 11뷰의 깊이·geometry mass·RGB alpha가
초기와 정확히 같았다. 이 고정 기하 실험의 보존 확인이며, 움직이는 세부나 mesh의
구조 보존 방법이 이미 검증됐다는 의미는 아니다.

외부 기록: `phase-payloads/phd/p2_ab_v3/PHD-P2-AB-V3-B-APPEARANCE-v1/result.json`.
SH3 확장: `phase-payloads/phd/p2_ab_v3/PHD-P2-AB-V3-B-SH3-v1/result.json`.
계수·현재사진·target/initial/final PNG, 고정 mask, 깊이·mass 배열과 학습 이력을 보존했다.

## A→B 연결과 결과 해석

실제 P2 양쪽 원본 점을 사용한 영역별 전달 fixture에서 151,712개의 선택 좌표·소속이
변경 없이 전달됐다. 유보는 기하를 생성하지 않고, 외관 허가가 세부 이동으로 바뀌지 않았다.
이는 실제 A 결정이나 통합 A+B 학습을 완료한 결과가 아니다.

이번에 구현·검산한 것은 A의 공동 계산 핵심, 영역별 기하 전달, B의 외관 가중·SH3 갱신이다.
surface 결합·경계 제한·세부 기하 갱신은 구체 계산 설계와 실제 완성 구현을 구분한다.
기존 v1/v2 문서·코드·실험·뷰어를 보존하고 새 자료는 v3에만 추가했다.
