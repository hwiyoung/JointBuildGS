# P2 v3 — 비교할 방법의 계산과 구현 진입점

2026-09-07. `scientific_verdict: null`.
사용자가 비교 목표를 나열하는 데 그치지 말고 공동 오류 판단과 구조 유지·영상 복원 방법을
실제로 설계하라고 요청한 작업이다. 기존 v1/v2 및 v3의 00 설계는 보존한다.

**채택한 방법 후보:** A에서는 두 source·공유 오차와 시기·정합 대안을 함께 넣은 제약집합에서
각 후보의 사용오차를 계산한다. B에서는 선택된 표면을 기준으로 외관 갱신과 허가된 세부
갱신을 나누고, 관측이 유효하면서 영상 잔차가 큰 부분에 외관 학습 비중을 더 준다.
양쪽 방법의 독창성·우월성은 아직 확정하지 않는다.

## A — 입력에서 판단까지

1. 같은 지지에서 현재 영상 기하와 정합 prior를 각각 후보로 보존한다.
2. 현재 형상, source별 오차, 공유 카메라 오차, 상대 정합, 대응·시기 분기를 변수로 둔다.
   두 source 관측과 현재 영상 근거를 **같은 변수에 대한 제약**으로 연결한다.
3. 각 분기에서 가능한 현재 형상의 최소·최대 범위를 계산한다. 현재 구현은 국소 법선 방향의
   선형 모형과 LP 풀이로 한정한다. 실제 사진의 비선형 투영 전체를 푼 결과로 확대하지 않는다.
4. 그 범위와 각 후보 사이의 오차 상·하한을 계산한다. 최악 오차까지 요구 수준 이내일 때만
   적격으로 둔다. 동일 현재 표면이 지지될 때만 보정·결합 후보를 만들고 다시 같은 검사를 한다.
5. 적격 후보 중 사용오차가 작은 후보를 고른다. 불확실성이 남아 적격성을 확인할 수 없으면
   유보한다. 오차모형 자체가 미보정인 경우도 실제 사용 승인을 내리지 않는다.

구체 관측식·분기·LP·조건부 정리·알려진 정답 검산은
[A 계산 명세](A_CONCRETE_METHOD_ko_v3.md)와
[joint_error.py](../../../../src/phd/p2_ab_v3/joint_error.py)에 둔다.
알려진 정답 모형 검산과 실제 P2 오류 보정·판단은 서로 다른 단계다.

## B — 구조를 유지하며 현재 영상의 기여를 늘리는 갱신

1. A가 선택한 영역별 기하로 기준 표면과 Gaussian 지지를 구성한다.
2. **외관 단계:** 위치·방향·크기·불투명도를 고정하고 현재 영상으로 색을 학습한다.
   가시·유효 관측 중 잔차가 큰 곳의 비중을 제한적으로 높이며, 가중치는 역전파에서 분리한다.
   같은 유효 분모로 정규화해 단순한 전체 학습률 상승과 구별한다.
3. **표현 확장 단계:** 작은 무늬를 현재 표현으로 담지 못하면 표면 위 표현 해상도와 SH를
   늘리는 비교를 한다. 개수·opacity 변화가 출력 표면을 보존한다는 가정은 하지 않는다.
4. **세부 단계:** 현재 영상의 다뷰 깊이·시차가 지지하고 A가 허가한 성분만 움직인다.
   기준 표면에 연결한 좌표에서 허용 범위로 투영하며, 고정 경계와 출력 표면의 지지·깊이·법선을
   검사한다. 위반 갱신은 되돌린다. 허용 범위 밖 새 구조는 새 후보 생성과 A 재판단이 필요하다.

이번 실측은 2단계의 **고정 기하·색 학습에서 잔차 가중치의 효과**와 SH0→SH3 색 표현
확장의 효과를 분리했다. SH3는 같은 공간 지지에 시선 방향별 색 표현을 더하는 것이며
새 세부 형상을 만든 것이 아니다. 면 세분·세부 갱신 전체를 완료한 실험은 아니다. 정확한 손실·변수·표면 결합과
갱신 검사 절차는 [B 계산 명세](B_CONCRETE_METHOD_ko_v3.md)에 둔다.

[2DGS §4–5](https://arxiv.org/html/2403.17888v1)는 planar Gaussian과 깊이·법선 정규화를
사용하면서 위치·크기·방향도 최적화한다. [SuGaR 저자 설명 §3](https://anttwo.github.io/sugar/)의
mesh 결합 refinement는 mesh와 Gaussian을 함께 최적화한다. 두 방법을 과거 입력 구조의
불변 보장으로 해석하지 않는다. 표면 결합과 잔차 가중 자체를 새 기여로 선언하지 않는다.
연구 가설은 **오류가 있는 두 source에서 확인한 성분·범위를 재구성 자유도에 반영하는 것이
외관·세부 개선 중 구조 열화를 줄이는가**다. 같은 기준 표면을 받는 기존 결합·정규화 방법과
제약·잔차 mask를 제거한 조건이 필요하다.

## 영역별 A→B 전달 구현

[handoff.py](../../../../src/phd/p2_ab_v3/handoff.py)는 영역별 선택 후보의 좌표·법선·소속,
geometry hash·정합 버전, 성분별 오차와 단위, 외관·세부 권한을 받는다.
선택한 좌표를 내부에서 재정합·융합·보간하지 않으며, 해시가 다른 입력은 거부한다.
`ABSTAIN`은 초기화 점을 추가하지 않는다. 외관 권한만으로 세부 이동은 허용하지 않는다.
이 유효성 검사는 입력 판단의 과학적 적절성이나 공간 지지의 타당성을 증명하지 않는다.

동일 P2에서 XY 중앙 `x=134m`로 서쪽 ALS·동쪽 MVS를 고정한 **연결 확인용 fixture**를
실행했다. 이는 실패 지역이나 정답에 맞춘 선택표가 아니며 실제 A 판단 결과도 아니다.
151,712점의 좌표·원본 소속이 정확히 전달되고, 세부 이동 허가는 없으며 유보는 점을
추가하지 않는 것을 확인했다. 실제 B 학습은 별도 고정 ALS 진단으로 실행되므로 이 두
검산을 통합 A+B 실험이라고 부르지 않는다.

실행: `bash scripts/phd/p2_ab_v3/handoff_probe_docker.sh`.
외부 기록: `phase-payloads/phd/p2_ab_v3/PHD-P2-AB-V3-HANDOFF-v1/return/receipt.json`.
검산의 0.1/0.2m는 직렬화·권한 처리용 값이며 실제 P2 보정오차나 사용 기준이 아니다.
현재 함수의 `FUSION` 검사는 두 부모 계보가 있다는 최소 검사다. 실제 결합 후보를 생성하고
부모별 점 대응·오류 이득을 검증하는 계산은 A에서 수행해야 한다.

## 다음 실측을 가능하게 하는 정확한 남은 입력

- A: 실제 P2의 source별 오류와 공유 카메라·대응 오류를 만들 허용 보정자료 및 비선형
  관측→제약 변환. UAS 평가기하로 모형을 맞추지 않는다.
- B: surface 결합·분할·허가된 세부 갱신의 구현, 같은 초기화·표현·예산의 표준 GS와
  기존 surface 결합 비교. 이번 색 가중치 probe로 이를 대신하지 않는다.
- 전체: 실제 A 판단 파일을 고정해 각 B에 동일하게 전달하고, 동일 평가 지지에서 외관,
  구조의 현재 정확도·보존, 직접 확인 가능한 세부와 양호 영역 열화를 함께 비교한다.
