## 1. 문제와 입출력

**[원문 사실]** 과거 ALS+보정 aerial stereo에서 변화와 갱신 점군을 만든다. ALS의 평면·후보 DSM, 영상의 시차는 파생 기하다. NDVI용 별도 NIR와 BAG/도로·하천 지도도 사용한다. 상대정합이 cm급이고 유사 조명의 연속 stereo를 가정하며 near-nadir 한 쌍을 시험했다. [§3–4.1, PDF pp.7–20](https://repository.tudelft.nl/file/File_5e70c9f8-1674-49ab-b4a5-fa3085f3dd77#page=7).

**[우리 분석]** ALS+RGB만 가진 연구와 후처리 정보량이 다르다. 건물 지도·NIR 제거 성능을 알고리즘 자체의 geometry 판단 성능으로 합쳐 비교하면 안 된다. 외부 사전학습은 제안법에 없다.

## 3. 무엇을 고정하고 수정하는가

**[원문 사실]** LiDAR 평면 후보에서 `D1`을 고르고 잔여 색차로 변화 seed를 만든다. 2차에서는 LiDAR 정보를 제외해 `D2`를 구한다. 새 변화에 따라 탐색영역을 반복 확장하고 이전 추정 영역 1m를 겹쳐 smoothness를 전달한다. [§3.2, Fig.6, PDF pp.15–17](https://repository.tudelft.nl/file/File_5e70c9f8-1674-49ab-b4a5-fa3085f3dd77#page=15).

```text
고정 ALS → 평면 후보 → 영상 경계/음영을 이용한 D1 → 변화 seed
                                               ↓
영상-only D2 → D2 대 D1 검정 → 변화 영역 확장 ───┐
     ↑                                        │
     └──── 다음 계층/영역 재매칭 + 이전 경계 겹침 ┘
최종 변화·D2 → NDVI/지도/면적 정제 → ALS 교체
```

**[우리 분석]** 단계가 있어도 변화→매칭영역→시차→변화의 feedback이 실제로 있다. 고정 ALS 자체와 1차 후보 평면을 매번 다시 추정하는 루프는 확인되지 않는다. 매 반복 새로운 센서 정보가 생기는 것은 아니며 원 stereo와 `D1`, 지도는 재사용한다. 이를 “모든 prior가 끝까지 강제됨”이라고 기술하면 틀린다.

제한 탐색은 안정성·비용을 줄이고 image-only 2차는 낡은 prior를 벗어날 자유를 준다. **[우리 추론]** 반대로 seed가 없거나 2차 관측이 부족하면 수정 기회가 줄 수 있다. 정합·plane까지 풀면 불일치의 원인을 서로 흡수할 수 있으므로 공동 최적화가 자동 해법은 아니다.

## 4. 실제 검증 범위

**[원문 사실]** Amersfoort는 2010 ALS/영상에 2008 BAG으로 합성 이전 상태를 만들고, Assen은 2012 ALS→2018 영상의 실제 시간차다. Assen 미변화 952동을 확인; 신축 object F1 0.94, 철거 0.90, 두 범주 pixel F1 0.91이다. [§4.1.3, §4.2.3, Table2](https://repository.tudelft.nl/file/File_5e70c9f8-1674-49ab-b4a5-fa3085f3dd77#page=19).

**[평가 감사]** projection–geometry와 robust–dDSM 비교는 전체 workflow 비교다. 모든 요소를 하나씩 바꾼 factorial ablation은 아니다. 참조는 BAG 수동 편집·AHN3 및 raster DSM이며 20cm 경계 buffer를 평가에서 제외한다. Assen AHN3의 수집 구간은 2014–2019로 표기되어 모든 참조가 2018과 정확 동시라는 주장은 불가하다. supervised train/test는 없지만 같은 사례의 경험적 parameter 선택과 일반화는 구분한다. 평균 높이 차이(0.32m)는 보고되나 독립 textured surface·국소 비악화·렌더·공통 runtime 비교는 미평가다.

## 6. 연구 공백 후보

**이미 해결:** 유효 ALS의 안정성과 영상 경계 세부 결합, 변화 시 prior 해제, 반복 변화 확장, 비건물 필터, 미변화 검증. 이름만 다른 source-selection으로 신규성을 선언하지 않는다.

**후보:** “2차에서 prior를 해제해야 하는 영역에서 관측이 부족할 때 실제로 어느 정보까지 복원 가능한가?”는 **적용 조건+검증 문제**다. 모든 영역에 다시 prior를 강제하는 해법은 낡은 구조를 복구할 수 있으므로, 다중 뷰 hierarchical matching·기존 신뢰도 정제·Wu식 가시성과 품질 선택의 단순 조합을 먼저 대조한다.

**최소 비교/기각:** 같은 seed·같은 영상으로 1-pair/허용 multi-pair/기존 confidence 처리/수정 후보를 비교하고, 별도로 native full pipeline과 공통 geometry 고정 비교를 구분한다. 부분 검출과 80% 피복, 현재 표면 오류, 올바른 prior 오삭제·새 geometry 오추가, 미변화 비악화를 모두 평가한다. 기존 multi-view+정제가 같거나 더 낫다면 새 판단/반복 모듈의 필요성은 기각한다. 새로운 영상 추가의 이득을 알고리즘의 이득으로 혼동하지 않는다.
