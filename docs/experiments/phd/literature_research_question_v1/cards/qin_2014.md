## 1. 문제와 입출력

**[원문 사실]** LoD2 face별 변화와 신규 건물을 검출한다. 실제 관측은 target stereo·multispectral; 외부 기하는 건물/지형 LoD2, 파생물은 encoded DSM와 SGM DSM다. 기존 texture는 TEXDIF에 사용 가능하지만 PBMIGC는 무색 모델도 검정한다. [§2–3.1, PDF pp.5–11](https://rongjunqin.weebly.com/uploads/2/3/2/3/23230064/3d_change_detection_based_on_lod2_3d_models_and_very_high_resolution_spaceborne_stereo_pairs_v5.pdf#page=5).

**[우리 분석]** LoD2가 제공하는 face·object·구조 정보량은 ALS-only보다 많다. footprint만 허용된 JointBuildGS honest arm에 원 LoD2 입력을 그대로 넣는 비교는 정보가 다르다. 논문은 추상 모델과 관측의 세부 수준 차이를 문제로 인정한다. 날짜1/2는 자료 역할이며 chronological ordering을 강제하지 않는다.

## 3. 무엇을 고정하고 수정하는가

**[원문 사실]** 모델 유도 patch 안에서 시차를 matching해 기하 일관성을 평가한다. SOM이 `change/non-change/uncertain`을 만들고, 자동 pipeline의 MRF는 최종 binary label을 산출한다. [§3.1.1/3.2/3.3, 식13](https://rongjunqin.weebly.com/uploads/2/3/2/3/23230064/3d_change_detection_based_on_lod2_3d_models_and_very_high_resolution_spaceborne_stereo_pairs_v5.pdf#page=8).

```text
LoD2 → encoded DSM / faces ────┐
target stereo → SGM DSM → LS3D 정합 → height 차이
LoD2+stereo → patch 재매칭 → PBMIGC ├→ SOM/vote → MRF label
old texture(있을 때)+target → TEXDIF ┘
target DSM+multispectral → building mask → 기존 검증 결과 제외 → 신규 건물
```

**[우리 분석]** surface registration은 추정되고 patch disparity도 탐색되므로 단순 고정 투영점의 색차 검정이 아니다. 그러나 판정 후 model vertices나 camera를 최종 변화 label로 재추정하는 경로는 확인되지 않는다. SOM은 현 scene evidence에 적합하는 비지도 학습이며 외부 사전학습과 구분한다. 최종 `uncertain` 보존을 기본 출력으로 주장하면 틀린다; §3.2는 operator 검토 가능성을 제시하되 §3.3 자동 모드는 이를 결정한다.

고정 face는 안정적인 공간 단위·추상화 허용을 제공한다. **[우리 추론]** 자유롭게 세분화/수정하면 세부 변화에 민감해질 수 있으나 matching noise·추출 잡음을 실제 변화로 과분할할 수 있다. MRF를 풀고 유보를 유지하는 효과는 coverage와 오판 위험의 trade-off로 검증해야 한다.

## 4. 실제 검증 범위

**[원문 사실]** Singapore WV2 982동에 합성 추가·삭제·높이 변화; 실제 Rochor 927동은 **2010 모델→2002 IKONOS의 역사시점 검정**이다. 실측 Table2는 200m² 초과 건물만 평가, object 총98변화 중81검출(0.826)이다. [§5.1–5.2, Table1–2, PDF pp.18–20](https://rongjunqin.weebly.com/uploads/2/3/2/3/23230064/3d_change_detection_based_on_lod2_3d_models_and_very_high_resolution_spaceborne_stereo_pairs_v5.pdf#page=18).

**[평가 감사]** 수동 변화 참조와 pixel/object 결과가 있으며 image matching의 occluded pixels를 일부 평가 모집단에서 제외한다. Fig.10은 channel weight/voting/MRF parameter sensitivity로 모든 경쟁 재구성기의 대조는 아니다. 단일 scene에서 조율한 SOM/threshold를 독립 scene 일반화로 취급하지 않는다. native 산출물이 change labels이므로 texture rendering, 최종 surface accuracy·완전성·local regression은 범위 밖이다. 원고 Table1 일부 요약비율은 열 정의/산식 재검증 없이 재인용하지 않는다.

## 6. 연구 공백 후보

**이미 해결:** 무색 모델을 새 시점 영상으로 검정, 모델 추상화·정합/DSM 불확실성 처리, 불확실 중간 상태, MRF로 공간 판단 보강. “prior 검정/unknown을 처음 도입”하는 주장은 기각한다.

**후보 [출력 조건 차이]:** reconstruction에 전달할 때 불확실 상태를 계속 유지하는 것이 기존 자동 binary 완성과 비교해 유효 구조의 손상을 줄이는가? 이는 이름을 바꾸는 것이 아니라 risk–coverage/복원 손상을 확인할 질문이다. Qin patch 검정+기존 robust confidence+Wu/기존 surface reconstruction의 순차 조합이 반증 comparator다.

**최소 비교/기각:** 같은 후보·관측으로 height-only, PBMIGC+height, 원 SOM/MRF, 유보 유지, 추가 수정 후보를 비교한다. 라벨 정확도뿐 아니라 downstream geometry/coverage와 benign 비악화를 평가한다. 기권 때문에 오류만 줄고 유용한 복원이 지나치게 줄면 채택하지 않으며, 기존 calibratable threshold로 동일 trade-off를 얻으면 별도 명시적 판단 모듈의 신규성 주장을 접는다.
