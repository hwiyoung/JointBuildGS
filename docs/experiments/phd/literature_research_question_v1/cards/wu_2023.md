## 1. 문제와 입출력

**[원문 사실]** 품질·피복·취득시점이 다른 sensor mesh들을 지속 가능한 최신 mesh로 합친다. 입력은 잘 정합된 mesh와 triangle/vertex별 센서 시점이다. 실제 실험 관측은 MLS이며 mesh는 파생 기하다. RGB 사전학습을 요구하지 않는다. 지속성은 후속 취득에서 다시 관측되는 시간 간격으로 평가한다. [§I, III-A/C](https://arxiv.org/html/2303.07182v1#S3.SS1).

**[우리 분석]** 정밀도와 시점을 다르게 다루며, 오래된 고품질 기하가 유효할 때 보존하는 목표가 이미 명시돼 있다. “새 자료가 항상 우선”이라는 비판은 적용되지 않는다. 새 mesh의 표면/가시성 정확성 및 필요한 재관측 여부는 별도 입력 조건이다.

| 요소 | 판정 | 실제 역할 / 근거 |

## 3. 무엇을 고정하고 수정하는가

**[원문 사실]** 추정하는 것은 triangle의 시간상태·keep/remove boolean과 seam 조합이다. 미변화부는 품질 우선, 변화부는 지속성 검정을 통과한 시점 우선이다. 기본 quality가 triangle 수를 선호하면 고밀도 mesh가 선택되며 precision/certainty를 quality로 넣을 가능성도 명시한다. [§III-C, IV-A, 식2](https://arxiv.org/html/2303.07182v1#S4.SS1).

```text
정합된 M(t), 시점 → 거리+empty-space consistency graph
                 → 새 시기마다 최초/최근 확인시각 갱신 → 지속성 후보
                 → QPBO triangle 선택 → seam boundary matching/stitching → mesh
```

**[우리 분석]** 시간 정보를 실제로 증분 갱신하고 QPBO가 전역적으로 선택하므로 “한 번 거리비교 후 단순 합집합”이 아니다. 최종 stitch/새 render 잔차가 원 sensor depth·registration·변화 label을 재추정하는 경로는 확인되지 않는다. 원 triangle 좌표는 주로 보존하되 stitching에서 경계점 병합·새 연결이 있어 최종 기하가 전혀 변하지 않는다는 설명도 부정확하다.

좌표 고정은 원 관측의 구조를 보존하고 탐색을 줄인다. **[우리 추론]** 이를 풀면 정합 편차를 줄일 수 있지만 진짜 변화도 흡수할 수 있다. 품질을 해상도로 대용하면 밀도와 정확도가 분리되는 입력에서는 오선택 위험이 있다. 이는 해당 실험에서 측정된 오선택률이 아니다. density 외 quality를 추가하는 기능 자체는 저자가 이미 열어 두었다.

## 4. 실제 검증 범위

**[원문 사실]** Robotcar의 여러 시기와 Stéréopolis 두 시기를 시험한다. first-observation update baseline보다 seam·coverage·triangle 크기가 개선된 예시를 보인다. Stéréopolis는 두 시기라 지속성 분석을 하지 못하며 최신 triangle을 보존한다. runtime은 QPBO/improve가 지배적이다. [§V, Fig.4–11](https://arxiv.org/html/2303.07182v1#S5).

**[평가 감사]** §V-C의 “mesh accuracy”는 작은 triangle/높은 해상도의 시각 비교이며 독립 표면 GT에 대한 RMSE가 아니다. 거리-only와 ray 결과 비교, seam 선택 baseline은 확인되나 전체 최신 대조군/조건별 calibration/국소 개선·악화 계량은 없다. 외부 학습 split은 해당 없으며 실험 모두 LiDAR 유래라 낮은 품질 image mesh까지 입증했다는 주장은 불가하다. textured render·LoD2·현재 표면 절대 정확도는 미평가다.

## 5. 남은 오류와 전달 경로

| 상태 | 구분과 근거 | 오류 전달 / 다른 원인 |
|---|---|---|
| **관측된 어려움** | [저자 해석] Robotcar의 지면과 거의 평행한 ray는 교차 오차가 커 거리검사를 결합; §V-A | acquisition geometry→visibility 오류. 완화 장치가 존재함 |
| **저자가 명시한 한계** | [저자 해석] 오래 주차한 차량은 지속성만으로 제거할 수 없음; §VI | 의미적 “영구 구조”와 시간상 반복 관측이 다름 |
| **미평가** | [우리 분석] 이미지 유래 오기하·상관 오류·상대정합 잔차를 한꺼번에 갖는 경우 | 센서 mesh 오류→conflict 관계→후보 제거→stitch 손상 가능 |
| **범위 밖** | [원문 사실] texture stitching은 future; §VI | 현 결과의 외관 복원 성공으로 주장 불가 |

근거: [§V-A, §VI](https://arxiv.org/html/2303.07182v1#S6). 2023 원문은 입력 결합의 성공 예시를 보이지만 최종 결과의 독립 기하 오차를 계량한 잔여 오류 표는 확인되지 않는다.

## 6. 연구 공백 후보

**이미 해결:** 시간·가시성·비관측·품질 우선 선택·전역 mesh 선택·접합. “품질 대신 사용 가능성”이나 “선택 뒤 복원”이라는 말만으로 구별할 수 없다.

**후보 [검증 부족 중심]:** 밀도와 정확도가 다른 cross-modal mesh에서 기존 quality 확장과 가시성 정제 뒤에도 해로운 triangle 선택이 남는가? 먼저 `Q=해상도`, `Q=기존 matching confidence/정밀도`, robust registration+quality+stitch의 강한 순차 조합을 비교해야 한다.

**최소 비교/기각:** 같은 sensor meshes·시점·quality evidence로 first-update, Wu QPBO, 기존 quality 강화, 수정 후보를 비교한다. 동시에 sensor mesh 생산기를 바꾼 전체 비교를 따로 둔다. 독립 표면 GT, coverage, seam, 보존면 손상, 실제 변화 복원, 계산량으로 평가한다. quality를 기존 확률/정밀도 지표로 바꾸는 것만으로 문제가 해소되거나 strong sequential과 같은 성능이면 새로운 명시적 판단/공동 최적화 필요성을 기각한다.
