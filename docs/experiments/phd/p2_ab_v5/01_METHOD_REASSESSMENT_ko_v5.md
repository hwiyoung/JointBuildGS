## 1. ALS와 MVS의 학습 방법은 같았는가

**직전 표의 ALS v3 SH3와 MVS v4 SH3는 같은 학습법이다.**
두 조건의 코드·설정·실제 512개 `(image_id, tile)` 로그·렌더러 해시를 대조했다.

| 항목 | ALS v3 SH3와 MVS v4 SH3 |
|---|---|
| 렌더러·손실 | 같은 corrected gsplat / SH3, `0.8 weighted L1 + 0.2 (1−masked SSIM)` |
| 최적화 | Adam 512회, SH0 LR 0.015, 고차 SH LR은 1/20, 같은 감소·gradient clip |
| 사진 | 33 train/11 eval, 실제 타일 방문 순서 동일 |
| 갱신 변수 | 색/SH만. 위치·방향·크기·opacity·개수 고정 |
| 다른 입력 | 45,986 / 266,361 Gaussian, 위치·법선·크기·초기 색·가시 지지·학습 mask/q |

초기 opacity 설정은 둘 다 0.85다. Gaussian 수에 따른 표현 용량도 다르므로,
소스 간 차이를 현재성 또는 위치 정확성 하나의 인과 효과로 분해할 수 없다.
[ALS 설정](../../../../configs/phd/p2_ab_v3/b_sh_probe_v1.json),
[MVS 설정](../../../../configs/phd/p2_ab_v4/b_mvs_appearance_v1.json),
[같은 손실·순서 구현](../../../../scripts/phd/p2_ab_v4/b_mvs_appearance_probe.py).

**v2는 다른 실험이다.** 당시에는 2,048회 SH0 학습에 조건별 기하·scale·opacity 갱신과
coverage/depth-normal/MVC 항을 넣었다. 원인 분리를 위해 v3에서 기하를 고정하고 색 표현과
잔차 가중을 비교했으며, v4에서 그 진단을 MVS 초기화로 반복했다. 앞선 설명은 이 버전을 섞었다.
[v2 변수·손실](../p2_ab_v2/B_CORRECTED_TECHNICAL_RETURN_ko_v2.md).

## 2. 외관이 절대적으로 좋은가

고품질 재구성에 도달했다고 평가할 근거는 없다. 같은 5,150,892픽셀에서 MVS는
MAE 0.161113→0.148340, PSNR 12.8256→13.3328dB다. 최종 MAE는 8-bit RGB로 약
37.83/255의 평균 채널 절대차다. 흐림·렌더 지지 부족도 남는다.
[공통 분모 결과·정성 뷰어](../p2_ab_v4/00_READ_THIS_FIRST_ko_v4.md).

이 평가는 초기 두 소스의 관측 지지 합집합에서 누락 예측도 포함한다. 서로 다른 논문의
전경/전체 영상, 해상도, 배경, 노출 처리, PSNR 평균 방식과 직접 비교할 수 없다.
512회는 사전 고정된 개발 진단이며 수렴·강한 표준 GS 대비 우월성을 검증하지 않았다.
MAE/PSNR은 사진 오차이고 기하·지각 품질 전체를 나타내지 않는다.
[Wang & Bovik, 2009](https://ece.uwaterloo.ca/~z70wang/publications/SPM09.pdf).

## 3. A: 두 소스의 오류를 실제 판단 계산에 넣는 방법

**제안 방법은 ‘오차를 가진 두 관측의 공동 제약 아래, 현재 사용할 수 있는 후보 기하를 검사하는 방식’이다.**
최적화로 어느 오류가 원인인지 항상 하나로 판명된다고 가정하지 않는다.

### A1. 원본 후보를 보존하고 실제 영상에서 위치 검정 자료를 만든다

같은 P2 원본 MVS/ALS 소속을 유지한다. 지붕면·벽·단차·경계를 비교 단위로 삼되 작은 점
몇 개만으로 후보를 축소하지 않는다. 평면 근사가 적합한 면에서는 높이/법선, 경계에서는
경계 위치를 별도 성분으로 다룬다. 동일한 표면 대응이 없는 곳을 최근접점으로 강제 대응하지 않는다.

각 후보를 법선 방향으로 이동·기울여 가며 **현재 사진 사이의 기하 유도 warp 비용**을 구한다.
노출에 둔감한 패치 비교, 왕복 재투영, 가림 검사를 함께 사용한다. 비용을 하나의 승자 점수로
줄이지 않고, 관측이 허용하는 위치/방향 구간과 복수 극소를 남긴다. 비용이 평평하면 그 방향은
미확인이다. 반복 창무늬·그림자·가림으로 다중 해가 생기면 모호성을 유지한다.
색/SH를 충분히 학습한 뒤의 RGB 적합으로 후보 기하의 사용을 승인하지 않는다.
후보별로 카메라·노출의 허용 범위를 다르게 주지 않는다. 후보가 설명하지 못한 픽셀을
자기 visibility mask로 삭제하지 않고, 공통 관측 범위에서 가림 근거·부재·잔차를 함께 기록한다.

### A2. 오류 범위의 출처를 소스별로 만든다

| 항목 | 제안하는 실제 계산·자료 | 이것만으로 알 수 없는 것 |
|---|---|---|
| MVS 오류 | 촬영 그룹 재표본화, 영상 대응·카메라 교란 후 재삼각측량; 같은 원행/면 성분의 변화 기록 | 반복해도 남는 공통 편향·절대 정확도 |
| ALS 오류 | 취득 메타데이터의 거리·각도·궤적 오차 전파, 가능하면 strip 중복 차이; 점 간격/국소 형상과 표현 오차 별도 기록 | 평면 잔차만으로 센서 편향이나 현재성을 알 수 없음 |
| 상대 정합 | 현재 영상의 구조 대응 등 안정 근거가 있는 주변 영역에서 여러 면을 함께 쓰는 강체 errors-in-variables 적합 | 전체가 변했거나 평행면뿐이면 일부 이동·회전이 미식별 |
| 공유 오류 | 동일 카메라·기준점의 교란을 MVS와 영상 검사에 함께 적용; 출처가 공유되는 ALS 성분도 함께 전달 | 독립 근거 없는 공통 좌표 편향을 표본 증가로 제거할 수 없음 |

재표본화의 산포를 참오차 상한으로 부르지 않는다. 메타데이터·독립 보정 근거가 없는 편향은
0으로 넣지 않고 미확정으로 남긴다. 평가용 UAS/LoD2는 이 계산·정합·오차 보정에 쓰지 않는다.
이미 전체 영상으로 만든 기존 MVS를 영상별로 나누어 점수만 계산해도 독립 평가가 되지 않는다.
새 영상 분할 검산은 각 분할에서 후보를 다시 만드는 별도 파생 실행이 필요하다.

오차 전파의 직접적인 참고는 [M3C2-EP, 2021](https://www.geog.uni-heidelberg.de/en/3dgeo/projects-of-the-3dgeo-research-group/m3c2-ep)다.
다만 두 소스의 유의한 차이만으로 어느 후보가 현재 사용에 적합한지 정할 수는 없다.

### A3. 두 소스·정합·공유 오류를 하나의 상태로 계산한다

국소 대응 성분에 대한 제안 모형은 다음과 같다. 3D 면에서는 위치·방향 성분으로 확장한다.

```text
MVS 관측 m       = 현재 표면 x     + J_M c + b_M + η_M
정합한 ALS Tδ(p) = 과거 표면 x_old + J_P c + b_P + η_P
현재 영상        = x와 교란된 카메라가 유도하는 투영 + 대응/광도 관측 오류
```

`b_M/b_P`는 소스별 편향, `η_M/η_P`는 잔여 측정·표현 오류, `c`는 공유 오류,
`δ`는 여러 영역에 공유되는 상대 강체 정합이다. 현재와 과거의 대응이 성립할 때에만
`Δ=x−x_old`를 형상 차이로 정의한다. ALS가 현재 카메라에서 만들어졌다고 가정하지 않으며
`J_P`의 공유 성분은 실제 계보로 정한다.

이것이 ‘동시에 고려한다’가 들어가는 자리다. MVS를 정확한 고정 기준으로 두고 ALS만
움직이지 않는다. 두 소스의 오차·공유 교란·정합을 함께 변화시켰을 때에도 관측을 설명하는
현재 표면들의 집합을 계산한다. 차이의 산포도 소스별 분산 두 개만 더하지 않고, 필요한 경우
공유 교란과 정합을 포함한 전체 공분산을 잔차 Jacobian으로 전파한다. 편향은 별도 범위로 유지한다.

MVS와 같은 사진의 검정값에 **독립 우도를 곱하지 않는다**. 재표본화·교란을 공유한 공동
제약의 포함성을 검산한다. 의존 모형이 확보되지 않으면 MVS 요약을 추가 관측항으로 중복
사용하지 않고 후보 생성에만 사용하며, 그 제한을 기록한다. 이 경우 완성된 공동 오류법을
검증했다고 주장하지 않는다.

같은 현재 표면 / 시기 차이가 있는 대응 / 무대응·가림을 별도 가설로 유지한다. 정합과 변화,
공유 편향을 구별하지 못하면 임의로 한 설명을 선택하지 않는다. 근거로 배제하지 못한 가설의
가능 집합을 **합집합**으로 남긴다. 모든 가설이 모순이면 모델 불일치이며 소스 승자가 아니다.
계산은 면 성분의 선형화와 원래 warp의 재검산부터 시작한다. 비선형 전체 표면의 엄밀 인증은
별도 과제이며, v3의 합성 LP를 실제 P2 오차 보정으로 대체해 부르지 않는다.

### A4. 후보를 만든 뒤 사용오차와 행동을 결정한다

생존 가설 모두가 허용하는 현재 기하 집합을 `X`라고 하자. 각 원본·보정·융합 후보 `g`에 대해
그 후보의 최악 사용오차 `U(g)=sup_{x∈X} d(g,x)`를 구한다. 성분·규모·지지는 `d`에 명시한다.
보정은 식별된 정합 성분에만 적용하고 결과 후보를 다시 검사한다. 융합은 두 관측이 유효하고
같은 현재 표면이라는 근거가 있을 때만 제안하며, 공유 오차를 유지한 채 부모보다 이득이 있는지 검사한다.
단순 평균으로 과거/현재의 서로 다른 두 지붕 사이에 새 지붕을 만들지 않는다.

허용오차 안의 후보를 채택하고, 부적격이면 배제하며, 어느 쪽인지 확인할 수 없으면 유보한다.
MVS 관측 자체가 없거나 사용할 수 없으면 `PRIOR/ABSTAIN`만 남는다. 실제 소스 관측으로는
쓸 수 있으나 원본 위치가 최종 허용오차를 넘는 경우와, 관측 자체가 무효인 경우를 구분한다.

조건부 이론은 단순하다. 참 상태가 공동 집합에 포함되고 극값 계산이 보수적이면
`d(g,x_true)≤U(g)`다. **실제 P2의 집합 포함성은 아직 검증되지 않았다.** 추정 오류 범위,
누락 가설, 선형화 나머지, 수치 오차가 모두 이 전제에 들어간다.

P2의 기존 약 4.3m 소스 차이는 검정할 현상이지 오차상한이나 자동 IMAGE 승인값이 아니다.
지지된 정합·소스 오류로도 과거 지붕이 현재 사진과 양립하지 않고, 현재 후보는 위치 검정을
통과해야 IMAGE를 낸다. 다른 영역에서는 PRIOR/FUSION 또는 유보가 정상 결과일 수 있다.

## 4. B: 세부 복원 관련 연구와 구체적 차별성 후보

| 연구 | 참고할 실제 장치 | 우리 문제에 별도로 필요한 부분 |
|---|---|---|
| [2DGS, 2024](https://arxiv.org/html/2403.17888v3) | 원반형 표면 표현, 깊이 distortion·법선 일관성, 깊이 기반 표면 추출 | 과거 prior의 유효성·오차에 따른 보존/수정 허용 |
| [SuGaR, 2024](https://anttwo.github.io/sugar/) | 표면 정렬, Poisson 추출, 삼각형에 Gaussian을 결속하고 메시와 함께 최적화 | A가 확인한 기하 성분을 최종 표면까지 유지하는 제한 |
| [PGSR, 2024](https://zju3dv.github.io/pgsr/) | 평면 깊이 렌더링, 다중뷰 광도·기하 일관성, 노출 보정 | 세부 관측 가능성과 소스 오류에 따른 갱신 범위 |

이 연구들이 임의의 초기 기하를 정확히 고정하면서 모든 세부를 복원한다는 뜻은 아니다.
2DGS는 텍스처 중심 densification이 형상 세부를 놓치거나 규제가 과도한 평활화를 만들 수
있음을 한계로 설명한다. 잔차 마스크만 추가하는 것을 세부 기여로 삼기에는 부족하다.

**제안 표현:** A가 선택·보정한 지붕면/벽/경계의 거친 제어 표면과, 표면 좌표에서의 국소
변위장을 분리한다. Gaussian 중심은 표면에 결속하고 방향은 접평면과 연결한다.
재사용 구현은 gsplat 기반 planar 2D Gaussian을 유지한다. 세부 변위가 거친 높이·기울기
변화를 대신하지 않도록 관측 규모에 따른 성분 분리를 명시한다. 새 돌출물·독립 구조는
기존 면의 자유 변위로 밀어 만들지 않고 현재 영상의 삼각측량 seed와 별도 사용 검정을 요구한다.

**마스크와 갱신을 분리한다.**

- 외관: 가시성·포화·노출 등을 다루는 mask에서 색/SH와 제한된 영상별 노출 보정을 학습한다.
  큰 잔차에 가중을 주는 것은 외관 학습의 후보 장치다.
- 기하 세부: 여러 뷰에서 같은 3D 위치를 지지하고 깊이/경계의 대안을 구별할 수 있는 영역에만
  변위·국소 분할을 연다. RGB 잔차 크기나 영상 edge 하나만으로 이 mask를 만들지 않는다.
- 불확실: 깊이 비용이 평평하거나 복수 해·가림이 남으면 세부 기하를 갱신하지 않는다.
  보이는 색을 학습할 수 있다는 사실과 깊이를 복원할 수 있다는 사실은 다르다.

**최적화:** 먼저 외관·노출을 맞추고, 구조 허용 범위 아래 다중뷰 기하·광도·경계 일관성으로
세부 변위를 갱신하며, 영상 지지가 있는 곳만 표현을 세분한다. 같은 면의 소스 이음새만
연결하고 실제 단차·용마루·유보 경계를 가로질러 평활화하지 않는다. 기준 표면 밖으로 번지는
Gaussian footprint와 opacity에 따른 표면 소실도 확인한다. 제어 메시와 실제 렌더 깊이·법선·
기하 지지 및 최종 추출 표면을 함께 검증한다.

**A→B 연결의 핵심:** A의 가능한 현재위치 집합 안에 결과를 넣는 것만으로 안전하지 않다.
참위치가 집합 반대쪽 끝일 수 있다. 보호할 성분에서는 갱신 뒤에도 `U(S(G))≤ε`를 검사한다.
충분조건으로 같은 대응·거리에서 `U(S0)+d(S(G),S0)≤ε`인 남은 오차 예산을 사용할 수 있다.
이는 보호된 성분의 조건이지 아직 관측하지 않은 모든 세부의 정확도 보장이 아니다.
상관이 있는 성분을 독립 허용 box로 바꾸어 갱신을 승인하지 않는다. 세부 관측이 새 기하나
기존 사용 범위 밖의 변형을 지지하면 기존 판단을 몰래 넘지 않고 해당 후보를 재검정한다.

기여 후보는 **‘과거 prior를 포함한 공동 오류 판단이 지지한 구조를 보존하면서, 현재 관측이
구별하는 세부만 확장하는 재구성’**이다. surface binding·다중뷰 loss·세부 변위 각각의 최초
제안이라는 주장은 하지 않는다. 결합의 이득과 열화 억제를 강한 기존 방법 대비 검증해야 한다.

## 5. 다음 비교의 고정 원칙

1. A: 같은 native 입력·관측·보정 용량·계산 예산으로 강한 정합→판단→조건부 융합과 비교한다.
   M3C2-EP 기반 비교와 [Wu & Vallet, 2026](https://isprs-annals.copernicus.org/articles/XI-2-2026/385/2026/isprs-annals-XI-2-2026-385-2026.html)의
   항공영상–LiDAR 갱신도 인접 비교로 검토한다. 공동 오류법이라는 명칭 자체는 기여가 아니다.
2. B: 동일 A 선택·동일 G0에서 표준 gsplat 2DGS, 구조 고정+외관, 구조 제한+세부를 비교한다.
   색 표현·노출 처리·훈련 예산은 맞추고, densification은 실제 추가 개수·계산량을 함께 보고한다.
3. A 제거 / B 제거 / A+B를 같은 P2에서 나누어 평가한다. 초기 소스 변경을 B의 고유 효과로
   세지 않는다. P2가 MVS 우세여도 valid-prior/MVS-weak 보완 주장을 그 사례 하나로 확인할 수 없다.
4. 외관은 공통 영상 범위와 미복원 비율, 구조는 면/경계/연결성 열화, 세부는 원래 관측 가능한
   지붕 단차·용마루 등 실제 3D 단면/위치와 무텍스처 표면으로 평가한다. 창 등은 P2 영상·참조의
   해상도로 식별 가능한지 먼저 확인한다. 관측하지 못한 세부를 성과 항목으로 가정하지 않는다.
5. 두 소스가 동시에 틀리는 조건·공유 편향·오정합·시기 변화·가림을 개발 검산하고, 오채택과
   유보율을 함께 본다. 기존 P2와 개발 노출 뷰만으로 일반화·확률 보정·박사 기여를 확정하지 않는다.

현재 완료된 것은 기존 실행의 학습 동등성 확인과 문헌 기반 설계 재정리다. 실제 P2의
오류 보정·공동 판단, 이 설계의 세부 형상 최적화와 전체 A+B 비교는 미실행이다.

작업 예외: 추가 문헌 agent 생성은 thread limit으로 거부되어 기존 agent와 root가 분담했다.
일부 출판사 페이지는 HTTP 403으로 열리지 않아 저자/대학 공식 페이지와 공개 논문으로 확인했다.
