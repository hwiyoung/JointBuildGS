# 7.1 기존 방법과의 비교 — 표 (PHD-MAIN-NUMBERS-v1)

- 만든 때 2026-10-16 10:35:00 KST, 스크립트 `scripts/phd/main_numbers_v1/t71.py`. 값은 결과마다의 지표 파일에서 옮겼다. 반올림 전 값·표본·출처는 `t71.json`.
- cm 값 가운데 파일의 저장값(m, 소수 넷째 자리)이 반올림 경계(x.x5 cm)인 칸은 측정 행에서 같은 식으로 반올림 전 값을 다시 구해 그 값을 적었다[새로 셈: 반올림 전 값]. 칸 목록과 두 값은 `cm_edges.md`.
- GeoGS: LoD2는 가림 검사와 깊이 묶음 축척을 고친 판(`trust_LoD2_fix1`; R1은 3단계 5.0에서 다시 한 후처리), 항공 LiDAR는 `geogs_ALS_fix1`. CDGS 칸은 채우기 일 1·9.

**F1의 정의 (1단계 묶음의 코드에서 확인)**

- 학습 시점 TSDF 메시(결과 폴더 post/mesh_tsdf.ply). 결합·학습 전 사전 정보도 같은 TSDF 메시
- 메시를 1 m²당 400점(씨앗 0)으로 넓이에 비례해 뽑는다(cloud.sample_mesh). 건물 표면 칸 안의 삼각형(무게중심이 칸 안이거나 넓이 0.01 m² 넘음)에서 뽑고, 칸 안의 표본만 남긴다
- 건물 표면 칸 = 0.5 m 격자 칸 가운데 칸 중심이 건물 발자국을 2 m 넓힌 범위 안이고 평가 범위의 참값 점이 있는 칸(defs_s1.py bsurf). 지붕과 벽 모두
- 그 칸 안의 평가 범위 참값 점(B0 2,063,378점 = 전체 완전성의 표본)
- 정확도 = 결과 표본 가운데 가장 가까운 참값 점까지 거리가 t 이하인 몫
- 완전성 = 참값 점 가운데 가장 가까운 결과 표본까지 거리가 t 이하인 몫(= 전체 완전성)
- F1 = 2 × 정확도 × 완전성 ÷ (정확도 + 완전성)
- t = 0.2 m, 0.5 m
- scripts/phd/main_stage1_v1/metrics_s1.py 249~289행(summary), src/phd/metrics_v3/cloud.py 53~70행(chamfer_pcf), scripts/phd/main_stage1_v1/defs_s1.py 165~207행(bsurf)
