# 실행 이슈 및 검토 변경 기록

## R1J-001 — 검증 출력 경로 권한

- 문제: 첫 검증 launcher가 `ln -s /work/validation /output`을 실행하면서 `Permission denied`로 종료했다.
- 원인: 비루트 Docker 사용자에게 컨테이너 `/` 아래 symlink 생성 권한이 없었다. Python 검증기는 실행되기 전이었다.
- 조치: 출력 경로를 필수 인자로 받고, 새 validation attempt를 writable bind mount로 연결하는 `run_validation.sh`를 추가했다. 실패 시 source snapshot은 보존했다.
- 해결: `validation_20260916T140730Z_ZUNJ9PVu/result/receipt.json`에서 PASS. 원본·감사·검토 산출물은 변경하지 않았다.
- 남은 위험: 없음. 다른 산출물의 과학적 정확성을 이 기술 PASS가 인증하지 않는다.

## R1J-002 — 초기 검토 맥락 수정

- 문제: 상면 투영만으로 Z11의 배후 통로를 지붕 맥락으로 읽을 수 있었고, Z12/Z13에는 통로와 연결교가 겹쳐 있었다.
- 원인: XY 위치에 서로 다른 높이의 표면이 겹친다.
- 조치: 원영상에 가시점만 표시해 검토한 뒤 Z11 명칭/맥락을 수정하고, Z12/Z13 연결교와 돌출부의 가시 표면 다각형을 추가했다. 녹지 구역의 높은 안정된 구조는 비대상 자동 분류에서 제외해 유보했다.
- 해결: `review_revision: 2` 및 활성 review에 반영. 초기 검토 attempt는 보존했다.
- 남은 위험: 다각형은 검토 맥락을 위한 근사 경계다. 정밀 semantic segmentation이나 면적 GT가 아니다.

## R1J-003 — 이유 문자열 길이

- 문제: 중간 review의 NumPy `U48` 이유 필드에서 49글자 reason이 잘릴 수 있었다.
- 조치: `U80`으로 넓혀 새 최종 review를 생성했다. 판단 수/좌표/후보 정책은 변경하지 않았다.
- 해결: 활성 `review_20260916T140058Z_pvyQNrYK` 및 문자열 보전 검증 PASS. 중간 결과는 보존했다.

## R1J-004 — 이전 감사와 경계 픽셀 수 차이

- 관측: 이전 native 픽셀 총합 128,271,094, 이번 128,271,088, 차이 -6.
- 해석: 두 코드의 float32/float64 역투영 차이와 일치하는 극소수 경계 차이다. 개별 6픽셀의 ID까지 재추적하지 않았으므로 확정 원인으로 단정하지 않는다.
- 처리: 비교 수치와 제한을 검증 receipt에 보존했다. 전체 커버리지 bitset 재구성과 표본 소속 검증은 통과했다.
- 남은 위험: 경계상의 극소수 픽셀 소속 차이. 구역 정확도/과학적 결론을 이 비교로 주장하지 않는다.
