2. 전체 0.5m XY 셀 82,000개에 depth 도착점 존재와 기여 시점 수를 기록했다.

## 3. 판단 방법

- 현재 MVS 표면의 native depth 지지는 ±0.5m에서 조사한다. 같은 광선의 prior가 현재 표면에 부합하는지, 앞에 있는지, 뒤에 있는지, 없는지 별도로 기록한다.
- 후보 분류는 최소 3개 지지 시점, 카메라 위치 폭 5m, 우세 관계 비율 0.67을 개발용 기준으로 사용한다. 큰 차이는 1m 초과다. 이 수치는 정확성 보증이나 검증된 최적 임계값이 아니다.
- prior 표면은 자체 가림 검사를 먼저 통과해야 한다. 현재 표면이 앞에 보이는 경우 **prior가 가려진 것만으로 보정 후보가 되지 않는다**.
- 지붕·벽·지면은 출처별 국소 표면 법선과 기존 terrain-normal 기반 중력 추정을 사용해 구분한다. 입력 두 출처를 합쳐 법선을 맞추지 않는다.
- 객체 맥락과 안정된 표면 관계가 함께 있는 부분만 보존·보완 후보로 둔다. C1 밖에서 prior가 앞에 나타나는 충돌은 여전히 유보한다.
- 녹지·통로의 구역 명칭만으로 모든 높이를 비대상으로 처리하지 않는다. Z12/Z13의 연결교·돌출부는 원영상에서 직접 표시한 다각형과 가시성으로 분리했다.

원영상과 MVS는 같은 입력 계보다. 서로 독립인 두 정답 증거처럼 합산하지 않는다. 기존 fused-MVS 생산에 평가 영상이 포함되어 있어 전체 산출물은 개발용이며, 새 평가 분리나 confirmatory 실험을 구성하지 않는다.
