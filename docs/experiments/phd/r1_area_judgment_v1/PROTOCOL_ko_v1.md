# R1 전체 영역 판단 절차

- Task: `PHD-R1-AREA-JUDGMENT-v1`
- 범위: 승인된 객체축 R1 전체의 입력 기반 구역 판단 초안. CPU 분석·검토이며 학습/수동 loss 가중치 설정은 포함하지 않는다.
- `scientific_verdict: null`

## 1. 무엇을 전체로 볼 것인가

R1 객체축 `u=[-135,70]m`, `v=[-65,35]m`, 20,500m²를 빠짐없이 다룬다. 0.5m XY 셀 82,000개에는 관측 상태를 기록한다. 이 격자는 커버리지 집계용이고 건물 부위의 판단 경계는 아니다. 지붕·외벽·아래 지면처럼 같은 XY에 겹친 표면의 판단은 별도 3D 표면 점으로 보존한다.

기존 C1/S1/U1은 상세 사례로 유지한다. 나머지를 보존이나 비대상으로 자동 간주하지 않는다. 영역 내 관측이 부족한 곳도 지도에 남긴다.

## 2. 첫 층: 실제 입력의 관측 상태

봉인된 588개 학습 영상의 MVS와 ALS prior depth 전체를 읽고 각각의 유효 깊이를 3D로 역투영한다. R1 안에 도달한 XY 셀을 `양쪽 존재 / MVS만 / prior만 / 양쪽 depth 도착점 없음`으로 표시한다. 서로 다른 높이에 점이 있어도 같은 XY 셀에 들어갈 수 있으므로 **양쪽 존재를 표면 일치로 해석하지 않는다**. 카메라 FOV 밖, 가림, 결측 원인은 후속 3D 표면 검토에서 구분한다.

## 3. 둘째 층: 같은 표면을 비교할 수 있는가

- 현재 표면: 기존 R1 전체 fused-MVS 1m XYZ 표본 63,061개를 그대로 사용한다. 각 표면점을 지지하는 현재 native depth의 시점에서 동일 광선의 ALS 표면을 조회한다.
- prior 표면: 새 R1 ALS mesh에서 이미 추출한 초기 후보 표본 중 R1 내부 표본을 별도로 사용한다. prior 자체 가림을 통과한 시점에서 현재 MVS의 일치/앞쪽 관측/뒤쪽 관측/결측을 기록한다.
- current가 prior보다 앞에 보이면 prior가 가려졌을 수 있다. 이것만으로 prior 삭제나 과거 구조 소멸을 판단하지 않는다.
- 이번 분류에는 깊이 차이 ≤0.5m를 일치, >1m를 큰 차이로 사용한다. 최소 3시점과 카메라 위치 폭 5m도 개발용 관측 분리 기준이다. 정확성 또는 독립 관측을 보증하지 않는다. 0.25m 등으로 바꾼 민감도 실험은 이번에 수행하지 않는다.
- 영상·MVS는 같은 입력 계보이므로 두 개의 독립 정답 증거처럼 합산하지 않는다.

## 4. 셋째 층: 건물 부위별 의미와 판단

전체 입력 지지 범위를 잘 보여 주는 학습 영상을 먼저 선택하고, 평면 위치와 원영상의 지붕·외벽·지면·수목·일시적 물체를 대조한다. 영역별 검토표에는 입력 관계, 실제 본 영상, 판단, 남은 불확실성을 함께 쓴다.

| 판단 | 필요한 근거 | 해석 제한 |
|---|---|---|
| 보존 후보 | 여러 현재 관측과 기존 표면이 부합하고, 영상에서도 해당 구조가 확인됨 | 입력 일치만으로 독립 정확도를 인증하지 않음 |
| 보정 후보 | 지지되는 현재 표면과 prior의 차이가 일관되며, 영상에서 건물/변화 관련 표면으로 확인됨 | 큰 depth 차이만으로 실제 변화 원인·시점을 확정하지 않음 |
| 보완 후보 | 현재 구조가 관측되지만 prior에 대응 표면이 부족함 | 새 Gaussian 공급/가중치 설계를 자동 실행하지 않음 |
| 판단 유보 | 시점 지지 부족, 혼합 표면, 경계, 가림, 한쪽만 관측 또는 분류 근거 부족 | prior fallback과 prior 정확성 판정은 다름 |
| 비대상 후보 | 영상에서 수목·차량·일시적 물체 등으로 확인됨 | RGB·기본 학습에서 자동 삭제하지 않음 |

모든 표면을 억지로 보정 또는 보존 중 하나에 넣지 않는다. 순수 입력 관계와 검토한 의미 판단을 별도 필드로 보존한다. 도면의 전체 XY 범위 분류와 표면 점 수의 비율을 혼용하지 않는다.

## 5. 결과와 다음 단계

전체 커버리지 지도, 표면별 입력 관계 지도, 구역별 판단 지도·표, 검토 원영상, 정확한 표본/카메라 ID 및 실행 receipt를 만든다. UAS/LoD2 평가 기하를 이번 판단에 사용하지 않는다. 이 판단 초안으로 기본 대조군을 관찰한 뒤 수동 가중치를 별도로 정한다.
