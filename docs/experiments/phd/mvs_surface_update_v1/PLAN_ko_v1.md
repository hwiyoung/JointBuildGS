# 관측 근거–Gaussian 국소 수정 기술 비교

`PHD-MVS-SURFACE-UPDATE-v1` · 2026-09-15 · `scientific_verdict: null`

사용자는 7단계 결과 구현과 실제 수정 전후 형상·영상 적합도·주변 구조 손상 비교를
승인했다. P1/P2/P3의 기존 D005_Pnative complete Anchor8k를 고정하고, 현재 입력
Prior/MVS의 동일한 관측 자료를 사용한다. 현재 진행 중인 MVS/PGSR 학습을 수정하지 않는다.

각 지역에서 엄격한 근거 후보(없으면 유보), 모호한 후보, 일치 대조를 결정론적으로
선택한다. source별 자체 깊이 일치·동일 사진 비교·완전 비용곡선의 **같은 이웃**이
두 개 이상인지를 확인한다. MVS를 기준으로 Prior를 배제하는 cross-source gate는 없다.
좁은 비용 구간뿐 아니라 절대 비용·격자 간격·탐색 경계·MVS 위치와의 관계를 검사한다.
모든 문턱은 실행 전 config로 고정한 기술 진단 기준이며 정답/확률 보정 주장은 없다.

관측 자료에서 가우시안으로의 연결은 같은 7×7 원패치와 실제 렌더링 기여를 기준으로
한다. 보이는 그림의 64px 확대 영역을 근거 영역으로 확장하지 않는다. 정확한 checkpoint
및 Gaussian ID를 기록하며, 다른 Gaussian의 가림을 유지한 기여 측정을 사용한다.
실제 수정은 별도 복사 상태의 선택된 중심만 MVS 국소 평면 방향으로 최대 0.1m 이동한다.
색·opacity·scale·rotation·비선택 중심은 그대로다. 전체 학습 또는 GaussianUpdate 논문
재현이 아니라, 근거–연결–국소 작동–손상 확인의 기술 실험이다. 근거/연결이 부족하면
유보하고 before=after를 명시한다. 검증되지 않은 영역을 억지로 수정하지 않는다.

비교는 같은 checkpoint의 원 상태, 반복 no-op, 국소 수정 상태다. 기준 영상과 모든
결박 이웃에서 사전에 고정한 target union/annulus/outside를 사용한다. RGB 오차와
형상 변화, 예상 깊이·법선 변화, 실제 중심 이동 및 주변 렌더링 변화를 모두 기록한다.
동일 이미지 계보의 적합도 개선은 독립 정확도가 아니다. 현재 UAS 참조는 수정 결과를
고정한 뒤 별도 CPU 평가에서만 읽으며 선택·정합·이동량에는 들어가지 않는다.

완료 산출물은 7단계+전후 비교 화면, 모바일 카드/PDF, 원 수치와 변환·Gaussian ID,
판정 이유, 실행·검증 receipt다. 기술 성공과 이득/손해의 과학적 판정을 구분한다.
큰 손상이 나타나도 원 결과를 보존하고 실패로 공개한다. 원본 입력·학습·checkpoint
및 이전 진단 산출물은 모두 읽기 전용이며 새 출력 디렉터리에만 기록한다.
