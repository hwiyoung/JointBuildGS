# 이슈와 해석 경계

`PHD-MVS-SURFACE-UPDATE-v1` · `scientific_verdict: null`

- 초기 후보 audit에서 비용곡선 폭 0인 P1 표본의 깊이 간격이 0.55–2.87m였다.
  또한 최저점과 MVS 깊이가 다른 표본이 있었다. 이는 작은 폭만으로 수정 위치를
  정할 수 없음을 보여준다. 실행 전에 spacing≤0.25m와 최저점–MVS≤0.5m를 추가해
  고정했다. 기준을 완화해 통과점을 만들지 않는다.
- 가시성·사진·비용곡선의 이웃들이 서로 달라도 각각 개수만 많으면 통과하는 문제를
  피하기 위해 동일 neighbor ID 교집합을 사용한다. 이 검사는 모델 조건부이며
  독립 실제 가시성 또는 기하 정확도 증명은 아니다.
- 실제 변화/정합 편향/원 Prior 오류의 원인 식별은 미완료다. 작은 국소 수정에 대한
  기술 진단이며 최종 변화 지도 또는 전체 지붕의 업데이트 허가가 아니다.
- 초기 보조 agent 재사용/추가 생성 도구가 thread limit을 반환했다. 두 개의 신규
  bounded agent만 사용하며, 나머지 작성·실행·검증은 주 agent가 수행한다.
- 첫 prepare의 anchor receipt 필드에 원 config의 checkpoint SHA를 넣은 계보 필드
  불일치를 GPU 실행 전 검토에서 발견했다. 두 SHA를 분리한 `prepare_v2`를 만들고
  첫 prepare는 실행에 사용하지 않는다. 기존 checkpoint나 관측 수치는 수정하지 않았다.
- 대표 P2/P3 관측 후보는 종합 관측 기준을 통과했지만 Gaussian 연결 기준에서 유보됐다.
  이를 대표 사례 선택의 우연으로 해석하지 않도록, 같은 관측 기준을 통과한 P2 11개와
  P3 2개 전부를 별도 `prepare_screen`/`screen` 계보로 검사했다. 카메라 ID와 표본 ID
  순서이며 수정 후 성능으로 선택하지 않았다. 문턱은 동일하게 유지했고 모두 유보됐다.
- 연결 기준은 중심 투영 위치, 렌더 alpha≥0.5, 중심과 예상 깊이 차이≤0.25m,
  대상 누적 기여≥0.001, 전체 기여 중 7×7 대상 기여≥50%, 선택 ID≤256,
  대상 alpha의 선택 ID 설명 비율≥5%다. 마지막 5%는 원 `gaussian_probe.py`에 고정된
  기술 기준이며 관측 오차에 대한 확률 보정값이 아니다. 이 기준의 과도한 보수성이나
  예상 깊이를 이용한 표면 연결의 적절성은 아직 검증되지 않았다.
- 최종 실제 수정 Gaussian은 0개다. 전후 형상·영상·UAS 오차 변화 0은 수정 유보에
  따른 동일 상태의 재현성 결과이며, 수정 성능 또는 수정 후 주변 보존의 증명이 아니다.
  실제 시간 변화 영역, 필요한 수정의 회복률, 주변 구조 비손상 성능은 미입증이다.
