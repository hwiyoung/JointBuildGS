> 원자료: `decision_summary.json`. 아래 48행은 이 JSON의 `settings` 배열 순서를 그대로 따른다.

동일한 **64개 prior 소그룹**에 사진 점수 문턱 4개, 높이 허용오차 3개, 뷰쌍 각도 대역 2개, 검사 범위 2개를 적용했다. 각 행의 분모는 64이며 개수는 **n/64**로 적었다. 전체 3,072개 판단 행은 같은 64개 그룹의 반복 평가다. 3,072개의 독립 표본·독립 건물·독립 면적이 아니다.

`baseline PASS`는 원후보의 사진 점수 통과 수다. 나머지 여섯 열은 추가 계산의 서로 배타적인 결과이며, 각 행에서 합계가 64다. 기준선 PASS는 이 결과들과 겹치는 별도 집계이므로 합산하지 않는다. 여기서 SUPPORT와 opposition은 **고정 카메라·정합, 가시성 미검증, 검사한 이산 높이**에 한정된 상태이며 실제 `PRIOR` 사용 승인이나 원후보의 정오 판정이 아니다.

`angle`은 뷰쌍 각도의 상한이고, `extent`는 검사 구간 `[-extent, +extent]`의 반폭이다. 공통 표본·뷰쌍은 전체 측정 범위 ±2 m의 모든 높이에서 먼저 고정하고, 표의 ±1 m·±2 m 구간에 같은 곡선을 적용했다. 이산 격자는 0.125 m 간격이다. 적합 높이 사이를 연속적으로 검증한 것으로 보간하지 않는다.

**τ=0.9인 12개 설정에서는 모두 64/64가 empty K이고 기준선 PASS는 0/64다.** 이는 해당 점수 문턱 아래에서 적합 높이를 찾지 못했다는 측정 결과다. 실제 현재 기하오차의 정답이 없으므로 높은 문턱이 더 정확하다고 해석하지 않는다. 전체 표에서 유리한 설정이나 문턱을 선택하지 않으며, 허용오차와 문턱을 보정된 응용 요구조건으로 승격하지 않는다.

20°·60° 대역 모두 64개 그룹에서 필요한 공통 뷰쌍 수를 충족하여 이 집계의 untestable은 모든 설정에서 0/64다. 이것은 가림·정합 오차·연속 기하의 검증 완료를 의미하지 않는다. 이 표의 개수로 정확도, 오채택률 또는 구제 성공률을 계산하지 않는다.
