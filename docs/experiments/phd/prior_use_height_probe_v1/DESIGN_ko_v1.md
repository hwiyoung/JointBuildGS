## 1. 비교할 계산과 예상되는 결정 차이

| 기존 계산 | 남는 판단 문제 | 추가 계산 | 달라질 수 있는 결정 |
|---|---|---|---|
| 원후보의 현재 영상 간 ZNCC 점수 | 점수가 높아도 허용오차 밖의 높이가 같은 관측을 설명할 수 있음 | 동일 원점군의 수직 대안을 같은 사진·표본·뷰쌍으로 검사하고, 적합 높이 집합의 위치 범위를 계산 | 원후보 점수 통과 → 넓은 대안·여러 해·범위 끝의 해 때문에 유보 |
| 원후보 점수가 문턱 미달 | 문턱 미달이 사용 허용오차 밖의 기하라는 뜻인지는 별도 문제 | 관측에 맞는 높이들이 원후보의 허용 띠 안에 드는지 검사 | 점수 미달 → 검사한 이산 높이에서 조건부 사용 지지 가능 |
| 점수와 대안 반응을 각각 요약 | 그 반응이 후보의 기하오차 수락 조건에 직접 연결되지 않음 | 적합 높이 전체에 대한 최소·최대 위치오차를 계산 | 반대·미확정·조건부 지지를 서로 다른 이유로 기록 |

사진 대조·기하 이동 통제·유보는 기존 연구 및 r4에도 있다. 이번 비교는 **기존 2D-a 점수의 단순 사용**과 **같은 관측의 이산 높이 범위를 이용하는 판단 규칙**의 차이를 분리한다. r4의 미구현 우도 보정·정합·면 전파를 재현하지 않으므로 기준선을 `FULL_R4`로 부르지 않는다. 이 구성요소의 결정 차이가 곧 새로운 알고리즘의 독창성이나 정확도 우위를 뜻하지 않는다.

## 2. 입력과 적용 범위

기존 P2 개발 prism의 원 ALS tile과 원행 번호·표면 소속, exact-937 계보의 PINHOLE 카메라 및 해당 영상만 사용한다. 원좌표는 `raw_tile[point_rows_als]`로 복원하며 비교용 평균 높이·보간 격자·적합 평면으로 대체하지 않는다. 이미 scene-local인 점에 좌표 이동·수직 datum 보정을 다시 적용하지 않는다.

소그룹은 prior의 기존 planar 형상 분류와 고정 XY 격자로 나누며, 다른 표면 ID는 합치지 않는다. 그룹·점·시점의 수 제한은 사진 점수를 보기 전에 결정론적으로 적용한다. 원행 목록과 모든 선정·제외 분모를 저장한다. 기존 planar 타입은 원자산의 형상 분류이며 현재성·지붕 의미·정확도 라벨이 아니다. 퇴화한 XY 지지의 진단값도 남긴다.

**새 측정에서 MVS 기하를 제공하지 않는 통제 입력 조건**이다. 자연적인 MVS 결손에서의 성공이라고 부르지 않는다. 기존 P2 모집영역은 과거 MVS–ALS 관계를 사용해 선정했으므로 모집 자체가 MVS와 독립인 것도 아니다. 영상·카메라 계보는 서로 맞추고 원파일 해시를 확인한다.

이번 모형은 카메라·정합을 고정하고 scene-local Z 위치만 검사한다. FOV의 공통 표본을 맞추지만 현재 가림·빈 공간은 확인하지 않는다. 따라서 결과는 **검사한 높이 격자와 가시성 가정 아래의 판단 변화**다. 연속 위치 전체, 법선·경계, 정합 불확실성, 실제 현재 사용 권한을 확정하지 않는다. `full_current_use_action`은 `null`이다.

## 3. 실행 전에 정한 계산

소그룹 원점군 `P_u`와 수직 대안 `h`의 기하를 `P_u(h)=P_u+(0,0,h)`로 둔다. 각 뷰쌍에서 모든 검사 높이에 공통으로 투영 가능한 동일 원행을 사용해 ZNCC를 계산한다. 분산·표본이 부족한 높이는 미산출이며 점수 0 또는 기각으로 대체하지 않는다. 높이별로 관측이 달라진 결과와 후보 간 비교가 섞이지 않도록, 충분한 공통 표본·뷰쌍을 가진 그룹의 점수 곡선 `S_u(h)`를 두 비교법이 공유한다.

기준선은 `S_u(0)≥τ`이면 후보 사진 점수 통과, 아니면 미통과다. 이는 사용오차를 검증한 `PRIOR`가 아니다. 추가 계산은 다음과 같다.

$$
K_{u,\tau}=\{h\in H:S_u(h)\ge\tau\},\qquad
B_u=\min_{h\in K_{u,\tau}}\frac{|h|}{\varepsilon_h},\qquad
U_u=\max_{h\in K_{u,\tau}}\frac{|h|}{\varepsilon_h}.
$$

`K`가 비지 않고 측정·범위 조건을 충족하면 `U≤1`은 이산 높이 조건부 지지, `B>1`은 이산 높이 반대, 나머지는 미확정이다. 원후보 사진 점수 통과를 추가 계산의 필수 전제로 붙이지 않는다. 원후보 자체 점수가 낮아도 적합 기하가 허용 띠 안에 있을 수 있기 때문이다.

적합 높이가 검사 범위 끝에 닿으면 범위 밖 대안을 배제하지 못했으므로 경계 미확정으로 기록한다. 적합 높이가 없으면 모형 불일치, 공통 관측이 부족하면 검정 불가다. 모두 현재 기하 채택의 근거가 되지 않는다. 여러 적합 구간은 모두 보존한다. 유한 격자 사이를 검사한 것으로 보간하여 연속 보장을 주장하지 않는다.

설정에 적은 사진 문턱·사용 허용오차·각도 대역·검사 범위의 **전체 감도 표**를 보고한다. 사용 허용오차는 가시성 허용거리와 다른 양이며, 이번 값들은 응용 요구조건이나 보정된 안전 문턱으로 확정하지 않는다. 결과를 보고 유리한 조합을 성공선으로 고르지 않는다. 기존 T2의 각도 대역이 과거 결과를 본 뒤 조정됐다는 이력도 보존한다.

## 4. 정답·평가와 산출물

원래 prior의 실제 현재 기하오차는 이번 입력에서 확인하지 않는다. 이동량은 검사한 가설의 위치 차이이며, 그 자체가 현재 오류의 정답은 아니다. 평가용 LiDAR·LoD2를 선정·정합·문턱 조정에 쓰지 않는다. 따라서 실제 사례에서 정확도·오채택률·구제 성공률을 산출하지 않고, **공통 관측의 점수 곡선·판단 전이·지지 및 유보 범위와 사유**를 보고한다.

산출물은 설정·입력·코드·컨테이너 해시, 원행·그룹·시점 목록, 높이·뷰쌍·그룹별 점수와 결측, 모든 감도 조합의 비교표, 대표 곡선과 사진 위치 표시, 실행·검증 영수증, 실패 기록이다. 대표 사례는 사전 정의한 전이 유형별로 결정론적으로 고르며, 해당 유형이 없으면 없다고 보고한다. 모든 그룹의 표를 함께 공개한다.

결과 설명은 각 사례마다 **기존 계산값 → 그 값만으로 남는 문제 → 추가 계산값 → 실제로 바뀐 조건부 판단** 순서로 작성한다. 판단이 그대로인 사례와 검사 불가 사례도 포함한다. 분석식에 맞춘 작은 수치 예시는 코드 검산이며 실제 사진 실험의 성능 근거로 합산하지 않는다.

이 실험의 완료는 계산 차이와 판단 변화가 재현 가능하게 기록됐다는 뜻이다. 이후 전체 판단 설계에서는 현재 가림·공유 카메라 및 정합 오차·연속 기하 범위를 구체화해야 한다. 이 미설계를 실험 성공으로 대체하지 않는다.
