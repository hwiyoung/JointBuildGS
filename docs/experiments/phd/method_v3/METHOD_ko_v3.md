## 1. 입력·출력·경계

- 입력: 동결 현재 영상·카메라(exact-937), 현재 MVS 점군, 옛 ALS 점군(초기 정합 δ⁰ 적용). 색은 판정에 쓰지 않는다.
- 출력: 셀·점마다 `geometry + 출처 + 시기 + 정합 상태 + 원인 책임 + 인증/유보` 를 가진 현재시점 점군. LoD2(Roofer)는 하류 probe.
- 경계: 현재 UAS LiDAR·LoD2 Roof/Z·stable ID·roster 는 평가 전용(score-only). 증거는 한 번 계산해 해시로 동결한다(R1).

## 4. 원인과 처방 (T4)

| 원인 | 3D-a | 3D-b | 3D-c | 2D-a (M 후보 / P 후보) | 처방 |
|---|---|---|---|---|---|
| H_C 양립 | \\|d\\| ≤ LoD | 일치 | — | 양호 / 양호 | 정밀도 융합 |
| H_chg 바뀜 | \\|d\\| > LoD, 국소 | 관통(소실) 또는 차단(출현) | 국소 | 양호 / 불량 | prior 가중 0 |
| H_M 새 측정 오류 | prior 지지·σ_M ≫ σ_P 또는 결손 | 차단(편향) 또는 무착지(결손) | 국소 | 불량 / 양호(또는 부정 없음) | prior 우선 |
| H_δ 정합 | \\|d\\| > LoD, 건물 전체 같은 벡터 | 관통/차단 | **결맞음** | 불량 / δ̂ 후 양호 | δ̂ 갱신 후 둘 다 |
| H_U 비관측 | — | 광선 없음 | — | 평가 불가 | 유보(시효 미인증) |

책임: `E_u(h) = Σ_c −log p(o_{u,c} | h) − log P_u(h)`, `pi_u(h) ∝ exp(−E_u)`, 검정력 없는 채널은 항에서 빠짐, H_U 사전은 r 의 감소 함수.
가중치: `w_{u,s} = pi_{u,s} / σ²_{u,s}`. 인증: 건물별로 pi 를 문턱 이산화한 3분류(현재 확인 / 옛 것 사용·미확인 / 판단 불가).

## 5. 정합 δ 와 상호 검정 (T3·T6)

δ 는 건물·스트립 단위 강체(초기 수직 + 수평 2D). 양립·정합 책임이 높은 단위의 법선 방향 잔차에 GNC 커널로 적합(설계 v2 (10)). 벤치 실측: 0.5 m 부터
셀 판정이 무너지므로 δ 추정은 필수. 상호 검정 = 융합 표면 G 를 셋째 후보로 T2·T1 에 다시 세워 pi 를 갱신(2사이클). 채택 조건 = 같은 증거·판정기의
순차법(정합 1회 → 판정 → 융합)보다 오류율·오염이 낮을 것; 아니면 순차법 채택.

## 6. 재구성 (T5, 연산자 A)

셀마다 MVS 점에 `w_image`, δ̂ 로 옮긴 ALS 점에 `w_prior` 를 주고, 책임이 0 에 가까운 소스는 버리며, 유보 셀은 prior 점을 "현재 미확인"으로 남기거나
비운다. 가중 점군을 셀별 표면으로 정리해 속성 점군을 낸다.

**왜 이 목적함수인가 (2026-09-05 확정).** 셀 `u` 에서 소스 `s` 가 표면 높이를 `z_s` 로 잰다고 하자. 잡음이 정규 `N(0, σ_s²)` 이고 그 소스가 이 자리에서
옳을 책임이 `pi_s` 이면, 후보 높이 `ẑ` 의 음의 로그 사후확률(기대값)은

```text
E(ẑ) = Σ_s pi_s · (ẑ − z_s)² / (2 σ_s²)  =  ½ Σ_s w_s (ẑ − z_s)²,   w_s = pi_s / σ_s²
```

이다. 즉 "가중 제곱 오차"는 설계상의 선택이 아니라 §4 의 잡음 모형과 책임을 그대로 쓴 **최대 사후확률 추정**이며, 해는 정밀도 가중 평균
`ẑ = Σ w_s z_s / Σ w_s`, 사후 분산 `1 / Σ w_s` 다(역분산 가중, 칼만 갱신과 같은 식).

**왜 잘 되나.** (i) 볼록 이차식이라 셀마다 닫힌 형식·유일해·결정론이며 반복·학습률이 없다. (ii) 네 처방이 한 식에서 나온다: `pi_prior ≈ 1` 이면 prior
표면(틀린 MVS 와 평균하지 않음), `pi_image ≈ 1` 이면 prior 탈락, 양립이면 정밀도 융합으로 분산이 두 소스 어느 쪽보다 작아짐, 유보면 항이 없어 값을 만들지
않음. (iii) 품질 비대칭이 자동 반영된다(prism 3: σ_M 0.5 대 σ_P 0.08 이면 prior 가중 40배). (iv) 타깃이 동결 소스(`M`, `T(δ̂)P`)뿐이라 이전 융합 결과를
다시 타깃으로 삼지 않으므로 오차가 누적되지 않는다.

**한계와 보완.** 이 식은 책임이 맞을 때만 옳다 — `pi` 가 0.5/0.5 인데 두 높이가 크게 다르면 가운데 높이(반쯤 틀린 지붕)가 나온다. 그래서 (a) `pi` 는
원인 귀속으로 강한 자리에서 0/1 에 가깝고 약한 자리에서는 유보로 가야 하며(T3·T4 의 몫), (b) 다층 자리는 pairing 의 위층·아래층으로 미리 나누고,
(c) 잡음이 정규가 아닌 소스(MVS 이상점, ALS 투과)는 Huber/GNC 강건 커널로 바꾼다(IRLS 로 여전히 셀별 해). 경사면·벽은 수직 z 대신 법선 방향 거리를
쓴다. 패치 평면성·이웃 매끄러움 항을 붙이면 희소 최소제곱이 되며, 이것이 렌더링 없는 "위치 정련"이다. GS 의 `E_geo`(설계 v2 (9))는 같은 식을 광도 항과
함께 경사로 푸는 것이므로, A 는 그 특수형(광도 없음·닫힌 형식)이다. 비교자: E2(MVS→Roofer), B_I(image-only), B_P(prior-only), B_PR(정합 prior-only), B_U(단순
합집합), B_FW/B_CW(고정/적응 가중), B_SEQ(순차), O_LOCAL(score-only 국소 oracle). 렌더링 최적화(GS)는 방법에 없으며 텍스처 메시가 목적이 될 때만
별도 연산자로 검토한다.

## 7. 검증 계약 (K3)

- 통제 주입(벤치 v1, 확장): 원인별 식별성 혼동행렬, δ 붕괴 문턱, 결맞음 분리 — 필요성의 증거가 아니라 식별성·보정의 증거.
- 실데이터: benign 비열화(양립 자리), 독립 장면의 실제 충돌, 자연 prior 우세 사례(prism 3 형), 자연 결손 사례.
- 비교자 위의 지표: 기하 정확도·완전성, 오염(유령 기하), risk–coverage(유보율 대 오류), 인증 보정, 하류 probe(Roofer O/X).
- kill criterion: local oracle 이 단일 소스보다 낫지 않으면 중재 문제를 접고; 순차 ≈ 상호 검정이면 상호 검정을 접는다.
