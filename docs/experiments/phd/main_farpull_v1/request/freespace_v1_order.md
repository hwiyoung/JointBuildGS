## 2. 구현 — `--jbgs_freespace` 스위치

값은 `off`(기본, 지금과 같음)와 `on`. 바탕은 판 4(혼합 우도 · 범주별, `lt_dynnow`)의 설정 그대로다. 안전줄, 지우기, 다시점 일관성, 외관 보정은 모두 끈다.

학습 반복마다 그 반복의 학습 사진 한 장에 대해:

1. **자료.** 혼합 우도 손실이 이미 쓰는 것을 그대로 쓴다. 자료 s ∈ {사전 정보, MVS}마다 깊이 지도 D_s, 오차 폭 σ_s, 유효 확률 V_s, 바닥 c = 0.1 m⁻¹. 새 자료를 만들지 않는다.
2. **모두 놓아줌 정도 G.** 렌더의 중앙 깊이 D̂(없으면 기대 깊이를 쓰고 `진행.md`에 적는다)로 화소마다
   - r_s = V_s·N(D̂; D_s, σ_s) / (V_s·N(D̂; D_s, σ_s) + (1 − V_s)·c)  (혼합 우도 손실의 정상값일 확률과 같은 식)
   - G = ∏_{s ∈ S(u)} (1 − r_s). S(u)는 그 화소에 자료가 있는 자료들이다. S(u)가 비면 G = 0.
   - G는 판단에만 쓰고 기울기를 끊는다.
3. **자료마다의 붙잡는 거리 m_s.** r_s = 0.5가 되는 거리: m_s = σ_s·√(2·ln(V_s / ((1 − V_s)·c·σ_s·√(2π)))). 로그 안이 1 이하이면 그 자료는 그 화소에서 "비어 있음"을 말하지 않는다(그 자료는 아래 f_i에서 0). 새 문턱을 두지 않는다.
4. **앞에 있음 표시 f_i.** 가우시안 i의 중심을 이 사진에 투영한 화소 u_i, 카메라 깊이 z_i로
   - f_i = max_s [ V_s(u_i) · 1{ z_i < D_s(u_i) − m_s(u_i) } ]. 그 화소에 자료가 없는 s는 0.
   - 적용 범위는 지우기 발주와 같다(건물 윤곽 수평 1 m 안, 보호 가우시안 제외). 범위 밖이면 f_i = 0.
5. **앞에 있는 가우시안의 차지 비율 F.** f_i를 색 대신 넣어 한 번 더 렌더한다. F(u) = Σ_i w_i(u)·f_i. 이 렌더에서는 자리·크기·방향의 기울기를 끊고 **불투명도만 기울기를 받게** 한다. 옮기지 않고 흐리게만 하기 위해서다.
6. **손실.** L_free = 화소 평균 [ G(u)·F(u) ]. 전체 손실에 λ_free·L_free를 더한다. 반복 500부터 30,000까지 건다.
7. **나머지는 그대로.** 밀도 제어, 불투명도 정리(낮은 불투명도 지우기), 불투명도 재설정 규칙을 바꾸지 않는다.

## 3. 학습 전 점검 (학습 없음, 4절보다 먼저)

대상: B173 주변 · 항공 LiDAR 판 4(`lt_dynnow_ALS_s0`) 30,000회 모델, 학습 사진 203장 전부.

1. **누구에게 걸리나.** 가우시안마다 사진 203장에 걸쳐 빈 공간 압력 P_i = Σ_사진 Σ_u G(u)·w_i(u)·f_i 를 셈한다. 무리는 지우기 사전 점검의 가우시안 표식(`diagnostic_labels.npz`)을 그대로 쓴다: 참값 τ 안 지붕, 참값 τ 안 벽, 뜬 가우시안(지붕·벽과 겹친 것을 뺀 13,934개), 그 밖.
   - 무리마다 P의 분위수(50, 90, 99 %)와 P > 0인 비율.
   - 뜬 가우시안의 P가 지붕·벽 가우시안의 P보다 클 확률(순위 비교). **0.8 아래이면 학습하지 않고 알린다.**
   - 칸(0~6)마다 G > 0.5인 화소 비율. 칸 2(보존)에서 이 비율을 따로 적는다.
2. **무게 λ_free 정하기.** 같은 모델에서 뜬 가우시안의 불투명도에 대한 사진 손실 기울기 크기의 중앙값 a와, λ_free = 1일 때 빈 공간 손실 기울기 크기의 중앙값 b를 사진 203장에 걸쳐 셈한다. λ₁ = a / b(두 힘이 같은 크기), λ₄ = 4·a / b. 두 값을 잠근다.
3. **그림.** B173 날개, 뜬면-1, 뜬면-2가 보이는 학습 사진 하나씩에 대해, 사진 · G 지도 · F 지도를 나란히 둔 그림 세 장. 덮개 화소에 G와 F가 켜지고, 지붕과 보존 칸 화소에서 꺼지는지 눈으로 본다.
