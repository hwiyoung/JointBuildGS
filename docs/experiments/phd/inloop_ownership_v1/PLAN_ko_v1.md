## 0. 무엇을 확인하나

검사 뷰(색 학습에서 뺀 뷰)에서 렌더와 사진의 창 단위 무늬 유사도를 면별로 모아 **면의 소유자(prior / 영상 / 둘 다 / 유보 / 없음)를
2,000 iteration마다 다시 정하는 루프**가, 전역 계수만 쓰는 같은 GS보다 P1의 낡은 지붕을 배율 없이 걷어내면서 주변을 손상시키지 않는지 확인한다.
가중치는 소유자가 항을 켜고 끄는 스위치이고, 켜진 MVS 항 안의 크기만 다시점 일관성 ρ로 둔다. 첫 판은 ρ=1이다.

## 0.1 방법 한 장 — CDGS와의 대응

아래 §1의 Q-A~Q-D는 방법의 단계가 아니라 **검증 질문**이다. 방법 자체는 CDGS의 픽셀 가중 깊이 손실과 같은 자리에 들어간다.

| | CDGS | 이 방법 |
|---|---|---|
| 루프 전 계산 | 픽셀별 confidence c(u) 스칼라 | 픽셀별 소유자 o(u) ∈ {영상, prior, 둘 다, 유보, 없음}, 선택적으로 MVS 일관성 ρ(u) |
| 계산 근거 | 여러 단서의 일치 | 두 후보 표면 각각으로 사진 A→B warp-NCC와 광선 관통·차단, 면 단위 집계 |
| 손실 | L_RGB + Σ c(u)·\|D̂−D_prior\| | L_RGB + Σ k_P(u)·\|D̂−D_P\| + k_M(u)·\|D̂−D_M\|, k는 소유자가 정하는 0 또는 기존 계수 |
| Gaussian | 손실에 따라 조정, 새 변수 없음 | 같음. 추가는 영상 소유 면의 보호 해제뿐(GeoGS 기존 기제) |
| 지도 갱신 | 없음 | A1 없음. A2만 2,000 it마다 |

```text
# 학습 전 (A1, A2 공통)
for f in faces:   owner[f] = judge(P_f, M_f, photos)                 # warp-NCC + 광선, 면 집계. GS 없음
for i in views:   K_P[i], K_M[i] = raster(owner, face_id_map[i])     # CDGS의 c(u) 자리, 항이 둘

# 학습 (GeoGS 그대로, 모든 Gaussian, 새 변수 없음)
for it in 8001..30000:
    L = L_RGB + Σ_u K_P[i](u)·|D̂−D_P| + K_M[i](u)·|D̂−D_M| + reg
    if A2 and it % 2000 == 0:
        r[f] = 1 − NCC(render(check views), photo(check views))  면별   # 색 학습에 안 쓴 뷰. 학습 loss는 판사가 아님
        for f with r[f] > τ:  owner[f] = 반대 소스 (면당 최대 2회, 하락이면 확정, 아니면 없음)
        K_P, K_M, protection = update(owner)
```

판사는 두 곳 모두 사진이다. 학습 전에는 사진 대 사진(후보 표면으로 warp), 학습 중에는 색을 학습하지 않은 검사 뷰의 사진 대 렌더. 깊이 목표에 대한 학습 loss는 어느 목표로 감독하든 줄어들므로 판정에 쓰지 않는다. 근거: 손실 형태 = CDGS·GeoGS, 감독 선별 = NeuRIS·AGS-Mesh의 다시점 사진 일치 게이트, 두 후보 대조 = Taneja 2015, 3D 판결의 뷰 마스크 되쓰기 = CL-Splats.

**연속형(9-17 사용자 방향, 채택안).** 이산 소유자 대신 픽셀별 [0,1] 지도 세 장을 학습 전에 계산한다. CDGS(arXiv 2502.14684: C = 0.2·C_e + 0.5·C_t + 0.3·C_g, 학습 전 고정, 픽셀 가중 L1)와 같은 구조이며, 소스가 둘이라 지도가 셋이다.

| 지도 | 뜻 | 근거 |
|---|---|---|
| v(u) | prior가 아직 맞을 확률 | warp-NCC Δ·f, 광선 관통·차단 비율, 검정력 r의 보정 로지스틱(주입 벤치로 보정), 면 단위 평활 |
| g(u) | 두 후보 중 하나라도 사진을 설명할 확률 | 두 후보의 최고 사진 점수. 둘 다 낮으면 두 항 모두 소멸 |
| ρ(u) | MVS 정밀도 | CDGS 세 단서(에지·무늬·깊이 불연속) + 다시점 일치 수 |

```text
k_P(u) = c_P · g(u) · v(u)
k_M(u) = c_M · g(u) · (1 − v(u)) · ρ(u)
```

L1 아래에서 v>0.5는 prior, v<0.5는 영상, v≈0.5는 두 gradient 상쇄로 제자리(자연 유보). §2의 스위치표는 v, g ∈ {0,1}의 특수 경우다. A2의 갱신은 뒤집기가 아니라 검사 뷰 증거에 의한 v의 점진 갱신(logit에 증거 항 가산, 면당 상한)이다. 분모는 유효 픽셀 수로 고정한다. GeoGS 기존 `use_confidence` 경로는 가중치 합으로 나누므로 쓰지 않는다. 두 목표 사이의 중간 표면은 만들지 않으며(L1 중앙값 성질) 이것이 의도한 동작이다.

## 0.2 계산 단위 — depth map (9-17 사용자 방향, 격자 폐기)

지도 XY 격자를 두지 않는다. 기준 뷰 i의 픽셀 u와 두 후보 깊이 D_P(u)·D_M(u)가 곧 3D 점이므로 모든 증거를 depth map 연산으로 계산하고, 뷰별 픽셀 가중 그림으로 저장한다. 3D 요소는 카메라 자세와 prior 면 번호(각 뷰에 렌더한 면 ID 그림)뿐이다.

| 계산 | 정의 | 출력 |
|---|---|---|
| ① 차이 | 같은 광선의 D_M − D_P와 창 안 퍼짐(LoD) → 같다/다르다/한쪽만 | 판정 대상 픽셀 |
| ② 두 가정 사진 대조 | u 주변 창을 D_P로 이웃 j에 옮겨 NCC_P, D_M으로 옮겨 NCC_M. 교차각 ≤ 20° 이웃 전부 | Δ, f(M>P), r |
| ③ 광선 검사(image space 판) | X_P(u)를 j에 투영, j의 MVS 깊이가 X_P보다 멀면 관통, 가까우면 차단, 같으면 일치 | 관통·차단·일치 비율 |
| ④ MVS 정확도 | X_M(u)를 이웃에 투영해 일치 뷰 수 n → ρ = min(1, n/3) | ρ |
| ⑤ 면 집계 | 뷰별 면 ID 그림으로 같은 면 픽셀을 전 뷰에 걸쳐 합산, 미검사 픽셀 상속, 분할·유보 규칙 동일 | 면 답 |
| ⑥ 가중 그림 | k_P(u) = c_P·g·v, k_M(u) = c_M·ρ·g·(1−v) | 뷰별 2장 |

남는 척도 선택은 NCC 창(무늬 규모, 2 m)과 면(prior 점 평면 조각)뿐이며 둘 다 벤치로 조정한다. 앞선 픽셀 단위 시도(`irregular_source_masks_v1`)의 95~100 % 유보는 33 깊이 비용곡선·0.25 m 간격·완전 패치 조건 때문이었고, ②는 두 깊이만 비교하므로 그 제약이 없다. §3의 "30×30 도메인 안 소유자 지도"는 "prior 면이 렌더되는 픽셀"로 읽는다.

## 3. 공통 고정

- **지역**: P1. 소유자 지도는 30×30 m 평가 도메인 `x[-23,7], y[-21,9]` 안에서만 정의한다. 파일럿 prism의 옛 면 57·새 면 267이 이 도메인이다. 80×80 m 학습 문맥의 나머지는 A0과 같은 전역 계수. 도메인 경계 1 m 띠는 유보.
- **뷰**: train 98 유지. 검사 뷰 = 이름순 4장 중 1장(약 24장)에서 `0100_D`를 제외하고, 광장을 1,000 px 이상 보는 8장 중 2장(후보 `0005_D`, `0009_D`)을 강제 포함한다. 검사 뷰는 RGB 손실에서만 제외하고 깊이 손실은 유지한다. 평가 15장은 손대지 않는다.
- **anchor**: 검사 뷰 RGB 제외로 8k를 다시 학습한 `Anchor8k-hold`. 다섯 arm 공통. 기존 Anchor8k와 직접 비교하지 않는다.
- **계수·보호**: prior .005(A0′만 .0005), MVS .05, dynamic 끔, native 보호, 카메라 순서·RNG·학습 길이 30k·기하 정규화 동일.
- **색**: 첫 판은 검사 뷰 제외만으로 카무플라주를 막는다. SH 0차 제한과 도전 구간 색 동결은 Q-A 실패 시의 강화 변형이다.
- **검사 통계**: 검사 뷰마다 2 m 창(픽셀 크기는 깊이로 환산) ZNCC, 무늬 게이트는 T2의 2D-c 문턱 재사용. 면 통계 = 창 잔차 중앙값과 τ 초과 창 비율. 검사 뷰에 안 보이거나 무늬 창이 3개 미만인 면은 유보.
- **면**: 파일럿 옛 면(ALS)·새 면(MVS) 재사용. 픽셀→면 = 각 뷰에 P 높이장과 M 높이장을 3배 해상도 z-buffer로 그려 면 ID 부여(T2 자기 가시성 코드). Gaussian→면 = 중심에서 0.5 m 안 최근접 prior 점의 면. 보호 해제는 이 소속으로만.
- **도전 규칙**: 잔차 > τ인 면은 소유자를 반대 소스로 바꿔 한 구간 학습하고 재검사. 하락이면 확정·잠금, 아니면 "없음". MVS 일치 뷰 2 미만 면은 영상으로 바꾸지 않고, prior 없는 면은 prior로 바꾸지 않는다. 확정 면은 이후 큰 여유(τ의 2배)로 지지 않는 한 유지.
- **추출·평가**: raw TSDF512 동일 파라미터. UAS 동일 참조점 ID 짝 집계 recovered/damaged @0.5/1.0 m(기존 P1 후처리 코드). 층 = 수동 R1/R2/R3 마스크를 **평가 층으로만** 사용.
- **부수 필수**: 추출 전 모든 arm에서 `0100_D` 누적 알파 렌더 중앙값을 기록한다. 기존 α0/1/4도 같이 재서 α4 후처리 편이(−2.8 % 균일)의 원인을 닫는다. 편이가 있으면 정규화 깊이로 재평가한다.

## 5. 측정 항목

- 면별 시계열: 검사 잔차, 소유자, 도전 이력, 보호 해제 Gaussian 수, 항별 계수 합.
- R1·other_used·excluded 입력 적합 시계열(기존 trace 형식).
- 최종: UAS 짝 집계 @0.5/1.0(P1 prism, 층별), 표면 F1, 누적 알파 중앙값, Gaussian 수·보호 수.
- 정성: `0100_D`와 검사 뷰 2장의 RGB·깊이·소유자 오버레이, 단면 X=−8·Y=−6.

## 6. 위험과 대응

- 검사 뷰 제외로 색 품질이 낮아져 잔차가 전체적으로 올라간다 → 상대 문턱(양립 면 p90)으로 흡수. 모든 arm이 같은 anchor라 공정.
- 옛 지붕 면 잔차가 8k에서 안 갈린다(무늬 부족·그림자) → Q-A kill 규칙. SH 0차·색 동결 변형은 별도 attempt로만.
- 도전이 진동한다 → 면당 2회 상한, 확정 후 잠금.
- 30×30 밖에 면이 없다 → 밖은 전역 계수. 다음 판에서 문맥 전체로 면 확장.
- 새 anchor 때문에 기존 G·α 결과와 직접 비교가 안 된다 → 계획 내 arm끼리 비교, 기존은 참고 수치.
- α4 후처리 편이 미해결 → 단계 6의 누적 알파 검사를 통과한 결과만 UAS 비교에 쓴다.
