# PHD-MAIN-RESCORE-v1 채점기

채점기 준비됨. `scripts/phd/main_rescore_v1/score_mesh.py`가 새 τ·칸과 기둥 규칙으로 최종 메시 하나를 센다. 학습하지 않는다. scientific_verdict: null.

2026-11-04 01:59 수정: `surface_tau.py`의 `reference_surface_kind_v1`을 적용한다. LoD2 장면 참값은 기존 참값의 지붕·벽 종류, 결과 점은 최근접 참값 면의 종류, 영역 참값은 기존 `rows.kind`로 지붕·벽 τ를 정한다. 기둥 소속과 거리 계산은 그대로다. 이전에 가까운 패치 종류로 τ를 정한 LoD2 점수는 `recount_wall_tau.py`로 저장된 거리·좌표에서 재집계하며 수정 전 값을 보존한다. ALS와 옛 규칙 재현의 단일 τ는 영향 없다. FINALTRAIN 호출 방식은 동일하다.

현재 B173 주변 두 사전 정보의 새 칸과 공통 시점이 준비됐다. 실제 옛 학습 시점 메시에서 표본 400점/m²·seed 0과 거리를 다시 구한 재현은 r8, 기준선 모두 네 값 각각 0.1 %p/0.1 cm 이내다. `tables/reproduction_full_replay.json` 참조. 기둥 경계·중복·동률 및 원본 정리와 정점/삼각형 동일성 검증도 통과했다.

저장소에서 RESCORE 출력으로 실행하는 예:

```bash
bash scripts/phd/main_rescore_v1/run.sh score_final \
  score_mesh.py B173nb_b10 ALS UNIQUE_KEY \
  /art/phase-payloads/phd/main_rescore_v1/PHD-MAIN-RESCORE-v1/meshes/KEY/final.ply
```

결과는 `PH/main_rescore_v1/PHD-MAIN-RESCORE-v1/scores/UNIQUE_KEY/values.json`과 `points.npz`다. values에는 scene, cells(0,1,2,4,3), band, offsets, diagnostic, 입력/코드 해시가 있다. 비율은 0~1, 거리는 m이다. cells의 표본 수는 기존 참값 행 솎기를 따른다. 장면 전체 참값은 건물 표면 화소의 ULS, B0의 영역 참조는 기존 ULS+primary 규칙이다. 결과 법선 거리의 기존 가로 거리 0.5 m 유효성 제한을 보존하고 제외 비율을 diagnostic에 적는다. 평균 거리는 자르지 않는다.

FINALTRAIN은 본인 출력 폴더를 쓰도록 같은 CPU Docker(jointbuildgs:dev, nice 19, 32 GiB 이하)에 다음 환경변수를 지정하면 된다. `/repo`, `/art`, `/cfg`는 이 저장소, 기존 외부 아티팩트, RESCORE 설정의 읽기 전용 마운트다. `/out`은 FINALTRAIN이 쓰도록 허가된 출력 마운트다.

```bash
export RESCORE_OUTPUT_ROOT=/out/rescore
export RESCORE_DOC_ROOT=/out/rescore/logs
export RESCORE_CELLS_ROOT=/art/phase-payloads/phd/main_rescore_v1/PHD-MAIN-RESCORE-v1/cells_v2
python -B -u /repo/scripts/phd/main_rescore_v1/score_mesh.py \
  B173nb_b10 ALS FINALTRAIN_STATE_KEY /out/path/to/final.ply
```

최종 메시 입력 조건: 공통 학습+가상 시점, TSDF 0.05 m/0.25 m, 원본 연결 성분 상위 50개 및 평가 범위 자르기. 공통 시점은 RESCORE payload의 `views/B173nb_b10.json`이다. 파일에는 K, W2C, 크기와 virtual 여부가 있다. 학습 시점 메시는 별도로 두고 비교에만 쓴다. 30,000회가 없는 r8 LoD2의 7,000회를 30,000회로 표시하지 않는다.

메시 제작 드라이버는 `render_model.py`(각 방법 자체 렌더러), `mesh_pipeline.py`(원본 타일 TSDF), `bounded_cleanup.py`와 `cleanup.cpp`다. `run_mesh.sh jobs/KEY.json final`은 RESCORE 폴더 전용 실행 예다. 다른 작업에서 쓰면 입출력 경로와 작업 json을 본인 권한 범위로 설정한다. 연결 성분 정리는 같은 공유 변·삼각형 수 문턱·동률 유지·최소 50 삼각형 규칙을 메모리 제한 안에서 구현했다. 첫 원본 정리 호출 실패는 issues.md에 보존했다.

ALS는 JA에서 다시 추정한 법선과 JA의 tangent(n) 방식을 쓰고, 기둥 중심은 centre+prior_height_m*normal이다. LoD2는 원래 패치 접선이다. 두 경우 단면은 0.25 m 정사각형이며 ±10 m/±5 m 범위다. 기존 참값 점 소유 패치는 source_index로 JA patch_id에 연결한다. 벽 참값→메시는 최근접 면 점 변위를 참값 법선에 투영하며, 결과→참값은 앞 작업의 법선 거리 정의를 유지한다. 재현 모드 `--legacy`만 옛 τ=0.147 m와 옛 유클리드 참값 거리를 쓴다.

그림용 points 파일은 표본 위치, 거리, τ, 소유 패치와 참값 행 거리까지 담는다. 학습 목표를 분석하는 표 7.7과 그림 스크립트는 이후 순서에서 추가된다.
