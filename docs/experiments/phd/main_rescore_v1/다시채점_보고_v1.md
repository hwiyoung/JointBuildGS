## 바꾼 것과 확인 불가

B0·R1은 stage1 gpu_s1.py:307-314의 unseen.npz 존재 조건과 fill virtual/vv_defs.py:47-54에서 가상 시점 대상이 아니었다. defs_s1.py:209-217도 B173 두 범위에만 unseen 파일을 만들며, regions_v3.py:31-32,71-75의 대상은 고정된 B173 건물이다. B0/R1로 일반화하려면 새 대상 선택이 필요하므로 만들지 않았다. 이 발주의 freeze_views 초기 실행은 파일 부재로 실패했다. 원래 학습 시점 목록만 기록해 기존 학습 시점 메시를 확인·복사했다. 최종 메시를 학습 시점 메시로 대신하지 않았으며, 최종 값·조건부 저하 진단은 확인 불가다. 목표의 분류·넓이·참값 수는 계산했고 결과 완전성은 비웠다. 변경은 이 발주의 τ 제거 규칙, 결과 면, 기둥 소속, 목표와 표시 규칙 및 구현 오류 수정에 한정했다. 옮긴 원본 함수와 변경 사유는 각 스크립트·사용법·issues.md에 기록했다. τ 수정 전 입력과 원래 결과는 읽기 전용이었다. B173만은 기존 식으로 참값 법선을 이 발주 출력에서 계산해 장면 전체만 셌으며, 없는 JUDGEAPPLY 칸·기둥 값은 비워 두었다. 원본 MVS 표면·기준선이 없는 항목도 확인 불가다.

시간 어림은 첫 최종 메시의 실측으로 10.9808시간이었다. 덧붙임 1에 따라 멈추지 않았다. 각 단계 실측과 GPU 대기는 timing_summary.json과 progress.md에 있다. 최종 점검과 묶음 검사는 final_validation.json, package_receipt.json에 별도로 기록한다.
