# 실행 문제·정의 적용 기록

- v2가 v1과 덧붙임 1을 대체. 모의의 결과 면 생성은 3.3의 명시 지시 적용.
- 단계 2는 iterations=30000 일정과 학습률을 유지하고 --jbgs_stop_after 15000으로 정지한다.
- 단위 점검의 분할 연산에서 CuBLAS deterministic workspace 미설정으로 실행 오류. r23_failed_cublas 보존. 단위 점검에만 CUBLAS_WORKSPACE_CONFIG=:4096:8을 공통 지정해 재실행; 학습 설정 변경 없음.
- 단계 1 준비 표 출력에서 사전 정보 이름 변수와 prior 마스크 이름이 겹쳐 JSON 직렬화 오류. 이름 분리 후 저장된 최근접 거리 캐시를 재사용해 한 번 재실행.
- 채점 기준 칸은 참값 점 단위다. 패치가 여러 새 칸에 걸치므로 목표 넓이는 기존 패치 넓이를 그 패치 참값 점 수 비율로 분할하고, 참값 점 없는 패치 넓이는 따로 보고한다. 결과점의 새 칸은 기존 기둥 소속을 유지한 뒤 같은 소속의 가장 가까운 참값 행으로 연결한다. 거리와 유효성 규칙은 원 채점기 그대로다.
- 단계 0 그림 첫 출력의 한글 글꼴 검색 실패를 발견. 설치된 Noto TTC를 명시 등록해 그림만 다시 출력하고 4장 시각 확인 통과. 거리 재계산 없음.
- V0 풀림 중 현재 후보가 다시 생긴 점이 있어 현재 위치 사유를 가·나에 강제로 넣지 않는다. 별도 현재 유효 후보 항목 및 alpha×T 기여로 보고한다.
- 단계 0 게시 전 Git 경로 검사에서 한글 경로의 기본 따옴표 이스케이프를 실제 경로로 오인. NUL 구분 경로로 고침; 이미 추가된 RELEASE 경로만 검사·커밋하며 다른 인덱스는 건드리지 않음.
- 단계 1 요약에서 기존 cell 키를 중복 전달해 출력 오류. 원 점 파일은 그대로 두고 행 사전 병합만 고쳐 재출력.
- 면 없음 점은 3.2대로 참값 투영 화소의 실제 기여자를 센다. 전경 가림도 포함하며, 가림 없이 보는 시점 수는 별도로 센다. 예비 조인의 clear 조건이 꼬리표에도 걸린 부분을 분리하고 저장한 계보로만 다시 조인; 렌더 재실행 없음.
- 단계 2 그림 검토에서 빨간 표식이 풀림 사건을 낳은 밀도 제어 시점만 가리켰음을 확인. 원 reattach 기록의 모든 실제 밀도 제어 점검 시점으로 표식만 바로잡음. 사건 셈·학습 결정은 불변이며 처음 묶음은 packaging_attempt1으로 보존.
- 단계 0 묶음에 최대 차이 위치의 적음 표식·실제 지붕/벽 τ·두 칸 기준 장면 표·상위 정의 차이의 추가 표를 합침. 거리와 채점값은 재계산하지 않았고 최초 전달 ZIP은 before_supplement로 보존.
