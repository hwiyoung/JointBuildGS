CPU 호출 형식: `bash scripts/phd/main_release_v1/run_cpu.sh <로그이름> <스크립트.py> [인자]`. CPU 프로세스는 GPU 노출 없이 nice 19, 6 CPU, RAM 32 GiB 제한이다. 학습·계보 명령은 `gpu_job.command()`가 구성하며 각 학습 판의 `attempt1/command.json`에 실제 전체 명령을 보존했다. 원 실행 이미지 SHA는 주 설정의 `docker_images`다.

모의는 R1 ALS 가→나→다, R1 LoD2 가→나→다 순서로 실행했다. `<key>`는 `R1rep_b10__<ALS|LoD2>__sim_<delete_released|pull_released|delete_background>`다. 새로운 학습은 기록 판 두 개뿐이다. 단계 3 규칙 구현·단위 점검 코드는 있지만 진입 조건이 거짓이므로 `rl_*` 판은 만들지 않았다.

TSDF는 기존과 같은 0.05 m 복셀·0.25 m truncation·원 학습 시점만 사용했다. 타일은 메모리 제한을 위한 동일 계산이며 원 bounded merge와 cleanup(큰 연결 성분 50개, 동률 보존, 평가 사각형 자르기)을 재사용했다. 기존 V0·비교 방법의 PLY와 메시를 다시 만들지 않았다.

새 칸의 `-1`은 사전 정보 면이 기둥 안에 없음이다. 기존 칸과 합치지 않는다. 꼬리표 표의 결과 종류 4는 벽 앞·뒤 카메라 대응 확인 불가 18점이며 새 칸 번호 4와 별개의 열이다. 기록 사건 원본의 경로·해시는 `events/*/receipt.json`에 있다. 원 RESCORE·FINALTRAIN 계보는 주 설정, `score_inputs.lock.json`, 각 `binding.json`을 따른다.
