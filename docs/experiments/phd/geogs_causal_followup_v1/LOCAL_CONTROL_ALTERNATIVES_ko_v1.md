# 전역 prior 가중치의 한계와 국소 제어 대안

2026-09-10 · `scientific_verdict: null` · 문헌·기존 결과 기반 설계 검토

## 1. 사용자 가설과 확인된 범위

사용자 가설은 유효한 prior 구조의 보존과 잘못된 구조의 수정에 필요한 제약 강도가 다르면, 전역 prior 깊이 가중치를 낮추는 것만으로 보존·수정·세부·외관 요구를 함께 만족시키기 어렵다는 것이다. P3를 보존 검증 사례로 포함하는 것은 타당하다. 다만 P3 전체가 무변화이고 prior가 정확하다는 참조 검증, 전역 가중치로는 항상 불가능하다는 결론은 아직 아니다.

같은 전역 계수라도 국소 잔차·관측 수·가시성·표현·gradient가 달라 결과는 위치별로 달라진다. 따라서 전역 계수 자체가 국소 적응을 불가능하게 하지는 않는다. 검증할 것은 기존 목적함수·표현·보호 체계에서 하나의 전역 설정이 요구되는 복원 결과를 동시에 만족시키는가이다.

P2 내부에서도 큰 구조 변화부와 prior에 유용한 형상이 있는 반복 골의 요구를 함께 볼 수 있다. P1/P2는 수정, P3는 보존으로 건물 전체를 이진 분류하는 것이 유일한 검증 방식은 아니다.

## 2. 기존 P3 결과를 다시 확인한 내용

Docker에서 이미 계산된 final1024 raw/post JSON과 렌더 receipt를 읽었다. 조건은 native 보호 유지, prior 깊이 `.005→.0005`, 표면 표본/참조 voxel 각각 .1m다. 앞선 P2 골 그림의 512 추출과 혼합하지 않는다.

## 3. 마스크와 대안은 무엇이 다른가

마스크를 0/1 영역 구분으로 쓰면 다음 대안들이 있다. 마스크를 연속적인 반영 정도까지 포함하는 넓은 뜻으로 쓰면 소프트 가중치는 그 범주 안이다. 이름만 다른 독립 방법으로 세지 않는다. 아래는 설계 후보이며 우위·필요성·신규성 확정이 아니다.

| 설계 축 | 동작 | 이진 영역 mask와 다른 점 | 남는 문제 |
|---|---|---|---|
| 관측별 연속 신뢰도 | 각 prior·영상 깊이 관측의 지지와 불확실성에 따라 영향 조절 | 같은 위치에서도 시선·깊이·법선별 가중치를 다르게 함 | confidence가 실제 위치오차·현재성을 보장하지 않음; 나쁜 값 양쪽을 평균할 수 있음 |
| 강건 추정·반복 재가중 | 정규화한 잔차에 따라 과도한 감독 영향 제한 | 별도 변화 검출 mask 없이 손실에서 영향 조절 | 잘못된 prior 초기값과 다른 정확한 현재 관측을 outlier로 기각할 수 있음 |
| 변수·방향별 제약과 제한된 갱신 | 지지되는 평면 위치·방향의 변동은 제한하고, 관측되는 세부·외관 수정은 허용 | 영역 전체의 고정/해제 대신 바꿀 자유도를 지정 | 보호할 성분의 증거가 필요; loss 감소만으로 기하 비악화 보장 안 됨 |
| 기준 구조와 수정 표현 분리 | 구조 변형, 국소 세부 추가, 외관, 생성·삭제를 별도 변수로 표현 | 가중치보다 수정 가능한 형태와 모델 변경 경로를 설계 | 작은 변위·추가만으로 큰 변화/제거를 처리할 수 없음; 중복 표면 가능 |
| 정합·외관 등 공유 변수의 별도 추정 | 여러 위치의 불일치를 설명하는 카메라·정합·노출을 근거에 따라 추정 | 각 영역을 약화하기 전에 공통 오차를 설명 | 추가 자유도가 진짜 형상 변화를 흡수할 수 있어 식별성·기준 제약 필요 |

현재 GeoGS 깊이 손실은 이미 L1이다. 따라서 단순히 'robust loss를 넣는다'는 설명은 부족하다. 어떤 잔차를 어떤 척도로 정규화하고 어느 관측의 영향을 줄일지, 초기 prior와 다른 현재의 일관된 증거를 어떻게 살릴지가 실제 설계 대상이다.

기준 구조와 세부를 분리하더라도 'prior=항상 큰 구조, 영상=항상 세부'로 고정하지 않는다. P2 골처럼 기존 자산이 더 유용한 세부를 가질 수 있다. 또한 정확한 큰 구조의 보존이 같은 공간의 세부 추가·현재 외관 갱신을 막지 않아야 한다.

## 4. 가장 가까운 기존 해결책

문헌 주장은 아래 원문에서 이번에 확인했다. 이 표의 구성요소 참고 연구가 우리 입력·출력 조건을 직접 해결한다고 주장하지 않는다.

- [AGS-Mesh v2 §4.1–4.2, 식4–8](https://arxiv.org/html/2411.19271v2): 센서 깊이와 영상 유래 법선의 일관성으로 깊이를 필터링하고, 최적화 중 법선 감독을 완화한다. 해당 필터는 threshold 방식이므로 연속 소프트 가중치로 잘못 분류하지 않는다. 실내 센서 깊이·예측 법선 조건이며 과거 외부 기하의 현재성 판단과 다르다.
- [UNG-GS v1 §3.2–3.3, 식8–12](https://arxiv.org/html/2503.11172v1): 학습한 공간 불확실성이 깊이 합성과 법선 계산의 기여에 영향을 준다. 기존 기하 prior의 유효성을 판정하는 연구가 아니라, 불확실성을 감독 외 경로에도 쓰는 구성요소 참고다.
- [Ceres 공식 문서, LossFunction](https://ceres-solver.readthedocs.io/latest/nnls_modeling.html#lossfunction): 강건 손실은 큰 잔차 항의 영향을 줄이는 기존 추정 기법이다. 이를 현재성 분류 또는 복원 성공 보장으로 해석하지 않는다.
- [GaussianUpdate v1 §3.2](https://arxiv.org/html/2508.08867v1): 외관과 기하 갱신을 단계적으로 분리하고 기존 Gaussian의 제거 계수와 새 Gaussian을 최적화한다. [CL-Splats v2 §3](https://arxiv.org/html/2506.21117v2)는 변경 영역에 따른 국소 갱신을 다룬다. 기존 색 있는 GS를 갱신하는 조건이며 무색 이종 prior와 현재 사진을 사용하는 조건의 차이를 확인해야 한다.

## 5. 다음 설계·검증 순서

1. 기존 전역 설정에서 P1 수정부, P2 큰 변화·골, P3 보존·보완부가 각각 어떻게 달라지는지 같은 참조 범위와 출력 계약으로 구분한다. P3 전체의 시간적 무변화를 전제하지 않는다.
2. 전역 가중치·스케줄·보호 조절 중 충분한 설정이 있는지를 기준 비교로 둔다. 같은 전역 계수에서 정보가 이미 위치별로 다르게 작용하는 가능성을 배제하지 않는다.
3. 허용된 현재 관측으로 국소 신뢰도를 만들 수 있고 감독 충돌이 병목이면 관측별 연속 감독 조절부터 비교한다. 보호/생성/삭제 제한이 병목이면 해당 경로를 분리한다. 두 경우를 하나의 mask 변경으로 섞지 않는다.
4. 시험한 전역 설정들이 보존·수정을 함께 만족시키지 못하고, 같은 입력·표현·예산의 국소 제어가 양쪽을 만족시키는지 본다. 국소 제어의 결과를 보고 고른 정답 영역은 효과 상한 진단으로만 사용한다.
5. 입력 보정이나 기존 구성요소의 단순 조합으로 충분하면 그 결과를 채택한다. 관측이 없거나 원인을 구분할 증거가 부족한 부분에서는 국소 가중치·불확실성 학습만으로 정답이 생긴다고 가정하지 않는다.

이번에는 기존 수치 조회와 문헌·설계 분석만 수행했다. 새 학습·렌더·추론·추출·방법 실험은 시작하지 않았고 기존 정본·코드·산출물은 보존했다.
