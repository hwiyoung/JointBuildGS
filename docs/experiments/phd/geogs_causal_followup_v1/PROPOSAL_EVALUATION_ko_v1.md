# 연구질문과 영역별 감독 가중 제안의 학위 기여 평가

2026-09-10 · `scientific_verdict: null` · 문헌·방법 설계 평가, 구현/성능 판정 아님

## 1. 평가 대상과 결론

사용자는 현재 영상만으로 불완전한 도시 복원을 기존 LiDAR·LoD·DSM 등으로 개선하되, 유효 구조 보존·오류 수정·관측 가능한 세부·현재 외관을 달성하고자 한다. 네 결과 유형의 명시적 분류 없이 기존 기하에서 출발하여 학습 중 현재 영상으로 보정하고, 공간적으로 불균일한 감독의 영향을 영역·소스별 가중치로 조절하는 방법을 고려한다.

연구 목적은 일관되고 필요한 복원 결과를 명확히 한다. 그러나 '기존 기하 초기화 + 영상 정제 + 학습 중 국소 적응 가중'까지는 가까운 선행 기능과 겹친다. 현재 문장은 연구 가능한 방법 가설이지만 독립적인 방법론 기여를 아직 특정하지 못한다. 학위 가치의 최종 판정은 방법과 결과가 없는 이 단계에서 할 수 없다.

| 평가 축 | 현재 판단 | 다음에 필요한 근거 |
|---|---|---|
| 연구 필요성 | 영상 복원의 불완전성, 기존 자산 활용, 국소 손상과 개선의 동시 관리라는 목적은 타당 | 실제 조건에서 기존 강한 대안이 남기는 복원 요구와 그 중요성 |
| GeoGS 대비 차이 | 국소적으로 prior·영상의 반영을 조절하려는 구체적 확장 방향 | 기존 DA3 confidence·구조 보호 및 다른 국소 감독법으로 충분하지 않은 이유 |
| 방법론 참신성 | 국소 가중·학습 중 갱신·원인 분류 생략만으로는 약함 | 새 가중치의 의미·증거·산정 방식과 실제 기하 수정 경로 |
| 박사학위 기여 잠재력 | 조건별 실패 원인 설명과 이를 해결하는 일반적 방법으로 발전 가능 | 한 가지 이상 핵심 원인에 대한 설명·해결·기각 가능한 검증의 연결 |

정량 점수나 게재·학위 통과 가능성을 임의로 부여하지 않는다. 모든 입력 형식이나 모든 오류를 한 번에 해결해야 한다는 요구도 아니다.

## 2. 선행연구와 이미 겹치는 부분

| 연구 | 직접 확인한 기능 | 이번 제안과의 관계 |
|---|---|---|
| GeoGS | LoD2 초기화, 구조 보호, 현재 RGB/DA3 깊이 정제, 적응 visual-depth 계수. 공식 코드에는 선택적 DA3 픽셀 confidence도 있음 | 가장 가까운 전체 방법. 전역 계수만 있는 방법이라고 기술하면 부정확 |
| AGS-Mesh | 센서 깊이–단안 법선 일관성의 깊이 필터, 최적화 중 법선 감독의 적응 필터 | '공간적으로 다른 감독의 신뢰도를 학습 중 조절'하는 기존 해결책. 실내 센서 깊이 입력은 우리 조건과 다름 |
| VCR-GauS | 렌더·예측 법선 일치의 픽셀 confidence로 감독 가중, D-Normal을 통한 위치 수정 경로 | 연속 가중과 감독이 실제 기하 변수에 전달되는 경로의 구성요소 참고 |
| NeuRIS | 법선 prior를 사용한 초기 구조 후 현재 기하의 다중뷰 NCC로 법선 감독을 학습 중 선택 | 명시적 오류 원인 분류 없이 현재 영상으로 prior 감독을 조절하는 가까운 개념 |
| ARSGaussian | LiDAR와 항공영상의 정합, 기하 감독, Gaussian 생성·분할·삭제 제어 | LiDAR 사용과 항공 도시 조건 자체의 신규성 주장을 제한하는 비교 대상 |
| GaussianUpdate | 기존 GS의 외관·기하 갱신, 제거 계수와 새 Gaussian | 네 기대 중 변경·추가·외관 갱신의 기존 해결책. 기존 색 있는 GS 입력이라는 차이 있음 |

원문과 공식 소스:

- [GeoGS 공식 README](https://github.com/zqlin0521/GeoGS/tree/db40c95c657ec03ff21c83cb99cf39f4e90247a6), [train.py L278–324](https://github.com/zqlin0521/GeoGS/blob/db40c95c657ec03ff21c83cb99cf39f4e90247a6/train.py#L278), [DA3 confidence 적용 L788–817](https://github.com/zqlin0521/GeoGS/blob/db40c95c657ec03ff21c83cb99cf39f4e90247a6/train.py#L788). 코드에서 prior 깊이에는 해당 confidence 인자를 주지 않음을 확인했다. 기존 P1/P2/P3 native 실행의 비활성과 공식 기능의 존재를 구분한다.
- [AGS-Mesh v2 §4.1–4.3, 식4–10](https://arxiv.org/html/2411.19271v2).
- [VCR-GauS v2 §3.3, 식13–14](https://arxiv.org/html/2406.05774v2), [공식 trainer.py L252](https://github.com/HLinChen/VCR-GauS/blob/aa715d19bfacfa9d491f477c572eab1839dcee3e/trainer.py#L252). 공식 confidence 계산은 detach/no_grad 경로이며 별도 confidence network 학습이라고 부르지 않는다.
- [NeuRIS v2 §3.2 식6, §4.2 Fig6](https://arxiv.org/html/2206.13597v2).
- [ARSGaussian v2 §3, PDF6–9](https://arxiv.org/pdf/2412.18380v2).
- [GaussianUpdate v1 §3.2](https://arxiv.org/html/2508.08867v1).

AGS/VCR/NeuRIS 전체 방법은 입력·표현이 달라 무조건 동등한 직접 실행 baseline이 아니다. 그러나 동일 GeoGS에 그 감독 규칙을 이식한 구성요소 비교는 신규 국소 가중 규칙에 대한 강한 경쟁 방법이다. 이식은 원방법의 충실 재현과 분리한다.

## 3. 현재 논리에서 약한 연결

1. **적응의 축이 불명확하다.** 시간에 따라 바뀌는 장면 공통 계수와 픽셀/표면/시선별 국소 계수는 다르다. 'adaptive해도 세밀하지 않다'보다 '소스별 장면 공통 계수는 국소적으로 다른 감독 타당성을 충분히 반영하지 못할 수 있다'가 검증 가능한 가설이다. 전역 계수에서도 관측·gradient는 위치별로 다르므로 일반적 불가능성은 주장하지 않는다.
2. **감독 영향의 근거가 미정이다.** RGB 차이, DA3 깊이 차이, normal 일치, 관측 수는 서로 다른 것을 나타낸다. 현재 RGB·그로부터 추정한 깊이·법선·사전학습 정보는 독립적인 증거로 중복 계산하지 않아야 한다.
3. **큰 불일치가 나쁜 감독이라는 보장이 없다.** 초기 prior가 틀리면 맞는 현재 관측과 큰 차이가 난다. 현재 모델과의 일치로만 신뢰도를 정하면 수정할 관측을 배제할 수 있다. 이는 우리 추론인 원인 후보이지 P1/P2에서 확정한 단독 원인이 아니다.
4. **국소 가중이 올바른 기하 수정을 보장하지 않는다.** 같은 차이가 외관·불투명도·겹친 표면으로 흡수되거나 보호·생성삭제 제한에 막힐 수 있다. 가중치가 어느 감독과 변수·연산에 작용하는지 연결해야 한다. 원인 분류기를 만들라는 요구는 아니다.
5. **네 기대는 공간적으로 완전히 분리되지 않는다.** 동일 면의 위치는 맞고 세부·외관은 부족할 수 있다. 각 픽셀에 prior/영상 두 값만 주는 것으로 필요한 모든 자유도 제어가 가능한지는 별도 가설이다. 학습에서 네 유형을 명시 분류하지 않아도 평가에서는 보존·수정·추가·외관 효과를 분리한다.
6. **입력 형식 다양성은 아직 방법 차이가 아니다.** 실제 측정의 오차와 LoD의 표현 생략, DSM의 2.5D 지원 범위는 다르다. 모두 동일 depth로 변환해 적용한 결과만으로 일반적인 이종 prior 처리 기여를 주장하지 않는다. 한 번에 여러 prior를 결합하는 것으로 사용자 범위를 확대하지 않는다.

## 4. 기여로 발전시킬 후보 — 모두 구현하라는 뜻 아님

아래 중 실제 기존 방법의 부족과 연결되는 한 가지를 중심 원인으로 좁힐 수 있다. 새로운 기여인지의 최종 판단은 가장 가까운 기존 해결책과 비교 후 한다.

| 후보 | 핵심 질문 | 현재 제안에 추가해야 할 내용 |
|---|---|---|
| 기존 추정에 대한 동조를 벗어나는 감독 신뢰도 | 틀린 초기 구조와 다른 정확한 현재 관측을 어떻게 유지하는가 | 현재 모델과의 잔차 이외의 증거, 가시성/정합 조건, 독립적인 지지의 의미 |
| 표현 한계를 고려한 감독 | 세부가 생략된 prior가 관측 가능한 세부를 억제하지 않게 하려면 무엇을 제약해야 하는가 | prior의 지원 범위·해상도·표현 성분과 손실의 의미. 정밀 prior의 세부도 보존 가능해야 함 |
| 감독 신뢰도와 실제 수정의 연결 | 어느 감독을 믿는지가 어떻게 유효 구조 손상 감소와 필요한 수정으로 이어지는가 | 감독→위치/방향/외관/생성삭제→합성깊이→추출의 병목을 분리한 제어·검증 |

불확실성 네트워크, 가중치 맵, 반복 적용, 다중뷰 일관성을 쓴다는 기능은 각각 새로움의 증거가 아니다. 중요한 것은 기존 증거/제어가 부족한 구체적 조건에서 새 설계가 왜 작동하는지다.

## 5. 권장 문장 구성

상위 연구질문은 사용자의 첫 문장을 유지한다.

> 현재 영상만으로 불완전하게 복원되는 도시 장면에서, 품질과 표현 수준이 다른 기존 기하의 상보적 정보를 활용하여, 유효한 구조의 손상을 통제하면서 현재 기하·관측 가능한 세부·외관을 어떻게 개선할 수 있는가?

방법 연구질문은 해결책을 확정하지 않는 별도 질문으로 둔다.

> 기존 기하와 영상 유래 감독의 국소적 타당성을 어떤 관측 증거로 평가하고, 이를 학습 중 감독의 반영 정도와 필요한 기하 수정에 연결해야 유효 구조 보존과 현재 복원 개선을 함께 달성할 수 있는가?

방법 가설의 현재 후보:

> 오류 원인을 명시적으로 분류하지 않고 기존 기하에서 출발하되, 관측의 지지와 표현 한계에 따라 감독의 영향을 국소적으로 조절하면, 소스별 전역 가중 및 기존 confidence 제어보다 유효 구조의 손상을 줄이면서 필요한 구조 수정과 세부·외관 복원을 개선할 수 있다.

이 문장 자체는 참신성 주장이 아니다. '어떤 증거·산정 규칙·수정 경로'가 정해져야 방법 기여를 기술할 수 있다. 새로운 변수 제어가 필요 없다면 국소 감독만으로 달성한 결과를 유지하고, 부가 모듈을 강제하지 않는다.

## 6. 박사 기여를 뒷받침할 최소 연결과 기각

- **설명:** 유효/부정확/불완전 prior와 충분/약한 현재 관측이 섞일 때, 기존 방법이 어떤 감독을 어떤 변수로 전달하여 요구 결과를 놓치는지 규명한다. P1/P2/P3는 개발 증거이며 현재 확보한 사례만으로 일반화하지 않는다.
- **해결:** 그 원인을 겨냥한 하나의 명확한 감독·제약·관측모형 개선을 제안한다. 여러 기존 부품을 많이 붙였다는 사실로 기여를 대신하지 않는다.
- **검증:** 같은 입력/표현/학습 예산/추출에서 native GeoGS, 적절히 조정한 전역 계수·스케줄, 기존 DA3 confidence, 기존 국소 감독 규칙의 이식, 제안 방식을 비교한다. image-only·prior-only·정합 보정 및 강한 비GS/순차 경로도 출력·정보 조건에 맞춰 둔다. 추가 입력이나 파생 감독이 필요하면 경쟁 방법에도 같은 정보를 제공한다.
- **평가:** 보존부 악화와 수정부 회복, 세부·외관, raw/post, 관측 부족을 각각 기록한다. 개선량이 같을 때 손상이 줄거나 손상 한도가 같을 때 복원이 더 좋아지는지 평가한다. '손상 통제'는 평가용 오차 기준·허용범위·측정 대상을 명시하며 현재 법적/수학적 보장이라고 주장하지 않는다.
- **기각:** 기존 confidence/국소 필터의 이식이나 입력 보정으로 요구를 충족하면 신규 규칙의 필요성이 낮아진다. 전역 설정과 차이가 없거나 다른 영역의 악화·정보/예산 증가로 설명되면 방법 기여를 축소한다. 같은 입력의 정확한 수정 영역을 제공한 상한 진단에서도 이득이 없으면 가중치 산정이 주요 병목인지 재검토한다.

연구질문의 주제를 버리거나 ALS로 고정할 이유는 현재 없다. 구체화할 우선 대상은 **새 가중치의 근거와 그 가중치가 해결할 기존 방법의 한계**다.

## 7. 확인 범위와 실행 예외

이번에는 새 학습·렌더·추론·추출·방법 실험을 수행하지 않았다. 기존 정본·코드·산출물·서비스를 변경하지 않았다.

GeoGS 출판사 페이지는 HTTP403이었다. 별도 PDF 재추출은 Docker dev 이미지에 pypdf가 없어 실패했다. 다른 이미지의 모듈/실행 파일 조회에서도 pypdf가 없거나 python entrypoint가 없어 신규 패키지를 설치하지 않았다. 기존 추출 원문 텍스트를 참고하고 공식 README·고정 train.py의 실제 코드를 재확인했다. 출판 PDF 전체를 이번에 새로 재추출·재검증했다고 주장하지 않는다. AGS/VCR/NeuRIS/GaussianUpdate는 arXiv 원문, ARSGaussian은 v2 PDF를 확인했다. 이 기록의 기술·학술 평가와 scientific verdict를 구분하여 null을 유지한다.
