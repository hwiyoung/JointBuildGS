# 실패와 확인 불가 기록

- B173·항공 LiDAR의 43점에서 원본 `u_prior`를 구할 수 없음. 임의 값을 넣지 않고 판 다의 두 출발을 `STOP_MISSING_CANDIDATE_SIGMA`로 멈춤. 나머지 판의 입력은 영향받지 않음. [이 발주에서 냄]
- 판 라 준비 코드에서 저장된 불투명도를 sigmoid 뒤 logit으로 되돌리자, float32에서 1로 반올림된 값이 무한대가 됨. 학습 전 단위 점검에서 검출. 원본 PLY의 유한한 logit을 직접 읽도록 수정했으며 처음 실패 기록은 `preflight/implementation_r0/`에 보존. 기존 장면 바이트와 처음 렌더 값은 유지. [이 발주에서 냄]
- gsplat 1.4의 기본 깊이는 가우시안 중심의 카메라 Z를 평균함. GeoGS 메시 코드는 광선과 원반의 교차 깊이를 평균함. 일 2는 같은 v1 가시성 가중치에서 교차 깊이를 구한 뒤 GeoGS의 `depth_ratio=0` 규칙으로 정규화하도록 학습 전에 잠금. 중심 Z 평균은 수치 대조에만 사용. [이 발주에서 냄]

- 그림 준비에서 문자열 배열에 NumPy 최소값 연산을 적용한 오류와 컨테이너 기본 글꼴의 한글 누락을 확인했다. 문자열 정렬은 Python 최소값으로, 글꼴은 v1의 Noto Sans CJK 파일로 바꿨다. 수치 계산과 학습은 바꾸지 않았다. [이 발주에서 냄]
- 저장 곡선 float16 정밀도 때문에 옛 범위 재생에서도 항공 LiDAR 406패치(27.5324 m²), LoD2 1,326패치(82.875 m²)의 15개 판단 중 하나 이상이 기존 저장 판단과 다르다. 원래 선택값에서의 틀린 넓이 영향은 photo_precision_sensitivity 표에 별도로 보존했다. [이 발주에서 냄]
