# 소스 판단 문헌 추천의 범위 정정

2026-09-08 · 사용자 목적 재확인 · `scientific_verdict: null`

## 사용자 확인

현재 영상 소스의 불완전함을 기구축 3D prior로 보완한다. 두 소스 모두 오차를
포함하므로, 해당 영역에서 어떤 소스를 사용할지 판단한다. 원영상과 pose도
판단 근거로 이용할 수 있다. 이것은 새 목적이 아니라 기존 목적의 재확인이다.

## 앞선 추천에서 잘못 좁힌 부분

사용자의 단일 선행연구 기반 판단 시험 요청을 기존 기하의 현재 영상 적합성·변화
검정 중심으로 해석하면서, 영상 소스 자체의 오류와 prior의 보완 역할에 대한
적합성 검토가 충분하지 않았다. 이 때문에 Taneja를 전체 판단 문제에 가장 직접적인
출발 문헌으로 추천한 우선순위는 근거가 충분하지 않다.

[직전 문헌 검토](LITERATURE_RECOMMENDATION_ko_v2.md)의 개별 방법·한계 기록은
보존하되, Taneja의 최우선 추천을 현재 채택된 방향으로 사용하지 않는다.
해당 연구는 현재 영상으로 기존 기하를 검정하는 관련 근거로 남는다.

## 유지할 방법 검토 범위

- 영상 소스가 적합하고 prior가 부적합한 경우 영상 활용.
- 영상 소스가 부적합하고 prior가 사용 가능한 경우 prior 활용.
- 두 소스가 모두 사용 가능한 경우 선택 또는 상보적 활용 검토.
- 두 소스가 모두 부적합하거나 구별할 근거가 부족한 경우 유보.

이 상황 구분은 알고리즘이나 정답 판정 규칙이 아니다. 낮은 영상 신뢰도를 곧바로
prior 정답으로 바꾸지 않으며, 현재 영상과의 불일치를 곧바로 prior 오류로 바꾸지 않는다.
시간차는 prior 부적합의 가능한 원인 중 하나다. 판단이 독립 전처리여야 한다거나,
복원 중 소스별 판단을 갱신할 수 없어야 한다는 제약을 추가하지 않는다.

처음 제시한 GeoGS·Semantic MVS·AGS-Mesh·SpotLessSplats·SRDM은 복원과 판단의
관계 및 관련 처리 원리를 검토하기 위한 목록으로 보존한다. 전체 구조의 선례와
첫 판단 모듈의 구현 후보를 구분하여 설명한다. 어느 한 연구가 네 상황을 모두
해결한다고 간주하지 않는다.

이번 작업은 범위와 추천 지위의 정정이다. 새 실험·학습·코드 변경은 없다.
