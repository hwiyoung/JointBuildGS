# 데이터 제약과 Gaussian 초기값 연결을 반영한 추천 보완

2026-09-08 · 설계 논의 · `scientific_verdict: null`

## 사용자 제약과 추천 변경

사용자는 별도 학습에 충분한 데이터가 없음을 지적했고, 소스 판단을 Gaussian 초기값에
연결하려면 3차원에서의 선택을 중심으로 검토해야 하는지 질문했다.

[직전 검토](BOTH_SOURCE_RELIABILITY_REVIEW_ko_v3.md)의 방법·구현 조사 결과는 보존한다.
다만 **SenFuNet의 첫 구현 우선 추천은 데이터 적합성 확인 전까지 보류**한다.
문제 구조의 적합성과 실제 학습·검증 자원의 적합성을 함께 판단해야 한다.
SenFuNet은 소스별 기하를 유지하고 활용도를 정하는 구조 참고 후보로 남는다.
이것은 성능 실패 판정이나 다른 알고리즘의 채택 결정이 아니다.

## SenFuNet의 학습 요구

- 원형은 GT TSDF를 감독으로 사용해 소스 특징과 융합 가중치를 학습한다.
- 공개 pretrained 모델의 추론에는 새 학습이 필수는 아니다.
- 원문 CoRBS에서는 한 장면에서 학습해 다른 장면에서 시험한다. 따라서 반드시
  대규모 장면 수가 필요하다고 단정하지 않는다. 대신 적합한 센서 오류·기하와 GT가 필요하다.
- 실내 ToF+MVS 모델이 항공 ALS의 희소성·정합 오차·시간차에 일반화한다는 근거는
  확인되지 않았다. 추가 학습의 필요 여부도 입력 적합성과 검증 없이 확정할 수 없다.

[원문 §3–4](https://arxiv.org/html/2204.03353v2),
[공식 pretrained 안내](https://github.com/eriksandstroem/SenFuNet#testing)

현재 P1/P2/P3의 평가 결과를 감독으로 사용해 같은 사례의 판단 성능을 주장하는
방향으로 데이터 부족을 메우지 않는다. 별도 다수 장면의 판단기 학습과 현재 장면의
GS·기하 최적화는 요구하는 데이터가 다르므로 구분한다.

## 판단 공간과 출력 공간

**최종 판단은 초기화에 사용할 3D 기하 후보에 연결되어야 한다. 판단 근거의 계산을
3D로만 제한할 필요는 없다.** 같은 건물 영역의 ALS·MVS 표면 후보는 높이나 위치가
다를 수 있으므로 동일 XYZ 점끼리만 비교하는 구조로 제한하지 않는다.

```text
ALS·MVS의 3D 표면 후보 유지
  → pose로 각 원영상과 연결
  → 영상 관측 지지·후보별 가시성·각 소스의 품질과 정합 불확실성 검토
  → 해당 3D 후보의 채택·활용 강도·유보 결정
  → 채택 기하를 Gaussian 중심과 기하적 초기화에 연결
```

이것은 설계 후보 흐름이다. 영상이 모호하다는 사실만으로 ALS를 정답 처리하지 않는다.
판단하지 못한 위치의 후보는 보존하며, 보수적 초기화와 현재 기하 확정을 구분한다.
색·불투명도 등 모든 Gaussian 파라미터가 소스 선택만으로 정해지는 것은 아니다.
판단 후 초기값의 지역 연결, 후보 경계 처리, 이후 재채택 경로는 미결정이다.

## 후속 문헌 검토 기준

별도 GT 학습 데이터 요구가 없는 방법을 우선 검토하되, 장면별 최적화 방법도 포함한다.
어느 한 소스를 항상 참으로 두지 않고, RGB·pose 근거를 3D 후보의 선택으로 연결할
수 있어야 한다. 2D에서 판단하는 연구를 일괄 제외하지 않는다.

Marin 2016은 비학습으로 두 소스의 confidence를 구분하는 참고 원형이다. 그러나
ToF confidence의 ALS 치환과 여러 영상의 판단을 3D에 모으는 절차는 추가 설계다.
완성된 비학습 ALS–MVS 선택기로 대체 추천하지 않는다.
[저자 원문](https://giuliomarin.github.io/publications/conferences/marin16fusionconfidence.pdf)

이번 보완은 문헌 적합성과 설계 조건의 기록이다. 실험·학습·코드 변경은 없다.
