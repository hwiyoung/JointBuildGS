# Wu–Vallet P3: 작은영역 필터 교정과 실제 사진·점군 확인

2026-09-07 · `PHD-WU-VALLET-P3-FILTER-v3` · 비확증 개발 · `scientific_verdict: null`

**먼저 재구현 결함이 있었다. v2에서는 작은 변화영역을 탈락시킨 뒤 SINGLE로 처리해 새 영상점을 다시 추가했다. 이를 교정한 v3 점군과 실제 사진·3D를 [새 화면](http://127.0.0.1:8899/)에서 비교할 수 있다.** 기존 v1/v2 코드·점군·뷰어는 보존했다. 이 결과를 원저자의 구현 또는 논문 성능으로 부르지 않는다.

## 확인된 문제와 수정

v2의 작은 CHANGED 면 제거는 면의 상태를 SINGLE로 바꿨다. 그러나 최종 조립은 새 점에서 CONSISTENT가 아닌 상태를 모두 추가했다. 따라서 면적 문턱 0→1m²에서 새 추가점은 35,149개로 완전히 같았다. 기존 단위시험도 이 출력을 정답으로 고정해 결함을 잡지 못했다.

v3는 원래 SINGLE 면, 크기로 제거된 CHANGED 면, 남은 CHANGED 면을 별도 상태로 유지한다. 작은 old 변화영역의 점은 보존하고, 작은 new 변화영역에만 속한 점은 제외한다. 같은 v2 광선 판정·좌표·연결군을 재사용했으며 새 정합이나 좌표 보정은 수행하지 않았다. 1m² 직접 비교에서 **old 보존 마스크는 동일하고 new 4,333점만 제외**됐다.

면과 점은 구별한다. 29,533개 new 면이 크기 정제 대상이고, 그 면에 접하는 P3 점은 14,695개다. 한 점이 다른 종류의 면에도 접할 수 있으므로 모두 제외할 수는 없다. v2에서 CHANGED→SINGLE로 바뀐 점 11,587개와 v3에서 최종 제외한 4,333개는 분모가 다르다. 후자는 다른 허용 면의 지지가 없는 `filtered` 점이다.

점 상태 우선순위는 `consistent > accepted_changed > raw_single > filtered > unassessed`다. `raw_single`은 원시 SINGLE 면에 접한다는 뜻이며 실제 새 단독 관측의 인증이 아니다. 가림·검사 부재·피복 불확실성도 포함할 수 있다. 따라서 원래 SINGLE을 보존하는 주 비교와 이를 전부 배제하는 별도 민감도 조건을 함께 냈다. 면적의 정의·문턱·연결성·혼합 점 우선순위는 원문에 공개되지 않은 구현 선택이다.

1m² 교정으로 빠진 4,333점 중 큰 참조 편차점은 2,237개다. 동시에 참조 편차 ≤2m인 2,096점도 빠졌다. 따라서 제거량이나 거리 감소만으로 현재 세부 보존과 전체 품질 개선을 입증하지 않는다. 면적 민감도는 사전에 정한 0.25/1/4m²를 모두 보고하며 참조를 보고 최적 문턱을 선택하지 않았다.

참조는 기존 UAS 3,087,747점이다. 헤더 EPSG:32632와 작업 표기 EPSG:25832를 재투영·재정합하지 않은 기존 수치 좌표에서 계산했다. datum/epoch와 관측 차이가 남아 있으며 **>2m는 사후 진단 묶음이지 실제 오류·변화 정답이 아니다.** 후보 생성 컨테이너에는 UAS를 마운트하지 않았고, 점군·마스크 해시를 고정한 뒤 별도 평가 프로세스에서만 열었다.

## 왜 단순 이상점 제거로 모두 사라지지 않는가

고정 SOR(이웃 20개, 표준편차 배수 2)를 전체 영상 센서점 657,682개에 별도로 적용했다. P3에서 2,156점을 제거했지만, 참조 편차 >2m 7,971점 중 제거는 304개(3.81%)였다. P3만 처리하면 329개(4.13%)로 달라졌다. 이는 Wu의 원문 필터가 아닌 고립점 진단이다.

실제 잔존 연결군 3350은 면적 8.0715m², P3 666점이며 모두 참조 편차 >2m다. PCA 표준편차는 `[0.01444, 0.71638, 1.72269]m`로, 서로 떨어진 고립점보다 얇고 연속적인 면에 가깝다. 사진상 지붕에 대응하면서 3D에서는 다른 높이로 생성된 잔존 사례도 확인했다. 공간적으로 조밀한 오류 후보는 이웃 거리만 보는 필터와 작은 영역 필터를 통과할 수 있다. 모든 필터의 실패나 논문의 실증된 실패라는 뜻은 아니다.

원문은 PSMNet disparity와 다중 시점 전방교차로 영상 기하를 만들고, 작은 변화영역을 제거한 뒤 남은 영역을 합친다. 1px 필터는 SGM–LiDAR 차이로 **학습 라벨을 정제하는 단계**이며 최종 점군의 일반 이상점 제거가 아니다. 벽·matching·가림·식생 잔존 문제도 원문에서 인정한다. 현재 입력은 COLMAP depth133 역투영이고, 별도 native OpenMVS 융합점과도 다르다. **구현 결함 → 입력 대체의 영향 → 정제 후 남는 구조적인 문제**를 차례로 분리해야 한다. [원문·입력 계보·SOR 감사](PAPER_INPUT_AUDIT_ko_v3.md).

## 화면과 원점 연결

[http://127.0.0.1:8899/](http://127.0.0.1:8899/)에서 기본 `corrected_area1`과 `v2_a1`을 바꾼다. 실제 현재 사진에서 `v2에서 추가했으나 현재 조건에서 제외한 점` 또는 `추가점 중 UAS 거리 차이 2m 초과`를 선택하고 ROI나 점을 누르면 원 pixel·좌표·선택 상태를 확인할 수 있다. 같은 원점은 3D에도 표시된다. 전체 native NPZ/PLY도 내려받을 수 있다.

사진 오버레이는 145,577개 native 점을 사용한다. 깊이 raster index→실제 보정 사진의 재투영 오차 최댓값은 **5.80×10⁻¹³px**였다. 3D 표시 샘플링은 별도이며 점군 계산·사진 선택·정량 평가에 사용하지 않는다. 사진은 실제 image133 원본 바이트다. 사진과 3D의 선택 사례는 사후 진단이며 무작위 표본이나 성능 평가 집합이 아니다.
