# P1/P2/P3 Prior–MVS 단계별 관측 검토 결과

`PHD-MVS-EVIDENCE-v1` · 2026-09-15 KST · `scientific_verdict: null`

기술 상태는 **PASS_OBSERVATION_DIAGNOSTIC / PASS_ACTUAL_BROWSER**다.
MVS/PGSR 실험에 결박된 MVS·RGB·카메라와 부모 GeoGS의 Prior를 사용해 지역별
3시점, 총 9시점의 입력 불일치와 관측 지원을 계산했다. 이는 고정 입력 진단이며
학습 iteration별 GS residual을 추출한 결과는 아니다.

[단계별 검토 화면](http://127.0.0.1:8907/review_v2/)에서 지역·카메라·증거 지도를
선택하고, 원사진과 지도를 함께 이동·확대할 수 있다. 격자점을 클릭하면 원 수치가
표시된다. 아래 36개 사례에는 확대 영역, 이웃별 비용, 깊이 비용곡선과 실제 7×7
원사진/재투영 패치가 연결되어 있다. PNG·JSON·NPZ는 각각 직접 열거나 저장할 수 있다.

## 검토 순서

1. **불일치 후보:** 입력 존재 영역, Prior−MVS 깊이차, >0.5m 후보를 함께 본다.
   큰 차이가 포화되면 ±30m 지도로 전환한다. 값은 camera-Z 방향의 차이며 수직
   높이 차가 아니다. 0.5/1/2m는 탐색 기준이지 검증된 변화 임계값이 아니다.
2. **보임·가림 및 관측 가능성:** Prior 내부 깊이 일치와 MVS 내부 깊이 일치를
   각각 확인한다. Prior→MVS 호환성, 앞/뒤, 이웃 관측 수, 왕복 재투영 오차는 별도다.
   MVS를 기준으로 한 앞/뒤 판정은 실제 가시성의 독립 정답이 아니다.
3. **다중 시점 지지:** 동일 픽셀·동일 이웃의 두 가설 사진 비용, 지원 이웃 수,
   이웃 간 우열 불일치, 텍스처·시차각과 원패치를 함께 본다. 사진 비용 비교 지원을
   Prior→MVS 호환성으로 자르지 않았다. 낮은 사진 비용만으로 source 정확도를 결정하지 않는다.
4. **대응 모호성:** 깊이 비용곡선의 절대 비용, 낮은 비용 구간의 폭·분리 구간 수,
   탐색 경계 도달 여부를 확인한다. 폭 0은 깊이 격자의 한 점만 남은 경우이며
   불확실성 0이 아니다. 지원 부족·결측은 `null`로 남는다.

입력과 깊이차는 전체 raster, 이웃 관측은 16px 격자, 비용곡선은 48px 격자다.
빈 영역을 보간하지 않았다. 지점 선택 수치는 가장 가까운 격자 중심의 기록이다.

사진 비교 가능은 공통 픽셀·텍스처 기준을 통과한 이웃이 2개 이상이라는 뜻이다.
올바른 대응이나 실제 비가림을 보증하지 않는다. 비용곡선은 두 source의 원패치가
모두 완전하고 모든 깊이·두 normal 가설에서 같은 패치/이웃을 비교할 때만 제공한다.
따라서 불일치 후보 면적과 판별을 뒷받침하는 관측 지원 면적은 다르다.

지역별 카메라 선정은 prior 관측 면적과 카메라 위치 다양성에 따른 것이다.
9장의 픽셀을 독립 표본으로 보거나 세 지역의 변화 비율로 집계하면 안 된다.
역사 MVS 생성 이웃과 평가영상 독립성은 복구되지 않았으며, source 내부 일치는
독립 정확도 증거가 아니다. 비용곡선은 source별 국소 평면과 고정 탐색 구간에 조건부다.
3D/Gaussian 연결 전에 이러한 실패 유형과 지원 부족을 시각적으로 검토한다.
