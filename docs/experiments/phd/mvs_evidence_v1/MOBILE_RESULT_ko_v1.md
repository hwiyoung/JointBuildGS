# 모바일 검토: 깊이 불일치와 변화 후보

`PHD-MVS-EVIDENCE-MOBILE-v1` · 2026-09-15 KST · `scientific_verdict: null`

**깊이 불일치 영역은 추출되었다. 실제 시간 변화만 정확히 분리했다는 결론은 아직 없다.**
현재 MVS/PGSR 입력에 결박된 Prior·MVS의 기존 수치를 사용했다. DA3, 신규 학습,
추가 참조 정답 또는 새로운 변화 판정 문턱을 사용하지 않았다.

모바일 카드 9장과 9페이지 PDF를 만들었다. 대화에는 지역별 첫 시점인 P1_1/P2_1/P3_1을
표시한다. 이는 이미 선정된 카메라 순서의 첫 시점이며 지역의 전체 변화율을 대표하지 않는다.
상단은 동일 색척도(0–150m camera-Z)의 두 깊이, 중간은 사진 위의 불일치 후보,
하단은 불일치 후보 격자점의 공통 사진 비용 비교다.

| 첫 시점 | >0.5m 불일치 / 두 깊이 존재 픽셀 | 사진 비교 가능 / 후보 격자점 |
|---|---:|---:|
| P1_1 | 97,729 / 415,030 = 23.5% | 145 / 407 = 35.6% |
| P2_1 | 490,880 / 888,325 = 55.3% | 1,462 / 1,849 = 79.1% |
| P3_1 | 346,332 / 901,088 = 38.4% | 821 / 1,325 = 62.0% |

분모가 다르다. 첫 비율은 공통 유효 raster 픽셀, 두 번째는 16px 격자상의 불일치
후보 중 공통 사진 비교가 가능한 점이다. 여러 시점의 픽셀을 합쳐 고유 면적이나
실제 변화율로 해석하지 않는다. 전체 9시점의 0.5/1/2m 민감도는 summary.csv/json에 있다.

## 실제 그림에서 보이는 것

- P1_1: 긴 지붕의 일부 패치와 경계에서 불일치가 보인다. 비교 불가 영역과 사진 지원
  부족도 크다. 407개 후보점 중 사진 비교가 가능한 것은 145개다.
- P2_1: 중앙 지붕의 넓게 이어진 불일치 영역과 MVS의 사진 비용이 낮은 점들이 겹친다.
  이 시점은 후보의 사진 비교 지원 비율이 높아 우선 확대 검토할 만하다.
- P3_1: 오른쪽 지붕의 넓은 후보 영역과 중앙의 긴 지붕에서 다른 사진 비용 패턴이 보인다.
  후보 전체에 동일한 source 우열을 적용할 근거는 없다.

이 설명은 지도와 관측 비용의 시각적 해석이다. 어떤 위치의 불일치가 실제 시계열
변화인지, Prior 오류인지, MVS 오류·정합·가림 영향인지는 판정하지 않았다.
낮은 사진 비용만으로 정확한 기하·안전한 업데이트를 인증하지 않는다. 비용곡선은
더 엄격한 별도 48px 표본이다. 첫 시점들의 불일치 후보 중 곡선 공통 이웃 2개 이상은
P1 6개, P2 62개, P3 36개이며 16px 사진 비교 점수와 구분해야 한다.

## 범례와 원자료

- 불일치 지도: 주황 0.5–2m, 빨강 >2m, 회색 두 깊이 중 적어도 하나 결측.
  비교 가능한 무색 영역만 ≤0.5m다. 불일치는 절댓값이며 수직 높이 차가 아니다.
- 사진 지도: 청록 MVS 비용 낮음, 파랑 Prior 비용 낮음, 보라 비용 차이 ≤0.01,
  회색 공통 사진 비교 지원 부족. 후보 격자점만 표시하며 공간 보간하지 않았다.
- `*_discrepancy_classes.png`: 원 해상도 정수 class raster. 0 비교 불가,
  1 차이≤0.5m, 2 0.5m<차이≤2m, 3 차이>2m. `class_legend.json`이 해석을 소유한다.
- `*_masks.npz`: 공통 유효, 불일치 후보, 각 사진 비교 표본 분류와 원 영상좌표.
  실제 변화 또는 Gaussian 업데이트 허가 마스크는 포함하지 않는다.

외부 payload는
[`mobile_result_manifest_v1.json`](../../../../artifacts/manifests/phd/mvs_evidence_v1/mobile_result_manifest_v1.json)으로 해석한다.
기존 loopback 웹 화면에 의존하지 않고 대화 내 PNG와 PDF로 모바일 검토하도록 제공한다.
