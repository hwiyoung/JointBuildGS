# DA3 편차와 refinement 공간 변화의 대응 분석

2026-09-10 · 사용자 요청에 따른 기존 산출물 분석 · `scientific_verdict: null`

입력 정확도와 refinement 변화가 같은 위치에서 어떻게 나타나는지 계량한다. 관측된 공간 대응과 DA3 단독 인과 효과를 구분한다. 새 학습·깊이 생성·정합 보정은 이 분석에 포함하지 않는다.

## 비교·입력

P1/P2/P3 각각 공통 Anchor8k raw512와6개 최종30k raw512를 비교한다. JSON/NPZ의 표면표본.1m·참조voxel.1m·seed0·ROI·CRS·추출 설정을 확인하고 reference 원ID/XYZ가 일치하지 않으면 중단한다. `.final.raw`1024는 섞지 않는다. 입력은 봉인된 사진·K·표정·DA3배열과 기존 평가거리/삼각형이다. 각파일SHA·실행코드·config·Docker명령·결과경로를 기록한다.

## 측정 순서

1. 학습카메라의 local-Z 방향성분≤−.95인 수직에 가까운 뷰만 일차 정확도 진단에 사용한다. DA3 값으로 뷰를 선별하지 않는다. 모든 train뷰의 사진·loss 사용 여부는 source에서 따로 확인한다.
2. 고정 참조점 중 .25m XY cell 상부표면에서 .25m 이내인 점을 분리한다. 같은camera에서2px cell z-buffer상 앞표면+.2m 이내인 점에 대해 DA3잔차를 구한다.
3. 엄격 집합은 참조z-buffer의3×3주변cell이모두채워져있고깊이범위≤.5m인부분이다. 주변피복/경계게이트를풀어도부호·경향이유지되는지보조값을함께보존한다. 외부앞가림물을보충하지않으므로 물리적가시성인증으로부르지않는다.
4. 원camera-Z잔차와 실제pixel ray로 world-Z방향을환산한 DA3목표편차를 구한다. 관측뷰수·뷰간MAD·signed target높이구간을저장한다. 한뷰만있는경우뷰간불일치는미측정이다.
5. 같은UAS점의Anchor→최종삼각형거리변화, .25/.5/1m 근접도획득·상실, 초기Anchor양호/불량층별결과를집계한다. 이는조건부recall이며precision없는부분집합F1을만들지않는다. 전체P/R/F1은별도로원결과에서읽는다.
6. .5m XY지도에 DA3목표편차·관측피복·refinement거리변화·조건차이를그린다. 동일XY의수직ray와추출삼각형첫교차로상부표면높이를진단한다. 다층/결손은별도표시하며Gaussian이동으로부르지않는다.
7. 개선·악화·판단불가사례를같은사진·단면·범위로확인한다. 사후대표선택기준을기록한다. 원.5m단면과독립사진렌더는보조자료로연결한다.

## 해석 제약과 완료 기준

- DA3는refinement에서metric L1로사용된다. 실제학습은ROI/alpha/외부가림mask를전달하지않고confidence옵션도꺼져있다. 본엄격집합은학습전체노출의일부이며전체원인을설명하지않는다.
- 학습깊이는alpha정규화expected depth, 이번참조진단은first-visible, 최종평가는TSDF추출표면이다. 연산자차이를무시한1:1귀속을하지않는다.
- L1은큰잔차가픽셀별더큰gradient크기를보장하지않는다. 잘못된목표방향·지속노출과기하Jacobian을구분한다.
- 공통입력이어도조건별실현DA3가중이약.043~.05로다를수있다. 제어정책의경로효과이지동일노출량실험이아니다.
- 공통Anchor복원직후상태검증은통과했지만이후완전궤적parity/반복변동은확보되지않았다. 작은차이를확증하지않는다.
- 완료물: 입력·조건표, 지역/조건/오류구간CSV, reference-ID를보존한NPZ, 공간지도·대표단면·사진확인, 실제실행receipt, 결과와남은인과질문의문서. 원앱·원결과·기존서비스는보존한다.

DA3단독효과의후속최소비교는같은8kcomplete state에서실제DA3감독on/off로같은refinement량을수행하는것이다. `--lambda_da_depth 0`만바꾸면dynamic controller가.05로덮어쓸수있으므로 실제총DA항과first-step가중0검증이필요하다. 이는현재DA3감독전체의기여를보며특정오류만의몫은아니다. UAS로mask/척도를수정한조건을학습에넣지않는다.
