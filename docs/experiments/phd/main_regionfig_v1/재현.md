# PHD-MAIN-REGIONFIG-v1 재현

잠근 설정은 `configs/phd/main_regionfig_v1/regionfig_v1.json`이다. 최초 파일을 덮어쓰지 않는다. 추가 기록 01은 사진의 전체 4 m 주변 범위, 02는 사진 북쪽 표시 방향을 정한다. 그림에는 두 기록이 모두 적용됐다.

기존 Docker 이미지 `jointbuildgs:dev`와 외부 입력이 있는 원래 저장소에서 실행한다. 새 의존성 설치나 학습은 필요하지 않다.

```bash
bash scripts/phd/main_regionfig_v1/run_cpu.sh prepare prepare.py
bash scripts/phd/main_regionfig_v1/run_cpu.sh draw draw.py
bash scripts/phd/main_regionfig_v1/run_cpu.sh verify verify.py
bash scripts/phd/main_regionfig_v1/run_cpu.sh report finalize.py
```

`lock_config.py`, `amend_crop.py`, `amend_orientation.py`는 최초 기록용이며 재실행 시 기존 기록을 덮어쓰지 않고 멈춘다. `run_cpu.sh`는 저장소·기존 자료를 읽기 전용으로 붙이고, 이 작업의 설정·문서·외부 작업 폴더만 쓸 수 있게 한다. GPU 장치를 붙이지 않으며, CUDA 사용 금지·nice 19·7.5 GB 제한을 적용한다. 큰 점군은 압축 배열에서 10만 점씩 읽고 단면 둘레 10 m만 유지한다.

다른 영역은 새 작업의 설정을 잠근 뒤 `examples`에 `id`, `region`, `title`, `site`, `prior`, `prior_label`, `start_xy`, `end_xy`, `half_width_m`, `highlight_cells`, `highlight_colour`를 적는다. `expected` 대조값은 선택 사항이다. 행 수는 항목 수를 따른다. 기존 JSON의 `correction_*` 수치 필드는 해당 항목이 지정한 칸 목록의 합을 뜻한다. 그림 제목과 출력 묶음 이름도 그 작업에 맞게 지정한다. 이번 작업은 보정 두 예만 실행했다.

검증은 원본 배열의 띠 선택과 높이 차이를 별도 수식으로 다시 계산하고, 카메라 투영의 역변환, 사진 원본 화소, 시작·끝 좌표, 잠금 및 입력 SHA-256, 실행 제한을 확인한다. 생성형 이미지는 사용하지 않는다.

화면 표시 방향을 제외한 원본 사진 조각은 `figures/crops/*_원본.png`다. `*_표시.png`는 같은 사진에 패치·단면을 표시하고 북쪽이 위가 되도록 회전한 것이다. 상세 출처는 숫자 JSON과 SHA256SUMS에 있다.

단면 참값은 `centre_z + gt_p × normal_z`의 칸별 중앙값이다. 사진 패치 중심은 `centre + gt_p × normal`이고, 사진 단면은 지정 XY를 유지하며 단면 참값 높이를 보간한다. 두 투영 규칙을 혼동하지 않는다. 지도 사진 경계는 단면 참값 중앙 높이에 역투영한 근사다.
