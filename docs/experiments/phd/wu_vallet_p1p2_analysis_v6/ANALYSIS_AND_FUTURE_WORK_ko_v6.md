# P1·P2 Wu–Vallet 실행 분석과 원문 향후 과제

2026-09-07 · `PHD-WU-VALLET-P1P2-ANALYSIS-v6` · `scientific_verdict: null`

**P1과 P2에서 Wu 기반 선택 갱신은 과거 ALS보다 현재 UAS에 가까운 기하를 만든다. 다만 P2는 개선 후에도 큰 편차의 과거 표면이 남는다.** 저자가 제시한 ‘갱신 품질 평가’에 직접 대응하는 결과이며, 남은 표면의 판단 상태를 출발점으로 의미정보·메시 갱신의 후속 과제를 구체화할 수 있다.

## 1. 실제 실행과 이번 분석의 범위

최신 동등조건 v5의 P1/P2 갱신은 완료돼 있다. 각각 113/66개 고정 뷰 전체에 같은 영상 메시 XY 지원 최대 규칙을 적용해 image90/296을 선택했다. 두 구역 모두 같은 코드·mesh·양방향 광선·거리 0.3m·정제 조건을 사용한다. 주 분석은 작은 변화영역 1m² 조건이다. ALS/영상 단독·합집합·Wu는 같은 원점을 사용하고, UAS는 후보 생성·판정에 넣지 않았다.

이번 v6에서는 완료한 입력·갱신·평가·공통조건 gate·가시화 영수증의 봉인 해시를 다시 확인했다. 같은 입력의 갱신을 반복 실행하지 않고, **동결한 원점·판정 마스크·UAS 거리로 출처별 잔존 편차를 추가 계산**했다. v5 결과와 평가를 수정하지 않았다. 새 분석 코드·설정·Docker 실행·PNG/PDF 그림은 별도 v6 경로에 남긴다.

[비교 화면](http://127.0.0.1:8901/) 상단의 **지역 → P1/P2**에서 동기화된 `ALS / 영상 기하 / Wu 갱신 / UAS 참조`와 단면·출처를 확인한다. 현재 뷰어는 URL query로 지역을 선택하지 않는다.

## 2. 정량 결과: 개선과 잔존 편차를 함께 본다

UAS 참조는 P1 1,127,634점, P2 2,325,976점이다. 모든 원점으로 평가하며 아래 F1@0.5m는 양방향 참조 근접도의 조화평균이다. 변화 검출 정답에 대한 F1이 아니다.

| **P2 Wu** | **93.50** | **0.2679** | **0.1629** |

P1은 ALS 대비 F1 +35.10%p, P2는 +41.45%p다. 합집합 대비 개선은 P1 +2.26%p, P2 +0.58%p로 더 작다. Wu가 모든 지표에서 최상은 아니다. 영상 단독은 결과→참조 평균이 더 작지만 결손이 크고, 합집합은 참조→결과 평균이 더 작지만 오래된 표면도 남긴다. 따라서 점을 많이 추가하거나 삭제해 한 방향의 수치만 개선한 것을 전체 품질로 해석하지 않는다.

| 삭제한 ALS | 7,252 / 20,189 | 13,433 / 45,986 |

P2의 F1 93.50%만 보면 과거 표면이 충분히 정리됐다고 오해할 수 있다. 그러나 유지 ALS 32,553점 중 7,724점이 UAS에서 2m를 넘는다. 새 영상점이 많고 대부분 참조 가까이에 있어 전체 점수는 높다. **전체 갱신 품질과 과거 자산의 잘못된 유지 위험을 별도로 평가해야 한다.** >2m는 사후 거리 진단이며 확정 오류·실제 변화 라벨은 아니다.

남은 큰 편차 ALS의 상태는 P1 `raw_single405 / filtered4 / unassessed2`, P2 `raw_single5,436 / filtered469 / unassessed1,819`다. 두 구역 모두 `consistent`로 분류해 유지한 ALS에는 >2m점이 없다. 잔존 문제는 관측 관계 미판정·메시 지원 부족·작은 변화영역 정제에서 주로 조사해야 한다. `raw_single`을 실제 단독 피복이나 현재 사용성 인증으로 해석하지 않는다.

## 3. 정성 결과: 실제 표면의 교체와 남은 이중층

그림의 좌표는 scene-local 미터이며 아래 위치 범위는 단면에서 읽은 근사값이다. 고정 단면은 P1 X=-8/Y=-6, P2 X=134/Y=109이고 전체 폭은 모두 0.5m다. 모든 단면 원점을 표시한다. 빈 참조 영역을 철거 정답으로 사용하지 않는다.

- **P1 개선:** X=-8 단면의 Y≈[-20,-5]에서 과거 ALS의 Z≈-37m 경사층 대부분을 제거하고 현재 영상·UAS의 Z≈-41.8m 평면을 복원했다. Y=-6, X≈[-13,-6]에서 지면 연결도 보강됐다.
- **P1 잔존:** Y=-6, X≈[-8,-4], Z≈[-37.5,-36.5]의 과거 경사 조각이 현재 바닥 위에 남는다. X≈[-21,-14], Y≈[-9,1]의 사진상 수목으로 추정되는 군집에서는 UAS에 보이는 하부 연결을 Wu에서 연속적으로 확인하기 어렵다. 수목은 사진 해석이며 의미 정답 라벨이 아니다.
- **P2 개선:** Y=109, X≈[125,153]에서 과거 상부 경사층을 상당수 제거하고 현재 UAS의 더 낮은 단차·반복 곡면을 추가했다. X≈126 부근의 지면~상부 수직 연결도 보강됐다. 실제 image296에서 반복 곡면 지붕을 확인했다.
- **P2 잔존:** X=134, Y≈[114,120], Z≈-22m와 Y=109, X≈[145,152], Z≈[-24,-22]에 옛 상부 조각이 남아 낮은 현재 표면 위의 이중층을 만든다. X≈[148,158], Y≈[86,101]에서는 현재 영상 기하가 비어 희소 ALS를 유지하며 관측 기반 세부 보강이 제한된다. 이 영역의 ALS를 모두 잘못 유지했다고 단정하지 않는다.

우선순위는 **갱신 품질 평가 → 잔존 old의 관측·판정 경로 확인 → 독립 현재 관측과 의미 문맥의 효과 검증 → 표면/텍스처 재구성**이다. 현재까지는 기존 방법의 선택 갱신 효과와 후속 검증할 구체 사례를 확보한 단계다. 평가 지표를 추가하거나 저자의 future work를 구현한다는 사실만으로 새로운 연구 기여가 확정되지는 않는다.

## 5. 근거와 해석의 범위

- 원문 기여인 정적 LiDAR 보존·변화 부분 갱신의 효과를 P1/P2에서 인정한다. 원방법 실패나 우리의 우위를 전제하지 않는다.
- 현재 실행은 COLMAP depth·추정 ALS 궤적·명시적 ray/정제 구현을 사용한 원문 기반 재구현이다. PSMNet·실측 궤적·저자 코드와 동일한 전체 재현은 아니다. 동일 비교 조건을 확보한 사실과 원방법 동일성을 구분한다.
- UAS header EPSG:32632와 작업 EPSG:25832의 기존 좌표 처리·datum/epoch·정합 한계를 유지했다. 수치는 같은 처리 아래의 개발 진단이며 공식 절대 정확도·변화 정답·일반화 결론이 아니다.
- 이번 추가 계산은 Docker에서 동결 원점/거리와 source group 수를 검산했고, 처리 전후 입력 해시 불변을 확인했다. 새 갱신 실행 0회, 후보 변경 0회, raw UAS 재읽기 0회다. 완료한 v5 P1/P2 실행이 분석 대상이다.
