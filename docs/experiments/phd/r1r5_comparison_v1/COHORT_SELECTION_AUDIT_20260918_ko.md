# 보정 후보 선정과 국소 prior 실험의 해석 범위

- `scientific_verdict: null`; 입력 관계 및 저장 결과의 개발용 진단.
- payload: 활성 attempt의 `cohort_selection_audit_20260918T121849Z/`.
- driver: `scripts/phd/r1r5_comparison_v1/audit_correction_cohort.py`.
- 검증: 동결된 review 함수로 국소 평면성을 다시 계산하고 R2–R5의 모든 보정
  label과 정확히 일치 확인. CPU Docker, 새 학습 및 입력/마스크 변경 없음.

## 1. R5의 15점이 모두 Z04인 이유

최종 보정 표는 R5 전체 표본이 아니라 `MVS source + correction judgment`만 집계한다.
동결된 선정 과정은 다음과 같다.

| 누적 조건 | R5 MVS 표본 수 |
|---|---:|
| 전체 표본 | 24,552 |
| 반복 관측에서 prior가 현재 MVS보다 앞 | 264 |
| 그중 건물로 분류한 Z 문맥 | 24 |
| 그중 보정 검토 대상으로 지정한 Z01/Z03/Z04 | 19 |
| 그중 국소 평면성 조건 통과 | 15 |

Z01은 1,760점, Z03은 1,000점, Z04는 2,511점을 검토했다. 앞의 두 구역에는
`prior가 앞` 관계 label이 각각 0개이고, Z04에는 19개였다. 그중 15개가 최종
조건을 통과했다. Z00 잔여·혼합 문맥의 224점은 건물 여부가 확인되지 않아 제외됐다.
이것은 **R5의 모든 변화가 Z04뿐이라는 증거가 아니다.**

`prior가 앞` 관계에는 현재 MVS 지지 3시점 이상, 카메라 위치 범위 5m 이상,
같은 광선에서 prior가 1m 넘게 앞인 관계의 비율 0.67 이상을 적용했다.
국소 평면성은 이웃 20점, 고유값 기반 변동 비율 <=0.06, 이웃 최대거리 <=4m다.
이는 개발용 관계/형상 기준이며 정확성 또는 실제 변화 판정으로 보정된 기준이 아니다.

또한 3D 후보와 실제 2D 개입은 다르다. 두 depth endpoint가 각각 보정 표본에
근접해야 하는 마스크 조건까지 적용하면 R5의 실제 prior 해제는 1영상의 1픽셀이다.
따라서 R5 prior0 결과의 유사성을 국소 가중치 무용성의 근거로 쓰기에는 개입이 너무 작다.

## 2. 눈으로 비슷한데 DA3와 거리 차이가 큰 이유

지표는 **고정 MVS 표본점 → 최종 TSDF 최근접 삼각형 표면의 3D 거리**다.
MVS를 직접 감독신호로 쓴 모델과 다른 depth를 쓴 모델의 MVS 입력 일치도를
비교한다. 독립적인 기하 정확도 또는 prior 해제 효과의 비교가 아니다.

| 영역 | MVS 기본 | MVS 국소 prior0 | DA3 | DA3−기본 중앙값 차이 |
|---|---:|---:|---:|---:|
| R1 보정 표본 1,137개 | 0.126m | 0.124m | 0.425m | 0.299m |
| R2 보정 표본 582개 | 0.050m | 0.051m | 0.862m | 0.812m |

각 점에서 계산한 `DA3 거리−기본 거리`가 0.1m를 초과하는 비율은 R1 81.35%,
R2 92.61%다. 일부 이상치만의 결과는 아니다. 특히 R2 Z06 하측 평지붕 띠의
307점은 기본 0.033m, DA3 0.941m이고, 최근접점의 local Z 차 중앙값은
각각 −0.016m와 +0.669m다. 위치 차이가 존재한다. 다만 최근접점이 같은 의미의
표면이라는 보장은 없고, 이 값은 동일 XY의 지붕 높이 오차가 아니다.

비슷한 평면 형태와 RGB를 가진 면의 위치 차이는 넓은 사시 뷰에서 구분하기
어려울 수 있다. 3.4배/17.2배는 작은 기준 거리로 나눈 비율이며, 그 배수만큼
건물의 시각적 형태나 독립 정확도가 나빠졌다는 뜻이 아니다.

## 3. 국소 보정과 무관한 곳을 평가한 것인가?

앞선 `local_effect_explanation_20260918T205426/receipt.json`은 후보점 표와
별도로 실제 해제 마스크의 모든 픽셀에서 확인했다. R1 2,342,258개, R2
1,193,651개 관측이다. 입력 간격 중앙값은 약 3.98/4.32m이지만 기본 결과의
MVS depth 잔차 중앙값은 이미 약 0.035/0.035m였다.

따라서 R1/R2는 실제 개입 위치에서도 추가 MVS 일치도 개선 여지가 작은 경우다.
단, R1의 평균/P90 잔차는 prior0에서 악화했으므로 중앙값의 유사성을 무변화로
해석하면 안 된다. 원 실행환경 차이에 대한 matched 대조는 별도 진행 중이다.

## 4. 현재 사례 분류가 연구질문을 충분히 검증하지 못하는 지점

1. 보정 후보는 입력 불일치 가설이지, 기본 GeoGS가 필요한 보정에 실패했다는
   확인이 아니다. 실제 변화가 있어도 기본 방법이 이미 보정했다면 추가 이득은 작다.
2. 후보 규칙은 prior가 더 앞인 관계를 중심으로 한다. 반대 방향 차이, 가림,
   결측, 복잡한 형상, 유보 표본을 모두 포괄하는 변화 검출기가 아니다.
3. 보존 후보는 입력 일치 관계 위주다. 정확한 prior가 잘못된 MVS 때문에 훼손되는
   상황을 이 후보 집합만으로 충분히 검증했다고 할 수 없다.
4. R3/R5는 실제 해제 픽셀이 82/1개다. 비영(非零) 마스크라는 실행 조건 통과와
   실질적인 국소 개입 효과를 검증할 충분한 범위 확보는 별개다.

다음 개발 판단은 기존 입력·결과에서 (a) 현재 표면 증거가 있는데 기본 결과가
잘못된 prior에 남는 사례, (b) 유효한 prior가 잘못된 현재 depth로 훼손되는 사례가
있는지 확인하는 것이다. 고정된 전체 결과를 유지하고 이 분석은 개발 진단으로
구분한다. 실제 사례가 확인되지 않으면 이 데이터에서 국소 신뢰도 조정의 추가
가치가 입증되지 않았다고 보고해야 한다. 합성 오차 실험은 오류 크기에 대한
기작 확인용이며 실제 데이터의 개선 효과를 대신하지 않는다.
