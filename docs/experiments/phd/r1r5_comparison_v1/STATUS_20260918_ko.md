## DA3가 더 좋아 보이는 결과의 해석

현재 완료된 직접 비교는 R1이다. MVS와 DA3 모두 동일한 complete Anchor8k의
checkpoint `5851b758ce531a40ff9b58b3ad4c0338e4f0e39ca273c1c4b76862e49228b503`에서
복원했으며 restore-equivalence PASS다. prior 0.005, 초기 image-depth 0.05,
native protection 및 dynamic depth controller를 유지하고 image-depth target을
교체했다. 따라서 depth source 교체의 결과 차이는 비교할 수 있으나 MVS depth의
절대 정확도가 DA3보다 낮다는 결론은 아직 없다.

- 현재 MVS 패널은 fused point cloud다. 학습은 각 영상의 COLMAP
  `*.geometric.bin`에서 가져온 depth를 사용한다. 융합 점군의 필터링 결과와
  개별 depth 감독 오차·coverage는 같은 대상이 아니다.
- 매끄러운 TSDF 표면, 위치 정확도, 경계 보존, 관측 누락은 별도 측면이다.
  외관만으로 감독 깊이의 정확도 순위를 매기지 않는다.
- 같은 계수라도 유효 픽셀, 잔차, 시점 간 불일치와 dynamic controller의 응답이
  달라 실제 영향은 달라진다. 다른 target에 대한 학습 loss를 그대로 정확도 비교에 쓰지 않는다.
- 다음 판단 단위는 DA3가 좋아 보이는 같은 국소 면의 원영상, 두 입력 depth,
  공통 가시 픽셀 오차와 각 source만 유효한 coverage, 반복 시점 지지,
  최종 표면 위치·경계다. 독립 현재 기준 기하가 있는 곳은 평가 전용으로 사용한다.
