## 검증 순서

1. 현재 참조와 원영상으로 기본 결과가 잘못된 실제 위치를 확인한다.
2. 보정 실패에서는 바꿔야 할 현재 표면이 있는데 잘못된 prior가 남았는지,
   보존 실패에서는 현재에도 맞는 prior 구조를 기본 결과가 잃었는지 구분한다.
3. 입력 관측·학습·추출을 조사해 해당 소스 가중치가 원인에 작용할 수 있는지 확인한다.
4. 동일 위치에서 회복과 원래 정확한 위치의 비열화를 함께 비교한다.

입력 불일치, 참조 오차, 원인, 가중치로 회복 가능성은 서로 다른 증거다.
참조로 발견한 개발용 사례를 자동 신뢰도 라벨·학습 마스크·정합·임계값 튜닝에
사용하지 않는다. 대표 사례만으로 전체 성능이나 일반화를 주장하지 않는다.

## Z07에서 무엇을 비교하는가

u=[42,44), v=[14,16), local z=[−34,−32) 안의 동일 UAS 155점이다.
149점에서 prior 거리는 0.25m 이하이고 기본 결과 거리는 1m를 넘는다.

| 대상 표면 | 동일 UAS 점 → 원본 삼각형 거리 중앙값 |
|---|---:|
| Existing ALS prior | 0.121772 m |
| 기본 MVS–GeoGS | 1.607791 m |
| Z08 국소 prior 0 | 1.718030 m |
| DA3–GeoGS | 2.108622 m |

이는 기본 MVS–GeoGS와 국소 prior0 사이의 큰 차이를 뜻하지 않는다.
두 GS 표면 모두 낮은 LiDAR/prior 표면보다 위에 있다. 기존 RGB 전체 뷰에서는
Z 선택이 주변 표면을 자르지 않고 확대하므로 이 작은 표면을 특정하기 어렵다.

새 뷰어는 네 원본 메시의 같은 위치를 같은 축척으로 표시한다. 기본 설정은
v=15m 중심 ±0.25m 단면이며 노란 LiDAR와 빨간 평가 상자는 가림 없이 표시한다.
교차선도 native triangle과 v=15 평면의 실제 교선이다. 주변 3D, 옆면, 사시,
위, 회전/이동/확대 기능이 있다. 높이 과장·기하 보정은 없다.
155점 수치는 전체 2m 셀 기준이며 단면에 보이는 점만의 통계가 아니다.

네 국소 메시에서 거리를 재계산해 frozen 평가와 최대 0.005mm 미만 차이를
확인했다. 기존 RGB 뷰어의 binary mesh도 같은 점에서 최대 0.0041mm 차이다.
이 위치의 불일치는 새 분석의 crop/다른 메시 차이가 아니다. Z07 전체의 실패,
MVS가 원인이라는 결론, 국소 가중치로 회복된다는 결론은 아직 없다.

## 한계

UAS는 0.25m voxel의 첫 원본 행으로 모든 높이·classification을 포함한다.
원본 EPSG:32632에 작업 EPSG:25832의 numeric identity를 상속했고 새 정합·수직
datum/epoch 보정은 없다. 이전 평가의 한계를 그대로 유지한다.
UAS→표면의 단방향 최근접 거리는 추가 플로터를 모두 검출하지 못한다.
표면→UAS 검사도 참조 가시 범위 안에서 수행해야 한다. 건물·표면 대응과
원영상 확인 후 보정/보존 실패로 확정하는 검토가 남아 있다.
