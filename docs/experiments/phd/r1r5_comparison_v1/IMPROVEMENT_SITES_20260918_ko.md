# 원영상으로 검토한 GeoGS 개선 필요지점

- 요청: R1–R5에서 DA3 또는 MVS 기반 GeoGS의 개선 필요 위치를 직접 찾아 제시.
- 상태: `REVIEWED_DEVELOPMENT_SITES`, `scientific_verdict: null`.
- payload: comparison attempt의 `improvement_sites_20260918T135645Z`.
- 뷰어: http://127.0.0.1:8913/data/improvement_sites_20260918_v1/index.html
- 학습·마스크·가중치 변경 없음. CPU Docker에서 기존 완료 결과를 평가·표출했다.

## 우선 검토할 다섯 새 위치

수치는 동일한 국소 UAS 표본에서 각 원본 메시의 최근접 삼각형까지 거리 중앙값(m).
지붕 전체, 수직 거리만의 값, 참조와 무관한 점수로 해석하지 않는다.

| ID | 위치 | 객체축 u / v / local z 범위(m) | n | prior | MVS–GeoGS | DA3–GeoGS |
|---|---|---|---:|---:|---:|---:|
| C03 | R2 Z06, 반복 채광창 옆 녹화 평지붕 | 140–144 / 100–104 / −28…−26 | 279 | 3.608 | 0.055 | 1.845 |
| C04 | R3 Z04, 넓은 자갈 평지붕 중앙 | 152–156 / 32–36 / −26…−24 | 350 | 0.068 | 0.013 | 1.122 |
| C05 | R4 Z08, 오른쪽 긴 건물의 자갈 지붕 | 296–300 / 40–44 / −26…−24 | 345 | 0.039 | 0.134 | 1.297 |
| C06 | R5 Z03, 도로 옆 긴 녹화 지붕 | 212–216 / −68…−64 / −36…−34 | 511 | 0.102 | 0.043 | 1.178 |
| C07 | R5 Z01, 태양광 패널 옆 독립동 옥상 | 140–144 / −60…−56 / −22…−20 | 391 | 0.083 | 0.015 | 1.137 |

C04부터 검토한다. prior와 MVS가 같은 낮은 지붕을 따르는데 DA3 결과가 높게
형성됐다. DA3의 영향 감소와 유효한 prior 보존을 검토할 위치다. C05는 조사한
5개 투영 가능 영상 중 MVS depth가 표본의 80% 이상 유효한 영상이 1개라,
관측 결측과 편향을 함께 볼 수 있다. 이것이 모든 학습 영상에서 MVS가 결측이라는
뜻은 아니다. C06/C07은 별도 건물의 재현성·굴곡 보존 검토 위치다.

C03은 prior도 현재 지붕과 다르다. 여기서 prior를 일괄 강화하면 필요한 보정에
반대할 수 있다. DA3 입력도 편향되어 있어 prior 해제 하나로 해결된다고 단정하지
않는다. 현재 MVS의 관측을 비교 근거로 DA3 depth 편향과 prior 감쇠를 함께 검토한다.

두 유형을 함께 비교하면 국소적 판단의 필요성을 검토할 수 있으나, 국소 가중치의
효과나 전역 가중치 조정보다 우수함은 아직 실행·확인하지 않았다.

## 입력 depth에서도 같은 방향의 차이가 있는가

표본이 90% 이상 화면 내부에 있고 위에서 내려다보는 조건의 영상 중, 투영 크기가
큰 순서로 최대24개를 조사했다. 원영상 두 장은 카메라 중심을 8m 이상 분리해서
선택했다. n은 반복 투영 관측이며 독립 표본 또는 실제 loss 기여량이 아니다.

아래는 표본 80% 이상에서 유효 depth가 있는 영상별 camera-Z 차이 중앙값을,
다시 영상 간 중앙값으로 요약한 것이다. `입력 depth − UAS의 camera-Z`이므로
음수는 LiDAR보다 앞쪽이다. 가림이 있으면 입력 자체 오류로 단정할 수 없다.

DA3 입력의 차이와 결과 표면의 높이 오차 방향이 일치한다. 이것만으로 학습 loss의
인과적 기여량을 확정하지 않는다. 예측 깊이의 스케일/편향과 GS 최적화·TSDF 추출의
기여를 구분하는 후속 실험이 필요하다.

## 후보를 찾고 검토한 과정

1. 기존 고정 UAS 표본과 prior·MVS·DA3·국소 prior0의 exact native triangle
   거리를 재사용. 입력/메시 SHA를 검증하고 같은 평가 표본을 유지했다.
2. R1–R5의 4×4×2m 셀, 80점 이상, 기존 건물 XY 문맥 비율80% 이상,
   평면 RMS≤0.08m, |normal_z|≥0.65에서 prior 가까움(≤0.25m),
   결과 멂(>1m), MVS와 DA3 결과 차이를 탐색. 이는 평가용 검색 기준이다.
3. 영역·유형별 점수순 공간 분리(12m), 4개까지 shortlist. 처음 선택한 9곳의
   실제 원영상·두 시점 투영·native triangle 단면을 직접 확인했다.
4. 아래층·가려진 표면이 순위에 섞여 외부 표면 대응 검사를 추가했다.
   0.5m XY 열의 상단 UAS 높이에서 0.5m 이내인 표본 비율을 평가용으로 기록했다.
5. 별도 `exterior_search`에서는 상단 비율80% 이상, 오차>0.5m까지 추가 검색했다.
   이 조건에서 MVS–GeoGS의 큰 평면 지붕 실패를 새로 확보하지 못했다.
   외벽·비평면·추가 플로터나 더 작은 국소 오류가 없다는 뜻은 아니다.

이 과정은 사후 개발 사례 검토다. 참조로 찾은 상자/라벨을 학습 마스크·신뢰도
학습·정합·방법 임계값 튜닝에 넘기지 않는다. 향후 효과는 고정 위치의 회복과
정확했던 위치의 비열화를 함께 평가해야 한다. 영역 중복 표본을 독립 사례로 합산하지 않는다.

## 보류 사례와 기존 Z07 해석 보완

- C01/C02/C08(R1 Z03): 모든 평가 표본이 같은 XY 열의 상단 LiDAR보다 아래다.
  상단과의 중앙 높이 차이는 각각 6.568/4.145/4.429m. 사진에는 채광 지붕이 있고
  위쪽 지붕 LiDAR와 GS는 겹치는 부분이 있다. 내부/다층/가림·반사 원인은 미확정.
  큰 최근접 거리만으로 ‘정확한 prior를 GS가 훼손했다’고 해석할 수 없다.
- C09(R5 Z04): 평가 점과 상단 관측면의 높이 차이 중앙값22.067m. 투영 위치가
  시점에 따라 외벽/옥상으로 달라진다. 낮은 표면의 가림을 먼저 확인해야 한다.
- C10(기존 R1 Z07): 원영상에서 낮은 지붕 띠 위치를 확인했으나, 기존155점 중
  상단 관측면 근처인 점은80점(51.6%). 거리 차이는 그대로 확인되지만 경계·다층
  참조의 대응을 더 확인해야 한다. 확정적 보존 실패의 주 사례에서 보류했다.
  기존 failure inspector에도 해석 보완을 표시했고 기하와 수치는 보존했다.

새 주 사례 C03–C07은 각 표본의 상단 비율이100%다. 이는 외부 대응을 뒷받침하는
검사이며 semantic roof 정답이나 완전한 가시성 보증은 아니다. raw classification은
전부0(미분류)이므로 건물 semantic label로 해석하지 않았다.

## 기술 검증과 재현

`find_improvement_sites.py`, `inspect_improvement_sites.py`,
`audit_improvement_reference_layers.py` 및 helper snapshot을 payload에 보관했다.
실행 config, Docker image ID/command, 입력/메시/출력 SHA, 로그와 예외 상태를
함께 기록한다. runtime payload와 derived display 파일은 Git 밖에 보관한다.

10개 사례 × 4개 native 메시의 국소 export에서 같은 LiDAR 점의 거리를 재계산해
기존 native 전체 메시 거리와 차이<1mm를 확인했다. 이미지 bytes와 depth 파일을
hash로 기록했다. 원영상의 빨간 상자는 투영된 평가 위치이며 학습 마스크가 아니다.

최종 `qa_v2/receipt.json`: 37개 브라우저 검사 PASS. 10개 사례의 네 메시와
사진·단면, 기본 사례 C04, 주 목록5/보류5, 카메라 동기화, 모바일 표시,
HTTP/브라우저 오류 부재를 확인했다. `publication_v2.json`은 게시 파일의 HTTP
응답과 로컬 SHA 일치를 기록한다. `receipt.json`은 최종 소스·검토 기록의 SHA와
기술 완료 상태를 연결한다. 이는 가중치 방법의 성능 검증이나 과학적 결론이 아니다.
