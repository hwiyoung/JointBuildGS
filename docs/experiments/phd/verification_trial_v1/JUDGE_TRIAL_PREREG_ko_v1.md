# 판정전(判定戰) 사전 등록 초안 — 렌더-대조 판정의 존재 증명

- 지위: **PLANNING RECORD / PRE-REGISTRATION 초안** — 실행 권한 없음. GPU 실행과
  §3의 빈칸(변형 대상·변형량) 확정은 사용자 승인 사항. `scientific_verdict: null`.
- 이름 체계: `../EXPERIMENT_MAP_ko_v1.md` (과거 코드 HV-3 → 판정전).
- 서사 담당: **⑦(판정)의 존재 증명 + ⑨ 검증 2단**.
- 전제(2026-08-23 실측으로 충족 확인): 판정할 사건 존재 = 모집단 층화 측정
  N=22/12 · 동기 = 붕괴층 45동(원인 귀속 라벨 진행 중) · 판정 재료 =
  실루엣/에지 + ALS intensity(2022 정사영상은 부재).

## 0. 이 실험이 답하는 유일한 질문

**"prior 가설 표면을 현재 영상에 렌더-대조하면, 3D 비교가 침묵하는 자리
(채움 지대·수직-분리 클래스)에서 채택/기각/판단불가를 실제로 판정할 수 있는가."**

배선(공동 최적화 구현)은 이 실험의 대상이 아니다 — 여기서 재는 것은
**신호(판정 재료에 정보가 실리는가)** 하나다. 공동 최적화 착수는 판정전
통과가 조건이며, 실패 시 최적화는 설계하지 않고 강등한다(§5).

**S1–S4 재설계와의 순서(2026-08-22 확정, 2026-08-23 재확인)**: 판정전은
S1–S4를 사용하지 않는다 — 전부 봉인 자산 재사용(δ-주입 크롭·55뷰 코리도·
수직-분리 패치 클래스). S1(평면 가설·배열)·S2(씨앗·o_init) 자산은 향후에도
재사용 입력이고, **재설계 대상은 S3(δ·평면·외관 배선 + 패치 판정 함수)이며
그 설계 착수 조건이 판정전 통과다**. 신호 부재 시 S3 재설계는 생략하고 §5
강등. 아키텍처·손실함수 논의도 판정전 통제 결과 이후로 유보.

## 1. 3막 구성 — 통제 2막(기제 증명) + 실전 1막(실재성), 분리 보고

| 막 | 정답 | 측정 | 성공선 |
|---|---|---|---|
| 1막 오차-주입 | 주입 δ (기지) | δ만큼 틀어놓은 prior 채움 패치의 렌더-영상 정합 점수 ROC | **3D-검사 전맹 기준선(C2C AUC 0.573/0.669/0.763) 초과**, 특히 평지붕 층(3D는 dS≈0.001 전맹)에서 유의 신호 |
| 2막 변화-주입 | 합성 변형 (기지) | 변형-prior 렌더의 현재-영상 지지도 하락 검출 ROC | 변형 3종 각각 AUC 명시(사전 예측: 실루엣 변화형(증축·철거) > 지붕형) |
| 3막 실전 | 없음 (라벨만) | A-티어 구지붕 렌더의 현재-영상 지지도, C-티어 대조 | **N=12 사례 시리즈 + 사전등록판 22동 얇은 ROC** (모집단 층화 측정의 스코프 규칙) |

통제는 "기제가 존재한다", 실전은 "이 장면에 실재한다" — 두 주장을 절대 섞지
않는다. 실전의 완전형 ROC 주장은 제2 장면으로 이월.

## 2. 1막 오차-주입 판정전

- 데이터: 결합 오차-주입 커브(D1) 계보 재사용 — E8/E7 δ∈{0, 0.25, 0.5, 1.0}
  크롭(전부 synthetic 표기 기존재). 판정 단위 = 채움 패치(선택-결합 규칙
  시험의 수직-분리/순수-채움 클래스 셀).
- 판정 신호: ① 실루엣/에지 정합(가설 표면 렌더 vs 현재 영상 에지) ② ALS
  intensity 렌더 vs 영상 명도(보조 — 단채널·복사 미보정 단서, 파일럿 판별).
- 비교 기준선(값싼 신호): 3D-검사 C2C AUC 0.573/0.669/0.763 + 봉인 게이트
  깊이 잔차(측방 전맹 실측). **동률이면 §5 강등 발동.**
- 뷰: 봉인 55뷰 코리도부터(파일럿) → 신호 확인 시 확대.

## 4. 3막 실전 판정전 — **확정판 (2026-08-24, 실행 전 등록)**

2막 게이트 통과 + 자연 낡음 스크린(후보 7/12) + 사용자 방향(합성 주력)을
반영한 2원 설계. 측정기 = 1막 v5-④ 광도 일관성 그대로, 학습·loss·S1–S4 무관.

**(a) 합성 확장 — 고유 주장 지대의 GT ROC (기제, 주력)**
- 대상: **비변화∧불충분 31동**(AX-10 사용자 조정판 셀 그대로). N=12가 아닌
  이유: 그중 7동이 자연 낡음 후보라 "무변형=참"이라는 합성 GT 전제가 오염됨
  — 합성은 깨끗한 비변화 건물에서, 자연은 N=12에서(역할 분리).
- 절차·변형·게이트: 2막과 동일(증축 +3.0 m 동측 / 철거→지면 서측 / 게이블
  +2.0 m; 변형-영역 AUC ≥ 0.75 게이트, 건물별 뷰 자동 선정 px/m≥8 상위 24).
- 주장 형태: "3D 비교가 침묵하는 채움 지대에서도 판정 기제가 성립"(2막의
  충분층 결과를 고유 주장 지대로 확장).

**(b) 자연 심문 — 실재성 사례 시리즈**
- 대상: N=12 — 자연 낡음 후보 7동(B173/B003/B019/B119/B001/B125/B038) 판정
  + ALS-현행 5동(B017/B021/B042/B045/B117) 특이도 대조.
- 절차: 무변형 ALS 가설을 그대로 채점(방법=영상만) → 셀 점수 지도 →
  **E1-기반 낡음 지도(|ALS−E1| 셀 z 차 >1 m)는 평가 전용 채점표**로만 사용
  (불변식 9 유지 — 방법 입력 금지). 판독: 건물별 낡음-셀 vs 현행-셀 AUC,
  대조 5동의 오경보(문턱 = 대조군 합동 5% 분위), 건물별 지지/모순/판단불가
  판독서.
- 단서 등록: E1 cls6 수관 혼입으로 낡음 지도 일부가 가짜 양성일 수 있음 —
  판독서에 건물별 뷰어 검수 결과 병기, B173(전 지붕 +4.1 m)은 무异론.
- 자연 정합-오차 사례: **0동**(장면 잔차 ~0.1 m 실측) — 정합 축 실전은 없음
  을 명시 기록, fine-δ는 GPU 트랙 이월.
- 라벨 계보: 티어·E1·낡음 지도 전부 평가 전용 — 방법 입력 금지.

## 5. 사전 등록 반증·강등 (은폐 금지)

- **반증 조건**: 1·2막에서 렌더-대조가 값싼 신호(C2C·깊이 잔차)와 동급(AUC 차
  유의 없음)이면 — "미분 가능 렌더링 판정 우위" 주장을 철회하고 C2C-기반
  인증으로 결론(그 부정 결과도 보고 가치로 정직 기재).
- **강등 사다리**: 공동(판정+보정+생성) → 판정+생성(δ는 탐지만) → 검증-전용.
  서사 ①–⑥ 진단·필요성·인증 기여는 판정전 결과와 독립 성립.
- 판정 주장은 어떤 경우에도 확정 93 마스크 위에서만(성능 기반 재선정 금지).
