## 4. 종합 — 판정전 3막 마감

- 1막: 채널 실증(단조 용량-반응), 굵은 δ 패치 판정권, fine-δ는 GPU 이월.
- 2막: 변화 판정 기제 GT ROC 0.88~0.96 (충분층) — 게이트 통과.
- 3막: 같은 기제가 **고유 주장 지대에서 유지**(철거 0.92 중앙값) + **자연
  낡음 실재성 사례**(B173 0.90) + 특이도 양호 + 판단불가 3유형 실증.
- **강등 불발동**: 실측 지지선 = "판정(변화 채택/기각) + 생성 + 건물별 인증
  (3분류)". fine-δ 보정 주장만 GPU 결정판 대기.
- **다음 = S3 재설계**(새 세션): 설계 입력 = 본 시리즈의 신호 지도 — 변화는
  판정 배선, fine-δ는 구속, 저텍스처·가설-희박은 유보 출력, 판정 단위는
  셀이 아닌 패치 집계.
