# E5 C001 S3-A′ Phase 1 — 씨앗면 준비 측정 (2026-07-15)

> 학습 0회 · 신규 MASt3R 추론 0회 · EPSG:25832. LoD2·ALS는 씨앗 생성과 B-c 후보 분류에 사용하지 않았다. 이 문서는 수치·분류만 기록하며 판정·해석을 포함하지 않는다.

## 입력·계약

- 정본 표면: Phase 0 `p0_fill_points.npz`의 건물별 P0 평면채움 배열.
- 높이 앵커: 같은 정본 NPZ에 저장된 발자국 안 FM점 전체의 z 중앙값.
- 씨앗 좌표: P0 float64 배열을 little-endian float32로 1회 형변환. 재적합·재격자화 없음.
- 엔진 입력: `jointbuildgs.s3ap.surface_seeds.v1`; 배열은 `xyz`, `rgb`, `sem`, `metadata_json` 네 개만 허용.
- 초기 불투명도: 엔진 로더가 모든 씨앗에 `0.10`을 부여.
- B-c 후보: 관측 SfM점과 밀집 초기점 중 발자국 경계 1.0 m 밴드, 다중뷰 조건, 대상 발자국 주소, P0/FM 평면 높이차 ≤0.30 m의 교집합.

세 정본 표면의 평면 최대 절대 잔차는 모두 잠금값 `≤1e-9 m`이다. 생성된 세 NPZ는 실제 Phase 2 로더로 왕복 검증했으며, 로더가 만든 `init_opacity=0.10`과 surface lineage를 함께 확인했다.

## B-c 경계 관측점 분류

| 건물 | 적용 | 후보 | 다중뷰 통과 | 대상 주소 | 높이 정합 | 최종 교집합 | 보조 NPZ |
|---|---|---:|---:|---:|---:|---:|---|
| 4907199 | true | 93 | 86 | 30 | 0 | 0 | 없음 |
| 8568391 | false | 0 | 0 | 0 | 0 | 0 | 해당 없음 |
| 8568392 | true | 73 | 27 | 5 | 4 | 2 | `DEBY_LOD2_8568392_bc_aux_seed.npz` |

`대상 주소`와 `높이 정합`은 각각 다중뷰 통과 집합에서 센 수이며, `최종 교집합`은 다중뷰·대상 주소·높이 정합 세 조건을 모두 만족한 수다.

분류 합계는 후보를 `다중뷰 탈락 / 대상 주소 밖 / 대상 주소 안·높이 불일치 / 최종 교집합` 네 범주로 분할한다. 4907199는 `7 / 56 / 30 / 0`, 8568392는 `46 / 22 / 3 / 2`다. 8568392 최종 2점의 P0/FM 평면 대비 절대 높이 잔차 중앙값은 `0.242837931055 m`, MAD는 `0.050960330729 m`다.
