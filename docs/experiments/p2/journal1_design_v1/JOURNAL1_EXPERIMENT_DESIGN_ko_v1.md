## 1. 목적

### 1.1 상위 목적 (헌장 앵커 유지)

불완전하지만 재사용 가능한 기구축 3D 자산(2022 Existing ALS)의 구조적 안정성과
현재 항공영상의 현재성·세부 관측을 상보 결합하여, 자동 LoD2 생성이 가능한 건물의
범위를 확대한다.

### 1.2 논문 중심 주장 (이번 설계로 입증할 것)

미분 가능 렌더링 기반 GS 최적화는 낡은 기하 prior와 현재 영상 증거를 **융합하는
틀**로서,

1. 영상 단독 산출물(`E2` MVS)보다, 그리고
2. 같은 정보의 단순 합성(`E2∪ALS` concatenation)보다

LoD2 구축에 더 적합한 point cloud를 만든다. 증거는 2단 구조다: **기하 레벨이 주
증거**(층화 GT — 비변화군 기존 LoD2 / 변화군 `E1`, §4.1 규약; 연속 지표,
per-building paired), **동결된
Roofer LoD2 판독이 응용 확인**, 그리고 둘 사이 **매개 분석**이 접착제다. 주장의
형태는 절대 품질이 아니라 **융합 증분**(E2→E4/E5, E8→E4/E5)이다.

### 1.3 개념 프레임 (교수님 요구 "개념적 설명+실험적 검증" 대응)

> 합성은 증거를 쌓고(union), GS는 증거를 하나의 표면으로 재구성한다(re-synthesis).

관측 가능한 결과 세 가지, 각각 측정으로 결박:

| 메커니즘 | 내용 | 측정 |
|---|---|---|
| M1 충돌 중재 | 광도 증거가 낡은 prior를 검증/기각 | 변화/비변화 층화 (H4) |
| M2 정합 잔차 흡수 | M1과 동일 기계의 전역 케이스 — 잔여 정합 오차에서 완만 열화(면역 아님) | δ-shift 강건성 커브 (H5) |
| M3 균질 재합성 | 단일 표면·균질 밀도·일관 노멀 vs 이중 표면·이질 합집합 | z-spread·노멀 일관성 (H3) |

### 1.4 비주장 (명시적 스코프 밖)

- GS 단독의 절대 우수성 — `E3 > E2`를 요구하지 않는다. E3는 분해용 ablation이며,
  실측(O50: E2 31 vs E3 23)과도 정합한다.
- 현시점 드론 LiDAR를 융합 입력으로 쓰는 arm — 전제 훼손(현시점 LiDAR가 있으면
  그냥 쓰면 됨 = E1) + 참조 순환(기하 평가 참조를 입력에 혼입)으로 제외.
- SfM 수준 합성 베이스라인 — 비교군은 파이프라인 내부 단계가 아니라 **입력 정보
  집합**으로 맞춘다. GS arm의 정보 집합(영상+SfM 포즈/시드+MVS 타깃+ALS)의 무-GS
  대응물은 `MVS∪ALS`다. `SfM∪ALS`는 표면 지표에서 ALS 단독(E7)으로 수렴하므로
  독립 slot이 불필요하다.
- confirmatory·일반화 주장 — 본 설계 전체가 비확증 기술개발이다(§7).

## 3. 실험 조건 (arms)

> **약어 규약(2026-08-12 사용자 확정)**: 모든 실험 조건은 E 연번 단일 시리즈를
> 쓴다. 신규 arm은 `E7`(구 P0)·`E8`(구 P1)·`E9`(구 P2)로 부여하며, E1–E6 로스터
> 확장은 04 계약/결정 로그 개정에 함께 반영한다. 참조는 조건이 아니며, 기하
> GT는 §4.1의 층화 규약(D-F)을 따른다.

| arm | 구성 | 역할 | 상태 | 비용 |
|---|---|---|---|---|
| E1 | 현시점 UAS LiDAR | 기하 레벨: 변화군 주 참조·비변화군 보조 참조·변화 라벨 근거(조건 아님); LoD2 레벨에서만 실용 상한 조건 | 보유 | 0 |
| E2 | 현시점 MVS → Roofer | product baseline (`DEC-P1-023` 유지) | 보유 | 0 |
| **E7** | ALS(2022) 단독 → SMRF → Roofer | 음성 대조: 낡은 자산 혼자의 한계(변화 건물에서 실패해야 함) | **신규** | 학습 0 |
| **E8** | E2∪ALS 합성 → SMRF → Roofer | **핵심 반사실**: GS 없는 단순 합성 | **신규** | 학습 0 |
| E3 | image-only GS (신형 레시피) | mechanism ablation | 보유 | 0 |
| E4 v3 | GS + ALS 정적 게이트 (TIN 0.25 m) | 무감쇠 융합 | S2c 재학습 중 | 진행 중 |
| E5 v3 | GS + ALS + F1 conflict 게이트 | conflict-aware 융합 (product primary) | S2c 재학습 중 | 진행 중 |
| E9 | E8 + 표면재구성(Poisson/TSDF) + 재샘플 | 2군 예비 — 리뷰어의 강화 합성 요구 대비 | 예비 | 보류 |
| E6 | GS + LoD prior | 계약대로 diagnostic-only, 본 설계 비포함 | — | — |

**공정성 규칙**

- E7/E8은 E4/E5와 **동일한 ALS 원본·정합 바이트**를 쓴다. 소비 방식만 다르다
  (GS: TIN 레이캐스트 depth/normal 손실, E8: 점 직접 합집합). 정합 혼입 차단.
- E8은 점수가 ~2배이므로 E2 밀도로 voxel thin한 밀도 정규화 민감도 체크 1회.
- E7/E8은 기존 봉인 체인(fusion→SMRF→roofer) 재사용, fuse 단계만 identity/
  concatenation 어댑터로 대체. Roofer 파라미터·footprint는 전 조건 동일(불변식 8).

## 4. 평가 프로토콜 (확정 시 동결)

### 4.1 기하 레벨 (주 증거)

**참조 규약(D-F 층화 GT, 2026-08-12 사용자 결정)**: 기하 GT는 건물의 변화
상태(§4.4 라벨)로 결정한다.

- **비변화군(주 GT = 기존 LoD2)**: `RoofSurface` 면 균일 샘플 + point-to-plane
  거리. 참조 노멀은 면 노멀로 정확. 보조 참조 = E1 스위트(방향 일치 확인용).
- **변화군(주 GT = E1)**: LoD2는 낡아 참조로 무효이므로 GT를 E1 현시점 UAS
  LiDAR로 교체한다(NA 아님). 변화군에는 LoD2 기반 지표를 산출하지 않는다.
- 공통: 건물별 footprint + 3 m 버퍼 크롭(8880 뷰어 자산 규약), 지면 제거 후 지붕
  영역, E1 결손 셀 마스크 공개. 방법 점군 A는 동결 추출 프로토콜(r0.25 depth
  렌더 융합 + 밀도 게이트)로 생성하며 전 GS arm 동일. A3 실행은 라벨 확정과
  무관하게 **건물마다 두 GT 스위트를 모두 계산·저장**하고, 층화 집계만 라벨을
  따른다.
- **판정 규칙(triangulation)**: H2/H3 판정은 주 GT와 보조 GT(E1)에서 **방향
  일치**를 요구한다. 불일치 시 원인 규명 전까지 주장을 보류한다.
- 미모델 상부구조(굴뚝·옥탑 등 LoD2 비표현 요소)에 대한 벌점은 trimmed 통계로
  완화하고 공개한다.

| 지표 | 정의 | 방향 | 잡아내는 실패 | 연결 |
|---|---|---|---|---|
| 정확도 | A→R 최근접 거리 중앙값 | A→R | 계통 바이어스·노이즈 | H2/H3 |
| Precision@τ | d≤τ인 A 점 비율 | A→R | 플로터, 잔존한 낡은 지붕(M1 실패) | H4 |
| Completeness@τ | d≤τ인 R 점 비율 | R→A | 구멍·미관측 지붕면 | H2 |
| F1@τ 커브 | P/C 조화평균, τ∈{0.1, 0.25, 0.5, 1.0 m} | 양방향 | 종합(단일 임계 의존 제거) | 헤드라인 |
| Outlier율 | d>1 m인 A 점 비율 | A→R | GS 플로터·낡은 기하 잔존 | H4 |
| RMSD(+trimmed) | 제곱평균 거리 | A→R | 큰 오차 민감(교수님 지목) | 보조 |
| Coverage | R 점유 0.25 m 셀 중 A 점 존재 셀 비율 | R→A(면적) | 국소 결손의 공간 분포(셀 지도) | H2·국소 |
| 노멀 일관성 | 매칭쌍(d≤τ) 노멀 각오차 중앙값 | 양방향 | 방위 붕괴(Roofer 직결; S0 절제 근거) | H3/H6 |
| 표면 두께 | 셀 내 z p90−p10 | 참조 불요 | **이중 표면** — 합성 vs GS 판별기 | H3/H5 |

- 노멀은 전 점군 동일 PCA 추정(공정성; GS 고유 노멀의 이점은 Roofer 성능으로 발현).
- 통계: per-building paired Wilcoxon + 효과크기(중앙값 Δ, bootstrap CI), τ 커브
  보고(단일 임계 금지), 변화/비변화 층화, 0.25 m 셀 국소 지도.
- (보조, 비변화군) E1 기반 스위트를 방향 일치 확인용 secondary로 병행
  보고한다(위 판정 규칙). 변화군은 E1이 주 GT이므로 별도 보조가 없다.

### 4.2 LoD2 레벨 (응용 확인)

- 기존 봉인 체인 재사용: fusion→SMRF→Roofer(199동)→판정 r0.25, O50(noG2) +
  대시보드 5지표(comp/corr/cov/rmse/angle).
- `DEC-P1-023` estimand 유지: E2 O/X 층화 전이표, `E2 fail→m pass`와
  `E2 pass→m fail` 동시 보고.
- LoD2 레벨 참조(기존 LoD2 `RoofSurface` + 현재 UAS 근거)는 **비변화군에서
  유효**하다. 변화군은 참조 낡음을 명시 처리한다: 현재 UAS 근거로 판정하거나
  NA(reference-absence 의미론, `DEC-P1-024`)로 공개하고, 불변식 12의 temporal
  status를 기록한다.

### 4.3 매개 분석 (H6)

조건쌍(E2→E4v3, E2→E5v3, E8→E5v3)별로 건물 단위 Δ기하(F1@0.25, completeness,
노멀) vs ΔLoD2(5지표, O/X 전이)의 상관 및 전이 예측(로지스틱). "point cloud 품질
향상이 LoD2 개선으로 이어짐"의 직접 입증.

### 4.4 변화/비변화 라벨 (H4·기하 GT 층화 전제)

- 자동 후보: 건물별 ALS(2022) vs E1(2024) footprint 크롭 거리(중앙값 NN, z-diff)
  임계 → 변화 후보.
- 사람 확정: 8876/8880 뷰어에서 O/X 검토.
- 사용 제한: **평가 층화 전용**. 파라미터 선택·학습 입력 사용 금지(불변식 9).
  변화 건물의 temporal status 기록은 불변식 12 이행.
- 라벨은 평가 층화와 **기하 GT 선택**(§4.1)을 함께 결정한다. A3가 두 GT 스위트를
  모두 저장하므로 라벨 확정 시점과 무관하게 재집계만으로 반영된다.

| H2 | E4v3/E5v3가 E2 격차(v2 실측 −8/−7)를 0~양수로 회복 | 융합 이득 성립 | prior 축 종료 검토 → E2 하이브리드 안건으로 피벗 |
| H3 | E8은 completeness 최고이나 z-spread·노멀 악화, Roofer RMSE 악화 → 종합 F1·LoD2에서 E4/E5 우위 | **중심 주장 성립** | GS 융합 주장 폐기 → conflict-aware 합성/하이브리드로 방법 재설계, GS 훈련 중단 |
| H4 | 비변화: E4≈E5≈E8 / 변화: E5>E4, E8·E7 급락 | E5 헤드라인 + 시간축 서사 완성 | conflict 항 기여 없음을 보고하고 E4로 단순화 |
| H5 | 합성은 δ=0.1 m부터 구조적 열화(z-spread 이중모드), GS는 ~0.5 m까지 완만 | 정합 반론 방어 + 허용 정합 오차(운영 한계) 정의 | "정합 QA 게이트가 유일 방어선"으로 한계 명시 |
| H6 | Δcompleteness/ΔF1이 ΔO/X 전이를 예측 | 기하 지표 = 검증된 대리 지표 → 이후 개발 루프에서 Roofer 생략 가능 | 기하는 진단 전용으로 강등, LoD2 판독 유지 |

**주의 기대(사전 공개)**: E7(ALS 단독)이 **비변화 건물에서 강할 수 있다.** 2022
이후 무변화 건물이라면 깨끗한 항공 LiDAR가 그대로 유효하기 때문이다. 이 경우에도
E7은 불변식 12(현재 증거 없는 현재성 주장 불가) 때문에 product가 될 수 없으며,
논문 가치는 (a) 라벨 없이 낡음/유효를 자동 중재하는 E5, (b) 변화 건물 회복으로
집중된다. 이는 약점이 아니라 서사의 정밀화다.

**결과 조합 → 논문 형태**

- H2 지지 · H3 지지 → 본 설계대로 (GS = prior 융합의 틀).
- H2 지지 · H3 기각 → 합성 기반 conflict-aware 융합으로 방법 피벗.
- H2 기각 → prior 축 종료, E2 하이브리드/기하 개선 축 재설계(기존 안건).

## 7. 위험·한계 (공개 항목)

- `DEC-P1-015` 199동 census로 기존 held-out 소진 — 본 설계 전체가 비확증 기술개발.
  confirmatory 주장은 설계 동결 후 새 분할에서 별도 결정(사람 결정 사항).
- 기하 GT 위험(D-F 채택안의 통제 항목): ① **prior-계보 상관** — 기존 LoD2는
  prior(ALS)와 동시대·동계보라 비변화군에서 prior 소비 arm(E4/E5/E7/E8)에 구조적
  이점이 있고, image-only arm(E2/E3) 대비 H1/H2가 부풀 수 있다 → E1 보조 GT
  방향 일치 요구로 방어. H3는 E4/E5와 E8이 같은 prior 바이트를 공유해 상관이
  대칭이므로 내성이 있다. ② **추상화 편향** — LoD2 평면 단순화는 과평활 arm에
  유리 → trimmed 통계 + 공개. ③ E7 음성 대조의 실패 판정은 변화군(E1 GT)에서만
  유효하다. ④ E1도 측량값이며 절대 정답이 아니다(사용자 확인 2026-08-12) —
  변화군·보조 GT에서 노이즈 바닥 위 해석, 전 arm 동일 참조의 paired Δ로 1차
  상쇄, 결손 마스크 공개. E1은 기하 레벨에서 조건이 아니다.
- 판정 민감도(S3b 실측: 판정 해상도로 E4↔E5 순위 반전) — 단일 임계 의존 금지,
  τ 커브 보고.
- 라벨·δ-shift의 E1 의존 — 평가 전용 사용으로 한정하고 명시 기록.
- 용어: 논문·문서 전체에서 "미분 가능 렌더링" 사용(불변식 6).
