## 3. 해석 (D3 판정의 절반 — union 측)

1. **주입 δ는 실질적 오염이다**: 현재 증거가 없는 E7에서 모든 채널이 붕괴(δ=1에서
   f1 −0.098, 판독 O 31→10). 즉 union의 강건해 보임은 δ가 무해해서가 아니다.
2. **union의 겉보기 강건은 "흡수"가 아니라 "보험"이다**: ① E2 밀도 지배(약 9:1) —
   오염 점이 평균·OR 지표를 못 움직임, ② 평면 미끄러짐 — 평지붕 내부 무해,
   ③ τ/z_tol 버퍼. 보험이 없는 곳에서 비용이 정확히 드러난다:
   **이중 표면이 86/93동에서 보편 발생(z-spread +12%\*\*\*)**, 채움의 위치 정확도
   하락(comp@0.25 −0.014\*\*\*, 사전 등록한 "구멍 오염" 그대로), Roofer −3동.
3. **응용 레벨(판독 O/X)은 δ≤1 m에 대체로 둔감** — G3 50% 겹침·G4 임계가 1 m급
   이동을 흡수. 정직 보고: fine-δ 구간에서 union의 실용 손실은 "붕괴"가 아니라
   "표면 순도의 보편적 오염 + 소폭의 Roofer 손실"이다.
4. **D2(GS) 판정 기준이 선명해졌다**: 같은 δ에서 —
   - GS의 z-spread가 union처럼 오르면(이중 표면) **H-M2 기각**.
   - GS가 E7처럼 z-spread 플랫(단일 표면 재합성)을 유지하면서 completeness를
     union 수준으로 지키면 **H-M2 지지** — "union의 보편적 이중 표면 비용을
     재합성이 제거한다"가 정확한 주장 형태가 된다.
