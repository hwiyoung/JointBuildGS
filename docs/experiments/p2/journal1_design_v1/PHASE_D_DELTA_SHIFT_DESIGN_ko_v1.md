## 1. 목적과 가설

**H-M2 (정합 잔차 흡수):** 표준 지오레퍼런싱 이후 남는 fine 잔차 급(수십 cm)의
평면 오프셋 δ에 대해, 단순 합성(union, E8)은 이중 표면화로 기하·Roofer 판독이
단조 열화되지만, GS-prior 재합성은 current-consistency 게이트가 어긋난 프라이어를
감쇠해 열화 기울기가 유의하게 완만하다.

**주장 스코프(사전 등록, 사용자 합의 2026-08-12):**
1. 기지 datum/높이계 차이(예: 지오이드 45.7 m)는 결정론적 전처리 계약 — 흡수 주장 아님.
2. **M2 주장 구간 = 표준 지오레퍼런싱 후 잔차** (본 데이터 실측: signed-z 중앙
   0.092 m, xy p95 0.41 m). δ 격자가 이 구간과 그 2~10×를 훑는다.
3. ≥1 m급 계통 오차는 흡수 금지 대상 — conflict 맵의 "정합 실패 탐지" 영역(verification).

**사전 등록 예측:**

| arm | 예측 |
|---|---|
| E8(δ) union | z-spread ↑(경사면에서 ≈δ·tan(slope) 추가), precision@0.5 ↓, f1 ↓, Roofer 기술유효 ↓, rf_rmse ↑, G3 평면매칭 ↓. δ=0.5 m(셀 격자 급)부터 가시적, 1.0 m에서 강함. **completeness/coverage는 τ=0.5 m·z_tol=1 m 버퍼 때문에 δ≲τ에서 높게 유지될 것 — 이는 강건성의 증거가 아니라 무딘 이득 지표가 오염을 가리는 것**(아래 분리 판독 규칙) |
| E7(δ) ALS 단독 (음성 대조) | 흡수 기제 없음 — acc_median이 δ에 비례해 그대로 전이 |
| GS55(δ) 재합성 | confidence×current-consistency(exp(−\|r\|/2 m)) 감쇠로 GS55(0) 대비 완만한 열화, δ=1.0에서도 붕괴 없음 |
| E2 (δ 불변 대조선) | 플랫 — 재실행하지 않음 |

**판정 규칙:** Δm(δ)=m(δ)−m(0) 페어드 열화량을 E8 vs GS(E5 레시피)에서 **동일
확정 93 모집단**으로 비교. z-spread를 이중 표면 판별기로 사용.
H-M2 지지 = E8 열화 기울기 > GS 기울기(방향 일치, 두 GT). 기각 시 M2 주장 철회.
E4(δ=0.5) 스팟과의 차이로 게이트 기여를 분리 보고.

**게이트 상수의 계보와 사전 감쇠 계산(사전 등록):** conflict 게이트
exp(−|r|/2 m)·프라이어 가중(depth 0.01/normal 0.005)·Huber 1.0 m는 문헌 인용
값이 아니라 **C4 preflight 계보의 동결 프로젝트 상수**다(운영 근거 = gradient/
GPU preflight + 12k dose-safety 게이트; 손실 형태 자체는 Huber 로버스트 추정·
지수 soft down-weighting·sign-invariant 노멀의 표준 관행). XY δ에서 깊이 잔차는
표면 미끄러짐 때문에 평면 내부 r≈0(무해·무감쇠), 경사 30°에서 r≈δ·tanθ →
감쇠 계수 0.93/0.86/0.75(δ=0.25/0.5/1.0), 불연속부 r≈수 m → 차단. 즉 감쇠는
위험 지점에 국소화되지만 스케일 2 m는 온화하므로, **흡수는 게이트 단독이 아니라
Huber+저가중(0.01, MVS 깊이 0.03의 1/3)+MVS 감독 우세의 합성 효과**로 예측한다.
따라서 본 실험은 H-M2 검증이면서 동결 상수의 스트레스 테스트를 겸하며, 흡수
부족 시 게이트 스케일(2→1 m) 민감도 후속이 정당화된다.

**흡수 유효 영역의 사전 한정(2026-08-13 논의):** 게이트·깊이 중재의 원료는
현재 깊이 잔차이므로 **MVS 구멍(무증거) 픽셀에서는 중재가 불가**하다
(current-consistency 중립 0.5, 광도 채널만 잔존). 따라서 GS의 δ 우위는
**겹침 영역의 이중 표면 방지**에서 나와야 하며, 구멍 채움의 δ 오염은
union·GS **공통**으로 예측한다 — 구멍은 Claim A의 이득 지점이므로, "채움의
양(completeness)은 유지되나 채움의 위치 정확도는 양 arm 모두 δ만큼 손해"가
사전 예측이다. GS의 구멍-방어는 광도 단독의 몫이라 약할 것으로 예측(측정 대상).

## 2. Arms와 δ 격자

- **δ의 정의**: raw ALS 점(동결 datum 브리지 z+45.7 적용 후)을 EPSG:25832 월드
  프레임에서 **x → x+δ 평행이동**(수평 지오레퍼런싱 잔차 모사). 이동 주체는
  프라이어/합성에 들어가는 ALS 바이트뿐이며 다른 입력은 불변.
- **δ_xy ∈ {0.25, 0.5, 1.0} m, 방향 고정 +X(동쪽)** — 사전 등록 단일 방향
  (RNG 금지 불변식 준수; 93동의 다양한 지붕 방위가 용마루-평행/직교 효과를
  모집단 안에서 평균화). 방향 민감도는 필요 시 δ=0.5에서 +Y 1점 확장만 예약.
  δ=0은 기존 봉인 런 재사용(E8, E7, S2 E4_V2_STATIC/E5_V2_F1).
- **z 민감도 1점: δ_z=+0.25 m** (union 측만; 실측 z 잔차의 ≈2.7×; z는 전 표면
  직격이라 1점으로 방향 판독 가능).
- **union 측 (CPU, 학습 0):** E8(δ) 4런(xy 3 + z 1) + E7(δ) 3런(xy만).
  기존 `a2_build_e7_e8.py`에 `--delta-xy-east-m/--delta-z-m` 추가 — ALS 로드
  직후 δ 평행이동만 삽입, 이후 체인(SMRF·overlay·Roofer defaults·크롭·
  geometry_eval 93동)은 봉인 파라미터 그대로.
  **정합 게이트 전환:** δ 주입 런에서 게이트는 통과 조건이 아니라 **계측 기록**
  으로 역할 변경. 참고(사전 예측): 봉인 게이트의 XY NN 거리는 준균일 점군의
  **측방 이동에 구조적으로 둔감**하고(NN 거리는 점 간격을 재지 이동량을 재지
  않음) 평지에서 z 잔차도 불변이므로, δ_xy 런이 게이트 수치상 '통과'로 보일
  수 있다 — **이 둔감성 자체가 δ 위협 모델의 현실성 근거**다(파이프라인 자체
  게이트로 탐지되지 않는 종류의 오차). 게이트 출력은 기록만 하고 차단하지 않는다.
- **GS 측 (GPU, 풀신 — 2026-08-13 사용자 결정으로 코리도 1동에서 확대):**
  - **D2a 코리도 스모크**: `e4_local_4906982_55v_als_prior_v1` 릭에 δ=0.5 1런
    (~1–2 h) — δ-주입 prior 재투영 배관 검증 전용, 판정에 불사용.
  - **D2b 풀신 본런**: S2(redesign) 레시피 재사용, 프라이어 준비 단계에서
    ALS에 δ 주입 후 TIN 재구성·재투영 → 동일 학습 스케줄.
    **conflict-게이트 arm(E5_V2_F1 레시피) × δ{0.25, 0.5, 1.0}** = 주 커브 +
    **static arm(E4_V2_STATIC 레시피) × δ{0.5} 1점** = 게이트 기여 분리 스팟
    (E4(δ)−E5(δ) 차 = 게이트의 흡수분). δ=0 앵커는 기존 봉인 S2 런 재사용,
    재학습 없음. 단일 개입 = 프라이어 바이트의 δ뿐. 판독은 union과 동일 경로
    (S3 크롭 → geometry_eval 확정 93 → 페어드 기울기 비교, 동일 모집단).

## 3. 지표와 읽기

1. **기하(확정 93, 두 GT, lod2 앞세우고 e1 병기):** f1@0.5·completeness·precision·
   acc_median·z-spread — E8(δ)−E8(0) 건물별 페어드(Wilcoxon).
2. **Roofer:** 기술유효 수, rf_rmse_lod22 중앙값. **union 부작용 7동 추적**
   (δ=0에서 E2 성공→E8 실패로 확인된 42364659/4906967/4906968/4906975/4907514/
   4907517/4959460): δ 증가 시 부작용 확대 여부 = union 취약성의 독립 신호.
3. **auto-OX(현재-UAS 앵커층, noG2, NOT_OFFICIAL):** O 수 커브.
4. **코리도 페어:** GS55(δ) vs E8(δ)@4906982 — 동일 건물·동일 δ 직접 비교
   (+ E8 크롭 행에서 4906982 추출).
5. **이득/비용 채널 분리 판독(사전 등록, 2026-08-12 사용자 논의):** Claim A의
   이득 채널(completeness/coverage 증분 잔존)과 비용 채널(z-spread·precision·
   normal·Roofer 붕괴)을 별도 커브로 읽는다. 이득 채널은 τ 버퍼로 δ에 둔감한
   무딘 지표이므로, completeness 유지만으로 union 강건을 주장할 수 없다 —
   τ 민감도(τ=0.1/0.25 completeness 커브)로 교차 확인한다. Claim A의 스코프는
   "불변·정합 양호 영역의 공백 충전"이며, 변화·오정합 영역에서는 이득이
   소멸하고 비용만 남는다는 것이 본 실험의 배경 명제다.
