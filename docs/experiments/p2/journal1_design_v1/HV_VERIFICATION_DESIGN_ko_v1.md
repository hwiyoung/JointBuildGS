# H-V — 검증(verification) 실험 설계 v1 (PLANNING RECORD)

- 상태: **설계 — 1단계(무학습 CPU)는 사용자 승인(2026-08-13 "그래 진행하자"), 광도 단계는 결과 후 결정**
- task_id(예정): `P2-JOURNAL1-HV-v1` · 비확증 · `scientific_verdict: null`
- 배경: A2/D1/D2a 실측으로 기여 재배치 — 기하 백본=union(E8), GS=검증+외관 계층.
  변화·정합은 "GS가 고치는 문제"에서 "**반드시 탐지해야 할 문제**"로 이동
  (union 제품은 조용히 오염되고, 봉인 정합 게이트는 측방 오차 전맹 — D1 실측).

## 1. 질문과 가설

**질문**: "이 prior를 여기에 합쳐도 되는가"를 판정하는 conflict/currentness 맵을
누가 가장 잘 만드는가 — 값싼 깊이-기반 탐지기(C2C 잔차)로 충분한가, 아니면
미분 가능 렌더링(광도 채널)이 원리적으로 필요한가?

- **H-V-δ (정합 오차 탐지, 통제 실험)**: δ-주입 데이터(D1)의 정답을 이용해
  탐지기별 δ 검출력을 잰다. **사전 등록 예측**: 깊이-기반 탐지기(C2C·깊이
  잔차·봉인 게이트)는 표면 미끄러짐 때문에 **평지붕(horizontal)에서 전맹**,
  경사지붕(slanted)에서만 δ·tanθ만큼 감지. 광도-기반(렌더 텍스처 어긋남)은
  질감 있는 평지붕에서도 감지 — 성립 시 GS 검증의 원리적 우위.
- **H-V-chg (변화 탐지, 후보 라벨)**: 양성=A-티어 23(선정 93 내 변화 후보),
  음성=C-층. conflict 점수의 판별 ROC를 탐지기별 비교. 라벨이 자동 후보라
  예비 지위 — 인간 라벨 확정 시 재판정.

## 2. 탐지기(경쟁자) 로스터

| 탐지기 | 원리 | 비용 | 사전 예측 |
|---|---|---|---|
| C2C 잔차 | ALS→E2 최근접 3D 거리 통계(건물별) | CPU, 무학습 | 평지붕 전맹, 경사 δ·tanθ |
| 깊이 잔차(봉인 게이트 동형) | 투영 prior depth vs MVS depth | CPU | C2C와 동형 맹점 |
| **광도 잔차(GS)** | prior-정합 기하로 렌더 vs 실제 영상 | GPU(코리도부터) | 질감면 측방 감지 가능 |

## 3. 단계

1. **HV-1 (지금, CPU 반나절)**: C2C 기준선 — D1의 E7(δ) 크롭(ALS 단독) vs E2
   크롭으로 건물별 conflict 점수 S(δ), δ∈{0, 0.25, 0.5, 1.0}. 판독: 페어드
   ΔS(δ), δ-검출 AUC, **rf_roof_type(horizontal/slanted) 층화로 맹점 예측 검정**.
   + 같은 점수로 H-V-chg ROC(A23 vs C층).
2. **HV-2**: 깊이 잔차 채널(투영 기반) — C2C와 맹점 동형성 확인.
3. **HV-3 (GPU, 코리도→확대 결정)**: 광도 채널 — GS55_dx050(δ 기하) 렌더 vs
   실제 55뷰 광도 잔차가 GS55_0 대비 상승하는가(평지붕 질감 포함). 코리도 1동
   파일럿 후 풀신 여부 결정.
4. **HV-4**: 종합 — 탐지기별 ROC/AUC 표 + 맹점 지도 + "재사용 안전 인증서"
   산출물 시안(건물별 O/주의/거부).

## 4. 통제·정직

- δ 산출물은 전부 synthetic 표기(D1 계보) — 정답 주입 실험임을 명시.
- H-V-chg 라벨은 자동 후보 — 예비. C2C가 광도와 동급이면 "GS 검증 우위" 주장
  철회하고 C2C-기반 인증으로 결론(그 결과도 논문 가치 있음 — 정직 보고).
- 외관 축은 본 실험과 별개(존재성 + held-out PSNR/SSIM + bounded 정성 패널).
