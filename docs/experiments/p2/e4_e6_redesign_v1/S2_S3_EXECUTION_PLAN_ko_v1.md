**S2 프리플라이트(전 게이트 통과 전 학습 금지, DEC-P1-017 계승):**

1. 풀신 프라이어 생성: 콜맵 풀신 937 카메라로 동일 투영기 — 풀신은 카메라가 장면
   내부이므로 코리도=장면 bbox. E4(정적)와 E5(정적×F1, fused = 신형 E3 풀신
   fused 타깃) 두 변형. 픽셀 stride 2(용량 ~8 GB).
2. 등록 게이트(|z 중앙| ≤ 0.5 m, XY p95 ≤ 0.5 m) + 누출 QA(전역 중앙값 ≤ 1.0 m,
