- **C2:** 51동 중 50동은 MVS 입력이 연결되고 Roofer 출력과 유효한 3D 형상까지
  생성됐다. `DEBY_LOD2_4907183` 한 동은 연결할 MVS 건물 성분이 없어 첫 입력
  단계에서 멈췄다.
