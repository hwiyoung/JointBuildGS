## 0. 연구 문장과 세 가지 장애물

이 트랙은 **낡았지만 구조가 온전한 기존 3D 자산**(과거 항공 라이다 점군,
이하 "기존 자산")과 **현재 드론 영상**을 결합해, 어느 한쪽 단독이나 판단
없는 결합보다 나은 건물 모델을 만들 수 있는지 검증한다. 기존 자산을
**그냥 합치면 안 되는 이유** 세 가지가 연구의 출발점이며, 각각 담당 주장이
있다:

| 장애물 | 뜻 | 담당 주장 | 실험 현황 |
|---|---|---|---|
| **변화** | 건물이 그동안 바뀌어 기존 자산이 낡음 | 주장 4·5 (재량 축) + 부록 주장 A | 변한 건물(B173) 상시 시험대; 셀별 해제로 낡은 부피 제거 실증(0.08→0.34); 무판단 결합은 낡은 지붕이 함께 남음(정밀 0.55) 실측 |
| **정합** | 두 데이터의 위치가 어긋남 | 주장 7 | 오차 주입-회수 실험만 존재(수직 72% 회수, 수평은 형상 의존 11~56%) — 명제 미정식화 |
| **외관(텍스처)** | 기존 자산엔 현재 겉모습이 없음 | 주장 8 | **공백** — 광도 학습은 내장(평가 PSNR 추적)이나 산출 계약 미정의 |

## 1. 파이프라인 (방법이 무엇인가)

우리 조립기는 4단계다(상세: 용어 문서 §1):

| 단계 | 하는 일 | 한 줄 |
|---|---|---|
| S1 평면 가설 생성 | 후보 평면 수집 | 참 표면이 들어 있을 가설 공간 확보(기존 자산 + 현재 영상 점군 유래) |
| S2 공간 분할·초기화 | 평면으로 공간을 **방(셀)**으로 나누고, 기존 자산으로 각 방의 채움/비움 초기값을 놓음 | "기존 자산의 부피 가설" 배치 |
| S3 미분 가능 렌더링 최적화 | 현재 영상 증거로 초기값을 **심판·수정** | 판정 단계 — 끄면 "재현", 켜면 "판정" |
| S4 모델 추출 | 확정된 채움/비움에서 구조화 모델을 뽑음 | 출구(파일명 s5_* 동결) |

- **재현 모델** = S3를 끈 것(학습 0): "기존 자산을 그대로 믿으면 이만큼".
- **판정 모델** = S3를 켠 것: 세부 손잡이 = 앵커 세기 w(초기값을 붙잡는
  용수철), 셀별 앵커 신뢰 occ_w(방마다 용수철을 풀 수 있는 배율), 평면
  모드, 가림 처리.
- 초기값은 **기존 자산 전용**이다 — 심판(영상 증거)과 피고(기존 자산의
  가설)를 분리해야 "영상이 기존 자산을 심판한다"는 실험 구도가 성립한다.

## 3. 주장 사다리 (논리 설계)

> 이후 판독 문서는 "주장 n"으로 인용한다. 번호는 동결, 배열은 3막.

**한눈 요약 — 주장은 세 묶음이다:**

|---|---|---|---|

### 막 1 — 기반: 재료와 조립이 성립한다

**주장 1 — "혼자서도 선다"** (2026-08-18 좁힘)
기존 도구(Roofer)가 실패하는 재료·유형의 건물에서도, 같은 기존 자산으로
우리 조립기는 모델을 만든다.
비교: 재현 모델 vs E7(같은 재료, 조립만 다름). 상태: **부분 입증** —
B036에서 기존 도구는 빈 모델, 우리는 0.805. 반례 기록: B022는 기존 도구
우세(0.851 vs 0.778) = 우리 추출(S4) 표현 갭. 잔여: 합집합·현재 영상
점군의 재현 칸(매트릭스), 93동에서 "기존 도구 실패 유형"의 빈도.

**주장 2 — "낡은 자산이 정말 필요하다"** (공정 조건 포함)
기존 자산 없이 현재 영상 파생 재료만으로 시작하면(가설·초기값 모두 영상
유래), 영상이 못 본 곳(가림·미관측 지대)에서 모델이 무너진다.
**공정 조건**: 영상-만 팔도 최선을 다해 구성한다(동일 조립기·동일 판정
설정·동일 노력). 비교: 영상-초기값 팔 vs 재현/판정 모델.
상태: **방향 증거 확보(AX-9 재현형, 2026-08-18)** — 영상-단독 재현이
비변화 2동에서 붕괴 방향(0.489/0.414 vs 재현 v3 0.778/0.805; 영상-붕괴
프로파일인 B036이 최악으로 일치). 단 공정 조건(최선 구성의 판정형 팔)은
미충족 — 본시험 남음. **등록 문항 오류 기록**: "3동 모두 v3 미만" 기대는
설계 실수 — 변화 건물(B173)에선 영상이 최신이라 0.524로 stale 재현(0.079)을
이기는 게 응당하며, 이는 주장 2의 반례가 아니라 선택-결합 서사의 근거다.

### 막 2 — 본체: 변화는 방별 판정으로만 다스려진다

**주장 3 — "한 손잡이로는 안 된다"**
영상 수정권을 건물 전체에 한 가지 세기로 주면, 안 변한 곳 보존과 변한 곳
수정을 동시에 만족하는 세기가 존재하지 않는다.
비교: 전역 손잡이 스윕(앵커 w 7단 × 3동 / 평면 3모드 / 자유공간 벌점).
상태: **입증(3중)** — 점유(AX-3 kill), 평면(AX-4), 자유공간(AX-6) 모두
전역으로는 보존↔수정 동시 불가. 이것이 "방별(셀별)"의 실측 근거.

**주장 4 — "방별로 주면 된다"** (기술 관문)
수정권을 방마다 조절(셀별 앵커 신뢰)하면 보존과 수정이 동시에 성립한다.
관문: 비변화 두 동 재현 유지(0.778/0.805 −0.02 이내) ∧ 변한 동 ≥ 0.40.
kill: 비변화 하락(과잉 해제) 또는 변한 동 < 0.30(신호 불충분).
상태: **그래디언트-EMA 래칫 계열 소진(2026-08-18, 등록 조항 발동)** —
신호 3종이 모두 kill. 1차(총합): 과잉 해제(잡음 방아쇠)나 재량 실증(B173
0.338). 2차(깊이 단독): 유지 회복 방향(B036 0.805 완전 회복)이나 재량
사멸(0.134) — 해제 채널과 수정력이 갈리면 문이 열려도 아무도 안 민다.
3차(합동 min): 안전핀 완벽(released 0.2~1.5%)이나 같은 핀이 재량도 잠금
(B173 14셀 해제·5플립, 0.124). **시리즈가 남긴 것**: 재량 존재 증명(0.338)
과 유지 존재 증명(0.805)을 따로따로 — 동시 달성만 실패. 셀 스코프의
그래디언트 신호만으론 변화/잡음 분리가 안 된다는 것이 3중 실측.
다음 기제(새 등록 필요, 문턱 미세조정 금지): **건물 게이트 × 셀 해제 2층
스코프**(부록 주장 A 변화 랭킹으로 건물 단위 재량 스위치 → 켜진 건물만
1차형 광도 해제 — E9 선택-결합과 동형) / 분할 채널 방아쇠 검증 / 뷰 예산.

**주장 5 — "판단이 그냥 섞기보다 낫다"** (연구 관문)
방별 판정 모델이, 판단 없이 두 재료를 합쳐 기존 도구로 만든 모델(E8)보다
낫다 — 특히 변한 건물에서.
과녁: B173에서 E8 = **0.630** (2026-08-17 눈금 확정). 보조 실측: 무판단
결합은 낡은 경사 지붕이 함께 남아 정밀 0.55에 그침 = "그냥 합치면 낡은
것도 남는다"의 수치 증거.
보조 눈금 2 (AX-9): ① 변화 건물의 영상-단독 재현 = **0.524** — 판정
모델은 무판단 결합(0.630)과 영상-단독(0.524)을 모두 넘어야 "결합+판단"의
존재 이유가 선다. ② 합집합을 **초기값**에 넣는 무판단 결합(우리 조립기판)은
0.061로 무익 — 포락면(백분위) 초기화에선 높은 쪽(=낡은 경사)이 이긴다.
E8(0.630)이 사는 이유는 재검출 파이프라인이라 현재 점 다수가 이기기 때문
— 무판단 결합의 성패조차 판독기 의존임이 실측됨.
상태: **과녁만 확정** — 주장 4(기술 관문) 통과 후 판정.

**주장 7 — "정합 오차에 견딘다/추정한다"** (재정식화 예정)
두 데이터의 위치 어긋남(정합 오차)이 있어도 (a) 판정 결과가 오차 범위
내에서 안정하거나(견딤), (b) 오차를 변수로 추정해 회수한다(추정).
기존 증거: 오차 주입-회수 실험(AX-1 부속) — 수직 오차 회수 72%, 수평
오차는 건물 형상 의존 11~56%(평지붕 측방 관측 불가), 1동 발산. 현재
파이프라인은 봉인 체인의 **동결 정합**(사전 검증 통과분)에 의존 중.
상태: **명제 미정식** — (a)/(b) 중 논문 주장으로 세울 것과 허용 오차
범위를 정한 뒤 재실험.

**주장 8 — "현재 외관을 입힌다"**
판정을 통과한 기하 위에 현재 영상의 겉모습(텍스처/외관)을 입힌 산출물을
낸다 — 기존 자산엔 없는 현재성 정보의 두 번째 축.
현황: 광도 학습은 파이프라인에 내장(가우시안 외관, 평가 뷰 PSNR ~14.6
추적)이나 **산출물 계약(형식·품질 기준·채점)이 미정의**.
상태: **공백** — 저널1 프레임("기하 = 측정+판정 통과 prior, GS = 패치
판정함수 + 외관")과의 접속 지점. 계약 정의가 선행 과제.

**부록 주장 A — "재현-실측 차이는 변화 신호다"** (부산물, 승격 검토)
재현 모델과 기준 실측의 점수 차이가 변화 건물을 골라낸다.
실측: 93동에서 판별력 AUC 0.959 (값싼 CPU 계산). 단서: 라벨 계보 일부
공유 — 독립 라벨 검증이 승격 조건.

**완료 조건 (주장 아님)** — 최종 결론은 개발용 눈금이 아니라 **점군화 →
공유 Roofer → 봉인 공식 채점** 경로로 재확인한다(전 조건 동일 판독 원칙).

| AX-3 | 앵커 w 전역 스윕 | 주장 3 | kill — 보존∧재량 동시 불가 | 원인 후보: 평면도 자유변수 |

| AX-5 | 입력 수리(v3: 타워 후보 등) | 주장 1 강화 | B022 재현 신기록 0.778 | 유지 챔피언 = v3 동결 |
| AX-6 | 가림/자유공간 전역 항 | 주장 3 완성 | 미달 — 자유공간은 반-채움 부작용 | "모든 길이 셀별로 수렴" |

| AX-8c | 셀별 3차: 합동 방아쇠 | 주장 4 | kill — 안전핀이 재량도 잠금(B173 0.124); **래칫 계열 소진 선언** | 2층 스코프(건물 게이트×셀 해제) 설계로 |

한 줄 서사: **"재현은 세다(AX-2·5) → 전역 판정은 어떤 변수로도 안 된다
(AX-3·4·6) → 그러면 방별로 — 첫 시도는 방아쇠가 민감해 기각, 그러나 변한
건물을 고치는 능력은 실증(AX-8a) → 남은 것은 방아쇠 정밀화와, 낡은 자산
필요성(주장 2)·정합(주장 7)·외관(주장 8)의 공백 메우기."**
