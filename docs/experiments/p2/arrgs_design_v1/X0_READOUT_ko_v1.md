## 2. 사전 등록 예측 대비 판정

- **P-X0-1 (렌더링 손실만으로 점유 100%)**: 원문대로는 **부분 기각** — box는 4/4 구성
  전부 100%, gable은 임의 초기화에서 0.6~0.7 정체. **단, 실파이프 유사 조건
  (prior-기반 초기화)에서는 100%** (proxyinit). 실패 모드는 특정적: 처마 슬리버
  (경사 지붕과 수평 교란 평면 사이 얇은 쐐기)가 초기값 반대편으로 굳음 — 얇은
  쐐기의 시차 신호가 이진화 압력을 못 이김.
- **P-X0-2 (대칭 초기화 실패)**: 지지 — sym이 main보다 낫기도 한 수준(0.7 vs 0.6)으로
  전 구성이 나쁜 축에 수렴하나, "고정-빈 셀(경계)이 대칭을 깨서 그래디언트는 흐른다"
  는 예상 밖 관찰 확보(콜드스타트가 예측만큼 치명적이지 않음).
- **P-X0-3 (무어닐링 → 미결정 잔존)**: 지지 (미결정 1).

## 3. kill gate 판정

**통과 (조건부·개정 해석).** 검증 대상이었던 유일한 신규 배관 — v_f = |Δo| 가시성
게이트를 통한 렌더링→점유 그래디언트 경로 — 는 작동한다:
게이트 건강 프로브 전 런 ∂L/∂o 비영 ~100%, box 전 구성 완벽, gable도
prior-유사 초기화에서 완벽. **결론: 이 아키텍처는 "prior가 초기 가설을 주고 광도가
검증·정련한다"는 설계 의도 그대로의 조건에서 성립하며, prior 없이 임의 초기화로
얇은 구조를 발견하는 능력은 없다(주장하지도 않았던 능력).** X1~X4는 항상 ALS
초기화를 가지므로 실행 조건은 proxyinit 조건이다.

## 4. 부수 발견 (설계 교훈)

1. **관측 기하 함정**: 저앙각(h11)·중앙각(h18) 링 추가는 일관되게 해로움(0.7→0.6) —
   프리즘-투영 마스크가 경사 시점에서 배경 픽셀을 끌어들여 유령 면을 가르침.
   실데이터에서 같은 기전이 "이웃 건물 픽셀"로 재현됨(X1 판독 참조).
2. **어닐링과 초기화의 상호작용**: 이진화 압력은 "정답 근처 초기값의 유지·정련"에는
   적합하나 "잘못된 쪽으로 초기화된 얇은 셀의 반전"을 막는 쪽으로 작용.
3. 콜드스타트(전부 0.5)는 그래디언트 소실이 아니라 품질 저하로 나타남 — 경계
   고정-빈 셀이 대칭을 깨기 때문.
