# ARRGS 용어·단계·실험 명명 체계 (v1)

- 지위: REFERENCE(어휘 사전) — 이후 ARRGS 트랙의 모든 판독·대화·코드 주석은
  이 용어를 따른다. **트랙의 입구·서사·주장·상태는
  `ARRGS_RESEARCH_LEDGER_ko_v1.md`(연구 원장)가 단일 진실이다.**
- 동기: i2/i3 등 임시 명명, "오라클/동결 백본" 혼용, S3/S4 구분 혼란, 저널 조건
  로스터(E1~E9)와 ablation 실험 번호의 충돌을 정리.

## 1. 파이프라인 단계 — 공식 4단계 (2026-08-16 재번호)

실행 단계가 4개이므로 번호도 4개다. 파일명·봉인 판독의 구 표기는 레거시로
동결하고 매핑만 유지한다.

| 공식 | 명칭(직관/학술) | 의도 | 입력 | 출력 | 레거시 |
|---|---|---|---|---|---|
| **S1** | **평면 가설 생성** (plane hypothesis generation) | 참 표면이 들어 있는 가설 공간 확보 | 봉인 Roofer OBJ(**E7=ALS계 + E8=union계 → MVS 평면 포함**), ALS 크롭, footprint | 후보 평면 목록 | S1 |
| **S2** | **공간 분할·초기화** (arrangement construction & initialization) | 가설로 공간을 구획하고 prior의 부피 가설·외관 출발점을 배치 | S1 후보, footprint, ALS 점군(o_init 전용) | 셀·facet·o_init·시드 | S2 |
| **S3** | **미분 가능 렌더링 최적화** (inverse-rendering MAP optimization) | 영상 증거로 초기값을 심판·수정 | S2 전부 + 영상·포즈·**MVS 깊이 맵**(봉인) | 수렴 파라미터 + 계측 | "S3+4" |
| **S4** | **모델 추출** (cell-selection surface extraction) | 연속 상태를 이산 구조화 모델로 확정 | S3 최종(또는 S2 경화) 파라미터 | 모델(`s5_brep.obj` 동결) + 평면 요약 | "S5" |

**MVS 사용 지점 명시**: MVS는 배제된 것이 아니라 역할이 배정돼 있다 — S1에는
E8(union) Roofer와 MVS RANSAC 평면으로 **가설**로서 들어오고(B022 실측: mvs
평면 8개), S3에는 깊이 맵으로 **증거**로서 들어온다. **o_init만 ALS 전용**인
이유는 판정 의미론의 분리다: 초기값 = "prior의 부피 가설"이어야 "영상(MVS 포함)
증거가 prior를 심판한다"는 실험 구도가 성립한다. o_init에 MVS를 섞으면
심판이 피고와 섞인다.

S3 내부의 *논리적 역할* 구분(증거 채널 형성 vs 점유 결정)은 계측 축으로만
사용하고, 단계 번호로는 더 이상 쓰지 않는다. 구 문서·뷰어 탭의 "S3+4"/"S5"
표기는 각각 S3/S4를 가리킨다.

분류 기준은 **검수 가능한 중간 산출물(게이트 경계)**이다. 기능으로 보면
3분류(초기값 생성 = S1+S2, 최적화 = S3, 후처리 = S4)가 상위에 있고, S1과
S2가 나뉘는 이유는 실패 모드와 게이트가 다르기 때문이다 — S1 게이트 =
설명률·응집(후보가 충분한가), S2 게이트 = o_init·시드 검증(재료를 올바르게
배열했는가). AX-5에서 실제로 두 단계가 따로 수리되었다(타워 측벽 후보 = S1,
다점 라벨링 = S2).

| 변수 | S2에서의 표현(초기값) | S3에서의 표현(조정) |
|---|---|---|
| 평면 (n,d) | 파란 facet 윤곽(평면 자체는 S1 탭) | 우측 표 dn°/dd m (이동 미세 → 수치) |
| 가우시안 | 시드 점(소속 평면 소스색) | 렌더 vs 사진 패널(외관) |
| 점유 o | 복셀: 초기 주황 / 최종 청록 / Δ 수정분 | 면 진하기(게이트 v = 점유의 면-그림자) |

## 2. 용어

| 용어 | 정의 |
|---|---|
| **입력 구성 v#** | S1+S2 재료의 버전. v1=원본(기둥 상면 휴리스틱), v2=상면 top-cluster 수리(무효과, 폐기), v3=타워 측벽 후보+다점 라벨링+상면 수리 |
| **재현 모델** | 처리 없음(학습0): o_init을 0.5에서 경화 → S5 추출. CPU. 구칭 "오라클/동결 백본" |
| **판정 모델** | S3+4 최적화를 허용한 모델. 세부 설정 = 점유 앵커 w, 평면 모드(free/anchor/freeze), 가림 가드, 자유공간 벌점 λ_fs 등 |
| **모델 눈금** | 모델 표면 샘플 vs 참조 점군(E1 cls6) — 산출 계약의 성적표. proxy-f1은 개발용, 공식 수치는 봉인 geometry_eval |
| **점군 눈금** | 점군 vs 점군 — 원료 품질·단계 국소화용. 모델 눈금과 교차 비교 금지 |
| **진단 카운트** | 구멍/유령/플립(o_init 대비), 판정 원장 — GT 아님, 학습 중 감시용 |

핵심 문장: *실험 런 하나 = (입력 구성 v#) × (처리: 재현 또는 판정 설정) → 동일한
S5 모델 → 평가.* 재현과 판정은 같은 재료·같은 출구의 정확한 대조군 쌍이다.

## 3. 실험 명명 — 2층 분리

- **논리 조건 (E1~E9)**: 저널1 로스터(연구 계약 04 문서 소관). ARRGS 문서에서
  임의 확장 금지. 번호는 동결 계보 라벨 — 재부여 대신 역할 열로 읽는다:

| 역할 | 조건 | Stage-3 판독 |
|---|---|---|
| 평가 참조 | E1 (조건 아님 — 참조 승격) | — |
| 제품 기준선 | E2 MVS | 공유 Roofer |
| 대조군 | E7(prior만), E8(판단 없는 결합), E3(prior 없는 재합성) | 공유 Roofer |
| 실험(제안) | E9 선택 결합(판정 함수 = AX 승자 이식 = E9C) | 공유 Roofer |
| 역사적 융합 실험 | E4/E5(불활성 가중 실측), E6(진단) | 공유 Roofer |

  핵심: **E-링의 공식 Stage-3는 전 조건 공유 Roofer**(불변식 8 — 같은 footprint,
  같은 판독기). **ARRGS의 S4는 트랙 내부 판독이지 Roofer가 아니며**(배열 경계
  추출 vs 점군 평면검출+셀 최적화 — 같은 역할, 다른 기계), ARRGS가 E-링에
  공식 입장하려면 기하 점군화 → 공유 Roofer 경유가 계약 경로다. 개발 중의
  모델 눈금(S4 vs roofer.obj 샘플)은 상대 비교용 트랙 내부 눈금으로만 쓴다.
  또한 저널1 원래의 ablation 축(prior 유무: E3 vs E4/E5)에 더해, ARRGS 실측이
  세운 주장 축은 **"prior의 존재가 아니라 처리(판단) 방식이 성능을 가른다"**
  — E8(판단 없음) vs E9C(셀별 판정)가 그 축의 링이고, 처리 방식 내부의
  ablation(w, 초기값 v#, 스코프)은 E-로스터가 아니라 AX 트랙이 담당한다.

- **ARRGS ablation 실험 (AX-#)**: 이 트랙 내부의 의도별 실험 번호.

## 5. E 로스터 개정 초안 (승인 대기 — 계약 04/DEC 개정 사항)

공유 판독을 본 방법의 S4로 통일한 신 로스터(구 E1~E9와 번호 충돌 →
개정 문서에 "로스터 v2 + 구번호 매핑표" 필수; 저널1 계약 수치의 공유 Roofer
프레임은 별도 병존):

| 신 | 역할 | 구성 |
|---|---|---|
| E1 | 평가 참조 | UAS LiDAR 점군 (판독 없음) |
| E2 | 상한 조건 | LiDAR → S4 |
| E3 | 제품 기준선 | MVS → S4 |
| E4 | prior 재현 | ALS → S4 |
| E5 | 무판단 결합 | union → S4 |
| E6 | **제안** | union + v3 + 셀별 판정(S3) → S4 |

**E6 성분 제거표 (기준점: AX-8 산출 — C는 ablation이 아니라 제안 본체)**:

| 제거 성분 | 조건 | 검증 주장 | AX 대응 |
|---|---|---|---|
| 판정(S3) | E5 | 판정이 오염을 막는다 | AX-2/5 ✅ |
| MVS 입력 | E4 | 현재 영상 결합 필요 | **공백**(순수 ALS 팔 미실행) |
| prior | prior-부재(MVS 가설+최적화) | prior 필요 | **공백** |
| 셀별성 | 전역 스칼라 w | 셀별 스코프 필요 | AX-3 ✅ (kill) |
| 초기값 수리 | v1 | 입력 구성 기여 | AX-5 ✅ |
| 가림 처리 | 가드/fs off | 가림 채널 기여 | AX-6 ✅ |
| (부록) 판독 | S4↔Roofer 교차 | 판독기 비의존 | AX-7 ❌ 기각 — 모델 눈금은 트랙 내부 상대 눈금, 공식 입장은 점군화→공유 Roofer |

## 6. 명명 이력 (혼선 기록)

- 런 디렉토리의 `_i2/_i3` 접미사 = 입력 구성 v2/v3 (스윕 러너 작성 시 임시 명명).
