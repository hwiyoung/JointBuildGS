  표현력, 후보 완전성)과 정합.

## 4. 정직한 종합 (X0~X4)

1. **아키텍처 핵심(신규 배관)은 성립**: v_f 게이트 렌더링→점유 그래디언트, 공동
   최적화, 어닐링→경화, watertight B-rep 직렬화 — 합성에서 prior-유사 초기화 조건
   100% (X0).
2. **실데이터 v1 구현은 제품 품질 미달**: f1 0.38 vs 0.95. 원인은 개념이 아니라
   장면 조립 층(X1 사다리로 분해·정량화, 각 수정의 기여 실측).
3. **δ 트랙의 실질 수확은 관측가능성 구조**(X3): 평면 δ̂도 측방 성분에 원리적
   전맹 — 프로그램의 기존 결론(게이트·C2C 전맹)의 세 번째 독립 확인이며 δ-보정
   설계의 제약 조건.
4. **자연 stale-ALS 시험대는 이 데이터셋에 없음**(X2) — D-2(ALS 한정)의 귀결.
   중재 주장 검증은 δ-주입 통제 실험 또는 독립 LoD 소스 확보 이후에만 가능.
5. 위 1·2의 간극이 다음 단계를 정의: v2 = 가림-인지 마스크(정확한 판별),
   footprint 충실도(국소화된 벽 평면), 후보 생멸, 배열 재구축 루프 — 또는
   E9C(판정-주도 결합) 트랙과의 접속 재설계. 우선순위 판단은 리뷰어 소관.
