## 0. 한 줄 요약

prior 주입과 구조 결정을 **픽셀·임계값 수준에서 평면·점유 수준으로 승급**한다:
건물별 평면 배열(칼)과 셀 점유(채움)를 가우시안 렌더링 손실로 공동최적화하고,
수렴 후 점유 경계면을 읽어 watertight 의미론 B-rep(→CityGML/textured mesh)과
평면별 증거 귀속(이미지 지지/prior 의존/충돌)을 **한 표현에서** 산출한다.

## 1. 배경 — 프로그램 내부 증거가 가리키는 자리

본 트랙은 신규 아이디어가 아니라 기존 실측 3건의 수렴점이다.

1. **픽셀 수준 prior의 불활성 딜레마** (D2a 정정): 봉인 레시피의 prior 유효 가중
   ≈0.002(photo의 0.2%) — 세게 쓰면 오염 위험, 약하게 쓰면 무의미. v3(TIN 0.25m)의
   E5=29 > E3=23 (net +6)이 이 계열의 실질 상한 부근으로 판단되며, 기하 레벨에서는
   GS 융합 0.895 < E2 0.936 < E8 0.952 (확정 93 e1-f1)로 학습-0 union에도 열세.
2. **union의 비가시 오염** (D1): δ=1에서 z-spread 86/93동 상승(+0.024***),
   채움-의존층 이득 54% 잠식 — 그러나 봉인 게이트·C2C 모두 fine-δ 전맹.
3. **기하 신호의 원리적 경계면** (E9): 채움 이득과 오염 강건을 기하 신호만으로 동시
   확보 불가 — 모호성이 수직-분리 클래스(겹침의 43%)에 응집, 3D-대-3D 비교가
   정의상 불가능한 자리. 판정은 렌더-영상 대조(미분 가능 렌더링)만 가능.

구조적 해석: 현재 구조에서 결정(구조 확정)은 Roofer의 평면·임계값 수준에서 일어나는데
prior는 픽셀 수준에서 주입되어, prior가 결정을 도울 수 없다. 따라서 **주입과 결정을
같은 수준(평면·셀)에 올리고, 그 수준을 미분 가능하게** 만든다.

### 1.1 단계 구조 선언 (방법 분류의 정직한 진술)

| 단계 | 성격 | 경쟁 가설 간 "결정"이 있나 |
|---|---|---|
| S1 후보 생성 | 결정론적 전처리 | 없음 — 과잉완전 후보, 버리는 것 없음 |
| S2 배열·부착 | 초기화/구성 | 없음 |
| **S3+S4 공동최적화** | **유일한 결정 지점** | 있음 — 전부 여기 |
| S5 직렬화 | 결정론적 후처리 | 없음 — 어닐링 수렴값의 반올림+포맷 기록 |

주장 형태: "end-to-end"가 아니라 *"결정을 내리는 단계는 공동최적화 하나이며,
전·후처리는 대안 가설 간 선택이 없는 결정론적 변환"*.

## 2. 방법 정의

### 2.1 5단계 파이프

- **S1 후보 평면 생성** (건물당 J≈10~40):
  - prior: **정합 Existing ALS에서 평면 검출**(RANSAC/region growing, E4/E5 계보의
    registered ALS 바이트 재사용) → (nⱼ⁰, dⱼ⁰) + 검출 지지점수.
  - 현재 증거: 공통 베이스 MVS depth/normal의 노멀 클러스터 평면.
  - footprint: 각 XY 변의 수직 압출 = 벽 평면, footprint 고도 = 지면 평면.
  - **금지**: 기존 LoD2 면을 입력 후보로 사용하는 것. 본 프로그램에서 LoD2는 평가
    참조(GT, D-F 규칙)이므로 입력 사용은 E6형 순환(REFERENCE_DERIVED) — 평가 전용
    유지(불변식 9 계승). §7 D-2 참조.
- **S2 배열 구축 + 가우시안 부착**: footprint 프리즘을 J개 평면으로 절단 → 셀
  {k=1..K}(예상 K≈30~300). 각 평면 위 면(face) 후보에 2D 가우시안 시딩(평면 프레임
  좌표 uᵢ로 파라미터화 — 3D 위치는 평면 파라미터의 유도량). 점유 초기화: ALS-유래
  솔리드 내부 셀 0.8 / 외부 0.2 (전부 0.5 금지 — v_f=0 대칭점에서 그래디언트 소실).
- **S3+S4 공동최적화** (단일 Adam 루프, 기존 신형 E3 레시피 골격):
  변수 = 평면(nⱼ, dⱼ) + 점유(oₖ) + 가우시안(uᵢ, sᵢ, cᵢ, αᵢ) + 정합 δ(공유 3-벡터
  또는 z+xy 분해). 어닐링: λ_b 스케줄 상승.
- **S5 직렬화**: oₖ 반올림 → 경계면 {f : |o_{k₁}−o_{k₂}|=1} 열거 = watertight
  다면체 → 중력 대비 자세로 Roof/Wall/Ground 분류(중력은 기존 지형 MVS 노멀 추정치
  재사용, 하드코딩 금지) → CityGML LoD2 직렬화 + 면별 텍스처 베이크 + 증거 카드.

### 2.2 기호 사전

| 기호 | 종류 | 의미 |
|---|---|---|
| nⱼ, dⱼ | 변수 | 평면 j 법선(단위)·오프셋. 평면 = {x : nⱼ·x = dⱼ} |
| nⱼ⁰, dⱼ⁰ | 상수 | prior(ALS 검출) 평면 자세 |
| δ | 변수 | prior 전체의 정합 이동(명시 변수 — Phase D δ-shift의 승급) |
| wⱼ | 변수/스케줄 | 평면별 prior 신뢰 가중(E5 currentness 자리) |
| oₖ ∈ [0,1] | 변수 | 셀 k의 점유(솔리드=1/공기=0에 대한 잠정 믿음) |
| f, k₁(f), k₂(f) | 유도량 | 면 f와 그 양쪽 셀 |
| v_f = \|o_{k₁}−o_{k₂}\| | 유도량 | 면 가시성 게이트 |
| uᵢ, sᵢ, cᵢ, αᵢ | 변수 | 가우시안 i의 평면 내 2D 위치·크기·색·불투명도 |
| xᵢ | 유도량 | 가우시안 3D 위치 = 평면 j(i) 프레임 전개 — ∂xᵢ/∂(nⱼ,dⱼ) ≠ 0 |
| Ĉ(p), C(p) | 유도량/상수 | 렌더 색 / 관측 색 |

### 2.3 손실

```
L = L_photo + λ_d·L_depth + λ_n·L_normal        (기존 3채널 계승)
  + λ_p·Σⱼ wⱼ·[ ρ(∠(nⱼ, nⱼ⁰)) + ρ(dⱼ − dⱼ⁰ − nⱼ⁰·δ) ]   (평면 수준 prior)
  + λ_b·Σₖ oₖ(1−oₖ)                              (이진화 압력, 어닐링)
렌더: Ĉ(p) = Σᵢ Tᵢ · [αᵢ · Gᵢ(p) · v_f(i)] · cᵢ
```

ρ = Huber. L_depth/L_normal 타깃 = 기존 fused depth/normal(신형 E3 레시피와 동일
바이트). prior가 없는 평면(MVS/footprint 유래)은 λ_p 항 제외.

### 2.4 구현 노트

- **게이트 구현은 래스터라이저 무포크**: v_f(i)는 가우시안별 스칼라이므로, gsplat
  호출 전에 PyTorch에서 불투명도 텐서에 곱한다(autograd가 o까지 전파). CUDA 커널
  수정 불필요 — 불변식 6(gsplat 사용) 유지.
- **배열 토폴로지 갱신 정책**: 토폴로지(셀 인접 구조)는 S2에서 고정하되, 면 꼭짓점은
  평면 파라미터의 미분 가능 함수(3-평면 교점)로 추종. 평면 이동량이 문턱(예: 0.3 m
  또는 5°) 초과 시 배열 재구축 + 점유를 포함 관계로 이월. 재구축 이벤트는 receipt에
  기록(재현성).
- **평면 소멸은 자동**(면 전부 v≈0), **평면 생성(신규 구조)은 v1 범위 외** —
  후보 과잉완전성으로 완화, v2에서 PlanarSplatting식 분열/병합 검토.
- 하네스 교훈 계승: gsplat JIT 웜캐시 이식(TASK_ROOT/cache/torch_extensions),
  full-state 체크포인트 유지, 컨테이너 산출물 chown(ensure_task_owner).
- 실행은 Docker(`jointbuildgs:dev`), 스크립트+config+receipt 필수(불변식 1·2).
  코드 네임스페이스(승인 시): `scripts/p2/arrgs_v1/`, `configs/p2/arrgs_v1/`,
  `tests/p2/test_arrgs_*.py`. 페이로드: artifacts
  `phase-payloads/p2/arrgs_v1/<TASK_ID>/`.

## 5. 실험 카드 X0–X4

공통 규칙 (사용자 요구 반영):
- **각 실험은 5단계 산출물 전부를 뷰어에 표출한다** (X0 합성 포함).
- **각 실험은 판독 문서** `X{n}_READOUT_ko_v1.md` **로 마감한다** — 필수 섹션:
  ① 정량 표(§6 지표, 기준선 병기) ② 정성 패널(뷰어 딥링크 + 캡처) ③ 분석
  (사전 등록 예측 대비 적중/기각, 원인 해석) ④ 이슈·한계 ⑤ 다음 단계 권고.
  분석 없는 수치 나열 금지.
- 사전 등록 예측을 실행 **전에** 본 문서(각 카드)에 고정한다. 판독 시 수정 금지.

### X0 — 배관 검증 (합성, GPU 소규모)

- **목적**: 유일한 미검증 부품 = v_f 게이트를 통한 렌더링→점유 그래디언트 경로의
  단독 검증. 실데이터 진입 전 kill 판정.
- **입력**: 합성 장면 2개 — (a) 박스(평면 6), (b) 박공(평면 7 + 교란 후보 3:
  가짜 수평면 1·오프셋 지붕면 2). 정답 메시에서 링 배치 16~24뷰 렌더(텍스처 부여).
  카메라·조명 고정, 시드 고정.
- **절차**: S1은 정답 평면+교란 후보를 수동 주입(생성 로직 검증 아님) → S2~S5.
  절제 2종: 어닐링 유무 / 점유 초기화(정답 근처 vs 반전 vs 0.5 대칭).
- **사전 등록 예측**:
  - P-X0-1: 렌더링 손실만으로(depth/normal 감독 없이) 최종 점유 정확도 100%
    (전 셀 정라운딩), 교란 평면의 전 면 v < 0.05.
  - P-X0-2: 0.5 대칭 초기화는 그래디언트 소실로 수렴 실패 — 초기화 비대칭 필요성 실증.
  - P-X0-3: 어닐링 제거 시 o가 중간값 정체(0.3~0.7 잔류 셀 ≥1개).
- **성공/kill**: P-X0-1 실패(정체·진동) 시 **본 트랙 정지** → 등록된 폴백 2안 평가:
  (i) 워밍업 동안 depth 감독으로 o 보조 후 이탈, (ii) o만 주기적 그래프컷으로 푸는
  하이브리드(요령3 혼합). 폴백도 실패 시 트랙 종료 보고.
- **정량**: 점유 정확도, 면 v 분포, 평면 자세 회복 오차(°, cm), 수렴 스텝 수.
- **정성**: S3+4 타임라인에서 셀이 차오르는 과정, 교란 평면이 투명해지는 과정.

### X1 — 정상 1동 sanity (실데이터 최초)

- **목적**: 실데이터에서 5단계 전체 파이프 관통 + 품질 1차 확인.
- **건물 선정 절차**(D-4에서 확정): B티어 비변화 19동 ∩ 게이트 통과 ∩ E2
  comp@0.25 ≥ 0.9 ∩ 단순 지붕(LoD2 RoofSurface ≤ 4) 중 1동. 뷰 선별: 937뷰
  풀신 포즈에서 건물 가시 뷰 추출(1회성 스크립트, 코리도 55뷰 패턴 준용).
- **사전 등록 예측**:
  - P-X1-1: e1-GT f1@0.5 ≥ 같은 건물의 E8 행, z-spread ≤ GS융합 행(단일 표면).
  - P-X1-2: 사용 평면 수(면이 살아남은 평면)가 LoD2 면 수의 ±2 이내.
  - P-X1-3: 내부 절단면 전부 v < 0.05 (자동 소멸 확인).
- **성공/kill**: P-X1-1 두 항 모두 실패 시 X2 진입 보류, 원인 분해(게이트/배열/
  후보 부족) 후 1회 재시도 — 재실패 시 리뷰어 판단.
- **정량**: §6 전체 + 같은 건물 E2/E8/E9/GS융합 행 병기. **정성**: S5 증거 착색
  (비변화 건물이므로 prior 의존도가 낮고 이미지 지지도가 높아야 정상), LoD2
  참조 오버레이 육안 대조.

### X2 — 프로파일 3동 (존재 이유 검증)

- **대상**: ① 변화 건물 **4959326(B173)** — 현재 평지붕 vs LoD2 경사(양센서 dz −3.7
  일치, LoD2 GT 무효 판정 이력) ② 구멍 건물 **4906982(B036)** — MVS/분류 붕괴,
  코리도 55뷰 하네스 보유 ③ X1의 정상 동(대조).
- **사전 등록 예측**:
  - P-X2-1 (변화): ALS-유래 경사 지붕 평면이 **기각**된다 — 해당 상부 셀 점유가
    사진에 눌려 0으로, 최종 모델은 평지붕. 기각된 평면의 충돌량이 증거 카드에
    상위 기록(= 변화 탐지가 부산물로 나옴).
  - P-X2-2 (구멍): 이미지 증거 공백 구역이 prior 평면으로 채워지되, 해당 면의
    이미지 지지도가 낮게 기록된다(재현임이 표시 — 불변식 12 temporal status가
    모델 출력으로 구현됨). completeness는 E2 행 대비 회복, E8 행과 동급.
  - P-X2-3 (대조): X1 결과 재현(회귀 없음).
- **성공/kill**: P-X2-1 실패(prior가 사진을 이기고 낡은 지붕 생성) 시 λ_p/wⱼ
  스케줄 문제로 분류, 1회 재캘리브레이션. 재실패 = "평면 수준도 충돌 중재 불가"
  → 트랙 주장 축소(채움 전용) 보고.
- **정량**: §6 + 변화 건물은 E1-GT 주(D-F 층화 규칙 준수). **정성**: ①의
  S3+4 타임라인(경사면 셀이 비워지는 과정 = 논문 그림 후보), ②의 증거 히트맵.

### X3 — δ 강건성 (union이 진 그 시험)

- **대상**: X2의 3동 × δ_xy ∈ {0.25, 0.5, 1.0 m} 동쪽 평행이동(D1과 동일 주입
  프로토콜) + δ_z 0.25 스팟. prior 평면(nⱼ⁰, dⱼ⁰)과 점유 초기화 솔리드에 주입.
- **사전 등록 예측**:
  - P-X3-1: 명시 변수 δ가 주입량을 흡수 — **|δ̂ − δ_주입| < 0.1 m** (통제 정답
    있는 검증; 기존 δ-보정 데모 계획과 접속).
  - P-X3-2: z-spread δ-플랫(D1의 union: 86/93동 상승과 대조), completeness 유지
    (E9v1의 "플랫하지만 이득 축소"와 달리 이득 보존 — 채움이 δ 보정 후 재사용되므로).
  - P-X3-3: 픽셀 GS의 불활성(D2a: 흡수도 오염도 없음)과 달리, ARRGS는 δ̂ 보고
    자체가 산출물 — "무영향이라 무해"가 아니라 "추정했으므로 무해"로 구분 가능.
- **성공/kill**: P-X3-1 실패 시 δ 파라미터화(공유 vs 평면군별) 재설계 1회.
  P-X3-2 실패(z-spread 상승) 시 H-M2형 주장 포기, 진단 결과로 보고.
- **정량**: δ-커브(z-spread/comp@0.25/f1/acc × δ) + D1 union 커브 오버레이 +
  δ̂ 표. **정성**: [비교] 탭 스몰멀티플, δ=1 렌더-사진 대조 타임라인.

### X4 — 확정 93 (통계, X0~X3 전부 통과 시에만)

- **모집단**: `labels/selection_confirm_v1.json` 동결 93동(전 조건 동일 마스크).
- **판독**: geometry_eval 9지표 × 2GT 페어드(vs E2/E8/GS융합), 3층 표준 보고 컷
  (전체 93 / 채움-의존(E2 comp@0.25<0.9) / 현재-지배), auto-OX(v22 O50 noG2,
  NOT_OFFICIAL) 전이표, 변화군은 E1-GT 주.
- **사전 등록 예측** (X1~X3 결과로 실행 전 수치 갱신 가능하나 방향은 고정):
  - P-X4-1: 페어드 f1(e1) ARRGS ≥ E8, z-spread ≤ GS융합, Roofer 대체 판독으로
    기술유효 건수 ≥ E8의 79.
  - P-X4-2: 증거 카드의 이미지 지지도가 실제 커버리지 진단(coverage_diag)과 상관
    (r > 0.6) — 증거 레이어의 외적 타당성.
- **주의**: 비확정적(non-confirmatory) 기술 개발 판독 유지 — 공식 G3/G4·PASS_usable·
  모집단 일반화 주장 금지(기존 계약 계승). GPU 예산 별도 승인(D-6).

## 8. 재현성·실행 환경

- Docker `jointbuildgs:dev`, `docker run --network none` 패턴(compose 네트워크 풀
  이슈 회피), artifacts 마운트 `-v <artifacts>:/artifacts/JointBuildGS`.
- 각 런 = 스크립트+config+receipt, 입력 SHA-256, 커밋 해시, 스냅샷 스케줄 기록.
- 테스트: 배열 구축(합성 평면→셀 수·인접 검증), v_f 게이트(수치 그래디언트 대조),
  S5 직렬화(watertight 검사, 의미 분류), 뷰어 빌더(manifest 스키마).
- 커밋은 태스크 단위 승인 후(1태스크 1커밋), 본 문서 포함 전량 미커밋 상태로 시작.

## 9. 문헌 지형 (부품별 선례 — 조합이 빈칸)

| 부품 | 선례 | 본 설계와의 차이 |
|---|---|---|
| 평면에 그래디언트 집약 | PlanarSplatting (CVPR 2025) | 배열/점유/토폴로지·prior·의미 없음 |
| 셀 점유의 연속 완화·경화 | BSP-Net/CVXNet (CVPR 2020), DefTet (NeurIPS 2020) | 훈련 데이터 기반 or 비렌더링 감독; 우리는 장면별+렌더링 |
| 배열 셀 점유 (건물) | Points2Poly (2022), PolyGNN (ISPRS 2024) | feedforward/GT 감독, 렌더링·prior 없음 |
| 안/밖 라벨→표면 추출 | Marching Cubes, Labatut+ (ICCV 2007), KSR (TOG 2020) | 표준 기법 — 우리는 라벨을 연속 변수화 |
| 다면체의 미분 최적화 | Diff. Convex Polyhedra (ECCV 2024) | 볼록체 한정, prior·의미 없음 |
| prior→GS 주입 | GS4Buildings (ISPRS 2025), GeoGS (2026), DN-Splatter | 픽셀/가우시안 수준, 구조화 산출 없음 — E4/E5의 외부 대응물 |
| 가우시안-표면 결속 | SuGaR (CVPR 2024), 2DGS/PGSR | 결속 대상이 비구조 메시/자유 평면 |

신규 배관은 단 하나: **v_f = |Δo| 가시성 게이트로 점유를 렌더링 손실에 물리는 연결**
— X0이 이것만을 단독 검증한다.
