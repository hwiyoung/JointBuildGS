## 1. 왜 이것부터인가

정정 `ARRGS_ERRATA_ko_v1.md` E-1/E-2가 다음을 실측했다.

- B173(변화 건물)에서 무판단 결합 E8은 낡은 경사 지붕을 **기하적으로 제거**했다
  (지붕면적 중 낡은 상부 44.7% → **3.5%**, 현재 평지붕 23.1% → **61.5%**).
- 그 기제는 점 밀도 다수결이다 — 현재 영상 기여분이 기존자산의 **8.3배**
  (334,198 vs 40,127점), 합집합의 지붕 z 중앙값 26.31 m = 현재 평지붕.

즉 **현재 영상이 충분한 곳에서는 단순 결합 + 재검출이 이미 변화를 해결한다.**
그러면 본 트랙의 대상은 밀도 다수결이 실패하는 자리 — **"변화 ∧ 영상 불충분"** —
이며, **그 층의 크기가 측정된 적이 없다.**

이 숫자가 없으면 β의 모든 아키텍처 논의(L_area · L_normal · 셀별 판정 · 초기값
집계 규칙)가 대상 없는 설계가 된다. 그래서 대기열 1순위다.

## 2. 측정 설계

### 2.1 모집단

`labels/selection_confirm_v1.json` 동결 93동. 티어 라벨은
`P2-JOURNAL1-PHASE-A-v1/labels/change_label_candidates_v1.csv`(199동, 93은 부분집합).

### 2.2 두 축

**축 1 — 변화 여부** (동결 티어 라벨 사용)

| 값 | 티어 |
|---|---|
| 변화 | `A_STRONG_MISMATCH`, `B_MODERATE_MISMATCH` |
| 비변화 | `C_CONSISTENT` |
| 판정불능 | `NA_E1_INSUFFICIENT` — 별도 층으로 보고, 합산하지 않음 |

**축 2 — 현재 영상 충분성** (기존 봉인 지표 재사용)

주 기준: `evaluation/rows.csv`의 **E2, gt=e1, `completeness@0.25`**.
- **불충분** = `< 0.9` (원장 3층 보고 컷의 "채움-의존" 정의와 동일 — 신규 문턱을
  만들지 않는다)
- **충분** = `≥ 0.9`

보조 기준(층 성격 기술용, 판정에 미사용):
- MVS 지붕점 밀도 = `(E8 크롭 cls6 점수 − E7 크롭 cls6 점수) / footprint 면적`
  [pts/m²]
- `rows.csv`의 E2 `coverage` 열

### 2.3 산출

1. **주 표**: 93동 2×2 교차표 (변화/비변화 × 불충분/충분) + NA 층 별도 행.
2. 각 칸의 건물 목록(stable_id)과 보조 지표 분포(중앙값·사분위).
3. **부수 측정 A(α-1 담당)**: 93동 각각의 `E7/*.roofer.obj`, `E8/*.roofer.obj`가
   빈 모델(정점 0 또는 면 0) 또는 퇴화(지붕면적 < footprint의 0.2배)인 건수.
   → "기존 도구 실패 유형"의 모집단 빈도(원장 v2 α-1의 잔여 항목).
4. **부수 측정 B**: "변화 ∧ 불충분" 칸과 부수 측정 A 칸의 중첩.

### 2.4 계보 주의 (필수 기록)

축 1의 티어 라벨은 **E1 및 LoD2 파생**이다(`change_label_candidates_v1.csv`의
`e1_lod2_*` 열). 두 참조 모두 불변식 9의 평가 전용 GT다.

- **본 측정에서의 사용은 허용된다** — 이는 모집단 성격의 *분석*이지 방법의
  입력이 아니다.
- **금지**: 여기서 나온 층 라벨을 이후 방법의 스위치(건물 게이트 등)로
  전용하는 것. 그 경우 정정 E-4와 동일한 REFERENCE_DERIVED 순환이 성립한다.
  방법에 쓸 변화 신호는 E-4가 제시한 GT 무접촉 대체안으로 별도 구성한다.

## 3. 사전 등록 판정선

`N` = "변화(A∪B) ∧ 영상 불충분(E2 comp@0.25 < 0.9)" 칸의 건물 수.

| N | 판정 | 후속 |
|---|---|---|
| **≥ 10** | **β 변화 축 존치** | 이 층이 새 시험대. B022/B036/B173 3동 시험대는 대표성 없음으로 은퇴(계보 라벨은 동결 유지). 대기열 3~5 진행 |
| **3 ≤ N ≤ 9** | **사례 연구 규모로 축소** | 변화 축은 사례 보고로만 유지하고, β의 주 축을 **β-7(정합)**로 이동 |
| **≤ 2** | **β 변화 축 폐기** | β는 β-7(정합) 전용. 변화는 필요성(motivation)과 부정 결과 보고에만 남김 |

**보조 등록**
- P-AX10-1 (예측): "변화 ∧ 충분" 칸에서는 E8이 ARRGS 재현을 우세할 것이다
  (E-1/E-2의 밀도 다수결 기제가 모집단에서도 작동). 검정: 해당 칸의
  paired f1@0.5 (gt=e1) E8 vs ARRGS_ORACLE.
- P-AX10-2 (예측): "비변화 ∧ 불충분" 칸에서는 ARRGS 재현이 E8을 우세할 것이다
  (B036 프로파일의 모집단 일반화 — α-1).
- 두 예측이 모두 맞으면 **"밀도가 되는 곳 / 안 되는 곳"의 분할이 모집단 수준에서
  확인**되며, 그 자체가 α/β 경계의 실측 근거가 된다.
- 두 예측 중 하나라도 어긋나면 그 칸을 별도 진단 대상으로 등록한다.

## 6. 이 측정이 답하지 않는 것

- "그 층에서 우리 방법이 이기는가" — 답하지 않는다. 대상의 **존재와 크기**만
  측정한다.
- "변화를 어떻게 탐지할 것인가" — 답하지 않는다. 여기서는 동결 GT 라벨을
  분석용으로 쓸 뿐이며, 방법용 탐지기는 별도 사전 등록 사항이다(E-4).
