## 2. 판정선 대비 결과

- **개정 규칙(2026-08-22) 적용**: N은 실데이터 주장의 스코프를 정한다.
  N=12~22는 "소수~중간" — **실전 판독(서사 ⑨ 실데이터 층화)은 층화 사례
  시리즈 + 얇은 ROC(사전 등록판 22동 기준)로 가능**하고, 완전형 ROC 주장은
  제2 장면으로 이월. 기제 증명(판정·보정)은 통제 주입으로 N 무관 진행.
- 참고: 종전(대체된) 판정선으로도 두 판 모두 N≥10 → "β 변화 축 존치"였음 —
  개정이 결론을 뒤집지 않음.
- **해석 가드레일**: N은 축 폐기 판단이 아니다. 12동은 "prior가 필요한 자리
  (영상 불충분)에서 변화 판정이 실제로 걸리는 실데이터 사례"의 스코프다.
