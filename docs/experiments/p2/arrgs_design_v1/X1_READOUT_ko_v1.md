## 2. 원인 분해 (측정 근거 첨부)

1. **o_init 배선 버그** (v2→v3, +0.05 f1): `load_real_scene`이 컬럼 초기화 함수를
   반환 딕셔너리에 누락 → 휴리스틱(전 셀 0.7)이 실행됨. 높이 밴드 추적으로 적발
   (z45-50 init=0.60 → 수정 후 0.15).
2. **유령 상부 질량**: 수정된 초기화에서도 z40-50 셀 13/22가 광도에 의해 solid로
   복귀 — 연접 시가지에서 프리즘-투영 마스크 내부에 이웃 건물 파사드 픽셀이 들어와
   유령 솔리드를 가르침(X0 부수 발견 1의 실데이터 재현). fused depth 채널이 이를
   부분 상쇄(acc 2.15→1.76)하나 제거하지 못함.
3. **footprint 표현력** (v6, +0.06 f1, acc −0.5): 159버텍스 U자 외곽을 14변으로
   뭉개 개방부를 유령 지붕으로 충전. 24변 확대가 최대 단일 개선. 지붕면 단독
   분해(클래스별 최근접): roof p50 1.44 m — 벽 샘플링 아티팩트가 아니라 지붕
   자체가 오프(개방부 충전 성분).
4. **occluder 마스크 퇴행** (v5): MVS 파사드 잡음이 건물 자체 픽셀도 깎음 —
   opt-in으로 강등, 후속 진단 대상.
