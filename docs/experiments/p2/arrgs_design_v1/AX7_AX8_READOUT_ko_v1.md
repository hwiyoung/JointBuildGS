## 1. AX-7 모델 챔피언전 (S0′) — 완료

E7/E8의 봉인 공유-Roofer 모델(`journal1_phase_a a2/assets_roofer_input`)을
ARRGS 모델 눈금으로 채점. 공정 어댑터(기록): roofer.obj는 g-그룹이 없어
기하 재분류 — 수평(|nz|>0.95)·기저고도(≤E1 지면 p99+0.5 m) 면 = 바닥판 제외

무보정(전면 지붕 취급) 수치는 민감도 행으로 병기.

### 판독

1. **판독기(추출기)는 강한 변수다.** 같은 ALS 재료에서 공유 Roofer와 ARRGS
   S1+S2+S4가 −0.80~+0.25까지 갈라진다. 모델 눈금은 추출기 표현 차이(벽·크롭
   피복·기저면 처리)를 섞으므로 **트랙 내부 상대 눈금**으로만 유효 — E-링
   공식 입장은 점군화→공유 Roofer 경로라는 계약을 재확인.
2. **B036에서 공유 Roofer가 ALS 단독으로 빈 모델**(v=0, f=0; 입력 점군 커버리지
   0.18이 단서, 원인 로그 후속). 같은 재료에서 ARRGS 재현은 0.805 —
   "Roofer가 실패하는 재료에서도 배열 재현은 성립"이 실측됨(트랙 존재 이유).
   단 B022에선 반대로 Roofer가 +0.07(0.851 vs 0.778): ARRGS S4/S2 표현
   품질에 아직 갭. 남은 항목: B022 갭 성분 분해(벽 표현 vs 셀 구획).
3. **B173 스토리 완성**: stale prior도 Roofer로 읽으면 0.33(벽·불변부 일치),
   무판단 결합 E8은 0.63, ARRGS stale 재현은 0.08. 판정 모델이 넘어야 할
   자연 하한이 눈금 위에 놓임.

## 2. AX-8 셀별 감쇠 C — 설계·사전 등록 (실행 중)

### 설계

- 골격: 유지 챔피언 구성(v3 입력 + w_occ=5 + 평면 freeze)을 기본으로,
  `occ_w`(셀별 앵커 신뢰, `arrgs_model` 후크)를 학습 중 갱신.
- 신호: flip_ledger의 해석적 분해 재사용 — `g_render`(광도+깊이 증거 총합)의
  **반앵커 성분** s = g_render·sign(o_init−½) (>0 = 증거가 초기값을 반박).
  활성 셀 평균 |g_render|로 정규화, diag 주기(25 iter) EMA(0.9, 지평 ~250 iter).
- 해제: 래칫(감소 전용) occ_w ← min(occ_w, exp(−β·max(0, EMA−1))), β=2 —
  지속 모순 셀만 앵커가 풀리고, 외관 잡음의 재조임 진동은 구조적으로 배제.
  갱신 창 = anneal warm~full(증거 유효 구간), 이후 동결.
- 계측: diagnostics.jsonl `cellw`(released 수·min·mean), 종료 시
  `cellw_ledger.json`(occ_w<0.9 셀: 셀 id·occ_w·EMA·o_init·o_final),
  metrics `cellw` 블록. 등록 상수 = β2 / 문턱1 / EMA0.9 (컨트롤러 v1).

| kill (b) | B173 < 0.30 (전역 w0 수준) → 신호 불충분, fs-귀속/분할 채널로 재설계 |

  **v2 후보(다음 사전 등록 대상)**: ① 해제 신호를 깊이-유효 픽셀 귀속으로

  판정 근거가 광도 단독이면 해제 금지—가 세 후보의 공통 문장.

|---|---|---|---|---|---|

| B036 | 0.714 | **0.805** | ✅ 완전 회복 | 0.065 | 3/1 |

- B022 잔여 −0.01: 깊이-주도 해제 셀 40개가 상시 깊이 항에 밀려 꺼짐

### 2c. AX-8c 합동 방아쇠(3차) — 사전 등록·실행 중

1차·2차의 상보적 실패가 설계를 지정한다: **광도가 방아쇠(수정력과 정렬),
깊이가 안전핀** — 두 정규화 채널의 최소값 min(광도, 깊이)이 지속 모순일
때만 해제. 등록(anchor_sweep `cellw3` 주석 동일): 기대 = 유지 회복(양 동
게이트+released<0.05) ∧ B173 ≥ 0.40 (정렬된 해제+수정력이 1차 0.338 초과);
kill = 유지 하락 또는 B173 < 0.338 → **그래디언트-EMA 래칫 계열 소진 선언**,
문턱 미세조정이 아니라 분할 채널/뷰 예산 대안으로 전환.

**결과 (2026-08-18) — kill, 소진 조항 발동**: B022 0.746(❌ −0.012) /
B036 0.805(✅) / B173 0.124(❌). 안전핀은 설계대로 작동(released_frac
0.002~0.015, B036 플립 1개)했으나 **같은 핀이 재량도 잠금**: B173에서
광도·깊이 EMA가 같은 셀에서 동시에 문턱을 넘는 일이 드묾(해제 14셀,
플립 5). **시리즈 종합(신호 3종 = 총합/깊이/합동 모두 kill)**: 재량의 존재
증명(1차 0.338)과 유지의 존재 증명(2·3차 0.75~0.805)을 각각 얻었으나 동시
달성은 실패 — 셀 스코프의 그래디언트 신호만으로는 변화/잡음이 분리되지
않는다. 다음 기제 후보(백로그, 새 사전 등록 필요): ① **건물 게이트 × 셀
해제의 2층 스코프**(부록 주장 A의 변화 랭킹 AUC 0.959로 건물 단위 재량
스위치를 켜고, 켜진 건물에만 1차형 광도 해제 — E9 선택-결합과 동형)
② 분할 채널(봉인 Stage-1 분할 마스크로 방아쇠 검증) ③ 뷰 예산 증설.
