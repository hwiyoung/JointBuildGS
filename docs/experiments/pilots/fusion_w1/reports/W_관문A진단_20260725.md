## T6. 관문 A v2 문안 초안 — 비채택·미적용

현재 관문은 `BLOCKED` 상태를 유지한다. 아래는 김휘영 검수용 설계 문안으로, 현 관문의 판정값이나 통과 기록이 아니며 승인 전에는 transform·pose·학습에 아무 영향도 주지 않는다. 숫자 0.3 m는 유지하지만, 원 view-edge 잔차와 이번 3D point-to-plane 잔차는 관측량이 다르므로 정식 문안에서 둘을 동일시하지 않는다.

> **관문 A v2 비채택 초안.** 승인 시 사용할 숫자는 `동별 잔차 중앙 ≤ 0.3 m`로 둔다. 측정 모집단은 보정 전 대응수 `n=min(사진→ALS matched 수, ALS→사진 matched 수)`가 전 178동 분포에서 사전에 잠근 `max(40, nearest-rank Q10)=40` 이상인 대응 가능 동으로 정의하고, 대응 불가 동 수와 층은 별도 보고한다. 한 좌표계의 사진 프레임과 고정 ALS 프레임 사이 오차는 하나의 강체 좌표계 오차라는 전제에 따라, 별도 승인된 하나의 전역 SE(3)만 전 동에 동일 상속하며 동별 변형은 허용하지 않는다. 블록별 보정은 별도 사전등록 기준과 독립 검수 없이는 이 관문에 섞지 않는다. 승인 시 gate 통계는 명시한 동별 중앙과 0.3 m만 사용하고, P90·censored P90·지지율·bias·개선폭은 보조 기록으로만 남긴다. 결과 확인 뒤 통계량이나 `n` 문턱을 다시 정하지 않는다.

초안의 결과 슬롯에 넣을 진단 관찰값은 `n*=40`, 대응 가능 `132/178`, 해당 모집단의 조건부 matched 중앙≤0.3 m `132/132`; 핵심군 대응 가능 `24/28`, 해당 조건부 관찰 `24/24`다. 이 값은 승인된 v2 판정값이 아니며 0.35 m 반경 matched 대응에 조건부다. 전역 후보 SE(3)도 현재 미채택이다.

이 초안의 “잔차”를 본 진단의 3D point-to-plane으로 사용할 경우 원 §2의 뷰별 ALS 지붕 경계↔영상 에지 잔차와 측정량이 달라진다. 정식 v2는 둘 중 어느 관측량을 관문 본체로 삼는지 명시해야 하며, 원 영상 에지 정의를 유지하면 별도의 view-edge 측정 구현이 필요하다. 이 문안과 후보 transform은 김휘영 승인 전 적용하지 않는다.
