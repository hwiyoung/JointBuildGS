## 1. 한 줄 요지

- S1 완성판의 확증: 조절값(모으기 강도×걸러내기 문턱)을 어떻게 돌려도 "지붕은 살리고 떠다니는 점은 치운다"의 동시 달성 실패. 원인 = **위치 신호 부재**(강도↑ = 오응집 고도↑ 609→662m).
- S2 = 무늬와 무관한 신호 두 계열을 주입: **방향(단안 법선)** + **위치(깊이 감쇠 바닥 상향, 조건부로 단안 깊이)**.
- 자세: "안 넣는 것보다 무조건 좋다" **아님**. 진단이 맞다면 가장 조준된 처방 — 단 ① 단안 깊이는 사전 검증 통과 조건부(기각 분기 잠금) ② "없으니만 못한" 효과는 arm 대조가 심판 ③ 사전 예측을 잠그고 빗나가면 기제 수정 재료로.

## 2. S1 손실 대장과 확증된 결과

| 항 | 무엇을 아는가 | 무엇을 모르는가 | S1 완성판에서 실측된 행동 |
|---|---|---|---|
| 사진 손실 (L1+D-SSIM) | 무늬 있는 곳의 위치+모양 | 무늬 없는 곳에서 침묵 | 4907184 전 셀 제자리 응집(0.34~0.65m). 202/168/178 못 지킴 |
| 깊이 감독 (영상 점군, 0.5→감쇠) | 위치 — 유일한 위치 신호 | 무늬 없는 픽셀 값 없음. 후반 감쇠(0.34→0.054)로 시한부 | 말기 표류(4908178 렌더 0.43→0.03). 조기 절도(5k→10k, 가중 0.3대)도 못 막음 |
| 표면 모으기 (w 100~240) | 얇음 | **위치** — 어디에 모이든 만족 | 강도 21→50에 오응집 고도 609→662m 단조 악화 |
| 걸러내기 (0.05/0.005, 보호 5k) | "흐릿함=잡음" 대리 가정 | 흐릿함≠틀림 (무늬 약한 지붕 정품이 0.004~0.09) | 완화 시 재료 생존하나 유령·공중 막행(465개, z609) |
| 법선 항 | (레포에 존재, 가중 0) | — | 미사용 — S2의 자리 |

- 종합: 위치를 아는 항이 하나뿐인데 무늬 의존+시한부 → 사진이 침묵하는 지붕에서 모으기·걸러내기만 남고, 둘 다 위치를 몰라 공중 막이 응집 승자가 됨. 원 S1이 지붕을 지킨 것도 같은 문장(모으기가 사실상 꺼져 경쟁 자체가 없었음).

## 3. S2 레버와 개선 예측 (근거 문헌 병기)

| 레버 | 주는 신호 | 겨냥 병리 | 예측(잠금 후보) | 문헌 |
|---|---|---|---|---|
| (i) 단안 법선 (가중 0.05~0.1) | 방향, 무늬 무관 | 박공→평판 붕괴·면 방향·Roofer 면 품질 | 방향 지표 개선. **높이 절도 미해결**(+35m 수평 막도 법선상 무결) | DN-Splatter(2403.17822)·Omnidata(ICCV'21)·MonoSDF(NeurIPS'22)·AlignGS(2510.07839) 경계 법선 |
| (ii) 깊이 감쇠 바닥 상향 (0.05→0.15~0.2) | 기존 위치 신호 수명 연장 | 말기 표류 + 무늬 6동 위치 방어 | 말기 표류 차단. 조기 절도(가중 0.3대에서도 발생)는 불확실 → 부분 회복 | CityGaussianV2(2411.00771): distortion 없이 강한 깊이 감독이 주역 |
| (iii) 단안 깊이 (정렬 후, 분담) | 위치, 무늬 무관, 전 화면 | **높이 절도 그 자체** + 무늬 없는 지붕의 유일한 위치 신호 | 절도 차단 최대. 무늬 6동 6/6 복귀가 성공선 | MonoSDF·DN-Splatter(정렬 방식 선례)·SSI=MiDaS(TPAMI'20). 사전 등록 E 레버 조건("영상 깊이 강화로도 무늬 없는 지붕 실패 시") 충족 |
| (대조) 모으기 0 | 도둑 제거 | "표면 모으기 자체가 해악인가" | 지붕 생존(원 S1 수준)·청소 지표 미달 | CityGaussianV2 구성 + 우리 실측(강도↑=악화) |

- 한 줄 예측: 법선은 모양을, 깊이 바닥은 무늬 있는 지붕의 높이 수명을, 단안 깊이는 무늬 없는 곳까지 높이 그 자체를 고친다. 병리 중심이 높이이므로 (i) 단독 미달 예측, 최소 (i)+(ii), 본명 (i)+(iii).
- 단안 깊이 사용법: 전처리에서 이미지별 정렬(영상 점군 기준, DN-Splatter 계열) → 미터화 저장 → **픽셀 분담**(영상 점군 유효 픽셀=영상 점군만, 빈 픽셀=단안만) + 가중 위계(미터 닻 우선). MonoSDF는 렌더 깊이 기준 정렬(자기 교정형) — 우리는 닻이 더 조밀하므로 영상 점군 기준 채택.

## 4. 단안 깊이 위험 관리 — 휨 분기표 (사전 잠금 후보)

- 인정하는 위험: 정렬은 직선 보정이라 휨을 못 지움. 실패 모드는 "몇 m 치우친/휜 표면"(이미지 기반이라 공중 막 쪽으로는 안 당김). 임무는 0.5m 계측이 아니라 수십 m 절도 차단(코스 앵커) — 허용선이 거기서 나옴.
- 사전 검증(A-1)에서 재는 것: ① 정렬 잔차(영상 점군 유효 픽셀, 중앙·p90) ② **휨 진폭**(잔차를 화면 위치의 저차 곡면으로 적합 → 이미지당 m) ③ **지붕 직접 채점**(무늬 없는 3채+재구성 실패 8동의 지붕 픽셀에서 참조 LoD2·레이저 점군과 대조 — "정렬된 단안이 이 지붕을 몇 m에 놓는가" 건물별 표) ④ 건물 분해능(윤곽 깊이 단차 vs 참조 높이 상관).
- 분기(제안값 — 판정 요청): 지붕 채점 중앙 ≤3m·휨 소폭 → 그대로 채택 / 3~8m·구조적 → 완화 사다리에서 시작 칸 선택(1. **조기 한정 스케줄**: 절도 창구 5k~10k에 세게, 이후 감쇠 — 영상 깊이와 반대 방향 2. 국소(타일별) 정렬 3. 휨 빼기(저차 곡면 보정) 4. 절대항 가중↓+기울기(모양)항 위주) / >8m·비구조적(건물 분해 실패) → **(iii) 기각**, Arm 사슬에서 제외.
- 최후 안전망: (ii) arm과 (iii) arm의 나란한 대조 + 가드레일 — "(iii)이 (ii)보다 무늬 6동 퇴행이면 단안 기각"을 예측에 포함.

## 5. 실험 계획

### Track A — 학습 0 선행 (본 학습 전·병렬)

- **A-1 단안 깊이 사전 검증**: 모델 Depth Anything V2 우선(예비 Omnidata depth) → §4 측정 4종 → 분기표 적용·채택 칸 보고. (법선 A-5와 같은 판독 문화: 기준 잠금·크롭 구도 확인)
- **A-2 공중 막 정체 확인**: 막 고도(595~615·660대) vs 카메라 비행 고도 분포 대조 + 막 가우시안의 시점 일관성 프로파일(스트립 안/사이) → "카메라 근접 플로터인가"의 재료. 2선 도구(근접 컷·일관성 잣대·densification 교정) 채택은 이 결과 후 판정.
- **A-3 구현 확인 3건**: 길쭉이 필터 설정값(config 한 줄) · 법선 렌더 경로와 단안 법선 손실 꼴(DN-Splatter식 확인) · 단안 깊이 전처리 파이프(정렬·미터화 저장).
- **A-4 (판정 ② 대기)** defect 법선 재판독 — 뷰 재선정 후 60098·4907186·4907188 재채점.
- **A-5 채점 결손 방지 준비**: rend_dist mean(붕괴뷰 proxy)·셀별 전체 가우시안 개수·전역 z 히스토그램 산출 코드 — S1 완성판 ③ 미산출의 재발 방지.

### 채점 — 파레토 4항(v2.2) + S2 신설 관찰

- ① 가드레일: 무늬 6동 조립 + ≥5/6 raw+0.5m (불변) ② 정확도 비퇴행: 원 S1 대비 짝 중앙 ≤+0.3m·파국(+1.5m) 없음 ③ 청소 개선: 개수 ≤S0×2 · rend_dist mean ≤0.5 — **이번엔 산출 의무** ④ 유효성 비퇴행: 수리본 dense 유효-조립(원 S1=10 기준).
- 신설 관찰(게이트 아님): 방향 지표(박공 2모드 회복·면수 vs 참조, G7) · 무늬 없는 3채 상태 · 4907202 시계열(잠긴 관전: 5k 생존 → 10k 제 높이 정착 여부) · 전역 z 히스토그램(공중 막 크기 추적 — factor 셀 결손 메움).

### 사전 예측 (잠금 후보 — 판정 요청)

- P-A: Arm 0 = 지붕 생존(조립 5~6/6)·청소 지표(개수·rend_dist) 미달.
- P-B: Arm 1 = 방향 지표 개선·절도 미해결(202/168/178 미회복).
- P-C: Arm 2 = 말기 표류형(178류) 회복·조기 절도형(202) 불확실 — 부분 회복.
- P-D: Arm 3 = 최다 회복, **무늬 6동 6/6 복귀가 성공선**. (iii)이 (ii)보다 무늬 6동 퇴행이면 단안 기각.
- P-E(갈림길): Arm 3에서 4907202가 5k 생존+제 높이 정착이면 "위치 신호 작동" 확증 / Arm 3에서도 공중 막행이면 "신호 부족이 아닌 다른 기제" → 공중 막 제어(2선) 회부.
- 맥락 명기: 사전 예측은 corrected-S1·S1 완성판에서 **2연속 빗나간 상태** — 이번(3번째)도 크게 빗나가면 재프레임 논의를 기본 안건으로.

## 6. 세 기준 감사

- **연구 의도·전후 실험과의 부합**: 단안 깊이는 설계 메모 E 레버의 사전 등록 조건("영상 깊이 강화로도 무늬 없는 지붕 실패 시 도입")이 충족된 뒤의 투입 — 순서 준수. 무모델 원칙(3D 모델 prior 금지, 2D foundation 허용) 유지. 의미 레버는 S2에 없음(점군화 라벨용만) → S3의 delta(의미-유도 기하)가 깨끗하게 격리됨 — AlignGS 대비 구도 유지. P0→E5→S1의 "정직한 audit" 서사와 연속(음성 결과 → 기제 → 조준된 처방). **주의 1건**: S2 정의가 "표면 방향 잡기"였는데 위치 신호가 합쳐지므로 이름 갱신 필요 — "표면 방향·자리 잡기" 제안(판정).
