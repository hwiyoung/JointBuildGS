# Document archive

This directory preserves superseded or historical material needed for lineage and reproducibility. Archived files are not deleted and are not silently treated as current evidence.

Current reader-facing experiment entry points are under [`../../experiments/`](../../experiments/README.md). Exact old-to-new paths and SHA-256 values are recorded under [`../../research/repository/migrations/`](../../research/repository/migrations/).

Current archived families include `boundary_map`, `bucket_crosswalk`, `claude_web_brief`, [`overnight_coordination/`](overnight_coordination/README.md), `pointcloud_attributes`, `population_aux`, `projection_gate`, and [`pre_tum_results/`](pre_tum_results/README.md). Each version or historical bundle remains separate.
