# Pre-C1–C5 research archive

This directory preserves the legacy four-condition geometry–semantics program that
preceded `C1C5_CANON_v1`.

- `RESEARCH_CONTEXT.md` — historical method and result context
- `EXPERIMENT_PLAN.md` — historical v7 experiment sequence and embedded prompts

These documents are evidence for exact legacy reproduction only. They do not define
current research or authorize execution. Current work follows
[`docs/research/00_RESEARCH_CHARTER.md`](../../../research/00_RESEARCH_CHARTER.md)
through [`docs/research/06_DECISION_LOG.md`](../../../research/06_DECISION_LOG.md) and
an explicitly approved task packet.

The compatibility notices at the former `docs/research/RESEARCH_CONTEXT.md` and
`docs/research/EXPERIMENT_PLAN.md` paths exist only so immutable historical references
resolve to this archive.
