# ③b 레시피 설계 — 레퍼런스 기반 (2026-07-07)

> 목적: 재료(distortion·depth·normal·densification·elongation·sem)를 **레퍼런스로 따져** 표적 레시피 + **단계 누적 ablation**(기여 분리)으로 설계. kitchen-sink 금지. 판정·채택은 김휘영.
> 설계 원칙: ① 우리 진단이 지목한 실패에만 표적 ② **textureless=make-or-break** → texture-무관 레버 중심 ③ AlignGS·CityGSV2가 자기 ablation으로 기여를 분리했듯 **누적 단계**로 어느 레버가 무엇을 movr는지 본다 ④ 레퍼런스 없는 값은 넣지 않고 출처·검증 필요를 표기.

## 0.5 의도·semantic의 자리·novelty (프레이밍 확정 07-08)

- **순서 한 줄**: 기하 기계를 복원해 공정한 바닥 + textured를 만들고(S1+S2), 일반 기하가 못 닫는 **textureless 잔차를 semantic 구조가 닫는지** 시험한다(S3). S1+S2 = 전제조건(AlignGS "결함 기하 위엔 의미가 못 선다"), S3 = 논문 질문.
- **semantic의 두 자리**: (a) **CityGML 조립에 필수인 분류**(roof/wall/ground → RoofSurface 등; 공동최적화가 경계 분류를 개선 → 조립 정확도) — 항상 유효한 fallback. (b) **textureless 구조 prior**(증거 없는 곳에 지붕-평면·능선 경계 주입 = 관측가능성 게이트) — 더 날카로운 novelty·최상 서사.
- **novelty(좁힘·정직)**: "의미가 기하를 유도"는 AlignGS 것. 우리 delta = **단일 GS 공동최적화에서 의미 구조로 *textureless 건물* 기하를 채워 *CityGML* 생성, *3D-모델 prior 없이***. vs AlignGS(sparse-view 실내)·vs 의미제약 MVS(단계적 파이프라인). **실험(S1→S3)이 곧 novelty 검증** — S1+S2가 다 닫으면 semantic은 (a)로 축소, S3가 textureless를 닫으면 (b)로 증명.
- **무모델 = 3D-모델 prior 없음**(3D 모델 만드는 데 3D 모델 prior 쓰면 순환). 2D foundation(mono-normal scale-free·SSI mono-depth)은 영상 유래라 허용.

## 1. 실패 → 레버 매핑 (texture 의존성 표기)

| 진단된 실패 | texture-의존 레버 | texture-**무관** 레버(무텍스처 핵심) | 근거 |
|---|---|---|---|
| 플로터(표면 집중 없음·prune 약함) | — | **distortion 복원**, **prune 0.05 + elongation 필터** | 2DGS·CityGSV2 |
| textured 정확도 약함 | **MVS depth 0.03→0.5** | — | CityGSV2 |
| textureless 정확도(무신호) | — | **mono-depth SSI + gradient-aware** | DN-Splatter |
| 평탄화(형태 오류) | — | **mono-normal**(scale-free) | DN-Splatter·AlignGS |
| sem이 기하 안 몲(논문 핵심) | — | **sem-유도 depth(masked)+경계 법선** | AlignGS |

→ 오른쪽 열(texture-무관)이 논문의 **실제 가치 자리**(무텍스처에서 MVS를 이기는 곳). MVS depth 강화는 textured만 돕는다.

## 2. 레버별 레퍼런스 + 결정

**A. depth-distortion (표면 집중, texture-무관)**
- 레퍼런스: 2DGS 기하 recipe `lambda_dist 1000(bounded)/100(unbounded)`. CityGSV2는 0으로 두고 강한 depth 감독+floater 제어로 대체.
- 결정: **복원**(우리가 끈 바로 그 항). 단 우리 장면은 **unbounded 대규모 항공** → 값은 100 계열에서 **scene-scale 정규화**로 튜닝(맹목 1000 금지). 저위험·직접적.

**B. densification/prune/elongation (플로터 제거, texture-무관)**
- 레퍼런스: 2DGS `prune_opa 0.05`. CityGSV2 **elongation filter**(퇴화 가우시안 제거)+decomposed densification.
- 결정: `prune_opa 0.005→0.05` + **elongation 필터 도입**. 우리 플로터(50-63% 저불투명·19-29% 세장)를 근원에서 제거.

**C. depth 감독 (textured 정확도, texture-의존)**
- 레퍼런스: CityGSV2 `depth 0.5→0.05`. DN-Splatter SfM-정렬 + gradient-aware(무텍스처 집중).
- 결정: **MVS depth 0.03→0.5**(textured에서 ~MVS 품질≈1m로 당김). textureless엔 무력 → D로.

**D. mono-normal (평탄화·textureless, texture-무관 — 핵심 후보)**
- 레퍼런스: DN-Splatter Omnidata mono-normal. AlignGS geometric normal `ω_ng=0.05` + **경계 법선** `ω_nb=0.01`.
- 결정: **mono-normal 도입**(scale-free — 우리 depth-스케일 우려 무관). 두 경사(박공)를 법선 두 방향으로 강제 → 평탄화 직격. **무텍스처 make-or-break의 1순위 레버.**

**E. mono-depth (textureless 정확도, 조건부)**
- 레퍼런스: DN-Splatter **SSI(scale-shift invariant) mono-depth + gradient-aware**(저텍스처에 정규화 집중). AlignGS **Pearson**(scale-불변) depth, 의미 경계 마스킹.
- 결정: **2단 조건부** — S1(MVS depth 강화)로 textureless가 여전히 실패하면 도입. scale은 SSI/Pearson로 처리(절대 depth 안 씀).

**F. sem-유도 기하 (논문 핵심, 격리 시험)**
- 레퍼런스: AlignGS — 의미-마스킹 depth(Pearson) `ω_d=0.5` + **경계 법선 발산** `ω_nb=0.01`, `α=100`, 1.5k iter부터. **자기 ablation: 의미 distillation(=우리 sem CE)만으론 기하 F 0.565→0.570(무변), 이득은 의미-유도 depth/법선에서.**
- 결정: **별도 단계로 격리**(번들 금지) — 우리 sem CE는 이미 있고 기하에 무력하니, "sem이 기하를 몬다"를 시험하려면 **AlignGS식 의미-유도 손실을 명시적으로 추가**해 그 증분만 본다.

## 4. 결정 필요 포크 (김휘영)

1. **표면 집중 경로**: distortion 복원(2DGS 네이티브, 우리가 끈 것) vs CityGSV2식(distortion 0 + 강depth+floater제어)? → 권고: **distortion 복원**(가장 직접적·우리가 끈 항). 둘 다 S1에서 비교 가능.
2. **sem-유도 격리 vs 번들**: → 권고: **격리**(AlignGS ablation 교훈 — 증분을 봐야 논문 주장 검증).
3. **mono-depth 도입 시점**: 처음부터 vs textureless 실패 시 조건부? → 권고: **조건부**(S2까지 보고).
4. **distortion 값**: unbounded scene-scale 정규화 — 정확 값은 2DGS unbounded(100)·CityGSV2 config에서 뽑아 확정(검증 필요).

## 5. 성공선·트리거 (재고)

- **성공**: textured에서 raw_dense(~1m)·F~0.85 **동등** + textureless에서 MVS **우위**(GS-JSO의 실제 주장). LiDAR-실패 지대는 목표 아님.
- **트리거(사전약속)**: S1~S3 후에도 **ACMP급(~2.5m) 정체·textureless 우위 없음**이면 재프레임. 단계별로 어느 레버까지 갔는지 기록해 "무엇이 부족한지"를 남긴다.

## 6. 시작 가중치 (문헌 확인 완료 07-08)

| 단계 | 레버 | 시작값 | 출처 |
|---|---|---|---|
| S1 | distortion (`w_distort`) | **~100**(unbounded, scene-scale) — 0에서 복원 | 2DGS: bounded 1000/unbounded 100 |
| S1 | `prune_opa` | **0.05**(우리 0.005→) | 2DGS |
| S1 | elongation 필터 | 극단 세장 가우시안 densify 금지(SSIM-grad densify) | CityGSV2 |
| S1 | depth 감독 | **~0.5 지수감쇠→0.05**(우리 0.03→) | CityGSV2 |
| S2 | mono-normal(외부, Omnidata) | **λ_n 0.05~0.1** | DN-Splatter 0.1 · AlignGS ω_ng 0.05 |
| S3 | 의미-마스킹 depth(Pearson·scale-불변) | **ω_d 0.5** | AlignGS |
| S3 | 경계 법선 발산 | **ω_nb 0.01**, α=100, ~1.5k iter부터 | AlignGS |

- **S3 마스킹/경계는 우리 자체 의미 라벨로 구동**(무모델 유지 — foundation 의미 안 씀).
- CityGSV2 정확 depth 가중·elongation 임계는 `github.com/DekuLiuTesla/CityGaussian` repo에서 **S1 셋업 시 확정**(지수감쇠 스케줄·SSIM-gradient densification 포함).
- DN-Splatter: λ_d 0.2·λ_n 0.1·λ_smooth 0.1(SSI/SfM-정렬 depth, Omnidata normal). AlignGS: λ_sem 1.0(soft1.0+hard0.1)·ω_d 0.5·ω_ng 0.05·ω_nb 0.01·α100·1.5k, PGSR 기반 7k iter.
