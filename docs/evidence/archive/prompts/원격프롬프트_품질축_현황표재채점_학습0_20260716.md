# 원격 발주문 — 품질 축 현황표 재채점 (조립 품질·학습 0) (2026-07-16 · v2 용어 동기화)

> **이 문서의 규칙.** 모호어 금지 · 원격은 측정·산출만(판정·해석 금지) · 학습 0(GS 최적화 시작 금지·기존 산출물 읽기 전용) · 파도별 issues.md 커밋+해시 · 미푸시 커밋 먼저 push.
> **배경 한 줄.** 생성 축은 합성 점군 구성(0단 검수·별도 판정 트랙)으로 넘어갔고, GS의 남은 전장은 품질 축이다. 그런데 지금까지의 채점은 점 거리·has_lod22 중심이라 **"조립했을 때 면 구조가 얼마나 충실한가"를 GS vs dense로 같은 건물끼리 짝 지은 표가 없다.** 이 파도는 새 실험이 아니라 기존 조립 산출물의 전수 재채점으로 그 표(현황표)를 만든다 — 품질 축 본선 설계의 입력이다.

## 1. 용어 (이 파도 한정)

1. **조립 품질 지표(면 구조)** — 모델 CityJSON을 참조 LoD2와 대조해 건물별로:
   - `roof_face_count_model` / `roof_face_count_ref`: RoofSurface 인스턴스 수(모델/참조). **fallback(lod11) 모델은 지붕면 1로 계수하고 fallback 플래그를 별도 열로** — 면수 비교에서 숨기지 말 것.
   - `face_count_ratio` = model/ref (1.0이 충실·>1 과분할·<1 과병합).
   - `roof_rms_m`: 기존 CityGML 지붕 rms 정의 그대로(참조 지붕면 대비, 기존 산출 재사용 가능 시 출처 명기).
   - `val3dity_valid`: val3dity 통과 여부(기존 리포트 재사용 가능하나 버전 상이하면 일괄 재실행·버전 기록).
   - `rf_extrusion_mode` / `has_lod22`: 잠금 규칙 그대로(형식 geometry ≠ 유효 조립). **역할=게이트 변수**(LoD2 재구성 성공 표본을 정의 — 평지붕은 LoD1 상자와 기하가 비슷하므로 이 열 단독 판독 금지, RMS·면수와 함께).
2. **짝(pair)** — 같은 건물의 GS 모델 vs canonical dense 모델(±ALS 상한 모델).
3. **cherry-picking 금지 규칙** — "GS 최선"은 사전 규칙으로만: 후보 = 해당 건물에서 유효(val3dity)한 모델 중 roof_rms 최소. 유효 모델이 없으면 전체 중 roof_rms 최소 + `invalid_best` 플래그. **전 arm 전수 표가 본체이고 최선 열은 부속.**

## 2. 잠금

- 학습 0. 새 GS 런·재학습·파라미터 변경 금지. 모든 입력은 기존 runs/ 산출물 읽기 전용.
- GT(참조 LoD2)는 채점 전용(이 파도는 채점이 목적이라 전 구간 허용 — 단 새 기하 산출물 생성 없음).
- 판정어 금지: "대등/우위/실패" 선언 없이 수치·표만.
- 기록: CSV+manifest(SHA256)+그림, `learning_runs_started=0` 전 행, issues.md 커밋+해시.

## 3. 과제

### R1 — 조립 산출물 인벤토리 (전수·누락 정직)
- C001 18동을 대상으로 조립 CityJSON이 존재하는 **모든 GS 웨이브·arm·런**을 runs/에서 열거: 최소 [③b-S1, corrected-S1, S1 완성판(요인 3셀), S2(4arm), S2p, S3 계열] — 실존하는 것만, 없는 웨이브는 없다고 기록.
- 비교재: canonical dense = **w2_1**(199 전수 정본·C001 18동분) + run_2(감도 대조용·있으면), ALS 상한 = P0 audit Ref-L 모델(있으면), 참조 = LoD2 CityGML.
- 산출: `qs_rescore_inventory.csv` — (wave, arm, run, building, cityjson 경로, SHA256, 좌표계/오프셋 확인 열). **크롭 로컬 좌표 모델은 datum 오프셋을 명기하고 참조와 정합 확인 후 채점**(과거 datum 시차 함정).

### R2 — 조립 품질 전수 재채점
- R1의 모든 (모델, 건물)에 §1-1 지표 산출. dense·ALS·참조도 같은 코드 경로로(참조 자기 자신 대조 = 무결성 체크 행).
- 기존 점군 지표(점군 |Δz|·커버리지·voxel 등)가 같은 런에 이미 있으면 **별도 열로 병기**(점군 정확도와 조립 품질을 한 표에서 보게).
- 산출: `qs_rescore_scores.csv` (모델×건물 전수).

### R3 — 짝 현황표 (본 산출물)
- 기준 모집단: **dense(w2_1)가 조립 성공한 C001 건물 집합**(개수를 실측 확정 — "11동"은 예상치로 취급) + 참고로 GS만 조립된 건물.
- 건물별 한 행: dense 조립 품질 | GS 전-arm 요약(유효 개수/총 모델 수) | GS 최선(§1-3 규칙·arm 라벨 명기) | ALS(있으면) | 참조 면수.
- 층화 열: 기존 18동 분류(기준문서 부록 표기 그대로 — 무텍스처/DEFECT/입력한계 등).
- 산출: `qs_rescore_pairs.csv` + 요약 통계(면수비 중앙·RMS 중앙·유효율, dense vs GS-최선, 층화별).

### R4 — 그림 (정성, 판정 재료)
- ① 면수 산점: x=참조 면수, y=모델 면수 — dense와 GS-최선을 색으로(대각선=충실). ② 건물별 RMS 짝 막대(dense vs GS-최선). ③ 대표 3~4동(짝 성공/과분할 대표/무텍스처 1) 지붕면 인스턴스 색칠 top-view: 참조 | dense | GS-최선 나란히. fallback은 "평판 1면"임이 보이게.
- 산출: `docs/figs/qs_rescore/` PNG.
