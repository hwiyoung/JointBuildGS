## §0′ ⚠ 검증으로 정정된 헤드라인 (must-fix 3 반영)

2. **원인은 "GS 저주파 waviness"가 아니라 "다층(단차/경사) 지붕 복합도"** — LF metric(전역 단일평면 RMS)은 **실단차에 오염**되어 ALS_LF ≥ GS_LF(4906969 ALS 1.63 > GS 1.15); excess–LF r=+0.32는 **1점(4906969) 의존**(제거 시 −0.00). 고-excess 2동(4906969·42364659)은 **동일 메커니즘**(동향 평면들이 높이만 다름 — 42364659 4면 0.5~1.3° 동향·z 3.5m차), "진짜 다른 평면" 아님(1차 이분법 기각).
3. **밀도는 "원인 아님"이 아니라 "변조하나 ALS 미도달"** — ceil 5/20/200 → 7/14/17(단조). 단 ceil 5(ALS밀도 미만)도 7>ALS5, decim 14→17, 최고밀도 동 excess 0 → 밀도 단독으론 ALS 못 감. r=−0.51은 기술적(n=6 비유의).

## §8 한 줄 관찰 + Phase B 권고 (판정 금지)

**"후처리 레버는 과분할 면수를 ALS에 맞출 수 있으나(facet-merge 2/6, 가드안전) — 실 높이구조(z-span 1.8~3.4m)를 무너뜨려야 도달하고, 표면 충실 격차(roof-env RMS 1.7~2.6× ALS, 3/6동)는 그대로다."** 원인은 밀도(변조하나 ALS 미도달·decim 실패)도 고주파 노이즈(smoothing 죽음·가드 파괴)도 아닌 **다층 지붕 복합도 × GS 표면이 각 실레벨을 동향 조각으로 분절**(4906969·42364659 동일 메커니즘; "곡면 waviness"는 데이터 미지지). 셋 중 **facet-merge만 가드안전**하나 **면-절약을 살 뿐 표면 충실·실구조 보존은 못 산다**; smoothing/decimation은 무효(smoothing은 가드 파괴). → **Phase A 부족(충실한 수렴 불가) → Phase B 권고**(판정=김휘영): **cp/평면성 손실 재학습**(D5=부분 레버 재방문, 정정 라벨로) 또는 **곡률/구조-인지 structure-G2**(D6 step0 지시) = **학습 단계에서** 분절 자체를 줄이되 **실 단차는 보존**하는 길. 후처리(Phase A)로는 "면수 vs 실구조"를 동시에 못 만족.
