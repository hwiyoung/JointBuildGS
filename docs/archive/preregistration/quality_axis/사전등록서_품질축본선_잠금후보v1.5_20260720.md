## 1. 질문 (불변)

**사전에 지정한 단일 GS 레시피(고정조건)가, 같은 건물 짝에서, 표준 조립(Roofer 캐노니컬) 품질 지표로 dense(w2_1)를 이기는가.** 상한(건물별 갈아끼우기)은 참고 전용·완전율 조건 병기 필수.

## 2. 모집단 — 이중 보고 원칙 신설 (07-20)

- 파일럿 = C001 dense-성공 짝 **10동 고정**(불변·명단 v1.2 §2). 정본 평가 모집단 = **178동**(채점·전후 표의 분모 — 소형 포함. 소형도 조립·채점은 전부 받으므로 채점 모수에서 빼지 않는다).
- **이중 보고 원칙**: 주 수치는 전체 모집단으로 보고하되, **소형(<50㎡) 제외판을 민감도 참고 행으로 병기**한다. 지도(신호 기반 배정)의 성능을 말할 때는 분모를 배정 시도 대상(178−소형 37 = **141**)으로 쓰고 "배정률 141/178"을 명기한다.
- 조건부 생성 적용 대상 목록: `[census 후 기입]` — 현행 5동(실증 2 + 후보 3)은 잠정. 199·8568391은 B-1 실증 근거 override 등재(불변).

## 3. 지표 (5개 자 — 불변) + 앵커의 조작적 정의 (신설)

5지표(지붕 RMS·면수비·유효성·LoD2 성공·완전율)와 각주 2건(Hausdorff 단방향·완전율 출처 교체)은 v1.4 그대로.

**높이 앵커(correspondence anchor)의 조작적 정의(07-20 확정 문안):** 건물별로 dense 다이얼(MASt3R 조밀 대응·crop 주소 지정 → 고정자세 DLT → 재투영 2px 통과)을 실행해, **발자국 안 삼각측량 점 수 ≥ 문턱(현행 1·실질 "0 대 수백" 이분) ∧ 높이 일관성(MAD)** 이면 "앵커 있음". 시각적 사전 기준(텍스처 등)으로 대체하지 않는다 — 텍스처 신호에 의한 예측은 3판 실측(이득 0 → −0.091 → −0.025)에서 상수 이하로 확인됐고, 텍스처는 서술용 공변량으로만 쓴다. 앵커의 물리적 의미: 조건부 생성(평지붕)의 유일 미지수인 높이 z의 공급원 — 면 전체를 세울 정보(MVS 조립)와 달리 숫자 하나를 읽을 검증점이면 충분하므로, "앵커 있음 ∧ 조립 실패"(예: 4907199, 373점·커버리지 0.125)가 자연스럽게 존재한다.

## 4. 비교선 (실측 눈금 — 주 수치 불변 · 민감도 행 신설)

**민감도 참고 행(07-20 신설 — 판정 기준 아님):** 파일럿에서 소형 1동(4908168)을 제외한 9동판 = dense **1.354** · GS 고정 2.353 · 상한 1.062. 10개 값 중앙값이 최저권 1개 값에 민감함을 사전 공개하는 행이며, **합격선 ⓐ는 사전등록대로 10동·0.990에 고정**(명단·기준 변경 아님).

**정본 178(전후 표 "전" 칸):** dense 성공 114·RMS 0.761 / ALS 178·0.421 — 소형 제외판(참고): dense 95동·0.791 / ALS 141동·0.480(강건 확인). **이길 지대: 주 수치 38동**(RMS>1 ∧ 완전율≥0.5) — 소형 제외판 33동·조건 없이 44동 병기. 상한 승리 분해 주석 = v1.4 유지.

## 7. (iii) 실험 계획 + **판독 층 정의 확정 (07-20)**

0파~3파 구성·런 수(12~14런) = v1.2 확정판 유지. **판독 보고의 층 = 실측 사다리로 잠근다(예측 규칙 아님):**

| 사다리 칸 (영상에서 건질 수 있는 정보의 양) | 조작적 정의 (전부 측정) | 붙는 처방 |
|---|---|---|
| ① 전부 건짐 | dense 조립 성공(has_lod22) | 고전 경로 — **품질 축의 무대(① 내부에서 본선·이길 지대 38동 분해 보고)** |
| ② 높이 앵커까지 건짐 | 조립 실패 ∧ 앵커 있음(§3 정의) | 조건부 생성(B-1 실증 경로) |
| ③ 윤곽까지만 건짐 | 조립 실패 ∧ 앵커 없음 ∧ 윤곽 관측(뷰≥2·프레임 안·유효 화소) | 미검증 후보(h-스윕)·신중 딱지 |
| ④ 거의 못 건짐 | 조립 실패 ∧ 앵커 없음 ∧ 윤곽 부실 (가림·관측각 포함) | LiDAR 영토 |

소형도 같은 측정 기준으로 이 네 칸에 배정한다(§2 이중 보고 원칙과 병행). 텍스처는 칸 정의에 입력되지 않는다(서술 변수). ①~④ 인원·명단 = `[census 후 기입]`. mono 게이트 눈금 재료 유지(199=9.81° 등).
