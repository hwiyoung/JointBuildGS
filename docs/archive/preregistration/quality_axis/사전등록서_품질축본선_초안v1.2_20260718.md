## 1. 질문 (불변)

**사전에 지정한 단일 GS 레시피(고정조건)가, 같은 건물 짝에서, 표준 조립(Roofer 캐노니컬) 품질 지표로 dense(w2_1)를 이기는가.**

- 비교 기준 = **고정조건**(건물별 조건 갈아끼우기 금지). 건물별 최선 갈아끼우기 상한(oracle·RMS 중앙 0.784)은 사후 선택 상한이므로 **참고 전용**.
- 본선 채점 전에 레시피 1개를 명시 고정하고 이후 변경하지 않는다.

## 3. 지표 (5개 자 확정)

| 지표 | 정의 | 판독 |
|---|---|---|
| 지붕 RMS | 조립 지붕면의 참조 대비 수직 오차(m) | 격차 본체 — 낮을수록 개선 |
| 지붕면 수 비 | 모델 면수 ÷ 참조 면수 (폴백=1면+플래그) | 1.0이 충실 |

## 5. 성공 기준 — 두 갈래 문안

**개선의 정의 `[잠금 확인]`:** 파일럿 10동 짝에서 ⓐ **RMS 중앙 < 0.990 m (필수)** ⓑ 나머지 3지표 중 ≥1 개선 ⓒ 전 지표 열화 없음 ⓓ 완전율 비열화 ⓔ **2런 재현: 두 런 모두에서 ⓐ~ⓓ 성립** (07-18 판정 — 런 요동 이김 차단).

- **주선(이김)**: "GS 정칙화가 같은 사진에서 MVS보다 나은 조립 재료를 만든다."
- **부선(못 이김) — 3층**: ① 원인 귀속 분해(상한과 고정조건의 갭을 건물·성분별로) ② 대안 처방 실증(값싼 정제의 체계적 최적화 — "영상 점군 조립 품질의 최선 비학습 전처리" 확정) ③ 라우팅 처방(경계 지도를 도구 배정 규칙으로 — 결과 장 178동 표를 "단일 방법 vs 측정 기반 라우팅" 비교로).

- 판독 보고: 층(관측·크기)별 채점 + 건물별 역대 상한 대비 접근도 + 항별 손실 비중.
- **라벨→조립 채널 2단 사다리**(07-18 판정): 1단 정답급 딱지(상한·혼재 분리) → 2단 vision FM 세그먼트(실전·열화 측정). 실패 진단 분리: 상한부터 실패=채널 설계 문제 / 상한 성공·실전 실패=라벨 품질 문제.

## 8. 경계 지도 층 분류 — 4단 확정·명명 (07-18)

**well-textured**(사진 매칭으로 점군이 서는 건물) / **textureless, correspondence-anchored**(매칭은 안 되나 높이 기준점[대응점]이 있는 건물 — B-1 실증 경로 적용 가능) / **outline-only**(대응점 0·윤곽만 관측 — h-스윕은 미검증 후보라 신중 딱지) / **unobservable**(영상 단독 재구성 불가) + 소형(<50㎡)은 판별불가 별도 표기. 나눔의 근거 = 방법의 검증 상태(실증/후보/불가). 각 이름 첫 사용 시 괄호 부연 1줄.
