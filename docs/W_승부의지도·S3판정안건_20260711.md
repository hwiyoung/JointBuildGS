## 1. 승부의 지도 — 개정판

### 1.1 층 두 개 (Textureless는 축이 아니라 층이다)

- **자격 시험 층** = 무늬 있고 관측 정상인 건물(C001 대표 = 양쪽 성공 6동). 목표 = raw dense와 **대등**(짝 델타 ≤ +0.3 m·유효성 비퇴행). 체계적 우위(중앙값 역전)는 목표가 아니다 — GS의 위치 신호(깊이 감독)의 선생이 raw dense라, 선생이 틀리는 폭만큼만 이길 공간이 있는 구조.
- 단 **국소 우위는 실측 2건**: 원 S1의 4907202 = GS 0.389 vs raw 0.564 m(45% 우위) · S2p의 4907198 = GS 1.63/1.99 vs raw 2.13 m. raw가 흔들리는 건물(매칭 노이즈·부분 커버)에서 GS 다중뷰 렌더 일관성이 이긴다. prior는 이 집합을 넓히는 장치 — 보너스이지 성공선이 아님.
- **승부처 층** = 무늬없음·관측됨(C001 대표 = 8568391·8568392·4907199). raw dense가 원리적으로 0(점 없음 → 모델 없음)이라, **정품 조립 하나가 곧 전 축 승리**(0 대 유한). 현재 성적 = 전 라운드 0(8568391 r2의 14.07 m 무효는 잔재 착시). 논문 delta("무늬 없는 지붕까지 채운다")의 실증 자리.
- **완전성**은 두 층의 합에서 나온다: 자격 시험 층 대등 + 승부처 층 개봉 = 도시 전체 커버에서 raw 대비 우위. "전 축 승리" 인식은 대화 중 부푼 것 — 사전등록 문면(대등 + textureless 우위)이 원래 잣대.

### 1.2 GS를 쓰는 이유 (심사 방어용 문면)

- **완전성**: MVS는 무늬없음에서 원리적으로 0. GS 렌더는 무늬없음 지붕의 86%를 이미 표면으로 덮고 있음(지금은 틀린 높이 — "놓을 능력"의 실측, E5 렌더 감사). 대안은 재보고 닫음: 단안 깊이 = Large·5뷰 8.10 m 실측 기각 · LoD1식 가정 채움 = 관측 기반·무모델 원칙 위배.
- **공동 최적화**: "의미로 기하의 불완전성을 메꾼다" = **성능 가설이며 S3의 시험 대상**(우아함 논거가 아님 — 07-11 정정). 단계적 방식(의미제약 MVS) 대비 실질 메커니즘 후보: MVS는 침묵 픽셀에 제약을 걸 후보 깊이 자체가 없지만 GS는 연속·미분 가능 표현이라 어디든 밀 수 있음 + 2D 의미 마스크의 노이즈가 다중뷰 렌더 융합에서 정제됨.
- **정직한 조건부**: 승부처가 끝내 안 열리면 GS의 성능 논거는 소멸 — 재프레임(GS=의미 라벨링·조립 분류, 기하=영상 점군)이 사전 등록된 비상구.

### 1.3 문헌 좌표 (S3에 걸 수 있는 기대의 종류)

- 실내 신경 재구성에서 "photometric만 = 처참 → prior 투입 = 급반전"은 실재: Manhattan-SDF(의미 분할+맨해튼 가정)·MonoSDF(단안 깊이·법선 cue)·NeuRIS(법선 prior) — ScanNet F-score 0.3~0.4대 → 0.7대.
- **반전의 해부**: 무늬 있는 영역이 더 좋아진 게 아니라, **침묵 영역(흰 벽·바닥)이 채워지면서 평균이 뛴 것.**
- 성립 조건 3과 우리의 대조: (i) 침묵 영역이 장면을 지배 — 승부처와 같은 구조 ✓ (ii) prior가 그 도메인에서 정확 — **우리의 구멍**(단안 깊이는 항공에서 기각 실측·의미는 미검 → 관문으로 측정) (iii) 잣대가 표면 지표 — 우리는 조립·CityGML이라 더 가혹.
- 따라서 S3 기대의 종류 = **빵점 영역(승부처) 개봉 + 모양·경계 부분 개선.** 전 축 역전이 아님.

## 2. 채점 구조 — 상시 5축 채점표 + 실험별 합격 조건

### 2.1 상시 채점표 (관찰 — 어떤 실험에서도 생략 금지)

| # | 축 | 잣대 | 현재 성적(S2p r1/r2) |
|---|---|---|---|
| 1 | 완전성 | 층별 조립 수·커버 | 자격 시험 층 5/6·4/6 · 승부처 층 0 |
| 2 | 정확도 | 정답 채점 RMS·짝 델타(원 S1 대비 관찰 유지) | 짝 중앙 +0.50/+1.21 m·파국 1/2건 |
| 3 | **형상** | **경사 방향 모드 수 + 방위각 오차**(3D 법선 원형 군집, A-5′) — 면수 개수는 참고 강등 | 184만 4/4(오차 ~6°)·185/60098 0~1모드 |
| 4 | 유효성 | 405 수리본 유효 조립 수 | 7/6 (무효는 302 계열 지배) |
| 5 | 청소 | 개수 ≤ S0×2 · rend_dist mean ≤ 0.5 | 유일 통과(55.8/59.0만·0.315/0.299) |

- **형상 각주(07-11 김휘영 지적)**: RMS는 평판화에 구조적으로 관대 — 박공을 중간 높이 평판으로 만들면 오차가 진폭의 절반 안쪽에 깔려 "파국 아님"으로 살아남을 수 있고, 능선을 세우다 어긋난 모델보다 점수가 좋게 나올 수 있다. CityGML 생성 관점에선 후자가 낫다. → 읽기 규칙: **"RMS 좋고 경사 모드 0"은 성공으로 세지 않는다.** 면수 개수 일치는 잣대로 부적합(LiDAR 조립도 184=7↔참조4·202=4↔2로 어긋남).
- 청소 각주: 논문 보고에서는 "방법 건전성" 절(주장 축 아님). 실험 운영에서는 유지 — E5 진단에서 떠다니는 점이 정확도 오염의 주범이었으므로 함부로 뺄 항목 아님. 지위 변경은 §5-D 판정으로만.
- 서술 규칙: "청소-형성 양립"(장면 수준: 55.9만 개 세계에서도 표면 얇음)과 "0.05의 생존 학살"(붕괴 3동 국소)은 재는 대상이 다르다 — 병기할 때 반드시 이 구분을 명시.

### 2.2 합격 조건의 규칙 — 기준 미끄러짐 방지 잠금 3

1. 실험별 합격 조건 = 5축 중 "이번 실험이 움직이겠다고 설계된 줄"의 부분집합 + 문턱. **결과를 보기 전에 발주문에 잠근다**(사후 변경 금지).
2. 5축 전 과목 채점·보고는 어떤 실험에서도 생략하지 않는다(불리한 줄을 안 재는 회피 차단).
3. **최종 채택(전수 진출 구성·논문 대표 구성)의 잣대는 전 과목** — 실험별 합격은 계단 한 칸의 당락일 뿐, 전 과목 통과라는 최종 지향의 대체물이 아니다.

- 이 틀로 과거를 다시 쓰면: S1~S2p의 질문은 "의미 없이 기초가 되는가"였으므로 합격 조건이 사실상 전 과목(파레토 4항)이었던 것이 정합. S3의 질문은 "의미가 침묵 영역을 여는가"이므로 합격 조건은 §5-C의 두 줄로 좁히고, 나머지는 관찰로 계속 찍는다.

## 3. 세 기준 점검 (현재까지 전체 — 07-11 밤)

- **정합**: 사슬(E5 진단→S1→corrected→완성판→S2→S2p)은 논문 전제 2(표면 기계 켜기·레버 귀속)에 충실. 의미 레버를 S3까지 아껴둔 것 = delta 격리 설계 그대로. 07-11 재정밀화 = 사전등록 문면으로의 복귀(새 기준 아님). 플래그 3: ① 청소 지위 재서술은 §5-D로 정식화 전까지 변경 아님 ② "의미 영역 내 씨딩" 후보는 무모델 원칙 심사 미결 ③ **S3 조건부 진입 = 원 설계("기초 확보 후 S3")로부터의 의도된 이탈** — 재서술: 현재 가진 부품·조절값만으로는 기초가 안 나옴이 4라운드로 확인(07-11 김휘영 동의), 남은 병(생존·미형성·모양)의 남은 치료제 후보가 의미뿐이라면 **의미는 기초의 마지막 부품 후보** — 기초 만들기와 delta 시험이 S3 한 실험에 합쳐지고, 귀속 흐림의 대가는 관문·합격 조건 사전 잠금·base 명시로 관리. 진입 시 이 이탈을 발주문에 명기.
- **건너뜀**: 실행·검수에는 없음(S2p 검수 §6). 위험이던 "오늘 산출이 대화로만 존재"는 본 문서로 해소. 대기 목록(놓치면 건너뜀이 되는 것): 법선 채점 다중뷰화+미측정 건물(185 포함) 채움 · 무늬없음 3채 씨앗 재고 조사 · 의미 라벨 관문 · 연속 빗나감 카운트 기입(§5-H) · 파도 커밋 3개 해시 확인(다음 pull) · 지도교수와 승리 조건 문면 정렬 · 부속 게이트 2종 판정(§5-F).
- **모순**: ① S3 성공선 이중성(승부처가 열려도 파레토로는 "fail"로 찍히는 엇박자) → §2.2 구조로 해소, 정식화는 §5-C·D ② C001 심층의 중단 규칙 공백 → §5-E의 상정 규칙으로 해소(진행 자동 아님·상정만 자동·판단은 실험 결과 기반 — 07-11 방향 동의) ③ 양립/학살 서술 충돌 → §2.1 서술 규칙로 해소. 해소 완료 기록: 원 S1 프런티어 vs 꺼진 기계(성적표/방법 정체성 구분) · 법선 청소 몫(P-H) · 면수(잣대 교체) · textured 우위(체계/국소 구분).

## 4. S3 실험의 뼈대 (판정 후 설계 문서에서 상세화)

- **Track 0 — 관문(학습 0·반나절)**: ① 의미 라벨 품질 — 무늬없음 3채+핵심 6동에서 라벨이 지붕을 한 영역으로 잡는지(뷰별·IoU·경계 정합), **기각 분기 사전 잠금** ② 씨앗 재고 — 무늬없음 3채의 SfM 씨앗·초기 가우시안 수(0에 가까우면 의미-유도 깊이가 잡을 재료 자체가 없음 → 씨딩 보강책은 별도 원칙 심사·판정) ③ 법선 채점 다중뷰화+미측정 채움 ④ (§5-F 채택 시) 1k 게이트 2종.
- **Track A — 본 학습**: base(§5-G) + 의미-유도 깊이(마스크 영역 내 Pearson 상관·경계 마스킹) + 경계 법선(ω_nb≈0.01) · 2런 · 시계열·densify 기록 유지 · 인접 대조 = S3↔base 한 쌍(의미 몫 격리).
- 예측 잠금 후보: P-I 1k 게이트에서 의미-유도 깊이가 무늬없음 픽셀에 실기울기를 공급(학습 전 수치 확인 가능) / P-J 씨앗 있는 채에서 형성 신호 / P-K 경계 법선으로 185 또는 60098 경사 모드 회복 / P-L 씨앗 0인 채는 무반응(다음 레버 = 씨딩·원칙 심사행).
- 소요(순조 시): 관문 반나절 + 본 학습·채점 밤샘 1회 + 검수 반나절. long pole = 신규 손실 2종의 구현 신뢰성(새 부품 첫 판 감사 전력 — 주관 확률 ~50%로 +1~2일).
