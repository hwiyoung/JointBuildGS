## 3. 잠긴 관전 4항 판독 — 본점(240, 0.005)의 4907202

**① 5k~30k 시계열 재료 생존**: **생존 실패 — 아예 못 태어났다.** 본점은 5k(씨앗 보호 해제 시점)에 지붕 상공 재료가 **2개**뿐(다른 셀: reuse 416·(240,0.05) 280·(100,0.005) 31), 10k에 0개, 20k부터 32개의 초저불투명(0.0039) 유령 구름만 남는다. corrected 계열의 "5k에 생겼다가 소실"보다 더 나쁜, "형성 자체가 안 됨" 패턴.

**② 최종 z — 567 복귀 vs 601 이동**: **어느 쪽도 아니고 셋 다 나쁜 쪽.** 셀별 최종(30k) 지붕 상공: 본점 z 580(+13 m, 유령 32개) / (100,0.005) z 609(+42 m, 시트대, 465개, 불투명 0.004) / (240,0.05) **z 662(+95 m, 고불투명 0.98, 74개)**. 제자리(567) 복귀는 0셀. 특히 (240,0.05)는 5k에 z 567.4 제자리 280개가 있다가 10k에 z 659로 점프 — **corrected(+35~38 m)보다 더 높이 끌려 올라갔다**. 강도 100→240에서 이동 고도 609→662로 상승 = **강도를 올릴수록 오응집이 강해진다**. 잠근 판독문 적용: **"+35 m 강화" 쪽 = 위치 신호 부재(도구 부재)**.

**③ 조립 + raw 0.56 m 대비 정확도**: **비교 불능 — 4셀 전부 미조립.** 본점 readout: 필터 전 166점 → 다시점 문턱 14 → SOR 1 → footprint 1점 → `no_points`. (원 S1: 641→437→342→18,485점, 조립 success 0.39 m ≤ raw 0.56 m.)

## 5. 예측 밖 관찰 (새 재료 4건)

1. **강도와 이동 고도의 단조 관계**: w100 → z 609 / w240 → z 662(4907202). 4908178도 (240,0.05)에서 일시 667~669까지 감. 오응집 고도가 기존 시트대(595~615)를 넘는 **660 m대 신층**인데, A-2 전역 z 히스토그램은 corrected 계열 ckpt만 대상이라 **factor 셀의 전역 분포는 미산출** — 660대가 전역 층인지 이 건물 국소 기둥인지 못 가른다(후속 학습0 후보).
2. **prune 완화 셀들의 5k 역설**: 보호 구간이 같은데 5k 시점 지붕 재료가 (0.005) 셀들에서 오히려 적다(31·2개 vs (0.05) 셀 416·280개). 걸러내기 문턱이 densify 예산 배분과 상호작용하는 것으로 보이나 원인 미상 — 관찰만 기록(단정 금지).
3. **시트 재료가 미조립 건물을 "조립"시킴**: (240,0.05)의 has 11·유효 7에는 45 m급 2동이 들어 있음(§2). 유효성·조립 개수가 정확도 없이 움직이는 신규 경로.
4. **오염형 2동(60098·4907186)의 개선은 4셀에서도 유지**(60098: S1 5.72 → 4.04~5.77 / 4907186: 12.66 → 5.57~5.91, 단 (100,0.005)에서 미조립 플립 1회 = 런 요동 G9 범위) — corrected 동역학의 순기능(청소·응집)은 재확인. Track C 생략으로 발주가 요구한 "오염형 관찰"이 빠졌지만 데이터에서 이렇게 확인된다.

## 6. B-0 판정(대기 중인 플래그 1)에 딸린 보강 재료

- 중간검수 플래그 그대로: 발주 문면 게이트는 "기여율(손실 비중) >40%"인데 실행은 **기울기 노름 비중**으로 480을 떨어뜨림. **손실 비중 기준이면 480(0.305)도 통과권이었다** — 척도 치환이 채택값(240 vs 480)을 실제로 갈랐다.
- **새 재료**: 본 런 30k에서 240 셀들의 기울기 비중 max가 **0.57(본점)·0.65(240,0.05)** — 프리뷰에서 480을 떨어뜨린 0.40 문턱을 **240 본 런도 넘었다**(w100은 0.29로 안전). 즉 프리뷰 1k iter의 구분(240 안전/480 위험)이 30k 동역학에서 유지되지 않음 — 게이트의 변별력 자체가 약하다는 증거.
- 판정에 걸리는 것: ①번 판정(240 채택 인정)은 이제 "형식 승인"을 넘어 **"의도 강도(등가 100=w480)가 미시험으로 남아 있음"**의 처리 문제. 다만 **강도 100→240에서 오응집이 단조 악화**(z 609→662)했으므로, 480이 결과를 뒤집을 것이라 기대할 근거는 관찰상 없다(480 config 2종은 생성돼 있어 원하면 ~2.2 h로 확인 가능).

## 8. 분기표 적용·회부 (판정은 김휘영)

**분기표(잠금) 적용**: "통과 셀 없음 + 오응집 강화(4907202 상방 유지·강화)" 행 = **위치 신호 부재 확증 → S2 합침(법선+위치 신호: depth 감쇠 바닥 상향 또는 mono-depth) 회부**. A-5 법선 판독(무늬없음 3채 good 2·borderline 1)로 "A-5 불가" 행은 닫힘 — S2 전제 유지.

**판정 대기 5건**:

1. **B-0 240 채택 인정 여부** (기존 플래그 1 + §6 보강) — 인정 시 이번 결과를 강도 21↔50 요인으로 확정 기록. 불인정 시 480 2셀 추가 실행(~2.2 h, config 존재)이 남은 수단 — 단 §6의 단조 악화 관찰상 결론 반전 기대는 낮음.
2. **defect 법선 재판독 여부** (기존 플래그 2) — bad 3건(60098 42.5°·4907186 44.3°·4907188 32.9°) 중 앞 2건은 크롭 구도 교란 의심. S2 발주에 "뷰 재선정 재판독" 한 항목으로 끼울지. (무늬없음 3채 판독은 구도 정상 — S2 포크 입력으로 그대로 사용 가능.)
3. **분류 용어 개정안 확정** — 상위 4(양쪽 성공 6 / GS만 실패 5 / 입력 한계 5 / 본질 난이 2) + 하위 괄호 병기, 잣대 각주("영상 계열 하나라도 성공", GS 성패 S1 시점 고정), 소급 편집 없음 + **대장 부록 대조표 추가**(이번 최종 검수 회차에 하기로 했던 것). 이번 문서는 잠정적으로 기존 표기(무늬 6동=정상 6동)를 썼음.
4. **Track C 생략 인정** — 사실관계는 타당(① 전멸로 파레토 승자 없음). "최다 충족" 부분점수 해석(그 경우 reuse가 2항으로 최다)을 쓰지 않은 실행 선택을 소급 승인할지. 승인 시 "이긴 셀 3 arm 확장+2런째"는 소멸(어차피 확장 가치 없음).

## 9. 스스로 반박

1. **"위치 신호 부재" 판독의 한계**: 강도 2점(100·240)·1런씩의 관찰이다. 런 요동(G9 실측: 조립 플립 2~3동·RMS ±1~2 m)이 있으므로 "단조 악화"는 2점 추세일 뿐 확정 기울기가 아니다. 다만 corrected 원 런·재실행에서 같은 상방 이동이 재현된 바 있어(602.6/605.2) 방향 자체는 세 번째 재현이다.
2. **본점 5k 2개(형성 실패)는 별개 병리일 수 있다**: "이동"이 아니라 "미형성"이면 위치 신호 부재보다 densify/prune 상호작용(§5-2) 쪽 설명이 맞을 수 있다. 어느 쪽이든 S1 도구상자 안에서 답이 안 나왔다는 결론은 같다.
3. **③ 미산출이 채점을 바꿀 가능성**: 없음 — ①이 전 셀 확정 탈락이라 ③이 만점이어도 통과 셀 0. 단 "청소가 됐는지"의 서사(플로터 층이 줄었는지)는 이번 회신으로 답할 수 없게 됐다.
4. **G11**: C001 최악 구역 — 크기의 일반화 유보 유지.
