## 1. 주장 경계 재잠금

- S3-A = **정답급 라벨 + 정답급 인스턴스 주소(class+instance oracle) 조건의 기제 상한 시험**.
- 합격선 충족은 기제 성립(상한)이며 승부처 승리가 아니다. 영상·2D FM 유래 의미의 본 주장은 S3-B에서만 판독한다.
- raycast building ID는 오직 **손실 주소 `R`**(어느 픽셀이 어느 건물 영역인지)를 결정한다.
- ID에서 깊이·높이·평면 파라미터·절대 눈금을 가져오는 것은 금지한다. 높이 눈금은 기존 `L_depth`의 유효 영상 점군 감독에서만 온다.
- **S3-B에서는 정답 building-ID 주소를 사용하지 않는다.** FM 선정·인스턴스 정책은 별도 원칙 심사 발주로 재잠근다.

## 2. 정답ID 지도·영역 규격

- 주소 ID 지도는 고정 class mask의 실제 생성 계보인 `ζ=48.0 m`, `shift_z=556.0 m`로 raycast해 맞춘다.
- 공식 `ζ=45.7 m`, `shift_z=558.3 m`는 audit-only로 유지하고 `S3A-T0-DATUM-001`은 open 상태로 둔다.
- class-1 roof mask ∩ raycast building ID로 건물별 `R`을 만든다. 하나의 건물 `R`에서만 8-연결 성분을 만들고 256 px 미만은 제외한다.
- 인스턴스 경계 절단선 양쪽 7 px를 `L_smooth`·`L_plane`에서 제외한다.
- `L_nb`는 고정 class mask의 roof↔non-roof 경계 5 px 밴드만 쓴다. 정답 ID 절단선은 `L_nb`에 쓰지 않는다.
- 영역↔건물 매핑·원 class 성분의 건물 ID 겹침 수·절단 픽셀 수를 audit에 남긴다.
- 3뷰 발자국 투영 smoke 표는 **정답ID 대비 발자국 규칙의 결손 기록**으로 보존하고 S3-B 주소 델타 기준으로 쓴다.

## 3. P-J / P-L 사전 분류 잠금

- 1k gate audit에서 무늬없음 3동의 가시 뷰별 `alpha>=0.5 AND L_depth valid` 픽셀 수를 측정한다.
- 건물값 = 가시 뷰 측정값의 중앙값.
- 건물값 `>=64 px` = **P-J 재료 형성 예측 대상**, `<64 px` = **P-L 씨앗 부재 갈래 관찰 대상**.
- `32..128 px`은 규칙대로 분류하되 `boundary_case=true`를 병기한다. gate 커밋 후 분류를 바꾸지 않는다.
- `4907202`·`4908168`·`4908178`은 P-J 대상으로 사전 확정한다.

## 4. 구현 확인 5건

1. `L_smooth` 5점 ∇² 창은 중앙+상하좌우 전체가 같은 positive region이고 cutline이 아니며 finite depth/α이고 `alpha>=0.5`일 때만 쓴다(`src/stage2/loss/semantic_guided.py:264-270,289-307`). v2의 “무효 쌍 제외”보다 보수적인 구현으로 승인한다.
2. **edge-aware=OFF 확인.** `semantic_guided.py:308-314`의 RGB/영상 기울기 없는 비가중 5점 `lap=N+S+W+E-4C`이다.
3. AlignGS Eq. (4)는 **이미지 전역 `I\M`에서 한 번 계산하는 Pearson**(영역별 아님)이고, Eq. (6)은 의미 경계를 가로지르는 인접 픽셀쌍의 두 렌더 법선을 발산시킨다. 우리 `L_nb`는 class 경계 5 px 밴드에서 렌더 법선을 고정 Omnidata 법선에 `1-|dot|`로 정합하는 다른 꼴이다(`semantic_guided.py:571-582`).
4. **동일 픽셀 집합 확인.** 0048뷰 component 4·초기 3D점 전파 집합·최근접 규칙의 `108247349` 오배정 집합·legacy48 정답ID의 `4907199` 집합은 모두 같은 2,402 px이다. pairwise XOR=0, flat-index SHA256=`4b9e02a34d6e8c2135f946a67b73db14a7c1ed182c83bc6634c77b78b3074428`.
5. T0-1 영문 overlay gallery를 gate 전 1순위로 생성하고, 무늬없음 3동이 각각 3뷰 이상에서 실제 지붕 class mask로 덮이는지 정성 QA한다.
