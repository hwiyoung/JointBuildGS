## Track A — 학습 0 선행 (본 학습과 병렬 · 완료 즉시 개별 커밋+한 줄 보고 · 18:00 체크포인트까지 전부 도착 목표)

**A-1. 단안 깊이 사전 검증 (Arm 3의 관문).** ① 런타임: Depth Anything V2 우선(대안 Omnidata depth) — 설치 실패 시 issues 기록 후 **Arm 3 제외**하고 진행(전체 비차단). ② C001 이미지에 깊이 추론 → 이미지별 정렬: 영상 점군(MVS) 깊이 유효 픽셀에 최소제곱으로 축척 a·원점 b 적합 → 미터화 깊이 지도 저장(Arm 3 입력, 전처리 1회 고정). ③ 측정 4종(전부 CSV+그림): (a) 정렬 잔차(유효 픽셀 중앙·p90, 이미지별) (b) **휨 진폭** — 잔차를 화면 좌표의 저차 곡면(평면·2차)으로 적합해 이미지당 진폭(m) (c) **지붕 직접 채점** — 양쪽 성공 6동+무늬없음·관측됨 3채+GS만 실패 5동의 참조 LoD2 지붕면을 이미지에 투영, "정렬된 단안 깊이가 이 지붕을 놓는 높이 오차" 건물별 표(대조군=양쪽 성공 6동 분포 공개) (d) 건물 분해능 — 윤곽 깊이 단차 vs 참조 높이 상관. ④ **분기(잠정 문턱 3 m/8 m — 채택은 18:00 중간점검에서 김휘영이 대조군 분포 보고 최종 잠금)**: 지붕 채점 중앙 ≤3 m → Arm 3 그대로 / 3~8 m·구조적(휨) → 완화 사다리 칸 제안 보고(1 조기 한정 스케줄: 절도 창구 5k~10k에 세게·이후 감쇠 / 2 국소(타일) 정렬 / 3 휨 빼기(저차 곡면 보정) / 4 절대항↓+기울기 위주) / >8 m·비구조 → Arm 3 제외 제안. **판정 전 임의 채택 금지 — 체크포인트 보고에 분기 제안만.**

**A-2. 공중 막 정체 확인.** corrected·S1 완성판 ckpt에서 막 대역(595~615·655~670) 가우시안 추출 → ① 막 고도 vs **카메라 비행 고도 분포**(포즈 z) 대조 — "카메라 근처 플로터인가"의 직접 재료 ② 막 가우시안의 시점 일관성(비행 스트립 안/사이 기여 프로파일) ③ 수평 슬라이스+고도 히스토 그림. 관찰만(2선 도구 채택은 분기표 경유).

**A-3. 구현 확인 4건(한 줄씩 보고).** ① 길쭉이 필터 설정값(config 값·적용 시점) ② 법선 렌더 경로 확인 + 단안 법선 손실 꼴 구현(DN-Splatter식: 렌더 법선 vs 단안 법선, absdot 각도 기반; 코드 신설은 브랜치) ③ 깊이 감쇠 스케줄 코드 확인 + 바닥 구현(유효 가중 = max(스케줄값, 바닥)) ④ 점군화 단계 개수의 단위 정의 한 줄(pre/minobs/sor vs fp pts — 중간검수 미답 항목 청산).

**A-4. GS만 실패 5동 법선 재판독(뷰 재선정).** 60098·4907186·4907188은 크롭 구도 교란 의심(도로·차량·프레임 모서리) — 지붕이 크롭 중앙에 오는 뷰로 재선정 후 A-5 잠금 기준(<15°/15~30°/>30°) 재채점, before/after 표 + 크롭 그림.

**A-5. 채점 확장 준비(③ 결손 재발 방지).** 전 arm 채점에 의무 포함될 세 산출 코드 준비: ① rend_dist mean(붕괴뷰 proxy, 재점검과 동일 방식) ② arm별 전체 가우시안 개수(S0 대비 배율) ③ **전역 z 히스토그램**(공중 막 크기 추적 — S1 완성판 결손 메움).

## Track B — 게이트 + 본 학습 (dense · C001 18동 · seed 2001 · 30k · ckpt 5k)

**B-0'. 새 손실 게이트(짧은 런 1,000 iter).** Arm 1 config로 법선 손실 게이트: 총손실 유한·return 0 + **게이트 척도 = 항별 기울기 노름 비중(문면 확정 — S1 완성판 플래그 1의 교훈): >40% 지배 시 가중 절반(0.05→0.025)으로 1회 재게이트, 그래도 초과면 중단·보고.** 손실 비중·기울기 비중 둘 다 CSV 기록(loss_grad_norms 방식 유지). Arm 3의 단안 깊이 손실도 A-1 통과 시 동일 게이트. 결과 CSV·보고 먼저 기록 후 본 런 자동 진행.

**B-1. 본 런 — 누적 사슬 4 arm × 2런(같은 config 재실행).** 공통 base: 표면 모으기 **w=100**(scene_scale_sq 정규화 유지·등가 21) · 걸러내기 **0.005** · 씨앗 보호 5000 · final prune 없음 · depth 0.5 감쇠(Arm 2부터 바닥) · 길쭉이 필터 불변 · 법선 가중 0.05(게이트 조정치).

| arm | 구성 | 격리하는 질문 | 실행 순서 |
|---|---|---|---|
| Arm 1 | base + 단안 법선 | 법선 단독의 몫 | 1번째 |
| Arm 2 | Arm 1 + 깊이 감쇠 바닥 0.15 | 위치 신호 수명 연장의 몫 | 2번째 |
| Arm 0 | Arm 1에서 모으기만 0 | 표면 모으기 자체가 해악인가(대조) | 3번째 |
| Arm 3 | Arm 2 + 단안 깊이(분담·A-1 조건부) | 무늬 무관 위치 신호의 몫 | **4번째(중간점검 반영)** |

- 단안 깊이 적용(Arm 3): 영상 점군 깊이 유효 픽셀 **밖에서만**(픽셀 분담), 가중 0.05(게이트), 스케줄은 A-1 분기 칸(중간점검 잠금) — 기본은 상시, 조기 한정 칸 채택 시 5k~10k 강·이후 감쇠.
- **시계열 추적(전 arm)**: 5k 스냅샷으로 핵심 4동(4907202·4908168·4908178·4907184) footprint 상공 개수·z_p50·z_std·불투명도 — 잠긴 관전 = "Arm 3에서 4907202가 5k 생존 → 10k 제 높이(z≈567) 정착하는가".

**B-2. 채점(405 수리본 파이프라인 통일).** 정본 base 점군화(GS-의미 점군화·minobs3·voxel0.05·SORstd2) → 조립 → 8-way. **파레토 4항 v2.2 채점표를 arm×항 표로 필수 산출**: ① 가드레일 = 양쪽 성공 6동 조립 + ≥5/6 raw+0.5 m ② 정확도 비퇴행 = 원 S1 대비 짝 중앙 ≤+0.3 m·파국(+1.5 m 초과 악화) 없음 ③ 청소 개선 = **개수 ≤S0×2 · rend_dist mean ≤0.5 — 이번 산출 의무(A-5 코드)** ④ 유효성 비퇴행 = 수리본 dense 유효-조립 ≥ 원 S1(10). **+ 신설 관찰(게이트 아님)**: 박공 2모드 회복·면수 vs 참조(G7) · 무늬없음·관측됨 3채 상태 · 전역 z 히스토그램(공중 막 크기, arm 대조) · 인접 arm 대조표(0↔1 모으기 / 1↔2 바닥 / 2↔3 단안 — 레버별 몫). 띠 그림: 핵심 4동 × 4 arm(가우시안 사시+정측면·렌더·점군화 단계·모델 vs 참조 — S1 완성판 규격).

**사전 예측(잠금).** P-A: Arm 0 = 지붕 생존(조립 5~6/6)·청소 지표(개수·rend_dist) 미달. P-B: Arm 1 = 방향 지표 개선·높이 절도 미해결(202/168/178 미회복). P-C: Arm 2 = 말기 표류형(178류) 회복·조기 절도형(202) 불확실 — 부분 회복. P-D: Arm 3 = 최다 회복, **양쪽 성공 6동 6/6 복귀가 성공선**; (iii)이 (ii)보다 6동 퇴행이면 단안 기각. P-E(갈림길): Arm 3에서 4907202가 5k 생존+제 높이 정착이면 "위치 신호 작동" 확증 / Arm 3에서도 공중 막행이면 "신호 부족 아닌 다른 기제" → 공중 막 제어(2선) 회부. **맥락: 사전 예측 2연속 빗나간 상태의 3번째 잠금 — 크게 빗나가면 재프레임 논의가 기본 안건.**
