# W_E5_C001 S3-A 의미-유도 기하 정책화

> **판정 0 · 관찰 자료.** 판정자는 김휘영이다. 정본 S0–S2p 산출물은 변경하지 않는다.
> 본 파도는 **S3-A = 참조 LoD2 레이캐스트 clean label을 쓰는 정답급 라벨 기제 상한 시험**이다.
> 결과가 답하는 범위는 “라벨이 정확할 때 의미-유도 평활·평면이 침묵 영역 기하를 세울 수 있는가”의 상한에 한정된다. FM 라벨·무모델 논문 본 주장은 별도 S3-B에서만 판독한다.

## 0. 사전 잠금

- 진입: T0-1은 자기일치 참고 측정이며 관문이 아니다. Track A 진입은 **T0-2 완료 + T0-4 1k 게이트 통과**로 잠근다.
- base: Arm 1′ 그대로(`w_distort=100`, `w_normal=0.05`, `w_nc=0.05`, `prune_opa=0.05`, final prune 없음, seed 2001, 30k, dense C001 18동).
- S3 delta: `0.25·L_smooth + 0.25·L_plane + 0.01·L_nb`, 첫 투입 iter 1,500. 단안 깊이는 0이다.
- 1k 게이트: iter 0–2,499 프로브의 1,500–2,499 = 신규 손실 1,000 active update. 총손실 유한 + 결합 `L_semdepth`·`L_nb` 각 기울기 노름 비중 `<=0.40`.
- 초과 시 해당 가중만 절반 1회 재게이트한다. `L_semdepth`는 항 1·2를 비례 절반한다. 두 번째도 초과하면 해당 손실을 제외하고 Track A를 보류한다.
- 본 셀은 동일 seed·config의 비결정성 반복 2런. 합격선 (i)·(ii)는 **두 런 모두** 충족해야 충족이다.
- 패스를 자동 판정하지 않는다. 아래 표의 기계적 `pass/fail/pending`은 김휘영 판정의 재료다.

### T0-4 신규 손실 구현·1k 게이트
