## 2. `roof_share` 수식·공통 roof audit scope

항 집합은

`T = {pho, dep, nrm, nc, str.na, str.cp, plane}`

로 고정한다. 모든 arm에서 roof audit scope는 **같은 입력 유래 projected-footprint
mask**다. 이 mask의 투영 높이는 SfM/MVS에서만 산출하며 ④a vision mask 또는 ④b
LoD2-GT mask로 바꾸지 않는다.

- `W_t = abs(weighted_t)`
- `share_t = W_t / sum(j in T, W_j)`
- `W_t,roof = abs(weighted_t를 공통 roof audit scope에서 재계산한 값)`
- `roof_share_t = W_t,roof / sum(j in T, W_j,roof)`

분모가 0이면 해당 행의 share를 모두 0으로 기록하고 NaN을 쓰지 않는다. pixel 항은
공통 mask에서 재계산한다. `str.na/cp`는 같은 footprint XY union 안의 primitive만 audit
대상으로 한다. 공개 `nrm` 행은 MVS normal과 15° gate를 통과한 Omnidata auxiliary의
weighted 합이며, 내부 detail log에서는 두 소항을 분리한다.

④ strong-arm 등가점 검사는 같은 scope의
`W_plane,roof / W_pho,roof`로 수행한다. 공통 분모이므로 `roof_share_plane /
roof_share_pho`와 같다.

## 3. ③ soft에서 `global`의 정확한 의미

`global`은 **segmentation/instance address 없이 모든 유효 image location에 동일한 local
rendered-depth plane rule을 적용**한다는 뜻이다. 확장 AOI 전체나 한 건물 전체에 평면
하나를 맞추지 않는다.

- gsplat 2DGS의 alpha-normalized/unbiased plane-intersection rendered depth를
  camera-coordinate local window로 back-project한다.
- plane fit은 detached point로 수행하고 residual만 rendered depth에 미분한다.
- 점-평면 residual의 집계는 L1로 고정한다.
- alpha·공통 valid mask와 최소 점 수를 적용한다.
- 고정된 depth-discontinuity range를 넘는 window는 서로 다른 면을 한 평면으로
  압착하지 않도록 제외한다.
- semantic·instance·LoD2-GT region 입력은 받지 않는다.

gsplat 2DGS는 out-of-plane thickness를 이미 고정하므로 PGSR의 minimum-scale
flattening을 가중 loss 또는 개선 성과로 계산하지 않는다. thickness는
`audit_2dgs_flattening_invariant`의 통과/실패만 기록하고 `plane` loss·share 분자에는
포함하지 않는다.

## 4. ④ medium weight의 forward-only 사전 보정

`w_plane`은 optimizer 첫 step 전에 한 번만 산출하고 resolved config에 숫자로 잠근다.

1. 고정된 calibration view 명단을 eval/no-grad로 forward한다.
2. ④a의 비-GT vision mask에서 `weighted roof photo`와 `raw roof plane`을 모은다.
3. 목표 ratio 1.0으로 `w_plane = weighted_roof_photo / raw_roof_plane`을 계산한다.
4. 이 단일 숫자를 ④a와 ④b 두 seed 모두에 그대로 사용한다.
5. 첫 optimizer step 이후 재보정·EMA·자동 조절을 금지한다.

④b mask나 GT 지표로 ④a의 weight를 정하지 않는다. 고정 weight를 적용한 사전
forward에서 ④a 또는 ④b가 필수 범위 0.5×~2×를 벗어나면 자동으로 arm별 weight를
바꾸지 않고 관문을 중지하여 잠금 개정을 요청한다. 이로써 ④a↔④b는 segmentation
source만 다른 통제쌍을 유지한다.

### 4.1 ③ soft 세기와 calibration view 잠금

원 발주문은 ④ medium의 등가점 범위만 수치화했으므로, 실행 전에 ③의 `soft < medium`을
재현 가능한 수치 규칙으로 보완한다. ③도 optimizer 첫 step 전 forward-only로
`w_plane`을 산출하되, 공통 projected-footprint roof audit mask에서
`weighted plane / weighted photo = 0.25`를 목표로 한다. 이는 medium 필수 범위의 하한
0.5보다 낮다. ③의 학습 plane 영역 자체는 계속 segmentation-free global-local rule이며,
footprint는 weight 산출·audit scope에만 쓴다. 산출한 ③ 숫자는 두 seed에 공용한다.

calibration은 projected-footprint mask inventory 481개를 filename 정렬하고 매 10번째
(0-origin index `% 10 == 9`) eval view를 뺀 뒤,
`SHA256(selection_sha256 + "|" + view_id)` 오름차순 앞 16개를 쓴다. 정확 명단·집계식·
입력 SHA·③ 목표 0.25·④ 목표 1.0은
`phases/p2-gsjso/configs/pilot_1wave_calibration_lock.json`에 기계 판독 형태로 잠근다.
eligible view가 8개 미만이거나 raw plane 합이 0이면 optimizer를 시작하지 않는다.

기본 기하 가중도 같은 lock에 D 레시피 계보대로 고정한다: `pho=1`, `dep=0.1`,
MVS `nrm=0.15`, gated Omnidata auxiliary `0.05`, `nc=0.05`,
`str=0.08(na=1, cp=1)`. depth/normal은 5k warmup+5k ramp, structure는 15k부터다.
semantic·mutual·MVC·distortion과 미등록 손실은 0이다.

④a·④b의 plane-guided initialization도 같은 lock에 결과 전 고정한다. 각 조건의 mask와
MVS depth/world-normal의 교집합을 `stride=8 px, offset=4 px` 고정 격자로 표본화하고,
MVS dense seed마다 반경 `0.5 m` 안 최근접 최대 4개 normal의 평균을 쓴다. query는
100,000개 chunk·single-worker cKDTree로 결정론적으로 수행한다. 전체 dense seed의 5%보다
적게 매칭되거나 0 evidence/0 match이면 시작하지 않는다. 미매칭 seed는 +Z를 유지한다.
fresh run에서만 optimizer 생성 전에 quaternion을 초기화하고, resume에서는 입력 binding을
재계산·검증하되 checkpoint quaternion을 덮어쓰지 않는다.

## 6. ④a vision fusion·항공 실패 fallback

각 view에서 projected footprint와 GroundedSAM 후보를 다음과 같이 결합한다.

```text
roof_mask =
  (cross_view_consistent_sam ∩ dilate(projected_footprint, 5 px))
  ∪ erode(projected_footprint, core_px)
```

- 기본 `core_px=5`다.
- 소형 건물에서 5 px erosion core가 empty면 정확히 1 px erosion으로 한 번 대체한다.
- SAM 후보가 없거나 cross-view consistency를 통과한 후보가 없어도 core는 유지하고
  `core_only_fallback=true`를 기록한다.
- view별로 `sam_candidate_present`,
  `cross_view_consistent_candidate_present`, `core_erosion_px_used`,
  `core_only_fallback`을 저장한다.
- mask 선택·fusion에는 GT를 사용하지 않는다. projected footprint 높이도 SfM/MVS
  유래만 허용한다.

`cross_view_consistent_sam`은 별도 producer lock에서 다음 숫자로 고정한다.

- source view를 포함한 최소 지지 view 수 `2`, 즉 다른 유효 view가 최소 1개 필요하다.
- source당 pose-neighbor는 camera-centre 거리 오름차순으로 최대 `4`개다. optical-axis
  중앙각은 `20°` 이하, camera baseline은 `0.5 m` 이상이어야 한다.
- source MVS depth로 pixel centre를 3D 역투영하고 고정 COLMAP pose로 target에
  재투영한다. target 후보 mask의 허용오차는 닫힌 원판 반경 `3 px`다.
- target MVS depth의 occlusion/consistency 허용차는
  `max(0.5 m, 0.02 × |projected depth|)`이며 절대 depth 차가 그 이하여야 한다.
- 유효 neighbor가 없으면 SAM candidate는 불일치로 처리하고 footprint core fallback만
  유지한다.

수치 선택 이유는 다음과 같다. 최소 2-view는 단일-view vision 오검출을 그대로
통과시키지 않는 가장 약한 일관성 조건이다. 최대 4-view는 장면당 계산을 제한하면서
항공 스트립의 인접 중복 관측을 여러 방향에서 사용할 수 있는 상한이다. `20°`는 나디르
인접 pose를 유지하되 큰 시점차의 MVS depth 재투영을 배제하고, `0.5 m` baseline은 사실상
동일 pose의 자기확인을 막는다. `3 px`는 crop·MVS map 재표본화와 경계 양자화를 흡수하는
국소 허용치다. depth 허용차 `0.5 m/2%`는 근거리의 고정 오차 바닥과 깊이에 비례하는
투영 오차를 함께 제한한다. 이 값들은 GT IoU를 보거나 조정해 정한 값이 아니며, 1파
동안 고정한다.

④a segmentation 품질은 두 단계로 보고한다.

1. **학습 전 비-GT 보고:** footprint overlap, 후보/일관성 통과율, core-only fallback율.
2. **추론 후 score-only:** GT roof mask IoU. GT IoU는 mask 선택·threshold 변경·fusion·
   학습·calibration·해당 1파 재실행의 입력으로 사용하지 않는다.

## 8. mono-normal 15° patch gate 구현 정의

MVS normal은 모든 유효 pixel에서 주 감독으로 계속 사용한다. Omnidata는
별도 auxiliary term이며 아래 gate를 통과한 pixel에서만 추가한다.

- 학습 해상도의 왼쪽 위를 원점으로 한 `16×16 px` non-overlap patch를 쓴다.
- 오른쪽·아래의 불완전 border patch는 제외한다.
- MVS와 Omnidata가 모두 finite·nonzero인 pixel이 `>=64`인 patch만 판정한다.
- pixel 각도는 `acos(clamp(abs(dot(unit_mvs, unit_omnidata)),0,1))`이다.
- patch 중앙값은 유효 pixel 각도의 `torch.median`으로 고정한다. 유효
  pixel 수가 짝수면 lower order statistic을 쓴다.
- 중앙값 `<=15.0°`인 patch의 mutual-valid pixel만 auxiliary loss에 넣는다.
  미통과·유효점 부족 patch는 auxiliary loss와 gradient가 정확히 0이다.

구현은 `src/stage2/mono_normal_gate.py`이며, 9.81° 통과와
18.11°·45.46° 미통과를 Docker unit test로 고정한다. 이 gate는 LoD2·ALS·의미
입력을 받지 않고 MVS primary normal을 대체하지 않는다.
