# 사전등록서 — 품질 축 본선 (iii) 1파: 확장 파일럿·4조합 + 세그 상한

> **승인 잠금판 v4.** 발주문 기준일은 2026-07-21이고, 김휘영의 발신 전 승인은 2026-07-22에 기록했다. 이 문서는 (iii) 1파에 한해 `사전등록서_품질축본선_잠금후보v1.5_20260720.md`의 10동·고정 0.990 파일럿 문구를 대체한다.
>
> **승인된 선택.** ① 확장 명단은 드라이버가 아래 사전 규칙으로 결과 열람 전 확정한다. ② mono-normal은 기존 Omnidata DPT-Hybrid를 사용하고 15° 게이트를 적용한다. ③ 학습은 20,000 iter, 5,000 iter 간격 full-state checkpoint, 2 GPU·9시간 guard로 잠긴다. ④ footprint는 지금까지 C001/E5에서 쓴 동일한 LoD2 `GroundSurface` XY를 공통 표준 입력으로 승계한다.

## 0. 질문·런

확장 파일럿(목표 30 dense-성공동, C001+인접 AOI)에서 짧은 학습으로 ① 표면, ② +사진 통제, ③ +평면 약(PGSR soft), ④a +평면 강(PlanarGS medium·GroundedSAM vision)의 honest 4조합과 ④b LoD2-GT 영역 상한을 각 2런 실행한다. 승자 후보는 ①②③④a만이고, ④b는 세그 상한 참고로만 사용하고 승자 선정에서 배제한다.

- 총 예정: 5조건 x 2 random seeds = 10 scene-runs
- random seeds: r1=`1001`, r2=`1002`
- 짧은 학습: `max_steps=20000`
- 학습런 시작 정의: optimizer step 1을 실행하면 `learning_runs_started` 1 증가
- 실행 ID: `20260721_pilot_1wave`; 실제 시작·종료 UTC/KST는 manifest에 별도 기록

## 1. 확장 파일럿·눈금 선잠금

### 1.1 모집단과 필터

1. canonical 178동을 모집단으로 삼는다.
2. `qs_baseline178` status에서 dense `has_lod22=True`인 건물만 후보로 남긴다.
3. 핵심 10동 `4907184, 4907185, 4907186, 4907188, 4907195, 4907198, 4907202, 4908168, 4908178, 60098`은 모두 포함해야 한다.
4. 선정에 RMS·ALS·LoD2 z·지붕면·의미를 쓰지 않는다.

### 1.2 드라이버 확장 규칙

- 기존 C001 학습 AOI의 EPSG:25832 XY bbox를 시작 영역으로 삼는다.
- bbox를 네 방향으로 같은 거리만큼 등방 확장하여, dense-성공 후보의 footprint centroid가 처음 30개 들어오는 최소 거리를 선택한다.
- 동률이면 `(centroid_distance, building_id)` 오름차순으로 30개를 자른다.
- 채점 대상 30동 명단과 실제 학습 crop AOI bbox를 각각 명시한다. 추가 문맥 buffer에 다른 건물이 들어와도 채점 모수에 합류시키지 않는다.
- `<50 m²` 건물을 포함하고, 전체판과 소형 제외 민감도판을 이중 보고한다.

### 1.3 바-as-rule

확장 30동을 확정한 직후, GS 결과를 열람하기 전 `qs_baseline178`의 동일 건물 dense RMS 중앙을 성공 기준 ⓐ의 눈금으로 계산한다. 명단·AOI·각 건물 dense 수치·중앙·입력 SHA를 `_pilot_set.csv`와 manifest에 선커밋한다. 10동 0.990은 부분집합 재현 검사로만 유지한다.

## 3. 고정 조건

- 입력 점군: 같은 사진의 dense `w2_1` 계열. 건물별 입력 갈아끼우기 금지.
- 조립기: 전 조건·런에 동일한 Roofer canonical recipe와 digest-pinned image. 조립·채점 각 1회.

## 4. 조합 잠금

| 조합 | 지위 | 고정 구성 |
|---|---|---|
| ① 표면 | honest 승자 후보 | `pho` + MVS `dep` L1 + MVS `nrm` + `nc` + `str.na/cp`; mono-normal은 15° 통과 패치에만 보조 |
| ② +사진 통제 | honest 승자 후보 | ① + footprint 밖 photo 이웃 마스킹 + `seed_protect`; 씨앗 opacity 0.10→0.25, 끝까지 보호 |
| ③ +평면 약 | honest 승자 후보 | ② + PGSR형 soft 기하: minimum-scale flattening, rendered-depth unbiased plane fit, global co-planarity L1; segmentation 영역 없음 |
| ④a +평면 강 vision | honest 승자 후보 | ② + PlanarGS형 medium: GroundedSAM roof mask + cross-view + footprint, plane-guided init, flattening, co-planarity |
| ④b +평면 강 GT | 상한·승자 배제 | ④a와 동일하고 roof mask 출처만 LoD2-GT raycast roof class로 교체 |

세기 사다리는 ③ soft < ④a/④b medium으로 고정하며 hard PlanarSplatting arm은 이번 1파에 쓰지 않는다. ④a↔④b는 segmentation 출처 외의 config·seed·random seed·view·손실·조립·채점이 같은 통제쌍이어야 한다.

## 6. 손실 비중 audit

각 런의 iter audit CSV는 `iter, term, raw, weighted, share, roof_share` 필드를 갖고 `pho, dep, nrm, nc, str.na, str.cp, plane`을 분리한다. 최소한 모든 checkpoint iter와 예정된 audit interval에 남긴다.

④a·④b에서 유효한 지붕 영역의 weighted plane/photo 비율이 0.5×~2×인 행이 각 런에 하나 이상 있어야 한다. 해당 행이 없으면 그 런은 조절값 선택 증거로 쓰지 않는다.

## 7. compute·checkpoint guard

- 동시성: GPU 2개, GPU당 학습 1개
- 정상 완료: arm/seed별 20,000 optimizer steps
- checkpoint: 5,000·10,000·15,000·20,000 step에 model + optimizer + scheduler/strategy + RNG + current step을 포함한 full-state 저장
- 경과 8시간 30분: 신규 런 시작 금지
- 경과 9시간: 실행 중 런을 다음 5k checkpoint에서 정상 종료하고 partial로 표시. 즉시 kill이 필요하면 직전 완전 checkpoint만 유효하다.
- partial checkpoint는 부분 수치로 보고할 수 있지만, 20k를 완료하지 않은 런은 승자 규칙의 `2런 재현`에 산입하지 않는다.
- manifest에 condition/seed별 start/end/checkpoint SHA, `learning_runs_started`, guard 발동 시간·사유를 남긴다.

## 8. 성공·승자 규칙

승자는 honest ①②③④a 중 두 런 모두 ⓐ~ⓓ 방향 비악화를 만족한 조건의 2런 최악 RMS 중앙이 최소인 것이다. ④b는 승자 계산에 절대 포함하지 않는다.

- ⓐ RMS 중앙 < 선잠금한 확장 파일럿 dense 중앙
- ⓑ 면수비·유효성·LoD2 중 1개 이상 개선
- ⓒ RMS·Hausdorff·면수비·완전율·유효성·LoD2 전 지표 비열화
- ⓓ 완전율 동별 `>= max(dense, 0.9)`; 민감도 0.8·0.95 병기
- ⓔ 동일 조건 2런 재현

1파 honest 최선 RMS 중앙이 2.0 m에 미달하면 3차 확장을 중단한다. 약형 조기 점검은 파국적 악화·붕괴만 중단 사유로 삼는다.
