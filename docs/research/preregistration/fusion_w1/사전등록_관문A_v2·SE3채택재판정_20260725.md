## 2. 관문 A v2 문안 (잠금)

- **합격선(유지)**: 동별 잔차 중앙 ≤ 0.3 m.
- **관측량(확정)**: 영상 유래 dense DIM/MVS 3D 점군 ↔ 분류 ALS(지붕 class 6·지면 class 2)의 양방향 point-to-plane 잔차. 검색 반경 0.35 m, 조작적 정의는 진단 T1(`W_관문A진단_20260725.md`)을 그대로 계승한다. 원 §2의 뷰별 "ALS 지붕 경계 ↔ 영상 에지" 잔차와 **동일시하지 않는다**.
  - 대체 사유(기록): 에지 관측량은 무텍스처 동에서 측정 자체가 붕괴함이 실측됐다(RUN-004: 실패 8동 선두 3동에서 IRLS 3연속 불수렴·유효 뷰 0/41·뷰 중앙 2.32~5.51 m — 3D cm급 증거(datum tie 0.060 m)와 모순 = 오(誤)에지 매칭 정황). 에지 매칭은 영상 증거를 요구하므로 지지율과 같은 범주 오류를 2D에서 재생산한다. 또한 0.3 m 수치의 혈통은 datum tie(3D 높이 맞추기) 합격선 재사용이므로 3D 관측량과 출처가 정합한다.
- **측정 모집단(정정)**: 보정 전 대응수 `n = min(사진→ALS matched, ALS→사진 matched)`가 사전 잠금식 `max(40, nearest-rank Q10) = 40` 이상인 **대응 가능 동**. 대응 불가 동의 수와 층은 별도 보고하되 정합 판정에 쓰지 않는다.
  - 강체성 논거: 한 좌표계의 사진 프레임과 고정 ALS 프레임 사이 오차는 하나의 강체 좌표계 오차다. 측정은 증거가 있는 동에서 하고, 적용은 전 동에 동일 상속한다. 동별 변형은 허용하지 않는다.
- **초과 구현 금지 조항**: 게이트 판정에 쓰는 통계량·문턱은 본 문안에 명시된 것만이다. P90·censored P90·지지율·bias·개선폭은 **보조 기록**으로만 남긴다. 결과 확인 뒤 통계량이나 `n` 문턱을 다시 정하지 않는다.
- **조건부 통계 딱지**: matched 중앙은 0.35 m 반경 안 대응에 조건부인 통계임을 결과 표에 병기한다(전 모집단 정합의 단독 증명으로 쓰지 않는다).
- **투영(렌더링 공간) 취급**: 강체 + 미소 회전(0.008°) 하에서 3D cm급 잔차의 투영 오차는 뷰 GSD 수 px로 상한된다는 논증을 관문 부속으로 명시한다. 정량 에지 게이트는 두지 않는다. 대신 핵심군 전 동에 대해 분류 ALS를 보정판 포즈로 투영한 오버레이 그림(동당 1뷰 이상)을 **정성 확인 기록**으로 생성한다(판정 아님).

## 4. 전역 SE(3) 채택 — 공개 재판정 (잠금)

- **사실 기록(은폐 없음)**: lock2 채택 계약(사전등록: 중앙 0.15·censored P90 0.3·지지율 0.7·bias 0.1·개선폭 절대 0.05 m/상대 20%)은 후보 개선 0.0300 m(19.68%)로 **어떤 변환도 동결하지 않았다**(COREG2-RUN-001, `choice=none`). 본 채택은 그 계약의 재적용이 아니라 별도 판정이다.
- **새 근거(그 계약이 재지 않은 양)**: 진단 T5 전수(값 관측 134동)의 **부호 있는 계통 오프셋** — dZ 지붕 +0.05 m/지면 +0.09 m, 동 가중 총 잔차 0.073360 m가 후보 적용 시 0.004186 m로 소멸. 무부호 중앙 개선폭은 초기 정합이 좋을수록(잔차 바닥 ~7–9 cm) 마진 0.05 m에 구조적으로 도달 불가하며 계통 성분에 둔감하다. 이 계통 오프셋은 §8 눈금 2의 비김 마진(0.05 m)과 같은 자릿수로, 제거하지 않으면 photo 손실과 ALS 감독의 계통적 줄다리기 및 눈금 2 해석 오염이 발생한다.
- **결정**: `coreg_lock2` 전역 후보 — 회전 0.0080702577°, 이동 (+0.040581, +0.020840, −0.097784) m, rank 6, 최종 대응 33,969 — 를 **채택**한다.
  - 적용 대상 = **카메라 포즈만**(보정판 COLMAP 모델 1회 발행). ALS LAZ·영상 픽셀·참조 GML·footprint·ζ=45.7 m·EPSG:25832·scale=1 전부 불변(V3B 계약 계승).
  - 동별·블록별 변형 불허. 3개 촬영 블록 후보의 기각은 유지한다.
  - arm A/B는 동일한 보정판 포즈 해시를 사용한다.
- **잠금 조건**: 본 재판정은 학습·조립·채점 결과 열람 전(전부 0회)에 이루어졌다. 이후 하류 결과를 이유로 한 변환 재조정은 금지한다(문제 발견 시 BLOCKED 보고·재판정 회부만).
