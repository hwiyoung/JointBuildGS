## 1. 질문과 가설

**질문 한 줄: 점군을 고치는 방법(GS 공동최적화)이, 같은 촬영·같은 조립기에서 조립 결과 자체를 좋게 만드는가?**

- **본 비교 실험(코드 E5)**은 4장 실험 사슬(E1 audit → … → E5)의 **최종 확증**이다. §3.2 회귀(07-06, 부분 지지)는
  "어떤 점군 속성이 결과를 가르는가"를 관찰로 보였고, 본 비교 실험은 "그 속성을 실제로 고치면 결과가 좋아지는가"를 확증한다.
- **가설(지목 축 두 채널, §3.2c에서 승계)**:
  - H-의미(라벨 채널 ③′): GS의 semantic 공동최적화가 라벨 오류를 줄여 **조립 성공**을 늘린다.
    (회귀 근거: 라벨 오류↑ → 조립 실패, −1.01 (−1.58..−0.45), 극단 제외·더미·다른 실행 생존)
  - H-기하(노이즈 채널 ②): GS의 기하 공동최적화(depth·구조 항)가 표면 거칢을 줄여 **형상 적합**을 좋게 한다.
    (회귀 근거: 노이즈↑ → rf_rmse↑, +0.167 (0.07..0.26), 여섯 변형 생존 · LiDAR 같은 축 최강 +0.365)
  - H-완전성(절벽 관문): 빈 점군은 예외 없이 실패했다(48/48). GS가 무텍스처에서 점을 만들면
    이 절벽 자체가 움직인다 — 회귀 밖의 1차 결정자라서 별도 관문으로 센다.
- 기여의 두 채널(semantic+기하 공동최적화)이 지목 축 둘(라벨=의미·노이즈=기하)과 1:1로 대응한다 — 이 대응이 본 비교 실험 해석의 뼈대.

### 3.1 기준 레시피 = D4 (확정)


**채택 근거(recipe_registry §4 검증, 07-03 감사):**

- D4는 이후 평가의 기반으로 반복 사용됐다 — D6·D9·D11·D12 지지, B1/D10의 비교 기준이자 config 기반.
- 반박 범위도 정직하게: v6 8-way·raw/LiDAR 대조·투영/모집단 숫자는 D4 기반이 아니다(다른 축이므로 당연).
  D7/D8 라벨은 현 checkout에서 근거 없음(→ §9 판정 ⑦-2, 폐기).
- B1(다시점 일관성 추가판)과의 우열은 추가 검증 불요 — D12에서 교란(confound)으로 결론불가 정리, D4가 기준으로 남은 경위.
- ckpt 해시(레시피 검증 이력의 지문): D4 dense `a4332ea2…d1214` · D4 acmp `03dfd9dd…9be05` (전체 해시 = recipe_registry §4.1).

### 3.2 GS 점군화 — 점군화·라벨 방식(코드명 read-out), GS 시스템의 일부로 사전등록

```
readout(gssem; semantic-TSDF[minobs3, voxel0.05]; Roofer eps0.3/minpts15/complexity0.888)
```

- **원래 점군 규칙(§1.5)의 GS 버전**: raw 입력은 자기 산출물 그대로, GS는 렌더 깊이맵→위 방식으로 점군화 —
  이것이 GS의 "자기 방식"이며, 여기 사전등록함으로써 튜닝 여지를 차단한다.
- **③′ 라벨 채널(빈8ⓒ의 해소)**: raw 입력 = SMRF+경계 규칙(P0 T4 구현). GS = **GS-의미 점군화(gssem)** —
  GS가 학습한 의미 정보로 지붕/지면을 구분해 라벨을 붙인다. 각자 자기 시스템의 라벨.
  그래서 **모든 GS 수치에 점군화·라벨 방식 명기 의무**(§9 ⑦-4).
- **Roofer 정합**: 위 방식의 Roofer 설정(eps 0.3/minpts 15/complexity 0.888)이 P0 정본 런(w2_1, 기본값 실행)과
  같은 기본값 계열인지 발주 시 **지문으로 재확인**한다(④ 고정·입력 종류별 튜닝 금지 — §1.2).

### 3.3 실행 2단 구조 — 파일럿 게이트 (판정 ①의 부속 확정)

**왜**: 기준 레시피는 씨앗별 1회씩만 학습된 실적이고(재현성 미검), 실적 무대(make-or-break 지역 학습 + 71동 확장 평가)가
본 비교 실험(199 전수 신규 학습)보다 작다(일반화 미검). 이 두 검증을 별도 선행 런이 아니라 **본 비교 실험의 1단으로 내장**한다 —
사전등록은 지금 잠그고, 검증은 실행 첫 단계가 담당.

- **1단 파일럿**: 기존 학습 무대 밖 소블록 1개에서 기준 레시피 신규 학습. 게이트 둘 —
  - (재현) 같은 설정 2회 학습(무작위성만 다름)에서 조립 성공 동 집합의 변동이 경미할 것 — 플립 목록 전량 공개, 판정=김휘영.
  - (일반화) 학습→점군화→조립 전 단계 완주 + 절벽형 붕괴 없음(기준선 대비 파국적 저하 없음) — 수치·그림 쌍 제출, 판정=김휘영.
- **2단 전수**: 게이트 통과 후 199 전수 신규 canonical(세 입력 종류). 씨드 상수는 §8 확정값.
- **게이트 실패 시**: §11 사전등록 변경 절차로 복귀 — 레시피 수정은 변경 기록(사유·판정·날짜)으로만.

## 4. 측정 규약 (5축 — §3.1 잠금 사양 승계)

## 5. 성공 기준 — 조립 결과 자체의 개선 ⟦판정 ③, 07-06 확정·잠금⟧

**방향(07-06 김휘영 판정)**: 본 비교 실험의 성공은 속성 개선만으로는 불충분하다.
**조립 결과(성공·유효성·품질 등급)가 좋아져야 한다.** 아래 지표·문구로 잠금 완료.

**문구(잠금):**

> 본 비교 실험의 성공 = GS 점군이 자기 씨드의 기준선(원래 점군) 대비 **조립 결과 자체**를 개선하는 것.
> 속성 5축의 개선은 **설명 고리**(어느 채널이 담당했는지의 매개 증거)로만 쓰며, 그것만으로 성공을 선언할 수 없다.

**지표(잠금) — 세 축 + 관문:**

| 축 | 지표 | 무대 | 성공 방향 |
|---|---|---|---|
| 생성 축 | 조립 성공 동 수(has_lod22, 순증·순감 목록 공개) + McNemar 짝 검정(P0 방식) | 분모 199 · 실질 무대 = dense 실패 64 | 순증 & 기존 성공 동 이탈 없음 |
| 유효성 축 | 유효성 통과율(지어진 모델 기준) | 지어진 전 동 | 기준선 대비 **비열등**(P0에서 DIM −5.4pp 하락했던 축 · 4907019류 껍데기 감시 — 부유점 축과 연동) |
| 품질 축 | 형상 적합 rf_rmse_lod22(paired) + 품질 등급 3단(유효/높이/형상) 일치율 | 품질 무대 114(§2.4 제외 적용) | paired 개선 |
| (관문) H-완전성 | 표면 형성 실패 48동에서 점 생성 여부(밀도·커버리지) | 절벽 무대 48 | 절벽의 이동(P0 그림 1.1의 역전) — 성공 축이 아니라 **해석 관문** |

**판정 문구(잠금):**

- **성공** = 생성 또는 품질 중 **최소 한 축**에서 개선이 세 검사(§6)를 통과하고, **나머지 축과 유효성이 악화되지 않음**.
- **부분 지지** = 축별로 갈리면 "지어지느냐"(생성)와 "잘 지어지느냐"(품질)를 나눠 서술(P0 이원 교훈 · §3.2b 중간 조항 승계).
- **불지지** = 어느 축도 세 검사를 통과하지 못함 → §6 갈래 B.

**채널 귀속(해석 고리 — 주장이 아니라 설명의 순서):**

- 생성이 좋아졌으면 → **라벨 채널 매개 확인**: GS 점군의 라벨 오류율이 기준선보다 낮은가, 특히 개선 동에서.
- 적합이 좋아졌으면 → **노이즈 채널 매개 확인**: 평면 잔차·M3C2가 실제로 줄었는가.
- 부유점은 GS 대표 병리라서 **재측정 유지** — 유효성(껍데기 솔리드) 감시와 연동.
- 매개가 확인 안 되면 "개선은 있는데 경로는 다르다"로 정직하게 쓴다(귀속 단정 금지).

## 6. 판정 기준 — 두 갈래 (§3.2b 이관 · 본 비교 실험용 번역)

**세 검사(§3.2b와 동일 — "일관되게"의 정의):**

1. 우연으로 보기 어렵다 — 신뢰구간이 0을 안 걸침 / 짝 검정 유의.
2. 방향이 가설과 같다 — §1의 H-의미·H-기하 방향(개선).
3. 검사 방식을 바꿔도 남는다 — 정본 런↔감도 런 / 층화 렌즈를 바꿔도 / §2.4 로버스트 제외 후에도.

**갈래 A — "방법이 통했다"로 읽는 경우**: 한 축 이상이 세 검사 통과 →
채널 귀속(§5)으로 어느 기여가 담당했는지 밝히고, 논문 4장의 주장으로 승격. 남는 축은 한계로 정직 서술.

**갈래 B — "방법으로 안 됐다"로 읽는 경우**: 전 축 탈락 →
실패를 라벨 렌즈·관측 통제로 분해해 "관측 조건 지배"인지 "레시피 한계"인지 가른다.
서사 전환은 §3.2b 갈래 B 승계 — "같은 촬영에서 정보를 더 뽑는다(prior 통합·공동최적화)" 프레임 검토는 하되,
**결과를 보고 성공 기준을 바꾸지 않는다**(골대 이동 금지 — 전환은 다음 사이클의 사전등록으로).

**중간**: 축별 분리 서술(§5 부분 지지). 단정 금지. 함께 볼 것: 표본 수·결측·공선성 —
"검사 통과 못함 = 효과 없음"이 아니라 "이 표본으로는 안 보임"으로 쓴다.

**런 규약**: 결과 정본 런 = 신규 canonical(2단, 세 입력 종류 — 지문 표 필수: config·versions·ckpt sha256·점군화·라벨 방식(read-out)·geoid flag·시각).
파일럿(1단) 런도 같은 지문 규약. Roofer 조립은 재현 3회(P0 관례·저비용). GS 학습 감도는 1단 게이트의 재현 2회가 겸한다.
