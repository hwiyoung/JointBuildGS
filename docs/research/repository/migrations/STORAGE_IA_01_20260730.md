# STORAGE-IA-01 physical payload relocation

## Result

On 2026-07-30, 428,296,653,718 bytes in 85,375 files were moved from mixed
repository paths to the sibling `JointBuildGS-artifacts` backend. The operation
used same-filesystem directory renames; before/after device and inode identities
matched for every payload root. No payload file was deleted or rewritten.

The moved roots are `data`, `results`, `reports`, `fair-pilot`,
`phases/p0-audit/data`, and the bulk P0 run tree. The Git checkout retains P0's
189 compact tracked receipt files. The complete original P0 run tree remains in
the backend and is mounted into Docker for historical reproduction.

The active `phases/p2-gsjso/runs` workspace was deliberately not externalized:
the working tree contains live Fusion-W1 staged, unstaged, and untracked work.
Its separation is a later run-closeout action, not part of this migration.

## Compatibility

`docker-compose.yml` exposes the backend at `/artifacts/JointBuildGS` and mounts
historical runtime paths inside the container. Those compatibility paths are
not Git owners and contain no payload bytes in the host repository checkout.

The detailed byte/file/inode inventory is
`artifacts/manifests/local_workspace_20260730.yaml`.
