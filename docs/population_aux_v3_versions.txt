## Adopted parameters (also in QA §2)
SAMPLE_DENSITY   = 1.0 pt/m^2
SAMPLE_CAP       = 400 samples/building
NADIR_MAX_DEG    = 20 deg   (near-nadir: view vs vertical; project convention)
INC_OK_DEG       = 60 deg   (Soudarissanane incidence bound)
PAIR_LO,PAIR_HI  = 10,60 deg (Schoenberger view-selection parallax band)
MAXV_PAIR        = 24       (per-sample view cap for pairwise, lowest-incidence kept; Smith neighborhood)
w_parallax(a)    = exp(-(a-20)^2 / (2*20^2))            [PAR_PEAK=20, PAR_SIG=20]
w_incidence(th)  = max(0, cos(th))                      [pair-mean incidence]
w_distance(d)    = 1 on [20,120] m; linear decay outside [D_LO=20, D_HI=120]
LOWTEX_GRAD      = 0.02   (normalized [0,1] gray Sobel-gradient low-texture threshold; T11 sharp def)
SAT_THRESH       = 0.97   (brightness-saturation = specular proxy)
periodicity      = max autocorrelation peak outside central lobe (radius ~min(h,w)/8); crop downsampled if >512 px
RNG seed         = 0 (numpy; roof-sampling reproducible)

## Notes
- OPF/COLMAP frame is EPSG:32632 (WGS84) vs footprints/GML EPSG:25832 (ETRS89): sub-meter offset,
  negligible for view geometry (incidence/parallax), identical handling to P0 T9 (09_failure_surface_cause).
- Visibility = in-frame reprojection (approx); self/neighbour occlusion NOT strictly modelled in [1]
  (occlusion_frac_approx [4] is the separate coarse neighbour-height LOS proxy).
