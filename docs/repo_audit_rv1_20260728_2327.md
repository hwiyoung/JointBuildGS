## Audit uncertainty carried forward

The repository does not prove that the co-acquired ULS derivatives are vertically tied to the canonical orthometric baseline. Guessing a geoid shift would violate the request. R_v1 therefore uses the already aligned canonical ALS AOI reference and records ULS as unavailable for the primary surface contract. This choice can be revised only by a later explicit, provenance-backed ULS vertical-alignment artifact.
