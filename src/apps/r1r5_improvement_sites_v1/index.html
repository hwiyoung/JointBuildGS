R1–R5를 조사해 원영상과 단면으로 검토한 위치입니다. 아래 위치를 누르면 해당 지점의 3D·단면·사진이 함께 열립니다.

먼저 볼 위치

R3 Z04는 맞는 prior를 DA3 결과가 보존하지 못한 사례이고, R2 Z06는 prior도 틀린 보정 사례입니다. 두 곳을 함께 보면 prior를 모든 위치에서 강화하는 방식의 한계를 검토할 수 있습니다. 개선이 실제로 되는지는 후속 가중치 실험이 필요합니다.

현재 원영상에서 확인한 위치

두 사진의 빨간 상자는 동일한 LiDAR 평가 표본을 투영한 범위입니다. 가려진 표면도 투영은 가능하므로, 아래 보류 사례는 이 상자만으로 외부 표면 대응을 확정하지 않았습니다.

현재 영상 depth와 LiDAR의 관계

입력 depth표본 80% 이상 유효한 영상 / 조사 영상관측 depth − LiDAR 투영 깊이

같은 위치가 화면에 들어오고 위에서 보는 조건의 영상 중, 투영 크기 순 최대24장을 검사했습니다. 각 영상의 차이 중앙값을 다시 중앙값으로 요약했습니다. 음수는 LiDAR보다 카메라 앞쪽입니다. 표면 거리와 다른 지표이며, 가림이 있으면 입력 오류로 단정할 수 없습니다. 전체 학습 영상의 기여량을 뜻하지 않습니다.

큰 거리지만 주 개선 사례에서 보류한 위치

다층 LiDAR, 유리 지붕, 경계와 가림 때문에 평가 표본과 외부 지붕의 대응을 더 확인해야 합니다. 단순 오차 순위가 실패 목록이 될 수 없는 실제 예입니다.

검토 범위

원본 입력·완료 결과를 고정하고 참조용 LiDAR로 찾은 개발 사례입니다. 학습 마스크·가중치·소스 신뢰도 라벨로 전달하지 않았습니다. 국소 메시에서 거리를 재계산해 원본 평가와 일치하는지 검증했습니다.

우선 검색은 평면성이 있는 건물 XY 구역의 표면에 집중했습니다. R1–R5의 모든 외벽·곡면·플로터를 빠짐없이 찾아냈다는 뜻은 아닙니다. 단방향 LiDAR→메시 거리로 추가 표면을 모두 검출할 수 없으며, 같은 datum·정합 조건을 상속한 상대 비교입니다.
