해석과 비교 범위
  • 현재 영역은 수정 후보와 소스 선호 가설입니다. 실제 시간 변화나 올바른 소스라는 판정은 별도 검증이 필요합니다.
  • RGB·MVS는 같은 영상 계보입니다. 영상 자기일치가 독립 정확도 평가를 대신하지 않습니다.
  • 현재 단계는 마스크 추출입니다. Gaussian 연결·수정 전후 평가는 이 결과와 구분합니다.

평가 범위는 기존에 고정한 P1/P2/P3의 XY 투영 범위입니다. 근거가 없는 곳을 팽창·보간하여 채우지 않습니다. 학습 중 영역 갱신은 이번 비교에 포함하지 않습니다.
