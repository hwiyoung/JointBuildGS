R1 일치 영상 수 중앙값—자기 영상 제외 · 동일 MVS 계열
R1의 관측 가능한 다른 영상 수 중앙값—화면 안에 투영되고 유효 depth가 있는 경우

지도 위 청록색은 기존 R1, 초록색은 기존 R2 경계입니다. 전체 프레임을 표시하며 학습 마스크를 변경하지 않았습니다. 회색은 값 없음, 숫자 0은 검사 결과 지지가 없음을 뜻합니다.

해당 영상의 수치 지도 NPZ · 집계 JSON · depth 경계 지도 · 그림을 누르면 확대합니다.

개수 지도는 작은 값도 구분되도록 비선형 눈금을 사용합니다. 모든 영상에 같은 눈금을 적용했습니다. 가운데 잔차는 일치 기준을 통과한 관측에 한정되며, 아래 전체 잔차와 구분합니다.

지도를 읽는 순서

① 관측 가능 수
0이면 비교할 다른 depth가 없습니다. 불일치와 관측 부재를 구분합니다.
② 일치 수·잔차
현재 MVS 점을 다른 depth가 지지하는 정도입니다. 동일 추정기의 일치이므로 독립 정확도는 아닙니다.
③ 관측각·가림·경계
작은 관측각의 일치, 앞쪽 가림, 실제 지붕 경계를 별도로 읽습니다.

잔차 지도는 가림 후보도 포함합니다. 큰 잔차 하나로 MVS 오류라고 판정하면 안 됩니다. 관측각이 크다는 사실만으로 더 정확하다고 판단하지도 않습니다. Prior–MVS 차이 역시 어느 쪽이 맞는지 알려주지 않습니다.

R1 / R2 / R3 집계와 허용 오차 민감도

같은 픽셀에서 depth 허용 오차 10·25·50cm를 비교합니다. 모든 조건에 RGB 왕복 투영 오차 2px 이하를 함께 적용합니다. 이는 이번 진단 기준이며 원래 COLMAP 필터값은 아닙니다.

R1을 실제로 지지하는 영상

전체 후보 중 R1 지지가 많은 영상 순입니다. 각 영상이 R1 유효 표본의 몇 %를 지지하는지 표시합니다. 단 1픽셀 포함과 넓은 영역 지지를 구분해 볼 수 있습니다.

이번 단계의 범위

  • 대표 5개 영상: P1 0100_D, P2 0146_D·0108_D, P3 0142_D·0046_D. 비교 후보는 원래 MVS의 937장입니다.
  • 원본 depth의 4픽셀 간격 표본입니다. 빠른 진단 지도이며 전체 해상도의 학습 가중치가 아닙니다.
  • 지역 GS 학습 영상 집계는 해당 지역의 평가 영상을 제외합니다. 937장 집계는 평가 영상도 포함하므로 참고 진단으로만 구분합니다. 원본 MVS 자체도 이 전체 계열에서 만들어졌습니다.
  • 자료 구멍을 채우거나 depth·학습 마스크·checkpoint를 변경하지 않았습니다. GT를 사용하지 않았고 추가 학습도 없습니다.
  • 낮은 지지가 실제 부정확성과 연결되는지는 후속 평가 대상입니다. 이번 색을 그대로 자동 가중치로 쓰지 않습니다.
