원사진 · 입력 depth · 가중치 영역

촬영 영상을 바꾸면 아래 영역도와 세 조건의 GS RGB·depth가 함께 바뀝니다. 3D 표시 범위 선택은 기하 화면만 자르며, 입력 영역도는 전체 프레임을 표시합니다. 사진과 렌더는 고정 촬영 시점이며 위 3D 회전에 따라 바뀌지 않습니다.

원사진과의 학습뷰 일치도는 독립적인 복원 정확도 평가가 아닙니다. 가중치 0은 R1의 MVS 감독을 끈 조건이며 RGB·prior 감독은 남아 있습니다.

실제 학습에 사용한 depth 가중치 영역

입력 MVS의 색 = 깊이값 · 영역 분류의 색 = R1–R6 · 가중치 그림의 색 = 0 / 1 / 4. 각 그림의 범례를 구분해 읽어주세요.

P2/P3 도면 안의 ‘검토용 초안·학습에 아직 연결하지 않았습니다’는 도면 제작 당시의 기록입니다. 현재는 표시된 동일 마스크로 학습과 후처리가 완료됐습니다.
