# Research inspection apps

Small browser-facing applications used to inspect declared experiment evidence.
Application source and pinned browser dependencies live here; runtime datasets
and generated assets are resolved from external artifact storage.

- `gs3d_4way_viewer/` — Gaussian-splat, raster, and surfel inspection
- `experiment_dashboard/` — experiment comparison dashboard and templates
- `mvs_als_source_relation_viewer_v1/` — simultaneous MVS/Existing-ALS and five-class source-relation inspection
- `mvs_als_surface_patch_viewer_v1/` — raw five-class versus connected source-surface patch inspection
