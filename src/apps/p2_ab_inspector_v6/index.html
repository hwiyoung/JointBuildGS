실제 관측 결과를 불러오는 중입니다.

파랑·주황: 서로 다른 사진 그룹의 위치별 비교 비용. 음영: 관측 위치 범위. 초록: 조건부 사용오차를 만족하는 결과 위치 범위. 선이 낮다는 사실만으로 현재 기하의 절대 정확도를 인증하지 않습니다.

같은 초기값에서의 결과

공통 픽셀 MAE: 작을수록 좋음. 같은 사진의 같은 평가 픽셀에서 비교합니다.

렌더의 검정은 P2 렌더 지지가 없는 영역입니다. 영역 밖과 미복원이 함께 포함될 수 있어 모두 실제 결손을 뜻하지는 않습니다.

색이 잘 맞는다는 사실만으로 현재 기하의 정확도나 구조 복원을 확인할 수는 없습니다.

선택 목록의 법선·깊이 변화·갱신 마스크는 기하 진단입니다. 초기 마스크는 A 관측 위치, 최종 마스크는 1mm 초과 이동한 Gaussian 중심을 3픽셀로 표시합니다. 깊이 변화 색상은 0–0.3m입니다.

미해결 관측점과 A 관측이 없는 배경은 비교용 초기 MVS로 남아 있습니다. 화면 전체가 A에서 채택된 기하라는 뜻이 아닙니다. 보호 ray 검사는 33개 학습 뷰의 제한된 표면 위치를 대상으로 합니다.
