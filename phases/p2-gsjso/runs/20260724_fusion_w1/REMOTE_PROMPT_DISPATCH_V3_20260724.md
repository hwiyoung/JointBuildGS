## §2. 관문 A — 레이저-영상 위치 정합 (학습 진입 조건)

- 방법: 분류 ALS(지붕·지면)를 각 학습 뷰에 투영 → 건물 지붕 경계·에지와 영상 에지의 정합 잔차를 뷰별·동별로 측정(px와 m 병기). 전 뷰 계통 오프셋(평행이동 성분) 별도 보고.
- 산출: 잔차 분포 표(뷰별 중앙·P90) + 투영 오버레이 그림(대상 동 각 1장 이상).
- **합격선(확정)**: 동별 잔차 중앙 ≤ **0.3 m**(datum tie 합격선 재사용) ∧ 계통 오프셋 무시 가능. 불합격 → 미세 정합(ICP류) 1회 시도 후 재측정, 그래도 불합격이면 **학습 진입 금지·BLOCKED 보고**.

## §3. 시드·감독 준비 + 투입 시드 점검(P0′)

- **시드(레이저 점군 시드)**: 기하 무가공 원칙 — 대상 서브셋 범위 크롭 + 색 부여(영상 투영 샘플)만. 다운샘플·가시성 필터 **기본 생략**. 메모리 초과 시에만 최소 복셀 다운샘플 적용하고 파라미터·전후 점수 기록.
- **감독(시드 유래 조밀 depth/normal)**: 분류 ALS로 2.5D TIN(지붕+지면)을 만들어 각 학습 뷰에 래스터화한 depth 맵과 normal 맵. 유효 픽셀 마스크 필수(TIN 외곽·급경사 경계는 마스크 아웃 — 감독은 유효 픽셀만). 벽면은 감독하지 않음(지붕·지면만).
- **P0′(투입 시드 점검, 값싼 귀속 통제)**: 실제 투입 시드(가공 후)를 분류→Roofer로 1회 조립·채점. 기대=P0 Ref-L과 동급(0실패). 다르면 가공 원인 기록.

## §4. 학습 (건물 서브셋 · 2 arm · 2런)

- 서브셋: footprint + 지면 버퍼 **20 m**, 해당 동 관측 뷰 10~30장(GS4Buildings 규모와 동급). 뷰 목록 CSV 저장.
- **arm A — 기본형(시드+감독; GS4Buildings-동형, prior 원천만 모델→레이저 측정)**: 시드 초기화 + photo(기존 설정) + 시드 유래 depth L1 + normal 각도 손실 + 2단계 스케줄(전반 prior 강조 → 후반 가중 감쇠·표면 정칙화 활성) + 기존 생존 보호·이웃 마스킹. 가중 시작값(확정): **depth 0.5·normal 0.05**(문헌 기본) — 2단계 감쇠 스케줄과 함께 config에 기록.
- **arm B — 감독 제거(한 변수 ablation)**: arm A에서 depth/normal 감독 항만 제거, 나머지 전부 동일. 예상(사전 기록): 무텍스처에서 시드 훼손 재현.
- 런: 각 arm 2런(요동 실측). 반복 수 **30k**. **항별 손실 비중 로그 필수**(켜짐 검증 — "loss를 믿지 말라").
- 중간 체크포인트 렌더 패널(RGB·depth) 저장 — 정성 기록.

## §5. 점군화 → 조립 → 채점 (직렬)

- 점군화: 기존 정본 설정 그대로(변경 금지·버전 기록). → 분류 → **동일 Roofer(기본값)** → CityJSON.
- 채점(전 눈금 기존 정본 스크립트 재사용): LoD2 달성/폴백(조립 성립), val3dity, plane F1, RMS 짝(vs 레이저만 0.50 / vs 영상 점군 0.76 — 짝 정의·분모 명기), 완전율, 면수비. + **P0′(시드 자체 채점) 대비 델타 = 학습 몫 분리**.
- 층화: 동별 텍스처 층 태그(T9/T11 규격) 붙여 무텍스처/텍스처 층 분리 집계.
- 정성: 동별 패널(입력 영상 crop / 시드 탑뷰 / 학습 후 점군 탑뷰·단면 / 조립 모델 / 참조) — 전 대상 동.

## §7. 우선순위 큐·시간 끊김 규칙 (무인 드라이버 조항)

1. §0 preflight → §2 관문 A(핵심군 우선 측정, 확장군은 처리 직전 동별 측정) → §3 시드·감독 준비(핵심군 선행, 확장군은 처리 직전 동별 준비).
2. **스모크 1동**(실패 8동 중 1동): arm A r1 한 바퀴를 조립·채점까지 관통 — 파이프 결함 발견 시 전체 중단·보고(관문 규율). **동시에 1런 소요 시간을 측정해 "예상 처리 동수"를 로그로 남길 것**(밤의 규모는 큐가 스스로 정한다).
3. 핵심군 × arm A × r1 (순서: 실패 8 → GS4Buildings 겹침 → 표면 짝 10 → 높이 4·윤곽 4 → textured 2)
4. 핵심군 × arm A × **r2(재현)** — 확장군보다 우선(판정은 재현 있는 동만 가능).
5. arm B(감독 제거): 실패 2동 + textured 1동. 여력 시 확대.
6. **확장군 × arm A × r1** — 층 균형 라운드로빈, 시간 끝까지.
7. (그래도 남으면) 확장군 r2.
- 각 동 완료 즉시 산출물 저장(부분 결과도 아침 검수 가능 상태). **새벽 06:30 컷** — 그 시점 완료분으로 채점·집계·보고 생성 전환. 처리율(동/시간)과 도달 순번을 보고에 명기.
- 파국 중단 규칙: 같은 오류 3회 반복 시 해당 동 스킵·기록, 오류 유형이 3동 연속이면 해당 단계 전체 중단·보고.

## §8. 판정 눈금 — 사전 선언 (결과 열람 전 잠금 · 판정은 아침 검수에서 김휘영)

- **눈금 1 조립 성립(생성축)**: 실패 8동 중 arm A의 LoD2 달성 동 수. 참조점: 영상 점군=0/8(P0), 레이저만=8/8(P0 Ref-L). 관심 질문: **융합이 8/8을 유지하는가**(훼손 없음) — 미달 동은 원인 분해 대상.
- **눈금 2 시드 유지(품질·무텍스처 층)**: RMS 짝(융합) ≤ RMS 짝(레이저만) + 0.05 m(비김 마진) — 유지면 성공, 초과 악화면 훼손.
- **눈금 3 개선(품질·텍스처 층/경계)**: textured 층·경계부에서 융합 < 레이저만 여부 — 탐색적(융합의 존재 이유 후보, 이번 파는 관찰만).
- **눈금 4 감독 제거 대조**: arm B에서 무텍스처 훼손 재현 여부(예상=재현) — "시드+감독 둘 다 필요"의 완결 증거.
- 2런 요동: 눈금 판정은 2런 중앙, 요동 폭 병기.
- **판정 범위 선언**: 눈금 1~4의 판정은 **핵심군(2런 재현 확보 동)** 기준. 확장군(r1만)은 관찰·본선 예열 재료로만 집계(층별 요약표) — 단독 판정 금지.
