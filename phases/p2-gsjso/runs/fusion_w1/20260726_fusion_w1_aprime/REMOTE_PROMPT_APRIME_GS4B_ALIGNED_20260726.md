## §P. 사전등록 — arm A′ 계약 (결과 열람 전 잠금)

- **P1 시드**: ALS **class 6(건물)만** — 지면(class 2)·SfM 점 제외. **가시성 필터**(GS4B 동형): 각 점을 학습 뷰에 레이캐스트해 깊이 일치 |d_int−d_exp| < **ε=5 cm**(논문 명시값)인 뷰가 **k=3** 이상인 점만 유지(k는 논문 미공개 → 3 채택·여기 명시). 필터 후 시드 <50점인 동은 진행하되 "시드 과소" 딱지. 색 부여는 기존 절차(가림 검사 포함). 벽 없음 = ALS prior의 실체(합성 벽은 이번 제외·다음 칸 후보로만 기록).
- **P2 감독**: **지붕 마스크 안 픽셀만** 감독 — class 6 유래 지붕 TIN을 각 학습 뷰에 레이캐스트한 depth/normal + 유효 교차 마스크 M_j. 손실은 **(1/|M_j|) 정규화**(GS4B 동형 — 건물이 화면에서 작아도 감독 강도 불감) + depth 스케일 α 정렬. **지면·벽 감독 없음**(비건물 무유도는 GS4B도 명시적으로 감수). 경계 유효 마스크·급경사 마스크 아웃은 유지.
- **P3 손실·스케줄**: `L_total = L_c + λ_d·L_distortion + λ_n·L_normal-consistency + λ_db·L_depth-prior + λ_nb·L_normal-prior`(GS4B 식 구조). 2단계: 전반 = prior 항(λ_db·λ_nb) 강조 → 후반 = prior 감쇠 + **표면 정칙화(L_distortion·L_normal-consistency) 활성**. 전환 시점: 논문 미공개 → **15k/30k 절반 분할** 채택·명시. 수치: λ_db=0.5·λ_nb=0.05 유지 — **출처는 GS4B 아님**(논문 무수치·"2DGS 하이퍼 불변" 선언뿐)·실출처=CityGaussianV2(depth 0.5)·DN-Splatter 계열(normal 0.05~0.1). 그 외 하이퍼는 2DGS 공개 기본값 그대로("불변" 원칙 준수)·전량 config 기록.
- **P4 역학**: **시드 보호 전면 제거** — 2DGS 기본 densification/pruning/opacity reset 복원(GS4B도 무보호·"하이퍼 불변"). seed-lineage 보호 코드는 off를 config로 명시. 시드 잔존 수·지붕 영역 opacity 중앙의 iteration 궤적은 **로그 관찰만**(개입 금지).
- **P5 산출**: **TSDF fusion + Marching Cubes**(2DGS 파이프라인·voxel/절단 파라미터 기록) → mesh 표면 샘플 점군 = class 6 + **원본 ALS class 2 지면 합류**(기존 prior 재활용=전제 불파괴 논리·합류 방식 기록) → Roofer(기본값) → CityJSON → 채점. 기존 W1 alpha 점군 readout도 **병행 산출**(비교 기록용 — 판정에는 미사용).
- **P6 판정 눈금**: 원 §8 유지·A′ 적용 — ① 조립 성립(LoD2 달성/폴백) ② 시드 유지: RMS 짝(A′) ≤ RMS 짝(P0′-A′, 시드만 조립) + 0.05 m ③ 개선 관찰(텍스처 층·경계) ④ arm B(감독 제거) 대조 — 사전 예상: 무텍스처 훼손 재현. 판정은 검수 세션에서 김휘영·2런 재현 동 기준. arm A 스모크 결과는 기록 보존·판정 미사용.
- **P7 대상 명단(사전 선언 분기)**: **1순위 = GS4B 9개 subset 겹침 동.** 먼저 `w1_targets.csv`의 GS4Buildings 겹침 기록(원 §1에서 요구)을 확인하고, 없거나 미해결이면 공개 저장소(zqlin0521/GS4Buildings README·그림)와 논문 그림에서 9개 subset의 건물 위치·ID 식별을 시도해 우리 178 명단과의 겹침을 기록한다. **식별 성공 시**: 겹침 동 전부 + 실패 8동 병합이 대상. **식별 불가 시(fallback·여기 선언)**: 대상 9동 = **실패 8동 전수 + textured 대조 4908023**. 명단은 정본 CSV 조인·ID 손입력 금지·선정 사유 기록.
- **P8 무인 조항**: 사용자 질의 금지·시간 컷 없음(06:30류 컷 폐지) — **명단 완주까지 실행 후 보고**. 파국 규칙은 유지: 같은 오류 3회=해당 동 스킵·기록, 같은 오류 유형 3동 연속=해당 단계 중단·그 시점까지 산출로 보고. 각 동 완료 즉시 산출물 저장(부분 결과도 검수 가능 상태).

## §T. Preflight — A′ 진입 전 필수 3 + 기록 부록 2

- **T1 표면 정칙화 실활성 검증(필수)**: 스모크 arm A 손실 로그에서 L_distortion·L_normal-consistency 항의 활성 여부를 실측 확인하고, 미니 스모크(수백 iter)로 A′ config에서 항별 손실 비중 > 0을 검증("loss를 믿지 말라"·D4 `w_distort=0.0` 전례). 죽어 있으면 구현 수리 후 회귀시험·기록 — 이게 살아야 A′의 후반부가 성립한다.
- **T2 TSDF readout 리허설(필수)**: TSDF+MC 구현을 기존 arm A 스모크 체크포인트로 동작 확인(파라미터·산출 기록). 지붕 회복 기대 없음(opacity 실측상) — 목적은 A′가 의존할 산출 경로의 검증.
- **T3 새 시드 P0′(필수)**: A′ 시드(P1 구성) + 원본 지면 합류 → Roofer 조립·채점(학습 0). 이 값이 눈금 ②의 새 기준점(학습 몫 분리). 기대=P0 Ref-L 동급.
- **T4 기록 부록(30분 컷 — 이 항목만 시간 상한)**: 스모크 arm A 붕괴 궤적 그림 1장 — 지붕 영역 opacity 중앙 vs iteration + 단계 전환·감쇠 시점 선. 논문·검수 재료(판별 목적 아님).
- **T5 기록 부록**: 대상 동 전수의 지붕 마스크 픽셀 비율·시드 점수(필터 전/후) 표 — preprocess manifest 집계.
- **issues 등재 3건**: ㉮ 가중치 귀속 정정(λ 0.5/0.05는 GS4B 아님·출처 명시) ㉯ arm A 스모크 실패 정식 등재(지붕 유령화·보호 역설 — 기존 기록 있으면 참조 연결) ㉰ 시드 보호 제거 사유(GS4B 무보호 성립·opacity가 프루닝 대행하던 병목 제거).

## §R. 실행 순서 (무인·컷 없음)

1. preflight: 5핀(보정판 포즈 해시 기준) + T1→T2→T3(T4·T5는 병렬 가능) + 발주문 사본 run 폴더 커밋. T1~T3 중 하나라도 실패 시 그 지점에서 BLOCKED 보고(학습 진입 금지).
2. **스모크 관통**: 42364609(실패 8 선두·arm A와 동일 동) arm A′ r1을 조립·채점까지 관통 — 파이프 결함 확인용. 관통 실패 시 파국 규칙 적용·보고. (관통=파이프가 도는가이며 품질 판정 아님 — 판정은 사람.)
3. 본 실행: P7 대상 전 동 × arm A′ × r1 → 전 동 × r2(재현) → arm B(감독 제거): 실패 2동 + textured 1동. 각 동 즉시 저장.
4. 채점·집계: 원 §5 눈금 전 지표 + P0′-A′ 델타(학습 몫) + 층화 태그. 정성 패널: 동별 [입력 crop / A′ 시드 탑뷰 / 학습 후 TSDF mesh·점군 탑뷰·단면 / 조립 모델 / 참조] + **지붕 opacity 궤적 그래프**(전 동).
5. 보고: 한 장 요약(눈금 1~4 값·동별 표·GS4B 겹침 식별 결과) → T1~T5 결과 → 단계별 표·패널 링크 → issues → 미완 목록. **해석·판정 문장 금지**(검수에서 김휘영).
