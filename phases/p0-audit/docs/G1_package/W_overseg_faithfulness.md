"GS가 ALS보다 정확" 가설은 미지지.

## §2 cp(평면성 손실) 정의 — 단차 경계를 아는가? (코드 추출)

- **L_coplanar**(`src/stage2/loss/structure.py:7,51-52`) = `mean_{i∈group} (n_k[g(i)]·c_i + d_k[g(i)])²` — 그룹 대표평면(n_k,d_k **detach**)에 각 프리미티브 **중심 c_i를 끌어당김**(점-평면거리²). c_i만 gradient, n_k/d_k/f_i 비미분. → **무엇을 평면화?** 같은 그룹의 중심들을 한 평면으로.
- **그룹 정의 = g2**(`grouping.py:134-271`, D4/D5 공통 `structure_grouping: g2`): ① 프리미티브→**voxel 2m**(`structure_voxel_size 2.0`)+dir_bin(법선) 셀; ② 셀-레벨 union-find: **26-이웃 voxel** 셀끼리 `|n_i·n_j|>0.92(~23°)` **AND** `max(|n_i·Δc|,|n_j·Δc|)<0.5m`(`merge_d_tol`) 이면 병합. **단일연결(single-linkage)**, regroup 매 1000 iter.
- **단차 인지(핵심)**: `merge_d_tol=0.5m`는 **수평셀의 경우 Δz<0.5m일 때만 병합** → **실 단차(>0.5m)는 병합 차단** = cp 그룹은 **단차 경계를 안다**(Phase-A facet-merge의 off=1.0m·무제한 chaining과 **다름**). 즉 원리상 cp는 **한 레벨 안 조각만 합치고 실 단차는 보존** 가능.
- **두 잠재 빈틈(이론)**: (a) **단일연결 chaining** — <0.5m 미세 단차 연쇄 시 큰 z-span 병합(코드검증: 0.4m×3 → 0.8m span 1그룹); (b) **regroup가 매번 현재 기하에 수행**(train.py) → cp 일찍 발화 시 단차 형성 전 가로질러 평탄화 가능. **단 둘 다 코드상 위험이며 D5 d5c(early)에선 미실현**(§3: 오히려 깨끗) → 이론적 주의로만.

## §4 종합 (판정 금지 — Phase B 입력)

**① faithful-vs-defect (동별 결론)**: **결함(defect), 단 아형=±1~2.5m 높이오차**(통째 날조 아님). 정량 = 4906969 최선 정합서도 **5/14만 실레벨 받침**; 나머지 9 = 허위1+한-레벨-내2+어긋남(1~2.5m)6. **반대가설(GS가 ALS 놓친 실구조 포착) 검증 실패**(떠있는면 아래 ALS 0~6%만 0.5m내·이차클러스터 없음). 대조 박공 k=3/3로 방법 검증. 정성 = UAV로 **구조 복합도 실재**·ALS가 3 실레벨 이미 포착·GS는 **±1~2.5m 어긋난 조각**을 더함. → GS 초과면은 "ALS가 놓친 실구조" **아님**; GS 표면이 실레벨서 **±1~2.5m wavy**. (42364659·4907510 = 희박/양봉으로 면받침 신뢰낮음[표 회색] → 레벨구조만; **4906969·박공 정본**.)

**② cp가 로컬·단차맹인가**: **단차-인지**(merge_d_tol 0.5m가 실 단차>0.5m 병합 차단 = Phase-A facet-merge의 무제한 chaining과 다름; 코드검증 0.49 병합·0.51 차단). **두 잠재 한계**: (a) **단일연결 chaining**(<0.5m 미세단차 연쇄 시 0.8m span 합쳐짐 — 코드검증) + **regroup가 현재 기하에 수행**→ 일찍-발화 시 단차 형성 전 평탄화 가능 = **이론적 위험(코드상 실재)이나 D5 d5c에선 미실현**(오히려 허위면 제거로 깨끗); (b) GS 한-레벨-내 waviness가 **>0.5m**(±1~2.5m 어긋난 6면)이라 cp 0.5m-tol로는 못 합침(tol 올리면 실 단차 붕괴 위험). → **cp는 facet-merge보다 단차-안전**하나 **0.5m-tol 한계로 4906969류 ±1~2.5m wavy 어긋남엔 약함**.

**③ Phase B 입력(판정=김휘영)**:
- **충실 아님 → "면수↓ 접고 ④정확도 전환"은 비지시**(GS가 ALS보다 정확하지 않음; 실레벨서 ±1~2.5m wavy). **결함이므로 완화가 옳은 목표** — **단 목표=면수 아니라 표면 정확도(틀린 높이를 실레벨로 교정)**. Phase A(후처리 면수↓)는 실패(높이 그대로 틀림).
- **cp vs structure-G2**: cp(단차-인지 grouping)는 facet-merge보다 단차 보존에 유리하고, **D5 d5c(cp-early)가 허위면 제거로 더 깨끗** = cp/structure-G2가 **유효 방향**(D5 "(다) 부분 레버"와 정합). **단 ⓐ 0.5m-tol이 >0.5m within-level 어긋남(±1~2.5m)을 못 끌어옴** = 핵심 한계. ⓑ early-fire 단차붕괴는 **이론적 주의(D5 미실현)**라 "반드시 late" 처방은 **근거 약함**(1차 처방 철회).
- → **지시**: structure-G2를 **단차경계 탐지 후 within-level의 ±1~2.5m 어긋난 면을 실레벨로 끌어당기되(적응적 tol·곡률/레벨-인지) 실 단차(>0.5m)는 보존**. 단순 cp 강화(D5b=과분절)·Phase-A facet-merge(단차붕괴)는 비지시. (warmup 타이밍은 이론적 변수로 병기, 강제 아님.)
