## §A 건물 단위 상관 [핵심] (gs_d4, n=78, 편상관 통제=footprint_area·als_span·als_levels)

**결함 3축 × 관측가능성(텍스처 T9/T11 · 커버리지 T7), 각각 변수로(합산 아님):**

| 결함축 ~ 관측 | r_part (p, n) | 읽기 |
|---|---|---|
| **height ~ tex_lowratio** | **−0.06 (0.65, 70)** | 텍스처 **무상관** |
| height ~ tex_grad_p10 | −0.07 (0.58, 76) | 무상관 |
| height ~ hole_ratio | −0.28 (**0.014**, 78) | 약·**역방향**(구멍↑→결함↓) |
| height ~ view_count·incidence·occlusion·dim_density | +0.07·+0.17·−0.13·−0.08 (ns) | 무상관 |
| **slope ~ tex_*** | +0.10·−0.21 (ns~0.067) | 텍스처 무상관 |
| slope ~ dim_density | +0.30 (**0.007**) | **역방향**(밀도↑→기울기오차↑=복잡도 교란) |
| slope ~ view_count·hole_ratio | +0.26·−0.28 (sig, 역방향) | 복잡도 교란 의심 |
| **psd ~ tex_*** | −0.02·−0.12 (ns) | 텍스처 무상관 |
| psd ~ hole_ratio·occlusion | −0.31·−0.23 (sig, 역방향) | 약·역방향 |

→ **텍스처는 어느 결함축과도 유의 상관 0**(r≈−0.06, p>0.3). 커버리지(hole_ratio·dim_density·view_count)는 약하나 **부호가 반직관**(커버리지↑→결함↑, 또는 구멍↑→결함↓) = **복잡도·면수 교란**(복잡 건물이 면·뷰·밀도 多). **"결함=관측가능성" 재정의 미확인.**

**⭐ 결정적 반증(텍스처 극단 대비)**: 무텍스처-실패 8동 vs 생존 71동 — **높이 결함 중앙값 0.5 vs 1.43**(무텍스처가 **더 낮음**!), PSD 2.3 vs 2.5(≈). 즉 **무텍스처 건물이 결함 더 적음** — 가설과 정반대. (무텍스처-실패 8동은 **무텍스처지만 기하 단순**(소형 평지붕)이라 GS가 잘 복원; 생존동이 더 다양·복잡. slope 13 vs 32는 생존동 피치 교란.) → **관측가능성(무텍스처) 단독은 높이 결함을 일으키지 않음.**

정성: `docs/figs/W_D12/A_{height,slope,psd}.png`(관측 vs 결함 산점, 빨강=T9 무텍스처극단).

## §C B1 생사 [판정] — **둘 다 실패 → 죽임(사전등록 규칙)**

| 기준 | 결과 | 판정 |
|---|---|---|
| **1 받침** k/(k+m) D4→B1 | Δ=**+0.039**(<+0.10); Wilcoxon(건물쌍 77) **p=0.36**; McNemar(면 flip 잃음197/얻음222) **p=0.24** | **FAIL**(비유의·<+0.05) |

## §D 생성 성과 [모집단]

- **GS 생성 ≈ 보편**: 텍스처/커버리지 가진 70동 중 **70동 전부 GS 생성 성공**(roofer_ok & 면>0) → 클래스 불균형으로 로지스틱 불가. **무텍스처-실패 8동(DIM 0면)도 GS-JSO가 전부 복원**(assembly-fidelity 정합). → **관측가능성은 GS 생성을 가르지 않음**(무텍스처서도 생성). 오라클 상한 = 79(T7)/93(census).
- 정성: DIM실패·GS성공 = 무텍스처 8동(4907182 등, [[W_phaseB_structure]] D6 textureless). 단 생성됨 ≠ 충실(D6: ~2.5m 저편향 평슬랩).

## §E 종합 (판정 금지 — 관찰·진단·권고; 판정=김휘영)

① **재정의 미확정(반증 우세)**: **결함↔관측가능성 = 약-무상관**(텍스처 r≈0 전축; 커버리지 약·역방향=복잡도 교란) + **무텍스처극단이 오히려 저결함**(0.5<1.43). D11(결함≠복잡도)와 합치면 **GS 높이 결함은 복잡도도 관측가능성도 깔끔히 설명 못 함 = per-building 특이적**. **병목은 높이-특이도 전-축도 아닌, 관측가능성-무관**. (단 텍스처 표본은 생존동 중심=범위제한·면별 미측정·결함메트릭 희박ALS 노이즈 = 약화요인, 신호 자체가 0에 가까움.)
② **B1 죽임**: 사전등록 2기준 둘 실패(받침 Δ+0.04 p>0.3·텍스처 r≈0) → 다시점 일관성 종료.
③ **생성 서사**: GS 생성 보편(70/70·DIM실패 8동 복원), 관측가능성-무관. 충실(품질)과 분리.
④ **다음 권고(판정=김휘영)**: B1 죽음 → **깊이·법선 prior**(다시점 아님). 단 **깨진 축이 관측가능성과 안 묶이므로** 감독 종류를 관측가능성으로 못 고름 → **결함은 재구성 품질(깊이·법선 직접감독) 문제로 재프레임** 권고. 추가: 면별 텍스처 1회 산출로 §B 면 단위 직접검정 마무리(보류분); slope/수평 메트릭 정련(슬리버·희박ALS 게이트) 후 재해석.
