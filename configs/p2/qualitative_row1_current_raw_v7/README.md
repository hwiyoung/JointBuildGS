# Inactive v7 browser-overlay configurations

The JSON files in this directory bind historical add-once JPEG/SVG browser-overlay
experiments. They are retained only to explain and verify those external artifacts.
They are not execution authority for the current 199-building qualitative row.

Current execution authority is
`configs/p2/qualitative_row1_current_raw_v6/render199_v1.json`, which extends only the
accepted `preview10_v4` membership from 10 to the ordered 199 buildings and requires
the web viewer to consume exact rendered PNG bytes without redraw.
